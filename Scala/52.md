# Euler Problem 52 Solution in Scala

## Problem Statement
It can be seen that the number 125874 and its double 251748 contain exactly the same digits, but in a different order.

Find the smallest positive integer x such that 2x, 3x, 4x, 5x, and 6x contain the same digits.

## Solution

```scala
object Euler52 {
  def main(args: Array[String]): Unit = {
    val result = findSmallestInteger()
    println(s"The smallest positive integer is: $result")
  }
  
  def findSmallestInteger(): Long = {
    Stream.from(1)
      .find(x => hasSameDigits(x, 2 * x) && 
                 hasSameDigits(x, 3 * x) && 
                 hasSameDigits(x, 4 * x) && 
                 hasSameDigits(x, 5 * x) && 
                 hasSameDigits(x, 6 * x))
      .get
  }
  
  def hasSameDigits(x: Long, y: Long): Boolean = {
    val xDigits = x.toString.sorted
    val yDigits = y.toString.sorted
    xDigits == yDigits
  }
}
```

## Explanation

The solution works as follows:

1. **Main Logic**: We use `Stream.from(1)` to generate an infinite stream of positive integers starting from 1.

2. **Finding the Solution**: We use the `find` method to locate the first integer `x` that satisfies our condition.

3. **Digit Comparison**: The `hasSameDigits` function:
   - Converts both numbers to strings
   - Sorts the characters in each string
   - Compares the sorted strings for equality
   - If they're equal, the numbers contain the same digits

4. **Condition**: We check that `x` has the same digits as `2x`, `3x`, `4x`, `5x`, and `6x`.

## Key Insights

- **Sorting Approach**: By sorting the digits of both numbers, we can easily compare if they contain the same digits regardless of order
- **Efficiency**: The solution is efficient because we only check multiples up to 6x, and the stream is lazy (only generates numbers as needed)
- **Mathematical Insight**: The answer turns out to be 142857, which is a cyclic number
