# Euler Problem 628 Solution in Scala

## Problem Statement
The problem asks us to find the number of ways to write a positive integer n as a sum of positive integers, where the order doesn't matter (partitions) and each part is at least 2.

## Solution Approach
This is a classic partition problem with a constraint. We need to count the number of partitions of n into parts where each part is ≥ 2.

## Scala Implementation

```scala
object Euler628 {
  def main(args: Array[String]): Unit = {
    val result = countPartitions(1000, 2)
    println(s"Answer: $result")
  }
  
  /**
   * Count the number of partitions of n into parts of size at least minPart
   * Uses dynamic programming with memoization
   */
  def countPartitions(n: Int, minPart: Int): Long = {
    val memo = scala.collection.mutable.Map[(Int, Int), Long]()
    
    def partitions(remaining: Int, minAllowed: Int): Long = {
      if (remaining == 0) return 1L
      if (remaining < 0 || minAllowed > remaining) return 0L
      if (minAllowed == remaining) return 1L
      
      memo.get((remaining, minAllowed)) match {
        case Some(result) => result
        case None =>
          var count = 0L
          // Try all possible parts from minAllowed to remaining
          for (part <- minAllowed to remaining) {
            count += partitions(remaining - part, part)
          }
          memo((remaining, minAllowed)) = count
          count
      }
    }
    
    partitions(n, minPart)
  }
  
  /**
   * Alternative implementation using Bell numbers approach
   * For this specific problem, we can also use a more direct DP approach
   */
  def countPartitionsDP(n: Int, minPart: Int): Long = {
    // dp[i][j] = number of ways to partition i using parts >= j
    val dp = Array.ofDim[Long](n + 1, n + 1)
    
    // Base case: 0 can be partitioned in 1 way (empty partition)
    for (j <- 0 to n) {
      dp(0)(j) = 1L
    }
    
    // Fill the DP table
    for (i <- 1 to n) {
      for (j <- 1 to n) {
        if (j > i) {
          dp(i)(j) = 0L
        } else {
          // Either don't use part j, or use part j
          dp(i)(j) = dp(i)(j + 1) + dp(i - j)(j)
        }
      }
    }
    
    dp(n)(minPart)
  }
  
  /**
   * Most efficient approach - using recurrence relation
   */
  def countPartitionsEfficient(n: Int, minPart: Int): Long = {
    val memo = scala.collection.mutable.Map[(Int, Int), Long]()
    
    def p(n: Int, k: Int): Long = {
      if (n == 0) return 1L
      if (n < 0 || k > n) return 0L
      if (k == n) return 1L
      
      memo.get((n, k)) match {
        case Some(result) => result
        case None =>
          val res = p(n, k + 1) + p(n - k, k)
          memo((n, k)) = res
          res
      }
    }
    
    p(n, minPart)
  }
}
```

## Mathematical Analysis

The problem is asking for the number of partitions of n into parts where each part is at least 2. This is equivalent to finding the number of partitions of (n-2) into parts of size at least 1, but with a different indexing.

Let's think of it this way:
- We want partitions of n where each part ≥ 2
- This is the same as partitions of n-2 where each part ≥ 1 (by subtracting 1 from each part)
- But we need to be more careful about the counting

## Key Insights

1. **Dynamic Programming**: The solution uses memoization to avoid recalculating subproblems
2. **Recurrence Relation**: For each remaining sum, we try all possible parts starting from the minimum allowed
3. **Optimization**: We ensure that parts don't decrease (to avoid counting the same partition multiple times)

## Time and Space Complexity

- **Time Complexity**: O(n²) in the worst case, but much better with memoization
- **Space Complexity**: O(n²) for the memoization table
