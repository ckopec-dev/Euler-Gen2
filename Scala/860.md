# Euler Problem 860 Solution in Scala

I'll solve Euler Problem 860, which involves finding the number of ways to tile a 3×n rectangle with 2×1 dominoes.

## Problem Understanding

We need to find the number of ways to tile a 3×n rectangle using 2×1 dominoes. This is a classic dynamic programming problem.

## Approach

Let's define `f(n)` as the number of ways to tile a 3×n rectangle. We can use dynamic programming by considering how the rightmost columns can be filled.
