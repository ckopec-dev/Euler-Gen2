# Euler Problem 116 Solution in Scala

## Problem Statement
A row of 50 blocks is to be filled with tiles of different lengths. We have three types of tiles:
- Red tiles of length 2
- Green tiles of length 3  
- Blue tiles of length 4

The tiles cannot overlap and must fill the entire row. How many different ways can we fill a row of 50 blocks?

## Solution Approach
This is a classic dynamic programming problem. We'll use the principle of inclusion-exclusion or direct DP where we count the number of ways to fill a row of length `n` using the given tile sizes.

Let `dp[n]` represent the number of ways to fill a row of length `n`.

## Scala Implementation

```scala
object Euler116 {
  def main(args: Array[String]): Unit = {
    val targetLength = 50
    val result = countWays(targetLength)
    println(s"Number of ways to fill a row of length $targetLength: $result")
  }
  
  def countWays(length: Int): Long = {
    // dp[i] represents number of ways to fill a row of length i
    val dp = new Array[Long](length + 1)
    
    // Base case: one way to fill empty row
    dp(0) = 1
    
    // For each position, try placing each type of tile
    for (i <- 1 to length) {
      // Place red tile (length 2)
      if (i >= 2) dp(i) += dp(i - 2)
      
      // Place green tile (length 3)
      if (i >= 3) dp(i) += dp(i - 3)
      
      // Place blue tile (length 4)
      if (i >= 4) dp(i) += dp(i - 4)
    }
    
    dp(length)
  }
  
  // Alternative approach: solve for each color separately
  def countWaysSeparate(length: Int): Long = {
    // Count ways for red tiles (length 2)
    val redWays = countWaysForLength(length, 2)
    // Count ways for green tiles (length 3)  
    val greenWays = countWaysForLength(length, 3)
    // Count ways for blue tiles (length 4)
    val blueWays = countWaysForLength(length, 4)
    
    redWays + greenWays + blueWays
  }
  
  def countWaysForLength(length: Int, tileLength: Int): Long = {
    val dp = new Array[Long](length + 1)
    dp(0) = 1
    
    for (i <- 1 to length) {
      if (i >= tileLength) dp(i) += dp(i - tileLength)
    }
    
    dp(length)
  }
}
```

## Explanation

The solution uses dynamic programming where:
1. `dp[i]` represents the number of ways to fill a row of length `i`
2. For each position `i`, we can place a tile of length 2, 3, or 4 (if there's enough space)
3. The recurrence relation is: `dp[i] = dp[i-2] + dp[i-3] + dp[i-4]` (when applicable)
4. Base case: `dp[0] = 1` (one way to fill empty row)


The solution efficiently computes the result in O(n) time complexity with O(n) space complexity, where n = 50.
