## Problem Statement
Consider the number 142857. We can right-rotate this number to get 714285, and then we can right-rotate again to get 571428, and so on. We can see that 142857 is a cyclic number because all rotations are multiples of 142857.

Find the sum of all n-digit cyclic numbers where n is between 1 and 10.

## Solution Approach
A cyclic number is a number where all rotations are multiples of the original number. For an n-digit cyclic number, when we rotate it right, each rotation should be a multiple of the original number.

Let's think about this systematically:
- For an n-digit number, we need to check if all rotations are multiples of the original number
- We can generate numbers and test them for the cyclic property
- The key insight is that for a number to be cyclic, its rotations must follow a specific pattern
