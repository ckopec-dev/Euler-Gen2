# Euler Problem 778 Solution in Scala

I'll solve Euler Problem 778, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

We need to find the number of ways to express a number n as a sum of powers of 2 (2^0, 2^1, 2^2, ...) where each power can be used at most twice.

This is equivalent to finding the number of partitions of n using parts that are powers of 2, where each part can appear at most twice.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to partition the number.

```scala
import scala.collection.mutable

object Euler778 {
  
  def countWays(n: Long): Long = {
    val memo = mutable.Map.empty[(Long, Int), Long]
    
    def dp(remaining: Long, maxPower: Int): Long = {
      if (remaining == 0) return 1
      if (remaining < 0 || maxPower < 0) return 0
      
      memo.getOrElseUpdate((remaining, maxPower), {
        val power = 1L << maxPower  // 2^maxPower
        val maxUses = if (power <= remaining) 2 else 0
        
        // Try using 0, 1, or 2 of the current power
        var result = dp(remaining, maxPower - 1)  // Use 0 of current power
        
        if (maxUses >= 1 && remaining >= power) {
          result += dp(remaining - power, maxPower - 1)  // Use 1 of current power
        }
        
        if (maxUses >= 2 && remaining >= 2 * power) {
          result += dp(remaining - 2 * power, maxPower - 1)  // Use 2 of current power
        }
        
        result
      })
    }
    
    dp(n, 30)  // 2^30 is sufficient for reasonable inputs
  }
  
  // Alternative approach using generating functions
  def countWaysOptimized(n: Long): Long = {
    val memo = mutable.Map.empty[Long, Long]
    
    def dp(remaining: Long): Long = {
      if (remaining == 0) return 1
      if (remaining < 0) return 0
      
      memo.getOrElseUpdate(remaining, {
        var result = 0L
        var power = 1L
        
        // For each power of 2, we can use 0, 1, or 2 copies
        while (power <= remaining) {
          // Use 0 copies
          result += dp(remaining)
          // Use 1 copy
          if (remaining >= power) {
            result += dp(remaining - power)
          }
          // Use 2 copies
          if (remaining >= 2 * power) {
            result += dp(remaining - 2 * power)
          }
          power *= 2
        }
        
        result
      })
    }
    
    dp(n)
  }
  
  // More efficient bottom-up approach
  def countWaysBottomUp(n: Long): Long = {
    val dp = new Array[Long](n.toInt + 1)
    dp(0) = 1
    
    var power = 1L
    while (power <= n) {
      for (i <- (power to n).toInt) {
        // Add ways to form i using 0, 1, or 2 copies of power
        dp(i) += dp(i - power)  // 1 copy
        if (i >= 2 * power) {
          dp(i) += dp(i - 2 * power)  // 2 copies
        }
      }
      power *= 2
    }
    
    dp(n.toInt)
  }
  
  def main(args: Array[String]): Unit = {
    // Test with small values
    println(s"n=1: ${countWaysBottomUp(1)}")  // Expected: 1 (1 = 2^0)
    println(s"n=2: ${countWaysBottomUp(2)}")  // Expected: 2 (2 = 2^1 or 2^0 + 2^0)
    println(s"n=3: ${countWaysBottomUp(3)}")  // Expected: 3 (3 = 2^1 + 2^0 or 2^0 + 2^0 + 2^0 or 2^1 + 2^0)
    
    // For the actual problem
    val result = countWaysBottomUp(1000000000000L)
    println(s"Result: $result")
  }
}
```

## Explanation

The solution uses a dynamic programming approach:

1. **Bottom-up DP approach**: We build up the solution from smaller values
2. **State definition**: `dp[i]` represents the number of ways to write number `i` as sum of powers of 2 (each used at most twice)
3. **Transition**: For each power of 2 (2^k), we update all values that can include this power:
   - We can use 0, 1, or 2 copies of 2^k
   - For each valid count, we add the number of ways to form the remaining amount

## Key Insights

- Each power of 2 can be used 0, 1, or 2 times
- We process powers in increasing order (2^0, 2^1, 2^2, ...)
- The recurrence relation is: `dp[i] += dp[i - 2^k] + dp[i - 2*2^k]` for each valid power k

## Time and Space Complexity

- **Time Complexity**: O(n log n) where n is the input number
- **Space Complexity**: O(n) for the DP array

The bottom-up approach is most efficient for large inputs like the one required in Euler Problem 778.
