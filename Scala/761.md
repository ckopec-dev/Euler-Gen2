```scala
object Euler761 {
  
  def countDistinctPartitions(n: Int): Long = {
    val dp = Array.fill(n + 1)(0L)
    dp(0) = 1
    
    // For each part size from 1 to n
    for (part <- 1 to n) {
      // Update from right to left to prevent using updated values
      for (i <- n downTo part) {
        dp(i) += dp(i - part)
      }
    }
    
    dp(n)
  }
  
  def main(args: Array[String]): Unit = {
    val answer = countDistinctPartitions(1000000)
    println(s"The number of partitions of 1000000 into distinct parts is: $answer")
  }
}
```

This solution uses dynamic programming where `dp[i]` represents the number of ways to partition the integer `i` into distinct positive integers. The recurrence relation is:
- `dp[0] = 1` (one way to partition 0: empty partition)
- For each part size `j`, we update `dp[i] += dp[i-j]` for all `i >= j`

The time complexity is O(n²) and space complexity is O(n). For n = 1000000, this approach would be computationally intensive but theoretically correct.
