# Euler Problem 706 Solution in Scala

I'll solve Euler Problem 706, which asks for the sum of all integers n where the number of ways to write n as a sum of distinct positive integers (partitions into distinct parts) is odd.

## Problem Understanding

The problem asks us to find all integers n where p(n) is odd, where p(n) is the number of partitions of n into distinct parts, and then sum all such n.

## Mathematical Insight

Let's think about this step by step:

1. We need to count partitions of n into distinct positive integers
2. We want to find all n where this count is odd
3. We sum all such n

## Approach

I'll use the generating function approach and dynamic programming to count partitions into distinct parts, then check which ones have odd counts.

## Scala Implementation

object Euler706 {
  
  def countPartitionsIntoDistinct(n: Int): Int = {
    // Using dynamic programming to count partitions into distinct parts
    val dp = Array.fill(n + 1)(0)
    dp(0) = 1
    
    // For each number i from 1 to n
    for (i <- 1 to n) {
      // We go backwards to avoid using updated values in same iteration
      for (j <- n downTo i) {
        dp(j) += dp(j - i)
      }
    }
    
    dp(n)
  }
  
  def solve(limit: Int): Long = {
    var sum = 0L

      if (countPartitionsIntoDistinct(n) % 2 == 1) {
        sum += n
      }
    }

  }
