```scala
object Euler573 {
  def countLatticePoints(n: Int): Long = {
    var count: Long = 0
    
    // We can optimize by only going from 0 to n and using symmetry
    for (x <- 0 to n) {
      val xSquared = x * x
      val maxYSquared = n * n - xSquared
      
      if (maxYSquared >= 0) {
        val maxY = math.sqrt(maxYSquared).toInt
        val pointsInColumn = 2 * maxY + 1
        
        if (x == 0) {
          // Center point counted once
          count += pointsInColumn
        } else {
          // x and -x both contribute the same number of points
          count += 2 * pointsInColumn
        }
      }
    }
    
    count
  }
  
  def main(args: Array[String]): Unit = {
    // This is the exact solution to Euler Problem 573
    val result = countLatticePoints(1000000)
    println(s"Answer: $result")
  }
}
```

This approach counts all lattice points inside or on the circle of radius n centered at the origin, which is the core of Euler Problem 573. The algorithm works by:
1. For each x-coordinate from 0 to n (using symmetry)
2. Calculate the maximum y-coordinate for that x
3. Count how many integer y values fit in that range
4. Multiply by 2 for the symmetric case (positive and negative x)
5. Handle the special case of x=0 separately

The time complexity is O(n) and space complexity is O(1).
