# Euler Problem 93 Solution in Scala

## Problem Statement
By using each of the numbers from the set, {1, 2, 3, 4}, exactly once, and making use of the four arithmetic operations (+, −, ×, ÷) and brackets, we can form different positive integer targets.

For example,
- 3 × 4 × (2 − 1) = 12
- 4 × (3 + 2) − 1 = 19
- 4 × (3 − 1) × 2 = 16

Note that concatenation of numbers is not allowed.

Using the set, {1, 2, 3, 4}, it is possible to obtain thirty-one different target numbers. Find the set of four distinct digits a < b < c < d for which the longest set of consecutive positive integers 1 to n can be obtained, giving your answer as a string: abcd.

## Solution Approach

We need to:
1. Generate all combinations of 4 distinct digits from 1-9
2. For each combination, generate all possible expressions using the 4 digits and 3 operators
3. Calculate all possible results and count consecutive integers starting from 1
4. Find the combination that gives the maximum consecutive count
