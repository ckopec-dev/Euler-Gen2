# Euler Problem 189 Solution in Scala

## Problem Statement
We have a triangle divided into smaller triangles by drawing lines from each vertex to the opposite side, creating a triangular grid. Each triangle can be colored with one of three colors (red, green, blue). The constraint is that no two triangles sharing an edge can have the same color.

We need to find the number of ways to color a triangle grid with this constraint.

## Analysis
This is a classic graph coloring problem on a triangular lattice. Let's approach this systematically:

1. The problem involves a triangular grid where each triangle shares edges with adjacent triangles
2. We have 3 colors available
3. Adjacent triangles (sharing an edge) cannot have the same color
4. This is equivalent to finding the chromatic polynomial for a triangular lattice

    if (n == 0) return 3

    val twoPow2nMinus1 = 1L << (2 * n - 1)

  }
  
  // More precise mathematical approach
  def solveMath(n: Int): Long = {
    // For triangular lattice with 3 colors, the chromatic polynomial
    // gives us: f(n) = 3 * (2^(2n-1) - 2^(n-1) + 1)
    
    val pow2_2n1 = 1L << (2 * n - 1)  // 2^(2n-1)

  }

2. **Recursive structure**: Each new layer adds more constraints but maintains the pattern
