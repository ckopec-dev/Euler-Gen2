# Euler Problem 108 Solution in Scala

## Problem Statement
In the following equation, where x, y, and n are positive integers:
```
1/x + 1/y = 1/n
```
Find the smallest value of n for which the number of distinct solutions exceeds 1000.

## Mathematical Analysis

First, let's rearrange the equation to find a relationship:
```
1/x + 1/y = 1/n
xy = n(x + y)
xy - nx - ny = 0
xy - nx - ny + n² = n²
(x - n)(y - n) = n²
```

This means we need to find the number of divisors of n², but we need to be careful about counting. Since x and y are positive integers and x ≠ y (unless x = y = 2n), we can use the fact that the number of solutions is related to the number of divisors.

For the equation 1/x + 1/y = 1/n, the number of distinct solutions is:
- If n is a perfect square: (d(n²) + 1)/2 where d(n²) is the number of divisors of n²
- If n is not a perfect square: (d(n²) - 1)/2

Actually, let's reconsider this more carefully. The equation can be rewritten as:
```
1/x + 1/y = 1/n
xy = n(x + y)
xy - nx - ny = 0
xy - nx - ny + n² = n²
(x - n)(y - n) = n²
```

So if (x-n) = d and (y-n) = n²/d, then:
- x = n + d
- y = n + n²/d

For positive integers x and y, we need d > 0 and n²/d > 0, which means d must be a positive divisor of n².

The number of solutions is equal to the number of positive divisors of n², but we need to count unordered pairs (x,y) where x ≤ y.

3. Actually, let's think differently - for each divisor d of n² where d ≤ n²/d, we get a solution
4. But since we want x,y positive integers, we can directly count divisors of n² that are ≤ √(n²) = n

## Scala Implementation

```scala
object Euler108 {
  def countDivisors(n: Long): Int = {
    var count = 0
    val sqrt = math.sqrt(n).toLong
    for (i <- 1L to sqrt) {
      if (n % i == 0) {
        if (i * i == n) count += 1
        else count += 2
      }
    }
    count
  }
  
  def solve(target: Int): Long = {
    var n = 1L
    while (true) {
      val divisors = countDivisors(n * n)
      val solutions = (divisors + 1) / 2
      if (solutions > target) return n
      n += 1
    }
    0L
  }
  
  def main(args: Array[String]): Unit = {
    val result = solve(1000)
    println(s"The smallest value of n for which the number of distinct solutions exceeds 1000 is: $result")
  }
}
```
