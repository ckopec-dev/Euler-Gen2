# Euler Problem 768 Solution in Scala

Let me solve this step by step.

First, let me understand what Euler Problem 768 asks for:
- Find the sum of all positive integers n ≤ 10^17 such that n has exactly 17 divisors
- A positive integer n has exactly d divisors if and only if n can be written in the form n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ where (a₁ + 1)(a₂ + 1)...(aₖ + 1) = d

For n to have exactly 17 divisors:
- Since 17 is prime, the only way to write 17 as a product of integers ≥ 2 is 17 = 17 × 1
- This means n must be of the form p^16 where p is prime
- The divisors are 1, p, p², ..., p^16, so there are exactly 17 divisors

So we need to find all primes p such that p^16 ≤ 10^17.

Let me implement this in Scala:

```scala
object Euler768 {
  def main(args: Array[String]): Unit = {
    val limit = 10L.pow(17)
    val result = sumOfPrimesWith17Divisors(limit)
    println(s"Sum of all positive integers ≤ 10^17 with exactly 17 divisors: $result")
  }
  
  def sumOfPrimesWith17Divisors(limit: Long): Long = {
    // We need primes p such that p^16 ≤ limit
    // This means p ≤ (limit)^(1/16)
    val maxPrime = math.pow(limit, 1.0/16.0).toLong
    
    val primes = sieveOfEratosthenes(maxPrime)
    
    // For each prime p, check if p^16 ≤ limit
    primes
      .filter(p => p.toLong.pow(16) <= limit)
      .map(p => p.toLong.pow(16))
      .sum
  }
  
  def sieveOfEratosthenes(limit: Long): List[Int] = {
    if (limit < 2) return List()
    
    val sieve = Array.fill(limit.toInt + 1)(true)
    sieve(0) = false
    sieve(1) = false
    
    for (i <- 2 to math.sqrt(limit).toInt) {
      if (sieve(i)) {
        var j = i * i
        while (j <= limit) {
          sieve(j) = false
          j += i
        }
      }
    }
    
    (2 to limit.toInt).filter(sieve).toList
  }
}
```

The problem asks for positive integers n ≤ 10^17 with exactly 17 divisors.

Since 17 is prime, the only way to factor 17 is as 17 = 17 × 1.
This means n must be of the form p^16 where p is prime.
The divisors of p^16 are 1, p, p^2, ..., p^16, so there are exactly 17 divisors.

So we want to find all primes p such that p^16 ≤ 10^17.

The maximum value of p is floor((10^17)^(1/16)) = floor(10^(17/16)) = floor(10^1.0625) ≈ 11.5.
