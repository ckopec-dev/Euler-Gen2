# Euler Problem 56 Solution in Scala

## Problem Statement
A googol (10^100) is a massive number: one followed by one-hundred zeros; 100^100 is almost unimaginably large: one followed by two-hundred zeros. Despite their size, the sum of the digits in each number is only 1.

Considering natural numbers of the form, a^b, where a, b < 100, what is the maximum digital sum?

## Solution

```scala
def digitSum(n: BigInt): Int = {
  n.toString.map(_.asDigit).sum
}

def solve(): Int = {
  (1 until 100)
    .flatMap(a => (1 until 100).map(b => BigInt(a).pow(b)))
    .map(digitSum)
    .max
}

val result = solve()
println(result)
```

## Explanation

1. **digitSum function**: Takes a `BigInt` and calculates the sum of its digits by:
   - Converting the number to a string
   - Mapping each character to its digit value using `asDigit`
   - Summing all the digits

2. **solve function**: 
   - Uses `flatMap` to generate all combinations of a^b where a, b < 100
   - For each combination, calculates a^b using `BigInt(a).pow(b)`
   - Maps each result to its digit sum
   - Returns the maximum digit sum

3. **Key considerations**:
   - Uses `BigInt` to handle very large numbers (like 99^99)
   - The `flatMap` creates a Cartesian product of all a,b combinations
   - The solution efficiently computes the maximum without storing all intermediate results

## Result
The maximum digital sum is **972**

This occurs for numbers like 99^95, which produces a very large number whose digits sum to 972.
