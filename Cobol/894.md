# Euler Problem 894 Solution in COBOL

I'll solve Euler Problem 894, which asks for the sum of all numbers n ≤ 10^16 such that n is divisible by 3 and the sum of digits of n is 3.

## Problem Analysis

First, let me understand what we're looking for:
- Numbers n where n ≤ 10^16
- n is divisible by 3
- Sum of digits of n equals 3
- We need to find the sum of all such numbers

## COBOL Solution

```cobol

       PROGRAM-ID. EULER894.
       AUTHOR. AI Assistant.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  N                       PIC 9(16) VALUE 0.
       01  DIGIT-SUM               PIC 9(16) VALUE 0.
       01  TEMP-N                  PIC 9(16) VALUE 0.
       01  DIGIT                   PIC 9 VALUE 0.
       01  TOTAL-SUM               PIC 9(20) VALUE 0.
       01  COUNT                   PIC 9(16) VALUE 0.
       01  I                       PIC 9(16) VALUE 0.
       01  J                       PIC 9(16) VALUE 0.
       01  K                       PIC 9(16) VALUE 0.
       01  M                       PIC 9(16) VALUE 0.
       01  N-START                 PIC 9(16) VALUE 3.
       01  LIMIT                   PIC 9(16) VALUE 10000000000000000.
       01  DIGIT-ARRAY             PIC 9(16) OCCURS 16 TIMES.
       01  DIGIT-ARRAY-INDEX       PIC 9(2) VALUE 1.
       01  DIGIT-ARRAY-LENGTH      PIC 9(2) VALUE 16.
       01  FOUND                   PIC X VALUE 'N'.
       01  IS-DIVISIBLE-BY-3       PIC X VALUE 'N'.

       PROCEDURE DIVISION.
       MAIN-LOGIC.
           DISPLAY "Solving Euler Problem 894"
           DISPLAY "Finding sum of numbers <= 10^16 divisible by 3 with digit sum = 3"
           
           MOVE 3 TO N-START
           MOVE 0 TO TOTAL-SUM
           
           PERFORM CALCULATE-SUM UNTIL N > LIMIT
           
           DISPLAY "Sum of all qualifying numbers: " TOTAL-SUM
           STOP RUN.

       CALCULATE-SUM.
           IF N > LIMIT THEN GO TO END-PROGRAM.
           
           MOVE N TO TEMP-N.
           PERFORM CALCULATE-DIGIT-SUM.
           
           IF DIGIT-SUM = 3 THEN
               IF N MOD 3 = 0 THEN
                   ADD N TO TOTAL-SUM
               END-IF
           END-IF.
           
           ADD 3 TO N.
           GO TO CALCULATE-SUM.

       CALCULATE-DIGIT-SUM.
           MOVE 0 TO DIGIT-SUM.
           MOVE TEMP-N TO TEMP-N.
           
           IF TEMP-N = 0 THEN
               MOVE 0 TO DIGIT-SUM
               GO TO END-DIGIT-SUM
           END-IF.
           
           PERFORM UNTIL TEMP-N = 0
               COMPUTE DIGIT = TEMP-N MOD 10
               ADD DIGIT TO DIGIT-SUM
               COMPUTE TEMP-N = TEMP-N DIV 10
           END-PERFORM.
           
       END-DIGIT-SUM.
           EXIT.

       END-PROGRAM.
```
