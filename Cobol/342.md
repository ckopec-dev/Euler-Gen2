# Euler Problem 342 Solution in COBOL

Euler Problem 342 asks to find the sum of all positive integers n ≤ 10^16 such that σ(n) = σ(n-1) + σ(n-2), where σ(n) is the sum of divisors function.

Here's the COBOL solution:

       01  QUOTIENT         PIC 9(16) VALUE 0.
       01  REMAINDER        PIC 9(16) VALUE 0.

       01  MAX-N            PIC 9(16) VALUE 1000000000000000.
       01  SQRT-N           PIC 9(16) VALUE 0.
       01  SQRT-TEMP        PIC 9(16) VALUE 0.
       01  IS-SOLUTION      PIC 9 VALUE 0.
       01  COUNT            PIC 9(16) VALUE 0.
       01  LOOP-COUNT       PIC 9(16) VALUE 0.

       PROCEDURE DIVISION.
       MAIN-PROGRAM.
           DISPLAY "Solving Euler Problem 342"
           DISPLAY "Finding sum of all n <= 10^16 where sigma(n) = sigma(n-1) + sigma(n-2)"

           MOVE 3 TO N-VALUE
           MOVE 0 TO SUM-RESULT
           MOVE 0 TO COUNT

           IF N-VALUE > MAX-N GO TO END-PROGRAM

           COMPUTE N-MINUS-1 = N-VALUE - 1
           COMPUTE N-MINUS-2 = N-VALUE - 2

           IF N-VALUE > 2
               CALL "CALCULATE-SIGMA" USING N-VALUE, SIGMA-N
               CALL "CALCULATE-SIGMA" USING N-MINUS-1, SIGMA-NM1
               CALL "CALCULATE-SIGMA" USING N-MINUS-2, SIGMA-NM2

               IF SIGMA-N = SIGMA-NM1 + SIGMA-NM2
                   ADD N-VALUE TO SUM-RESULT
                   ADD 1 TO COUNT

                   DISPLAY "Sigma(" N-VALUE ") = " SIGMA-N

           GO TO LOOP-START

           DISPLAY "Total solutions found: " COUNT

       CALCULATE-SIGMA.
           01  PARM-N           PIC 9(16).
           01  PARM-SIGMA       PIC 9(20).
           01  LOCAL-N          PIC 9(16).
           01  LOCAL-SIGMA      PIC 9(20).
           01  LOCAL-DIVISOR    PIC 9(16).
           01  LOCAL-QUOTIENT   PIC 9(16).
           01  LOCAL-REMAINDER  PIC 9(16).

           MOVE 0 TO LOCAL-SIGMA
           MOVE 1 TO LOCAL-DIVISOR
           COMPUTE LOCAL-SQRT-N = FUNCTION SQRT(LOCAL-N)

       CALC-SIGMA-LOOP.
           IF LOCAL-DIVISOR > LOCAL-SQRT-N GO TO CALC-SIGMA-END

           COMPUTE LOCAL-QUOTIENT = LOCAL-N / LOCAL-DIVISOR
           COMPUTE LOCAL-REMAINDER = LOCAL-N MOD LOCAL-DIVISOR

               ADD LOCAL-DIVISOR TO LOCAL-SIGMA

               IF LOCAL-DIVISOR NOT EQUAL TO LOCAL-QUOTIENT
                   ADD LOCAL-QUOTIENT TO LOCAL-SIGMA
               END-IF
           END-IF

           ADD 1 TO LOCAL-DIVISOR
           GO TO CALC-SIGMA-LOOP

       CALC-SIGMA-END.
           MOVE LOCAL-SIGMA TO PARM-SIGMA
           EXIT PROGRAM.
