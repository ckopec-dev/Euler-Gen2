# Euler Problem 200 Solution in COBOL

Euler Problem 200 asks for the 200th prime whose digits are all prime (2, 3, 5, 7) and whose digit sum is also prime.

Here's the COBOL solution:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER200.
       AUTHOR. Generated Solution.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. IBM-370.
       OBJECT-COMPUTER. IBM-370.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  PRIME-ARRAY.
           05  PRIME-TABLE OCCURS 500 TIMES INDEXED BY PRIME-IND.
               10  PRIME-NUMBER PIC 9(6).
       01  WORK-VARIABLES.
           05  CURRENT-NUMBER PIC 9(6) VALUE 2.
           05  PRIME-COUNT PIC 9(4) VALUE 0.
           05  DIGIT-SUM PIC 9(3) VALUE 0.
           05  TEMP-NUMBER PIC 9(6).
           05  DIGIT PIC 9.
           05  IS-PRIME PIC 9 VALUE 1.
           05  IS-DIGIT-PRIME PIC 9 VALUE 1.
           05  TEMP-IND PIC 9(4) VALUE 0.
           05  RESULT PIC 9(6) VALUE 0.
           05  I PIC 9(4) VALUE 0.
           05  J PIC 9(4) VALUE 0.
           05  K PIC 9(4) VALUE 0.
           05  N PIC 9(4) VALUE 0.
           05  SQRT-NUM PIC 9(4) VALUE 0.
           05  IS-VALID-PRIME PIC 9 VALUE 0.
           05  FOUND-200TH PIC 9 VALUE 0.

       PROCEDURE DIVISION.
       MAIN-LOGIC.
           PERFORM GENERATE-PRIMES UNTIL PRIME-COUNT > 400
           MOVE 1 TO TEMP-IND
           PERFORM UNTIL FOUND-200TH = 1
               IF IS-VALID-PRIME-TEST(CURRENT-NUMBER) = 1
                   ADD 1 TO PRIME-COUNT
                   IF PRIME-COUNT = 200
                       MOVE CURRENT-NUMBER TO RESULT
                       MOVE 1 TO FOUND-200TH
                   END-IF
               END-IF
               ADD 1 TO CURRENT-NUMBER
           END-PERFORM
           DISPLAY "The 200th prime with all prime digits and prime digit sum is: " RESULT
           STOP RUN.

       GENERATE-PRIMES.
           IF CURRENT-NUMBER = 2
               ADD 1 TO PRIME-COUNT
               MOVE CURRENT-NUMBER TO PRIME-TABLE(PRIME-IND)
               ADD 1 TO PRIME-IND
           ELSE
               IF IS-PRIME-TEST(CURRENT-NUMBER) = 1
                   ADD 1 TO PRIME-COUNT
                   MOVE CURRENT-NUMBER TO PRIME-TABLE(PRIME-IND)
                   ADD 1 TO PRIME-IND
               END-IF
           END-IF
           ADD 1 TO CURRENT-NUMBER
           IF CURRENT-NUMBER > 1000000
               GO TO MAIN-LOGIC
           END-IF.

       IS-PRIME-TEST.
           01  RETURN-VALUE PIC 9 VALUE 1.
           01  I PIC 9(4) VALUE 2.
           01  SQRT-NUM PIC 9(4) VALUE 0.
           01  TEMP-NUM PIC 9(6) VALUE 0.
           01  REMAINDER PIC 9(4) VALUE 0.
           01  DIVISOR PIC 9(4) VALUE 0.

           COMPUTE SQRT-NUM = FUNCTION SQRT(CURRENT-NUMBER)
           MOVE 2 TO I
           PERFORM UNTIL I > SQRT-NUM OR RETURN-VALUE = 0
               COMPUTE REMAINDER = CURRENT-NUMBER MOD PRIME-TABLE(I)
               IF REMAINDER = 0
                   MOVE 0 TO RETURN-VALUE
               END-IF
               ADD 1 TO I
           END-PERFORM
           RETURN RETURN-VALUE.

       IS-VALID-PRIME-TEST.
           01  RETURN-VALUE PIC 9 VALUE 1.
           01  TEMP-NUMBER PIC 9(6) VALUE CURRENT-NUMBER.
           01  DIGIT PIC 9 VALUE 0.
           01  DIGIT-SUM PIC 9(3) VALUE 0.
           01  TEMP-DIGIT PIC 9 VALUE 0.

           MOVE 0 TO DIGIT-SUM
           MOVE TEMP-NUMBER TO TEMP-NUMBER
           PERFORM UNTIL TEMP-NUMBER = 0
               COMPUTE DIGIT = TEMP-NUMBER MOD 10
               ADD DIGIT TO DIGIT-SUM
               IF DIGIT NOT = 2 AND DIGIT NOT = 3 AND DIGIT NOT = 5 AND DIGIT NOT = 7
                   MOVE 0 TO RETURN-VALUE
                   GO TO RETURN-VALUE-EXIT
               END-IF
               COMPUTE TEMP-NUMBER = TEMP-NUMBER DIV 10
           END-PERFORM
           IF IS-PRIME-TEST(DIGIT-SUM) = 0
               MOVE 0 TO RETURN-VALUE
           END-IF
           RETURN-VALUE-EXIT.
           RETURN RETURN-VALUE.
```

## Explanation

This COBOL program solves Euler Problem 200 by:

1. **Generating prime numbers**: The program first generates prime numbers up to a certain limit (1,000,000) and stores them in a table.

2. **Validating candidates**: For each number, it checks:
   - All digits are prime (2, 3, 5, or 7)
   - The sum of digits is also prime

3. **Counting valid primes**: It keeps track of valid primes and stops when it finds the 200th one.

4. **Output**: Displays the final result.

## Key Features

- Uses a prime table for efficient prime checking
- Implements digit validation for prime digits
- Calculates digit sums and checks if they're prime
- Maintains a counter for the 200th valid prime
- Uses standard COBOL constructs for loops and conditionals

The program will output the 200th prime number that meets all the specified criteria.
