# Euler Problem 826 Solution in COBOL

Euler Problem 826 asks us to find the sum of all positive integers n ≤ 10^15 such that n is divisible by 3 and n! is divisible by n^3.

Let me solve this step by step:

## Problem Analysis

For a positive integer n:
- n must be divisible by 3
- n! must be divisible by n^3

Let's analyze when n! is divisible by n^3.

## Mathematical Insight

For n! to be divisible by n^3, we need to examine the prime factorization.

If n = 3^k × m where m is not divisible by 3, then we need to check the divisibility condition.

After mathematical analysis, it turns out that n must be of the form 3^k where k ≥ 2.

This is because:
- For n = 3^k, we need 3^k to divide (3^k)! / 3^(3k) = (3^k)! / 3^(3k)
- The power of 3 in n! is given by Legendre's formula: ⌊n/3⌋ + ⌊n/9⌋ + ⌊n/27⌋ + ...
- For n = 3^k, this becomes: 3^(k-1) + 3^(k-2) + ... + 1 = (3^k - 1)/2
- We need (3^k - 1)/2 ≥ 3k, which is true for k ≥ 2

So we need 3^k where k ≥ 2 and 3^k ≤ 10^15.

## COBOL Solution

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER826.
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. IBM-370.
       OBJECT-COMPUTER. IBM-370.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  N-POWER-3        PIC 9(16) VALUE 1.
       01  SUM              PIC 9(20) VALUE 0.
       01  TEMP             PIC 9(20).
       01  LIMIT            PIC 9(16) VALUE 1000000000000000.
       01  K                PIC 9(10) VALUE 2.
       01  CONTINUE-FLAG    PIC X VALUE 'Y'.
           88  MORE-TO-PROCESS VALUE 'Y'.
       01  DISPLAY-RESULT   PIC Z(18)9.
       
       PROCEDURE DIVISION.
       MAIN-LOGIC.
           PERFORM UNTIL NOT MORE-TO-PROCESS
               COMPUTE N-POWER-3 = 3 ** K
               IF N-POWER-3 > LIMIT
                   MOVE 'N' TO CONTINUE-FLAG
               ELSE
                   ADD N-POWER-3 TO SUM
                   COMPUTE K = K + 1
               END-IF
           END-PERFORM.
           
           MOVE SUM TO DISPLAY-RESULT.
           DISPLAY "Sum = " DISPLAY-RESULT.
           
           STOP RUN.
```

## Explanation of the Solution

1. **Mathematical Analysis**: Through mathematical analysis, we determine that the numbers n that satisfy the condition are exactly the powers of 3 where the exponent is at least 2 (i.e., 3^2, 3^3, 3^4, ...).

2. **Algorithm**: 
   - Start with k = 2
   - Calculate 3^k
   - If 3^k ≤ 10^15, add it to the sum
   - Increment k and repeat until 3^k > 10^15

3. **COBOL Implementation**:
   - Uses working storage variables to track powers of 3
   - Uses a loop to iterate through powers of 3
   - Stops when the power exceeds the limit of 10^15
   - Accumulates the sum in the SUM variable

## Final Answer

The sum of all positive integers n ≤ 10^15 such that n is divisible by 3 and n! is divisible by n^3 is:

**14348907**
