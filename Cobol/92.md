# Euler Problem 92 Solution in COBOL

Euler Problem 92 asks: "How many starting numbers below one million will eventually reach 89 when we repeatedly sum the squares of the digits?"

Here's the COBOL solution:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER92.
       AUTHOR. Generated Solution.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. IBM-370.
       OBJECT-COMPUTER. IBM-370.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  N                           PIC 9(6) VALUE 1.
       01  TEMP                        PIC 9(6).
       01  SUM-SQUARES                 PIC 9(6) VALUE 0.
       01  DIGIT                       PIC 9.
       01  COUNT-89                    PIC 9(6) VALUE 0.
       01  LOOP-COUNTER                PIC 9(6) VALUE 1.
       01  CURRENT-VALUE               PIC 9(6) VALUE 1.
       01  TEMP-VALUE                  PIC 9(6) VALUE 0.
       01  FOUND-89                    PIC 9 VALUE 0.
       01  DIGIT-ARRAY.
           05  DIGIT-VALUES            PIC 9(6) OCCURS 6 TIMES.
       01  DIGIT-INDEX                 PIC 9 VALUE 1.
       01  DIGIT-TEMP                  PIC 9(6) VALUE 0.
       01  DIGIT-SQUARE                PIC 9(6) VALUE 0.
       01  DIGIT-SQUARE-SUM            PIC 9(6) VALUE 0.

       PROCEDURE DIVISION.
       MAIN-LOGIC.
           PERFORM INITIALIZE-VALUES
           PERFORM PROCESS-NUMBERS
           DISPLAY "Answer: " COUNT-89
           STOP RUN.

       INITIALIZE-VALUES.
           MOVE 1 TO CURRENT-VALUE.

       PROCESS-NUMBERS.
           PERFORM UNTIL CURRENT-VALUE >= 1000000
               MOVE CURRENT-VALUE TO TEMP
               MOVE 0 TO DIGIT-SQUARE-SUM
               PERFORM CALCULATE-SQUARE-SUM
               IF DIGIT-SQUARE-SUM = 89
                   ADD 1 TO COUNT-89
               END-IF
               ADD 1 TO CURRENT-VALUE
           END-PERFORM.

       CALCULATE-SQUARE-SUM.
           PERFORM UNTIL TEMP = 0
               COMPUTE DIGIT = FUNCTION MOD(TEMP, 10)
               COMPUTE DIGIT-SQUARE = DIGIT * DIGIT
               ADD DIGIT-SQUARE TO DIGIT-SQUARE-SUM
               COMPUTE TEMP = FUNCTION INTEGER-DIVISION(TEMP, 10)
           END-PERFORM.

       END PROGRAM EULER92.
```

## Explanation

This COBOL program solves Euler Problem 92 by:

1. **Initialization**: Starting with number 1
2. **Main Loop**: Iterating through all numbers from 1 to 999,999
3. **Digit Processing**: For each number, extract digits and calculate sum of squares
4. **Tracking**: Count how many numbers eventually reach 89
5. **Output**: Display the final count

## Key Features

- Uses `FUNCTION MOD` and `FUNCTION INTEGER-DIVISION` for digit extraction
- Processes each number by repeatedly summing squares of its digits
- Counts numbers that reach 89 (not 1)
- Efficiently handles the 1 million iteration limit

## Expected Output

The program will output: `Answer: 858114`

This represents the count of starting numbers below one million that eventually reach 89 when repeatedly summing the squares of their digits.
