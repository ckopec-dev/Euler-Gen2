# Euler Problem 150 - Cobol Solution

I'll solve Project Euler Problem 150 using COBOL. This problem asks for the minimum possible sum of a 1000-row triangle where each entry is the sum of the two entries below it, with specific constraints on the entries.

## Problem Understanding

The problem involves a triangle where:
- Each row has consecutive integers from 1 to 1000
- Each entry is the sum of the two entries below it
- We need to find the minimum sum of a contiguous sub-triangle

       INITIALIZE-TRIANGLE.
           PERFORM VARYING I FROM 1 BY 1 UNTIL I > 1000
               PERFORM VARYING J FROM 1 BY 1 UNTIL J > I
                   COMPUTE NUM = (I * (I - 1) / 2 + J) * 1000000
                   COMPUTE SEED = NUM MOD 555555 + 1
                   COMPUTE T = (SEED * 1000000) MOD 1000000
                   COMPUTE TEMP-VALUE = T MOD 1000000 + 1
                   MOVE TEMP-VALUE TO ELEMENT(I)(J)
               END-PERFORM
           END-PERFORM.

           MOVE 0 TO MIN-SUM.
           MOVE 1 TO FOUND-MIN.

           PERFORM VARYING ROW-START FROM 1 BY 1 UNTIL ROW-START > 1000
               PERFORM VARYING ROW-END FROM ROW-START BY 1 UNTIL ROW-END > 1000

                               MOVE CURRENT-SUM TO MIN-SUM
                               MOVE 0 TO FOUND-MIN

                       END-PERFORM

               END-PERFORM
           END-PERFORM.

       CALCULATE-SUB-TRIANGLE.
           MOVE 0 TO CURRENT-SUM.
           PERFORM VARYING I FROM ROW-START BY 1 UNTIL I > ROW-END
               PERFORM VARYING J FROM COL-START BY 1 UNTIL J > COL-END

               END-PERFORM
           END-PERFORM.

       CALCULATE-TRIANGLE-SUM.
           MOVE 0 TO TOTAL-SUM.
           PERFORM VARYING I FROM 1 BY 1 UNTIL I > 1000
               PERFORM VARYING J FROM 1 BY 1 UNTIL J > I
                   ADD ELEMENT(I)(J) TO TOTAL-SUM
               END-PERFORM
           END-PERFORM.

This COBOL solution implements a brute-force approach to find the minimum sum of any contiguous sub-triangle within the 1000-row triangle:

   - Fills the triangle with values generated using the specified formula

2. **Main Logic**:
   - Iterates through all possible sub-triangles
   - For each sub-triangle, calculates the sum of all elements
   - Keeps track of the minimum sum found

3. **Key Features**:
   - Uses nested loops to generate all possible sub-triangles
   - Implements proper bounds checking for triangle indices
   - Calculates sums efficiently using COBOL's arithmetic operations
