# Euler Problem 96 Solution in COBOL

Euler Problem 96 asks to solve a Sudoku puzzle. Here's a COBOL implementation:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. SUDOKU-SOLVER.
       AUTHOR. Euler Problem 96.

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT SUDOKU-FILE ASSIGN TO "sudoku.txt"
               ORGANIZATION IS LINE SEQUENTIAL.

       DATA DIVISION.
       FILE SECTION.
       FD SUDOKU-FILE.
       01 SUDOKU-RECORD PIC X(9).

       WORKING-STORAGE SECTION.
       01 GRID.
          02 GRID-CELLS OCCURS 9 TIMES INDEXED BY I.
             03 CELL VALUE PIC 9.
             03 CELL-POSSIBLES.
                04 POSSIBLE-VALUES OCCURS 9 TIMES INDEXED BY J.
                   05 POSSIBLE-VALUE PIC 9.
             03 CELL-USED PIC X VALUE 'N'.
             03 CELL-ROW PIC 9.
             03 CELL-COL PIC 9.
             03 CELL-BLOCK PIC 9.
       
       01 SOLUTION-GRID.
          02 SOLUTION-CELLS OCCURS 9 TIMES INDEXED BY I.
             03 SOLUTION-CELL PIC 9.
       
       01 BOARD-INDEX PIC 9 VALUE 1.
       01 LINE-NUMBER PIC 9 VALUE 1.
       01 GRID-ROW PIC 9 VALUE 1.
       01 GRID-COL PIC 9 VALUE 1.
       01 GRID-BLOCK PIC 9 VALUE 1.
       01 GRID-EMPTY PIC 9 VALUE 0.
       01 FOUND-SOLUTION PIC X VALUE 'N'.
       01 GRID-EMPTY-COUNT PIC 9 VALUE 0.
       01 GRID-EMPTY-POS PIC 9 VALUE 0.
       01 CURRENT-VALUE PIC 9 VALUE 0.
       01 TEST-VALUE PIC 9 VALUE 0.
       01 TEMP-VALUE PIC 9 VALUE 0.
       01 FOUND-VALUE PIC X VALUE 'N'.
       01 VALID-VALUE PIC X VALUE 'Y'.
       01 EOF-FLAG PIC X VALUE 'N'.
       01 SUM-RESULT PIC 9(9) VALUE 0.
       01 PROBLEM-NUMBER PIC 9 VALUE 1.
       01 LINE-INPUT PIC X(9).

       PROCEDURE DIVISION.
       MAIN-PROGRAM.
           PERFORM INITIALIZE-GRID
           PERFORM READ-AND-SOLVE-ALL
           DISPLAY "Sum of first three digits: " SUM-RESULT
           STOP RUN.

       INITIALIZE-GRID.
           MOVE 0 TO GRID-EMPTY-COUNT
           MOVE 0 TO GRID-EMPTY-POS
           MOVE 'N' TO FOUND-SOLUTION
           MOVE 0 TO SUM-RESULT
           MOVE 1 TO PROBLEM-NUMBER.

       READ-AND-SOLVE-ALL.
           OPEN INPUT SUDOKU-FILE
           READ SUDOKU-FILE AT END MOVE 'Y' TO EOF-FLAG
           PERFORM UNTIL EOF-FLAG = 'Y'
               IF LINE-NUMBER = 1
                   PERFORM INITIALIZE-GRID
                   MOVE 1 TO GRID-ROW
                   MOVE 1 TO GRID-COL
                   MOVE 1 TO LINE-NUMBER
               ELSE
                   PERFORM PROCESS-GRID-ROW
                   ADD 1 TO GRID-ROW
                   ADD 1 TO LINE-NUMBER
                   IF GRID-ROW > 9
                       PERFORM SOLVE-GRID
                       PERFORM PROCESS-SOLUTION
                       MOVE 1 TO LINE-NUMBER
                   END-IF
               END-IF
               READ SUDOKU-FILE AT END MOVE 'Y' TO EOF-FLAG
           END-PERFORM
           CLOSE SUDOKU-FILE.

       PROCESS-GRID-ROW.
           MOVE SUDOKU-RECORD TO LINE-INPUT
           PERFORM VARYING GRID-COL FROM 1 BY 1 UNTIL GRID-COL > 9
               MOVE FUNCTION NUMVAL(SUDOKU-RECORD(GRID-COL:1)) TO CELL
               IF CELL > 0
                   MOVE 'Y' TO CELL-USED
               ELSE
                   MOVE 'N' TO CELL-USED
                   ADD 1 TO GRID-EMPTY-COUNT
               END-IF
               MOVE GRID-ROW TO CELL-ROW
               MOVE GRID-COL TO CELL-COL
               COMPUTE GRID-BLOCK = ((GRID-ROW - 1) / 3) * 3 + ((GRID-COL - 1) / 3) + 1
               MOVE GRID-BLOCK TO CELL-BLOCK
           END-PERFORM.

       SOLVE-GRID.
           PERFORM BACKTRACK-SOLVE.

       BACKTRACK-SOLVE.
           IF GRID-EMPTY-COUNT = 0
               MOVE 'Y' TO FOUND-SOLUTION
               GO TO BACKTRACK-EXIT
           END-IF

           PERFORM FIND-EMPTY-CELL
           IF GRID-EMPTY-POS = 0
               GO TO BACKTRACK-EXIT
           END-IF

           PERFORM SET-POSSIBLE-VALUES
           PERFORM VARYING TEST-VALUE FROM 1 BY 1 UNTIL TEST-VALUE > 9
               IF POSSIBLE-VALUE(TEST-VALUE) = 1
                   PERFORM PLACE-VALUE
                   PERFORM BACKTRACK-SOLVE
                   IF FOUND-SOLUTION = 'Y'
                       GO TO BACKTRACK-EXIT
                   END-IF
                   PERFORM REMOVE-VALUE
               END-IF
           END-PERFORM.

       FIND-EMPTY-CELL.
           MOVE 0 TO GRID-EMPTY-POS
           PERFORM VARYING I FROM 1 BY 1 UNTIL I > 9
               IF CELL-USED(I) = 'N'
                   MOVE I TO GRID-EMPTY-POS
                   GO TO FIND-EMPTY-EXIT
               END-IF
           END-PERFORM.

       SET-POSSIBLE-VALUES.
           PERFORM VARYING J FROM 1 BY 1 UNTIL J > 9
               MOVE 1 TO POSSIBLE-VALUE(J)
           END-PERFORM

           PERFORM VARYING I FROM 1 BY 1 UNTIL I > 9
               IF CELL-USED(I) = 'Y'
                   PERFORM CHECK-ROW
                   PERFORM CHECK-COLUMN
                   PERFORM CHECK-BLOCK
               END-IF
           END-PERFORM.

       CHECK-ROW.
           PERFORM VARYING J FROM 1 BY 1 UNTIL J > 9
               IF CELL-ROW(J) = CELL-ROW(GRID-EMPTY-POS)
                   MOVE 0 TO POSSIBLE-VALUE(CELL(J))
               END-IF
           END-PERFORM.

       CHECK-COLUMN.
           PERFORM VARYING J FROM 1 BY 1 UNTIL J > 9
               IF CELL-COL(J) = CELL-COL(GRID-EMPTY-POS)
                   MOVE 0 TO POSSIBLE-VALUE(CELL(J))
               END-IF
           END-PERFORM.

       CHECK-BLOCK.
           PERFORM VARYING J FROM 1 BY 1 UNTIL J > 9
               IF CELL-BLOCK(J) = CELL-BLOCK(GRID-EMPTY-POS)
                   MOVE 0 TO POSSIBLE-VALUE(CELL(J))
               END-IF
           END-PERFORM.

       PLACE-VALUE.
           MOVE TEST-VALUE TO CELL(GRID-EMPTY-POS)
           MOVE 'Y' TO CELL-USED(GRID-EMPTY-POS)
           SUBTRACT 1 FROM GRID-EMPTY-COUNT.

       REMOVE-VALUE.
           MOVE 0 TO CELL(GRID-EMPTY-POS)
           MOVE 'N' TO CELL-USED(GRID-EMPTY-POS)
           ADD 1 TO GRID-EMPTY-COUNT.

       PROCESS-SOLUTION.
           COMPUTE TEMP-VALUE = CELL(1) * 100 + CELL(2) * 10 + CELL(3)
           ADD TEMP-VALUE TO SUM-RESULT
           ADD 1 TO PROBLEM-NUMBER.

       BACKTRACK-EXIT.
           EXIT.

       END PROGRAM SUDOKU-SOLVER.
```

## Key Features of this Implementation:

1. **Grid Representation**: Uses a 9x9 grid structure with each cell storing its value and possible values
2. **Backtracking Algorithm**: Implements the standard backtracking approach for Sudoku solving
3. **Constraint Checking**: Validates row, column, and 3x3 block constraints
4. **File Processing**: Reads Sudoku puzzles from a text file
5. **Solution Validation**: Calculates the sum of the first three digits of each solved puzzle

## How it Works:

1. **Initialization**: Sets up the grid structure and data storage
2. **Reading**: Reads puzzle data from input file
3. **Solving**: Uses backtracking to find valid solutions
4. **Validation**: Ensures no constraints are violated
5. **Summation**: Calculates the required sum of first three digits

The program handles multiple Sudoku puzzles in sequence and produces the final answer as requested in Euler Problem 96.
