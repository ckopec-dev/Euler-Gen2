# Euler Problem 134 Solution in COBOL

## Problem Statement
Find the sum of all composite numbers n for which gcd(n, 10) = 1 and n is not divisible by 13, where n is less than 10^10, and the smallest positive integer solution to the equation 10^k ≡ 1 (mod n) is k = 134.

           05 PRIME-ITEM OCCURS 1000000 TIMES PIC 9(10).
       01 PRIME-COUNT       PIC 9(10) VALUE 0.

           05 FACTOR-ITEM OCCURS 100 TIMES PIC 9(10).
       01 FACTOR-COUNT      PIC 9(10) VALUE 0.
       01 TEMP-N            PIC 9(10) VALUE 0.

       GENERATE-PRIMES.
           MOVE 2 TO PRIME-ITEM(1)
           ADD 1 TO PRIME-COUNT
           
           MOVE 3 TO I-INDEX
           PERFORM UNTIL I-INDEX > MAX-PRIME
               PERFORM IS-PRIME-TEST
               IF IS-PRIME = 1
                   ADD 1 TO PRIME-COUNT
                   MOVE I-INDEX TO PRIME-ITEM(PRIME-COUNT)
               END-IF

           END-PERFORM.

                       END-IF
                       ADD 2 TO J-INDEX
                   END-PERFORM
               END-IF
           END-IF.

       CHECK-ALL-NUMBERS.
           MOVE 10 TO N-VALUE
           PERFORM UNTIL N-VALUE >= MAX-N
               PERFORM CHECK-NUMBER
               ADD 1 TO N-VALUE
           END-PERFORM.

       CHECK-NUMBER.
           IF N-VALUE < 10
               GO TO CHECK-NUMBER-CONTINUE
           END-IF
           
           PERFORM CALCULATE-GCD
           IF GCD-RESULT = 1
               PERFORM CHECK-DIVISIBILITY
               IF IS-DIVISIBLE = 0
                   PERFORM CHECK-ORDER
                   IF FOUND-SOLUTION = 1
                       ADD N-VALUE TO RESULT-SUM
                   END-IF
               END-IF
           END-IF
           
           CHECK-NUMBER-CONTINUE.

       CALCULATE-GCD.
           MOVE N-VALUE TO TEMP-VALUE
           MOVE 10 TO TEMP-DIV

               MOVE TEMP-VALUE TO TEMP-N
               COMPUTE TEMP-VALUE = TEMP-N MOD TEMP-DIV
               MOVE TEMP-DIV TO TEMP-DIV
           END-PERFORM

       CHECK-DIVISIBILITY.
           MOVE 0 TO IS-DIVISIBLE
           IF N-VALUE MOD 13 = 0

           END-IF.

                   MOVE 1 TO FOUND-SOLUTION
               END-IF
               ADD 1 TO K-INDEX
           END-PERFORM.

       CALCULATE-POWER.
           COMPUTE POWER-RESULT = (10 ** K-INDEX) MOD N-VALUE.
