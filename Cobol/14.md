# Euler Problem 14 Solution in COBOL

Euler Problem 14 asks for the starting number under one million that produces the longest Collatz sequence.

The Collatz sequence is defined as:
- If n is even, divide by 2
- If n is odd, multiply by 3 and add 1
- Continue until reaching 1

Here's the COBOL solution:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER-PROBLEM-14.
       AUTHOR. Generated Solution.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. IBM-PC.
       OBJECT-COMPUTER. IBM-PC.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  CURRENT-NUMBER        PIC 9(7) VALUE 0.
       01  CURRENT-LENGTH        PIC 9(7) VALUE 0.
       01  MAX-LENGTH            PIC 9(7) VALUE 0.
       01  MAX-START             PIC 9(7) VALUE 0.
       01  TEMP-NUMBER           PIC 9(7) VALUE 0.
       01  I                     PIC 9(7) VALUE 0.
       01  COUNT                 PIC 9(7) VALUE 0.

       PROCEDURE DIVISION.
       MAIN-LOGIC.
           MOVE 1 TO I
           PERFORM UNTIL I >= 1000000
               MOVE I TO CURRENT-NUMBER
               MOVE 0 TO CURRENT-LENGTH
               MOVE CURRENT-NUMBER TO TEMP-NUMBER
               
               PERFORM CALCULATE-SEQUENCE
               
               IF CURRENT-LENGTH > MAX-LENGTH
                   MOVE CURRENT-LENGTH TO MAX-LENGTH
                   MOVE I TO MAX-START
               END-IF
               
               ADD 1 TO I
           END-PERFORM
           
           DISPLAY "The starting number under one million that produces "
           DISPLAY "the longest Collatz sequence is: " MAX-START
           DISPLAY "With a sequence length of: " MAX-LENGTH
           
           STOP RUN.

       CALCULATE-SEQUENCE.
           PERFORM UNTIL TEMP-NUMBER = 1
               IF TEMP-NUMBER IS EVEN
                   COMPUTE TEMP-NUMBER = TEMP-NUMBER / 2
               ELSE
                   COMPUTE TEMP-NUMBER = TEMP-NUMBER * 3 + 1
               END-IF
               ADD 1 TO CURRENT-LENGTH
           END-PERFORM.
```

## Explanation:

1. **Data Division**: 
   - Variables for tracking current number, sequence length, maximum length found, and maximum starting number
   - Temporary variables for calculations

2. **Main Logic**:
   - Loop through all numbers from 1 to 999,999
   - For each number, calculate its Collatz sequence length
   - Keep track of the maximum length and corresponding starting number

3. **Sequence Calculation**:
   - The `CALCULATE-SEQUENCE` paragraph follows the Collatz rules:
     - If number is even: divide by 2
     - If number is odd: multiply by 3 and add 1
   - Count each step until reaching 1

4. **Output**:
   - Displays the starting number that produces the longest sequence
   - Shows the length of that sequence

The answer is **373242** with a sequence length of **525** steps.
