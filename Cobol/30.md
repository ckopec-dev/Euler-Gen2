# Euler Problem 30 Solution in COBOL

Euler Problem 30 asks: Find the sum of all numbers that can be written as the sum of fifth powers of their digits.

Here's the COBOL solution:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER30.
       AUTHOR. Generated Solution.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. IBM-370.
       OBJECT-COMPUTER. IBM-370.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  N                       PIC 9(6) VALUE 0.
       01  DIGIT-SUM               PIC 9(7) VALUE 0.
       01  TEMP-N                  PIC 9(6) VALUE 0.
       01  DIGIT                   PIC 9 VALUE 0.
       01  POWER                   PIC 9(7) VALUE 0.
       01  TOTAL-SUM               PIC 9(7) VALUE 0.
       01  I                       PIC 9(6) VALUE 1.
       01  J                       PIC 9(6) VALUE 1.
       01  FOUND                   PIC X VALUE 'N'.
       01  POWER-ARRAY.
           05  POWER-ITEM          PIC 9(6) OCCURS 10 TIMES.
       01  DIGIT-ARRAY.
           05  DIGIT-ITEM          PIC 9 OCCURS 10 TIMES.

       PROCEDURE DIVISION.
       MAIN-LOGIC.
           PERFORM INITIALIZE-POWERS
           PERFORM FIND-VALID-NUMBERS
           DISPLAY "Sum of all numbers that are sum of fifth powers: " TOTAL-SUM
           STOP RUN.

       INITIALIZE-POWERS.
           MOVE 0 TO POWER-ITEM(1)
           MOVE 1 TO POWER-ITEM(2)
           MOVE 32 TO POWER-ITEM(3)
           MOVE 243 TO POWER-ITEM(4)
           MOVE 1024 TO POWER-ITEM(5)
           MOVE 3125 TO POWER-ITEM(6)
           MOVE 7776 TO POWER-ITEM(7)
           MOVE 16807 TO POWER-ITEM(8)
           MOVE 32768 TO POWER-ITEM(9)
           MOVE 59049 TO POWER-ITEM(10)
           .
           .
           .
           (This would be expanded to calculate all powers 0^5 to 9^5)

       FIND-VALID-NUMBERS.
           PERFORM VARYING I FROM 2 BY 1 UNTIL I > 354294
               MOVE I TO TEMP-N
               MOVE 0 TO DIGIT-SUM
               MOVE 0 TO J
               PERFORM EXTRACT-DIGITS
               IF DIGIT-SUM = I
                   ADD I TO TOTAL-SUM
               END-IF
           END-PERFORM.

       EXTRACT-DIGITS.
           IF TEMP-N > 0
               COMPUTE DIGIT = FUNCTION MOD(TEMP-N, 10)
               COMPUTE TEMP-N = FUNCTION INTEGER(TEMP-N / 10)
               ADD POWER-ITEM(DIGIT + 1) TO DIGIT-SUM
               ADD 1 TO J
               PERFORM EXTRACT-DIGITS
           END-IF.

       * More concise version:
       INITIALIZE-POWERS.
           PERFORM VARYING I FROM 0 BY 1 UNTIL I > 9
               COMPUTE POWER-ITEM(I + 1) = I ** 5
           END-PERFORM.

       FIND-VALID-NUMBERS.
           PERFORM VARYING I FROM 2 BY 1 UNTIL I > 354294
               MOVE I TO TEMP-N
               MOVE 0 TO DIGIT-SUM
               PERFORM EXTRACT-DIGITS
               IF DIGIT-SUM = I
                   ADD I TO TOTAL-SUM
               END-IF
           END-PERFORM.
```


## Key Points:

1. **Upper Limit**: The maximum possible sum for a 6-digit number is 6 × 9^5 = 354,294, so we only need to check up to this number.

2. **Power Calculation**: Pre-compute the fifth powers of digits 0-9.

3. **Digit Extraction**: Extract each digit from the number and sum their fifth powers.

4. **Validation**: Check if the sum equals the original number.

The answer to Euler Problem 30 is **443839**.
