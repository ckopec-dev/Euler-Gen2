# Euler Problem 257 Solution in COBOL

Euler Problem 257 asks for the number of triangles with integer sides where the area equals the perimeter.

## Problem Analysis
We need to find triangles with integer sides (a, b, c) where:
- a + b + c = area (perimeter equals area)
- Area = √[s(s-a)(s-b)(s-c)] where s = (a+b+c)/2 (Heron's formula)
- All sides are positive integers

## COBOL Solution

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EULER257.
       AUTHOR. COBOL SOLUTION.

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT OUTPUT-FILE ASSIGN TO "EULER257.OUT"
               ORGANIZATION IS LINE SEQUENTIAL.

       DATA DIVISION.
       FILE SECTION.
       FD OUTPUT-FILE.
       01 OUTPUT-RECORD.
           05 RESULT-COUNT    PIC 9(8).
           05 SEPARATOR       PIC X(10) VALUE SPACES.
           05 TRIANGLE-SIDES  PIC X(20) VALUE SPACES.

       WORKING-STORAGE SECTION.
       01 COMPUTE-AREA.
           05 A               PIC 9(6).
           05 B               PIC 9(6).
           05 C               PIC 9(6).
           05 S               PIC 9(8).
           05 AREA            PIC 9(10).
           05 AREA-FLOAT      PIC 9(10)V99.
           05 PERIMETER       PIC 9(8).
           05 TEMP            PIC 9(12).
           05 SQRT-TEMP       PIC 9(10)V99.
           05 IS-TRIANGLE     PIC 9 VALUE 0.
           05 IS-SOLUTION     PIC 9 VALUE 0.

       01 LOOP-VARIABLES.
           05 I               PIC 9(6) VALUE 1.
           05 J               PIC 9(6) VALUE 1.
           05 K               PIC 9(6) VALUE 1.
           05 MAX-SIDE        PIC 9(6) VALUE 1000.
           05 COUNT           PIC 9(8) VALUE 0.

       01 OUTPUT-VARIABLES.
           05 DISPLAY-RESULT  PIC Z(7)9.
           05 DISPLAY-SIDES   PIC X(15).
           05 DISPLAY-TRIANGLE PIC X(15).

       PROCEDURE DIVISION.
       MAIN-PROGRAM.
           DISPLAY "Solving Euler Problem 257"
           DISPLAY "Finding triangles where area equals perimeter"
           DISPLAY " "

           PERFORM FIND-SOLUTIONS
           DISPLAY "Total number of solutions: " COUNT
           DISPLAY " "

           STOP RUN.

       FIND-SOLUTIONS.
           PERFORM VARYING I FROM 1 BY 1 UNTIL I > MAX-SIDE
               PERFORM VARYING J FROM I BY 1 UNTIL J > MAX-SIDE
                   PERFORM VARYING K FROM J BY 1 UNTIL K > MAX-SIDE
                       IF I + J + K > 1000
                           GO TO NEXT-K
                       END-IF
                       MOVE I TO A
                       MOVE J TO B
                       MOVE K TO C
                       COMPUTE PERIMETER = A + B + C
                       COMPUTE S = (A + B + C) / 2
                       COMPUTE TEMP = S * (S - A) * (S - B) * (S - C)
                       COMPUTE SQRT-TEMP = FUNCTION SQRT(TEMP)
                       COMPUTE AREA-FLOAT = SQRT-TEMP
                       COMPUTE AREA = FUNCTION INTEGER(AREA-FLOAT)
                       IF AREA = PERIMETER
                           ADD 1 TO COUNT
                           DISPLAY "Solution found: " A " " B " " C
                           DISPLAY "  Area = " AREA " Perimeter = " PERIMETER
                       END-IF
                       NEXT-K
                   END-PERFORM
               END-PERFORM
           END-PERFORM.

       END PROGRAM EULER257.
```

## Key Points of the Solution

1. **Heron's Formula**: Uses the standard formula for triangle area: Area = √[s(s-a)(s-b)(s-c)] where s is the semi-perimeter.

2. **Optimization**: The loop structure is optimized to avoid checking all combinations by setting appropriate bounds.

3. **Integer Validation**: The solution checks that the computed area is exactly equal to the perimeter.

4. **Efficiency**: The algorithm limits the search space by ensuring that a ≤ b ≤ c and that the sum doesn't exceed reasonable bounds.
