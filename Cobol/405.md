# Euler Problem 405 Solution in COBOL

Euler Problem 405 asks us to find the sum of all numbers n such that the sum of the digits of n equals the sum of the digits of n², where n is a positive integer and 1 ≤ n ≤ 10^15.

Here's the COBOL solution:

```cobol

       PROGRAM-ID. EULER405.
       AUTHOR. Generated Solution.

       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.

       OBJECT-COMPUTER. IBM-370.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  N                       PIC 9(15).
       01  N-SQUARED               PIC 9(30).
       01  DIGIT-SUM-N             PIC 9(15).
       01  DIGIT-SUM-N-SQUARED     PIC 9(15).
       01  TEMP-NUMBER             PIC 9(15).
       01  DIGIT                   PIC 9.
       01  TOTAL-SUM               PIC 9(20) VALUE 0.
       01  COUNT                   PIC 9(10) VALUE 0.
       01  I                       PIC 9(15).
       01  J                       PIC 9(15).
       01  FOUND                   PIC X VALUE 'N'.
       01  DIGIT-ARRAY             PIC 9(15) OCCURS 15 TIMES.
       01  DIGIT-ARRAY-INDEX       PIC 9(2) VALUE 1.
       01  DIGIT-ARRAY-COUNT       PIC 9(2) VALUE 0.
       01  POWER-OF-TEN            PIC 9(15) VALUE 1.
       01  TEMP-POWER              PIC 9(15).
       01  MAX-NUMBER              PIC 9(15) VALUE 100000000000000.
       01  LIMIT                   PIC 9(15) VALUE 100000000000000.
       01  STEP                    PIC 9(15) VALUE 100000000000000.
       01  DEBUG-FLAG              PIC X VALUE 'N'.

       PROCEDURE DIVISION.
       MAIN-PROGRAM.
           DISPLAY "Solving Euler Problem 405"
           DISPLAY "Finding numbers where digit sum(n) = digit sum(n²)"
           DISPLAY "Range: 1 to 10^15"

           PERFORM COMPUTE-DIGIT-SUMS
           DISPLAY "Total sum: " TOTAL-SUM
           STOP RUN.

       COMPUTE-DIGIT-SUMS.
           MOVE 1 TO N
           MOVE 0 TO TOTAL-SUM

           PERFORM UNTIL N > LIMIT
               IF DEBUG-FLAG = 'Y' AND N MOD 1000000 = 0
                   DISPLAY "Processing n = " N
               END-IF

               MOVE N TO TEMP-NUMBER
               PERFORM CALCULATE-DIGIT-SUM
               MOVE DIGIT-SUM-N TO DIGIT-SUM-N-SQUARED

               COMPUTE N-SQUARED = N * N
               MOVE N-SQUARED TO TEMP-NUMBER
               PERFORM CALCULATE-DIGIT-SUM
               IF DIGIT-SUM-N = DIGIT-SUM-N-SQUARED
                   ADD N TO TOTAL-SUM
                   IF DEBUG-FLAG = 'Y'
                       DISPLAY "Found match: " N
                   END-IF
               END-IF

               ADD 1 TO N
           END-PERFORM.

       CALCULATE-DIGIT-SUM.
           MOVE 0 TO DIGIT-SUM-N
           MOVE TEMP-NUMBER TO TEMP-NUMBER
           MOVE 1 TO DIGIT-ARRAY-INDEX
           MOVE 0 TO DIGIT-ARRAY-COUNT

           PERFORM UNTIL TEMP-NUMBER = 0
               COMPUTE DIGIT = TEMP-NUMBER MOD 10
               ADD DIGIT TO DIGIT-SUM-N
               MOVE DIGIT TO DIGIT-ARRAY(DIGIT-ARRAY-INDEX)
               ADD 1 TO DIGIT-ARRAY-INDEX
               COMPUTE TEMP-NUMBER = TEMP-NUMBER DIV 10
               ADD 1 TO DIGIT-ARRAY-COUNT
           END-PERFORM.

       COMPUTE-DIGIT-SUM-N-SQUARED.
           MOVE 0 TO DIGIT-SUM-N-SQUARED
           MOVE N-SQUARED TO TEMP-NUMBER
           MOVE 1 TO DIGIT-ARRAY-INDEX
           MOVE 0 TO DIGIT-ARRAY-COUNT

           PERFORM UNTIL TEMP-NUMBER = 0
               COMPUTE DIGIT = TEMP-NUMBER MOD 10
               ADD DIGIT TO DIGIT-SUM-N-SQUARED
               MOVE DIGIT TO DIGIT-ARRAY(DIGIT-ARRAY-INDEX)
               ADD 1 TO DIGIT-ARRAY-INDEX
               COMPUTE TEMP-NUMBER = TEMP-NUMBER DIV 10
               ADD 1 TO DIGIT-ARRAY-COUNT
           END-PERFORM.
```
