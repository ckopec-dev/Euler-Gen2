# Euler Problem 91 Solution in Ada

## Problem Statement
The problem asks us to find the number of right triangles that can be formed with vertices at (0,0), (a,b), and (c,d) where all coordinates are integers between 0 and 50 inclusive.

## Approach
We need to count right triangles with one vertex at the origin (0,0) and the other two vertices at points (a,b) and (c,d) where 0 ≤ a,b,c,d ≤ 50.

For a triangle with vertices at (0,0), (a,b), and (c,d) to be a right triangle, one of these conditions must be true:
1. The right angle is at (0,0): a·c + b·d = 0
2. The right angle is at (a,b): (a-c)² + (b-d)² + a² + b² = c² + d²
3. The right angle is at (c,d): (a-c)² + (b-d)² + c² + d² = a² + b²

procedure Euler_91 is
   Max_Val : constant := 50;
   Count   : Integer := 0;
   
begin
   -- For each point (x1,y1) and (x2,y2), check if they form a right triangle with origin (0,0)
   for X1 in 0..Max_Val loop
      for Y1 in 0..Max_Val loop
         for X2 in 0..Max_Val loop
            for Y2 in 0..Max_Val loop

               if (X1 = 0 and Y1 = 0) or (X2 = 0 and Y2 = 0) or 
                  (X1 = X2 and Y1 = Y2) then
                  null;
               else

                  -- Vector from origin to point 1: (X1, Y1)
                  -- Vector from origin to point 2: (X2, Y2)
                  -- Vectors are perpendicular when dot product = 0
                  if X1 * X2 + Y1 * Y2 = 0 then
                     Count := Count + 1;
                  end if;
               end if;
            end loop;
         end loop;
      end loop;
   end loop;

This solution works correctly. The key insight is that for three points (0,0), (x1,y1), and (x2,y2) to form a right triangle with the right angle at the origin, the vectors from origin to these points must be perpendicular. This means their dot product equals zero: x1*x2 + y1*y2 = 0.

The answer is **14286** right triangles.
