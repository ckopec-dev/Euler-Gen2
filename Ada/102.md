# Euler Problem 102 Solution in Ada

## Problem Statement
Three distinct points are plotted at random on a Cartesian plane, for which -1000 ≤ x, y ≤ 1000, such that a triangle is formed.

Consider the following two triangles:
- Triangle 1: (-340,495), (-153,-910), (835,-947)
- Triangle 2: (-175,41), (-421,-714), (574,-647)

It can be verified that triangle 1 contains the origin, whereas triangle 2 does not.

Determine how many triangles contain the origin.

## Solution Approach
We'll use the barycentric coordinate method to determine if a point lies inside a triangle. For a triangle with vertices A, B, C and point P (origin in this case), we can express P as:
P = αA + βB + γC where α + β + γ = 1

The point P is inside the triangle if and only if all coefficients α, β, γ are non-negative.

procedure Euler_102 is
   
   type Point is record
      X, Y : Integer;
   end record;
   
   type Triangle is record
      A, B, C : Point;
   end record;
   
   -- Function to check if origin (0,0) is inside triangle
   function Contains_Origin(T : Triangle) return Boolean is
      -- Using barycentric coordinates
      -- For triangle with vertices A, B, C and point P:
      -- Area of triangle ABC = 0.5 * |det([A-B, A-C])|
      -- Area of triangle PBC = 0.5 * |det([P-B, P-C])|
      -- And so on for other sub-triangles
      --
      -- If origin is inside triangle, sum of areas of three sub-triangles
      -- equals area of main triangle
      
      -- Using cross product method (more direct):
      -- We can use the sign of cross products to determine if point is inside
      
      -- For a triangle with vertices A(x1,y1), B(x2,y2), C(x3,y3)
      -- and point P(0,0), we compute cross products
      -- The point is inside if all cross products have same sign
      
      -- Cross product of vectors (A-P) and (B-P) where P = (0,0)
      -- This gives us the signed area of triangle formed by A,B,P
      -- Sign determines which side of line AB point P lies
      
      -- Alternative approach: Use barycentric coordinates
      -- Calculate coefficients using Cramer's rule
      X1, Y1, X2, Y2, X3, Y3 : Integer;
      
   begin
      X1 := T.A.X; Y1 := T.A.Y;
      X2 := T.B.X; Y2 := T.B.Y;
      X3 := T.C.X; Y3 := T.C.Y;
      
      -- Using barycentric coordinates with origin (0,0)
      -- The three barycentric coefficients are:
      -- alpha = ((y2-y3)*(0-x3) + (x3-x2)*(0-y3)) / det
      -- beta  = ((y3-y1)*(0-x1) + (x1-x3)*(0-y1)) / det  
      -- gamma = ((y1-y2)*(0-x2) + (x2-x1)*(0-y2)) / det
      
      -- Determinant of the matrix formed by triangle vertices
      declare
         det : Integer := (X1 - X3) * (Y2 - Y3) - (X2 - X3) * (Y1 - Y3);
         alpha : Float;
         beta  : Float;
         gamma : Float;
      begin
         if det = 0 then
            return False; -- Degenerate triangle
         end if;
         
         alpha := ((Y2 - Y3) * (-X3) + (X3 - X2) * (-Y3)) / Float(det);
         beta  := ((Y3 - Y1) * (-X1) + (X1 - X3) * (-Y1)) / Float(det);
         gamma := ((Y1 - Y2) * (-X2) + (X2 - X1) * (-Y2)) / Float(det);
         
         -- Point is inside triangle if all barycentric coordinates are non-negative
         return alpha >= 0.0 and then beta >= 0.0 and then gamma >= 0.0;
      end;
   end function Contains_Origin;

      -- Since we don't have the actual data file, let's define the problem directly:
      -- We'd normally read from a text file containing triangle coordinates
   begin
      -- This is where you would read from file and count triangles
      -- For now, let's simulate with the two example triangles:
      
      -- Triangle 1: (-340,495), (-153,-910), (835,-947)
      declare
         T1 : Triangle := (
            A => (X => -340, Y => 495),
            B => (X => -153, Y => -910),

         end if;
      end;
      
      -- Triangle 2: (-175,41), (-421,-714), (574,-647)
      declare
         T2 : Triangle := (
