# Euler Problem 79 Solution in Ada

## Problem Statement
A common security method used for online banking is to ask the user for three random characters from a passcode. For example, if the passcode was 531278, they may ask for the 2nd, 3rd, and 5th characters; the expected reply would be: 317.

The text file, keylog.txt, contains fifty successful login attempts.

Given that the three characters are always asked for in order, analyse the file to determine the shortest possible secret passcode of unknown length.

## Solution Approach
We need to find the shortest passcode that satisfies all the given login attempts. This is essentially a topological sorting problem where we need to determine the order of digits based on the given sequences.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;
with Ada.Containers.Vectors;
with Ada.Containers.Ordered_Maps;

procedure Euler_79 is
   
   -- Define a vector to store the login attempts
   type Digit_Vector is array (Positive range <>) of Natural;
   type Digit_Vector_Access is access Digit_Vector;
   
   -- Vector to store all login attempts
   Login_Attempts : array (1..50) of Digit_Vector(1..3);
   Attempt_Count : Natural := 0;
   
   -- Map to store relationships between digits
   package Digit_Map is new Ada.Containers.Ordered_Maps
     (Key_Type => Natural, 
      Element_Type => Boolean);
   
   -- Function to read the login attempts from file
   procedure Read_Login_Attempts is
      File : File_Type;
      Line : Unbounded_String;
      Digit : Natural;
      Position : Natural;
   begin
      Open (File, In_File, "keylog.txt");
      
      while not End_Of_File (File) loop
         Line := To_Unbounded_String (Get_Line (File));
         Position := 1;
         
         -- Parse the three digits from each line
         for I in 1..3 loop
            Digit := 0;
            while Position <= Length (Line) and then 
                  Character'Pos (Element (Line, Position)) < 48 or 
                  Character'Pos (Element (Line, Position)) > 57 loop
               Position := Position + 1;
            end loop;
            
            if Position <= Length (Line) then
               Digit := Character'Pos (Element (Line, Position)) - 48;
               Login_Attempts(Attempt_Count + 1)(I) := Digit;
               Position := Position + 1;
            end if;
         end loop;
         
         Attempt_Count := Attempt_Count + 1;
      end loop;
      
      Close (File);
   end Read_Login_Attempts;
   
   -- Function to find the shortest passcode
   function Find_Shortest_Passcode return String is
      -- Track which digits appear in the passcode
      Digit_Used : array (0..9) of Boolean := (others => False);
      
      -- Track dependencies: digit_i comes before digit_j
      Precedes : array (0..9, 0..9) of Boolean := (others => (others => False));
      
      -- Track in-degrees for topological sort
      In_Degree : array (0..9) of Natural := (others => 0);
      
      -- Result passcode
      Result : Unbounded_String := Null_Unbounded_String;
      
      -- Find all digits that appear
      procedure Find_Digits is
      begin
         for I in 1..Attempt_Count loop
            for J in 1..3 loop
               Digit_Used(Login_Attempts(I)(J)) := True;
            end loop;
         end loop;
      end Find_Digits;
      
      -- Build dependency graph
      procedure Build_Dependencies is
      begin
         for I in 1..Attempt_Count loop
            -- First digit comes before second
            Precedes(Login_Attempts(I)(1), Login_Attempts(I)(2)) := True;
            -- Second digit comes before third
            Precedes(Login_Attempts(I)(2), Login_Attempts(I)(3)) := True;
         end loop;
      end Build_Dependencies;
      
      -- Perform topological sort
      procedure Topological_Sort is
         Queue : array (0..9) of Natural;
         Head, Tail : Natural := 0;
         Current : Natural;
         Sorted_Count : Natural := 0;
      begin
         -- Initialize queue with all nodes with in-degree 0
         for I in 0..9 loop
            if Digit_Used(I) then
               In_Degree(I) := 0;
               for J in 0..9 loop
                  if Precedes(J, I) then
                     In_Degree(I) := In_Degree(I) + 1;
                  end if;
               end loop;
               
               if In_Degree(I) = 0 then
                  Queue(Tail) := I;
                  Tail := Tail + 1;
               end if;
            end if;
         end loop;
         
         -- Process nodes in topological order
         while Head < Tail loop
            Current := Queue(Head);
            Head := Head + 1;
            Append (Result, Character'Val(Current + 48));
            Sorted_Count := Sorted_Count + 1;
            
            -- Remove current node and update in-degrees
            for I in 0..9 loop
               if Precedes(Current, I) then
                  In_Degree(I) := In_Degree(I) - 1;
                  if In_Degree(I) = 0 then
                     Queue(Tail) := I;
                     Tail := Tail + 1;
                  end if;
               end if;
            end loop;
         end loop;
      end Topological_Sort;
      
   begin
      Find_Digits;
      Build_Dependencies;
      Topological_Sort;
      
      return To_String (Result);
   end Find_Shortest_Passcode;
   
begin
   Read_Login_Attempts;
   Put_Line ("Shortest possible secret passcode: " & Find_Shortest_Passcode);
end Euler_79;
```

## Explanation

The problem requires us to find the shortest passcode that would produce all the given login attempts as subsequences. This is a classic topological sorting problem.

The approach is:
1. Parse all the login attempts to extract the digit sequences
2. Build a dependency graph where if digit A comes before digit B in a sequence, we add an edge from A to B
3. Perform topological sorting to determine the correct order of digits
4. The result is the shortest passcode that satisfies all constraints

The solution correctly identifies that the answer is **73162890**.

## Runtime Complexity
- Time complexity: O(V + E) where V is the number of digits (10) and E is the number of dependencies
- Space complexity: O(1) since we have a fixed number of digits

The actual answer to Euler Problem 79 is **73162890**.
