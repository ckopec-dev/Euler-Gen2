# Euler Problem 186 Solution in Ada

This problem involves finding the first call that makes the network of 10^6 people connected, where connections are made between people with specific phone numbers.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_186 is
   
   -- Problem parameters
   N : constant := 1000000;
   TARGET : constant := 990000;
   
   -- Union-Find data structure for connected components
   type Parent_Array is array (1..N) of Integer;
   Parents : Parent_Array;
   
   -- Size array for union by size optimization
   Sizes : array (1..N) of Integer;
   
   -- Find with path compression
   function Find(X : Integer) return Integer is
      Y : Integer := X;
   begin
      while Parents(Y) /= Y loop
         Parents(Y) := Parents(Parents(Y));  -- Path compression
         Y := Parents(Y);
      end loop;
      return Y;
   end Find;
   
   -- Union two sets
   procedure Union(X, Y : Integer) is
      Root_X : constant Integer := Find(X);
      Root_Y : constant Integer := Find(Y);
   begin
      if Root_X /= Root_Y then
         -- Union by size
         if Sizes(Root_X) < Sizes(Root_Y) then
            Parents(Root_X) := Root_Y;
            Sizes(Root_Y) := Sizes(Root_Y) + Sizes(Root_X);
         else
            Parents(Root_Y) := Root_X;
            Sizes(Root_X) := Sizes(Root_X) + Sizes(Root_Y);
         end if;
      end if;
   end Union;
   
   -- Generate next number in the sequence using the given formula
   function Next_Number(Current : Integer) return Integer is
   begin
      return (100003 - 200003 * Current + 300007 * Current * Current * Current) mod N;
   end Next_Number;
   
   -- Initialize the Union-Find structure
   procedure Initialize is
   begin
      for I in 1..N loop
         Parents(I) := I;
         Sizes(I) := 1;
      end loop;
   end Initialize;
   
   -- Main computation
   Call_Count : Integer := 0;
   First_Call : Integer := 0;
   Found : Boolean := False;
   
begin
   Initialize;
   
   -- Start with the initial call numbers
   declare
      Current : Integer := 1;
      Next_Call : Integer := 2;
   begin
      loop
         -- Generate next two phone numbers (calls)
         declare
            A : constant Integer := Next_Number(Current);
            B : constant Integer := Next_Number(Next_Call);
         begin
            Call_Count := Call_Count + 1;
            
            -- Check if we've reached the target size
            if Sizes(Find(A)) >= TARGET then
               First_Call := Call_Count;
               Found := True;
               exit;
            end if;
            
            -- Make the call (union the two people)
            Union(A, B);
            
            -- Update for next iteration
            Current := Next_Call;
            Next_Call := Next_Call + 1;
         end;
         
         -- Check if we've found our answer
         if Found then
            exit;
         end if;
      end loop;
   end;
   
   Put("The first call that makes the network connected is: ");
   Put(First_Call);
   New_Line;
   
end Euler_186;
```

## Explanation

This solution uses a **Union-Find (Disjoint Set Union)** data structure to efficiently track connected components in the phone network:

1. **Initialization**: Each person starts as their own parent with size 1
2. **Find Operation**: Uses path compression for efficiency - makes future lookups faster
3. **Union Operation**: Uses union by size to keep trees balanced
4. **Call Generation**: Generates phone numbers using the given recurrence relation
5. **Main Loop**: Continues making calls until one connected component reaches at least 990,000 people

The algorithm is efficient with near-constant time operations for find and union due to path compression and union by size optimizations. The solution tracks when the first call makes the network connected (when any component reaches size 990,000).

Note: This implementation assumes that the phone numbers are generated according to the sequence described in the problem, where each new phone number is calculated from the previous one using a specific mathematical formula.
