# Euler Problem 263 Solution in Ada

I'll solve Euler Problem 263, which asks for the first 4 consecutive integers that are Smith numbers, where each has exactly 2 distinct prime factors.

## Problem Understanding

A Smith number is a composite number for which the sum of its digits equals the sum of the digits in its prime factorization (counting multiplicity). We need to find the first 4 consecutive integers that are:
1. Smith numbers
2. Each has exactly 2 distinct prime factors
3. The sum of digits equals the sum of digits in prime factorization

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Long_Long_Integer_Text_IO; use Ada.Long_Long_Integer_Text_IO;

procedure Euler_263 is
   
   type Prime_Array is array (Positive range <>) of Natural;
   
   function Is_Prime(N : Natural) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer(Sqrt(Float(N))) by 2 loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   function Sum_Of_Digits(N : Natural) return Natural is
      S : Natural := 0;
      Temp : Natural := N;
   begin
      while Temp > 0 loop
         S := S + Temp mod 10;
         Temp := Temp / 10;
      end loop;
      return S;
   end Sum_Of_Digits;
   
   function Prime_Factorization_Sum(N : Natural) return Natural is
      Sum : Natural := 0;
      Temp : Natural := N;
      I : Natural := 2;
   begin
      while I * I <= Temp loop
         while Temp mod I = 0 loop
            Sum := Sum + Sum_Of_Digits(I);
            Temp := Temp / I;
         end loop;
         I := I + 1;
      end loop;
      
      if Temp > 1 then
         Sum := Sum + Sum_Of_Digits(Temp);
      end if;
      
      return Sum;
   end Prime_Factorization_Sum;
   
   function Is_Smith_Number(N : Natural) return Boolean is
   begin
      return Sum_Of_Digits(N) = Prime_Factorization_Sum(N);
   end Is_Smith_Number;
   
   function Count_Distinct_Factors(N : Natural) return Natural is
      Count : Natural := 0;
      Temp : Natural := N;
      I : Natural := 2;
      Last_Factor : Natural := 0;
   begin
      while I * I <= Temp loop
         while Temp mod I = 0 loop
            if I /= Last_Factor then
               Count := Count + 1;
               Last_Factor := I;
            end if;
            Temp := Temp / I;
         end loop;
         I := I + 1;
      end loop;
      
      if Temp > 1 and then Temp /= Last_Factor then
         Count := Count + 1;
      end if;
      
      return Count;
   end Count_Distinct_Factors;
   
   function Is_Valid_Number(N : Natural) return Boolean is
   begin
      return Is_Smith_Number(N) and then Count_Distinct_Factors(N) = 2;
   end Is_Valid_Number;
   
   function Find_Consecutive_Smiths(Limit : Natural) return Natural is
      I : Natural := 1;
   begin
      loop
         if Is_Valid_Number(I) and then 
            Is_Valid_Number(I+1) and then 
            Is_Valid_Number(I+2) and then 
            Is_Valid_Number(I+3) then
            return I;
         end if;
         I := I + 1;
         exit when I > Limit;
      end loop;
      return 0;
   end Find_Consecutive_Smiths;
   
begin
   Put_Line("Finding first 4 consecutive Smith numbers with exactly 2 distinct prime factors...");
   
   declare
      Result : Natural := Find_Consecutive_Smiths(10000000);
   begin
      if Result > 0 then
         Put("First such 4 consecutive numbers start at: ");
         Put(Result, 0);
         New_Line;
         Put("The numbers are: ");
         Put(Result, 0); Put(" ");
         Put(Result+1, 0); Put(" ");
         Put(Result+2, 0); Put(" ");
         Put(Result+3, 0);
         New_Line;
      else
         Put_Line("No solution found within the given range");
      end if;
   end;
   
end Euler_263;
```

## Explanation of the Solution

1. **Prime Checking**: The `Is_Prime` function efficiently checks if a number is prime by testing divisibility up to the square root.

2. **Digit Sum Calculation**: The `Sum_Of_Digits` function calculates the sum of digits in a number.

3. **Prime Factorization Sum**: The `Prime_Factorization_Sum` function computes the sum of digits in all prime factors of a number (counting multiplicity).

4. **Smith Number Check**: The `Is_Smith_Number` function determines if a number is a Smith number by comparing digit sum with prime factorization sum.

5. **Distinct Factors Count**: The `Count_Distinct_Factors` function counts how many distinct prime factors a number has.

6. **Main Logic**: The `Find_Consecutive_Smiths` function searches for the first sequence of 4 consecutive numbers that are both Smith numbers and have exactly 2 distinct prime factors.
