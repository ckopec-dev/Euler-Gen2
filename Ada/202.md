# Euler Problem 202 Solution in Ada

I'll solve Project Euler Problem 202, which involves finding the number of ways to write a number as a sum of powers of 2.

## Problem Statement
Project Euler 202 asks: "How many ways are there to write 10^25 as a sum of powers of 2 where each power can be used at most twice?"

## Solution Approach
This is a dynamic programming problem where we need to count the number of ways to express a number as a sum of powers of 2, with each power used at most twice.

   function Count_Ways(n : Big_Integer) return Big_Integer is
      -- We'll use dynamic programming approach
      -- For each power of 2, we can use it 0, 1, or 2 times
      Max_Power : constant := 85;  -- 2^85 > 10^25
      DP : array (0 .. Max_Power) of Big_Integer;
      Result : Big_Integer := 0;
   begin
      -- Initialize DP array
      for i in 0 .. Max_Power loop
         DP(i) := 0;
      end loop;
      
      -- Base case: there's one way to make 0 (use nothing)
      DP(0) := 1;
      
      -- For each power of 2 from 1 to the maximum needed
      for i in 1 .. Max_Power loop
         declare
            Power : Big_Integer := 2**(i-1);
         begin
            -- We can use this power 0, 1, or 2 times
            -- But we only process if power <= n
            if Power > n then
               exit;
            end if;
            
            -- Update DP array from right to left to avoid overcounting
            for j in (n - Power) downto 0 loop
               if DP(j) /= 0 then
                  -- Use this power 1 time
                  if j + Power <= n then
                     DP(j + Power) := DP(j + Power) + DP(j);
                  end if;
                  
                  -- Use this power 2 times
                  if j + 2 * Power <= n then
                     DP(j + 2 * Power) := DP(j + 2 * Power) + DP(j);
                  end if;
               end if;
            end loop;
         end;
      end loop;
      
      return DP(n);
