# Euler Problem 64 Solution in Ada

This problem asks us to find how many continued fractions for √N have an odd period, where N is not a perfect square.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_64 is
   
   type Continued_Fraction is record
      a0 : Integer;
      period_length : Natural;
   end record;
   
   function Is_Perfect_Square(N : Integer) return Boolean is
   begin
      if N < 0 then
         return False;
      end if;
      
      declare
         Sqrt_N : Integer := Integer(Sqrt(Float(N)));
      begin
         return Sqrt_N * Sqrt_N = N;
      end;
   end Is_Perfect_Square;
   
   function Continued_Fraction_Period_Length(N : Integer) return Natural is
      m : Integer := 0;
      d : Integer := 1;
      a : Integer := Integer(Sqrt(Float(N)));
      a0 : Integer := a;
      period_count : Natural := 0;
      a_prev : Integer := 0;
   begin
      if Is_Perfect_Square(N) then
         return 0;
      end if;
      
      loop
         m := d * a - m;
         d := (N - m * m) / d;
         a := (a0 + m) / d;
         
         period_count := period_count + 1;
         
         exit when a = 2 * a0;
      end loop;
      
      return period_count;
   end Continued_Fraction_Period_Length;
   
   Count : Natural := 0;
   
begin
   for i in 2 .. 10000 loop
      if not Is_Perfect_Square(i) then
         if Continued_Fraction_Period_Length(i) mod 2 = 1 then
            Count := Count + 1;
         end if;
      end if;
   end loop;
   
   Put("Answer: ");
   Put(Count, 0);
   New_Line;
   
end Euler_64;
```

## Explanation

The solution uses the standard algorithm for finding the continued fraction expansion of √N:

1. **Perfect Square Check**: First, we check if N is a perfect square (since √N would be rational in that case, not an infinite continued fraction).

2. **Continued Fraction Algorithm**: 
   - Initialize: m₀ = 0, d₀ = 1, a₀ = floor(√N)
   - For each step: mₙ₊₁ = dₙ × aₙ - mₙ
   - dₙ₊₁ = (N - mₙ₊₁²) / dₙ
   - aₙ₊₁ = floor((a₀ + mₙ₊₁) / dₙ₊₁)
   - Continue until aₙ = 2 × a₀ (period repeats)

3. **Counting**: We count how many non-perfect square numbers from 2 to 10000 have an odd period length.

The key insight is that for √N, the continued fraction expansion will be periodic, and we only need to count those with odd periods.

**Answer: 1322**
