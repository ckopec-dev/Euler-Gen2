# Euler Problem 41 Solution in Ada

Problem 41: We shall say that an n-digit number is pandigital if it makes use of all the digits 1 to n exactly once. For example, 2143 is a 4-digit pandigital and is also prime.

What is the largest n-digit pandigital prime that exists?

## Solution Approach

I'll create a solution that:
1. Generates pandigital numbers in descending order
2. Checks if each number is prime
3. Returns the first (largest) prime found

```ada
         return True;

         return False;
      else

            if N mod I = 0 then

      end if;
```

```ada
      S : String(1..9);
      L : Integer := 0;
      Digits_Used : array (1..9) of Boolean := (others => False);
      Temp : Integer := N;
   begin
      -- Convert to string and count digits
      while Temp > 0 loop
         L := L + 1;
         S(L) := Character'Val(Temp mod 10 + Character'Pos('0'));
         Temp := Temp / 10;
      end loop;
      
      -- Check if number of digits matches expected pandigital
      if L = 0 or else L > 9 then
         return False;
      end if;
      
      -- Check that we have exactly the digits 1 to L
      for I in 1..L loop
         declare
            Digit : Integer := Character'Pos(S(I)) - Character'Pos('0');
         begin
            if Digit < 1 or else Digit > L or else Digits_Used(Digit) then
               return False;
            end if;
            Digits_Used(Digit) := True;
         end;
      end loop;
      
      -- Check that we used all digits from 1 to L
      for I in 1..L loop
         if not Digits_Used(I) then
            return False;
         end if;
      end loop;
      
      return True;
   end Is_Pandigital;
   
   -- Find the largest pandigital prime
   function Find_Largest is
      Max : Integer := 0;
      -- Check from largest possible pandigital numbers down
      -- Since we know 9-digit pandigitals can't be prime (sum of digits = 45, divisible by 3)
      -- And 8-digit pandigitals sum to 36, also divisible by 3
      -- We should check 7-digit pandigitals first

      for I in reverse 7654321..1234567 loop
         if Is_Pandigital(I) and then Is_Prime(I) then
            return I;
         end if;
      end loop;
      
      -- If no 7-digit found, check 6-digit etc.
      for I in reverse 654321..123456 loop

      end loop;
      
      for I in reverse 54321..12345 loop
         if Is_Pandigital(I) and then Is_Prime(I) then

         end if;
      end loop;
      
      for I in reverse 4321..1234 loop
         if Is_Pandigital(I) and then Is_Prime(I) then
            return I;
         end if;
      end loop;
      
      return Max;
   end Find_Largest;
```

## Final Solution

Looking at this more carefully, let me provide the actual solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_41 is
   
   -- Function to check if a number is prime
   function Is_Prime(N : Integer) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3..Integer(Sqrt(Float(N))) by 2 loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Function to check if a number is pandigital (1 to n)
   function Is_Pandigital(N : Integer) return Boolean is
      Digits_Used : array (1..9) of Boolean := (others => False);
      Temp : Integer := N;
      Digit_Count : Integer := 0;
      Last_Digit : Integer;
   begin
      -- Count digits and check for validity
      while Temp > 0 loop
         Digit_Count := Digit_Count + 1;
         Last_Digit := Temp mod 10;
         
         -- Check if digit is valid (1-9) and not already used
         if Last_Digit < 1 or else Last_Digit > Digit_Count or else Digits_Used(Last_Digit) then
            return False;
         end if;
         
         Digits_Used(Last_Digit) := True;
         Temp := Temp / 10;
      end loop;
      
      -- All digits from 1 to Digit_Count must be used exactly once
      for I in 1..Digit_Count loop
         if not Digits_Used(I) then
            return False;
         end if;
      end loop;
      
      return True;
   end Is_Pandigital;
   
   -- Find the largest pandigital prime
   function Solve return Integer is
      -- Start with 7-digit numbers since we know that 9 and 8 digit pandigitals 
      -- are divisible by 3 (sum of digits 1+2+...+9 = 45, 1+2+...+8 = 36)
   begin
      for N in reverse 7654321..1234567 loop
         if Is_Pandigital(N) and then Is_Prime(N) then
            return N;
         end if;
      end loop;
      
      return -1; -- Should not happen
   end Solve;

begin
   Put_Line("Largest pandigital prime: " & Integer'Image(Solve));
end Euler_41;
```
