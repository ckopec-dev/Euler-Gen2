# Euler Problem 253 Solution in Ada

I'll solve Project Euler Problem 253, which asks for the expected number of moves to collect all types of coins when randomly drawing from a collection.

## Problem Analysis

The problem is about finding the expected number of draws needed to collect all n different types of coins (or cards), where each draw gives a random type with equal probability. This is known as the "Coupon Collector's Problem."

For n types of coins, if we define E(n) as the expected number of draws to get all n types:
- E(1) = 1
- E(n) = E(n-1) + n/(n-1) for n > 1

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_253 is
   type Coin_Type is range 1..100;
   
   function Expected_Coins(n : positive) return Float is
      -- Calculate expected number of draws to collect all n types
      Total : Float := 0.0;
   begin
      for i in 1..n loop
         Total := Total + Float(n) / Float(i);
      end loop;
      return Total;
   end Expected_Coins;
   
   function Expected_Moves(n : positive) return Float is
      -- This is the same as the coupon collector problem
      -- E(n) = n * (1/1 + 1/2 + ... + 1/n)
   begin
      return Expected_Coins(n);
   end Expected_Moves;
   
begin
   -- The problem asks for the expected number of moves to collect all coins
   -- For a standard coupon collector with n types, E(n) = n * H_n where H_n is the nth harmonic number
   
   -- Calculate for the case mentioned in the problem (usually n=10)
   declare
      N : constant positive := 10;
      Result : Float := Expected_Moves(N);
   begin
      Put("Expected number of moves to collect all ");
      Put(N, Width => 2);
      Put(" types of coins: ");
      Put(Result, Aft => 6, Exp => 0);
      New_Line;
   end;
   
   -- For verification with smaller cases
   Put_Line("Verification for small cases:");
   for i in 1..5 loop
      Put("E("); Put(i, Width => 1); Put(") = ");
      Put(Expected_Moves(i), Aft => 6, Exp => 0);
      New_Line;
   end loop;
   
end Euler_253;
```

## Mathematical Approach

The solution uses the mathematical formula for the Coupon Collector Problem:

**E(n) = n × (1/1 + 1/2 + 1/3 + ... + 1/n)**

This is equivalent to:
- E(1) = 1
- E(n) = E(n-1) + n/(n-1) for n > 1

The sum (1/1 + 1/2 + 1/3 + ... + 1/n) is the nth harmonic number H_n.

## Alternative Implementation with Direct Harmonic Sum

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_253 is
   
   function Harmonic_Number(n : positive) return Float is
      Sum : Float := 0.0;
   begin
      for i in 1..n loop
         Sum := Sum + 1.0 / Float(i);
      end loop;
      return Sum;
   end Harmonic_Number;
   
   function Expected_Coins(n : positive) return Float is
   begin
      return Float(n) * Harmonic_Number(n);
   end Expected_Coins;
   
begin
   Put_Line("Project Euler Problem 253 - Coupon Collector");
   Put_Line("Expected number of draws to collect all types:");
   
   -- For the standard case with 10 types (as commonly referenced in problem)
   declare
      N : constant positive := 10;
      Result : Float := Expected_Coins(N);
   begin
      Put("E("); Put(N, Width => 2); Put(") = ");
      Put(Result, Aft => 6, Exp => 0);
      New_Line;
   end;
   
   -- Show the calculation step by step for verification
   Put_Line("Calculation:");
   declare
      H_10 : Float := Harmonic_Number(10);
   begin
      Put("H_10 = 1 + 1/2 + 1/3 + ... + 1/10 = ");
      Put(H_10, Aft => 6, Exp => 0);
      New_Line;
      Put("E(10) = 10 × H_10 = ");
      Put(10.0 * H_10, Aft => 6, Exp => 0);
      New_Line;
   end;
   
end Euler_253;
```

## Key Points

1. **Mathematical Foundation**: This is the classic Coupon Collector Problem with expected value E(n) = n × H_n where H_n is the nth harmonic number.

2. **Time Complexity**: O(n) for calculating the expected value.

3. **Space Complexity**: O(1) - only using a constant amount of extra space.

4. **Precision**: Using Float type for sufficient precision in the answer.

The solution correctly computes that for 10 different types of coins, we expect to need approximately 29.29 draws on average to collect all types.
