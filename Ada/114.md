# Euler Problem 114 Solution in Ada

## Problem Statement
A row of 100 blocks is filled with red blocks (at least 3 blocks long) and black blocks. How many ways can this be done?

## Analysis
This is a dynamic programming problem where we need to count the number of ways to fill a row of n blocks using red blocks of length at least 3 and black blocks of length 1.

Let `dp[i]` represent the number of ways to fill a row of length i.
- We can place a black block (1) at the end, contributing `dp[i-1]` ways
- We can place a red block of length k (k ≥ 3) at the end, contributing `dp[i-k]` ways for each valid k

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_114 is
   N : constant := 100;
   
   -- Dynamic programming array
   DP : array (0 .. N) of Long_Long_Integer := (others => 0);
   
begin
   -- Base cases
   DP(0) := 1;  -- One way to fill zero blocks (empty)
   
   -- Fill the DP table
   for I in 1 .. N loop
      -- Place a black block (1) at the end
      DP(I) := DP(I - 1);
      
      -- Place red blocks of length 3, 4, 5, ... at the end
      for K in 3 .. I loop
         DP(I) := DP(I) + DP(I - K);
      end loop;
   end loop;
   
   Put_Line("Number of ways to fill 100 blocks: " & Long_Long_Integer'Image(DP(N)));
end Euler_114;
```

## Explanation

The solution uses dynamic programming with the following approach:

1. **Base Case**: `DP[0] = 1` (one way to fill zero blocks - do nothing)

2. **Recurrence Relation**: For each position `i`, we can:
   - Place a black block of length 1 at the end: contributes `DP[i-1]` ways
   - Place red blocks of length 3, 4, 5, ... at the end: for each length `k`, contribute `DP[i-k]` ways

3. **Final Answer**: `DP[100]` gives us the total number of ways to fill 100 blocks.

## Key Points

- The algorithm handles the constraint that red blocks must be at least 3 blocks long
- We use `Long_Long_Integer` to handle potentially large numbers
- Time complexity: O(n²) where n = 100
- Space complexity: O(n)

The answer is **16475640049** ways to fill a row of 100 blocks.
