# Euler Problem 55 Solution in Ada

Euler Problem 55 asks: "How many Lychrel numbers are there below ten-thousand?"

A Lychrel number is a natural number that cannot form a palindrome through the iterative process of repeatedly adding it to its reverse.

Here's the Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_55 is
   
   type Big_Integer is array (1..200) of Integer;
   
   function Is_Palindrome(N : Big_Integer; Length : Integer) return Boolean is
      I : Integer;
   begin
      for I in 1..Length/2 loop
         if N(I) /= N(Length - I + 1) then
            return False;
         end if;
      end loop;
      return True;
   end Is_Palindrome;
   
   function Add_Reverse(N : Big_Integer; Length : Integer) return Big_Integer is
      Result : Big_Integer := (others => 0);
      Carry : Integer := 0;
      I : Integer;
      Sum : Integer;
   begin
      -- Add N to its reverse
      for I in 1..Length loop
         Sum := N(I) + N(Length - I + 1) + Carry;
         Result(I) := Sum mod 10;
         Carry := Sum / 10;
      end loop;
      
      -- Handle carry that might extend the number
      if Carry > 0 then
         Result(Length + 1) := Carry;
      end if;
      
      return Result;
   end Add_Reverse;
   
   function Is_Lychrel(N : Integer) return Boolean is
      Current : Big_Integer := (others => 0);
      Length : Integer := 0;
      Iteration : Integer := 0;
      Temp : Big_Integer;
   begin
      -- Convert N to big integer array
      declare
         T : Integer := N;
         I : Integer := 1;
      begin
         while T > 0 loop
            Current(I) := T mod 10;
            T := T / 10;
            I := I + 1;
         end loop;
         Length := I - 1;
      end;
      
      -- Check if it's Lychrel (max 50 iterations)
      for Iteration in 1..50 loop
         Temp := Add_Reverse(Current, Length);
         
         -- Update length if needed
         if Temp(Length + 1) /= 0 then
            Length := Length + 1;
         end if;
         
         -- Check if palindrome
         if Is_Palindrome(Temp, Length) then
            return False;  -- Not Lychrel
         end if;
         
         Current := Temp;
      end loop;
      
      return True;  -- Lychrel number
   end Is_Lychrel;
   
   Count : Integer := 0;
   I : Integer;
begin
   for I in 1..9999 loop
      if Is_Lychrel(I) then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("Number of Lychrel numbers below 10,000: ");
   Put(Count);
   New_Line;
end Euler_55;
```

## Explanation

This solution works as follows:

1. **Big Integer Support**: Since we're dealing with potentially large numbers (after multiple additions), I created a custom `Big_Integer` type using an array to handle numbers that exceed standard integer limits.

2. **Palindrome Check**: The `Is_Palindrome` function checks if the digits in the big integer form a palindrome by comparing elements from both ends.

3. **Add Reverse Function**: The `Add_Reverse` function adds a number to its reverse, handling carries properly through the array representation.

4. **Lychrel Detection**: The `Is_Lychrel` function:
   - Converts the input number into the big integer format
   - Iteratively adds the number to its reverse for up to 50 iterations
   - Checks if a palindrome is formed at each step
   - Returns `True` if no palindrome is found within 50 iterations

5. **Main Logic**: The program counts all numbers from 1 to 9999 that are Lychrel numbers.

The answer is **249** Lychrel numbers below ten-thousand.
