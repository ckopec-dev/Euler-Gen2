## Problem Understanding

Euler Problem 354 asks us to find the number of lattice points (points with integer coordinates) that lie inside or on a circle centered at (0,0) with radius r, where r is a positive integer.

This is essentially counting lattice points within a circle of radius r.

## Mathematical Analysis

The problem requires counting all integer pairs (x,y) such that:
x² + y² ≤ r²

For each value of x from -r to r, we need to count how many integer values of y satisfy the condition.
