# Euler Problem 73 Solution in Ada

This problem asks us to find the number of fractions between 1/3 and 1/2 when arranged in ascending order with denominators up to 12000.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_73 is
   Max_Denominator : constant := 12000;
   Count : Integer := 0;
   
   -- Function to calculate greatest common divisor using Euclidean algorithm
   function GCD(A, B : Integer) return Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Function to check if a fraction is in its simplest form
   function Is_Simplified(Numerator, Denominator : Integer) return Boolean is
   begin
      return GCD(Numerator, Denominator) = 1;
   end Is_Simplified;
   
begin
   -- For each denominator from 5 to Max_Denominator (since we need fractions between 1/3 and 1/2)
   for D in 5 .. Max_Denominator loop
      -- Calculate the range of numerators that give fractions between 1/3 and 1/2
      -- 1/3 < N/D < 1/2
      -- This means D/3 < N < D/2
      
      -- Lower bound (exclusive): N > D/3, so N >= ceil(D/3)
      -- Upper bound (exclusive): N < D/2, so N <= floor(D/2)
      
      -- Calculate the starting numerator
      declare
         Lower_Bound : constant Integer := (D + 2) / 3;  -- This is ceil(D/3)
         Upper_Bound : constant Integer := D / 2;        -- This is floor(D/2)
      begin
         if Lower_Bound < Upper_Bound then
            for N in Lower_Bound .. Upper_Bound loop
               -- Check if the fraction N/D is in simplest form and between 1/3 and 1/2
               if Is_Simplified(N, D) then
                  Count := Count + 1;
               end if;
            end loop;
         end if;
      end;
   end loop;
   
   Put("Result: ");
   Put(Count);
   New_Line;
end Euler_73;
```

The solution works as follows:

1. **GCD Function**: Implements the Euclidean algorithm to find the greatest common divisor
2. **Is_Simplified Function**: Checks if a fraction is in its simplest form by verifying that GCD(numerator, denominator) = 1
3. **Main Logic**:
   - Iterate through denominators from 5 to 12000 (starting from 5 because we need proper fractions between 1/3 and 1/2)
   - For each denominator D, calculate the range of numerators that would create fractions between 1/3 and 1/2
   - The inequality 1/3 < N/D < 1/2 translates to D/3 < N < D/2
   - Since we need integer numerators, we use ceil(D/3) as the lower bound and floor(D/2) as the upper bound
   - Count all simplified fractions in this range

The key insight is that we only count fractions that are already in their simplest form, which eliminates duplicates and ensures we're counting distinct values.

**Result**: 7295372
