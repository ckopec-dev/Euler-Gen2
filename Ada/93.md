# Euler Problem 93 Solution in Ada

This problem asks us to find the set of four distinct digits that can form the maximum number of consecutive positive integers starting from 1 using basic arithmetic operations.

## Analysis

We need to:
1. Try all combinations of 4 distinct digits from 1-9
2. For each combination, try all possible arrangements of the digits
3. For each arrangement, try all possible combinations of operators (+, -, *, /)
4. Calculate all valid results and count consecutive integers starting from 1
5. Find the combination that produces the maximum consecutive count
