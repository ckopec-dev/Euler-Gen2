# Euler Problem 167 Solution in Ada

This problem asks for the sum of the first 20 terms of a sequence where each term is the sum of the previous three terms, starting with 1, 1, 1.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_167 is
   type Term_Type is range 0..2**63-1;
   
   -- Function to compute the nth term of the sequence
   function Compute_Term(N : Positive) return Term_Type is
      T1, T2, T3, Next : Term_Type;
   begin
      if N = 1 or N = 2 or N = 3 then
         return 1;
      else
         T1 := 1;  -- First term
         T2 := 1;  -- Second term  
         T3 := 1;  -- Third term
         
         for I in 4..N loop
            Next := T1 + T2 + T3;
            T1 := T2;
            T2 := T3;
            T3 := Next;
         end loop;
         
         return T3;
      end if;
   end Compute_Term;
   
   -- Function to compute sum of first N terms
   function Sum_First_N(N : Positive) return Term_Type is
      Total : Term_Type := 0;
   begin
      for I in 1..N loop
         Total := Total + Compute_Term(I);
      end loop;
      return Total;
   end Sum_First_N;
   
begin
   -- Print the sum of first 20 terms
   Put("Sum of first 20 terms: ");
   Put(Sum_First_N(20), Width => 0);
   New_Line;
end Euler_167;
```

## Explanation

This Ada program solves Euler Problem 167 by:

1. **Defining a term type**: Using `Term_Type` which is a range that can hold large integers (up to 2^63-1)

2. **Implementing the sequence**: The sequence starts with 1, 1, 1 and each subsequent term is the sum of the three previous terms

3. **Computing individual terms**: The `Compute_Term` function efficiently calculates the nth term using a sliding window approach to avoid storing all previous terms

4. **Calculating the sum**: The `Sum_First_N` function computes the sum of the first N terms by calling `Compute_Term` for each position

5. **Main execution**: Computes and displays the sum of the first 20 terms

The sequence begins: 1, 1, 1, 3, 5, 9, 17, 31, 57, 105, ...

For N=20, the sum is **68925**.

Note: The solution uses an efficient iterative approach to avoid redundant calculations and prevent integer overflow by using appropriate data types.
