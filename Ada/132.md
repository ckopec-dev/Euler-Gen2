# Euler Problem 132 Solution in Ada

## Problem Statement
Find the sum of all primes that are factors of R(10^9) where R(n) is a repunit (a number consisting of n ones).

## Solution Approach
1. We need to find primes that divide R(10^9) = (10^10^9 - 1)/9
2. A prime p divides R(n) if and only if the multiplicative order of 10 modulo p divides n
3. For R(10^9), we need primes where the order of 10 modulo p divides 10^9
4. This means the order must be a divisor of 10^9 = 2^9 × 5^9

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Long_Long_Integer_Text_IO; use Ada.Long_Long_Integer_Text_IO;

procedure Euler_132 is
   
   type Prime_Array is array (Positive range <>) of Integer;
   
   -- Function to check if a number is prime
   function Is_Prime(N : Long_Long_Integer) return Boolean is
      Root : Long_Long_Integer;
   begin
      if N <= 1 then
         return False;
      elsif N <= 3 then
         return True;
      elsif N mod 2 = 0 or else N mod 3 = 0 then
         return False;
      end if;
      
      Root := Long_Long_Integer(Sqrt(Float(N)));
      for I in 5 .. Root loop
         if N mod I = 0 or else N mod (I + 2) = 0 then
            return False;
         end if;
      end loop;
      
      return True;
   end Is_Prime;
   
   -- Calculate multiplicative order of 10 modulo p
   function Order_Of_10_Mod_P(P : Integer) return Integer is
      Power : Long_Long_Integer := 1;
      Order : Integer := 0;
   begin
      if P = 2 or else P = 5 then
         return 0; -- Special case: 10 ≡ 0 (mod 2) or 10 ≡ 0 (mod 5)
      end if;
      
      for I in 1 .. P loop
         Power := (Power * 10) mod Long_Long_Integer(P);
         Order := I;
         if Power = 1 then
            return Order;
         end if;
      end loop;
      
      return 0; -- Should not happen for prime p > 2
   end Order_Of_10_Mod_P;
   
   -- Function to check if a prime divides R(10^9)
   function Divides_R_N(P : Integer) return Boolean is
      N : constant Long_Long_Integer := 10**9;
      O : constant Integer := Order_Of_10_Mod_P(P);
   begin
      -- If order is 0, it means 10 ≡ 0 (mod p), so p = 2 or p = 5
      if O = 0 then
         return False;
      end if;
      
      -- Check if the order divides 10^9
      return N mod Long_Long_Integer(O) = 0;
   end Divides_R_N;
   
   -- Generate primes up to a limit using Sieve of Eratosthenes
   function Get_Primes(Limit : Integer) return Prime_Array is
      Is_Prime_Array : array (1 .. Limit) of Boolean := (others => True);
      Count : Integer := 0;
      Result : Prime_Array(1 .. Limit);
   begin
      Is_Prime_Array(1) := False;
      
      for I in 2 .. Integer(Sqrt(Float(Limit))) loop
         if Is_Prime_Array(I) then
            for J in I * I .. Limit loop
               if J mod I = 0 then
                  Is_Prime_Array(J) := False;
               end if;
            end loop;
         end if;
      end loop;
      
      for I in 2 .. Limit loop
         if Is_Prime_Array(I) then
            Count := Count + 1;
            Result(Count) := I;
         end if;
      end loop;
      
      return Result(1 .. Count);
   end Get_Primes;
   
   -- Main solution
   N : constant Long_Long_Integer := 10**9;
   Primes : Prime_Array(1 .. 10000); -- Enough primes to find first 40
   Sum : Long_Long_Integer := 0;
   Count : Integer := 0;
   
begin
   -- Generate primes up to a reasonable limit
   Primes := Get_Primes(1000000);
   
   -- Check each prime
   for I in Primes'First .. Primes'Last loop
      if Primes(I) > 1000000 then
         exit;
      end if;
      
      if Divides_R_N(Primes(I)) then
         Sum := Sum + Long_Long_Integer(Primes(I));
         Count := Count + 1;
         
         -- Print progress
         Put("Prime ");
         Put(Primes(I), Width => 0);
         Put(" divides R(10^9)");
         New_Line;
         
         if Count >= 40 then -- We only need first 40 primes that work
            exit;
         end if;
      end if;
   end loop;
   
   Put("Sum of first 40 primes that divide R(10^9): ");
   Put(Sum, Width => 0);
   New_Line;
   
end Euler_132;
```

## Key Insights

The mathematical approach is based on the following:
- R(n) = (10^n - 1)/9
- A prime p > 5 divides R(n) if and only if the multiplicative order of 10 modulo p divides n
- For R(10^9), we want primes where order of 10 mod p divides 10^9 = 2^9 × 5^9

## Optimization Notes

The solution uses:
1. Sieve of Eratosthenes for efficient prime generation
2. Efficient multiplicative order calculation
3. Early termination when enough primes are found
