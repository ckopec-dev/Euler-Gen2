# Euler Problem 15 Solution in Ada

Euler Problem 15 asks: "Starting in the top left corner of a 20×20 grid, how many routes are there to the bottom right corner?"

This is a classic combinatorics problem. To go from the top-left to bottom-right corner of an m×n grid, we need exactly m moves right and n moves down, for a total of (m+n) moves. The number of ways to arrange these moves is the binomial coefficient C(m+n, m) or C(m+n, n).

For a 20×20 grid, this becomes C(40, 20).

```ada
with Ada.Text_IO;
with Ada.Integer_Text_IO;

procedure Euler_15 is
   type Big_Integer is range 0 .. 10**20;
   
   function Binomial_Coefficient(n, k : Positive) return Big_Integer is
      Result : Big_Integer := 1;
   begin
      -- Take advantage of symmetry: C(n,k) = C(n,n-k)
      if k > n - k then
         return Binomial_Coefficient(n, n - k);
      end if;
      
      for i in 1 .. k loop
         Result := Result * (n - i + 1) / i;
      end loop;
      
      return Result;
   end Binomial_Coefficient;
   
begin
   -- For a 20x20 grid, we need C(40, 20)
   Ada.Text_IO.Put_Line("Number of routes in a 20x20 grid:");
   Ada.Integer_Text_IO.Put(Binomial_Coefficient(40, 20), Width => 0);
   Ada.Text_IO.New_Line;
end Euler_15;
```

The solution uses the following approach:

1. **Combinatorial Mathematics**: The problem reduces to calculating the binomial coefficient C(40, 20) since we need exactly 20 right moves and 20 down moves in any order.

2. **Efficient Calculation**: Instead of computing factorials directly (which would cause overflow), we calculate the binomial coefficient iteratively using the formula:
   ```
   C(n,k) = n! / (k! × (n-k)!)
   ```
   By rearranging terms, we compute it as:
   ```
   C(n,k) = (n × (n-1) × ... × (n-k+1)) / (k × (k-1) × ... × 1)
   ```

3. **Optimization**: We use the symmetry property C(n,k) = C(n,n-k) to minimize calculations by choosing the smaller of k and n-k.

The answer for a 20×20 grid is **137,846,528,820**.
