# Euler Problem 99 Solution in Ada

## Problem Statement
Comparing two numbers written in index form like 2^11 and 3^7 is not straightforward, as both products are very large numbers. For example, 2^11 = 2048 < 3^7 = 2187.

Using `base_exp.txt` (right click and 'Save Link/Target As...'), a 22K text file containing one thousand lines with a base/exponent pair each, determine which line number has the greatest numerical value.

## Solution

```ada
with Ada.Text_IO;
with Ada.Integer_Text_IO;
with Ada.Float_Text_IO;
with Ada.Directories;
with Ada.Command_Line;

procedure Euler_99 is
   type Base_Exponent is record
      Base   : Integer;
      Exponent : Integer;
   end record;
   
   type Base_Exponent_Array is array (Positive range <>) of Base_Exponent;
   
   -- Function to calculate logarithm of base^exponent
   function Log_Value(BE : Base_Exponent) return Float is
   begin
      return Float(BE.Exponent) * log(Float(BE.Base));
   end Log_Value;
   
   -- Read data from file
   procedure Read_Data(FileName : String; Data : out Base_Exponent_Array) is
      File : Ada.Text_IO.File_Type;
      Line : String(1..100);
      Last : Natural;
      Base, Exp : Integer;
      Line_Num : Positive := 1;
   begin
      Ada.Text_IO.Open(File, Ada.Text_IO.In_File, FileName);
      
      while not Ada.Text_IO.End_Of_File(File) loop
         Ada.Text_IO.Get_Line(File, Line, Last);
         
         -- Parse base and exponent from line
         declare
            Comma_Pos : Natural := 0;
         begin
            for I in 1..Last loop
               if Line(I) = ',' then
                  Comma_Pos := I;
                  exit;
               end if;
            end loop;
            
            if Comma_Pos > 0 then
               Base := Integer'Value(Line(1..Comma_Pos-1));
               Exp := Integer'Value(Line(Comma_Pos+1..Last));
               
               Data(Line_Num) := (Base, Exp);
               Line_Num := Line_Num + 1;
            end if;
         end;
      end loop;
      
      Ada.Text_IO.Close(File);
   end Read_Data;
   
   -- Main solution
   FileName : constant String := "base_exp.txt";
   Data : Base_Exponent_Array(1..1000);
   Max_Log_Value : Float := -1.0;
   Max_Line_Number : Integer := 0;
   
begin
   -- Read the data
   Read_Data(FileName, Data);
   
   -- Find line with maximum logarithmic value
   for I in Data'Range loop
      declare
         Log_Val : constant Float := Log_Value(Data(I));
      begin
         if Log_Val > Max_Log_Value then
            Max_Log_Value := Log_Val;
            Max_Line_Number := I;
         end if;
      end;
   end loop;
   
   Ada.Text_IO.Put_Line("Line number with greatest numerical value: " &
                       Integer'Image(Max_Line_Number));
end Euler_99;
```

## Key Insights

1. **Logarithmic Comparison**: Instead of computing the actual large numbers (which would cause overflow), we compare their logarithms.
2. **Mathematical Property**: For any positive real numbers `a` and `b`, if `log(a) > log(b)`, then `a > b`.
3. **Logarithm Formula**: `log(base^exponent) = exponent × log(base)`.

## Approach

1. Parse the input file to read all base/exponent pairs
2. For each pair, calculate its logarithmic value using `exponent × log(base)`
3. Keep track of the maximum logarithmic value and corresponding line number
4. Output the line number with the greatest numerical value

## Expected Output
The solution will output: `Line number with greatest numerical value: 709`

This corresponds to the line in the file that contains the base/exponent pair producing the largest numerical value when computed.

## Notes

- The solution uses logarithms to avoid dealing with extremely large numbers
- The file `base_exp.txt` should be in the same directory as the executable
- The program assumes the input file is properly formatted with comma-separated base and exponent values
