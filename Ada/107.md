# Euler Problem 107 Solution in Ada

## Problem Statement
The following undirected network consists of seven vertices and twelve edges with a total weight of 249.

The network can be represented by the matrix below:
```
    A   B   C   D   E   F   G
A   -  16  12  21  -   -   -
B  16  -   -   17  20  -   -
C  12  -   -   28  -   31  -
D  21  17  28  -   18  19  23
E   -  20  -   18  -   -   11
F   -   -  31  19  -   -   27
G   -   -  31  23  11  27  -
```

The same network can be represented by the matrix below:
```
    A   B   C   D   E   F   G
A   0  16  12  21  0   0   0
B  16  0   0   17  20  0   0
C  12  0   0   28  0   31  0
D  21  17  28  0   18  19  23
E   0  20  0   18  0   0   11
F   0   0  31  19  0   0   27
G   0   0  31  23  11  27  0
```

However, it is possible to optimise the network by removing some edges and still ensure that all points on the network remain connected. The network which achieves the maximum saving is shown below. It has a weight of 93, representing a saving of 249 − 93 = 156.

Find the maximum saving which can be achieved by removing redundant edges from the network.

## Solution Approach
This is a Minimum Spanning Tree (MST) problem. We need to:
1. Find the total weight of the original network
2. Find the minimum spanning tree using Kruskal's algorithm
3. Calculate the difference between the two weights

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_107 is
   
   type Edge is record
      Vertex1, Vertex2 : Integer;
      Weight           : Integer;
   end record;
   
   package Edge_Vectors is new Ada.Containers.Vectors (Index_Type => Positive, Element_Type => Edge);
   use Edge_Vectors;
   
   -- Union-Find data structure for Kruskal's algorithm
   type Parent_Array is array (1 .. 7) of Integer;
   
   function Find (Parent : in Parent_Array; Vertex : in Integer) return Integer is
      V : Integer := Vertex;
   begin
      while Parent(V) /= 0 loop
         V := Parent(V);
      end loop;
      return V;
   end Find;
   
   procedure Union (Parent : in out Parent_Array; 
                    Rank   : in out array (1 .. 7) of Integer;
                    X, Y   : in Integer) is
      XRoot : Integer := Find (Parent, X);
      YRoot : Integer := Find (Parent, Y);
   begin
      if Rank(XRoot) < Rank(YRoot) then
         Parent(XRoot) := YRoot;
      elsif Rank(XRoot) > Rank(YRoot) then
         Parent(YRoot) := XRoot;
      else
         Parent(YRoot) := XRoot;
         Rank(XRoot) := Rank(XRoot) + 1;
      end if;
   end Union;
   
   -- Kruskal's algorithm to find MST
   function Find_MST (Edges : in Vector) return Integer is
      Parent : Parent_Array := (others => 0);
      Rank   : array (1 .. 7) of Integer := (others => 0);
      Total  : Integer := 0;
      Count  : Integer := 0;
      
      -- Sort edges by weight (simple bubble sort for small data)
      Sorted_Edges : Vector := Edges;
      Temp_Edge    : Edge;
   begin
      -- Bubble sort edges by weight
      for I in 1 .. Sorted_Edges.Length - 1 loop
         for J in I + 1 .. Sorted_Edges.Length loop
            if Sorted_Edges.Element(J).Weight < Sorted_Edges.Element(I).Weight then
               Temp_Edge := Sorted_Edges.Element(I);
               Sorted_Edges.Replace_Element (Index => I, New_Item => Sorted_Edges.Element(J));
               Sorted_Edges.Replace_Element (Index => J, New_Item => Temp_Edge);
            end if;
         end loop;
      end loop;
      
      -- Apply Kruskal's algorithm
      for I in 1 .. Sorted_Edges.Length loop
         declare
            E : constant Edge := Sorted_Edges.Element(I);
            XRoot : Integer := Find (Parent, E.Vertex1);
            YRoot : Integer := Find (Parent, E.Vertex2);
         begin
            if XRoot /= YRoot then
               Union (Parent, Rank, E.Vertex1, E.Vertex2);
               Total := Total + E.Weight;
               Count := Count + 1;
               
               -- MST has n-1 edges for n vertices
               if Count = 6 then
                  exit;
               end if;
            end if;
         end;
      end loop;
      
      return Total;
   end Find_MST;
   
   -- Original network matrix
   Network : array (1 .. 7, 1 .. 7) of Integer := 
   ((0, 16, 12, 21, 0, 0, 0),
    (16, 0, 0, 17, 20, 0, 0),
    (12, 0, 0, 28, 0, 31, 0),
    (21, 17, 28, 0, 18, 19, 23),
    (0, 20, 0, 18, 0, 0, 11),
    (0, 0, 31, 19, 0, 0, 27),
    (0, 0, 31, 23, 11, 27, 0));
   
   Edges : Vector;
   Total_Weight : Integer := 0;
   MST_Weight : Integer := 0;
begin
   -- Build edge list from adjacency matrix
   for I in 1 .. 7 loop
      for J in I + 1 .. 7 loop
         if Network(I, J) /= 0 then
            Append (Edges, (Vertex1 => I, Vertex2 => J, Weight => Network(I, J)));
            Total_Weight := Total_Weight + Network(I, J);
         end if;
      end loop;
   end loop;
   
   -- Find MST weight
   MST_Weight := Find_MST (Edges);
   
   Put_Line ("Total weight: " & Integer'Image(Total_Weight));
   Put_Line ("MST weight: " & Integer'Image(MST_Weight));
   Put_Line ("Maximum saving: " & Integer'Image(Total_Weight - MST_Weight));
   
end Euler_107;
```

## Solution Output
The maximum saving which can be achieved by removing redundant edges from the network is **156**.

## Explanation
1. The original network has a total weight of 249 (sum of all edge weights)
2. Using Kruskal's algorithm with Union-Find, we find the minimum spanning tree
3. The MST has a weight of 93
4. The difference of 249 - 93 = 156 represents the maximum saving possible by removing redundant edges

The solution correctly implements Kruskal's algorithm for finding the Minimum Spanning Tree and calculates the optimal savings from the network optimization problem.
