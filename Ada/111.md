# Euler Problem 111 Solution in Ada

## Problem Statement
Finding numbers for which the sum of the digits is a divisor of the number.

## Analysis
This problem asks us to find all numbers where the sum of the digits divides the number evenly. For example, 123 has digit sum 1+2+3=6, and 123÷6=20.5, so 123 doesn't qualify. But 12 has digit sum 1+2=3, and 12÷3=4, so 12 qualifies.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_111 is
   
   function Digit_Sum(N : Integer) return Integer is
      Sum : Integer := 0;
      Temp : Integer := N;
   begin
      while Temp > 0 loop
         Sum := Sum + (Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Sum;
   end Digit_Sum;
   
   function Is_Divisible(N : Integer) return Boolean is
   begin
      if N = 0 then
         return False;
      else
         return (N mod Digit_Sum(N)) = 0;
      end if;
   end Is_Divisible;
   
   Sum : Integer := 0;
   Count : Integer := 0;
   
begin
   -- Check numbers from 1 to 10^6
   for I in 1..1_000_000 loop
      if Is_Divisible(I) then
         Sum := Sum + I;
         Count := Count + 1;
         Put_Line("Found: " & Integer'Image(I));
      end if;
   end loop;
   
   Put_Line("Total count: " & Integer'Image(Count));
   Put_Line("Sum of qualifying numbers: " & Integer'Image(Sum));
end Euler_111;
```
