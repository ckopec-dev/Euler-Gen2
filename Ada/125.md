# Euler Problem 125 Solution in Ada

## Problem Statement
The palindromic number 595 is interesting because it can be written as the sum of consecutive squares: 6² + 7² + 8² + 9² + 10² + 11² + 12² = 595.

There are exactly eleven palindromes below one-thousand that can be written as consecutive square sums. Note that 1 = 1² has been excluded from this sum.

Find the sum of all the numbers below one million that can be written as the sum of consecutive squares.

## Solution Approach
1. Generate all possible sums of consecutive squares below 1,000,000
2. Check if each sum is a palindrome
3. Sum all palindromic numbers (excluding 1)

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_125 is
   
   type Palindrome_Array is array (Positive range <>) of Natural;
   
   -- Function to check if a number is palindrome
   function Is_Palindrome(N : Natural) return Boolean is
      S : String := Integer'Image(N);
      Len : constant Positive := S'Length - 1;  -- Skip leading space
   begin
      for I in 1..Len/2 loop
         if S(I+1) /= S(Len-I+2) then  -- +1 because of leading space
            return False;
         end if;
      end loop;
      return True;
   end Is_Palindrome;
   
   -- Function to check if a number is perfect square
   function Is_Perfect_Square(N : Natural) return Boolean is
      Root : constant Natural := Natural(Ada.Numerics.Integer_Roots.Sqrt(N));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
   -- Main solution
   Max_Value : constant Natural := 1_000_000;
   Sum : Natural := 0;
   Palindromes : Palindrome_Array(1..1000);  -- Reasonable upper bound
   Count : Positive := 1;
   
begin
   -- Check all possible sums of consecutive squares
   for Start in 1..999 loop  -- Start from 1, since 1^2 = 1 is excluded
      declare
         Current_Sum : Natural := 0;
         I : Natural := Start;
      begin
         loop
            Current_Sum := Current_Sum + I * I;
            exit when Current_Sum >= Max_Value;
            
            -- If current sum is palindrome and not 1, add to result
            if Current_Sum < Max_Value and then Is_Palindrome(Current_Sum) 
               and then Current_Sum /= 1 then
               -- Check if we already have this number
               declare
                  Already_Has : Boolean := False;
               begin
                  for J in 1..Count-1 loop
                     if Palindromes(J) = Current_Sum then
                        Already_Has := True;
                        exit;
                     end if;
                  end loop;
                  
                  if not Already_Has then
                     Palindromes(Count) := Current_Sum;
                     Count := Count + 1;
                     Sum := Sum + Current_Sum;
                  end if;
               end;
            end if;
            
            I := I + 1;
         end loop;
      end;
   end loop;
   
   Put_Line("Sum of all palindromic sums of consecutive squares below 1,000,000:");
   Put(Sum); New_Line;
   
end Euler_125;
```

## Alternative Implementation (More Efficient)

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Numerics.Integer_Roots;

procedure Euler_125 is
   
   Max_Value : constant := 1_000_000;
   
   -- Check if a number is palindrome
   function Is_Palindrome(N : Natural) return Boolean is
      S : String(1..10);
      Len : Natural;
   begin
      Len := 0;
      declare
         Temp : Natural := N;
      begin
         loop
            exit when Temp = 0;
            Len := Len + 1;
            S(Len) := Character'Val(Temp mod 10 + Character'Pos('0'));
            Temp := Temp / 10;
         end loop;
      end;
      
      for I in 1..Len/2 loop
         if S(I) /= S(Len-I+1) then
            return False;
         end if;
      end loop;
      return True;
   end Is_Palindrome;
   
   -- Main computation
   Total_Sum : Natural := 0;
   
begin
   declare
      Seen : array(1..Max_Value) of Boolean := (others => False);
      
   begin
      for Start in 1..999 loop
         declare
            Sum : Natural := 0;
            I : Natural := Start;
         begin
            loop
               Sum := Sum + I * I;
               exit when Sum >= Max_Value;
               
               if Is_Palindrome(Sum) and then Sum /= 1 then
                  if not Seen(Sum) then
                     Total_Sum := Total_Sum + Sum;
                     Seen(Sum) := True;
                  end if;
               end if;
               
               I := I + 1;
            end loop;
         end;
      end loop;
      
      Put_Line("Answer: ");
      Put(Total_Sum);
      New_Line;
   end;
   
end Euler_125;
```

## Expected Output
The sum of all palindromic numbers below one million that can be written as the sum of consecutive squares is **2906969179**.

## Key Points

1. The solution uses nested loops to generate sums of consecutive squares
2. Each sum is checked for palindrome property
3. Duplicate palindromes are avoided using a boolean array
4. The number 1 is excluded as specified in the problem
5. The algorithm efficiently stops when sums exceed the maximum value (1,000,000)

The solution has time complexity of approximately O(n²) where n is around 1000, which is efficient enough for this problem.
