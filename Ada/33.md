# Euler Problem 33 Solution in Ada

Euler Problem 33 asks us to find the product of all "curious fractions" where a fraction ab/cd equals a/d when we cancel the common digit b and c.

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_33 is
   
   -- Function to calculate Greatest Common Divisor
   function GCD(A, B : Natural) return Natural is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Function to simplify a fraction
   procedure Simplify(Numerator, Denominator : in out Natural) is
      G : constant Natural := GCD(Numerator, Denominator);
   begin
      Numerator := Numerator / G;
      Denominator := Denominator / G;
   end Simplify;
   
   -- Check if a fraction is "curious"
   function Is_Curious(Numerator, Denominator : Natural) return Boolean is
      N1, N2, D1, D2 : Natural;
   begin
      -- Extract digits
      N1 := Numerator / 10;        -- First digit of numerator
      N2 := Numerator mod 10;      -- Second digit of numerator
      D1 := Denominator / 10;      -- First digit of denominator
      D2 := Denominator mod 10;    -- Second digit of denominator
      
      -- Check if we have a valid curious fraction
      -- Case 1: N2 = D1 and N1/D2 = Numerator/ Denominator
      if N2 = D1 and D2 /= 0 then
         return (N1 * Denominator) = (Numerator * D2);
      end if;
      
      -- Case 2: N1 = D2 and N2/D1 = Numerator/ Denominator
      if N1 = D2 and D1 /= 0 then
         return (N2 * Denominator) = (Numerator * D1);
      end if;
      
      return False;
   end Is_Curious;
   
   -- Main computation
   Result_Numerator : Natural := 1;
   Result_Denominator : Natural := 1;
   
begin
   -- Find all curious fractions where numerator < denominator
   for Numerator in 10..99 loop
      for Denominator in (Numerator + 1)..99 loop
         if Is_Curious(Numerator, Denominator) then
            Result_Numerator := Result_Numerator * Numerator;
            Result_Denominator := Result_Denominator * Denominator;
         end if;
      end loop;
   end loop;
   
   -- Simplify the final result
   Simplify(Result_Numerator, Result_Denominator);
   
   Put_Line("The denominator of the product of all curious fractions:");
   Put(Result_Denominator);
   New_Line;
   
end Euler_33;
```

## Explanation

The solution works as follows:

1. **GCD Function**: Implements Euclidean algorithm to find greatest common divisor
2. **Simplify Procedure**: Reduces a fraction to its simplest form using GCD
3. **Is_Curious Function**: Checks if a fraction is "curious" by:
   - Extracting individual digits of numerator and denominator
   - Testing two cases where digit cancellation might work:
     - When the second digit of numerator equals first digit of denominator
     - When the first digit of numerator equals second digit of denominator
4. **Main Logic**: 
   - Iterates through all possible 2-digit fractions (numerator < denominator)
   - Identifies curious fractions and multiplies them together
   - Simplifies the final result

## Key Insights

The curious fractions are those where:
- 49/98 = 4/8 (cancelling 9s)
- 39/93 = 3/3 (cancelling 9s) 
- etc.

After finding all such fractions and multiplying them together, we get a final fraction that simplifies to 1/100. Therefore, the denominator is **100**.
