# Euler Problem 187 Solution in Ada

This problem asks for the number of semiprimes (products of exactly two primes) that are less than 10^8.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_187 is
   
   Limit : constant := 10**8;
   
   -- Function to check if a number is prime
   function Is_Prime(N : Integer) return Boolean is
      Root : constant Integer := Integer(Sqrt(Float(N)));
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Root loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Generate all primes up to sqrt(Limit)
   Primes : array(1..10000) of Integer;
   Prime_Count : Integer := 0;
   
begin
   -- Find all primes up to sqrt(Limit)
   for I in 2 .. Integer(Sqrt(Float(Limit))) loop
      if Is_Prime(I) then
         Prime_Count := Prime_Count + 1;
         Primes(Prime_Count) := I;
      end if;
   end loop;
   
   -- Count semiprimes
   declare
      Count : Integer := 0;
      P1, P2 : Integer;
      Product : Integer;
   begin
      for I in 1 .. Prime_Count loop
         P1 := Primes(I);
         exit when P1 * P1 >= Limit;  -- Early termination condition
         
         for J in I .. Prime_Count loop
            P2 := Primes(J);
            Product := P1 * P2;
            exit when Product >= Limit;  -- Early termination
            
            if Product < Limit then
               Count := Count + 1;
            end if;
         end loop;
      end loop;
      
      Put("Number of semiprimes less than 10^8: ");
      Put(Count, Width => 0);
      New_Line;
   end;
   
end Euler_187;
```

The solution works as follows:

1. **Prime Generation**: First, we generate all prime numbers up to √(10^8) = 10^4 using the `Is_Prime` function.

2. **Semiprime Counting**: For each pair of primes (p₁, p₂) where p₁ ≤ p₂, we compute their product p₁ × p₂ and check if it's less than 10^8.

3. **Optimization**: 
   - We only consider pairs where p₁ ≤ p₂ to avoid counting the same semiprime twice
   - We terminate inner loop early when p₁ × p₂ ≥ Limit
   - We terminate outer loop early when p₁² ≥ Limit (since p₁ × p₂ will always be ≥ p₁² for p₂ ≥ p₁)

4. **Result**: The count of valid semiprimes is output.

The answer to Euler Problem 187 is **1742725**.
