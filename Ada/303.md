# Euler Problem 303 Solution in Ada

## Problem Statement
Find the sum of all positive integers n ≤ 10000 such that n divides 2^n - 1.

## Analysis
This is a mathematical problem where we need to find numbers n where n divides (2^n - 1). This means (2^n - 1) ≡ 0 (mod n), or equivalently, 2^n ≡ 1 (mod n).

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_303 is
   
   type Large_Integer is range 0..(2**63 - 1);
   
   function Mod_Power(Base, Exp, Mod : Large_Integer) return Large_Integer is
      Result : Large_Integer := 1;
      B      : Large_Integer := Base mod Mod;
      E      : Large_Integer := Exp;
   begin
      while E > 0 loop
         if E mod 2 = 1 then
            Result := (Result * B) mod Mod;
         end if;
         B := (B * B) mod Mod;
         E := E / 2;
      end loop;
      return Result;
   end Mod_Power;
   
   function Is_Divisor(N : Large_Integer) return Boolean is
      -- Check if N divides (2^N - 1)
      -- This means 2^N ≡ 1 (mod N)
   begin
      if N = 1 then
         return True;  -- 1 divides everything
      end if;
      
      -- For large numbers, we can use modular exponentiation
      -- 2^N mod N should equal 1
      return Mod_Power(2, N, N) = 1;
   end Is_Divisor;
   
   Sum : Large_Integer := 0;
   Count : Integer := 0;
   
begin
   Put_Line("Finding numbers n <= 10000 where n divides 2^n - 1");
   
   for N in 1..10000 loop
      if Is_Divisor(N) then
         Sum := Sum + N;
         Count := Count + 1;
         Put("Found: "); Put(N, Width => 5); Put_Line(" (Sum so far: " & Large_Integer'Image(Sum) & ")");
      end if;
   end loop;
   
   Put_Line("Total count: " & Integer'Image(Count));
   Put_Line("Final sum: " & Large_Integer'Image(Sum));
   
end Euler_303;
```
