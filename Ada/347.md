# Euler Problem 347 Solution in Ada

This problem asks for the sum of all distinct numbers that are the product of exactly two distinct primes, where both primes are less than or equal to a given limit.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_347 is
   
   Limit : constant := 10000;
   
   -- Function to check if a number is prime
   function Is_Prime(N : Integer) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer'Sqrt(N) loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Generate list of primes up to limit
   function Get_Primes(L : Integer) return Integer_Array is
      Primes : array(1 .. L) of Integer;
      Count  : Integer := 0;
   begin
      for I in 2 .. L loop
         if Is_Prime(I) then
            Count := Count + 1;
            Primes(Count) := I;
         end if;
      end loop;
      return Primes(1 .. Count);
   end Get_Primes;
   
   -- Main solution
   type Number_Set is array(1 .. Limit) of Boolean;
   
   procedure Solve is
      Prime_List : constant Integer_Array := Get_Primes(Limit);
      Numbers    : Number_Set := (others => False);
      Result     : Integer := 0;
      P1, P2     : Integer;
      Product    : Integer;
   begin
      -- For each pair of distinct primes
      for I in Prime_List'First .. Prime_List'Last - 1 loop
         P1 := Prime_List(I);
         exit when P1 * P1 > Limit;  -- Early termination
         
         for J in I + 1 .. Prime_List'Last loop
            P2 := Prime_List(J);
            Product := P1 * P2;
            
            -- Check if product is within range and not already counted
            if Product <= Limit and then not Numbers(Product) then
               Numbers(Product) := True;
               Result := Result + Product;
            end if;
            
            exit when P1 * P2 > Limit;  -- Early termination
         end loop;
      end loop;
      
      Put_Line("Sum of distinct numbers that are products of exactly two distinct primes:");
      Put(Result, Width => 0);
      New_Line;
   end Solve;
   
begin
   Solve;
end Euler_347;
```

This solution works by:

1. **Generating primes**: First, we generate all prime numbers up to the limit using a simple primality test.

2. **Finding valid products**: We iterate through pairs of distinct primes (P1, P2) where P1 < P2.

3. **Checking conditions**: For each pair, we compute their product and check if:
   - The product is ≤ Limit
   - The product hasn't been counted before

4. **Avoiding duplicates**: We use a boolean array to track which numbers have already been counted, ensuring each number is only added once.

5. **Optimization**: Early termination conditions prevent unnecessary computation:
   - When P1 * P1 > Limit, no further products with this prime will be valid
   - When P1 * P2 > Limit, no further products with this second prime will be valid

The algorithm efficiently finds all numbers that are exactly the product of two distinct primes ≤ 10000 and sums them up.
