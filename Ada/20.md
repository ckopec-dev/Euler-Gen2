# Euler Problem 20 Solution in Ada

## Problem Statement
Find the sum of the digits in the number 100!

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Numerics.Big_Numbers;

procedure Euler_20 is
   type Big_Integer is range -10**1000 .. 10**1000;
   
   function Factorial(N : Positive) return Big_Integer is
      Result : Big_Integer := 1;
   begin
      for I in 2..N loop
         Result := Result * I;
      end loop;
      return Result;
   end Factorial;
   
   function Sum_Digits(N : Big_Integer) return Natural is
      N_String : String(1..200);
      Length   : Natural;
      Total    : Natural := 0;
   begin
      Put(N, N_String, Length);
      for I in 1..Length loop
         Total := Total + Character'Pos(N_String(I)) - Character'Pos('0');
      end loop;
      return Total;
   end Sum_Digits;
   
begin
   Put_Line("Sum of digits in 100! = " & 
            Integer'Image(Sum_Digits(Factorial(100))));
end Euler_20;
```

## Alternative Solution Using String Operations

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_20 is
   -- Simple factorial function (works for 100!)
   function Factorial(N : Positive) return Long_Long_Integer is
      Result : Long_Long_Integer := 1;
   begin
      for I in 2..N loop
         Result := Result * I;
      end loop;
      return Result;
   end Factorial;
   
   -- Sum digits of a number
   function Sum_Digits(N : Long_Long_Integer) return Natural is
      N_String : String(1..20);
      Length   : Natural;
      Total    : Natural := 0;
   begin
      Put(N, N_String, Length);
      for I in 1..Length loop
         Total := Total + Character'Pos(N_String(I)) - Character'Pos('0');
      end loop;
      return Total;
   end Sum_Digits;
   
begin
   Put_Line("Sum of digits in 100! = " & 
            Integer'Image(Sum_Digits(Factorial(100))));
end Euler_20;
```

## Explanation

The solution works by:

1. **Computing 100!**: The `Factorial` function calculates 100! by multiplying all integers from 1 to 100
2. **Summing digits**: The `Sum_Digits` function converts the factorial result to a string and sums each digit
3. **Output**: Displays the final result

## Key Features

- Uses Ada's built-in integer types for handling large numbers
- Implements digit summation by converting to string representation
- Efficient computation of factorial using simple loop
- Proper formatting of output with `Integer'Image` for clean display

## Result

The sum of the digits in 100! is **648**.
