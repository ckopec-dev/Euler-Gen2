# Euler Problem 50 Solution in Ada

## Problem Statement
The prime 41, can be written as the sum of six consecutive primes:
41 = 2 + 3 + 5 + 7 + 11 + 13

This is the longest sum of consecutive primes that adds to a prime below one-hundred.

The longest sum of consecutive primes below one-thousand that adds to a prime, contains 21 terms, and is equal to 953.

Which prime, below one-million, can be written as the sum of the most consecutive primes?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_50 is
   
   Max_Value : constant := 1_000_000;
   
   -- Array to mark prime numbers (sieve of Eratosthenes)
   Is_Prime : array (0 .. Max_Value) of Boolean := (others => True);
   
   -- List of primes
   Primes : array (1 .. Max_Value) of Integer;
   Prime_Count : Integer := 0;
   
   -- Function to check if a number is prime
   function Is_Prime_Num(N : Integer) return Boolean is
   begin
      return Is_Prime(N);
   end Is_Prime_Num;
   
   -- Generate all primes up to Max_Value using sieve of Eratosthenes
   procedure Sieve_Of_Eratosthenes is
   begin
      Is_Prime(0) := False;
      Is_Prime(1) := False;
      
      for I in 2 .. Integer'Sqrt(Max_Value) loop
         if Is_Prime(I) then
            for J in I * I .. Max_Value loop
               if J mod I = 0 then
                  Is_Prime(J) := False;
               end if;
            end loop;
         end if;
      end loop;
      
      -- Collect all primes
      Prime_Count := 0;
      for I in 2 .. Max_Value loop
         if Is_Prime(I) then
            Prime_Count := Prime_Count + 1;
            Primes(Prime_Count) := I;
         end if;
      end loop;
   end Sieve_Of_Eratosthenes;
   
   -- Main solution
   procedure Solve is
      Max_Consecutive : Integer := 0;
      Result_Prime : Integer := 0;
      Sum : Integer;
      Current_Length : Integer;
   begin
      Sieve_Of_Eratosthenes;
      
      -- Try all possible starting positions
      for Start in 1 .. Prime_Count loop
         Sum := 0;
         Current_Length := 0;
         
         -- Add consecutive primes starting from 'Start'
         for I in Start .. Prime_Count loop
            Sum := Sum + Primes(I);
            Current_Length := Current_Length + 1;
            
            -- If sum exceeds our limit, break
            exit when Sum > Max_Value;
            
            -- If sum is prime and longer than previous best
            if Is_Prime_Num(Sum) and Current_Length > Max_Consecutive then
               Max_Consecutive := Current_Length;
               Result_Prime := Sum;
            end if;
         end loop;
         
         -- Early termination: if current length is less than or equal to 
         -- our best, no point continuing with smaller starting positions
         exit when Current_Length <= Max_Consecutive;
      end loop;
      
      Put_Line("The prime below one-million that can be written as the sum of the most consecutive primes is:");
      Put(Result_Prime);
      Put_Line(" which is the sum of " & Integer'Image(Max_Consecutive) & " consecutive primes.");
   end Solve;
   
begin
   Solve;
end Euler_50;
```

## Explanation

This solution works by:

1. **Generating primes**: Using the Sieve of Eratosthenes to find all prime numbers below one million
2. **Checking consecutive sums**: For each possible starting prime, we sum consecutive primes until we exceed one million
3. **Optimization**: We stop early when the current sequence length is no longer better than our best solution
4. **Validation**: We check if each sum is prime and track the longest valid sequence

## Key Features

- Uses the classic Sieve of Eratosthenes algorithm for efficient prime generation
- Implements early termination to improve performance
- Maintains a running count of consecutive primes to avoid redundant calculations
- Uses efficient array-based storage for primes and prime checking

## Output
The program will output: `997651` which is the prime below one million that can be written as the sum of 543 consecutive primes.

This solution is efficient with O(n log log n) complexity for prime generation and O(n²) for finding the maximum consecutive sum, making it suitable for the given constraints.
