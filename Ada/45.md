# Euler Problem 45 Solution in Ada

Euler Problem 45 asks us to find the next triangle number that is also pentagonal and hexagonal after 40755.

Let me break down the approach:
- Triangle numbers: T(n) = n(n+1)/2
- Pentagonal numbers: P(n) = n(3n-1)/2  
- Hexagonal numbers: H(n) = n(2n-1)

We need to find numbers that are simultaneously triangular, pentagonal, and hexagonal.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_45 is
   type Large_Integer is range 0 .. 2**63 - 1;
   
   -- Function to check if a number is triangular
   function Is_Triangular(N : Large_Integer) return Boolean is
      Root : Large_Integer := Large_Integer(Integer'Sqrt(Float(N * 2)));
   begin
      return Root * (Root + 1) / 2 = N;
   end Is_Triangular;
   
   -- Function to check if a number is pentagonal
   function Is_Pentagonal(N : Large_Integer) return Boolean is
      Root : Large_Integer := Large_Integer(Integer'Sqrt(Float(N * 2 / 3)));
   begin
      -- We need to be more precise for pentagonal numbers
      declare
         Temp : Large_Integer := Root * (3 * Root - 1) / 2;
      begin
         return Temp = N;
      end;
   end Is_Pentagonal;
   
   -- Generate hexagonal numbers and check if they're also triangular and pentagonal
   function Next_Tri_Pent_Hex return Large_Integer is
      H : Large_Integer := 144;  -- Start from where we know the answer
      Hex_Number : Large_Integer;
   begin
      loop
         Hex_Number := H * (2 * H - 1);
         
         -- Check if this hexagonal number is also triangular and pentagonal
         if Is_Triangular(Hex_Number) and then Is_Pentagonal(Hex_Number) then
            return Hex_Number;
         end if;
         
         H := H + 1;
      end loop;
   end Next_Tri_Pent_H;
   
   Result : Large_Integer;
begin
   Result := Next_Tri_Pent_H;
   Put("The answer is: ");
   Put(Result);
   New_Line;
end Euler_45;

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_45 is
   type Large_Integer is range 0 .. 2**63 - 1;
   
   -- Check if a number N is triangular: T(k) = k(k+1)/2 = N
   function Is_Triangular(N : Large_Integer) return Boolean is
      K : Large_Integer;
      Temp : Large_Integer;
   begin
      -- Using quadratic formula: k = (-1 + sqrt(1 + 8N))/2
      declare
         Root : Float := Float'Sqrt(Float(1 + 8 * N));
         K_F : Float := (Root - 1.0) / 2.0;
         K_Int : Large_Integer := Large_Integer(K_F);
      begin
         if K_F = Float(K_Int) then
            K := K_Int;
            Temp := K * (K + 1) / 2;
            return Temp = N;
         else
            return False;
         end if;
      end;
   end Is_Triangular;
   
   -- Check if a number N is pentagonal: P(k) = k(3k-1)/2 = N
   function Is_Pentagonal(N : Large_Integer) return Boolean is
      K : Large_Integer;
      Temp : Large_Integer;
   begin
      -- Using quadratic formula: k = (1 + sqrt(1 + 24N))/6
      declare
         Root : Float := Float'Sqrt(Float(1 + 24 * N));
         K_F : Float := (Root + 1.0) / 6.0;
         K_Int : Large_Integer := Large_Integer(K_F);
      begin
         if K_F = Float(K_Int) then
            K := K_Int;
            Temp := K * (3 * K - 1) / 2;
            return Temp = N;
         else
            return False;
         end if;
      end;
   end Is_Pentagonal;
   
   H : Large_Integer := 144;  -- Start after the given answer of 40755
   Hex_Number : Large_Integer;
   
begin
   loop
      Hex_Number := H * (2 * H - 1);
      
      if Is_Triangular(Hex_Number) and then Is_Pentagonal(Hex_Number) then
         Put("The next triangle number that is also pentagonal and hexagonal is: ");
         Put(Hex_Number);
         New_Line;
         exit;
      end if;
      
      H := H + 1;
   end loop;
end Euler_45;
```

This solution works by:
1. Generating hexagonal numbers starting from H=144 (since we know 40755 is the answer and it's the 143rd hexagonal number)
2. For each hexagonal number, checking if it's also triangular and pentagonal
3. The key insight is that all hexagonal numbers that are also triangular and pentagonal will be found this way
