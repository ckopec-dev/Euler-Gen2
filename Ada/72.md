# Euler Problem 72 Solution in Ada

This problem asks for the number of fractions n/d that are in reduced form (gcd(n,d) = 1) where n < d and d ≤ 1,000,000.

The solution uses the totient function approach. For each denominator d, we want to count how many numerators n < d are coprime to d. This is exactly φ(d), the Euler's totient function of d.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_72 is
   Max_D : constant := 1_000_000;
   
   -- Function to compute greatest common divisor
   function GCD(A, B : Integer) return Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Function to compute Euler's totient function φ(n)
   function Totient(N : Integer) return Integer is
      Count : Integer := 0;
   begin
      for I in 1 .. N - 1 loop
         if GCD(I, N) = 1 then
            Count := Count + 1;
         end if;
      end loop;
      return Count;
   end Totient;
   
   -- More efficient approach using Euler's totient function formula
   -- φ(n) = n * ∏(1 - 1/p) for all prime factors p of n
   function Fast_Totient(N : Integer) return Integer is
      Result : Integer := N;
      I      : Integer := 2;
   begin
      while I * I <= N loop
         if N mod I = 0 then
            Result := Result - Result / I;
            while N mod I = 0 loop
               N := N / I;
            end loop;
         end if;
         I := I + 1;
      end loop;
      
      if N > 1 then
         Result := Result - Result / N;
      end if;
      
      return Result;
   end Fast_Totient;
   
   Total_Count : Integer := 0;
begin
   -- Sum up all totient values from 2 to Max_D
   for D in 2 .. Max_D loop
      Total_Count := Total_Count + Fast_Totient(D);
   end loop;
   
   Put_Line("Answer: " & Integer'Image(Total_Count));
end Euler_72;

with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_72 is
   Max_D : constant := 1_000_000;
   
   -- Array to store totient values
   Totient : array(1 .. Max_D) of Integer;
   
   Total_Count : Integer := 0;
begin
   -- Initialize totient values (φ(n) = n for all n initially)
   for I in 1 .. Max_D loop
      Totient(I) := I;
   end loop;
   
   -- Sieve method to compute totient function
   for I in 2 .. Max_D loop
      if Totient(I) = I then  -- I is prime
         -- For each multiple of this prime, update its totient
         for J in I .. Max_D by I loop
            Totient(J) := Totient(J) / I * (I - 1);
         end loop;
      end if;
   end loop;
   
   -- Sum all totient values from 2 to Max_D
   for I in 2 .. Max_D loop
      Total_Count := Total_Count + Totient(I);
   end loop;
   
   Put_Line("Answer: " & Integer'Image(Total_Count));
end Euler_72;
```

This solution works by:

1. **Initialization**: Create an array where each element initially equals its index (φ(n) = n)
2. **Sieve approach**: For each prime number p, update all multiples of p using the formula: φ(n) = φ(n) × (p-1)/p
3. **Summation**: Add up all totient values from 2 to Max_D

The key insight is that the number of reduced fractions n/d with d ≤ N is exactly the sum of φ(d) for d from 2 to N, which equals the count of all pairs (n,d) where gcd(n,d) = 1 and n < d.
