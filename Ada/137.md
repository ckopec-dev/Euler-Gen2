The solution works as follows:

1. We initialize the first two Fibonacci numbers (both equal to 1)
2. We iterate through the Fibonacci sequence, computing each new number as the sum of the previous two
3. For each new Fibonacci number, we count how many digits it has using the `Count_Digits` function
4. When we find a Fibonacci number with exactly 1000 digits, we return its position
