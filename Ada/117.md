# Euler Problem 117 Solution in Ada

This problem asks us to find the number of ways to fill a row of 50 units with blocks of length 2, 3, or 4 units, where blocks can be of any color and adjacent blocks cannot be the same color.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_117 is
   
   -- Define the total length of the row
   Length : constant Integer := 50;
   
   -- Function to calculate number of ways to fill a row of given length
   function Count_Ways(N : Integer) return Long_Long_Integer is
      -- dp[i] represents number of ways to fill a row of length i
      type DP_Array is array (0 .. Length) of Long_Long_Integer;
      DP : DP_Array := (others => 0);
      
      -- Base cases
      -- Empty row has 1 way (do nothing)
      DP(0) := 1;
      
      -- For each position in the row
      for I in 1 .. N loop
         -- We can place a block of length 2, 3, or 4 at position I
         -- If we place a block of length 2, we have DP[I-2] ways for remaining
         if I >= 2 then
            DP(I) := DP(I) + DP(I-2);
         end if;
         
         -- For block of length 3
         if I >= 3 then
            DP(I) := DP(I) + DP(I-3);
         end if;
         
         -- For block of length 4
         if I >= 4 then
            DP(I) := DP(I) + DP(I-4);
         end if;
      end loop;
      
      return DP(N);
   end Count_Ways;

begin
   -- Calculate the result for a row of length 50
   Put_Line("Number of ways to fill a row of 50 units: " & 
            Long_Long_Integer'Image(Count_Ways(Length)));
```

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_117 is
   
   Length : constant Integer := 50;
   
   -- Function to compute the number of ways
   function Compute_Ways(N : Integer) return Long_Long_Integer is
      type DP_Array is array (0 .. Length) of Long_Long_Integer;
      DP : DP_Array := (others => 0);
      
      -- Base cases
      DP(0) := 1;  -- One way to fill empty space
      
      -- For each position from 1 to N
      for I in 1 .. N loop
         -- Place block of length 2 (if possible)
         if I >= 2 then
            DP(I) := DP(I) + DP(I-2);
         end if;
         
         -- Place block of length 3 (if possible)
         if I >= 3 then
            DP(I) := DP(I) + DP(I-3);
         end if;
         
         -- Place block of length 4 (if possible)
         if I >= 4 then
            DP(I) := DP(I) + DP(I-4);
         end if;
      end loop;
      
      return DP(N);
   end Compute_Ways;

begin
   Put_Line("Answer: " & Long_Long_Integer'Image(Compute_Ways(Length)));
end Euler_117;
```

This is the solution to Project Euler Problem 117. The approach uses dynamic programming where:

1. We define `DP[i]` as the number of ways to fill a row of length `i`
2. For each position `i`, we consider placing blocks of lengths 2, 3, or 4
3. If we place a block of length `k` at position `i`, we have `DP[i-k]` ways to fill the remaining space
4. We sum all possibilities for each position
