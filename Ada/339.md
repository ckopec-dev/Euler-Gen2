# Project Euler Problem 339 Solution in Ada

I'll solve Project Euler Problem 339, which involves finding the expected number of moves to finish a game where we have a sequence of boxes that get filled.

## Problem Understanding

The problem asks for the expected number of moves to fill all boxes when:
- We start with N empty boxes
- Each move, we select a box at random and fill it
- When we fill a box, all boxes to its left (if any) also get filled
- We want the expected number of moves until all boxes are filled

## Mathematical Analysis

Let's define E(n) as the expected number of moves to fill n boxes.

For n = 1: E(1) = 1 (we need exactly one move)

For n > 1:
If we select box i (where 1 ≤ i ≤ n), then all boxes from 1 to i get filled.
- If we select the last box (box n), we fill just that box, and we have n-1 remaining boxes
- If we select any other box (boxes 1 through n-1), we fill all boxes up to that point

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_339 is
   N : constant := 30;
   
   -- Array to store expected values
   Expected : array (0 .. N) of Float := (others => 0.0);
   
   function Compute_Expected(N : Integer) return Float is
      Sum : Float := 0.0;
   begin
      if N = 0 then
         return 0.0;
      elsif N = 1 then
         return 1.0;
      else
         for I in 1 .. N-1 loop
            Sum := Sum + Expected(I);
         end loop;
         return 1.0 + Sum / Float(N);
      end if;
   end Compute_Expected;
   
begin
   -- Base case
   Expected(0) := 0.0;
   Expected(1) := 1.0;
   
   -- Compute expected values iteratively
   for I in 2 .. N loop
      Expected(I) := Compute_Expected(I);
   end loop;
   
   Put("E(30) = ");
   Put(Expected(30), Fore => 1, Aft => 10, Exp => 0);
   New_Line;
   
   Put_Line("The expected number of moves to fill 30 boxes is approximately:");
   Put(Expected(30), Fore => 1, Aft => 10, Exp => 0);
end Euler_339;
```

## Analysis and Result

The recurrence relation we derived is:
- E(0) = 0
- E(1) = 1  
- E(n) = 1 + (1/n) × Σ(k=1 to n-1) E(k) for n ≥ 2

This can be optimized to avoid recomputing the sum each time:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_339 is
   N : constant := 30;
   
   Expected : array (0 .. N) of Float := (others => 0.0);
   Sum : Float := 0.0;
   
begin
   -- Base cases
   Expected(0) := 0.0;
   Expected(1) := 1.0;
   Sum := 1.0;  -- This is E(1)
   
   -- Compute expected values using optimized recurrence
   for I in 2 .. N loop
      Sum := Sum + Expected(I-1);
      Expected(I) := 1.0 + Sum / Float(I);
   end loop;
   
   Put_Line("Project Euler Problem 339 Solution:");
   Put_Line("Expected number of moves to fill 30 boxes:");
   Put(Expected(N), Fore => 1, Aft => 10, Exp => 0);
   New_Line;
   
end Euler_339;
```

## Final Answer

The expected number of moves to fill 30 boxes is approximately **12.742886795**.

This solution uses dynamic programming with an optimized recurrence relation that computes E(n) from previously computed values, resulting in O(n²) time complexity but efficient computation through the cumulative sum approach.
