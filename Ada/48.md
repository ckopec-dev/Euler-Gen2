# Euler Problem 48 Solution in Ada

Euler Problem 48 asks us to find the last ten digits of the series 1¹ + 2² + 3³ + ... + 1000¹⁰⁰⁰.

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_48 is
   type Large_Integer is mod 10**10;  -- Only keep last 10 digits
   
   Total : Large_Integer := 0;
   
begin
   for I in 1..1000 loop
      declare
         Power : Large_Integer := 1;
         Base  : Large_Integer := Large_Integer(I);
      begin
         -- Calculate I^I (mod 10^10)
         for J in 1..I loop
            Power := (Power * Base) mod 10**10;
         end loop;
         
         Total := (Total + Power) mod 10**10;
      end;
   end loop;
   
   Put_Line("Last 10 digits: " & Integer'Image(Integer(Total)));
end Euler_48;
```

Actually, let me provide a cleaner and more correct version:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_48 is
   -- We only need the last 10 digits, so we work mod 10^10
   type Big_Num is mod 10**10;
   
   Result : Big_Num := 0;
   
begin
   for N in 1..1000 loop
      declare
         Base : Big_Num := Big_Num(N);
         Current_Power : Big_Num := 1;
      begin
         -- Calculate N^N mod 10^10
         for I in 1..N loop
            Current_Power := (Current_Power * Base) mod 10**10;
         end loop;
         
         Result := Result + Current_Power;
      end;
   end loop;
   
   Put_Line("Last 10 digits: " & Big_Num'Image(Result));
end Euler_48;
```

The solution works by:
1. Using modular arithmetic throughout to keep only the last 10 digits
2. For each number N from 1 to 1000, calculating N^N
3. Adding each result to a running total
4. Using `mod 10**10` at each step to prevent overflow and maintain only relevant digits

The answer is **9110846700**.
