# Euler Problem 98 Solution in Ada

## Problem Statement
By replacing each of the letters in the word CARE with 1, 2, 9, and 6 respectively, we form a square number: 1296 = 36². We shall call this a square anagram word pair and consider CARE and RACE as an example.

Given a list of words, find the largest square number formed by any member of such a square anagram word pair.

## Solution Approach
1. Read the word list from the file
2. Group words by their anagram signatures (sorted letters)
3. For each group with at least 2 words, check all possible letter substitutions
4. Verify that the substitution produces valid square numbers
5. Track the maximum square number found

## Ada Implementation

```ada
with Ada.Text_IO;           use Ada.Text_IO;
with Ada.Integer_Text_IO;   use Ada.Integer_Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;
with Ada.Containers.Vectors;
with Ada.Directories;
with Ada.Calendar;

procedure Euler_98 is
   
   type Word_Vector is array (Positive range <>) of Unbounded_String;
   package Word_Vectors is new Ada.Containers.Vectors (Positive, Unbounded_String);
   
   type Square_Info is record
      Value : Positive;
      Root  : Positive;
   end record;
   
   type Square_Vector is array (Positive range <>) of Square_Info;
   package Square_Vectors is new Ada.Containers.Vectors (Positive, Square_Info);
   
   -- Generate all perfect squares up to a reasonable limit
   procedure Generate_Squares (Squares : in out Square_Vector.Vector) is
      I : Positive := 1;
      S : Positive;
   begin
      loop
         S := I * I;
         exit when S > 10**9;  -- Reasonable upper bound for 9-digit numbers
         Squares.Append ((Value => S, Root => I));
         I := I + 1;
      end loop;
   end Generate_Squares;
   
   -- Get anagram signature (sorted letters)
   function Anagram_Signature (Word : Unbounded_String) return Unbounded_String is
      Chars : array (1..Length(Word)) of Character;
      Result : Unbounded_String;
   begin
      for I in 1..Length(Word) loop
         Chars(I) := Element(Word, I);
      end loop;
      
      -- Sort characters
      for I in 1..Length(Word)-1 loop
         for J in I+1..Length(Word) loop
            if Chars(I) > Chars(J) then
               declare
                  Temp : Character := Chars(I);
               begin
                  Chars(I) := Chars(J);
                  Chars(J) := Temp;
               end;
            end if;
         end loop;
      end loop;
      
      Result := Null_Unbounded_String;
      for I in 1..Length(Word) loop
         Result := Result & Chars(I);
      end loop;
      
      return Result;
   end Anagram_Signature;
   
   -- Check if two words are anagrams
   function Are_Anagrams (Word1, Word2 : Unbounded_String) return Boolean is
   begin
      return Anagram_Signature(Word1) = Anagram_Signature(Word2);
   end Are_Anagrams;
   
   -- Convert word to number using letter mapping
   function Word_To_Number (Word : Unbounded_String; Mapping : array (Character) of Integer)
                            return Positive is
      Result : Positive := 0;
   begin
      for I in 1..Length(Word) loop
         declare
            C : Character := Element(Word, I);
         begin
            if C not in 'A'..'Z' then
               raise Constraint_Error;
            end if;
            
            Result := Result * 10 + Mapping(C);
         end;
      end loop;
      
      return Result;
   end Word_To_Number;
   
   -- Check if a number is a perfect square
   function Is_Perfect_Square (N : Positive) return Boolean is
      Root : constant Positive := Integer(Sqrt(Float(N)));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
   -- Find maximum square from anagram group
   procedure Process_Anagram_Group (Words : Word_Vector; Squares : Square_Vector.Vector) is
      Max_Square : Positive := 0;
      Group_Size : constant Natural := Words'Length;
      
      -- Generate all possible letter mappings for the first word
      procedure Try_Mapping (Word1, Word2 : Unbounded_String) is
         Mapping : array (Character) of Integer := (others => -1);
         Used    : array (0..9) of Boolean := (others => False);
         Result1, Result2 : Positive;
         
         -- Recursive function to try assignments
         procedure Assign_Letters (Pos : Natural) is
            C : Character := Element(Word1, Pos + 1);
         begin
            if Pos = Length(Word1) then
               -- Check if both words form valid squares
               begin
                  Result1 := Word_To_Number(Word1, Mapping);
                  Result2 := Word_To_Number(Word2, Mapping);
                  
                  if Is_Perfect_Square(Result1) and Is_Perfect_Square(Result2) then
                     Max_Square := Positive'Max(Max_Square, Result1);
                     Max_Square := Positive'Max(Max_Square, Result2);
                  end if;
               exception
                  when others => null;  -- Invalid mapping (like leading zeros)
               end;
               return;
            end if;
            
            -- Try assigning each digit to this letter
            for D in 0..9 loop
               if not Used(D) then
                  if (D = 0 and C = Element(Word1, 1)) or 
                     (Pos > 0 and Mapping(Element(Word1, Pos)) /= -1) then
                     -- Skip invalid assignments
                     null;
                  else
                     Mapping(C) := D;
                     Used(D) := True;
                     Assign_Letters(Pos + 1);
                     Mapping(C) := -1;
                     Used(D) := False;
                  end if;
               end if;
            end loop;
         end Assign_Letters;
      begin
         Assign_Letters(0);
      end Try_Mapping;
      
   begin
      -- Only process groups with at least 2 words
      if Group_Size >= 2 then
         for I in 1..Group_Size-1 loop
            for J in I+1..Group_Size loop
               if Are_Anagrams(Words(I), Words(J)) then
                  Try_Mapping(Words(I), Words(J));
               end if;
            end loop;
         end loop;
      end if;
      
      if Max_Square > 0 then
         Put_Line("Maximum square found: " & Positive'Image(Max_Square));
      end if;
   end Process_Anagram_Group;
   
begin
   -- In a real implementation, we would read from file here
   -- This is a simplified version showing the concept
   
   Put_Line("Euler Problem 98 Solution");
   Put_Line("=========================");
   
   -- Generate squares up to reasonable limit
   declare
      Squares : Square_Vector.Vector;
   begin
      Generate_Squares(Squares);
      
      -- Example: Process some sample words
      -- In practice, we'd read from the actual file
      declare
         Words : Word_Vector(1..4) := 
            (To_Unbounded_String("CARE"),
             To_Unbounded_String("RACE"),
             To_Unbounded_String("EARN"),
             To_Unbounded_String("NEAR"));
      begin
         Process_Anagram_Group(Words, Squares);
      end;
   end;
   
end Euler_98;
```

## Key Features of the Solution

1. **Anagram Detection**: Uses sorted character sequences to identify anagram groups
2. **Letter-to-digit Mapping**: Generates all valid digit assignments for letter positions
3. **Square Validation**: Checks if numbers formed are perfect squares
4. **Constraint Handling**: Ensures no leading zeros in generated numbers
5. **Optimization**: Only processes groups with multiple words
