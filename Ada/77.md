# Euler Problem 77 Solution in Ada

## Problem Statement
It is possible to write ten as the sum of primes in exactly five different ways:
- 7 + 3
- 5 + 5
- 5 + 3 + 2
- 3 + 3 + 2 + 2
- 2 + 2 + 2 + 2 + 2

What is the first value which can be written as the sum of primes in over five thousand different ways?

## Solution Approach
This is a classic coin change problem where we need to find the number of ways to express a number as a sum of prime numbers. We'll use dynamic programming with memoization.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_77 is
   
   -- Generate primes up to a reasonable limit
   type Prime_Array is array (Positive range <>) of Natural;
   
   function Is_Prime(N : Natural) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer'Sqrt(N) loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   function Get_Primes(Limit : Natural) return Prime_Array is
      Count : Natural := 0;
      Primes : Prime_Array(1 .. Limit);
   begin
      for I in 2 .. Limit loop
         if Is_Prime(I) then
            Count := Count + 1;
            Primes(Count) := I;
         end if;
      end loop;
      
      -- Return only the primes found
      return Primes(1 .. Count);
   end Get_Primes;
   
   function Count_Ways(N : Natural; Primes : Prime_Array) return Natural is
      -- Memoization table for dynamic programming
      type Ways_Array is array (0 .. N) of Natural;
      Ways : Ways_Array := (others => 0);
      Result : Natural;
   begin
      Ways(0) := 1;  -- One way to make 0
      
      -- For each prime
      for I in Primes'First .. Primes'Last loop
         if Primes(I) > N then
            exit;
         end if;
         
         -- Update ways for all values from prime to N
         for J in Primes(I) .. N loop
            Ways(J) := Ways(J) + Ways(J - Primes(I));
         end loop;
      end loop;
      
      return Ways(N);
   end Count_Ways;
   
   -- Main solution
   Limit : constant Natural := 1000;
   Primes : Prime_Array := Get_Primes(Limit);
   Target : Natural := 2;
   Ways_Count : Natural;
begin
   loop
      Ways_Count := Count_Ways(Target, Primes);
      
      if Ways_Count > 5000 then
         Put_Line("First value with over 5000 ways: " & Target'Image);
         exit;
      end if;
      
      Target := Target + 1;
   end loop;
   
end Euler_77;
```

## Explanation

The solution works as follows:

1. **Prime Generation**: The `Get_Primes` function generates all prime numbers up to a reasonable limit using the `Is_Prime` helper function.

2. **Dynamic Programming Approach**: The `Count_Ways` function uses dynamic programming to count the number of ways to express a given number as a sum of primes:
   - Initialize a `Ways` array where `Ways(i)` represents the number of ways to make sum `i`
   - Set `Ways(0) = 1` (one way to make 0: use no primes)
   - For each prime, update all possible sums that can include this prime
   - The recurrence relation is: `Ways[j] := Ways[j] + Ways[j - prime]`

3. **Main Loop**: Starting from 2, we check each number until we find one that can be written as the sum of primes in over 5000 different ways.

## Key Features

- **Efficient Prime Generation**: Uses trial division with square root optimization
- **Dynamic Programming**: Efficiently counts combinations without generating them explicitly
- **Memoization**: Uses bottom-up DP approach to avoid recomputation
- **Clear Structure**: Well-commented code that separates concerns clearly

The algorithm has time complexity O(N × P) where N is the target number and P is the number of primes less than N. This solution efficiently finds that the answer is 71, which can be expressed as the sum of primes in over 5000 different ways.
