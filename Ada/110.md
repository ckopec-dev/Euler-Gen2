# Euler Problem 110 Solution in Ada

## Problem Statement
Find the least value of n for which the number of solutions to 1/x + 1/y = 1/n (where x, y are positive integers) exceeds four million.

## Analysis
The equation 1/x + 1/y = 1/n can be rewritten as:
- xy = n(x + y)
- xy - nx - ny = 0
- xy - nx - ny + n² = n²
- (x - n)(y - n) = n²

This means that for each divisor d of n², we get a solution where x = n + d and y = n + n²/d.

The number of solutions equals the number of divisors of n², which is (2a₁ + 1)(2a₂ + 1)...(2aₖ + 1) where n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ.

We want to find the smallest n such that the number of divisors of n² exceeds 4,000,000.
