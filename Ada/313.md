with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_313 is
   
   -- Function to calculate Catalan numbers
   function Catalan(n : Integer) return Long_Long_Integer is
      C : Long_Long_Integer := 1;
   begin
      for i in 1..n loop
         C := C * (4 * i - 2) / (i + 1);
      end loop;
      return C;
   end Catalan;
   
   -- Function to calculate binomial coefficient C(n,k)
   function Binomial(n, k : Integer) return Long_Long_Integer is
      result : Long_Long_Integer := 1;
   begin
      if k > n or k < 0 then
         return 0;
      end if;
      
      if k = 0 or k = n then
         return 1;
      end if;
      
      -- Take advantage of symmetry
      if k > n - k then
         k := n - k;
      end if;
      
      for i in 1..k loop
         result := result * (n - i + 1) / i;
      end loop;
      
      return result;
   end Binomial;
   
   -- Direct calculation using the Catalan formula
   function Catalan_Direct(n : Integer) return Long_Long_Integer is
      numerator : Long_Long_Integer := 1;
      denominator : Long_Long_Integer := 1;
      i : Integer;
   begin
      for i in 1..n loop
         numerator := numerator * (2 * i - 1) * (2 * i);
         denominator := denominator * (i + 1) * i;
      end loop;
      
      return numerator / denominator;
   end Catalan_Direct;
   
   -- Calculate the nth Catalan number using recurrence relation
   function Catalan_Recurrence(n : Integer) return Long_Long_Integer is
      C : array(0..n) of Long_Long_Integer := (others => 0);
   begin
      C(0) := 1;
      
      for i in 1..n loop
         for j in 0..i-1 loop
            C(i) := C(i) + C(j) * C(i-1-j);
         end loop;
      end loop;
      
      return C(n);
   end Catalan_Recurrence;

## Mathematical Analysis

The key mathematical concept here is the **Catalan number**. The nth Catalan number counts:

1. The number of valid sequences of n pairs of parentheses
2. The number of paths from (0,0) to (n,n) that never go above the diagonal
3. The number of ways to triangulate a convex polygon with n+2 vertices

For an n×n grid where we count paths from top-left to bottom-right that never go above the main diagonal, the answer is the nth Catalan number.

The formula for the nth Catalan number:
```
C(n) = (1/(n+1)) × C(2n,n) = (2n)! / ((n+1)! × n!)
```
