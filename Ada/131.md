## Problem Statement
Find the number of values of n for which n³ + n²p is a perfect cube, where p is prime and n, p are positive integers.

## Analysis
We need to find when n³ + n²p = k³ for some positive integer k.

Rearranging: n²(n + p) = k³

This can be rewritten as: n²(n + p) = k³

Let's factor this differently. If n³ + n²p = k³, then:
n²(n + p) = k³

This means n²(n + p) must be a perfect cube.
