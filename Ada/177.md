## Problem Analysis

We need to find how many ways we can completely tile a 3×n rectangle using 2×1 dominoes. This is a classic dynamic programming problem.

## Approach

I'll use dynamic programming where I define states based on the configuration of the last row:
- State 0: All cells in the last row are filled
- State 1: Bottom cell of last row is empty (top cell filled)
- State 2: Middle cell of last row is empty (top and bottom filled)  
- State 3: Top cell of last row is empty (bottom cell filled)
- State 4: All cells in the last row are empty
