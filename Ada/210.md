# Euler Problem 210 Solution in Ada

I'll solve Euler Problem 210, which asks for the number of lattice points inside a specific region.

First, let me understand what the problem is asking:
- We need to find lattice points (integer coordinates) inside a circle with center at (0,0) and radius 10^6
- The constraint is: x² + y² ≤ 10^6

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_210 is
   type Large_Integer is range -10**12 .. 10**12;
   
   -- Define the radius squared
   Radius_Squared : constant Large_Integer := 10**12;
   
   -- Function to count lattice points inside circle
   function Count_Lattice_Points(Radius2 : Large_Integer) return Long_Long_Integer is
      Count : Long_Long_Integer := 0;
      X     : Long_Long_Integer;
      Y     : Long_Long_Integer;
      Y_Max : Long_Long_Integer;
   begin
      -- For each x coordinate from -sqrt(Radius2) to sqrt(Radius2)
      for X in -Long_Long_Integer(Sqrt(Float(Radius2))) .. Long_Long_Integer(Sqrt(Float(Radius2))) loop
         -- Calculate maximum y value for current x
         Y_Max := Long_Long_Integer(Sqrt(Float(Radius2 - X * X)));
         
         -- Count lattice points for this x
         Count := Count + 2 * Y_Max + 1;  -- +1 for y=0, and 2*Y_Max for positive and negative y values
```
