# Euler Problem 78 Solution in Ada

Euler Problem 78 asks for the smallest value of n for which p(n) is divisible by 1,000,000, where p(n) is the partition function (number of ways to write n as a sum of positive integers).

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_78 is
   Max_N : constant := 1000000;
   Modulus : constant := 1000000;
   
   -- Partition function array
   P : array (0 .. Max_N) of Integer := (others => 0);
   
   -- Pentagonal numbers generator
   function Pentagonal(k : Integer) return Integer is
   begin
      return k * (3 * k - 1) / 2;
   end Pentagonal;
   
begin
   -- Base case
   P(0) := 1;
   
   -- Calculate partition numbers using pentagonal number theorem
   for n in 1 .. Max_N loop
      declare
         Sum : Integer := 0;
         k   : Integer := 1;
         Sign : Integer := 1;
         Pent : Integer;
      begin
         -- Generate pentagonal numbers and calculate P(n)
         loop
            -- Positive pentagonal numbers: k*(3k-1)/2 for k = 1,2,3...
            Pent := Pentagonal(k);
            exit when Pent > n;
            
            Sum := Sum + Sign * P(n - Pent);
            
            -- Negative pentagonal numbers: k*(3k-1)/2 for k = -1,-2,-3...
            Pent := Pentagonal(-k);
            exit when Pent > n;
            
            Sum := Sum + Sign * P(n - Pent);
            
            k := k + 1;
            Sign := -Sign;  -- Alternate signs
         end loop;
         
         P(n) := Sum mod Modulus;
         
         -- Check if we found the answer
         if P(n) = 0 then
            Put_Line("Answer: " & Integer'Image(n));
            return;
         end if;
      end;
   end loop;
   
   Put_Line("No solution found");
end Euler_78;
```

## Explanation

This solution uses the **pentagonal number theorem** to efficiently compute partition numbers. The key insight is that:

1. We use the recurrence relation involving pentagonal numbers
2. The pentagonal numbers are: 1, 5, 12, 22, 35, 51, 70, ...
3. For each n, we calculate P(n) by summing terms of the form:
   ```
   P(n) = Σ(-1)^k * P(n - pentagonal(k))
   ```
   where k runs through positive and negative integers

## Key Features

- **Efficient algorithm**: Uses the pentagonal number theorem instead of brute force
- **Modular arithmetic**: Keeps numbers within bounds using modulo 1,000,000
- **Early termination**: Stops as soon as P(n) ≡ 0 (mod 1,000,000)
- **Memory efficient**: Only stores previously computed values

## Runtime and Output

The program will output the first value of n where p(n) is divisible by 1,000,000. This solution handles the large numbers efficiently by using modular arithmetic throughout the computation.

**Answer: 55374**
