# Euler Problem 147 Solution in Ada

This problem asks us to find the number of rectangles that can be formed in a grid with certain constraints.

Let me break down the approach:
- For an m×n grid, we need to count all possible rectangles
- A rectangle is defined by choosing two horizontal lines and two vertical lines
- In an m×n grid, there are (m+1) horizontal lines and (n+1) vertical lines
- The number of ways to choose 2 lines from (m+1) lines is C(m+1,2) = m(m+1)/2
- Similarly for vertical lines: C(n+1,2) = n(n+1)/2
- Total rectangles = [m(m+1)/2] × [n(n+1)/2]

      -- Count rectangles in an m×n grid
      -- Number of ways to choose 2 horizontal lines from (m+1) lines
      -- Number of ways to choose 2 vertical lines from (n+1) lines
   begin
      return (m * (m + 1) / 2) * (n * (n + 1) / 2);
   end Count_Rectangles;
