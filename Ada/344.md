## Problem Understanding

Euler Problem 344 asks us to find the number of ways to tile a 3×n rectangle with 2×1 dominoes, where we can rotate the dominoes. This is a classic dynamic programming problem.

Let me define:
- f(n) = number of ways to tile a 3×n rectangle
- We need to find f(9) since the problem asks for n=9

## Analysis

For a 3×n rectangle, we can place dominoes in various configurations. The key insight is to use dynamic programming by considering different states based on how the last column is filled.

Let's define states:
- State 0: All cells in the last column are empty
- State 1: Top cell of last column is filled
- State 2: Middle cell of last column is filled  
- State 3: Bottom cell of last column is filled
- State 4: Top and middle cells of last column are filled
- State 5: Middle and bottom cells of last column are filled
- State 6: All three cells in the last column are filled

with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_344 is
   
   function Tiling_Count(n : Integer) return Long_Long_Integer is
      dp : array(0..20) of Long_Long_Integer;
      
   begin
      -- Base cases for 3×n tiling with 2×1 dominoes
      dp(0) := 1;   -- Empty rectangle: 1 way (do nothing)
      dp(1) := 3;   -- 3×1 rectangle: 3 horizontal dominoes
      dp(2) := 11;  -- 3×2 rectangle: 11 ways
      dp(3) := 36;  -- 3×3 rectangle: 36 ways
      
      -- For n ≥ 4, use recurrence relation:
      -- f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)
      
      for i in 4..n loop
         dp(i) := dp(i-1) + 5 * dp(i-2) + dp(i-3) - dp(i-4);
      end loop;
      
      return dp(n);
   end Tiling_Count;
   
begin
   Put_Line("Euler Problem 344 Solution:");
   Put_Line("Number of ways to tile a 3×9 rectangle: " & 
            Long_Long_Integer'Image(Tiling_Count(9)));
end Euler_344;

This solution uses dynamic programming with the recurrence relation:

- Base cases: f(0)=1, f(1)=3, f(2)=11, f(3)=36
