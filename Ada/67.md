# Euler Problem 67 Solution in Ada

Euler Problem 67 asks us to find the maximum total from top to bottom in a triangle of numbers, similar to Problem 67 but with a larger triangle.

Here's the solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_67 is
   type Triangle is array (1 .. 100, 1 .. 100) of Integer;
   T : Triangle;
   
   -- Read the triangle from input
   procedure Read_Triangle is
      Line : String(1..100);
      Last : Natural;
      Row  : Integer := 1;
   begin
      while not End_Of_File loop
         Get_Line(Line, Last);
         if Last > 0 then
            declare
               Col : Integer := 1;
               I   : Integer := 1;
            begin
               while I <= Last loop
                  if Line(I) in '0'..'9' then
                     T(Row, Col) := 0;
                     while I <= Last and then Line(I) in '0'..'9' loop
                        T(Row, Col) := T(Row, Col) * 10 + Integer(Image(Line(I)) - Image('0'));
                        I := I + 1;
                     end loop;
                     Col := Col + 1;
                  else
                     I := I + 1;
                  end if;
               end loop;
               Row := Row + 1;
            end;
         end if;
      end loop;
   end Read_Triangle;
   
   -- Solve the maximum path sum
   procedure Solve is
      Row : Integer;
   begin
      -- Start from the second-to-last row and work up
      for Row in reverse 1 .. 99 loop
         for Col in 1 .. Row loop
            T(Row, Col) := T(Row, Col) + 
                          (if T(Row+1, Col) > T(Row+1, Col+1) 
                           then T(Row+1, Col) 
                           else T(Row+1, Col+1));
         end loop;
      end loop;
   end Solve;
   
begin
   Read_Triangle;
   Solve;
   Put_Line(Integer'Image(T(1,1)));
end Euler_67;
```

## Explanation of the Solution

The approach used is dynamic programming with a bottom-up strategy:

1. **Problem Understanding**: We need to find the maximum sum path from top to bottom in a triangle where we can only move to adjacent numbers (either directly below or diagonally below).

2. **Algorithm**: 
   - Start from the second-to-last row and work upward
   - For each element, add the maximum of the two elements directly below it
   - This effectively builds up the maximum path sum for each position
   - The top element will contain the final answer

3. **Time Complexity**: O(n²) where n is the number of rows
4. **Space Complexity**: O(1) additional space (modifying input in-place)

## Key Features

- Uses bottom-up dynamic programming approach
- Works from the second-to-last row upward
- For each element, adds the maximum of the two adjacent elements below it
- Efficient and elegant solution to the maximum path sum problem
