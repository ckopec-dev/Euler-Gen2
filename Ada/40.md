# Euler Problem 40 Solution in Ada

Euler Problem 40 asks us to find the value of the expression d₁ × d₁₀ × d₁₀₀ × d₁₀₀₀ × d₁₀₀₀₀ × d₁₀₀₀₀₀ × d₁₀₀₀₀₀₀ where dₙ represents the nth digit of the fractional part of the irrational decimal fraction formed by concatenating the positive integers: 0.123456789101112131415...

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_40 is
   -- Function to get the nth digit of the concatenated sequence
   function Get_Digit(N : Integer) return Integer is
      Digit_Count : Integer := 1;
      Number_Length : Integer := 1;
      Total_Digits : Integer := 0;
      Current_Number : Integer := 1;
      Digit_Position : Integer := 1;
   begin
      -- Find which number contains the nth digit
      while Total_Digits + (Number_Length * 9 * Digit_Count) < N loop
         Total_Digits := Total_Digits + (Number_Length * 9 * Digit_Count);
         Digit_Count := Digit_Count * 10;
         Number_Length := Number_Length + 1;
      end loop;
      
      -- Calculate which number contains the digit
      declare
         Remaining_Digits : Integer := N - Total_Digits;
         Number_Offset : Integer := (Remaining_Digits - 1) / Number_Length;
         Target_Number : Integer := Digit_Count + Number_Offset;
         Digit_Offset : Integer := (Remaining_Digits - 1) mod Number_Length;
      begin
         -- Convert number to string and get the specific digit
         declare
            Num_Str : String(1..Number_Length);
            Temp_Num : Integer := Target_Number;
            Index : Integer := Number_Length;
         begin
            -- Convert number to string (reversed)
            while Temp_Num > 0 loop
               Num_Str(Index) := Character'Val(Temp_Num mod 10 + Character'Pos('0'));
               Temp_Num := Temp_Num / 10;
               Index := Index - 1;
            end loop;
            
            return Integer(Num_Str(Digit_Offset + 1) - '0');
         end;
      end;
   end Get_Digit;

   -- Alternative simpler approach for better clarity
   function Get_Digit_Simple(N : Integer) return Integer is
      Digit_String : String := "";
      I : Integer := 1;
   begin
      -- Build string until we have enough digits
      while Digit_String'Length < N loop
         Digit_String := Digit_String & Integer'Image(I);
         I := I + 1;
      end loop;
      
      return Integer(Digit_String(N) - '0');
   end Get_Digit_Simple;

begin
   -- Calculate the product of specified digits
   declare
      Result : Integer := 1;
      Positions : array(1..7) of Integer := (1, 10, 100, 1000, 10000, 100000, 1000000);
   begin
      for I in Positions'Range loop
         Result := Result * Get_Digit_Simple(Positions(I));
      end loop;
      
      Put("The answer is: ");
      Put(Result);
      New_Line;
   end;
end Euler_40;
```

However, let me provide a more efficient version that avoids building large strings:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_40 is
   -- Efficient function to get the nth digit without storing all digits
   function Get_Digit(N : Integer) return Integer is
      Num_Digits : Integer := 1;    -- Number of digits in current numbers
      Count : Integer := 9;         -- How many numbers with current digit count
      Total : Integer := 0;         -- Total digits so far
   begin
      -- Find which range the digit belongs to (1-digit, 2-digit, etc.)
      while Total + Num_Digits * Count < N loop
         Total := Total + Num_Digits * Count;
         Num_Digits := Num_Digits + 1;
         Count := Count * 10;
      end loop;
      
      -- Calculate which number contains the digit
      declare
         Number_Offset : Integer := (N - Total - 1) / Num_Digits;  -- Which number in the range
         Digit_Offset : Integer := (N - Total - 1) mod Num_Digits; -- Which digit in that number
         Target_Number : Integer := 10**(Num_Digits-1) + Number_Offset;
         Temp_Num : Integer := Target_Number;
         Digit_Position : Integer := Num_Digits - 1;
         Digit_Value : Integer := 0;
      begin
         -- Extract the specific digit
         while Digit_Position >= 0 loop
            if Digit_Position = Digit_Offset then
               Digit_Value := Temp_Num mod 10;
               exit;
            end if;
            Temp_Num := Temp_Num / 10;
            Digit_Position := Digit_Position - 1;
         end loop;
         
         return Digit_Value;
      end;
   end Get_Digit;

begin
   -- Calculate product of d₁ × d₁₀ × d₁₀₀ × d₁₀₀₀ × d₁₀₀₀₀ × d₁₀₀₀₀₀ × d₁₀₀₀₀₀₀
   declare
      Result : Integer := 1;
      Positions : array(1..7) of Integer := (1, 10, 100, 1000, 10000, 100000, 1000000);
   begin
      for I in Positions'Range loop
         Result := Result * Get_Digit(Positions(I));
      end loop;
      
      Put_Line("The answer is: " & Integer'Image(Result));
   end;
end Euler_40;
```

## Explanation

The solution works by:

1. **Understanding the sequence**: The decimal part is formed by concatenating positive integers: 0.123456789101112131415...

2. **Finding digits efficiently**: Instead of building the entire sequence, we calculate which "range" (1-digit numbers, 2-digit numbers, etc.) contains our target digit.

3. **Calculating position within range**: Once we know the range, we determine exactly which number and which digit within that number contains our answer.

4. **Computing the product**: We compute d₁ × d₁₀ × d₁₀₀ × d₁₀₀₀ × d₁₀₀₀₀ × d₁₀₀₀₀₀ × d₁₀₀₀₀₀₀

The answer is **210**.

The key insight is that we don't need to store the entire decimal sequence - we can mathematically determine where any specific digit appears and extract it directly.
