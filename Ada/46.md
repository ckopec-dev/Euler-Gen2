# Euler Problem 46 Solution in Ada

## Problem Statement
It was proposed by Christian Goldbach that every odd composite number can be written as the sum of a prime and twice a square.

9 = 7 + 2×1²  
15 = 7 + 2×2²  
21 = 3 + 2×3²  
25 = 7 + 2×3²  
27 = 19 + 2×2²  
33 = 31 + 2×1²  

It turns out that the conjecture was false.

What is the smallest odd composite number that cannot be written as the sum of a prime and twice a square?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_46 is
   
   -- Maximum number to check (reasonable upper bound)
   Max_Number : constant := 10000;
   
   -- Array to mark prime numbers (sieve of Eratosthenes)
   Is_Prime : array (2 .. Max_Number) of Boolean;
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(N : Integer) return Boolean is
   begin
      if N < 0 then
         return False;
      end if;
      
      declare
         Sqrt_N : constant Integer := Integer(Sqrt(Float(N)));
      begin
         return Sqrt_N * Sqrt_N = N;
      end;
   end Is_Perfect_Square;
   
   -- Function to check if a number can be written as prime + 2*square
   function Can_Be_Expressed(N : Integer) return Boolean is
      Found : Boolean := False;
      I : Integer;
   begin
      -- Check all primes less than N
      for P in 2 .. N-1 loop
         if Is_Prime(P) then
            -- Check if (N - P) / 2 is a perfect square
            declare
               Diff : constant Integer := N - P;
            begin
               if Diff > 0 and then Diff mod 2 = 0 then
                  declare
                     Half_Diff : constant Integer := Diff / 2;
                  begin
                     if Is_Perfect_Square(Half_Diff) then
                        Found := True;
                        exit;
                     end if;
                  end;
               end if;
            end;
         end if;
      end loop;
      
      return Found;
   end Can_Be_Expressed;
   
begin
   -- Initialize sieve of Eratosthenes
   for I in 2 .. Max_Number loop
      Is_Prime(I) := True;
   end loop;
   
   -- Sieve of Eratosthenes to find all primes up to Max_Number
   for I in 2 .. Integer(Sqrt(Float(Max_Number))) loop
      if Is_Prime(I) then
         for J in I*I .. Max_Number loop
            if J mod I = 0 then
               Is_Prime(J) := False;
            end if;
         end loop;
      end if;
   end loop;
   
   -- Find the smallest odd composite that cannot be expressed as prime + 2*square
   for N in 9 .. Max_Number loop
      -- Check if N is odd and composite (not prime)
      if N mod 2 = 1 and then not Is_Prime(N) then
         if not Can_Be_Expressed(N) then
            Put_Line("The smallest odd composite number that cannot be written as the sum of a prime and twice a square is: " & Integer'Image(N));
            exit;
         end if;
      end if;
   end loop;
   
end Euler_46;
```

## Explanation

This solution follows these steps:

1. **Sieve of Eratosthenes**: First, we generate all prime numbers up to 10,000 using the classic sieve algorithm.

2. **Perfect Square Check**: We implement a helper function `Is_Perfect_Square` that checks if a number is a perfect square by computing its square root and squaring it back.

3. **Expression Check**: The `Can_Be_Expressed` function tests whether a given odd composite number can be written as the sum of a prime and twice a square:
   - For each prime number P less than N
   - Check if (N - P) is even and if (N - P)/2 is a perfect square

4. **Main Loop**: We iterate through odd numbers starting from 9, checking each composite number to see if it can be expressed in the required form. The first number that fails this test is our answer.

## Result
The solution finds that **5777** is the smallest odd composite number that cannot be written as the sum of a prime and twice a square.

This matches the known mathematical result for Euler Problem 46, where 5777 is indeed the first counterexample to Goldbach's conjecture in this specific form.
