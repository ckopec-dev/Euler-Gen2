# Euler Problem 26 Solution in Ada

Euler Problem 26 asks: "Find the value of d < 1000 for which 1/d contains the longest recurring cycle in its decimal fraction part."

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_26 is
   
   function Get_Cycle_Length(Denominator : Integer) return Integer is
      Remainder : Integer := 1;
      Position  : Integer := 0;
      Positions : array(0..999) of Integer := (others => -1);
   begin
      loop
         -- Check if we've seen this remainder before
         for I in 0..Position-1 loop
            if Positions(I) = Remainder then
               return Position - I;
            end if;
         end loop;
         
         -- Store the position of this remainder
         Positions(Position) := Remainder;
         Position := Position + 1;
         
         -- Multiply by 10 and get new remainder
         Remainder := (Remainder * 10) mod Denominator;
         
         -- If remainder is 0, no cycle
         if Remainder = 0 then
            return 0;
         end if;
      end loop;
   end Get_Cycle_Length;
   
   Max_D     : Integer := 0;
   Max_Length : Integer := 0;
   
begin
   -- Check all denominators from 2 to 999
   for D in 2..999 loop
      declare
         Length : Integer := Get_Cycle_Length(D);
      begin
         if Length > Max_Length then
            Max_Length := Length;
            Max_D := D;
         end if;
      end;
   end loop;
   
   Put_Line("The value of d < 1000 with longest recurring cycle is: " & Integer'Image(Max_D));
   Put_Line("Length of cycle: " & Integer'Image(Max_Length));
end Euler_26;
```

## Explanation

This solution works by:

1. **Finding the length of recurring cycles**: For each denominator `d`, we perform long division and track remainders
2. **Cycle detection**: When we encounter a remainder we've seen before, we know we've found the start of a repeating cycle
3. **Length calculation**: The difference between the current position and the previous occurrence gives us the cycle length

The algorithm:
- Starts with remainder = 1 (representing 1/d)
- For each step: multiply remainder by 10, divide by denominator to get new remainder
- Track each remainder we encounter in an array
- When a remainder repeats, calculate the cycle length as the difference in positions
- If remainder becomes 0, there's no repeating cycle (finite decimal)

The answer is **983**, which produces a recurring cycle of length **982**.
