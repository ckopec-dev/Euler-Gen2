## Analysis

For a number n with prime factorization n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, the number of divisors is (a₁ + 1)(a₂ + 1)...(aₖ + 1).

For n to be divisible by 10, n must be divisible by 2 and 5.
So n = 2^a × 5^b × (other primes)^c where a ≥ 1 and b ≥ 1.

The number of divisors = (a + 1)(b + 1)(c₁ + 1)(c₂ + 1)... where cᵢ are exponents of other primes.

For the number of divisors to be divisible by 10, we need (a + 1)(b + 1)(c₁ + 1)(c₂ + 1)... ≡ 0 (mod 10).

Since 10 = 2 × 5, we need the product to be divisible by both 2 and 5.
