with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_172 is
   -- Dynamic programming approach
   type DP_Table is array (0..18, 0..16) of Long_Long_Integer;
   
   function Count_Valid_Numbers return Long_Long_Integer is
      DP : DP_Table := (others => (others => 0));
      
      -- Initialize for first digit (can't be 0)
      for Digit in 1..9 loop
         DP(1, Digit mod 17) := DP(1, Digit mod 17) + 1;
      end loop;
      
      -- Fill the DP table
      for Length in 2..18 loop
         for Sum_Mod in 0..16 loop
            if DP(Length-1, Sum_Mod) /= 0 then
               for Digit in 0..9 loop
                  declare
                     New_Sum_Mod : Integer := (Sum_Mod + Digit) mod 17;
                  begin
                     DP(Length, New_Sum_Mod) := 
                        DP(Length, New_Sum_Mod) + DP(Length-1, Sum_Mod);
                  end;
               end loop;
            end if;
         end loop;
      end loop;
      
      return DP(18, 0);
   end Count_Valid_Numbers;
   
begin

end Euler_172;

The solution works as follows:

1. **Dynamic Programming Approach**: We use a DP table where `DP[i][j]` represents the number of ways to form an i-digit number such that the sum of digits modulo 17 equals j.

2. **Initialization**: For the first digit, we can only use digits 1-9 (no leading zeros), so we initialize `DP[1][d mod 17] = 1` for d in 1..9.

3. **Transition**: For each additional digit position, we consider adding each possible digit (0-9) to all existing numbers and update the DP table accordingly.

4. **Final Answer**: The result is `DP[18][0]`, which gives us the count of 18-digit numbers with sum of digits divisible by 17.
