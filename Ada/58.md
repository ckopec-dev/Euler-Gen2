# Euler Problem 58 Solution in Ada

## Problem Statement
Starting with 1 and spiralling anticlockwise in the following way, a square spiral with side length 7 is formed.

```
37 36 35 34 33 32 31
38 17 16 15 14 13 30
39 18  5  4  3 12 29
40 19  6  1  2 11 28
41 20  7  8  9 10 27
42 21 22 23 24 25 26
43 44 45 46 47 48 49
```

It is interesting to note that the odd squares lie along the bottom right diagonal, but what is more interesting is that 8 out of the 13 numbers lying along both diagonals are prime; that is, a ratio of 8/13 ≈ 62%.

If one were to continue this process, what would be the side length of the square spiral for which the ratio of primes along both diagonals first falls below 10%?

## Solution Approach
We need to:
1. Generate the spiral numbers and track diagonal elements
2. Check if each diagonal element is prime
3. Keep count of primes and total diagonal numbers
4. Stop when the ratio falls below 10%

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_58 is
   
   -- Function to check if a number is prime
   function Is_Prime(N : Integer) return Boolean is
      Root : Integer;
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         Root := Integer(Sqrt(Float(N)));
         for I in 3 .. Root loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   Side_Length : Integer := 1;
   Total_Count : Integer := 1;  -- Start with 1 (the center)
   Prime_Count : Integer := 0;  -- Count of primes on diagonals
   Current_Number : Integer := 1;
   
begin
   loop
      Side_Length := Side_Length + 2;  -- Next odd side length
      
      -- For each corner of the new layer, calculate the diagonal numbers
      for Corner in 1 .. 4 loop
         Current_Number := Current_Number + (Side_Length - 1);
         Total_Count := Total_Count + 1;
         if Is_Prime(Current_Number) then
            Prime_Count := Prime_Count + 1;
         end if;
      end loop;
      
      -- Check if the ratio is less than 10%
      if Float(Prime_Count) / Float(Total_Count) < 0.1 then
         Put_Line("Side length: " & Integer'Image(Side_Length));
         exit;
      end if;
   end loop;
end Euler_58;
```

## Explanation

The solution works by:

1. **Generating the spiral**: Starting from side length 1, we incrementally build larger squares by adding layers around the previous square.

2. **Calculating diagonal numbers**: For each new layer, we calculate the four corner numbers that lie on the diagonals. The difference between consecutive corners is (side_length - 1).

3. **Prime checking**: We use an efficient prime checking function that only tests odd divisors up to √N.

4. **Ratio calculation**: We keep track of total diagonal numbers and prime numbers found, then check if the ratio falls below 10%.

5. **Termination**: When the ratio drops below 10%, we output the current side length.

The spiral grows by adding layers of size (side_length - 1) between corners, where each corner is calculated from the previous one. This approach avoids generating all numbers in the spiral and instead focuses only on the diagonal elements that matter for our calculation.

**Answer**: 26241
