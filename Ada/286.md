# Euler Problem 286 Solution in Ada

This problem asks for the probability that a randomly chosen triangle with vertices at lattice points (0,0), (a,0), and (0,b) where a,b are positive integers and a+b ≤ 100, has an area of exactly 50.

The area of such a triangle is (1/2) × a × b = 50, so a × b = 100.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_286 is
   Total_Count : Integer := 0;
   Valid_Count : Integer := 0;
   
   -- Function to compute GCD using Euclidean algorithm
   function GCD(A, B : Integer) return Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
begin
   -- Iterate through all possible values of a and b
   for a in 1..100 loop
      for b in 1..(100 - a) loop
         Total_Count := Total_Count + 1;
         
         -- Check if area equals 50 (a * b = 100)
         if a * b = 100 then
            Valid_Count := Valid_Count + 1;
         end if;
      end loop;
   end loop;
   
   -- Calculate the probability as a reduced fraction
   declare
      G : Integer := GCD(Valid_Count, Total_Count);
   begin
      Put("Probability: ");
      Put(Valid_Count / G);
      Put("/");
      Put(Total_Count / G);
      New_Line;
      
      Put("Decimal value: ");
      Put(Float(Valid_Count) / Float(Total_Count), 0, 10);
      New_Line;
   end;
   
end Euler_286;
```
