# Euler Problem 62 Solution in Ada

Euler Problem 62 asks: "What is the smallest cube for which exactly five permutations of its digits are cube numbers?"

Let me solve this step by step:

## Approach
1. Generate cubes and their digit signatures
2. Group cubes by their sorted digit sequences
3. Find the first group with exactly 5 members
4. Return the smallest cube in that group

## Ada Solution

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;

procedure Euler_62 is
   
   type Cube_Vector is array (Positive range <>) of Natural;
   
   function Sort_Digits(N : Natural) return String is
      Digits : array(1..10) of Character := (others => '0');
      Count  : array(Character range '0'..'9') of Positive := (others => 0);
      Result : Unbounded_String;
      Temp   : Natural := N;
      I      : Positive := 1;
   begin
      if N = 0 then
         return "0";
      end if;
      
      -- Count each digit
      while Temp > 0 loop
         Count(Character'Val(Temp mod 10 + Character'Pos('0'))) := 
            Count(Character'Val(Temp mod 10 + Character'Pos('0'))) + 1;
         Temp := Temp / 10;
      end loop;
      
      -- Build sorted string
      for D in Character'Val(Character'Pos('0'))..Character'Val(Character'Pos('9')) loop
         for C in 1..Count(D) loop
            Append(Result, D);
         end loop;
      end loop;
      
      return To_String(Result);
   end Sort_Digits;
   
   type Cube_Group is record
      First_Cube : Natural;
      Count      : Natural;
   end record;
   
   package Cube_Group_Vector is new Ada.Containers.Vectors(Natural, Cube_Group);
   Groups : Cube_Group_Vector.Vector;
   
   Max_Cube : constant := 1000000000; -- Upper bound for search
   Cube   : Natural := 1;
   N      : Natural := 1;
   Found  : Boolean := False;
   
begin
   -- Generate cubes and group them by digit signature
   while Cube < Max_Cube loop
      Cube := N * N * N;
      
      declare
         Signature : constant String := Sort_Digits(Cube);
         Index     : Natural := 0;
         Found_Index : Boolean := False;
      begin
         -- Look for existing group with same signature
         for I in 1..Cube_Group_Vector.Length(Groups) loop
            if Cube_Group_Vector.Element(Groups, I).First_Cube = 0 then
               null; -- Skip empty entries
            else
               declare
                  Test_Cube : constant Natural := Cube_Group_Vector.Element(Groups, I).First_Cube;
                  Test_Sig  : constant String := Sort_Digits(Test_Cube);
               begin
                  if Test_Sig = Signature then
                     Index := I;
                     Found_Index := True;
                     exit;
                  end if;
               end;
            end if;
         end loop;
         
         -- If group exists, increment count
         if Found_Index then
            declare
               Group : Cube_Group := Cube_Group_Vector.Element(Groups, Index);
            begin
               Group.Count := Group.Count + 1;
               Cube_Group_Vector.Replace_Element(Groups, Index, Group);
               
               -- Check if we found exactly 5 cubes
               if Group.Count = 5 then
                  Put_Line("Found solution: " & Natural'Image(Group.First_Cube));
                  Found := True;
                  exit;
               end if;
            end;
         else
            -- Create new group
            Cube_Group_Vector.Append(Groups, (First_Cube => Cube, Count => 1));
         end if;
      end;
      
      N := N + 1;
   end loop;
   
   Put_Line("Solution: " & Natural'Image(Cube));
end Euler_62;

         return "0";

## Explanation

The solution works by:

1. **Digit Signature Generation**: For each cube, we create a signature by sorting its digits in ascending order
2. **Grouping**: We group cubes by their digit signatures (cubes with the same digits will have the same signature)
3. **Counting**: We track how many cubes belong to each group
4. **Finding Solution**: When we find a group with exactly 5 members, we return the smallest cube in that group

## Key Insight

The key insight is that if two numbers are permutations of each other, they will have identical digit signatures when sorted. So we can efficiently group cubes by their digit signatures and count how many cubes belong to each group.
