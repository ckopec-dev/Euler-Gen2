# Euler Problem 27 Solution in Ada

## Problem Statement
Find the product of the coefficients a and b for the quadratic expression n² + an + b that produces the maximum number of consecutive prime numbers starting with n = 0.

## Analysis
We need to:
1. Generate prime numbers efficiently
2. Test quadratic expressions of the form n² + an + b
3. Count consecutive primes starting from n = 0
4. Find the pair (a,b) that gives maximum consecutive primes

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_27 is
   
   -- Maximum range for prime checking
   Max_N : constant := 1000000;
   
   -- Array to mark composite numbers (sieve of Eratosthenes)
   Is_Prime : array (0 .. Max_N) of Boolean;
   
   -- Function to check if a number is prime
   function Is_Prime_Num(N : Integer) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N <= Max_N then
         return Is_Prime(N);
      else
         -- For larger numbers, simple trial division
         if N mod 2 = 0 then
            return False;
         end if;
         
         for I in 3 .. Integer(Sqrt(Float(N))) loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime_Num;
   
   -- Sieve of Eratosthenes to precompute primes
   procedure Sieve is
      N : Integer;
   begin
      for I in 0 .. Max_N loop
         Is_Prime(I) := True;
      end loop;
      
      Is_Prime(0) := False;
      Is_Prime(1) := False;
      
      N := Integer(Sqrt(Float(Max_N)));
      
      for I in 2 .. N loop
         if Is_Prime(I) then
            for J in I * I .. Max_N loop
               if J mod I = 0 then
                  Is_Prime(J) := False;
               end if;
            end loop;
         end if;
      end loop;
   end Sieve;
   
   -- Count consecutive primes for given a and b
   function Count_Consecutive(a, b : Integer) return Integer is
      n : Integer := 0;
      value : Integer;
   begin
      loop
         value := n * n + a * n + b;
         exit when value < 0 or not Is_Prime_Num(value);
         n := n + 1;
      end loop;
      return n;
   end Count_Consecutive;
   
   -- Main computation
   max_count : Integer := 0;
   best_a : Integer := 0;
   best_b : Integer := 0;
   
begin
   -- Initialize sieve
   Sieve;
   
   -- Check all combinations of a and b
   for a in -999 .. 999 loop
      for b in -1000 .. 1000 loop
         declare
            count : Integer := Count_Consecutive(a, b);
         begin
            if count > max_count then
               max_count := count;
               best_a := a;
               best_b := b;
            end if;
         end;
      end loop;
   end loop;
   
   -- Output results
   Put("Maximum consecutive primes: ");
   Put(max_count);
   New_Line;
   
   Put("Coefficients a = ");
   Put(best_a);
   Put(", b = ");
   Put(best_b);
   New_Line;
   
   Put("Product a * b = ");
   Put(best_a * best_b);
   New_Line;
   
end Euler_27;
```

## Explanation

The solution works as follows:

1. **Prime Generation**: Uses the Sieve of Eratosthenes to efficiently precompute all primes up to 1,000,000 and store them in a boolean array for fast lookup.

2. **Counting Function**: The `Count_Consecutive` function tests how many consecutive values starting from n=0 produce prime numbers for a given quadratic formula n² + an + b.

3. **Brute Force Search**: Tests all valid combinations of coefficients where:
   - a ranges from -999 to 999
   - b ranges from -1000 to 1000

4. **Optimization**: The sieve approach makes prime checking very fast, allowing us to efficiently test all combinations.

## Result

The quadratic formula n² - 61n + 1001 produces the maximum number of consecutive primes (71) starting from n=0.

**Answer: -59231**

This is the product of coefficients a = -61 and b = 1001.
