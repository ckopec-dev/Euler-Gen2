# Euler Problem 179 Solution in Ada

This problem asks for the number of integers 1 < n < 10^7 for which n and n+1 have the same number of divisors.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_179 is
   N : constant := 10**7;
   
   -- Array to store number of divisors for each number
   Divisors : array (1 .. N) of Integer;
   
   Count : Integer := 0;
   
begin
   -- Initialize divisors array
   for I in 1 .. N loop
      Divisors(I) := 0;
   end loop;
   
   -- Count divisors for each number using the fact that 
   -- if i divides n, then both i and n/i are divisors
   for I in 1 .. N loop
      for J in 1 .. N / I loop
         Divisors(I * J) := Divisors(I * J) + 1;
      end loop;
   end loop;
   
   -- Count consecutive numbers with same number of divisors
   for I in 2 .. N - 1 loop
      if Divisors(I) = Divisors(I + 1) then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("Answer: ");
   Put(Count);
   New_Line;
end Euler_179;
```

## Explanation

This solution uses an efficient approach to count divisors:

1. **Initialize**: Create an array `Divisors` where `Divisors(i)` will store the number of divisors for integer `i`.

2. **Count Divisors**: For each number `i`, we iterate through multiples `i*j` up to `N`. Each such multiple gets one more divisor counted (the factor `i`).

3. **Compare Consecutive Numbers**: We check pairs of consecutive integers from 2 to N-1, counting how many have the same number of divisors.

## Time Complexity
- The algorithm has time complexity O(N log N) due to the nested loops
- Space complexity is O(N) for the divisors array

## Key Insights
- Instead of checking all possible divisors for each number separately (which would be O(N²)), we use the fact that if `i` divides `n`, then both `i` and `n/i` are divisors
- This approach counts divisors incrementally, making it much more efficient
- The constraint 1 < n < 10^7 makes brute force impractical, so this optimized method is necessary

The answer for Euler Problem 179 is **986262**.
