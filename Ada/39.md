# Euler Problem 39 Solution in Ada

Problem 39 asks: "If p is the perimeter of a right angle triangle with integral length sides, {a,b,c}, there are exactly three solutions for p = 120. {20,48,52}, {24,45,51}, {30,40,50}. For which value of p ≤ 1000, is the number of solutions maximised?"

## Analysis

For a right triangle with sides a, b, c where a² + b² = c² and perimeter a + b + c = p:
- Since a, b, c are positive integers and a² + b² = c², we know c > a and c > b
- Also, a + b + c = p, so c = p - a - b
- Substituting: a² + b² = (p - a - b)²

Let me solve this step by step:

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_39 is
   Max_Solutions : Integer := 0;
   Best_P      : Integer := 0;
   
   function Count_Solutions(P : Integer) return Integer is
      Count : Integer := 0;
   begin
      -- For a right triangle with perimeter P, we need to find all valid (a,b,c)
      -- where a² + b² = c² and a + b + c = P
      
      -- Since a ≤ b < c and a + b + c = P, we have:
      -- a ≤ P/3 (since if a > P/3, then b and c would also be > P/3)
      for A in 1 .. P/3 loop
         -- From the constraint that a² + b² = c² and a + b + c = P:
         -- We can derive: b = (P² - 2*P*A) / (2*(P-A))
         -- For this to be integer, (P² - 2*P*A) must be divisible by 2*(P-A)
         
         declare
            Numerator : Integer := P * P - 2 * P * A;
            Denominator : Integer := 2 * (P - A);
         begin
            if Numerator > 0 and then Numerator mod Denominator = 0 then
               declare
                  B : Integer := Numerator / Denominator;
                  C : Integer := P - A - B;
               begin
                  -- Check if this forms a valid right triangle
                  if A < B and then B < C and then A*A + B*B = C*C then
                     Count := Count + 1;
                  end if;
               end;
            end if;
         end;
      end loop;
      
      return Count;
   end Count_Solutions;
   
begin
   for P in 1 .. 1000 loop
      declare
         Solutions : Integer := Count_Solutions(P);
      begin
         if Solutions > Max_Solutions then
            Max_Solutions := Solutions;
            Best_P := P;
         end if;
      end;
   end loop;
   
   Put_Line("The value of p ≤ 1000 with maximum solutions is: " & Integer'Image(Best_P));
   Put_Line("Number of solutions: " & Integer'Image(Max_Solutions));
end Euler_39;
```

## Alternative Optimized Approach

Here's a more efficient solution using a different mathematical approach:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_39 is
   Max_Solutions : Integer := 0;
   Best_P      : Integer := 0;
   
   function Count_Solutions(P : Integer) return Integer is
      Count : Integer := 0;
   begin
      -- For right triangle with integer sides and perimeter P:
      -- We iterate through possible values of a and b to find valid c
      for A in 1 .. P/3 loop
         for B in A .. (P - A)/2 loop
            declare
               C : Integer := P - A - B;
            begin
               if A*A + B*B = C*C then
                  Count := Count + 1;
               end if;
            end;
         end loop;
      end loop;
      
      return Count;
   end Count_Solutions;
   
begin
   for P in 1 .. 1000 loop
      declare
         Solutions : Integer := Count_Solutions(P);
      begin
         if Solutions > Max_Solutions then
            Max_Solutions := Solutions;
            Best_P := P;
         end if;
      end;
   end loop;
   
   Put_Line("The value of p ≤ 1000 with maximum solutions is: " & Integer'Image(Best_P));
   Put_Line("Number of solutions: " & Integer'Image(Max_Solutions));
end Euler_39;
```

## Explanation

The solution works by:

1. **Iterating through all possible perimeters** from 1 to 1000
2. **For each perimeter P**, finding all valid right triangles with integer sides
3. **Using the constraints**: 
   - a + b + c = P (perimeter constraint)
   - a² + b² = c² (Pythagorean theorem)
4. **Optimization**: 
   - For a right triangle, we know that a ≤ b < c
   - We can limit our search space by noting that a ≤ P/3 and b ≤ (P-a)/2

## Result

The perimeter p = 840 gives the maximum number of solutions (8 solutions).

**Answer: 840**
