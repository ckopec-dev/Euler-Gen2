# Euler Problem 106 Solution in Ada

## Problem Statement
Let S(A) represent the sum of elements in set A of size n. We shall call it a special sum set if for any two non-empty disjoint subsets, B and C, the sum of elements in B is not equal to the sum of elements in C.

If S(A) is minimised for a given n, we shall call it an optimum special sum set. The first five optimum special sum sets are:
- n = 1: {1}
- n = 2: {1, 2}
- n = 3: {2, 3, 4}
- n = 4: {3, 5, 6, 7}
- n = 5: {6, 9, 11, 12, 13}

For n = 6, the optimum special sum set is A = {11, 17, 20, 22, 23, 24}.

If we have two non-empty disjoint subsets B and C, then the number of such pairs that need to be checked is the number of pairs of subsets with the same size. For a set of size n, there are C(n,k) ways to choose k elements for subset B, and C(n-k,k) ways to choose k elements for subset C from the remaining elements.

The number of pairs that need to be checked for each size k is C(n,k) × C(n-k,k) / 2, but we must also consider when k = n/2 (which gives us the same subsets).

However, there's a more elegant approach: we can use a recursive method to count the invalid pairs.
