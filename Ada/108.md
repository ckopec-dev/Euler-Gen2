# Euler Problem 108 Solution in Ada

## Problem Statement
In the following equation, where x, y, and n are positive integers:
```
1/x + 1/y = 1/n
```

For n = 4 there are exactly three distinct solutions:
- 1/5 + 1/20 = 1/4
- 1/6 + 1/12 = 1/4  
- 1/8 + 1/8 = 1/4

What is the least value of n for which the number of distinct solutions exceeds one thousand?

## Analysis
From the equation 1/x + 1/y = 1/n, we can derive that:
- xy = n(x + y)
- xy - nx - ny = 0  
- xy - nx - ny + n² = n²
- (x - n)(y - n) = n²

This means that for each divisor d of n², we can set x - n = d and y - n = n²/d.
Therefore: x = n + d and y = n + n²/d

For valid solutions, we need x ≥ 1 and y ≥ 1, which means d ≥ 1 and n²/d ≥ 1, so d ≤ n².

The number of solutions is equal to the number of divisors of n², but we must be careful about counting since x and y are interchangeable.

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_108 is
   
   function Count_Divisors(N : in Natural) return Natural is
      Count : Natural := 0;
      I     : Natural;
   begin
      I := 1;
      while I * I <= N loop
         if N mod I = 0 then
            if I * I = N then
               Count := Count + 1;  -- Perfect square case
            else
               Count := Count + 2;  -- Two divisors: I and N/I
            end if;
         end if;
         I := I + 1;
      end loop;
      return Count;
   end Count_Divisors;
   
   function Number_Of_Solutions(N : in Natural) return Natural is
      N_Squared : constant Natural := N * N;
      Div_Count : Natural;
   begin
      Div_Count := Count_Divisors(N_Squared);
      
      -- For the equation 1/x + 1/y = 1/n, 
      -- we want to count distinct solutions where x <= y
      -- The number of solutions is (number of divisors + 1) / 2
      return (Div_Count + 1) / 2;
   end Number_Of_Solutions;
   
   N : Natural := 1;
   Solutions : Natural;
begin
   loop
      Solutions := Number_Of_Solutions(N);
      if Solutions > 1000 then
         Put("The least value of n for which the number of distinct solutions exceeds one thousand is: ");
         Put(N);
         New_Line;
         exit;
      end if;
      N := N + 1;
   end loop;
end Euler_108;
```

## Explanation

The key insight in solving this problem is recognizing that the number of solutions to the equation 1/x + 1/y = 1/n is related to the number of divisors of n².

Let's break down the approach:

1. **Mathematical Transformation**: Starting from 1/x + 1/y = 1/n, we manipulate it to get (x-n)(y-n) = n²
2. **Divisor Counting**: For each divisor d of n², we can find a solution where x = n + d and y = n + n²/d
3. **Solution Counting**: Since we're counting distinct solutions with x ≤ y, the count is (number of divisors + 1) / 2

The `Count_Divisors` function efficiently counts all divisors by iterating up to √N and checking for divisibility.

## Optimization Note

The solution above is efficient enough for this problem. For very large values of n, we could optimize further by using prime factorization methods to count divisors more quickly, but the current approach works well within reasonable time limits.

The answer is 180180.
