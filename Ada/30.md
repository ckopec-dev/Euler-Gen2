# Euler Problem 30 Solution in Ada

Euler Problem 30 asks: Find the sum of all numbers that can be written as the sum of fifth powers of their digits.

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_30 is
   Power : constant := 5;
   Total_Sum : Integer := 0;
   
   -- Function to calculate sum of fifth powers of digits
   function Sum_Of_Powers(N : Integer) return Integer is
      Result : Integer := 0;
      Temp : Integer := N;
   begin
      while Temp > 0 loop
         declare
            Digit : constant Integer := Temp mod 10;
         begin
            Result := Result + Digit ** Power;
            Temp := Temp / 10;
         end;
      end loop;
      return Result;
   end Sum_Of_Powers;
   
begin
   -- We need to find an upper bound for our search
   -- For a d-digit number, the maximum sum of fifth powers is d * 9^5
   -- We need this to be >= the number itself
   -- 9^5 = 59049
   -- So for 6 digits: 6 * 59049 = 354294
   -- For 7 digits: 7 * 59049 = 413343 (too small)
   
   -- We can safely search up to 354294
   for I in 2..354294 loop
      if Sum_Of_Powers(I) = I then
         Total_Sum := Total_Sum + I;
         Put_Line("Found: " & Integer'Image(I));
      end if;
   end loop;
   
   Put_Line("Sum of all numbers that can be written as sum of fifth powers of their digits:");
   Put(Total_Sum);
   New_Line;
end Euler_30;
```

## Explanation

The solution works as follows:

1. **Problem Understanding**: We need to find numbers where the number equals the sum of its digits raised to the 5th power.

2. **Upper Bound Calculation**: 
   - For a 6-digit number, the maximum possible sum is 6 × 9⁵ = 354,294
   - For any number greater than this, it's impossible for the sum of fifth powers of digits to equal the number itself
   - We start from 2 since 1¹⁵ = 1 doesn't count (we want numbers that are sums of at least two digits)

3. **Algorithm**:
   - For each number from 2 to 354,294:
     - Calculate the sum of fifth powers of its digits
     - If this sum equals the original number, add it to our total

4. **Key Functions**:
   - `Sum_Of_Powers`: Extracts each digit and computes the sum of fifth powers
   - The main loop checks all candidates and accumulates valid numbers
