# Euler Problem 149 - Searching for a maximum-sum subsequence

I'll solve this step by step in Ada.

## Problem Understanding

We need to find the maximum sum of a contiguous subsequence in a 2000×2000 grid where each cell is generated using a specific formula. The grid contains 2000² elements, and we must check all possible directions for contiguous subsequences.

## Solution Approach

1. Generate the 2000×2000 grid using the given formula
2. Check all possible directions: horizontal, vertical, and both diagonals
3. For each direction, find the maximum sum of any contiguous subsequence
4. Return the overall maximum

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_149 is
   
   -- Constants
   N : constant Integer := 2000;
   
   -- Generate the grid using the formula
   function Generate_Grid return array (1..N, 1..N) of Long_Long_Integer is
      Grid : array (1..N, 1..N) of Long_Long_Integer;
      s : Long_Long_Integer := 0;
      
      -- Helper function to generate next value in sequence
      function Next_Value return Long_Long_Integer is
         temp : Long_Long_Integer;
      begin
         s := (s + 1) mod 1000000;
         temp := (615949 * s + 797807) mod 1000000;
         return temp - 500000;
      end Next_Value;
      
   begin
      for i in 1..N loop
         for j in 1..N loop
            Grid(i,j) := Next_Value;
         end loop;
      end loop;
      return Grid;
   end Generate_Grid;
   
   -- Function to find maximum subsequence sum in a given direction
   function Max_Subsequence_Sum(Grid : array (1..N, 1..N) of Long_Long_Integer;
                               Direction : Integer) return Long_Long_Integer is
      Max_Sum : Long_Long_Integer := Long_Long_Integer'First;
      Current_Sum : Long_Long_Integer := 0;
      
      -- Direction 1: Horizontal (left to right)
      -- Direction 2: Vertical (top to bottom)  
      -- Direction 3: Diagonal (top-left to bottom-right)
      -- Direction 4: Diagonal (top-right to bottom-left)
      
   begin
      case Direction is
         when 1 => -- Horizontal
            for i in 1..N loop
               Current_Sum := 0;
               for j in 1..N loop
                  Current_Sum := Current_Sum + Grid(i,j);
                  if Current_Sum > Max_Sum then
                     Max_Sum := Current_Sum;
                  end if;
                  if Current_Sum < 0 then
                     Current_Sum := 0;
                  end if;
               end loop;
            end loop;
            
         when 2 => -- Vertical
            for j in 1..N loop
               Current_Sum := 0;
               for i in 1..N loop
                  Current_Sum := Current_Sum + Grid(i,j);
                  if Current_Sum > Max_Sum then
                     Max_Sum := Current_Sum;
                  end if;
                  if Current_Sum < 0 then
                     Current_Sum := 0;
                  end if;
               end loop;
            end loop;
            
         when 3 => -- Diagonal (top-left to bottom-right)
            for k in 1..2*N-1 loop
               Current_Sum := 0;
               for i in 1..N loop
                  declare
                     j : constant Integer := k - i + 1;
                  begin
                     if j >= 1 and then j <= N then
                        Current_Sum := Current_Sum + Grid(i,j);
                        if Current_Sum > Max_Sum then
                           Max_Sum := Current_Sum;
                        end if;
                        if Current_Sum < 0 then
                           Current_Sum := 0;
                        end if;
                     end if;
                  end;
               end loop;
            end loop;
            
         when 4 => -- Diagonal (top-right to bottom-left)
            for k in 1..2*N-1 loop
               Current_Sum := 0;
               for i in 1..N loop
                  declare
                     j : constant Integer := k - i + N;
                  begin
                     if j >= 1 and then j <= N then
                        Current_Sum := Current_Sum + Grid(i,j);
                        if Current_Sum > Max_Sum then
                           Max_Sum := Current_Sum;
                        end if;
                        if Current_Sum < 0 then
                           Current_Sum := 0;
                        end if;
                     end if;
                  end;
               end loop;
            end loop;
            
         when others => null;
      end case;
      
      return Max_Sum;
   end Max_Subsequence_Sum;
   
begin
   -- Generate the grid
   declare
      Grid : constant array (1..N, 1..N) of Long_Long_Integer := Generate_Grid;
      Max_Value : Long_Long_Integer := Long_Long_Integer'First;
      Temp : Long_Long_Integer;
   begin
      -- Check all four directions
      Temp := Max_Subsequence_Sum(Grid, 1); -- Horizontal
      if Temp > Max_Value then
         Max_Value := Temp;
      end if;
      
      Temp := Max_Subsequence_Sum(Grid, 2); -- Vertical
      if Temp > Max_Value then
         Max_Value := Temp;
      end if;
      
      Temp := Max_Subsequence_Sum(Grid, 3); -- Diagonal (top-left to bottom-right)
      if Temp > Max_Value then
         Max_Value := Temp;
      end if;
      
      Temp := Max_Subsequence_Sum(Grid, 4); -- Diagonal (top-right to bottom-left)
      if Temp > Max_Value then
         Max_Value := Temp;
      end if;
      
      Put_Line("Maximum sum of contiguous subsequence: ");
      Put(Max_Value, Width => 0);
      New_Line;
   end;
   
end Euler_149;
```

## Explanation

The solution works as follows:

1. **Grid Generation**: The `Generate_Grid` function creates a 2000×2000 grid where each element is generated using the formula:
   - s starts at 0
   - Each subsequent value is calculated as (615949 × s + 797807) mod 1000000
   - The final value is (generated_value - 500000)

2. **Maximum Subsequence Algorithm**: For each direction, we use a modified version of Kadane's algorithm to find the maximum sum of contiguous elements:
   - Keep track of current running sum
   - Reset sum to zero when it becomes negative
   - Track maximum sum encountered

3. **Direction Checking**:
   - **Horizontal**: Check each row
   - **Vertical**: Check each column  
   - **Diagonal 1**: Check diagonals from top-left to bottom-right
   - **Diagonal 2**: Check diagonals from top-right to bottom-left

## Optimization Notes

The algorithm uses Kadane's algorithm for efficiency, which runs in O(n) time for each direction, making the overall complexity manageable even for a 2000×2000 grid.
