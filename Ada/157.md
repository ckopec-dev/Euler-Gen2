# Euler Problem 157 Solution in Ada

This problem asks us to find the number of solutions to the equation 1/x + 1/y = p/q where x, y, p, q are positive integers and p ≤ q.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Long_Long_Integer_Text_IO; use Ada.Long_Long_Integer_Text_IO;

procedure Euler_157 is
   
   type Long_Long is new Long_Long_Integer;
   
   function GCD(a, b : Long_Long) return Long_Long is
   begin
      if b = 0 then
         return a;
      else
         return GCD(b, a mod b);
      end if;
   end GCD;
   
   function Count_Solutions(p, q : Long_Long) return Long_Long is
      -- We need to count solutions to 1/x + 1/y = p/q
      -- This transforms to (p*q - x*q - x*p) = x*y*p*q
      -- Or equivalently: (p*q - x*p) * q = x*y*p*q
      -- Simplifying: q*(p*q - x*p) = x*y*p*q
      -- Further: p*q*q - x*p*q = x*y*p*q
      -- Rearranging: p*q*q = x*y*p*q + x*p*q
      -- Factoring: p*q*q = x*q*(y*p + p)
      -- Simplifying: p*q = x*(y*p + p)
      -- Which gives us: p*q = x*p*(y + 1)
      -- So: q = x*(y + 1)
      -- Therefore: x = q / (y + 1)
      
      -- Alternative approach:
      -- From 1/x + 1/y = p/q we get (x+y)/(x*y) = p/q
      -- So q*(x+y) = p*x*y
      -- This gives us: q*x + q*y = p*x*y
      -- Rearranging: q*x = p*x*y - q*y = y*(p*x - q)
      -- So: q*x = y*(p*x - q)
      -- If we solve for y: y = q*x / (p*x - q)
      
      -- For valid solutions, we need:
      -- 1. x > 0 and y > 0
      -- 2. p*x - q > 0 (so x > q/p)  
      -- 3. q*x must be divisible by (p*x - q)
      
      count : Long_Long := 0;
      max_x : constant Long_Long := q * p;  -- Upper bound for x
   begin
      -- We can also derive that x*y = p*q/(p*q - q) = p*q/(q*(p-1)) = p/(p-1) when simplified
      -- But let's use a more direct approach
      
      -- The equation 1/x + 1/y = p/q transforms to:
      -- xy = pq/(p-q) when we rearrange properly, but this is not correct.
      
      -- Correct approach: 1/x + 1/y = p/q
      -- (x+y)/(xy) = p/q  
      -- q(x+y) = p(xy)
      -- qx + qy = pxy
      -- qx - pxy = -qy
      -- x(q - py) = -qy
      -- x(q - py) = -qy
      -- x(py - q) = qy
      -- x = qy / (py - q)
      
      -- For integer solutions, we need (py - q) to divide qy
      -- And x must be positive, so py > q
      
      -- Let's use: y = q*x / (p*x - q) where p*x > q and (p*x - q) divides q*x
      for x in 1..max_x loop
         declare
            numerator : constant Long_Long := q * x;
            denominator : constant Long_Long := p * x - q;
         begin
            if denominator /= 0 and then numerator mod denominator = 0 then
               declare
                  y : constant Long_Long := numerator / denominator;
               begin
                  if y > 0 then
                     count := count + 1;
                  end if;
               end;
            end if;
         end;
      end loop;
      
      return count;
   end Count_Solutions;
   
   function Count_Solutions_Improved(p, q : Long_Long) return Long_Long is
      -- A more efficient approach:
      -- From 1/x + 1/y = p/q we get: xy = pq/(p-q)*q when rearranged incorrectly
      -- Actually, let's start fresh:
      -- 1/x + 1/y = p/q 
      -- (x+y)/(xy) = p/q  
      -- q(x+y) = pxy
      -- qx + qy = pxy  
      -- qx - pxy = -qy
      -- x(q - py) = -qy
      -- x(py - q) = qy
      -- x = qy / (py - q)
      
      -- For x to be positive integer, we need:
      -- 1. py > q  
      -- 2. (py - q) divides qy
      -- 3. x = qy / (py - q) is a positive integer
      
      count : Long_Long := 0;
   begin
      -- Let's think of it another way:
      -- If we rearrange: q(x+y) = pxy
      -- This can be written as: xy - (q/p)x - (q/p)y = 0  
      -- Adding (q/p)² to both sides: xy - (q/p)x - (q/p)y + (q/p)² = (q/p)²
      -- (x - q/p)(y - q/p) = (q/p)²
      -- (px - q)(py - q) = q²
      -- So px - q = d where d is a divisor of q²
      -- Then px = d + q, so x = (d+q)/p  
      -- And py - q = q²/d, so y = (q²/d + q)/p = q(q + d)/(dp)
      
      -- For positive integer solutions:
      -- 1. d must be a divisor of q²
      -- 2. d + q must be divisible by p  
      -- 3. q + d must be divisible by d (which means q is divisible by d)
      -- Wait, let's restart properly.
      
      -- From (px - q)(py - q) = q²:
      -- Let d = px - q, then py - q = q²/d  
      -- So px = d + q and py = q²/d + q
      -- This gives us x = (d + q)/p and y = (q²/d + q)/p
      
      -- For x,y to be positive integers:
      -- 1. d + q divisible by p
      -- 2. q²/d + q divisible by p  
      -- 3. d > 0
      -- 4. d divides q²
      
      count := 0;
      
      for d in 1..q * q loop
         if (q * q) mod d = 0 then
            declare
               x : constant Long_Long := (d + q) / p;
               y : constant Long_Long := (q * q / d + q) / p;
            begin
               if (d + q) mod p = 0 and then (q * q / d + q) mod p = 0 and then 
                  x > 0 and then y > 0 and then (p * x) * (p * y) = (p * x + p * y) * q then
                  count := count + 1;
               end if;
            end;
         end if;
      end loop;
      
      return count;
   end Count_Solutions_Improved;
   
   function Count_Solutions_Better(p, q : Long_Long) return Long_Long is
      -- Let's derive properly:
      -- 1/x + 1/y = p/q
      -- (x+y)/(xy) = p/q
      -- q(x+y) = pxy  
      -- qx + qy = pxy
      -- qx - pxy = -qy
      -- x(q - py) = -qy
      -- x(p y - q) = qy
      -- x = qy / (py - q)
      
      -- For valid solutions:
      -- py > q and (py - q) divides qy
      -- Also x must be positive integer
      
      count : Long_Long := 0;
   begin
      -- Use the substitution approach:
      -- If we let d = py - q, then y = (d + q)/p and x = qy/d = q*(d+q)/(pd)
      
      -- The correct transformation:
      -- From q(x+y) = pxy, multiply by p: pq(x+y) = p²xy
      -- pqx + pqy = p²xy
      -- pqx - p²xy = -pqy  
      -- px(q - py) = -pqy
      -- x(pq - p²y) = -pqy
      -- x * p(q - py) = -pqy
      -- x(q - py) = -qy
      -- x(py - q) = qy
      -- x = qy / (py - q)
      
      for y in 1..(q * p + 10000) loop  -- reasonable upper bound
         declare
            numerator : constant Long_Long := q * y;
            denominator : constant Long_Long := p * y - q;
         begin
            if denominator /= 0 and then numerator mod denominator = 0 then
               declare
                  x : constant Long_Long := numerator / denominator;
               begin
                  if x > 0 and then y > 0 then
                     count := count + 1;
                  end if;
               end;
            end if;
         end;
      end loop;
      
      return count;
   end Count_Solutions_Better;
   
   -- Better mathematical approach:
   function Count_Solutions_Final(p, q : Long_Long) return Long_Long is
      total_count : Long_Long := 0;
   begin
      -- From 1/x + 1/y = p/q we get xy = (p*q)/(p-q) when rearranged incorrectly.
      -- Actually let's use the correct approach:
      -- (x+y)/(xy) = p/q => q(x+y) = pxy => qx + qy = pxy
      -- qx - pxy = -qy => x(q-py) = -qy => x(py-q) = qy => x = qy/(py-q)
      
      -- This means for a given y, x is integer if (py-q) divides qy.
      -- Also, we need py > q and x > 0.
      
      -- But there's an even better way:
      -- Let u = px - q, v = qy - q
      -- Then uv = q²  
      
      -- Or we can think of it as:
      -- From (x+y)/(xy) = p/q => q(x+y) = pxy => xy - (q/p)x - (q/p)y = 0
      -- Add (q/p)² to both sides: xy - (q/p)x - (q/p)y + (q/p)² = (q/p)²  
      -- (x-q/p)(y-q/p) = q²/p²
      -- So (px-q)(py-q) = q²
      
      -- The correct approach:
      -- From (px-q)(py-q) = q², we have that each factor divides q².
      -- For every divisor d of q² such that d = px - q, then px = d + q
      -- So x = (d+q)/p. Also py - q = q²/d, so y = (q²/d + q)/p
      
      -- But we want x and y to be positive integers:
      -- 1. d must be a divisor of q²  
      -- 2. d + q must be divisible by p
      -- 3. q²/d + q must be divisible by p
      -- 4. x = (d+q)/p > 0
      -- 5. y = (q²/d + q)/p > 0
      
      declare
         q_squared : constant Long_Long := q * q;
         divisors : array(1..1000) of Long_Long;
         num_divisors : Integer := 0;
      begin
         -- Find all divisors of q²  
         for i in 1..q_squared loop
            if q_squared mod i = 0 then
               num_divisors := num_divisors + 1;
               divisors(num_divisors) := i;
               if i * i /= q_squared then
                  num_divisors := num_divisors + 1;
                  divisors(num_divisors) := q_squared / i;
               end if;
            end if;
         end loop;
         
         -- Count valid solutions  
         for i in 1..num_divisors loop
            declare
               d : constant Long_Long := divisors(i);
            begin
               if (d + q) mod p = 0 and then (q_squared / d + q) mod p = 0 then
                  -- Verify that x and y are positive integers
                  declare
                     x : constant Long_Long := (d + q) / p;
                     y : constant Long_Long := (q_squared / d + q) / p;
                  begin
                     if x > 0 and then y > 0 then
                        total_count := total_count + 1;
                     end if;
                  end;
               end if;
            end;
         end loop;
      end;
      
      return total_count;
   end Count_Solutions_Final;
   
   result : Long_Long := 0;
   
begin
   -- Let's calculate for all p/q where p <= q and both are between 1 and 1000
   for p in 1..1000 loop
      for q in p..1000 loop
         declare
            gcd_val : constant Long_Long := GCD(p, q);
         begin
            if gcd_val = 1 then  -- We only count reduced fractions
               result := result + Count_Solutions_Final(p, q);
            end if;
         end;
      end loop;
   end loop;
   
   Put("Result: ");
   Put(result, 0);
   New_Line;
   
end Euler_157;
```

The solution uses the mathematical transformation of the equation to find all valid solutions. The key insight is that we can rewrite the equation $1/x + 1/y = p/q$ as $(px - q)(py - q) = q^2$, which allows us to count solutions by considering divisors of $q^2$.
