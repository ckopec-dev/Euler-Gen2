# Euler Problem 153 Solution in Ada

This problem asks us to find the sum of all divisors of all numbers from 1 to N, where N = 999999.

Let me break down the approach:
- For each number i from 1 to N, we need to find all its divisors
- Sum all divisors across all numbers
- This can be optimized using the fact that each divisor d contributes to the sum for all multiples of d

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_153 is
   N : constant := 999_999;
   Total_Sum : Long_Long_Integer := 0;
   
   -- Function to compute sum of divisors for a given number
   function Sum_Of_Divisors(N : Integer) return Long_Long_Integer is
      Sum : Long_Long_Integer := 0;
      I : Integer;
   begin
      for I in 1 .. N loop
         if N mod I = 0 then
            Sum := Sum + Long_Long_Integer(I);
         end if;
      end loop;
      return Sum;
   end Sum_Of_Divisors;
   
begin
   -- Optimized approach: for each divisor d, it appears in all multiples of d
   -- So we can compute the sum by iterating through divisors and adding them
   -- to their respective multiples
   
   for I in 1 .. N loop
      declare
         D : Integer := 1;
         Sum : Long_Long_Integer := 0;
      begin
         while D * D <= I loop
            if I mod D = 0 then
               Sum := Sum + Long_Long_Integer(D);
               if D * D /= I then
                  Sum := Sum + Long_Long_Integer(I / D);
               end if;
            end if;
            D := D + 1;
         end loop;
         Total_Sum := Total_Sum + Sum;
      end;
   end loop;
   
   Put_Line("Result: " & Long_Long_Integer'Image(Total_Sum));
end Euler_153;
```

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_153 is
   N : constant := 999_999;
   Total_Sum : Long_Long_Integer := 0;
   
begin
   -- For each number d from 1 to N, it appears as a divisor in all multiples of d
   -- So we count how many times each number d contributes to the sum:
   -- d contributes to the total sum exactly floor(N/d) times (once for each multiple)
   -- The contribution is d * floor(N/d)
   
   for D in 1 .. N loop
      Total_Sum := Total_Sum + Long_Long_Integer(D) * Long_Long_Integer(N / D);
   end loop;
   
   Put_Line("Result: " & Long_Long_Integer'Image(Total_Sum));
end Euler_153;
```

This solution uses the mathematical insight that:
- Each number d from 1 to N appears as a divisor in exactly floor(N/d) numbers
- Therefore, the total sum is Σ(d=1 to N) d × floor(N/d)
- This gives us O(N) time complexity instead of O(N log N)
