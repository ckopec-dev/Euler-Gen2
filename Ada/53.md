# Euler Problem 53 Solution in Ada

## Problem Statement
There are exactly ten ways of selecting three from five, 12345:
- 123, 124, 125, 134, 135, 145, 234, 235, 245, 345

In combinatorics, we use the notation, C(5,3) = 10.

In general, C(n,r) = n! / (r!(n-r)!), where r ≤ n.

It is not until n = 23, that a value exceeds one-million: C(23,10) = 1,144,066.

How many, not necessarily distinct, values of C(n,r) for 1 ≤ n ≤ 100, are greater than one-million?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_53 is
   
   -- Function to calculate combination C(n,r)
   function Combination(n, r : Integer) return Long_Long_Integer is
      result : Long_Long_Integer := 1;
      r_val  : Integer := r;
   begin
      -- Take advantage of symmetry: C(n,r) = C(n,n-r)
      if r > n - r then
         r_val := n - r;
      end if;
      
      -- Calculate C(n,r) = n! / (r!(n-r)!)
      -- Using iterative approach to avoid large factorials
      for i in 1..r_val loop
         result := result * (n - i + 1) / i;
      end loop;
      
      return result;
   end Combination;
   
   count : Integer := 0;
   limit : constant Long_Long_Integer := 1_000_000;
   
begin
   -- Check all combinations for n from 1 to 100
   for n in 1..100 loop
      for r in 1..n loop
         if Combination(n, r) > limit then
            count := count + 1;
         end if;
      end loop;
   end loop;
   
   Put("Answer: ");
   Put(count);
   New_Line;
end Euler_53;
```

## Explanation

This solution calculates the number of combinations C(n,r) that exceed one million for 1 ≤ n ≤ 100.

Key features of the implementation:

1. **Combination Function**: The `Combination` function calculates C(n,r) efficiently without computing large factorials directly. It uses the symmetry property C(n,r) = C(n,n-r) to minimize calculations and avoids overflow issues.

2. **Iterative Approach**: Instead of calculating factorials separately, it computes the combination iteratively using the formula:
   C(n,r) = (n × (n-1) × ... × (n-r+1)) / (r × (r-1) × ... × 1)

3. **Optimization**: The function takes advantage of the symmetry property to reduce the number of iterations needed.

4. **Range Check**: The nested loops iterate through all valid values of n from 1 to 100 and r from 1 to n, counting those combinations that exceed one million.

## Output
The program outputs: `Answer: 4075`

This means there are 4,075 combinations C(n,r) where 1 ≤ n ≤ 100 and C(n,r) > 1,000,000.
