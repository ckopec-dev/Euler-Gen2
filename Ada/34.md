# Euler Problem 34 Solution in Ada

Euler Problem 34 asks: "Find the sum of all numbers which are equal to the sum of the factorial of their digits."

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_34 is
   
   -- Function to calculate factorial
   function Factorial(N : Integer) return Integer is
      Result : Integer := 1;
   begin
      for I in 2..N loop
         Result := Result * I;
      end loop;
      return Result;
   end Factorial;
   
   -- Function to check if number equals sum of factorials of its digits
   function Is_Sum_Of_Factorials(N : Integer) return Boolean is
      Temp : Integer := N;
      Sum  : Integer := 0;
   begin
      while Temp > 0 loop
         Sum := Sum + Factorial(Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Sum = N;
   end Is_Sum_Of_Factorials;
   
   -- Precompute factorials for digits 0-9 (for efficiency)
   Factorials : array(0..9) of Integer :=
     (Factorial(0), Factorial(1), Factorial(2), Factorial(3),
      Factorial(4), Factorial(5), Factorial(6), Factorial(7),
      Factorial(8), Factorial(9));
   
   -- Function to check if number equals sum of factorials (using precomputed values)
   function Is_Sum_Of_Factorials_Fast(N : Integer) return Boolean is
      Temp : Integer := N;
      Sum  : Integer := 0;
   begin
      while Temp > 0 loop
         Sum := Sum + Factorials(Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Sum = N;
   end Is_Sum_Of_Factorials_Fast;
   
   Total_Sum : Integer := 0;
   
begin
   -- We need to find upper bound
   -- For a number with n digits, if each digit is 9, then:
   -- 10^(n-1) <= n * 9! = n * 362880
   -- So we need to find when 10^(n-1) > 362880 * n
   
   -- Check up to a reasonable limit (we can see that 7-digit numbers 
   -- cannot possibly satisfy the condition, so let's go up to 10^7)
   
   for I in 3..1000000 loop
      if Is_Sum_Of_Factorials_Fast(I) then
         Total_Sum := Total_Sum + I;
         Put_Line("Found: " & Integer'Image(I));
      end if;
   end loop;
   
   Put_Line("Sum of all numbers equal to sum of factorials of digits:");
   Put(Total_Sum);
   New_Line;
   
end Euler_34;
```

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_34 is
   
   -- Precompute factorials for digits 0-9
   Factorials : array(0..9) of Integer :=
     (1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880);
   
   -- Function to check if number equals sum of factorials of its digits
   function Is_Sum_Of_Factorials(N : Integer) return Boolean is
      Temp : Integer := N;
      Sum  : Integer := 0;
   begin
      while Temp > 0 loop
         Sum := Sum + Factorials(Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Sum = N;
   end Is_Sum_Of_Factorials;
   
   Total_Sum : Integer := 0;
   
begin
   -- We need to find all numbers where the sum of factorials of digits equals the number itself
   -- We know that for n-digit numbers, if each digit is 9, we have:
   -- 10^(n-1) <= n * 9! = n * 362880
   
   -- For n=7: 10^6 = 1000000 > 7*362880 = 2540160 (not true)
   -- For n=6: 10^5 = 100000 < 6*362880 = 2177280 (true)
   
   -- So we only need to check up to about 999999
   for I in 3..999999 loop
      if Is_Sum_Of_Factorials(I) then
         Total_Sum := Total_Sum + I;
         Put_Line("Found: " & Integer'Image(I));
      end if;
   end loop;
   
   Put_Line("Sum of all numbers equal to sum of factorials of digits:");
   Put(Total_Sum);
   New_Line;
   
end Euler_34;
```

The key insights for this problem are:

1. **Upper Bound**: For a number with n digits, we can establish that 10^(n-1) ≤ n × 9! (since the maximum digit is 9)
2. **Small numbers**: We don't need to check large numbers since they won't satisfy the condition
3. **Precomputed factorials**: It's more efficient to precompute factorials of digits 0-9

The answer is **40730**, which is the sum of 145 and 40585 (since 1! + 4! + 5! = 1 + 24 + 120 = 145, and 4! + 0! + 5! + 8! + 5! = 24 + 1 + 120 + 40320 + 120 = 40730).
