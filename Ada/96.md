# Euler Problem 96 Solution in Ada

This solution solves the Sudoku puzzle from Project Euler Problem 96 using backtracking algorithm.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;

procedure Euler_96 is
   
   type Grid is array (1..9, 1..9) of Integer;
   
   -- Read a Sudoku grid from input
   procedure Read_Grid(G : out Grid) is
      Line : Unbounded_String;
   begin
      for I in 1..9 loop
         Line := Get_Line;
         for J in 1..9 loop
            G(I, J) := Integer'Value(Element(Line, J));
         end loop;
      end loop;
   end Read_Grid;
   
   -- Check if placing a value at position (I,J) is valid
   function Is_Valid(G : Grid; I, J, Value : Integer) return Boolean is
      -- Check row
      Row_Valid : Boolean := True;
      -- Check column
      Col_Valid : Boolean := True;
      -- Check 3x3 box
      Box_Valid : Boolean := True;
   begin
      for K in 1..9 loop
         if G(I, K) = Value then
            Row_Valid := False;
         end if;
         if G(K, J) = Value then
            Col_Valid := False;
         end if;
      end loop;
      
      -- Check 3x3 box
      declare
         Box_Row : constant Integer := ((I - 1) / 3) * 3 + 1;
         Box_Col : constant Integer := ((J - 1) / 3) * 3 + 1;
      begin
         for I2 in Box_Row..Box_Row + 2 loop
            for J2 in Box_Col..Box_Col + 2 loop
               if G(I2, J2) = Value then
                  Box_Valid := False;
               end if;
            end loop;
         end loop;
      end;
      
      return Row_Valid and Col_Valid and Box_Valid;
   end Is_Valid;
   
   -- Solve the Sudoku puzzle using backtracking
   function Solve_Grid(G : in out Grid) return Boolean is
      I, J : Integer;
      Found : Boolean := False;
   begin
      -- Find empty cell
      for I in 1..9 loop
         for J in 1..9 loop
            if G(I, J) = 0 then
               Found := True;
               exit;
            end if;
         end loop;
         exit when Found;
      end loop;
      
      -- If no empty cell found, puzzle is solved
      if not Found then
         return True;
      end if;
      
      -- Try values 1-9
      for Value in 1..9 loop
         if Is_Valid(G, I, J, Value) then
            G(I, J) := Value;
            
            if Solve_Grid(G) then
               return True;
            end if;
            
            G(I, J) := 0; -- Backtrack
         end if;
      end loop;
      
      return False;
   end Solve_Grid;
   
   -- Calculate the sum of first three digits of the top-left corner
   function Get_Top_Left_Corner(G : Grid) return Integer is
   begin
      return G(1, 1) * 100 + G(1, 2) * 10 + G(1, 3);
   end Get_Top_Left_Corner;
   
   procedure Process_Puzzle(Puzzle_Num : Integer) is
      Grid_Data : Grid;
      Solution : Integer;
   begin
      -- Read the puzzle number line (we don't actually use it)
      declare
         Line : Unbounded_String := Get_Line;
      begin
         null;  -- Just read and discard
      end;
      
      Read_Grid(Grid_Data);
      
      if Solve_Grid(Grid_Data) then
         Solution := Get_Top_Left_Corner(Grid_Data);
         Put("Puzzle "); Put(Puzzle_Num, 0); Put(": ");
         Put(Solution, 0); New_Line;
      else
         Put("Puzzle "); Put(Puzzle_Num, 0); Put(": No solution found"); New_Line;
      end if;
   end Process_Puzzle;
   
begin
   -- Process all 50 puzzles (we'll use a simple loop)
   for Puzzle_Num in 1..50 loop
      Process_Puzzle(Puzzle_Num);
   end loop;
end Euler_96;
```

This solution implements:

1. **Grid Representation**: Uses a 9x9 array to represent the Sudoku grid
2. **Input Reading**: Reads puzzle data from standard input
3. **Validation Function**: Checks if placing a number in a cell is valid according to Sudoku rules (row, column, and 3x3 box constraints)
4. **Backtracking Algorithm**: Solves the puzzle using recursive backtracking
5. **Result Extraction**: Extracts the top-left 3-digit number from the solved puzzle

The algorithm works by:
1. Finding an empty cell (containing 0)
2. Trying numbers 1-9 in that cell
3. Checking if the placement is valid
4. Recursively solving the rest of the puzzle
5. Backtracking if no solution is found with current placement

The time complexity is exponential in worst case, but backtracking significantly reduces the search space through pruning.
