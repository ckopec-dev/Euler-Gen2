# Euler Problem 52 Solution in Ada

## Problem Statement
It can be seen that the number 125874 and its double 251748 contain exactly the same digits, but in a different order. Find the smallest positive integer x such that 2x, 3x, 4x, 5x, and 6x contain the same digits.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_52 is
   
   -- Function to check if two numbers have the same digits
   function Same_Digits(N1, N2 : Integer) return Boolean is
      Digit_Count1 : array (0..9) of Integer := (others => 0);
      Digit_Count2 : array (0..9) of Integer := (others => 0);
      Temp1, Temp2 : Integer;
   begin
      -- Count digits in first number
      Temp1 := N1;
      if Temp1 = 0 then
         Digit_Count1(0) := 1;
      else
         while Temp1 > 0 loop
            Digit_Count1(Temp1 mod 10) := Digit_Count1(Temp1 mod 10) + 1;
            Temp1 := Temp1 / 10;
         end loop;
      end if;
      
      -- Count digits in second number
      Temp2 := N2;
      if Temp2 = 0 then
         Digit_Count2(0) := 1;
      else
         while Temp2 > 0 loop
            Digit_Count2(Temp2 mod 10) := Digit_Count2(Temp2 mod 10) + 1;
            Temp2 := Temp2 / 10;
         end loop;
      end if;
      
      -- Compare digit counts
      for I in 0..9 loop
         if Digit_Count1(I) /= Digit_Count2(I) then
            return False;
         end if;
      end loop;
      
      return True;
   end Same_Digits;
   
   -- Function to check if a number and its multiples have same digits
   function Valid_Number(N : Integer) return Boolean is
   begin
      for Multiplier in 2..6 loop
         if not Same_Digits(N, N * Multiplier) then
            return False;
         end if;
      end loop;
      return True;
   end Valid_Number;
   
   X : Integer := 1;
   
begin
   loop
      if Valid_Number(X) then
         Put_Line("Answer: " & Integer'Image(X));
         exit;
      end if;
      X := X + 1;
   end loop;
end Euler_52;
```

## Explanation

This solution works by:

1. **Same_Digits function**: Takes two integers and determines if they contain exactly the same digits by:
   - Counting the frequency of each digit (0-9) in both numbers
   - Comparing these counts to see if they match

2. **Valid_Number function**: Checks if a given number has the property that its multiples 2x through 6x contain the same digits

3. **Main loop**: Starting from 1, incrementally checks each number until we find one that satisfies the condition

## Key Features

- **Digit counting approach**: Instead of sorting digits, we count occurrences of each digit
- **Efficient comparison**: Uses arrays to track digit frequencies rather than string manipulation
- **Clear structure**: Separates concerns into helper functions for readability
