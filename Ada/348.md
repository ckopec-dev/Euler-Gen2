Let me provide a simpler and more efficient version:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_348 is
   Max_Search : constant Integer := 1000000;
   Count : array (1..Max_Search) of Integer := (others => 0);
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(N : Integer) return Boolean is
      Root : Integer := Integer(Sqrt(Float(N)));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
begin
   -- Find all numbers that can be expressed as sum of cube and square in exactly 4 ways
   for I in 1..Integer(Sqrt(Float(Max_Search))) loop
      declare
         Cube : constant Integer := I * I * I;
      begin
         for J in 0..Integer(Sqrt(Float(Max_Search - Cube))) loop
            declare
               Sum : constant Integer := Cube + J * J;
            begin
               if Sum <= Max_Search then
                  Count(Sum) := Count(Sum) + 1;
               end if;
            end;
         end loop;
      end;
   end loop;
   
   -- Collect numbers that can be expressed in exactly 4 ways
   Put_Line("Numbers that can be expressed as sum of cube and square in exactly 4 ways:");
   declare
      Total_Sum : Integer := 0;
      Found_Count : Integer := 0;
   begin
      for I in 1..Max_Search loop
         if Count(I) = 4 then
            Put(Integer'Image(I));
            Total_Sum := Total_Sum + I;
            Found_Count := Found_Count + 1;
            
            -- Output every 5th number for readability
            if Found_Count mod 5 = 0 then
               New_Line;
            else
               Put(" ");
            end if;
            
            -- Stop after finding first few (the problem asks for sum of first few)
            exit when Found_Count >= 5;
         end if;
      end loop;
      
      New_Line;
      Put_Line("Sum of these numbers: " & Integer'Image(Total_Sum));
   end;
   
end Euler_348;
```

## Solution Analysis

The solution works by:

1. **Iterating through possible cubes**: For each integer I, compute I³
2. **For each cube, iterate through possible squares**: For each J from 0 to √(Max_Search - I³), compute I³ + J²
3. **Counting representations**: Keep track of how many ways each number can be represented as sum of cube and square
4. **Finding those with exactly 4 representations**: Collect numbers that have exactly 4 different ways to be expressed as sum of cube and square

The answer is the sum of the first few such numbers (typically 5 numbers are required). 

## Final Answer
