# Euler Problem 38 Solution in Ada

## Problem Statement
Take the number 192 and multiply it by each of 1, 2, and 3:
- 192 × 1 = 192
- 192 × 2 = 384
- 192 × 3 = 576

By concatenating each product we get the 1 to 9 pandigital, 192384576. We will call 192384576 the concatenated product of 192 and (1,2,3).

The same can be achieved by starting with 9 and multiplying by 1, 2, 3, 4, and 5, giving the pandigital, 918273645, which is the concatenated product of 9 and (1,2,3,4,5).

What is the largest 1 to 9 pandigital 9-digit number that can be formed as the concatenated product of an integer with (1,2, ..., n) where n > 1?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_38 is
   
   function Is_Pandigital(Number : in String) return Boolean is
      -- Check if a string represents a 1-9 pandigital number
      Digit_Count : array (1..9) of Natural := (others => 0);
      Length : constant Natural := Number'Length;
   begin
      -- Must be exactly 9 digits
      if Length /= 9 then
         return False;
      end if;
      
      -- Count each digit
      for I in Number'Range loop
         declare
            Digit : constant Natural := Character'Pos(Number(I)) - Character'Pos('0');
         begin
            if Digit = 0 or else Digit > 9 then
               return False;  -- Invalid digit
            end if;
            Digit_Count(Digit) := Digit_Count(Digit) + 1;
         end;
      end loop;
      
      -- Check that each digit 1-9 appears exactly once
      for I in 1..9 loop
         if Digit_Count(I) /= 1 then
            return False;
         end if;
      end loop;
      
      return True;
   end Is_Pandigital;
   
   function Concatenated_Product(Number : in Natural; N : in Positive) return String is
      -- Calculate concatenated product of Number with (1,2,...,N)
      Result : String(1..9) := (others => '0');
      Position : Natural := 1;
   begin
      for I in 1..N loop
         declare
            Product : constant Natural := Number * I;
            Product_String : String := Integer'Image(Product);
         begin
            -- Remove leading space from Image function
            if Product_String(1) = ' ' then
               Product_String := Product_String(2..Product_String'Last);
            end if;
            
            -- Copy digits to result string
            for J in Product_String'Range loop
               if Position <= 9 then
                  Result(Position) := Product_String(J);
                  Position := Position + 1;
               else
                  return Result(1..Position-1);  -- Should not happen in valid cases
               end if;
            end loop;
         end;
      end loop;
      
      return Result;
   end Concatenated_Product;
   
   Max_Pandigital : Natural := 0;
   
begin
   -- We need to find the maximum pandigital number
   -- The concatenated product must be exactly 9 digits long
   -- Since we're concatenating at least 2 products, we can't start with numbers > 9876
   -- (because 9876 * 1 = 9876, and 9876 * 2 = 19752, total length would be 9+5=14 digits)
   
   for Num in 1..9876 loop
      -- Try different values of N (number of multiplications)
      for N in 2..9 loop
         declare
            Concatenated : String := Concatenated_Product(Num, N);
         begin
            if Concatenated'Length = 9 and then Is_Pandigital(Concatenated) then
               declare
                  Value : constant Natural := Integer'Value(Concatenated);
               begin
                  if Value > Max_Pandigital then
                     Max_Pandigital := Value;
                  end if;
               end;
            end if;
         end;
      end loop;
   end loop;
   
   Put("The largest 1-9 pandigital number is: ");
   Put(Max_Pandigital);
   New_Line;
end Euler_38;
```

## Explanation

This solution works by:

1. **Checking for pandigital numbers**: The `Is_Pandigital` function verifies that a 9-digit string contains each digit from 1 to 9 exactly once.

2. **Generating concatenated products**: The `Concatenated_Product` function takes a number and a count N, then multiplies the number by 1, 2, ..., N and concatenates the results.

3. **Iterating through possibilities**: We iterate through potential starting numbers (from 1 to 9876) and different values of N (from 2 to 9) to find valid concatenated products.

4. **Optimization**: Since we want a 9-digit result, and we're concatenating at least 2 products, we don't need to check numbers larger than 9876 (as that would produce too many digits).

The key insight is that for any number with more than 4 digits, when multiplied by 2, it will produce a 5+ digit result, making the concatenated total exceed 9 digits. So we only need to check up to 9876.

## Result
The largest 1-9 pandigital number formed this way is **932718654**.
