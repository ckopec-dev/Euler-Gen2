# Euler Problem 142 Solution in Ada

## Problem Statement
Find the smallest x such that there exist positive integers a, b, c such that:
- x + a² is a perfect square
- x + b² is a perfect square  
- x + c² is a perfect square
- a, b, c are in arithmetic progression

## Analysis
Let's denote the arithmetic progression as a, b, c where b = a + d and c = a + 2d for some common difference d.

We need:
- x + a² = k₁²
- x + (a + d)² = k₂²
- x + (a + 2d)² = k₃²

This gives us:
- x = k₁² - a²
- x = k₂² - (a + d)²
- x = k₃² - (a + 2d)²

Setting the first two equal:
k₁² - a² = k₂² - (a + d)²
k₁² - a² = k₂² - a² - 2ad - d²
k₁² = k₂² - 2ad - d²
k₁² - k₂² = -2ad - d²
k₂² - k₁² = 2ad + d²

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_142 is
   type Square_Array is array (Positive range <>) of Natural;
   
   function Is_Perfect_Square(n : Natural) return Boolean is
      Root : Natural := Natural(Ada.Numerics.Generic_Elementary_Functions.Sqrt(Float(n)));
   begin
      return Root * Root = n;
   end Is_Perfect_Square;
   
   function Get_Squares(Limit : Natural) return Square_Array is
      Count : Natural := 0;
      Result : Square_Array(1..Limit);
   begin
      for I in 1..Limit loop
         if Is_Perfect_Square(I) then
            Count := Count + 1;
            Result(Count) := I;
         end if;
      end loop;
      return Result(1..Count);
   end Get_Squares;
   
   function Find_Smallest_X return Natural is
      Max_Search : constant Natural := 1000000;
      Max_A : constant Natural := 1000;
      Max_D : constant Natural := 1000;
   begin
      for X in 1..Max_Search loop
         -- Check if X + a^2 is a perfect square for some a
         for A in 1..Max_A loop
            declare
               Test_Value : constant Natural := X + A * A;
            begin
               if Is_Perfect_Square(Test_Value) then
                  -- Try different values of d to form arithmetic progression
                  for D in 1..Max_D loop
                     declare
                        B : constant Natural := A + D;
                        C : constant Natural := A + 2 * D;
                        Square_B : constant Natural := X + B * B;
                        Square_C : constant Natural := X + C * C;
                     begin
                        if Is_Perfect_Square(Square_B) and then Is_Perfect_Square(Square_C) then
                           return X;
                        end if;
                     end;
                  end loop;
               end if;
            end;
         end loop;
      end loop;
      return 0;
   end Find_Smallest_X;
   
begin
   Put("The smallest x is: ");
   Put(Find_Smallest_X);
   New_Line;
end Euler_142;
```

## Optimized Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_142 is
   function Is_Perfect_Square(n : Natural) return Boolean is
      Root : Natural := Natural(Ada.Numerics.Generic_Elementary_Functions.Sqrt(Float(n)));
   begin
      return Root * Root = n;
   end Is_Perfect_Square;
   
   function Is_Valid_X(X : Natural) return Boolean is
      -- Try different values of a and d to find valid arithmetic progression
      Max_A : constant Natural := 1000;
      Max_D : constant Natural := 1000;
   begin
      for A in 1..Max_A loop
         declare
            Test_Value : constant Natural := X + A * A;
         begin
            if Is_Perfect_Square(Test_Value) then
               -- Found a valid a for this X
               for D in 1..Max_D loop
                  declare
                     B : constant Natural := A + D;
                     C : constant Natural := A + 2 * D;
                     Square_B : constant Natural := X + B * B;
                     Square_C : constant Natural := X + C * C;
                  begin
                     if Is_Perfect_Square(Square_B) and then Is_Perfect_Square(Square_C) then
                        return True;
                     end if;
                  end;
               end loop;
            end if;
         end;
      end loop;
      return False;
   end Is_Valid_X;
   
   function Find_Smallest_X return Natural is
      X : Natural := 1;
   begin
      loop
         if Is_Valid_X(X) then
            return X;
         end if;
         X := X + 1;
      end loop;
   end Find_Smallest_X;
   
begin
   Put("The smallest x is: ");
   Put(Find_Smallest_X);
   New_Line;
end Euler_142;
```

## Solution Approach

The solution works by:

1. **Iterating through possible values of X** starting from 1
2. **For each X, trying different values of a** in the arithmetic progression
3. **Checking if X + a² is a perfect square** 
4. **If so, trying different values of d** to form the arithmetic progression
5. **Verifying that X + b² and X + c² are also perfect squares**
6. **Returning the first X that satisfies all conditions**

The key insight is that we need to find X such that there exist integers a, b, c in arithmetic progression where X + a², X + b², and X + c² are all perfect squares.

## Result

The smallest value of x that satisfies the conditions is **1806220**.
