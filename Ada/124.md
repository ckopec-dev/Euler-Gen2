# Euler Problem 124 Solution in Ada

## Problem Statement
The radical of n, rad(n), is the product of the distinct prime factors of n. For example:
- rad(12) = 2 × 3 = 6
- rad(30) = 2 × 3 × 5 = 30

We are to find the value of n for which rad(n) is the smallest among all n ≤ 100000.

## Solution Approach
1. Calculate the radical of each number from 1 to 100000
2. Sort numbers by their radical values
3. Return the n at position 10000 (1-indexed)

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;
with Ada.Synchronous_Task_Control;

procedure Euler_124 is
   
   type Radical_Pair is record
      Number : Natural;
      Radical : Natural;
   end record;
   
   package Radical_Vector is new Ada.Containers.Vectors
     (Index_Type => Positive, Element_Type => Radical_Pair);
   
   procedure Calculate_Radical (N : in out Natural);
   
   Max_Value : constant := 100_000;
   Radicals : Radical_Vector.Vector;
   
   -- Function to compute greatest common divisor
   function GCD (A, B : Natural) return Natural is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Function to compute radical of a number
   function Rad (N : Natural) return Natural is
      Result : Natural := 1;
      Temp_N : Natural := N;
   begin
      if N = 0 then
         return 0;
      elsif N = 1 then
         return 1;
      end if;
      
      -- Check for factor 2
      if Temp_N mod 2 = 0 then
         Result := Result * 2;
         while Temp_N mod 2 = 0 loop
            Temp_N := Temp_N / 2;
         end loop;
      end if;
      
      -- Check for odd factors from 3 onwards
      for I in 3 .. Integer(sqrt(Float(Temp_N))) loop
         if Temp_N mod I = 0 then
            Result := Result * I;
            while Temp_N mod I = 0 loop
               Temp_N := Temp_N / I;
            end loop;
         end if;
      end loop;
      
      -- If Temp_N > 1, then it's a prime factor
      if Temp_N > 1 then
         Result := Result * Temp_N;
      end if;
      
      return Result;
   end Rad;
   
   -- Procedure to sort the vector by radical values
   procedure Sort_By_Radical is
      procedure Swap (I, J : Positive) is
         Temp : Radical_Pair := Radicals.Element(I);
      begin
         Radicals.Replace_Element(I, Radicals.Element(J));
         Radicals.Replace_Element(J, Temp);
      end Swap;
      
      procedure Quick_Sort (Low, High : Positive) is
         Pivot : Positive;
         I, J : Positive;
      begin
         if Low < High then
            Pivot := Low;
            I := Low;
            J := High;
            
            while I < J loop
               while I < High and then Radicals.Element(I).Radical <= Radicals.Element(Pivot).Radical loop
                  I := I + 1;
               end loop;
               
               while J > Low and then Radicals.Element(J).Radical >= Radicals.Element(Pivot).Radical loop
                  J := J - 1;
               end loop;
               
               if I < J then
                  Swap(I, J);
               end if;
            end loop;
            
            Swap(Pivot, J);
            Quick_Sort(Low, J - 1);
            Quick_Sort(J + 1, High);
         end if;
      end Quick_Sort;
   begin
      Quick_Sort(1, Radicals.Length);
   end Sort_By_Radical;
   
begin
   -- Initialize the vector with numbers and their radicals
   for I in 1 .. Max_Value loop
      Radicals.Append((Number => I, Radical => Rad(I)));
   end loop;
   
   -- Sort by radical value
   Sort_By_Radical;
   
   -- Output the result (10000th element)
   Put_Line("The value of n for which rad(n) is smallest among all n ≤ 100000:");
   Put(Radicals.Element(10000).Number);
   New_Line;
   
end Euler_124;
```

## Explanation

This Ada program:

1. **Defines a data structure** `Radical_Pair` to hold both the number and its radical value
2. **Implements the radical calculation function** `Rad` that:
   - First handles special cases (0 and 1)
   - Factors out all 2s from the number
   - Then checks odd numbers starting from 3 up to √n
   - Multiplies distinct prime factors together
3. **Populates a vector** with all numbers 1 to 100000 along with their radical values
4. **Sorts the vector** by radical value using a quicksort algorithm
5. **Outputs the result** which is the 10000th element (1-indexed)

## Time Complexity
- Computing radicals for all numbers: O(n√n)
- Sorting: O(n log n)
- Overall: O(n√n)

The answer to Euler Problem 124 is **21417**.
