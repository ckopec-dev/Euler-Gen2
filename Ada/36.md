# Euler Problem 36 Solution in Ada

Euler Problem 36 asks for the sum of all numbers less than one million that are palindromic in both base 10 and base 2.

## Analysis
- Need to check each number from 1 to 999,999
- For each number, verify if it's palindromic in base 10
- If yes, also check if it's palindromic in base 2
- Sum all numbers that satisfy both conditions

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_36 is
   
   -- Function to check if a string is palindromic
   function Is_Palindrome(S : String) return Boolean is
      Left  : Natural := S'First;
      Right : Natural := S'Last;
   begin
      while Left < Right loop
         if S(Left) /= S(Right) then
            return False;
         end if;
         Left  := Left + 1;
         Right := Right - 1;
      end loop;
      return True;
   end Is_Palindrome;
   
   -- Function to convert integer to binary string
   function To_Binary(N : Natural) return String is
      Result : String(1..32); -- Enough for 2^20
      Pos    : Integer := Result'Last;
      Temp   : Natural := N;
   begin
      if N = 0 then
         return "0";
      end if;
      
      while Temp > 0 loop
         if Temp mod 2 = 0 then
            Result(Pos) := '0';
         else
            Result(Pos) := '1';
         end if;
         Temp := Temp / 2;
         Pos := Pos - 1;
      end loop;
      
      return Result(Pos+1..Result'Last);
   end To_Binary;
   
   Sum : Natural := 0;
   
begin
   for I in 1..999_999 loop
      -- Check if decimal representation is palindromic
      if Is_Palindrome(Integer'Image(I)) then
         -- Check if binary representation is palindromic
         declare
            Binary_Str : constant String := To_Binary(I);
         begin
            if Is_Palindrome(Binary_Str) then
               Sum := Sum + I;
            end if;
         end;
      end if;
   end loop;
   
   Put_Line("Sum: " & Natural'Image(Sum));
end Euler_36;
```

## Key Features of the Solution

1. **Palindrome Check**: The `Is_Palindrome` function uses two pointers moving from both ends toward the center to efficiently check palindromes.

2. **Binary Conversion**: The `To_Binary` function converts integers to their binary string representation without using built-in conversion functions.

3. **Memory Management**: Uses fixed-size arrays with proper bounds checking for binary string conversion.

4. **Efficiency**: Only processes numbers up to 999,999 as specified in the problem.
