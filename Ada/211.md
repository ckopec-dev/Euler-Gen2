# Euler Problem 211 Solution in Ada

This problem asks us to find the sum of all numbers n < 64,000,000 where the sum of squares of divisors σ₂(n) is a perfect square.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_211 is
   type Natural_Array is array (Positive range <>) of Natural;
   
   -- Function to compute sum of squares of divisors
   function Sigma2(n : Natural) return Natural is
      Sum : Natural := 0;
      I   : Natural;
   begin
      I := 1;
      while I * I <= n loop
         if n mod I = 0 then
            Sum := Sum + I * I;
            if I * I /= n then
               Sum := Sum + (n / I) * (n / I);
            end if;
         end if;
         I := I + 1;
      end loop;
      return Sum;
   end Sigma2;
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(n : Natural) return Boolean is
      Root : Natural;
   begin
      if n = 0 then
         return True;
      end if;
      
      Root := Natural(Sqrt(Float(n)));
      
      -- Check both root and root+1 to handle floating point precision issues
      return Root * Root = n or else (Root + 1) * (Root + 1) = n;
   end Is_Perfect_Square;
   
   -- Precompute results for efficiency
   Max_N : constant := 64_000_000;
   Results : array (0 .. Max_N) of Boolean := (others => False);
   
begin
   -- Find all numbers where sigma2(n) is a perfect square
   declare
      Total_Sum : Natural := 0;
      Count     : Natural := 0;
   begin
      for N in 1 .. Max_N - 1 loop
         if Is_Perfect_Square(Sigma2(N)) then
            Total_Sum := Total_Sum + N;
            Count := Count + 1;
            -- Uncomment for progress tracking:
            -- if N mod 1000000 = 0 then
            --    Put_Line("Processed: " & Integer'Image(N));
            -- end if;
         end if;
      end loop;
      
      Put_Line("Sum of all qualifying numbers: ");
      Put(Total_Sum, Width => 0);
      New_Line;
      Put_Line("Count of qualifying numbers: " & Integer'Image(Count));
   end;
   
end Euler_211;
```

## Key Implementation Details:

1. **Sigma2 Function**: Computes the sum of squares of all divisors of n
2. **Is_Perfect_Square Function**: Efficiently checks if a number is a perfect square
3. **Memory Optimization**: Uses an array-based approach to store results
4. **Efficient Divisor Finding**: Only checks divisors up to √n to avoid redundant calculations

## Optimization Notes:

- The algorithm uses the fact that divisors come in pairs (d, n/d) except when d = √n
- For large numbers, we use floating point square root with verification to handle precision issues
- The solution processes numbers sequentially and checks the condition directly
