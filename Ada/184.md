## Problem Understanding

Euler Problem 184 asks us to find the number of triangles formed by three lattice points (integer coordinates) that contain the origin (0,0) in their interior.

## Solution Approach

The key insight is to use the property that a triangle contains the origin if and only if the origin lies on the same side of each edge of the triangle. We can use the cross product method to determine this.

   -- Function to compute cross product of vectors
   function Cross_Product(P1, P2 : Point) return Long_Long_Integer is
   begin
      return Long_Long_Integer(P1.X) * Long_Long_Integer(P2.Y) 
             - Long_Long_Integer(P1.Y) * Long_Long_Integer(P2.X);
   end Cross_Product;

   function Origin_Inside_Triangle(T : Triangle) return Boolean is
      V1, V2, V3 : Point;
      D1, D2, D3 : Long_Long_Integer;
   begin
      -- Compute vectors from each vertex to origin
      V1 := (X => -T.P1.X, Y => -T.P1.Y);
      V2 := (X => -T.P2.X, Y => -T.P2.Y);
      V3 := (X => -T.P3.X, Y => -T.P3.Y);
      
      -- Compute cross products
      D1 := Cross_Product((X => T.P2.X - T.P1.X, Y => T.P2.Y - T.P1.Y), V1);
      D2 := Cross_Product((X => T.P3.X - T.P2.X, Y => T.P3.Y - T.P2.Y), V2);
      D3 := Cross_Product((X => T.P1.X - T.P3.X, Y => T.P1.Y - T.P3.Y), V3);

      return (D1 > 0 and D2 > 0 and D3 > 0) or (D1 < 0 and D2 < 0 and D3 < 0);
