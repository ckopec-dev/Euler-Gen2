# Euler Problem 140 Solution in Ada

## Problem Statement
Consider the infinite polynomial series $A_G(x) = xG_1 + x^2G_2 + x^3G_3 + \ldots$, where $G_k$ is the $k$th term of the second order recurrence relation $G_{k} = G_{k-1} + G_{k-2}$, $G_1 = 1$, $G_2 = 1$.

Find the sum of all positive integers $n$ for which $A_G(n)$ is a positive integer.

3. Finding values of $n$ where $A_G(n)$ is a positive integer

## Mathematical Analysis

For the Fibonacci sequence with $G_1 = G_2 = 1$:
- $A_G(x) = x + x^2 + 2x^3 + 3x^4 + 5x^5 + 8x^6 + ...$

Using the recurrence relation, we can find that:
$A_G(x) = \frac{x}{1 - x - x^2}$

So we need to find positive integers $n$ such that $\frac{n}{1 - n - n^2}$ is a positive integer.

This means $1 - n - n^2$ must be a divisor of $n$, and the result must be positive.
