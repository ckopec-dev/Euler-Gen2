# Euler Problem 12 Solution in Ada

Euler Problem 12 asks for the first triangle number to have over five hundred divisors.

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_12 is
   
   function Count_Divisors(N : in Natural) return Natural is
      Count : Natural := 0;
      I     : Natural;
   begin
      for I in 1 .. Integer(Sqrt(Float(N))) loop
         if N mod I = 0 then
            if I * I = N then
               Count := Count + 1;  -- Perfect square case
            else
               Count := Count + 2;  -- Count both divisors
            end if;
         end if;
      end loop;
      
      return Count;
   end Count_Divisors;
   
   Triangle_Number : Natural := 0;
   Divisor_Count   : Natural := 0;
   N               : Natural := 0;
   
begin
   loop
      N := N + 1;
      Triangle_Number := Triangle_Number + N;
      Divisor_Count := Count_Divisors(Triangle_Number);
      
      if Divisor_Count > 500 then
         Put_Line("The first triangle number with over 500 divisors is:");
         Put(Triangle_Number);
         Put_Line(" (has " & Integer'Image(Divisor_Count) & " divisors)");
         exit;
      end if;
   end loop;
end Euler_12;
```

## Explanation

This solution works by:

1. **Count_Divisors function**: Efficiently counts the number of divisors for a given number
   - Only checks up to the square root of the number for efficiency
   - For each divisor found, it counts both the divisor and its complement
   - Special handling for perfect squares where the square root is counted only once

2. **Main loop**: 
   - Generates triangle numbers sequentially: 1, 3, 6, 10, 15, ...
   - For each triangle number, counts its divisors
   - Stops when a triangle number has over 500 divisors

## Key Optimizations

- **Square root optimization**: Only checks divisors up to √N instead of N
- **Pair counting**: When a divisor `i` is found, both `i` and `N/i` are counted as divisors
- **Early termination**: Stops as soon as the condition is met


This is the answer to Euler Problem 12, where 7657650 is the first triangle number to have more than 500 divisors.
