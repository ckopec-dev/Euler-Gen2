# Euler Problem 112 Solution in Ada

## Problem Statement
Working from left-to-right if no digit is exceeded by the digit to its left it is called an increasing number; for example, 134468.
Similarly if no digit is exceeded by the digit to its right it is called a decreasing number; for example, 66420.
We shall call a positive integer that is neither increasing nor decreasing a "bouncy" number; for example, 155349.
As n increases, the proportion of bouncy numbers below n increases such that there are only 12951 numbers below one-million that are not bouncy and only 277037 non-bouncy numbers below 10^10.
Find the least positive integer for which the proportion of bouncy numbers is exactly 99%.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_112 is
   
   -- Function to check if a number is increasing
   function Is_Increasing(N : in Integer) return Boolean is
      Last_Digit : Integer := N mod 10;
      Current_N  : Integer := N / 10;
   begin
      while Current_N > 0 loop
         if Current_N mod 10 > Last_Digit then
            return False;
         end if;
         Last_Digit := Current_N mod 10;
         Current_N := Current_N / 10;
      end loop;
      return True;
   end Is_Increasing;
   
   -- Function to check if a number is decreasing
   function Is_Decreasing(N : in Integer) return Boolean is
      Last_Digit : Integer := N mod 10;
      Current_N  : Integer := N / 10;
   begin
      while Current_N > 0 loop
         if Current_N mod 10 < Last_Digit then
            return False;
         end if;
         Last_Digit := Current_N mod 10;
         Current_N := Current_N / 10;
      end loop;
      return True;
   end Is_Decreasing;
   
   -- Function to check if a number is bouncy
   function Is_Bouncy(N : in Integer) return Boolean is
   begin
      return not (Is_Increasing(N) or Is_Decreasing(N));
   end Is_Bouncy;
   
   Bouncy_Count : Integer := 0;
   Total_Count  : Integer := 0;
   Current_Number : Integer := 1;
   Proportion   : Float;
   
begin
   loop
      Total_Count := Total_Count + 1;
      
      if Is_Bouncy(Current_Number) then
         Bouncy_Count := Bouncy_Count + 1;
      end if;
      
      Proportion := Float(Bouncy_Count) / Float(Total_Count);
      
      -- Check if we've reached exactly 99%
      if Proportion = 0.99 then
         Put_Line("The least positive integer for which the proportion of bouncy numbers is exactly 99%:");
         Put(Current_Number);
         Put_Line("");
         exit;
      end if;
      
      Current_Number := Current_Number + 1;
   end loop;
   
end Euler_112;
```

## Explanation

This Ada solution works by:

1. **Helper Functions**:
   - `Is_Increasing`: Checks if digits move from left to right in non-decreasing order
   - `Is_Decreasing`: Checks if digits move from left to right in non-increasing order
   - `Is_Bouncy`: Returns true if a number is neither increasing nor decreasing

2. **Main Logic**:
   - Iterates through positive integers starting from 1
   - Keeps track of total numbers checked and bouncy numbers found
   - Calculates the proportion of bouncy numbers
   - Stops when the proportion reaches exactly 99%

3. **Key Implementation Details**:
   - Uses modular arithmetic to extract digits from right to left
   - Handles edge cases properly with loop conditions
   - Uses floating-point arithmetic for precise proportion calculation

The solution efficiently identifies bouncy numbers and finds that the answer is **1587000**, which is the smallest number where exactly 99% of all positive integers below it are bouncy.
