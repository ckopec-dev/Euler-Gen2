# Euler Problem 296 Solution in Ada

This problem asks us to find the number of triangles with integer sides where the area equals the perimeter.

Let me solve this step by step.

## Problem Analysis

For a triangle with sides a, b, c, we need:
- Area = Perimeter
- Area = √(s(s-a)(s-b)(s-c)) where s = (a+b+c)/2
- Perimeter = a + b + c

So we need: √(s(s-a)(s-b)(s-c)) = a + b + c

## Solution Approach

1. Iterate through possible triangle side lengths
2. For each valid triangle, check if area equals perimeter
3. Use the constraint that triangles must satisfy triangle inequality

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_296 is
   type Triangle is record
      A, B, C : Integer;
   end record;

   function Area(T : Triangle) return Float is
      S : Float := Float(T.A + T.B + T.C) / 2.0;
   begin
      return sqrt(S * (S - Float(T.A)) * (S - Float(T.B)) * (S - Float(T.C)));
   end Area;

   function Perimeter(T : Triangle) return Integer is
   begin
      return T.A + T.B + T.C;
   end Perimeter;

   function IsValid(T : Triangle) return Boolean is
   begin
      return T.A + T.B > T.C and T.A + T.C > T.B and T.B + T.C > T.A;
   end IsValid;

   Count : Integer := 0;
   Max_Side : constant := 1000;
begin
   for A in 1 .. Max_Side loop
      for B in A .. Max_Side loop
         for C in B .. Max_Side loop
            declare
               T : Triangle := (A, B, C);
            begin
               if IsValid(T) then
                  if Area(T) = Float(Perimeter(T)) then
                     Count := Count + 1;
                  end if;
               end if;
            end;
         end loop;
      end loop;
   end loop;

   Put("Number of triangles: ");
   Put(Count, 0);
   New_Line;
end Euler_296;
```

## Optimized Version

Since we're looking for integer solutions, we can optimize the approach:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_296 is
   Count : Integer := 0;
   Max_Perimeter : constant := 10000;
begin
   -- We know that for a triangle with area = perimeter,
   -- the perimeter must be even (since area is integer)
   for P in 2 .. Max_Perimeter loop
      if P mod 2 = 0 then
         -- For each perimeter P, we need to find triangles with sides a, b, c
         -- such that a + b + c = P and area = P
         for A in 1 .. P/3 loop
            for B in A .. (P - A)/2 loop
               declare
                  C : constant Integer := P - A - B;
               begin
                  -- Check triangle inequality
                  if A + B > C and A + C > B and B + C > A then
                     -- Calculate area using Heron's formula
                     declare
                        S : constant Float := Float(P) / 2.0;
                        Area_Sq : constant Float := S * (S - Float(A)) * (S - Float(B)) * (S - Float(C));
                     begin
                        if Area_Sq > 0.0 then
                           declare
                              Area_Val : constant Float := sqrt(Area_Sq);
                           begin
                              if abs(Area_Val - Float(P)) < 0.0001 then  -- Handle floating point precision
                                 Count := Count + 1;
                              end if;
                           end;
                        end if;
                     end;
                  end if;
               end;
            end loop;
         end loop;
      end if;
   end loop;

   Put_Line("Number of triangles: " & Integer'Image(Count));
end Euler_296;
```
