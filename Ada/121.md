# Euler Problem 121 Solution in Ada

## Problem Statement
A bag contains one red disc and one blue disc. In a game of chance, a player takes a disc at random and notes its color. After each turn, the disc is returned to the bag, and an extra red disc is added to the bag. The player pays £1 to play and wins if they have taken more blue discs than red discs at the end of the game.

## Solution Approach
This is a probability problem where we need to calculate the probability of winning after 15 turns. We'll use dynamic programming to track the probability of having different numbers of blue discs.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_121 is
   type Probability_Array is array (0 .. 15) of Long_Float;
   
   -- Calculate probability of winning after n turns
   function Calculate_Winning_Probability(Turns : Positive) return Long_Float is
      Probabilities : Probability_Array := (others => 0.0);
      Total_Prob : Long_Float := 1.0;
      
      -- Initialize first turn
      Blue_Prob : Long_Float := 1.0 / 2.0;  -- 1 blue out of 2 discs
      Red_Prob : Long_Float := 1.0 / 2.0;   -- 1 red out of 2 discs
      
   begin
      Probabilities(0) := 1.0;  -- Starting with 0 blue discs
      
      -- For each turn, update probabilities
      for Turn in 1 .. Turns loop
         declare
            New_Prob : Probability_Array := (others => 0.0);
            Disc_Count : constant Positive := Turn + 1;
            Blue_Prob_Turn : constant Long_Float := 1.0 / Long_Float(Disc_Count);
            Red_Prob_Turn : constant Long_Float := Long_Float(Disc_Count - 1) / Long_Float(Disc_Count);
         begin
            -- Update probabilities for each number of blue discs
            for Blue_Count in reverse 0 .. Turn loop
               if Probabilities(Blue_Count) > 0.0 then
                  -- Take a blue disc
                  New_Prob(Blue_Count + 1) := New_Prob(Blue_Count + 1) + 
                     Probabilities(Blue_Count) * Blue_Prob_Turn;
                  
                  -- Take a red disc
                  New_Prob(Blue_Count) := New_Prob(Blue_Count) + 
                     Probabilities(Blue_Count) * Red_Prob_Turn;
               end if;
            end loop;
            
            Probabilities := New_Prob;
         end;
      end loop;
      
      -- Calculate probability of winning (more blue than red)
      declare
         Win_Prob : Long_Float := 0.0;
         Half_Turns : constant Positive := Turns / 2;
      begin
         for Blue_Count in (Half_Turns + 1) .. Turns loop
            Win_Prob := Win_Prob + Probabilities(Blue_Count);
         end loop;
         
         return Win_Prob;
      end;
   end Calculate_Winning_Probability;
   
   -- Calculate the maximum prize fund
   function Calculate_Prize_Fund(Prob : Long_Float) return Natural is
      -- Prize fund = floor(1 / probability of winning)
   begin
      return Natural(1.0 / Prob);
   end Calculate_Prize_Fund;

begin
   -- Calculate probability of winning after 15 turns
   declare
      Win_Prob : constant Long_Float := Calculate_Winning_Probability(15);
      Prize_Fund : constant Natural := Calculate_Prize_Fund(Win_Prob);
   begin
      Put_Line("Probability of winning: " & Float'Image(Float(Win_Prob)));
      Put_Line("Maximum prize fund: " & Integer'Image(Integer(Prize_Fund)));
   end;
end Euler_121;
```

## Explanation

The solution uses dynamic programming to track the probability of having different numbers of blue discs after each turn:

1. **Initialization**: Start with 1 red disc and 1 blue disc (total 2 discs)
2. **Each Turn**: 
   - Add one more red disc to the bag
   - Calculate probabilities for both outcomes (taking blue or red disc)
3. **Probability Update**: For each possible number of blue discs, update the probability distribution
4. **Winning Condition**: Sum all probabilities where blue discs > red discs (i.e., blue discs > turns/2)

## Key Insights

- The bag grows by one disc each turn: 2, 3, 4, ..., 16 discs
- At turn n, there are n+1 discs total
- Probability of drawing blue at turn n is 1/(n+1)
- Probability of drawing red at turn n is n/(n+1)
- The maximum prize fund is the floor of 1 divided by the probability of winning
