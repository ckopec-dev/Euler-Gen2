# Euler Problem 97 Solution in Ada

## Problem Statement
Find the last ten digits of the prime number 28433 × 2^7830457 + 1.

## Solution Approach
We need to compute (28433 × 2^7830457 + 1) mod 10^10 to get the last ten digits. Since we're only interested in the last ten digits, we can use modular arithmetic throughout the computation to avoid dealing with extremely large numbers.

## Ada Implementation

```ada
with Ada.Text_IO;
procedure Euler_97 is
   type Big_Integer is mod 10**10;  -- Only keep last 10 digits
   
   function Power_Mod(base, exponent, modulus : Big_Integer) return Big_Integer is
      result : Big_Integer := 1;
      base_mod : Big_Integer := base mod modulus;
      exp : Big_Integer := exponent;
   begin
      while exp > 0 loop
         if exp mod 2 = 1 then
            result := (result * base_mod) mod modulus;
         end if;
         base_mod := (base_mod * base_mod) mod modulus;
         exp := exp / 2;
      end loop;
      return result;
   end Power_Mod;
   
   -- Calculate 2^7830457 mod 10^10
   power_of_2 : Big_Integer := Power_Mod(2, 7830457, 10**10);
   
   -- Calculate 28433 * 2^7830457 mod 10^10
   result : Big_Integer := (28433 * power_of_2) mod 10**10;
   
   -- Add 1 and get final answer
   final_result : Big_Integer := (result + 1) mod 10**10;
   
begin
   Ada.Text_IO.Put_Line("The last ten digits are: " & 
                        Big_Integer'Image(final_result)(2..11));
end Euler_97;
```

## Explanation

1. **Modular Exponentiation**: The key insight is using modular exponentiation to compute 2^7830457 mod 10^10 efficiently. This avoids computing the enormous intermediate value.

2. **Binary Exponentiation**: The `Power_Mod` function implements fast modular exponentiation using binary exponentiation, which reduces the time complexity from O(n) to O(log n).

3. **Modular Arithmetic**: All operations are performed modulo 10^10 throughout to keep numbers manageable and ensure we only track the last ten digits.

4. **Step-by-step computation**:
   - First compute 2^7830457 mod 10^10
   - Then multiply by 28433 and take mod 10^10
   - Finally add 1 and take mod 10^10
