# Euler Problem 148 Solution in Ada

This problem asks for the number of entries in Pascal's triangle up to row 1000000 that are not divisible by 7.

## Analysis

The key insight is to use Lucas' theorem for binomial coefficients modulo a prime. For a prime p, the binomial coefficient C(n,k) is divisible by p if and only if at least one of the digits in the base-p representation of k is greater than the corresponding digit in the base-p representation of n.

For our problem with p=7, we need to count how many entries in Pascal's triangle are NOT divisible by 7.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_148 is
   
   -- Function to compute the number of entries in Pascal's triangle up to row n that are not divisible by p
   function Count_Non_Divisible(n : Integer; p : Integer) return Long_Long_Integer is
      result : Long_Long_Integer := 0;
      power  : Long_Long_Integer := 1;
      temp_n : Integer := n;
   begin
      -- Process each digit of n in base p
      while temp_n > 0 loop
         declare
            digit : Integer := temp_n mod p;
         begin
            -- For each digit d, the number of entries in that row not divisible by p is (d+1)
            -- But we need to be more careful - it's (digit+1) * power
            result := result + (Long_Long_Integer(digit + 1) * power);
            temp_n := temp_n / p;
            power := power * Long_Long_Integer(p);
         end;
      end loop;
      
      return result;
   end Count_Non_Divisible;
   
begin
   -- For row 1000000, we want all entries in Pascal's triangle up to row 1000000 (inclusive)
   -- that are not divisible by 7
   Put_Line("Result: " & 
            Long_Long_Integer'Image(Count_Non_Divisible(1000000, 7)));
end Euler_148;
```
