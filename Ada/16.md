# Euler Problem 16 Solution in Ada

## Problem Statement
2¹⁵ = 32768 and the sum of its digits is 3 + 2 + 7 + 6 + 8 = 26. What is the sum of the digits of the number 2¹⁰⁰⁰?

## Solution

```ada
with Ada.Text_IO;     use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_16 is
   type Big_Integer is array (Positive range <>) of Integer;
   
   function Power_Of_2(N : Positive) return Big_Integer is
      Result : Big_Integer(1..N*3);  -- Enough space for 2^N
      Carry  : Integer := 0;
      Len    : Positive := 1;
   begin
      Result(1) := 1;
      
      for I in 1..N loop
         for J in 1..Len loop
            Result(J) := Result(J) * 2 + Carry;
            Carry := Result(J) / 10;
            Result(J) := Result(J) mod 10;
         end loop;
         
         while Carry > 0 loop
            Len := Len + 1;
            Result(Len) := Carry mod 10;
            Carry := Carry / 10;
         end loop;
      end loop;
      
      return Result(1..Len);
   end Power_Of_2;
   
   function Sum_Digits(N : Positive) return Integer is
      Power : Big_Integer := Power_Of_2(N);
      Sum   : Integer := 0;
   begin
      for I in Power'Range loop
         Sum := Sum + Power(I);
      end loop;
      return Sum;
   end Sum_Digits;
   
begin
   Put_Line("Sum of digits of 2^1000: " & Integer'Image(Sum_Digits(1000)));
end Euler_16;
```

## Explanation

This solution uses a custom big integer implementation to handle the large number 2¹⁰⁰⁰:

1. **Big_Integer Type**: Defines an array to store individual digits of the large number
2. **Power_Of_2 Function**: Computes 2^N using digit-by-digit multiplication with carry propagation
3. **Sum_Digits Function**: Calculates the sum of all digits in the resulting number
4. **Main Procedure**: Calls the function for 2¹⁰⁰⁰ and outputs the result

The algorithm works by:
- Starting with 1 (which is 2⁰)
- Repeatedly multiplying by 2, keeping track of carries
- Each multiplication step handles all digits in the current number
- The result array grows as needed to accommodate the increasing number of digits
