# Euler Problem 276 Solution in Ada

This problem asks for the number of triangles with integer sides that have a perimeter of at most 100,000 and are "almost isosceles" (meaning two sides are equal).

## Problem Analysis

For a triangle with sides a, b, c where a ≤ b ≤ c:
- Triangle inequality: a + b > c
- Perimeter constraint: a + b + c ≤ 100000
- Almost isosceles: a = b (or b = c, but we'll focus on a = b for simplicity)

Let's denote a = b and c as the third side. Then:
- 2a + c ≤ 100000
- 2a > c (triangle inequality)
- c ≥ 1

with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_276 is
   Max_Perimeter : constant := 100_000;
   Count         : Natural := 0;
   
   -- Function to calculate number of valid triangles for given a
   function Count_Triangles(a : Natural) return Natural is
      -- For triangle with sides a, a, c where a ≤ a ≤ c
      -- We need: 2*a > c and a + a + c ≤ Max_Perimeter
      -- This gives us: c < 2*a and c ≤ Max_Perimeter - 2*a
      -- Also c ≥ 1 (positive side length)
   begin
      if 2 * a >= Max_Perimeter then
         return 0;
      end if;
      
      -- c must satisfy:
      -- 1 ≤ c < 2*a and c ≤ Max_Perimeter - 2*a
      -- So: 1 ≤ c ≤ min(2*a - 1, Max_Perimeter - 2*a)
      
      declare
         Max_C : constant Natural := Natural'Min(2 * a - 1, Max_Perimeter - 2 * a);
      begin
         if Max_C >= 1 then
            return Max_C;
         else
            return 0;
         end if;
      end;
   end Count_Triangles;
   
begin
   -- For each possible value of a (first two equal sides)
   for a in 1 .. Max_Perimeter / 3 loop
      Count := Count + Count_Triangles(a);
   end loop;
   
   Put_Line("Number of almost isosceles triangles: " & Integer'Image(Integer(Count)));
end Euler_276;
