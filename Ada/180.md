# Euler Problem 180 Solution in Ada

I'll solve Project Euler Problem 180, which asks for the sum of all distinct values of f(a,b,c) = (a/b)^(b/c)^(c/a) where a, b, c are positive integers with a ≤ b ≤ c and a + b + c ≤ 30.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;
with Ada.Numerics.Elementary_Functions; use Ada.Numerics.Elementary_Functions;

procedure Euler_180 is
   
   type Real is new Float;
   
   -- Function to compute f(a,b,c) = (a/b)^(b/c)^(c/a)
   function F(a, b, c : Integer) return Real is
      -- Compute (a/b)^(b/c)^(c/a)
      -- Using logarithms to avoid overflow issues
      base : Real := Real(a) / Real(b);
      exponent : Real := Real(b) / Real(c);
      inner_exp : Real := Real(c) / Real(a);
      
      -- Use log to compute power: x^y = e^(y * ln(x))
      result : Real;
   begin
      if base <= 0.0 then
         return 0.0;
      end if;
      
      -- Compute (b/c)^(c/a)
      declare
         inner_power : Real := exponent * Log(inner_exp);
      begin
         -- Compute (a/b)^(b/c)^(c/a)
         result := Exp(inner_power * Log(base));
         return result;
      end;
   exception
      when others =>
         return 0.0;
   end F;
   
   type Value_Set is array(1..10000) of Real;
   Values : Value_Set;
   Count : Integer := 0;
   
   procedure Add_Value(Value : Real) is
      -- Check if value already exists (with some tolerance)
      Tolerance : constant Real := 1.0E-10;
      Already_Exists : Boolean := False;
   begin
      for I in 1..Count loop
         if abs(Values(I) - Value) < Tolerance then
            Already_Exists := True;
            exit;
         end if;
      end loop;
      
      if not Already_Exists then
         Count := Count + 1;
         Values(Count) := Value;
      end if;
   end Add_Value;
   
   -- For debugging - print all values
   procedure Print_Values is
   begin
      for I in 1..Count loop
         Put("Value ");
         Put(I, Width => 4);
         Put(": ");
         Put(Values(I), Aft => 10, Exp => 0);
         New_Line;
      end loop;
   end Print_Values;
   
begin
   -- Loop through all valid combinations of a, b, c
   -- where a ≤ b ≤ c and a + b + c ≤ 30
   for a in 1..30 loop
      for b in a..(30-a) loop
         for c in b..(30-a-b) loop
            declare
               result : Real := F(a, b, c);
            begin
               Add_Value(result);
            end;
         end loop;
      end loop;
   end loop;
   
   -- Calculate sum of all distinct values
   declare
      Total_Sum : Real := 0.0;
   begin
      for I in 1..Count loop
         Total_Sum := Total_Sum + Values(I);
      end loop;
      
      Put("Number of distinct values: ");
      Put(Count, Width => 4);
      New_Line;
      Put("Sum of all distinct values: ");
      Put(Total_Sum, Aft => 10, Exp => 0);
      New_Line;
   end;
   
end Euler_180;
```

This solution works by:

1. **Generating combinations**: Loop through all valid combinations of (a,b,c) where a ≤ b ≤ c and a + b + c ≤ 30
2. **Computing function values**: For each combination, calculate f(a,b,c) = (a/b)^(b/c)^(c/a)
3. **Avoiding duplicates**: Store only distinct values using a tolerance check for floating-point comparisons
4. **Summing results**: Add all unique values together

The key insight is to use logarithms to compute the power operations, which helps avoid numerical overflow issues with large exponents.

Note: The exact value of this sum would need to be computed numerically and may involve careful handling of floating-point precision. The solution uses a tolerance of 1E-10 to determine when two floating-point values are equal, which is appropriate for this type of problem.
