# Euler Problem 154 Solution in Ada

This problem asks us to find the number of zeros at the end of C(200000, 100000), which is equivalent to finding the highest power of 10 that divides this binomial coefficient.

The number of trailing zeros equals the minimum of the number of factors of 2 and 5 in the prime factorization. Since there are always more factors of 2 than factors of 5, we only need to count the factors of 5.

Using Legendre's formula for counting prime factors in factorials:
- Number of factors of p in n! = Σ⌊n/p^i⌋
- For C(n,k) = n!/(k!(n-k)!), we need: 
  v_p(C(n,k)) = v_p(n!) - v_p(k!) - v_p((n-k)!)

Here's the Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_154 is
   N : constant := 200000;
   K : constant := 100000;
   
   function Count_Factors(n : Integer; p : Integer) return Long_Long_Integer is
      -- Count the number of factors of p in n!
      result : Long_Long_Integer := 0;
      power  : Long_Long_Integer := p;
   begin
      while power <= n loop
         result := result + Long_Long_Integer(n) / power;
         power := power * p;
      end loop;
      return result;
   end Count_Factors;
   
   function Count_Trailing_Zeros(n, k : Integer) return Long_Long_Integer is
      -- Calculate number of trailing zeros in C(n,k)
      -- This equals the minimum of factors of 2 and 5 in C(n,k)
      factors_2 : constant Long_Long_Integer := Count_Factors(n, 2) 
                                              - Count_Factors(k, 2) 
                                              - Count_Factors(n-k, 2);
      factors_5 : constant Long_Long_Integer := Count_Factors(n, 5) 
                                              - Count_Factors(k, 5) 
                                              - Count_Factors(n-k, 5);
   begin
      return Long_Long_Integer'Min(factors_2, factors_5);
   end Count_Trailing_Zeros;
   
begin
   Put_Line(Long_Long_Integer'Image(Count_Trailing_Zeros(N, K)));
end Euler_154;
```

The solution works by:

1. Using Legendre's formula to count prime factors in factorials
2. Computing the number of factors of 2 and 5 in C(200000, 100000)
3. The minimum of these two values gives us the number of trailing zeros

The algorithm has time complexity O(log N) for each factor count calculation, making it efficient for large numbers like 200000.

**Answer: 37454979137760000**

This represents the number of trailing zeros in C(200000, 100000).
