# Euler Problem 322 Solution in Ada

I'll solve Euler Problem 322, which asks for the number of ways to write n as a sum of powers of 2, where each power can be used at most twice.

## Problem Analysis

The problem asks for the number of representations of a positive integer n as a sum of powers of 2, where each power 2^k can be used at most twice. This is equivalent to finding the number of ways to write n in a "binary-like" representation where coefficients are limited to 0, 1, or 2.

## Solution Approach

I'll use dynamic programming with memoization to count the representations efficiently.

```ada
with Ada.Text_IO;
procedure Euler_322 is
   type Big_Integer is range 0 .. 2**100;
   
   -- Memoization array for dynamic programming
   type Memo_Array is array (0 .. 1000000) of Big_Integer;
   Memo : Memo_Array := (others => 0);
   
   function Count_Representations(N : Big_Integer) return Big_Integer is
      Result : Big_Integer := 0;
   begin
      if N = 0 then
         return 1;
      elsif N < 0 then
         return 0;
      elsif Memo(N) /= 0 then
         return Memo(N);
      else
         -- Try all possible powers of 2 that are <= N
         -- We can use 0, 1, or 2 of each power
         declare
            Power : Big_Integer := 1;
            Temp : Big_Integer;
         begin
            while Power <= N loop
               -- Use 0 instances of current power
               Result := Result + Count_Representations(N - 0 * Power);
               
               -- Use 1 instance of current power
               if N >= Power then
                  Result := Result + Count_Representations(N - 1 * Power);
               end if;
               
               -- Use 2 instances of current power
               if N >= 2 * Power then
                  Result := Result + Count_Representations(N - 2 * Power);
               end if;
               
               Power := Power * 2;
            end loop;
         end;
      end if;
      
      Memo(N) := Result;
      return Result;
   end Count_Representations;
   
   -- More efficient approach using proper DP
   function Count_Representations_DP(N : Big_Integer) return Big_Integer is
      type DP_Array is array (0 .. 1000000) of Big_Integer;
      DP : DP_Array := (others => 0);
      Result : Big_Integer := 0;
   begin
      -- Base case
      DP(0) := 1;
      
      -- For each power of 2
      for Power in 1 .. 20 loop
         declare
            P : Big_Integer := 2**Power;
         begin
            -- For each number from P to N
            for I in P .. N loop
               -- Add ways using 0, 1, or 2 instances of this power
               DP(I) := DP(I) + DP(I - P);  -- 1 instance
               if I >= 2 * P then
                  DP(I) := DP(I) + DP(I - 2 * P);  -- 2 instances
               end if;
            end loop;
         end;
      end loop;
      
      return DP(N);
   end Count_Representations_DP;
   
   function Solve(N : Big_Integer) return Big_Integer is
   begin
      return Count_Representations_DP(N);
   end Solve;
   
begin
   -- For the actual problem, we need to find the answer for n = 10^10
   Ada.Text_IO.Put_Line("Solution: " & Big_Integer'Image(Solve(10**10)));
end Euler_322;
```

## Improved Solution

Let me provide a cleaner, more efficient solution:

```ada
with Ada.Text_IO;
procedure Euler_322 is
   
   -- Function to count representations of n as sum of powers of 2 (each used at most twice)
   function Count_Ways(N : Integer) return Long_Long_Integer is
      type DP_Array is array (0 .. 1000000000) of Long_Long_Integer;
      DP : DP_Array := (others => 0);
   begin
      DP(0) := 1;  -- Base case: one way to make 0
      
      -- For each power of 2 from 2^0 to 2^30 (since 2^30 < 10^10)
      for Power in 0 .. 30 loop
         declare
            P : Long_Long_Integer := 2**Power;
         begin
            -- Update DP table for all values >= P
            for I in P .. N loop
               DP(I) := DP(I) + DP(I - P);  -- Add ways using 1 instance of P
               if I >= 2 * P then
                  DP(I) := DP(I) + DP(I - 2 * P);  -- Add ways using 2 instances of P
               end if;
            end loop;
         end;
      end loop;
      
      return DP(N);
   end Count_Ways;
   
begin
   Ada.Text_IO.Put_Line("Number of representations: " & Long_Long_Integer'Image(Count_Ways(10**10)));
end Euler_322;
```

## Explanation

The solution uses dynamic programming where:
1. `DP[i]` represents the number of ways to represent integer `i`
2. For each power of 2 (2^k), we update all values from 2^k to N
3. For each value `i`, we add:
   - Ways to make `i - 2^k` (using one instance of 2^k)
   - Ways to make `i - 2*2^k` (using two instances of 2^k)

This approach has time complexity O(N log N) and space complexity O(N).
