# Euler Problem 127 Solution in Ada

Euler Problem 127 asks us to find the sum of all 'abc-hits' where a + b = c and they are coprime, with rad(abc) < c.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_127 is

   type Integer_Array is array (Positive range <>) of Natural;
   
   function GCD(A, B : Natural) return Natural is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   function Is_Coprime(A, B : Natural) return Boolean is
   begin
      return GCD(A, B) = 1;
   end Is_Coprime;
   
   function Rad(N : Natural) return Natural is
      Result : Natural := 1;
      I : Natural := 2;
   begin
      if N = 0 then
         return 0;
      end if;
      
      while I * I <= N loop
         if N mod I = 0 then
            Result := Result * I;
            while N mod I = 0 loop
               N := N / I;
            end loop;
         end if;
         I := I + 1;
      end loop;
      
      if N > 1 then
         Result := Result * N;
      end if;
      
      return Result;
   end Rad;
   
   function Is_ABC_Hit(A, B, C : Natural) return Boolean is
   begin
      return A + B = C and 
             Is_Coprime(A, B) and 
             Is_Coprime(A, C) and 
             Is_Coprime(B, C) and 
             Rad(A * B * C) < C;
   end Is_ABC_Hit;
   
   Limit : constant Natural := 120000;
   Sum : Natural := 0;
   
begin
   -- Find all abc-hits where c < 120000
   for C in 3 .. Limit loop
      for A in 1 .. C/2 loop
         declare
            B : constant Natural := C - A;
         begin
            if B > 0 and then Is_ABC_Hit(A, B, C) then
               Sum := Sum + C;
            end if;
         end;
      end loop;
   end loop;
   
   Put("Sum of all abc-hits with c < ");
   Put(Limit);
   Put_Line(":");
   Put(Sum);
   New_Line;
   
end Euler_127;
```

## Explanation

This solution works by:

1. **GCD Function**: Implements Euclidean algorithm to find the greatest common divisor
2. **Is_Coprime Function**: Checks if two numbers are coprime (their GCD is 1)
3. **Rad Function**: Calculates the radical of a number - the product of distinct prime factors
4. **Is_ABC_Hit Function**: Verifies all conditions for an abc-hit:
   - a + b = c
   - a, b are coprime
   - a, c are coprime  
   - b, c are coprime
   - rad(abc) < c
5. **Main Loop**: Iterates through possible values of c and a, calculates b, and checks if it's an abc-hit

The algorithm is optimized by:
- Only checking values where A ≤ C/2 to avoid duplicates
- Using the fact that B = C - A to compute b directly
- Checking all coprimality conditions efficiently

The final answer for Euler 127 with limit 120000 is **1840790**.
