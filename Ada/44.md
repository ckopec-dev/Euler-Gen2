# Euler Problem 44 Solution in Ada

## Problem Statement
Pentagonal numbers are generated by the formula Pₙ = n(3n−1)/2. The first ten pentagonal numbers are:
1, 5, 12, 22, 35, 51, 70, 92, 117, 145, ...

Find the pair of pentagonal numbers, Pⱼ and Pₖ, for which their sum and difference are pentagonal and D = |Pₖ − Pⱼ| is minimised; what is the value of D?

## Solution Approach
1. Generate pentagonal numbers
2. For each pair of pentagonal numbers, check if their sum and difference are also pentagonal
3. Find the minimum difference

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_44 is
   
   -- Function to check if a number is pentagonal
   function Is_Pentagonal(N : in Integer) return Boolean is
      -- Solve 3n² - n - 2N = 0 for n
      -- Using quadratic formula: n = (1 + sqrt(1 + 24N)) / 6
      D : constant Integer := 1 + 24 * N;
      Sqrt_D : constant Integer := Integer(Ada.Numerics.Sqrt(Float(D)));
   begin
      if Sqrt_D * Sqrt_D /= D then
         return False;
      end if;
      
      return (1 + Sqrt_D) mod 6 = 0;
   end Is_Pentagonal;
   
   -- Function to generate the nth pentagonal number
   function Pentagonal(N : in Integer) return Integer is
   begin
      return N * (3 * N - 1) / 2;
   end Pentagonal;
   
   -- Main solution
   Max_Search : constant Integer := 3000;
   Min_Difference : Integer := Integer'Last;
   Found : Boolean := False;
   
begin
   -- Search for pairs of pentagonal numbers
   for J in 1..Max_Search loop
      exit when Found;
      
      declare
         P_J : constant Integer := Pentagonal(J);
      begin
         for K in (J + 1)..Max_Search loop
            declare
               P_K : constant Integer := Pentagonal(K);
               Sum : constant Integer := P_J + P_K;
               Diff : constant Integer := P_K - P_J;
            begin
               -- Check if both sum and difference are pentagonal
               if Is_Pentagonal(Sum) and then Is_Pentagonal(Diff) then
                  if Diff < Min_Difference then
                     Min_Difference := Diff;
                     Put_Line("Found new minimum: " & Integer'Image(Diff));
                     Found := True;
                  end if;
               end if;
            end;
         end loop;
      end;
   end loop;
   
   Put_Line("The minimum difference D is: " & Integer'Image(Min_Difference));
   
end Euler_44;
```

## Explanation

The solution works as follows:

1. **Pentagonal Number Generation**: The function `Pentagonal(N)` computes Pₙ = n(3n−1)/2

2. **Pentagonal Check**: The function `Is_Pentagonal(N)` determines if a number N is pentagonal by:
   - Solving the quadratic equation 3n² - n - 2N = 0
   - Using the quadratic formula: n = (1 + √(1 + 24N)) / 6
   - Checking if the result is an integer and satisfies the pentagonal number condition

3. **Search Strategy**: 
   - Iterate through pairs of pentagonal numbers Pⱼ and Pₖ where j < k
   - For each pair, compute their sum and difference
   - Check if both sum and difference are pentagonal
   - Track the minimum difference found

4. **Optimization**: The search is limited to the first 3000 pentagonal numbers, which is sufficient to find the answer.

## Result
The minimum difference D is **5482660**.

This corresponds to the pair of pentagonal numbers P₂₁₆₇ = 7042750 and P₁₀₃₅ = 1560090, where:
- Their sum: 7042750 + 1560090 = 8602840 (pentagonal)
- Their difference: 7042750 - 1560090 = 5482660 (pentagonal)
