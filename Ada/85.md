# Euler Problem 85 Solution in Ada

## Problem Statement
> By counting carefully it can be seen that a rectangular grid measuring 3 by 2 contains eighteen rectangles.
>
> Although there exists no rectangular grid that contains exactly two million rectangles, find the area of the grid with the nearest solution.

## Analysis
We need to find the dimensions of a rectangle that contains approximately 2,000,000 rectangles. For a grid of size `m × n`, the number of rectangles is:
```
(m × (m+1) / 2) × (n × (n+1) / 2)
```

This can be simplified to: `(m² + m) × (n² + n) / 4`

We want to find `m` and `n` such that this value is as close as possible to 2,000,000.

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_85 is
   Target : constant := 2_000_000;
   
   function Count_Rectangles(m, n : Integer) return Long_Long_Integer is
      -- Calculate number of rectangles in m×n grid
      M_Sq : constant Long_Long_Integer := Long_Long_Integer(m) * Long_Long_Integer(m);
      N_Sq : constant Long_Long_Integer := Long_Long_Integer(n) * Long_Long_Integer(n);
   begin
      return ((M_Sq + Long_Long_Integer(m)) * (N_Sq + Long_Long_Integer(n))) / 4;
   end Count_Rectangles;
   
   Min_Diff : Long_Long_Integer := Long_Long_Integer'Last;
   Best_Area : Integer := 0;
   Best_M, Best_N : Integer := 0;
   
begin
   -- We can estimate the maximum possible dimensions
   -- Since we're looking for about 2 million rectangles,
   -- and each rectangle is roughly 1 unit, we can start with reasonable bounds
   
   for m in 1 .. 1000 loop
      exit when Count_Rectangles(m, 1) > Target;
      
      for n in 1 .. 1000 loop
         declare
            Rect_Count : constant Long_Long_Integer := Count_Rectangles(m, n);
            Diff : constant Long_Long_Integer := abs(Rect_Count - Target);
         begin
            if Diff < Min_Diff then
               Min_Diff := Diff;
               Best_Area := m * n;
               Best_M := m;
               Best_N := n;
               
               -- Early exit when difference is small enough
               if Diff <= 1000 then
                  Put_Line("Early exit: m=" & Integer'Image(m) & ", n=" & Integer'Image(n) 
                          & ", diff=" & Long_Long_Integer'Image(Diff));
               end if;
            end if;
            
            -- If we've gone too far, break inner loop
            exit when Rect_Count > Target;
         end;
      end loop;
   end loop;
   
   Put_Line("Best dimensions: " & Integer'Image(Best_M) & " × " & Integer'Image(Best_N));
   Put_Line("Area: " & Integer'Image(Best_Area));
   Put_Line("Rectangle count: " & Long_Long_Integer'Image(Count_Rectangles(Best_M, Best_N)));
   Put_Line("Difference from target: " & Long_Long_Integer'Image(Min_Diff));
end Euler_85;
```

## Explanation

The solution works by:

1. **Defining the rectangle counting formula**: For an `m × n` grid, the number of rectangles is `(m² + m) × (n² + n) / 4`

2. **Iterating through possible dimensions**: We try combinations of `m` and `n` values from 1 to 1000

3. **Tracking the best solution**: For each combination, we calculate how close it is to 2,000,000 rectangles and keep track of the minimum difference

4. **Early termination**: We can stop early when we get very close to the target (difference ≤ 1000) for efficiency

## Key Insights

- The number of rectangles grows quadratically with grid dimensions
- We only need to check reasonable bounds - larger grids will exceed 2 million rectangles quickly
- The solution involves finding integer dimensions that minimize the difference from the target

## Result

The answer is **2772** (the area of the grid that produces the closest number of rectangles to 2,000,000).
