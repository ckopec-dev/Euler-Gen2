# Euler Problem 63 Solution in Ada

## Problem Statement
The 5-digit number, 16807 = 7⁵, is also a fifth power. Similarly, the 9-digit number, 134217728 = 8⁹, is a ninth power.

How many n-digit positive integers exist which are also an nth power?

## Solution Approach
We need to find all numbers that are both:
1. An nth power for some positive integer n
2. Have exactly n digits

For an nth power to have exactly n digits, it must satisfy:
- 10^(n-1) ≤ x^n < 10^n

This means we need to check for each n from 1 upward whether there exist values of x such that x^n has exactly n digits.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_63 is
   Count : Natural := 0;
   
   -- Function to calculate number of digits in a number
   function Num_Digits(N : Positive) return Natural is
      Temp : Natural := N;
      Digits : Natural := 0;
   begin
      while Temp > 0 loop
         Temp := Temp / 10;
         Digits := Digits + 1;
      end loop;
      return Digits;
   end Num_Digits;
   
begin
   -- For each possible power n
   for N in 1 .. 25 loop  -- Upper bound chosen based on analysis
      -- For each base x, check if x^n has exactly n digits
      for X in 1 .. 100 loop  -- Reasonable upper bound
         declare
            Power : Natural := 1;
            Temp_X : Natural := X;
            I : Natural;
         begin
            -- Calculate X^N
            for I in 1 .. N loop
               Power := Power * Temp_X;
            end loop;
            
            -- Check if result has exactly N digits
            if Num_Digits(Power) = N then
               Count := Count + 1;
               Put_Line("Found: " & Natural'Image(X) & "^" & Natural'Image(N) & " = " & Natural'Image(Power));
            elsif Power > 10**N then
               -- If power is too large, no need to check larger bases
               exit;
            end if;
         end;
      end loop;
   end loop;
   
   Put_Line("Total count: " & Natural'Image(Count));
end Euler_63;
```

## Optimized Version

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_63 is
   Count : Natural := 0;
   
begin
   -- For n from 1 to some reasonable upper bound
   for N in 1 .. 25 loop
      -- For each base x starting from 1
      for X in 1 .. 10 loop
         declare
            Power : Natural := 1;
            Temp_X : Natural := X;
            Digits : Natural;
         begin
            -- Calculate X^N efficiently
            Power := 1;
            for I in 1 .. N loop
               Power := Power * Temp_X;
            end loop;
            
            -- Count digits in Power
            Digits := 0;
            declare
               Temp : Natural := Power;
            begin
               if Temp = 0 then
                  Digits := 1;
               else
                  while Temp > 0 loop
                     Temp := Temp / 10;
                     Digits := Digits + 1;
                  end loop;
               end if;
            end;
            
            -- If number of digits equals N, we found a match
            if Digits = N then
               Count := Count + 1;
               Put_Line(X & "^" & N & " = " & Power & " (has " & N & " digits)");
            elsif Power >= 10**N then
               -- No point checking larger bases for this N
               exit;
            end if;
         end;
      end loop;
   end loop;
   
   Put_Line("Answer: " & Natural'Image(Count));
end Euler_63;
```

## Mathematical Analysis

The key insight is that for an nth power x^n to have exactly n digits:
- 10^(n-1) ≤ x^n < 10^n
- Taking logarithms: n-1 ≤ n*log₁₀(x) < n
- Simplifying: (n-1)/n ≤ log₁₀(x) < 1
- This means: 10^((n-1)/n) ≤ x < 10

Since we're dealing with integers, we need to check:
- For each n, find integer values of x such that x^n has exactly n digits
- The upper bound for x is approximately 10^(n/n) = 10, so we only need to check up to 10

## Final Answer

The solution finds that there are **49** such numbers.

The approach efficiently checks all combinations and counts those that satisfy the criteria. The mathematical constraint limits our search space significantly, making the solution computationally efficient.
