# Euler Problem 42 Solution in Ada

## Problem Statement
The nth term of the sequence of triangle numbers is given by, tn = ½n(n+1). So the first ten triangle numbers are:
1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...

By converting each letter in a word to a number corresponding to its alphabetical position and adding these values we form a word value. For example, the word SCORE has a value of 3 + 15 + 19 + 3 + 5 = 45.

We shall call a word triangle if its word value is a triangle number.

Using words.txt (right click and 'Save Link/Target As...'), a 16K text file containing nearly two-thousand common English words, how many are triangle words?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;
with Ada.Text_IO.Unbounded_IO; use Ada.Text_IO.Unbounded_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;
with Ada.Directories;

procedure Euler_42 is
   type Word_Vector is array (Positive range <>) of Unbounded_String;
   
   -- Function to calculate triangle numbers
   function Triangle_Number(N : Positive) return Positive is
   begin
      return N * (N + 1) / 2;
   end Triangle_Number;
   
   -- Function to calculate word value
   function Word_Value(W : Unbounded_String) return Positive is
      Value : Positive := 0;
      Ch    : Character;
   begin
      for I in 1 .. Length(W) loop
         Ch := Element(W, I);
         if Ch >= 'A' and Ch <= 'Z' then
            Value := Value + (Character'Pos(Ch) - Character'Pos('A') + 1);
         end if;
      end loop;
      return Value;
   end Word_Value;
   
   -- Function to check if a number is a triangle number
   function Is_Triangle_Number(N : Positive) return Boolean is
      Triangle_Index : Positive := 1;
      Tn             : Positive := Triangle_Number(Triangle_Index);
   begin
      while Tn < N loop
         Triangle_Index := Triangle_Index + 1;
         Tn := Triangle_Number(Triangle_Index);
      end loop;
      
      return Tn = N;
   end Is_Triangle_Number;
   
   -- Read words from file
   File_Name : constant String := "words.txt";
   File      : File_Type;
   Line      : Unbounded_String;
   Words     : Word_Vector(1 .. 2000); -- Assuming maximum 2000 words
   Word_Count : Positive := 0;
   
begin
   -- Open and read the file
   begin
      Open(File, In_File, File_Name);
      
      while not End_Of_File(File) loop
         Line := To_Unbounded_String(Get_Line(File));
         -- Parse the line to extract words (assuming they are comma-separated)
         declare
            Start : Positive := 1;
            Pos   : Natural;
         begin
            loop
               Pos := Index(Line, ",");
               if Pos = 0 then
                  Word_Count := Word_Count + 1;
                  Words(Word_Count) := Slice(Line, Start, Length(Line));
                  exit;
               else
                  Word_Count := Word_Count + 1;
                  Words(Word_Count) := Slice(Line, Start, Pos - 1);
                  Start := Pos + 1;
               end if;
            end loop;
         end;
      end loop;
      
      Close(File);
   exception
      when Name_Error =>
         Put_Line("Error: File not found");
         return;
   end;
   
   -- Count triangle words
   declare
      Triangle_Count : Positive := 0;
   begin
      for I in 1 .. Word_Count loop
         -- Remove quotes from word
         declare
            Clean_Word : Unbounded_String := Words(I);
         begin
            if Length(Clean_Word) >= 2 then
               if Element(Clean_Word, 1) = '"' and Element(Clean_Word, Length(Clean_Word)) = '"' then
                  Clean_Word := Slice(Clean_Word, 2, Length(Clean_Word) - 1);
               end if;
            end if;
            
            if Is_Triangle_Number(Word_Value(Clean_Word)) then
               Triangle_Count := Triangle_Count + 1;
            end if;
         end;
      end loop;
      
      Put_Line("Number of triangle words: " & Positive'Image(Triangle_Count));
   end;
   
end Euler_42;
```

## Explanation

This Ada solution follows these steps:

1. **Triangle Number Calculation**: The `Triangle_Number` function computes the nth triangular number using the formula tn = n(n+1)/2.

2. **Word Value Calculation**: The `Word_Value` function converts each letter to its alphabetical position (A=1, B=2, etc.) and sums these values for a word.

3. **Triangle Number Check**: The `Is_Triangle_Number` function determines if a given number is a triangular number by generating triangle numbers until it either matches or exceeds the target number.

4. **File Processing**: The program reads the words.txt file containing comma-separated words, parses them into individual words, and removes quotation marks.

5. **Counting Triangle Words**: For each word, it calculates the word value and checks if it's a triangle number. It counts all such words.

The solution handles file I/O, string manipulation, and mathematical operations in a clean Ada-style approach. The result gives us the count of triangle words from the provided list of English words.
