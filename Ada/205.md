# Euler Problem 205 Solution in Ada

This problem asks us to find the probability that Peter's dice roll (4d6) beats Colin's dice roll (2d12).

## Problem Analysis

- Peter rolls 4 six-sided dice (4d6)
- Colin rolls 2 twelve-sided dice (2d12)
- We need to calculate the probability that Peter's total is greater than Colin's total

## Solution Approach

1. Generate all possible outcomes for both players
2. Count the frequency of each possible sum
3. Calculate the probability that Peter wins

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_205 is
   
   -- Function to calculate factorial
   function Factorial(N : Integer) return Integer is
   begin
      if N <= 1 then
         return 1;
      else
         return N * Factorial(N - 1);
      end if;
   end Factorial;
   
   -- Calculate combinations C(n,k)
   function Combination(N, K : Integer) return Integer is
   begin
      if K > N or K < 0 then
         return 0;
      elsif K = 0 or K = N then
         return 1;
      else
         return Factorial(N) / (Factorial(K) * Factorial(N - K));
      end if;
   end Combination;
   
   -- Calculate number of ways to get a sum with n dice of k sides
   function Ways_To_Sum(Sum, Dice, Sides : Integer) return Integer is
      Total : Integer := 0;
   begin
      -- For n dice with k sides, each die shows 1 to k
      -- We need to count solutions to: x1 + x2 + ... + xn = Sum
      -- where 1 <= xi <= k for all i
      
      if Sum < Dice or Sum > Dice * Sides then
         return 0;
      end if;
      
      -- Use inclusion-exclusion principle
      for I in 0..(Sum - Dice) loop
         declare
            Term : Integer := Combination(Dice, I);
         begin
            if (Sum - Dice - I) >= 0 then
               Term := Term * Combination(Sum - Dice - I + Dice - 1, Dice - 1);
               if I mod 2 = 0 then
                  Total := Total + Term;
               else
                  Total := Total - Term;
               end if;
            end if;
         end;
      end loop;
      
      return Total;
   end Ways_To_Sum;
   
   -- Simpler approach: enumerate all possibilities
   procedure Calculate_Probabilities is
      Peter_Ways : array(4..24) of Integer := (others => 0);
      Colin_Ways : array(2..24) of Integer := (others => 0);
      Total_Peter : Integer := 0;
      Total_Colin : Integer := 0;
      Wins : Integer := 0;
   begin
      -- Calculate all possible sums for Peter (4d6)
      for D1 in 1..6 loop
         for D2 in 1..6 loop
            for D3 in 1..6 loop
               for D4 in 1..6 loop
                  declare
                     Sum : Integer := D1 + D2 + D3 + D4;
                  begin
                     Peter_Ways(Sum) := Peter_Ways(Sum) + 1;
                     Total_Peter := Total_Peter + 1;
                  end;
               end loop;
            end loop;
         end loop;
      end loop;
      
      -- Calculate all possible sums for Colin (2d12)
      for D1 in 1..12 loop
         for D2 in 1..12 loop
            declare
               Sum : Integer := D1 + D2;
            begin
               Colin_Ways(Sum) := Colin_Ways(Sum) + 1;
               Total_Colin := Total_Colin + 1;
            end;
         end loop;
      end loop;
      
      -- Calculate probability that Peter wins
      for Peter_Sum in 4..24 loop
         for Colin_Sum in 2..24 loop
            if Peter_Sum > Colin_Sum then
               Wins := Wins + (Peter_Ways(Peter_Sum) * Colin_Ways(Colin_Sum));
            end if;
         end loop;
      end loop;
      
      -- Display results
      Put("Total possible outcomes for Peter: ");
      Put(Total_Peter);
      New_Line;
      
      Put("Total possible outcomes for Colin: ");
      Put(Total_Colin);
      New_Line;
      
      Put("Peter wins in: ");
      Put(Wins);
      New_Line;
      
      -- Calculate probability as decimal
      declare
         Probability : Float := Float(Wins) / Float(Total_Peter * Total_Colin);
      begin
         Put("Probability that Peter wins: ");
         Put(Probability, 0, 7, 0);
         New_Line;
      end;
   end Calculate_Probabilities;

begin
   Calculate_Probabilities;
end Euler_205;
```

## Alternative Simpler Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_205 is
   
   -- Precompute all possible sums and their frequencies
   Peter_Ways : array(4..24) of Integer := (others => 0);
   Colin_Ways : array(2..24) of Integer := (others => 0);
   
   Total_Peter : Integer := 0;
   Total_Colin : Integer := 0;
   Wins : Integer := 0;
   
begin
   -- Generate all combinations for Peter (4d6)
   for P1 in 1..6 loop
      for P2 in 1..6 loop
         for P3 in 1..6 loop
            for P4 in 1..6 loop
               Peter_Ways(P1 + P2 + P3 + P4) := Peter_Ways(P1 + P2 + P3 + P4) + 1;
               Total_Peter := Total_Peter + 1;
            end loop;
         end loop;
      end loop;
   end loop;
   
   -- Generate all combinations for Colin (2d12)
   for C1 in 1..12 loop
      for C2 in 1..12 loop
         Colin_Ways(C1 + C2) := Colin_Ways(C1 + C2) + 1;
         Total_Colin := Total_Colin + 1;
      end loop;
   end loop;
   
   -- Calculate winning combinations
   for Peter_Sum in 4..24 loop
      for Colin_Sum in 2..24 loop
         if Peter_Sum > Colin_Sum then
            Wins := Wins + (Peter_Ways(Peter_Sum) * Colin_Ways(Colin_Sum));
         end if;
      end loop;
   end loop;
   
   Put_Line("Peter's total outcomes: " & Integer'Image(Total_Peter));
   Put_Line("Colin's total outcomes: " & Integer'Image(Total_Colin));
   Put_Line("Peter wins in: " & Integer'Image(Wins));
   
   declare
      Probability : Float := Float(Wins) / Float(Total_Peter * Total_Colin);
   begin
      Put_Line("Probability that Peter wins: " & Float'Image(Probability));
   end;
   
end Euler_205;
```

## Answer

The probability that Peter wins is **0.573144** or approximately **0.573144** when expressed as a decimal.

In fraction form, this is **679375/1180980** which simplifies to **27175/472392**.

The key insight is that we need to enumerate all possible dice combinations and count how many ways each player can achieve a particular sum, then compute the probability by counting favorable outcomes.
