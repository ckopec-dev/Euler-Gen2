# Euler Problem 101 Solution in Ada

## Problem Statement
Looking at the optimum polynomial function, we define U(n) as the optimal polynomial function of degree n that best fits the given data points. For this problem, we need to find the sum of the first terms of the optimal polynomials for the sequence defined by u(n) = 1 - n + n² - n³ + n⁴ - n⁵ + n⁶ - n⁷ + n⁸ - n⁹ + n¹⁰.

## Solution Approach
We'll use polynomial interpolation to find the optimal polynomials and then sum the first terms of these polynomials.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_101 is
   
   type Polynomial is array (Integer range <>) of Integer;
   
   -- Function to evaluate a polynomial at point x
   function Evaluate(P : Polynomial; X : Integer) return Integer is
      Result : Integer := 0;
      Power  : Integer := 1;
   begin
      for I in P'First .. P'Last loop
         Result := Result + P(I) * Power;
         Power := Power * X;
      end loop;
      return Result;
   end Evaluate;
   
   -- Function to compute the optimal polynomial using Lagrange interpolation
   function Optimal_Polynomial(Xs, Ys : Polynomial) return Polynomial is
      Degree : constant Integer := Xs'Length - 1;
      Result : Polynomial(0 .. Degree);
      Numerator, Denominator : Integer;
   begin
      for I in 0 .. Degree loop
         Result(I) := 0;
         for J in Xs'First .. Xs'Last loop
            if J /= I then
               Numerator := 1;
               Denominator := 1;
               for K in Xs'First .. Xs'Last loop
                  if K /= J then
                     Numerator := Numerator * (0 - Xs(K));
                     Denominator := Denominator * (Xs(I) - Xs(K));
                  end if;
               end loop;
               Result(I) := Result(I) + Ys(J) * Numerator / Denominator;
            end if;
         end loop;
      end loop;
      return Result;
   end Optimal_Polynomial;
   
   -- Function to compute the sequence u(n) = 1 - n + n^2 - n^3 + ... + n^10
   function U(N : Integer) return Integer is
   begin
      return 1 - N + N*N - N*N*N + N*N*N*N - N*N*N*N*N +
             N*N*N*N*N*N - N*N*N*N*N*N*N + N*N*N*N*N*N*N*N -
             N*N*N*N*N*N*N*N*N + N*N*N*N*N*N*N*N*N*N;
   end U;
   
   -- Function to find the first term of the optimal polynomial
   function First_Term_Of_Optimal_Polynomial(Degree : Integer) return Integer is
      Xs : Polynomial(1 .. Degree);
      Ys : Polynomial(1 .. Degree);
      Poly : Polynomial(0 .. Degree - 1);
      Result : Integer := 0;
   begin
      -- Generate data points
      for I in 1 .. Degree loop
         Xs(I) := I;
         Ys(I) := U(I);
      end loop;
      
      -- Find optimal polynomial of degree (Degree-1)
      Poly := Optimal_Polynomial(Xs, Ys);
      
      -- The first term is the constant term of the polynomial
      return Poly(0);
   end First_Term_Of_Optimal_Polynomial;
   
begin
   -- We need to find the sum of the first terms of optimal polynomials
   -- for degrees 1 through 10 (since we're looking at u(n) = 1 - n + n^2 - ... + n^10)
   declare
      Sum : Integer := 0;
      Term : Integer;
   begin
      for Degree in 1 .. 10 loop
         Term := First_Term_Of_Optimal_Polynomial(Degree);
         Sum := Sum + Term;
         Put_Line("Degree " & Integer'Image(Degree) & ": First term = " & Integer'Image(Term));
      end loop;
      
      Put_Line("Sum of first terms: " & Integer'Image(Sum));
   end;
   
end Euler_101;
```

## Key Points in the Solution

1. **Polynomial Evaluation**: The `Evaluate` function computes the value of a polynomial at a given point using Horner's method.

2. **Lagrange Interpolation**: The `Optimal_Polynomial` function uses Lagrange interpolation to find the optimal polynomial that passes through the given data points.

3. **Sequence Generation**: The `U` function implements the given sequence formula: u(n) = 1 - n + n² - n³ + ... + n¹⁰.

4. **Optimization Strategy**: For each degree from 1 to 10, we compute the optimal polynomial using the first few terms of the sequence and extract its constant term (first term).

The solution computes the sum of the first terms of these optimal polynomials, which gives us the answer to Euler Problem 101.
