# Euler Problem 28 Solution in Ada

Euler Problem 28 asks us to find the sum of the numbers on the diagonals of a 1001×1001 spiral grid, where numbers are arranged in a clockwise spiral starting from 1 at the center.

Let me analyze the pattern:
- The spiral starts with 1 at the center
- Moving clockwise: right, down, left, up, right, down, etc.
- Each layer adds 4 corners that follow a specific pattern

Looking at the spiral, I can see that for each "layer" (starting from layer 1), the four corners follow this pattern:
- Layer 1: corners are 3, 5, 7, 9
- Layer 2: corners are 13, 17, 21, 25
- Layer 3: corners are 31, 37, 43, 49

The pattern for layer n (where n=1,2,3,...) is:
- First corner = (2n+1)² - 6n
- Second corner = (2n+1)² - 4n  
- Third corner = (2n+1)² - 2n
- Fourth corner = (2n+1)²

Let me verify with layer 1:
- (2×1+1)² = 9
- Corners: 9-6, 9-4, 9-2, 9 = 3, 5, 7, 9 ✓

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_28 is
   Total_Sum : Integer := 1;  -- Start with the center value (1)
   Layer     : Integer := 1;
   Max_Layer : constant Integer := 500;  -- For 1001×1001 grid, we need 500 layers
begin
   -- Add the diagonals for each layer
   while Layer <= Max_Layer loop
      declare
         Side_Length : constant Integer := 2 * Layer + 1;
         Square      : constant Integer := Side_Length * Side_Length;
      begin
         -- Add all four corners of this layer
         Total_Sum := Total_Sum + Square;                    -- Top-right corner
         Total_Sum := Total_Sum + Square - 2 * Layer;        -- Top-left corner
         Total_Sum := Total_Sum + Square - 4 * Layer;        -- Bottom-left corner
         Total_Sum := Total_Sum + Square - 6 * Layer;        -- Bottom-right corner
      end;
      
      Layer := Layer + 1;
   end loop;
   
   Put_Line("The sum of the diagonals is: " & Integer'Image(Total_Sum));
end Euler_28;
```

## Alternative Implementation (More Concise)

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_28 is
   Total_Sum : Integer := 1;  -- Center value
   Max_Layer : constant Integer := 500;
begin
   for Layer in 1..Max_Layer loop
      declare
         Square : constant Integer := (2 * Layer + 1) ** 2;
      begin
         Total_Sum := Total_Sum + 4 * Square - 12 * Layer;
      end;
   end loop;
   
   Put_Line("The sum of the diagonals is: " & Integer'Image(Total_Sum));
end Euler_28;
```

## Explanation

The key insight is that for each layer n (starting from 1), we can compute the sum of all four corners directly:
- Each layer's corners are at positions: 
  - (2n+1)², (2n+1)² - 2n, (2n+1)² - 4n, (2n+1)² - 6n
- Sum of these = 4×(2n+1)² - 12n = 4×(4n² + 4n + 1) - 12n = 16n² + 16n + 4 - 12n = 16n² + 4n + 4

For layer n:

- Sum = 4×(2n+1)² - 12n = 4×(4n² + 4n + 1) - 12n = 16n² + 16n + 4 - 12n = 16n² + 4n + 4
