# Euler Problem 57 Solution in Ada

This problem asks us to find how many fractions in the first 1000 expansions of the continued fraction for √2 have a numerator with more digits than the denominator.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with GNAT.Big_Numbers.Big_Integers; use GNAT.Big_Numbers.Big_Integers;

procedure Euler_57 is
   type Fraction is record
      Numerator : Big_Integer;
      Denominator : Big_Integer;
   end record;

   -- Function to compute the next fraction in the sequence
   function Next_Fraction(Prev : Fraction) return Fraction is
   begin
      return (Numerator => Prev.Denominator + Prev.Numerator,
              Denominator => Prev.Numerator);
   end Next_Fraction;

   -- Function to count digits in a big integer
   function Count_Digits(N : Big_Integer) return Natural is
      Temp : Big_Integer := N;
      Count : Natural := 0;
   begin
      if Temp = 0 then
         return 1;
      end if;
      
      while Temp > 0 loop
         Temp := Temp / 10;
         Count := Count + 1;
      end loop;
      
      return Count;
   end Count_Digits;

   -- Main computation
   Current : Fraction := (Numerator => 3, Denominator => 2);
   Count : Natural := 0;
begin
   -- Check first expansion
   if Count_Digits(Current.Numerator) > Count_Digits(Current.Denominator) then
      Count := Count + 1;
   end if;

   -- Compute next 999 expansions
   for I in 2 .. 1000 loop
      Current := Next_Fraction(Current);
      
      if Count_Digits(Current.Numerator) > Count_Digits(Current.Denominator) then
         Count := Count + 1;
      end if;
   end loop;

   Put("Result: ");
   Put(Count);
   New_Line;
end Euler_57;
```

## Explanation

The problem involves the continued fraction expansion of √2, which can be expressed as:
√2 = 1 + 1/(2 + 1/(2 + 1/(2 + ...)))

If we look at the convergents (successive approximations), they follow a pattern where:
- First approximation: 1 + 1/2 = 3/2
- Second approximation: 1 + 1/(2 + 1/2) = 1 + 2/5 = 7/5
- Third approximation: 1 + 1/(2 + 2/5) = 1 + 5/12 = 17/12

We can see that if we have a fraction a/b, the next fraction in the sequence is (a+b)/a.

The key insight is:
- Start with 3/2
- For each subsequent expansion: new_num = old_den + old_num, new_den = old_num
- Count how many times the numerator has more digits than the denominator

This solution uses big integers to handle the large numbers that appear in the continued fraction expansions, since the numerators and denominators grow rapidly.
