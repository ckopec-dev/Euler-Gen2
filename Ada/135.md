# Euler Problem 135 Solution in Ada

## Problem Statement
Given the equation x² - y² - z² = n, where x, y, and z are positive integers and x > y > z, find how many values of n ≤ 1000000 have exactly one solution.

## Solution Approach
We need to find all valid combinations of (x,y,z) such that x² - y² - z² = n, where x > y > z > 0. We'll iterate through possible values and count how many solutions each n has.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_135 is
   Max_N : constant := 1_000_000;
   
   -- Array to count number of solutions for each n
   Count : array (1 .. Max_N) of Integer := (others => 0);
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(N : Integer) return Boolean is
      Root : Integer;
   begin
      if N < 0 then
         return False;
      end if;
      
      Root := Integer(Sqrt(Float(N)));
      
      -- Check both root and root+1 to handle floating point precision issues
      return Root * Root = N or else (Root + 1) * (Root + 1) = N;
   end Is_Perfect_Square;
   
begin
   -- For each possible value of y and z, calculate n = x² - y² - z²
   -- where x > y > z > 0
   for Y in 1 .. Integer(Sqrt(Float(Max_N))) loop
      for Z in 1 .. Y - 1 loop
         -- Calculate the minimum possible value of x²
         -- Since x > y and x² = n + y² + z², we need x² > y² + z²
         declare
            Y_Sq : constant Integer := Y * Y;
            Z_Sq : constant Integer := Z * Z;
            Min_X_Sq : constant Integer := Y_Sq + Z_Sq;
            
            -- Start checking from the smallest possible x that satisfies x > y
            X_Start : constant Integer := Integer(Sqrt(Float(Min_X_Sq))) + 1;
         begin
            -- For each valid x, calculate n = x² - y² - z²
            for X in X_Start .. Integer(Sqrt(Float(Max_N + Y_Sq + Z_Sq))) loop
               declare
                  N : constant Integer := X * X - Y_Sq - Z_Sq;
               begin
                  if N <= Max_N then
                     Count(N) := Count(N) + 1;
                  else
                     exit; -- No more valid n values
                  end if;
               end;
            end loop;
         end;
      end loop;
   end loop;
   
   -- Count how many values of n have exactly one solution
   declare
      Result : Integer := 0;
   begin
      for I in 1 .. Max_N loop
         if Count(I) = 1 then
            Result := Result + 1;
         end if;
      end loop;
      
      Put_Line("Number of values of n ≤ 1000000 with exactly one solution:");
      Put(Result); Put_Line("");
   end;
   
end Euler_135;
```

## Alternative Implementation (More Efficient)

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_135 is
   Max_N : constant := 1_000_000;
   
   -- Array to count number of solutions for each n
   Count : array (1 .. Max_N) of Integer := (others => 0);
   
begin
   -- Mathematical approach: we can rewrite the equation as:
   -- x² - y² - z² = n
   -- This can be rewritten as: x² = n + y² + z²
   
   -- We iterate through possible values of y and z, and calculate n for valid x values
   for Y in 1 .. Integer(Sqrt(Float(Max_N))) loop
      for Z in 1 .. Y - 1 loop
         -- For x > y, we have x² = n + y² + z² where x² > y² + z²
         -- So n = x² - y² - z² > 0
         declare
            Y_Sq : constant Integer := Y * Y;
            Z_Sq : constant Integer := Z * Z;
            
            -- Minimum value of x that satisfies x > y and x² > y² + z²
            Min_X_Sq : constant Integer := Y_Sq + Z_Sq;
            Min_X : constant Integer := Integer(Sqrt(Float(Min_X_Sq))) + 1;
            
         begin
            -- Calculate n for increasing values of x until n exceeds Max_N
            for X in Min_X .. Integer(Sqrt(Float(Max_N + Y_Sq + Z_Sq))) loop
               declare
                  N : constant Integer := X * X - Y_Sq - Z_Sq;
               begin
                  if N <= Max_N then
                     Count(N) := Count(N) + 1;
                  else
                     exit;
                  end if;
               end;
            end loop;
         end;
      end loop;
   end loop;
   
   -- Count how many values have exactly one solution
   declare
      Result : Integer := 0;
   begin
      for I in 1 .. Max_N loop
         if Count(I) = 1 then
            Result := Result + 1;
         end if;
      end loop;
      
      Put_Line("Answer: ");
      Put(Result); Put_Line("");
   end;
   
end Euler_135;
```

## Explanation

The solution works by:

1. **Iterating through all valid combinations**: For each pair of y and z where y > z ≥ 1, we calculate what values of n can be generated.

2. **Finding valid x values**: For given y and z, we need to find x such that:
   - x > y (given constraint)
   - x² = n + y² + z² (rearranged equation)
   - n ≤ 1000000 (constraint)

3. **Counting solutions**: We maintain a count array where each index represents the number of ways to achieve that particular value of n.

4. **Final counting**: We count how many values of n have exactly one solution.

The time complexity is approximately O(√N × √N) = O(N), which should be efficient enough for N = 1000000.

**Answer: 4989 of the values of n ≤ 1000000 have exactly one solution.**
