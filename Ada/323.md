# Euler Problem 323 Solution in Ada

Euler Problem 323 asks for the expected number of operations to make all bits equal to 1 in a binary number, where each operation flips a random bit.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Numerics.Generic_Elementary_Functions;

procedure Euler_323 is
   package Float_IO is new Ada.Text_IO.Float_IO(Float);
   
   -- Number of bits in the binary number
   N : constant := 32;
   
   -- Calculate expected number of operations
   function Expected_Operations(N : Positive) return Float is
      -- Using the mathematical approach:
      -- E[X] = sum from i=1 to N of (1/2^i) * (1/(1-1/2^i))
      -- But more efficiently: E[X] = sum from i=1 to N of 1/(2^i - 1)
      Sum : Float := 0.0;
   begin
      for I in 1 .. N loop
         declare
            Denominator : constant Float := Float(2**I) - 1.0;
         begin
            if Denominator > 0.0 then
               Sum := Sum + 1.0 / Denominator;
            end if;
         end;
      end loop;
      
      return Sum;
   end Expected_Operations;
   
begin
   -- Calculate expected operations for 32 bits
   declare
      Result : constant Float := Expected_Operations(N);
   begin
      Put("Expected number of operations: ");
      Float_IO.Put(Result, Fore => 1, Aft => 10, Exp => 0);
      New_Line;
   end;
   
   -- Alternative approach using the known mathematical formula:
   -- E[X] = sum_{i=1}^{N} 1/(2^i - 1)
   Put_Line("Alternative calculation:");
   declare
      Total : Float := 0.0;
      I     : Integer := 1;
   begin
      while I <= N loop
         declare
            Term : constant Float := 1.0 / (Float(2**I) - 1.0);
         begin
            Total := Total + Term;
            Put("i=");
            Put(I, Width => 2);
            Put(" -> 1/(2^");
            Put(I, Width => 2);
            Put(" - 1) = ");
            Float_IO.Put(Term, Fore => 1, Aft => 6, Exp => 0);
            New_Line;
            I := I + 1;
         end;
      end loop;
      
      Put("Total: ");
      Float_IO.Put(Total, Fore => 1, Aft => 10, Exp => 0);
      New_Line;
   end;
end Euler_323;
```

## Mathematical Analysis

The problem can be approached using the concept of expected value in probability theory. Let's break it down:

1. We start with a binary number of N bits, all initially 0
2. Each operation randomly selects one bit and flips it
3. We want to find the expected number of operations until all bits are 1

This is a classic "Coupon Collector" problem variant. The expected time to get all N bits to be 1 is:

E[T] = Σ(i=1 to N) 1/(2^i - 1)

Where:
- 2^i represents the number of possible states for i bits
- 2^i - 1 represents the number of states where at least one bit differs from all 1s

## Key Insights:

1. **Probability Analysis**: When we have i bits already set to 1, the probability that a random operation will change some other bit is 1/(2^i - 1)
2. **Linearity of Expectation**: We can sum up individual expected waiting times
3. **Convergence**: The series converges quickly since each term decreases exponentially
