# Euler Problem 144 Solution in Ada

This problem involves finding the number of reflections a laser beam makes before escaping an elliptical mirror system.

## Problem Analysis

We need to:
1. Work with an ellipse defined by the equation x² + 4y² = 100
2. Start with a laser beam from (0,10.1) going towards (1.4,-9.6)
3. Find how many times the beam reflects off the ellipse before escaping

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Float_Text_IO; use Ada.Float_Text_IO;

procedure Euler_144 is
   type Point is record
      X, Y : Float;
   end record;
   
   type Vector is record
      X, Y : Float;
   end record;
   
   -- Ellipse parameters: x² + 4y² = 100
   -- This is an ellipse with a = 10, b = 5
   A_Squared : constant Float := 100.0;
   B_Squared : constant Float := 25.0;
   
   -- Starting point and direction
   Start_Point : constant Point := (X => 0.0, Y => 10.1);
   Direction_Vector : constant Vector := (X => 1.4, Y => -9.6);
   
   function Normalize(V : Vector) return Vector is
      Length : constant Float := sqrt(V.X * V.X + V.Y * V.Y);
   begin
      if Length = 0.0 then
         return (X => 0.0, Y => 0.0);
      else
         return (X => V.X / Length, Y => V.Y / Length);
      end if;
   end Normalize;
   
   function Dot_Product(V1, V2 : Vector) return Float is
   begin
      return V1.X * V2.X + V1.Y * V2.Y;
   end Dot_Product;
   
   function Reflect(I, N : Vector) return Vector is
      -- Reflect incident vector I about normal N
      -- R = I - 2 * (I · N) * N
      Dot : constant Float := Dot_Product(I, N);
   begin
      return (X => I.X - 2.0 * Dot * N.X,
              Y => I.Y - 2.0 * Dot * N.Y);
   end Reflect;
   
   function Get_Normal(P : Point) return Vector is
      -- Normal vector to ellipse at point P
      -- For x²/a² + y²/b² = 1, normal at (x,y) is (2x/a², 2y/b²)
      -- Normalized to unit vector
      X_Component : constant Float := 2.0 * P.X / A_Squared;
      Y_Component : constant Float := 2.0 * P.Y / B_Squared;
      Length : constant Float := sqrt(X_Component * X_Component + 
                                     Y_Component * Y_Component);
   begin
      if Length = 0.0 then
         return (X => 0.0, Y => 1.0); -- Default normal
      else
         return (X => -X_Component / Length, Y => -Y_Component / Length);
      end if;
   end Get_Normal;
   
   function Point_Equals(P1, P2 : Point; Epsilon : Float := 1.0E-6) return Boolean is
   begin
      return abs (P1.X - P2.X) < Epsilon and then abs (P1.Y - P2.Y) < Epsilon;
   end Point_Equals;
   
   function Distance(P1, P2 : Point) return Float is
   begin
      return sqrt((P1.X - P2.X)**2 + (P1.Y - P2.Y)**2);
   end Distance;
   
   function Is_Outside_Ellipse(P : Point) return Boolean is
      -- Check if point is outside the ellipse x² + 4y² = 100
   begin
      return P.X**2 + 4.0 * P.Y**2 > 100.0;
   end Is_Outside_Ellipse;
   
   function Intersect_Line_Ellipse(P : Point; V : Vector) return Float is
      -- Find intersection parameter t such that (P + t*V) intersects ellipse
      -- x² + 4y² = 100
      -- (Px + t*Vx)² + 4*(Py + t*Vy)² = 100
      -- Px² + 2*Px*Vx*t + Vx²*t² + 4*Py² + 8*Py*Vy*t + 4*Vy²*t² = 100
      -- (Vx² + 4*Vy²)*t² + (2*Px*Vx + 8*Py*Vy)*t + (Px² + 4*Py² - 100) = 0
      
      A : constant Float := V.X**2 + 4.0 * V.Y**2;
      B : constant Float := 2.0 * P.X * V.X + 8.0 * P.Y * V.Y;
      C : constant Float := P.X**2 + 4.0 * P.Y**2 - 100.0;
      
      Discriminant : constant Float := B**2 - 4.0 * A * C;
   begin
      if Discriminant < 0.0 then
         return Float'Last; -- No intersection
      elsif abs A < 1.0E-10 then
         -- Linear case: B*t + C = 0, so t = -C/B
         if abs B < 1.0E-10 then
            return Float'Last; -- No solution
         else
            return -C / B;
         end if;
      else
         declare
            Sqrt_Disc : constant Float := sqrt(Discriminant);
         begin
            -- We want the first intersection (positive t)
            -- The smaller root gives us the first hit
            return (-B - Sqrt_Disc) / (2.0 * A);
         end;
      end if;
   end Intersect_Line_Ellipse;
   
   function Next_Intersection(P : Point; V : Vector) return Point is
      T : constant Float := Intersect_Line_Ellipse(P, V);
   begin
      if T = Float'Last then
         return (X => Float'Last, Y => Float'Last); -- No intersection
      else
         return (X => P.X + T * V.X, Y => P.Y + T * V.Y);
      end if;
   end Next_Intersection;
   
   procedure Test_Ellipse is
   begin
      -- Verify that our ellipse equation works
      null;
   end Test_Ellipse;
   
   function Solve return Natural is
      Current_Position : Point := Start_Point;
      Current_Direction : Vector := Normalize(Direction_Vector);
      Reflection_Count : Natural := 0;
      Max_Iterations : constant Natural := 10000;
      Tolerance : constant Float := 1.0E-6;
      
      -- Starting point is outside ellipse
   begin
      -- Main simulation loop
      for Iter in 1 .. Max_Iterations loop
         declare
            Next_Point : Point;
            Normal_Vector : Vector;
            New_Direction : Vector;
            Distance_To_Ellipse : Float;
         begin
            -- Find next intersection point
            Next_Point := Next_Intersection(Current_Position, Current_Direction);
            
            -- Check if we have a valid intersection
            if Next_Point.X = Float'Last then
               exit; -- No more intersections
            end if;
            
            -- Get normal at intersection point
            Normal_Vector := Get_Normal(Next_Point);
            
            -- Reflect the beam
            New_Direction := Reflect(Current_Direction, Normal_Vector);
            
            -- Update position and direction
            Current_Position := Next_Point;
            Current_Direction := New_Direction;
            
            Reflection_Count := Reflection_Count + 1;
            
            -- Check if we've escaped the ellipse (outside the boundary)
            -- The entrance point is at (0,10.1) which is outside the ellipse
            -- We escape when we're sufficiently far from the ellipse center
            if Distance(Current_Position, (X => 0.0, Y => 0.0)) > 20.0 then
               exit;
            end if;
            
            -- Additional termination condition: check if we're in the escape region
            -- The beam escapes if it goes through the opening at top of ellipse
            -- This is a more precise way to detect escape
            if abs Current_Position.X < 0.1 and then Current_Position.Y > 9.9 then
               exit;
            end if;
            
         end;
      end loop;
      
      return Reflection_Count;
   end Solve;
   
begin
   Put_Line("Solving Euler Problem 144:");
   Put_Line("Number of reflections before escaping: ");
   Put(Integer'Image(Solve));
   New_Line;
end Euler_144;
```

## Explanation

This solution works by:

1. **Modeling the ellipse**: The equation x² + 4y² = 100 represents an ellipse with semi-major axis a = 10 and semi-minor axis b = 5.

2. **Ray tracing**: Starting from (0,10.1) in the direction of (1.4,-9.6), we trace the laser beam's path.

3. **Reflection calculation**: At each intersection with the ellipse, we:
   - Find the normal vector to the ellipse surface
   - Calculate the reflected direction using the reflection formula R = I - 2(I·N)N

4. **Termination condition**: The beam escapes when it passes through the opening at the top of the ellipse.

5. **Numerical precision**: We use appropriate tolerances to handle floating-point comparisons.

The solution uses the mathematical property that for an ellipse x²/a² + y²/b² = 1, the normal vector at point (x,y) is proportional to (2x/a², 2y/b²), which gives us the correct reflection direction.

This approach efficiently simulates the physics of the elliptical mirror system and counts the number of reflections before escape.
