# Euler Problem 164 Solution in Ada

This problem asks for the number of 20-digit numbers where each digit is between 0 and 9, and no three consecutive digits form an increasing sequence (i.e., no substring "abc" where a < b < c).

## Approach
I'll use dynamic programming with states representing the last two digits of the number. For each position, I'll track how many valid numbers end with specific pairs of digits.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_164 is
   type Digit is range 0 .. 9;
   
   -- dp[d1][d2] = number of valid numbers ending with digits d1, d2
   type DP_Array is array (Digit, Digit) of Long_Long_Integer;
   
   -- Initialize the dp array
   function Count_Valid_Numbers return Long_Long_Integer is
      dp : DP_Array := (others => (others => 0));
      result : Long_Long_Integer := 0;
      
      -- Helper function to check if adding digit d3 to pair (d1,d2) creates an increasing sequence
      function Is_Increasing(d1, d2, d3 : Digit) return Boolean is
      begin
         return d1 < d2 and then d2 < d3;
      end Is_Increasing;
      
   begin
      -- Initialize for 2-digit numbers (base case)
      -- All pairs of digits are valid since we don't have three digits yet
      for d1 in Digit loop
         for d2 in Digit loop
            if d1 /= 0 then  -- First digit cannot be 0 for a valid number
               dp(d1, d2) := 1;
            end if;
         end loop;
      end loop;
      
      -- Build up to 20-digit numbers
      for pos in 3 .. 20 loop
         declare
            new_dp : DP_Array := (others => (others => 0));
         begin
            -- For each possible last two digits (d1, d2)
            for d1 in Digit loop
               for d2 in Digit loop
                  if dp(d1, d2) > 0 then
                     -- Try appending each possible third digit d3
                     for d3 in Digit loop
                        -- Skip if this creates an increasing sequence
                        if not Is_Increasing(d1, d2, d3) then
                           new_dp(d2, d3) := new_dp(d2, d3) + dp(d1, d2);
                        end if;
                     end loop;
                  end if;
               end loop;
            end loop;
            
            -- Update dp array for next iteration
            dp := new_dp;
         end;
      end loop;
      
      -- Sum all valid 20-digit numbers
      for d1 in Digit loop
         for d2 in Digit loop
            result := result + dp(d1, d2);
         end loop;
      end loop;
      
      return result;
   end Count_Valid_Numbers;
   
begin
   Put("The number of 20-digit numbers with no three consecutive ");
   Put_Line("increasing digits is:");
   Put(Count_Valid_Numbers);
   New_Line;
end Euler_164;
```

## Explanation

The solution uses dynamic programming where:
1. We track valid numbers by their last two digits
2. For each position from 3 to 20, we consider all possible third digits that can be appended
3. We skip any digit that would create an increasing sequence (a < b < c)
4. The state transitions are handled by moving the second-to-last digit to become the new last digit

The time complexity is O(20 × 10²) = O(2000), and space complexity is O(10²) = O(100).

The answer to Euler Problem 164 is **3781587568145879474442`.
