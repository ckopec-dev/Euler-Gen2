# Euler Problem 246 Solution in Ada

This problem asks for the number of lattice points inside a specific elliptical region.

Let me analyze the problem first:
- We have an ellipse with equation: (x²/900) + (y²/400) = 1
- We need to count lattice points (integer coordinates) that satisfy this inequality
- The ellipse has semi-major axis a = 30 and semi-minor axis b = 20

Here's my Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_246 is
   Count : Integer := 0;
   
   -- Ellipse parameters: x²/900 + y²/400 <= 1
   -- So: x²/900 + y²/400 = 1
   -- Therefore: x² = 900 * (1 - y²/400)
   -- Or: x² = 900 - 9*y²/4
   
   -- For a given y, we need to find how many integer x values satisfy the condition
   -- This means: |x| <= sqrt(900 - 9*y²/4)
   
begin
   -- We iterate through possible y values from -20 to 20 (since b = 20)
   for Y in -20 .. 20 loop
      -- Calculate the maximum x value for this y
      -- x² = 900 - 9*y²/4
      declare
         X_Squared : Integer := 900 - (9 * Y * Y) / 4;
         
         -- If x² is negative, no real solutions exist
         X_Max   : Integer;
      begin
         if X_Squared < 0 then
            null;  -- No lattice points for this y
         else
            -- Find the maximum integer x value
            X_Max := Integer(Sqrt(Float(X_Squared)));
            
            -- Count all integer x values from -X_Max to X_Max inclusive
            Count := Count + (2 * X_Max + 1);
         end if;
      end;
   end loop;
   
   Put_Line("Number of lattice points: ");
   Put(Count, 0);
   New_Line;
end Euler_246;
```

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Numerics.Elementary_Functions; use Ada.Numerics.Elementary_Functions;

procedure Euler_246 is
   Count : Integer := 0;
   
begin
   -- Ellipse: x²/900 + y²/400 <= 1
   -- For each integer y from -20 to 20:
   for Y in -20 .. 20 loop
      declare
         Y_Squared : constant Integer := Y * Y;
         X_Max_Squared : constant Float := 900.0 - (9.0 * Float(Y_Squared)) / 4.0;
         
         -- If x² is negative, no valid points for this y
         X_Max : Integer;
      begin
         if X_Max_Squared >= 0.0 then
            X_Max := Integer(Sqrt(X_Max_Squared));
            Count := Count + (2 * X_Max + 1);
         end if;
      end;
   end loop;
   
   Put_Line("Number of lattice points: ");
   Put(Count, 0);
   New_Line;
end Euler_246;
```

This solution:
1. Iterates through all possible integer y-values from -20 to 20
2. For each y, calculates the maximum x² value that satisfies the ellipse inequality
3. Takes the integer square root of this maximum x² to find how many integer x values exist
4. Adds (2 * X_Max + 1) to the count for each valid y (the +1 accounts for x=0)
5. Returns the total count
