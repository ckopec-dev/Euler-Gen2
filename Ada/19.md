# Euler Problem 19 Solution in Ada

## Problem Statement
You are given the following information, but you should try to solve it yourself first!

- 1 Jan 1900 was a Monday.
- Thirty days has September,
  April, June and November.
  All the rest have thirty-one,
  Saving February alone,
  Which has twenty-eight, rain or shine.
  And on leap years, twenty-nine.
- A leap year occurs on any year evenly divisible by 4, but not on a century unless it is divisible by 400.

How many Sundays fell on the first of the month during the twentieth century (1 Jan 1901 to 31 Dec 2000)?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_19 is
   type Day_Type is (Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday);
   
   -- Function to check if a year is a leap year
   function Is_Leap_Year(Year : Integer) return Boolean is
   begin
      return (Year mod 4 = 0 and Year mod 100 /= 0) or else (Year mod 400 = 0);
   end Is_Leap_Year;
   
   -- Function to get number of days in a month
   function Days_In_Month(Month, Year : Integer) return Integer is
   begin
      case Month is
         when 1 | 3 | 5 | 7 | 8 | 10 | 12 =>
            return 31;
         when 4 | 6 | 9 | 11 =>
            return 30;
         when 2 =>
            if Is_Leap_Year(Year) then
               return 29;
            else
               return 28;
            end if;
      end case;
   end Days_In_Month;
   
   -- Function to get the day of the week for a given date
   function Get_Day_Of_Week(Day, Month, Year : Integer) return Day_Type is
      Total_Days : Integer := 0;
      -- Start from 1 Jan 1900 (Monday)
      -- We need to count days from 1 Jan 1900 to our target date
   begin
      -- Add days for complete years before the target year
      for Y in 1900 .. Year - 1 loop
         if Is_Leap_Year(Y) then
            Total_Days := Total_Days + 366;
         else
            Total_Days := Total_Days + 365;
         end if;
      end loop;
      
      -- Add days for complete months before the target month in the target year
      for M in 1 .. Month - 1 loop
         Total_Days := Total_Days + Days_In_Month(M, Year);
      end loop;
      
      -- Add the day of the month (subtract 1 because we're counting from day 1)
      Total_Days := Total_Days + Day - 1;
      
      -- Return the day of the week (Monday = 0, Sunday = 6)
      return Day_Type'Val(Total_Days mod 7);
   end Get_Day_Of_Week;
   
   Count : Integer := 0;
   Current_Day : Day_Type;
begin
   -- Iterate through all months from 1901 to 2000
   for Year in 1901 .. 2000 loop
      for Month in 1 .. 12 loop
         -- Check if the first day of the month is a Sunday
         Current_Day := Get_Day_Of_Week(1, Month, Year);
         if Current_Day = Sunday then
            Count := Count + 1;
         end if;
      end loop;
   end loop;
   
   Put_Line("Number of Sundays on first day of month: " & Integer'Image(Count));
end Euler_19;
```

## Explanation

This solution works by:

1. **Defining a Day_Type** with all seven days of the week
2. **Creating helper functions**:
   - `Is_Leap_Year`: Determines if a year is a leap year according to the rules
   - `Days_In_Month`: Returns the number of days in a given month and year
   - `Get_Day_Of_Week`: Calculates what day of the week a specific date falls on

3. **Main logic**:
   - Iterate through all months from 1901 to 2000
   - For each month, check if the first day (day 1) falls on a Sunday
   - Count such occurrences

4. **Day calculation approach**:
   - Start from January 1, 1900 (which is a Monday)
   - Calculate total days elapsed since that date
   - Use modulo 7 to determine the day of the week

The answer is **171 Sundays** that fell on the first of the month during the twentieth century.
