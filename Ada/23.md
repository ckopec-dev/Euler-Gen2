# Euler Problem 23 Solution in Ada

## Problem Statement
A perfect number is a positive integer that is equal to the sum of its proper divisors. A number n is called deficient if the sum of its proper divisors is less than n, and abundant if this sum exceeds n.

Find the sum of all the positive integers which cannot be written as the sum of two abundant numbers.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_23 is
   
   -- Maximum number to check (based on mathematical analysis)
   Max_Number : constant := 28123;
   
   -- Array to store whether a number is abundant
   Is_Abundant : array (1 .. Max_Number) of Boolean := (others => False);
   
   -- Array to store all abundant numbers
   Abundant_Numbers : array (1 .. Max_Number) of Integer := (others => 0);
   Abundant_Count : Integer := 0;
   
   -- Function to calculate sum of proper divisors
   function Sum_Of_Divisors(N : Integer) return Integer is
      Sum : Integer := 0;
   begin
      for I in 1 .. N/2 loop
         if N mod I = 0 then
            Sum := Sum + I;
         end if;
      end loop;
      return Sum;
   end Sum_Of_Divisors;
   
   -- Function to check if a number is abundant
   function Is_Abundant_Number(N : Integer) return Boolean is
   begin
      return Sum_Of_Divisors(N) > N;
   end Is_Abundant_Number;
   
begin
   -- Find all abundant numbers up to Max_Number
   for I in 1 .. Max_Number loop
      if Is_Abundant_Number(I) then
         Is_Abundant(I) := True;
         Abundant_Count := Abundant_Count + 1;
         Abundant_Numbers(Abundant_Count) := I;
      end if;
   end loop;
   
   -- Array to track which numbers can be expressed as sum of two abundant numbers
   declare
      Can_Be_Sum : array (1 .. Max_Number) of Boolean := (others => False);
      Total_Sum : Integer := 0;
   begin
      -- Mark all possible sums of two abundant numbers
      for I in 1 .. Abundant_Count loop
         for J in I .. Abundant_Count loop
            declare
               Sum : constant Integer := Abundant_Numbers(I) + Abundant_Numbers(J);
            begin
               if Sum <= Max_Number then
                  Can_Be_Sum(Sum) := True;
               else
                  exit;  -- No need to check further since numbers are increasing
               end if;
            end;
         end loop;
      end loop;
      
      -- Calculate sum of numbers that cannot be expressed as sum of two abundant numbers
      for I in 1 .. Max_Number loop
         if not Can_Be_Sum(I) then
            Total_Sum := Total_Sum + I;
         end if;
      end loop;
      
      Put_Line("Sum of all positive integers that cannot be written as sum of two abundant numbers:");
      Put(Total_Sum);
      New_Line;
   end;
   
end Euler_23;
```

## Explanation

1. **Problem Understanding**: We need to find the sum of all positive integers that cannot be expressed as the sum of two abundant numbers.

2. **Approach**:
   - First, identify all abundant numbers up to 28123 (this is known to be the upper limit for this problem)
   - Create a boolean array marking which numbers are abundant
   - For each pair of abundant numbers, mark their sum as "can be expressed as sum of two abundant numbers"
   - Sum all numbers that were never marked

3. **Key Functions**:
   - `Sum_Of_Divisors`: Calculates the sum of proper divisors for a given number
   - `Is_Abundant_Number`: Determines if a number is abundant (sum of divisors > number)

4. **Optimization**: 
   - We only check pairs where I ≤ J to avoid duplicate calculations
   - Once a sum exceeds 28123, we break out of the inner loop since numbers are increasing

5. **Result**: The program outputs 4179871, which is the sum of all positive integers that cannot be written as the sum of two abundant numbers.

The solution uses an efficient approach by precomputing abundant numbers and then using them to mark all possible sums, rather than checking each number individually for representation as a sum.
