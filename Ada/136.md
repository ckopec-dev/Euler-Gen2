# Euler Problem 136 Solution in Ada

This problem asks us to find how many values of n less than fifty million have exactly one solution to the equation x² - y² = n where x and y are positive integers.

Let me analyze the mathematical structure first:
- x² - y² = n
- (x-y)(x+y) = n
- Let a = x-y and b = x+y, so ab = n
- Then x = (a+b)/2 and y = (b-a)/2
- For x,y to be positive integers, a and b must have the same parity and b > a > 0

## Mathematical Analysis

For each factor pair (a,b) of n where ab = n:
1. Both a and b must have the same parity (both odd or both even)
2. b > a > 0
3. x = (a+b)/2 and y = (b-a)/2 must be positive integers

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_136 is
   Limit : constant := 50_000_000;
   Count : Integer := 0;
   
   function Is_Solution(n : Integer) return Boolean is
      Solution_Count : Integer := 0;
      a, b : Integer;
   begin
      -- Check all possible factor pairs of n
      a := 1;
      while a * a <= n loop
         if n mod a = 0 then
            b := n / a;
            
            -- Check if both a and b have same parity
            if (a mod 2) = (b mod 2) then
               -- Check if b > a > 0
               if b > a and a > 0 then
                  Solution_Count := Solution_Count + 1;
               end if;
            end if;
         end if;
         a := a + 1;
      end loop;
      
      return Solution_Count = 1;
   end Is_Solution;
   
begin
   for n in 1..Limit loop
      if Is_Solution(n) then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("Answer: ");
   Put(Count);
   New_Line;
end Euler_136;
```

The key insight is that we're looking for values of n where there's exactly one way to write n = x² - y² with x,y positive integers.

For a solution to exist: n = (x-y)(x+y) = ab where a = x-y, b = x+y.
