# Euler Problem 90 Solution in Ada

## Problem Statement
Each of the six faces on a cube is marked with a distinct digit (0-9). Two cubes are placed side by side to form a pair of digits. For example, the cubes (0,1,2,3,4,5) and (6,7,8,9,0,1) can be used to form the numbers 06, 17, 28, 39, etc.

How many distinct arrangements of two cubes can represent all the square numbers less than 100?

## Solution Approach
1. Generate all possible combinations of 6 digits from 0-9 for each cube
2. For each pair of cubes, check if they can form all square numbers (01, 04, 09, 16, 25, 36, 49, 64, 81)
3. Handle special cases where 6 and 9 can be used interchangeably
4. Count valid arrangements

## Final Answer

The number of distinct arrangements of two cubes that can represent all the square numbers less than 100 is **1217**.

The solution involves:
1. Generating all possible combinations of 6 digits from 0-9 (210 total combinations)
2. Checking each pair of combinations to see if they can form all required square numbers
3. Handling the special case where 6 and 9 are interchangeable
4. Counting valid pairs while avoiding duplicate counting

The key insight is that we must be careful about ordering - arrangements like (0,1,2,3,4,5) and (6,7,8,9,0,1) are considered the same as (6,7,8,9,0,1) and (0,1,2,3,4,5), so we only count each unique pair once.
