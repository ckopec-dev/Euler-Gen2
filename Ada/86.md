# Euler Problem 86 Solution in Ada

## Problem Statement
A spider, S, sits in one corner of a cuboid room, measuring 6 by 5 by 3, and a fly, F, sits in the opposite corner. By travelling on the surfaces of the room the shortest "straight line" distance from S to F is 10 and the path is shown on the diagram.

However, there are up to three "shortest" paths for any given cuboid and the shortest route doesn't always involve the wall faces. For example, the shortest path from S to F when the room measures 6 by 5 by 3 is 10.

Let M be the least value of M such that the number of solutions first exceeds one thousand; that is, there are at least 1000 cuboids (not necessarily distinct) with integer dimensions, up to a maximum dimension of M, for which the shortest distance is an integer.

## Solution Approach
We need to find cuboids with integer dimensions (a,b,c) where a ≤ b ≤ c and the shortest path distance is an integer.

The key insight is that when unfolding the cuboid, we can get three possible distances:
1. √((a+b)² + c²)
2. √((a+c)² + b²)  
3. √((b+c)² + a²)

We want the minimum of these three, which occurs when we have the shortest path on the surface.

For any cuboid with dimensions (a,b,c), where a ≤ b ≤ c, the shortest path is:
√( (a+b)² + c² ) = √( a² + 2ab + b² + c² )

We need this to be an integer. For each value of M, we count how many valid cuboids exist.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_86 is
   type Integer_Array is array (Positive range <>) of Integer;
   
   function Is_Perfect_Square(N : Integer) return Boolean is
      Root : Integer := Integer(Sqrt(Float(N)));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
   function Count_Solutions(M : Integer) return Integer is
      Count : Integer := 0;
      A, B, C : Integer;
      Distance_Squared : Integer;
   begin
      -- For each possible cuboid with dimensions a <= b <= c
      for C in 1..M loop
         for B in 1..C loop
            for A in 1..B loop
               -- Calculate the squared distance of the shortest path
               -- This is min((a+b)^2 + c^2, (a+c)^2 + b^2, (b+c)^2 + a^2)
               -- The minimum occurs when we have the shortest surface distance
               Distance_Squared := (A + B) * (A + B) + C * C;
               
               if Is_Perfect_Square(Distance_Squared) then
                  Count := Count + 1;
               end if;
            end loop;
         end loop;
      end loop;
      
      return Count;
   end Count_Solutions;
   
   M : Integer := 100;
   Solutions : Integer;
begin
   loop
      Solutions := Count_Solutions(M);
      Put("M = "); Put(M); Put(", Solutions = "); Put(Solutions); New_Line;
      
      if Solutions > 1000 then
         Put_Line("Answer: " & Integer'Image(M));
         exit;
      end if;
      
      M := M + 1;
   end loop;
end Euler_86;
```

## Optimized Version

The above approach is inefficient for large values. Here's a more optimized version that uses mathematical insights:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_86 is
   function Is_Perfect_Square(N : Integer) return Boolean is
      Root : Integer := Integer(Sqrt(Float(N)));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
   function Count_Solutions(M : Integer) return Integer is
      Count : Integer := 0;
      C : Integer;
      A, B : Integer;
      Distance_Squared : Integer;
      Limit : constant Integer := M + M; -- Since a+b can be at most 2*M
   begin
      for C in 1..M loop
         -- For each c, iterate through all possible values of a+b
         -- where a <= b <= c and a >= 1
         for AB in 2..Limit loop
            Distance_Squared := AB * AB + C * C;
            
            if Is_Perfect_Square(Distance_Squared) then
               -- Count how many valid (a,b) pairs exist for this AB
               for A in 1..(AB-1)/2 loop
                  B := AB - A;
                  if B >= A and B <= C then
                     Count := Count + 1;
                  end if;
               end loop;
            end if;
         end loop;
      end loop;
      
      return Count;
   end Count_Solutions;
   
   M : Integer := 100;
   Solutions : Integer;
begin
   loop
      Solutions := Count_Solutions(M);
      Put("M = "); Put(M); Put(", Solutions = "); Put(Solutions); New_Line;
      
      if Solutions > 1000 then
         Put_Line("Answer: " & Integer'Image(M));
         exit;
      end if;
      
      M := M + 1;
   end loop;
end Euler_86;
```

## Final Optimized Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_86 is
   function Is_Perfect_Square(N : Integer) return Boolean is
      Root : Integer := Integer(Sqrt(Float(N)));
   begin
      return Root * Root = N;
   end Is_Perfect_Square;
   
   function Count_Solutions(M : Integer) return Integer is
      Count : Integer := 0;
      C : Integer;
      AB : Integer;
      Distance_Squared : Integer;
   begin
      for C in 1..M loop
         -- For each c, we need to find all valid a+b combinations
         for AB in 2..2*M loop
            Distance_Squared := AB * AB + C * C;
            
            if Is_Perfect_Square(Distance_Squared) then
               -- Count valid (a,b) pairs where a <= b <= c and a+b = AB
               -- This means we need 1 <= a <= b <= c and a+b = AB
               -- So we have: a <= AB/2, a >= 1, and AB-a <= c
               -- Which gives us: max(1, AB-c) <= a <= min(AB/2, c)
               
               declare
                  Min_A : constant Integer := Integer'Max(1, AB - C);
                  Max_A : constant Integer := Integer'Min(AB / 2, C);
               begin
                  if Min_A <= Max_A then
                     Count := Count + (Max_A - Min_A + 1);
                  end if;
               end;
            end if;
         end loop;
      end loop;
      
      return Count;
   end Count_Solutions;
   
   M : Integer := 100;
   Solutions : Integer;
begin
   loop
      Solutions := Count_Solutions(M);
      Put("M = "); Put(M); Put(", Solutions = "); Put(Solutions); New_Line;
      
      if Solutions > 1000 then
         Put_Line("Answer: " & Integer'Image(M));
         exit;
      end if;
      
      M := M + 1;
   end loop;
end Euler_86;
```
