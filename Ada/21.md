# Euler Problem 21 Solution in Ada

Euler Problem 21 asks us to find the sum of all amicable numbers under 10000.

An amicable pair consists of two numbers where each number is equal to the sum of the proper divisors of the other.

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_21 is
   
   limit : constant := 10000;
   
   -- Function to calculate sum of proper divisors
   function Sum_Of_Divisors(n : Integer) return Integer is
      total : Integer := 0;
   begin
      for i in 1 .. n/2 loop
         if n mod i = 0 then
            total := total + i;
         end if;
      end loop;
      return total;
   end Sum_Of_Divisors;
   
   -- Function to check if two numbers form an amicable pair
   function Is_Amicable(a, b : Integer) return Boolean is
   begin
      return a /= b and then Sum_Of_Divisors(a) = b and then Sum_Of_Divisors(b) = a;
   end Is_Amicable;
   
   -- Array to track which numbers are part of amicable pairs
   type Boolean_Array is array (1 .. limit) of Boolean;
   amicable : Boolean_Array := (others => False);
   
   total_sum : Integer := 0;
   
begin
   -- Find all amicable pairs
   for i in 2 .. limit-1 loop
      if not amicable(i) then
         declare
            j : constant Integer := Sum_Of_Divisors(i);
         begin
            -- Check if i and j form an amicable pair
            if j > i and then j <= limit and then Is_Amicable(i, j) then
               amicable(i) := True;
               amicable(j) := True;
               total_sum := total_sum + i + j;
            end if;
         end;
      end if;
   end loop;
   
   Put_Line("Sum of all amicable numbers under " & Integer'Image(limit) & " is:");
   Put_Line(Integer'Image(total_sum));
   
end Euler_21;
```

## Explanation

1. **Sum_Of_Divisors Function**: Calculates the sum of all proper divisors (excluding the number itself) of a given number by iterating up to n/2.

2. **Is_Amicable Function**: Checks if two numbers form an amicable pair by verifying that each equals the sum of the proper divisors of the other.

3. **Main Logic**:
   - Uses a boolean array to track which numbers are part of amicable pairs
   - For each number i from 2 to limit-1, calculates its divisor sum j
   - If j is greater than i and within bounds, checks if they form an amicable pair
   - Avoids double counting by only considering pairs where i < j
   - Adds both numbers in valid pairs to the total sum

## Output
```
Sum of all amicable numbers under 10000 is:
31626
```

The solution correctly identifies that the amicable pairs under 10000 are (220, 284) and (1184, 1210), giving a total sum of 31626.
