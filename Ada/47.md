# Euler Problem 47 Solution in Ada

Euler Problem 47 asks: "Find the first four consecutive integers that each have four distinct prime factors."

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_47 is
   
   -- Function to count distinct prime factors
   function Count_Distinct_Factors(N : Integer) return Integer is
      Count : Integer := 0;
      I     : Integer := 2;
      Temp  : Integer := N;
   begin
      if N < 2 then
         return 0;
      end if;
      
      while I * I <= Temp loop
         if Temp mod I = 0 then
            Count := Count + 1;
            -- Remove all instances of this prime factor
            while Temp mod I = 0 loop
               Temp := Temp / I;
            end loop;
         end if;
         I := I + 1;
      end loop;
      
      -- If Temp > 1, then it's a prime factor
      if Temp > 1 then
         Count := Count + 1;
      end if;
      
      return Count;
   end Count_Distinct_Factors;
   
   -- Main search loop
   N : Integer := 1;
begin
   loop
      if Count_Distinct_Factors(N) = 4 and
         Count_Distinct_Factors(N + 1) = 4 and
         Count_Distinct_Factors(N + 2) = 4 and
         Count_Distinct_Factors(N + 3) = 4 then
         Put_Line("First four consecutive integers with four distinct prime factors:");
         Put_Line(Integer'Image(N));
         Put_Line(Integer'Image(N + 1));
         Put_Line(Integer'Image(N + 2));
         Put_Line(Integer'Image(N + 3));
         Put_Line("Answer: " & Integer'Image(N));
         exit;
      end if;
      N := N + 1;
   end loop;
end Euler_47;
```

## Explanation

The solution works as follows:

1. **`Count_Distinct_Factors` function**: 
   - Takes an integer N and returns the count of distinct prime factors
   - Uses trial division to find prime factors
   - For each prime factor found, it divides N by that factor completely before moving to the next potential factor
   - Handles the case where a remaining value > 1 is itself a prime factor

2. **Main loop**:
   - Starts checking from N = 1
   - For each number, checks if it and the next three consecutive numbers all have exactly 4 distinct prime factors
   - When found, prints the four consecutive numbers and exits

3. **Key optimization**:
   - The factor removal logic ensures we don't count repeated prime factors (e.g., 12 = 2² × 3 has only 2 distinct prime factors, not 3)
   - We only check up to √N for potential factors to improve efficiency

The answer is the first of the four consecutive integers that satisfy the condition.
