# Euler Problem 280 Solution in Ada

I'll solve Project Euler Problem 280, which involves a knight's random walk on a 3x3 chessboard.

## Problem Understanding

The problem asks for the expected number of steps to visit all cells of a 3×3 chessboard starting from the center, where the knight moves randomly to adjacent squares with equal probability.
