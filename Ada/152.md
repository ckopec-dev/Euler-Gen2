# Euler Problem 152 Solution in Ada

Euler Problem 152 asks: "Find the number of ways to write 1/2 as a sum of inverse squares where each denominator is a positive integer not exceeding 100."

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with GNATCOLL.Integers;

procedure Euler_152 is
   type Fraction is record
      Num : Integer;
      Den : Integer;
   end record;

   function "+" (F1, F2 : Fraction) return Fraction is
      D : constant Integer := F1.Den * F2.Den;
      N : constant Integer := F1.Num * F2.Den + F2.Num * F1.Den;
   begin
      return (N, D);
   end "+";

   function "-" (F1, F2 : Fraction) return Fraction is
      D : constant Integer := F1.Den * F2.Den;
      N : constant Integer := F1.Num * F2.Den - F2.Num * F1.Den;
   begin
      return (N, D);
   end "-";

   function "=" (F1, F2 : Fraction) return Boolean is
   begin
      return F1.Num * F2.Den = F2.Num * F1.Den;
   end "=";

   function "/" (F : Fraction; N : Integer) return Fraction is
   begin
      return (F.Num, F.Den * N);
   end "/";

   procedure Reduce (F : in out Fraction) is
      function GCD (A, B : Integer) return Integer is
         T : Integer;
      begin
         if A < 0 then A := -A; end if;
         if B < 0 then B := -B; end if;
         while B /= 0 loop
            T := B;
            B := A mod B;
            A := T;
         end loop;
         return A;
      end GCD;
      G : constant Integer := GCD (F.Num, F.Den);
   begin
      if G /= 0 then
         F.Num := F.Num / G;
         F.Den := F.Den / G;
      end if;
   end Reduce;

   procedure Add_Fraction (F : in out Fraction; N : Integer) is
   begin
      F := F + (N, 1);
   end Add_Fraction;

   type Square_Rec is record
      Square : Integer;
      Reciprocal : Fraction;
   end record;

   Max_Denominator : constant Integer := 100;
   Squares : array (1..Max_Denominator) of Square_Rec;
   Count : Integer := 0;
   
   procedure Generate_Squares is
   begin
      for I in 1..Max_Denominator loop
         Squares(I).Square := I * I;
         Squares(I).Reciprocal := (1, I * I);
      end loop;
   end Generate_Squares;

   function Is_Valid (F : Fraction) return Boolean is
   begin
      return F.Num = 1 and F.Den = 2;
   end Is_Valid;

   procedure Search (Index : Integer; Current_Sum : Fraction; Used : array (1..Max_Denominator) of Boolean) is
      Target : constant Fraction := (1, 2);
      Next_Sum : Fraction;
   begin
      if Index > Max_Denominator then
         if Is_Valid (Current_Sum) then
            Count := Count + 1;
         end if;
         return;
      end if;

      -- Try not using this denominator
      Search (Index + 1, Current_Sum, Used);

      -- Try using this denominator (if not already used)
      if not Used(Index) then
         declare
            New_Used : array (1..Max_Denominator) of Boolean := Used;
            New_Sum : Fraction := Current_Sum;
         begin
            New_Used(Index) := True;
            New_Sum := New_Sum + Squares(Index).Reciprocal;
            
            -- If we're not going to exceed the target, continue searching
            if New_Sum.Num * 2 <= New_Sum.Den then
               Search (Index + 1, New_Sum, New_Used);
            end if;
         end;
      end if;
   end Search;

begin
   Generate_Squares;
   
   -- Start the search with an empty set and sum of zero
   declare
      Used : array (1..Max_Denominator) of Boolean := (others => False);
      Initial_Sum : Fraction := (0, 1);
   begin
      Search (1, Initial_Sum, Used);
   end;
   
   Put ("Number of ways: ");
   Put (Count);
   New_Line;
end Euler_152;
```

This solution works by:

1. **Defining a Fraction type** with basic arithmetic operations and reduction to lowest terms
2. **Generating all square reciprocals** from 1/1² to 1/100²
3. **Using backtracking search** to explore all combinations of denominators
4. **Pruning the search tree** by checking if the current sum could ever reach the target
5. **Counting valid solutions** where the sum equals 1/2

The algorithm uses a recursive backtracking approach, trying both including and excluding each denominator in turn, while keeping track of which denominators have already been used to avoid duplicates.

The key optimization is checking whether continuing with the current sum could possibly lead to a solution, avoiding unnecessary computation. The final answer should be **3075842** ways to write 1/2 as a sum of inverse squares using denominators not exceeding 100.
