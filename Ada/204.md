# Euler Problem 204 Solution in Ada

This problem asks us to find the number of "generalized Hamming numbers" of type 100, which are numbers that have only prime factors from the set {2, 3, 5, 7}.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_204 is
   
   -- Maximum value for Hamming numbers
   Max_Value : constant := 10**9;
   
   -- Prime factors we're allowed to use
   Primes : array(1..4) of Integer := (2, 3, 5, 7);
   
   -- Counter for valid Hamming numbers
   Count : Integer := 0;
   
   -- Recursive function to generate Hamming numbers
   procedure Generate_Hamming(Number : in Integer; Prime_Index : in Integer) is
      Next_Number : Integer;
   begin
      -- If current number exceeds maximum, stop
      if Number > Max_Value then
         return;
      end if;
      
      -- Increment counter (this is a valid Hamming number)
      Count := Count + 1;
      
      -- Generate new numbers by multiplying with each prime factor >= current prime
      for I in Prime_Index..4 loop
         Next_Number := Number * Primes(I);
         
         -- Only proceed if the next number won't exceed our limit
         if Next_Number <= Max_Value then
            Generate_Hamming(Next_Number, I);
         end if;
      end loop;
   end Generate_Hamming;
   
begin
   -- Start generating from 1 (which has no prime factors)
   Generate_Hamming(1, 1);
   
   Put("The number of generalized Hamming numbers of type 100 is: ");
   Put(Count);
   New_Line;
   
end Euler_204;
```

## Explanation

This solution uses a recursive approach to generate all valid Hamming numbers:

1. **Base Case**: Start with the number 1, which is considered a valid Hamming number (no prime factors)
2. **Recursive Generation**: For each number, multiply it by each prime factor (2, 3, 5, 7) that is greater than or equal to the current prime factor to maintain ascending order
3. **Pruning**: Stop generating if any product exceeds the maximum allowed value (10^9)
4. **Counting**: Increment a counter for each valid Hamming number found

The key insight is that we only multiply by primes ≥ the current prime to avoid generating duplicates and ensure proper ordering.

## Key Features:
- Uses recursion for clean, readable code
- Prunes branches early when numbers exceed the limit
- Maintains ascending order to prevent duplicate counting
- Efficiently handles the constraint that numbers must be ≤ 10^9
