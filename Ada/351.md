The points are numbered in a clockwise spiral starting from the center, and we call a point P a **hexagonal orchard point** if it's visible from the center. A point is visible from the center if no other point lies on the line segment between the center and that point.

Let H(n) be the number of hexagonal orchard points of order n.

You are given that H(5) = 30, H(10) = 142, and H(1000) = 123456789.

Find H(10^8).

## Mathematical Analysis

This is a classic problem involving the number of visible lattice points in a hexagonal arrangement. The key insight is that we need to count lattice points (x,y) where gcd(|x|,|y|) = 1 and the point lies within the hexagon.

For a hexagonal orchard of order n, the total number of points is:
- Center point: 1
- Points at distance k from center: 6k for k = 1 to n
- Total points = 1 + 6 × (1 + 2 + ... + n) = 1 + 6 × n(n+1)/2 = 1 + 3n(n+1)

However, we need to count only visible points. Using the principle of inclusion-exclusion with the Möbius function, we get:

H(n) = 6 × ∑(k=1 to n) φ(k) × floor(n/k)²

Where φ is Euler's totient function.
