# Euler Problem 811 Solution in Ada

I'll solve Euler Problem 811, which asks for the sum of all numbers that are equal to the sum of the factorials of their digits, excluding 1 and 2.

Let me break this down:
- We need to find numbers where the number equals the sum of factorials of its digits
- For example, 145 = 1! + 4! + 5! = 1 + 24 + 120 = 145
- We need to sum all such numbers (excluding 1 and 2)

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_811 is
   -- Function to calculate factorial
   function Factorial(N : Integer) return Integer is
   begin
      if N <= 1 then
         return 1;
      else
         return N * Factorial(N - 1);
      end if;
   end Factorial;

   -- Precompute factorials for digits 0-9
   Factorial_Table : array(0..9) of Integer;
   
   -- Function to check if a number equals sum of factorials of its digits
   function Is_Sum_Of_Factorials(N : Integer) return Boolean is
      Temp : Integer := N;
      Sum  : Integer := 0;
   begin
      while Temp > 0 loop
         Sum := Sum + Factorial_Table(Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Sum = N;
   end Is_Sum_Of_Factorials;

   -- Main solution
   Total_Sum : Integer := 0;
   Max_Value : constant Integer := 1_000_000; -- Reasonable upper bound
begin
   -- Initialize factorial table
   for I in 0..9 loop
      Factorial_Table(I) := Factorial(I);
   end loop;

   -- Check numbers from 3 to max value
   for I in 3..Max_Value loop
      if Is_Sum_Of_Factorials(I) then
         Total_Sum := Total_Sum + I;
         Put_Line("Found: " & Integer'Image(I));
      end if;
   end loop;

   Put_Line("Sum of all numbers equal to sum of factorials of digits: ");
   Put(Total_Sum, 0);
   New_Line;
   
end Euler_811;
```

```ada
   for I in 0..9 loop
      Factorial_Table(I) := Factorial(I);
   end loop;

   -- For very large numbers, we can estimate upper bound
   -- 9! = 362880
   -- For 7 digits of 9: 7 * 9! = 7 * 362880 = 2,540,160
   -- So we only need to check up to 2,540,160

   Put_Line("Checking numbers up to: " & Integer'Image(Max_Value));

   -- Check numbers from 3 to max value
   for I in 3..Max_Value loop

   New_Line;
   
end Euler_811;
```

## Analysis of the Solution

The key insights for this problem are:

1. **Upper Bound Estimation**: For an n-digit number made entirely of 9's, the maximum possible sum of factorials is n × 9!. We need to find where n × 9! becomes less than the smallest n-digit number.

2. **Known Solutions**: The only numbers that satisfy this property (excluding 1 and 2) are:
   - 145 = 1! + 4! + 5! = 1 + 24 + 120 = 145
   - 40585 = 4! + 0! + 5! + 8! + 5! = 24 + 1 + 120 + 40320 + 120 = 40585

3. **Optimization**: We only need to check numbers up to 2,540,160 since that's the maximum possible sum for a 7-digit number of 9's.

## Final Answer

The sum of all numbers that are equal to the sum of the factorials of their digits (excluding 1 and 2) is **40730**.

This includes the two numbers: 145 and 40585, where:
- 145 = 1! + 4! + 5! = 1 + 24 + 120 = 145
- 40585 = 4! + 0! + 5! + 8! + 5! = 24 + 1 + 120 + 40320 + 120 = 40585

Therefore: 145 + 40585 = 40730
