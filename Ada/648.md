# Euler Problem 648 Solution in Ada

I'll solve Euler Problem 648 which asks for the sum of all distinct prime factors of all numbers from 1 to 10^12, modulo 10^9+7.

## Problem Understanding
We need to find the sum of all distinct prime factors of all numbers from 1 to 10^12, then take the result modulo 10^9+7.

## Approach
The key insight is to use the inclusion-exclusion principle. Instead of calculating for each number individually, we'll calculate how many times each prime appears in the sum.

For each prime p, it appears in all multiples of p. So we need to count how many numbers from 1 to N are divisible by p, then multiply by p, and so on.
