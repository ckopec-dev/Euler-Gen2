# Euler Problem 37 Solution in Ada

## Problem Statement
The number 3797 has an interesting property. Removing digits from left to right and right to left, we get:
- 3797, 797, 97, 7 (left to right)
- 3797, 379, 37, 3 (right to left)

All of these numbers are prime. We call a number that is both truncatable from left to right and right to left a "truncatable prime". There are only eleven such primes less than one million. Find the sum of these eleven primes.

## Solution Approach
1. Generate prime numbers up to 1,000,000 using Sieve of Eratosthenes
2. Check each prime to see if it's truncatable from both directions
3. Sum all truncatable primes

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_37 is
   
   Max_Prime : constant := 1000000;
   
   -- Array to mark prime numbers
   Is_Prime : array (2 .. Max_Prime) of Boolean := (others => True);
   
   -- Function to check if a number is truncatable from left to right
   function Is_Left_Truncatable(N : Integer) return Boolean is
      Temp : Integer := N;
   begin
      while Temp > 0 loop
         if not Is_Prime(Temp) then
            return False;
         end if;
         Temp := Temp / 10;
      end loop;
      return True;
   end Is_Left_Truncatable;
   
   -- Function to check if a number is truncatable from right to left
   function Is_Right_Truncatable(N : Integer) return Boolean is
      Temp : Integer := N;
      Power : Integer := 1;
   begin
      while Temp > 0 loop
         if not Is_Prime(Temp) then
            return False;
         end if;
         Temp := Temp / 10;
      end loop;
      return True;
   end Is_Right_Truncatable;
   
   -- Function to check if a number is truncatable from both directions
   function Is_Truncatable(N : Integer) return Boolean is
   begin
      return Is_Left_Truncatable(N) and Is_Right_Truncatable(N);
   end Is_Truncatable;
   
begin
   -- Sieve of Eratosthenes to find all primes up to Max_Prime
   for I in 2 .. Integer'Sqrt(Max_Prime) loop
      if Is_Prime(I) then
         for J in I * I .. Max_Prime loop
            if J mod I = 0 then
               Is_Prime(J) := False;
            end if;
         end loop;
      end if;
   end loop;
   
   -- Find all truncatable primes and sum them
   declare
      Sum : Integer := 0;
      Count : Integer := 0;
   begin
      for I in 10 .. Max_Prime loop
         if Is_Prime(I) and then Is_Truncatable(I) then
            Sum := Sum + I;
            Count := Count + 1;
            Put_Line("Truncatable prime: " & Integer'Image(I));
            
            -- Stop when we have found all 11 truncatable primes
            if Count = 11 then
               exit;
            end if;
         end if;
      end loop;
      
      Put_Line("Sum of truncatable primes: " & Integer'Image(Sum));
   end;
   
end Euler_37;
```

## Key Features of the Solution

1. **Sieve of Eratosthenes**: Efficiently generates all prime numbers up to 1,000,000
2. **Truncatable Prime Check**: 
   - `Is_Left_Truncatable`: Checks truncation from left to right
   - `Is_Right_Truncatable`: Checks truncation from right to left
3. **Optimization**: Starts checking from 10 since single digit primes (2, 3, 5, 7) cannot be truncatable
4. **Early Termination**: Stops when all 11 truncatable primes are found
