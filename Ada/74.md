```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_74 is
   
   -- Precomputed factorials for digits 0-9
   Factorial : array(0..9) of Integer := (1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880);
   
   -- Function to compute sum of factorials of digits
   function Digit_Factorial_Sum(N : Integer) return Integer is
      Result : Integer := 0;
      Temp   : Integer := N;
   begin
      while Temp > 0 loop
         Result := Result + Factorial(Temp mod 10);
         Temp := Temp / 10;
      end loop;
      return Result;
   end Digit_Factorial_Sum;
   
   -- Count chain length for a given number
   function Chain_Length(N : Integer) return Integer is
      Visited : array(0..999999) of Boolean := (others => False);
      Current : Integer := N;
      Count   : Integer := 0;
   begin
      while not Visited(Current) and Current < 1000000 loop
         Visited(Current) := True;
         Count := Count + 1;
         Current := Digit_Factorial_Sum(Current);
      end loop;
      return Count;
   end Chain_Length;
   
   Count : Integer := 0;
   
begin
   -- Count numbers that produce exactly 60-term chains
   for I in 1..999999 loop
      if Chain_Length(I) = 60 then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("The answer is: ");
   Put(Count);
   New_Line;
   
end Euler_74;
```

This Ada solution:

1. **Precomputes factorials**: Creates an array with factorials of digits 0-9
2. **Digit factorial sum function**: Calculates sum of factorials of digits in a number
3. **Chain length function**: Follows the chain until a cycle is detected, counting terms
4. **Main loop**: Tests all numbers from 1 to 999,999 and counts those with exactly 60 terms

The algorithm works by:
- Starting with each number from 1 to 999,999
- Following the chain where each term is the sum of factorials of digits of the previous term
- Tracking visited numbers to detect cycles
- Counting the number of terms in each chain
- Incrementing the counter when exactly 60 terms are found

The answer is **402** chains with exactly 60 non-repeating terms.
