# Euler Problem 333 Solution in Ada

This problem asks for the sum of all positive integers n ≤ 10^17 such that there exists a positive integer k where n = 2^k + 1.

Let me analyze this step by step:

- We need to find numbers n where n = 2^k + 1 for some positive integer k
- This means we're looking for numbers of the form 2^k + 1 that are ≤ 10^17
- For a given k, n = 2^k + 1
- We need to find all such n where n ≤ 10^17

Let me think about this more carefully:
- If n = 2^k + 1 and n ≤ 10^17, then 2^k ≤ 10^17 - 1
- So k ≤ log₂(10^17 - 1)

Let me write the Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_333 is
   type Large_Integer is range 0 .. 10**17;
   
   Limit : constant Large_Integer := 10**17;
   Total_Sum : Large_Integer := 0;
   K : Integer := 1;
   Power_Of_2 : Large_Integer := 2;
   Current_Number : Large_Integer;
   
begin
   -- Loop through all valid values of k
   loop
      Current_Number := Power_Of_2 + 1;
      
      -- Check if the current number is within our limit
      exit when Current_Number > Limit;
      
      -- Add to our sum
      Total_Sum := Total_Sum + Current_Number;
      
      -- Move to next power of 2
      K := K + 1;
      Power_Of_2 := Power_Of_2 * 2;
   end loop;
   
   Put("Sum = ");
   Put(Total_Sum);
   New_Line;
end Euler_333;
```

Wait, let me reconsider this more carefully. Looking at the problem again:

The problem is asking for all positive integers n ≤ 10^17 such that there exists a positive integer k where n = 2^k + 1.

This means we want numbers of the form 2^k + 1 where k ≥ 1, and the resulting n must be ≤ 10^17.

Let me verify with small examples:
- k=1: n = 2^1 + 1 = 3
- k=2: n = 2^2 + 1 = 5  
- k=3: n = 2^3 + 1 = 9
- k=4: n = 2^4 + 1 = 17
- k=5: n = 2^5 + 1 = 33

So the sequence is: 3, 5, 9, 17, 33, 65, 129, 257, ...

But wait - let me double-check what the actual problem asks. Actually, I should make sure I understand correctly that we want ALL such n where n = 2^k + 1 for some k ≥ 1.

The solution approach is:
1. Generate powers of 2: 2^1, 2^2, 2^3, ...
2. For each power of 2, add 1 to get a candidate n
3. Stop when n > 10^17
4. Sum all valid candidates

Here's the corrected Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_333 is
   type Big_Integer is range 0 .. 10**17;
   
   Limit : constant Big_Integer := 10**17;
   Sum : Big_Integer := 0;
   K : Integer := 1;
   Power_Of_2 : Big_Integer := 2;  -- 2^1
   Candidate : Big_Integer;
   
begin
   loop
      Candidate := Power_Of_2 + 1;
      
      exit when Candidate > Limit;
      
      Sum := Sum + Candidate;
      
      K := K + 1;
      Power_Of_2 := Power_Of_2 * 2;  -- Next power of 2
   end loop;
   
   Put_Line("Sum = " & Big_Integer'Image(Sum));
end Euler_333;
```

However, I need to be more careful with the exact computation. Since we're dealing with large numbers and Ada's integer range, let me provide a safer version:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_333 is
   type UInt64 is range 0 .. 2**64 - 1;
   
   Limit : constant UInt64 := 10**17;
   Total_Sum : UInt64 := 0;
   Power_Of_2 : UInt64 := 2;  -- 2^1
   Current_Number : UInt64;
   
begin
   loop
      Current_Number := Power_Of_2 + 1;
      
      exit when Current_Number > Limit;
      
      Total_Sum := Total_Sum + Current_Number;
      
      Power_Of_2 := Power_Of_2 * 2;
   end loop;
   
   Put_Line("Sum = " & UInt64'Image(Total_Sum));
end Euler_333;
```

This solution works by:
1. Starting with 2^1 = 2
2. Computing n = 2^k + 1 for increasing values of k
3. Adding valid numbers (≤ 10^17) to the running sum
4. Stopping when we exceed the limit

The numbers that satisfy the condition are: 3, 5, 9, 17, 33, 65, 129, 257, 513, 1025, ...
This is the sequence of Fermat numbers minus 1, or numbers of the form 2^k + 1.
