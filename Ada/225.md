# Euler Problem 225 Solution in Ada

This problem asks for the smallest odd composite number that cannot be written as the sum of a prime and twice a square.

## Problem Analysis

We need to find the smallest odd composite number n such that there are no prime p and integer k where n = p + 2k².

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_225 is
   
   -- Maximum number to consider (reasonable upper bound)
   Max_Number : constant := 100000;
   
   -- Array to mark prime numbers (sieve of Eratosthenes)
   Is_Prime : array (1..Max_Number) of Boolean;
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(N : Integer) return Boolean is
   begin
      if N < 0 then
         return False;
      end if;
      
      declare
         Sqrt_N : constant Integer := Integer(Sqrt(Float(N)));
      begin
         return Sqrt_N * Sqrt_N = N;
      end;
   end Is_Perfect_Square;
   
   -- Function to check if a number can be expressed as prime + 2*square
   function Can_Be_Expressed_As_Prime_Plus_Twice_Square(N : Integer) return Boolean is
      P : Integer;
   begin
      -- Check all primes less than N
      for P in 2..N-1 loop
         if Is_Prime(P) then
            -- Check if (N - P) / 2 is a perfect square
            declare
               Remaining : constant Integer := N - P;
            begin
               if Remaining > 0 and then Remaining mod 2 = 0 then
                  if Is_Perfect_Square(Remaining / 2) then
                     return True;
                  end if;
               end if;
            end;
         end if;
      end loop;
      
      return False;
   end Can_Be_Expressed_As_Prime_Plus_Twice_Square;
   
begin
   -- Initialize sieve of Eratosthenes
   for I in 1..Max_Number loop
      Is_Prime(I) := True;
   end loop;
   
   Is_Prime(1) := False;  -- 1 is not prime
   
   -- Sieve of Eratosthenes
   for I in 2..Integer(Sqrt(Float(Max_Number))) loop
      if Is_Prime(I) then
         for J in I*I..Max_Number loop
            if J mod I = 0 then
               Is_Prime(J) := False;
            end if;
         end loop;
      end if;
   end loop;
   
   -- Find the answer - smallest odd composite that fails the condition
   for N in 9..Max_Number loop
      -- Check if N is odd and composite (not prime)
      if N mod 2 = 1 and then not Is_Prime(N) then
         -- Check if N can be expressed as prime + 2*k^2
         if not Can_Be_Expressed_As_Prime_Plus_Twice_Square(N) then
            Put_Line("Answer: " & Integer'Image(N));
            exit;
         end if;
      end if;
   end loop;
   
end Euler_225;
```

## Alternative Optimized Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_225 is
   
   Max_Number : constant := 100000;
   Is_Prime : array (1..Max_Number) of Boolean;
   
   -- Function to check if a number is a perfect square
   function Is_Perfect_Square(N : Integer) return Boolean is
   begin
      if N < 0 then
         return False;
      end if;
      
      declare
         Sqrt_N : constant Integer := Integer(Sqrt(Float(N)));
      begin
         return Sqrt_N * Sqrt_N = N;
      end;
   end Is_Perfect_Square;
   
   -- Precompute all primes up to Max_Number
   Primes : array (1..Max_Number) of Integer;
   Prime_Count : Integer := 0;
   
begin
   -- Initialize sieve
   for I in 1..Max_Number loop
      Is_Prime(I) := True;
   end loop;
   
   Is_Prime(1) := False;
   
   -- Sieve of Eratosthenes
   for I in 2..Integer(Sqrt(Float(Max_Number))) loop
      if Is_Prime(I) then
         for J in I*I..Max_Number loop
            if J mod I = 0 then
               Is_Prime(J) := False;
            end if;
         end loop;
      end if;
   end loop;
   
   -- Collect all primes
   for I in 2..Max_Number loop
      if Is_Prime(I) then
         Prime_Count := Prime_Count + 1;
         Primes(Prime_Count) := I;
      end if;
   end loop;
   
   -- Find the answer
   for N in 9..Max_Number loop
      if N mod 2 = 1 and then not Is_Prime(N) then
         -- Check if it can be written as prime + 2*k^2
         declare
            Found : Boolean := False;
            P : Integer;
         begin
            for I in 1..Prime_Count loop
               P := Primes(I);
               exit when P >= N;
               
               declare
                  Remaining : constant Integer := N - P;
               begin
                  if Remaining > 0 and then Remaining mod 2 = 0 then
                     if Is_Perfect_Square(Remaining / 2) then
                        Found := True;
                        exit;
                     end if;
                  end if;
               end;
            end loop;
            
            if not Found then
               Put_Line("Answer: " & Integer'Image(N));
               exit;
            end if;
         end;
      end if;
   end loop;
   
end Euler_225;
```

## Explanation

The solution works as follows:

1. **Sieve of Eratosthenes**: Generate all prime numbers up to a reasonable limit using the sieve method.

2. **Perfect Square Check**: Implement a function to check if a number is a perfect square.

3. **Main Logic**: 
   - Iterate through odd composite numbers starting from 9
   - For each number, check if it can be expressed as prime + 2×k²
   - If no such representation exists, that's our answer

4. **Optimization**: The second approach precomputes all primes and uses them directly to avoid redundant prime checking.

The answer to Euler Problem 225 is **5777**.
