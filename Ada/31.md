# Euler Problem 31 Solution in Ada

Euler Problem 31 asks: "How many different ways can £2 be made using any number of coins?"

The coin denominations are: 1p, 2p, 5p, 10p, 20p, 50p, £1 (100p), and £2 (200p).

## Solution Approach

I'll use dynamic programming with a bottom-up approach. For each coin denomination, I'll calculate how many ways to make each amount from 0 to 200p.

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_31 is
   -- Define the target amount in pence
   Target_Amount : constant := 200;
   
   -- Define coin denominations in pence
   Coins : array (1..8) of Integer := (1, 2, 5, 10, 20, 50, 100, 200);
   
   -- Array to store number of ways to make each amount
   Ways : array (0..Target_Amount) of Long_Long_Integer;
   
begin
   -- Initialize: there's one way to make 0p (use no coins)
   Ways(0) := 1;
   
   -- For each coin denomination
   for Coin_Index in Coins'Range loop
      -- For each amount from the current coin value up to target
      for Amount in Coins(Coin_Index)..Target_Amount loop
         -- Add the number of ways to make (Amount - Coin)
         -- This represents using one more of the current coin
         Ways(Amount) := Ways(Amount) + Ways(Amount - Coins(Coin_Index));
      end loop;
   end loop;
   
   -- Output the result
   Put_Line("Number of ways to make £2: " & Long_Long_Integer'Image(Ways(Target_Amount)));
end Euler_31;
```

## Explanation

The algorithm works as follows:

1. **Initialization**: Create an array `Ways` where `Ways(i)` represents the number of ways to make amount `i` pence
2. **Base case**: `Ways(0) = 1` (one way to make 0p: use no coins)
3. **Dynamic Programming**: For each coin denomination:
   - For each amount from the coin value up to 200p:
   - Add the number of ways to make `(amount - coin)` to `Ways(amount)`
4. **Result**: `Ways(200)` contains the answer

## How it works

For example, when processing coin = 2p:
- Ways(2) = Ways(2) + Ways(0) = 0 + 1 = 1 way (2p coin)
- Ways(3) = Ways(3) + Ways(1) = 0 + 0 = 0 ways
- Ways(4) = Ways(4) + Ways(2) = 0 + 1 = 1 way (2p + 2p)

This approach ensures we count each combination exactly once, avoiding overcounting different orderings of the same coins.

## Output

The program outputs: `Number of ways to make £2: 73682`

Therefore, there are **73,682** different ways to make £2 using British coin denominations.
