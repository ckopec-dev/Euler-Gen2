# Euler Problem 193 Solution in Ada

This problem asks for the number of squarefree integers between 1 and N, where N = 2^50.

## Problem Analysis

A squarefree integer is one that is not divisible by any perfect square other than 1. We need to count integers from 1 to 2^50 that are squarefree using inclusion-exclusion principle.

## Solution Approach

I'll use the inclusion-exclusion principle:
- Count all numbers
- Subtract numbers divisible by p² for each prime p
- Add back numbers divisible by p²q² for each pair of primes
- Continue alternating...
