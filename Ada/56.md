# Euler Problem 56 Solution in Ada

## Problem Statement
A googol (10^100) is a massive number: one followed by one-hundred zeros; 100^100 is almost unimaginably large: one followed by two-hundred zeros. Despite their size, the sum of the digits in each number is only 1.

Considering natural numbers of the form a^b, where a, b < 100, what is the maximum digital sum?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Big_Integers; use Ada.Big_Integers;

procedure Euler_56 is
   type Big_Integer is new Ada.Big_Integers.Big_Integer;
   
   function Digital_Sum(N : Big_Integer) return Integer is
      N_String : String(1..100);
      Length   : Natural;
      Sum      : Integer := 0;
   begin
      Ada.Big_Integers.Image(N, N_String, Length);
      
      -- Skip leading spaces and sum digits
      for I in 1..Length loop
         if N_String(I) in '0'..'9' then
            Sum := Sum + Character'Pos(N_String(I)) - Character'Pos('0');
         end if;
      end loop;
      
      return Sum;
   end Digital_Sum;
   
   Max_Sum : Integer := 0;
   Current_Sum : Integer;
   Result : Big_Integer;
begin
   -- Check all combinations of a^b where a, b < 100
   for A in 1..99 loop
      for B in 1..99 loop
         Result := Ada.Big_Integers.Power(Ada.Big_Integers.To_Big_Integer(A), B);
         Current_Sum := Digital_Sum(Result);
         
         if Current_Sum > Max_Sum then
            Max_Sum := Current_Sum;
         end if;
      end loop;
   end loop;
   
   Put_Line("Maximum digital sum: " & Integer'Image(Max_Sum));
end Euler_56;
```

## Explanation

This solution uses Ada's built-in big integer support to handle the large numbers involved in computing 99^99. Here's how it works:

1. **Digital_Sum Function**: Takes a big integer and calculates the sum of its digits by:
   - Converting the number to a string representation
   - Iterating through each character
   - Summing up the numeric values of digit characters

2. **Main Logic**: 
   - Iterates through all combinations where a and b range from 1 to 99
   - Computes a^b using Ada's Power function for big integers
   - Calculates the digital sum of each result
   - Keeps track of the maximum sum found

3. **Key Features**:
   - Uses Ada.Big_Integers package for arbitrary precision arithmetic
   - Handles the large numbers that would overflow standard integer types
   - Efficiently computes digit sums by string conversion

The answer is 972, which occurs for 99^95 (and other combinations).
