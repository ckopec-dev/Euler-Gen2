# Euler Problem 320 Solution in Ada

I'll solve Euler Problem 320, which asks for the sum of all positive integers n ≤ 10¹⁵ such that f(n) = n, where f(n) is the number of trailing zeros in n!.

## Problem Analysis

The function f(n) counts the trailing zeros in n! (n factorial). Trailing zeros are created by factors of 10, which come from pairs of 2 and 5. Since there are always more factors of 2 than 5 in n!, we need to count factors of 5.

The number of trailing zeros in n! is:
f(n) = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ⌊n/625⌋ + ...

We want to find all n ≤ 10¹⁵ such that f(n) = n.

## Mathematical Insight

For large values of n, we have:
- f(n) = n/4 (approximately)
- So we're looking for n where n/4 ≈ n, which is impossible
- But we need to be more precise about when f(n) = n
