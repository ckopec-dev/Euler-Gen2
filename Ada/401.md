# Euler Problem 401 Solution in Ada

Euler Problem 401 asks us to find the sum of the sum of divisors for all numbers from 1 to N, where N = 10^15, and return the result modulo 10^9.

Let me solve this step by step:

## Mathematical Approach

The key insight is to use the formula for the sum of divisors function. For each divisor d, it appears in exactly ⌊N/d⌋ numbers from 1 to N. So the sum of sum of divisors is:
∑(d=1 to N) d × ⌊N/d⌋

However, we can optimize this by grouping terms with the same value of ⌊N/d⌋.

procedure Euler_401 is
   type Large_Integer is range 0 .. 10**18;
   type Mod_Integer is range 0 .. 10**9 - 1;
   
   N : constant Large_Integer := 10**15;
   MOD : constant Mod_Integer := 10**9;
   
   function Mod_Add(A, B : Mod_Integer) return Mod_Integer is
   begin
      return (A + B) mod MOD;
   end Mod_Add;
   
   function Mod_Mul(A, B : Large_Integer) return Mod_Integer is
   begin
      return Mod_Integer((A * B) mod Large_Integer(MOD));
   end Mod_Mul;
   
   function Sum_Of_Divisors_Sum(N : Large_Integer) return Mod_Integer is
      Result : Mod_Integer := 0;
      D      : Large_Integer := 1;
      Q      : Large_Integer;
      R      : Large_Integer;
   begin
      while D <= N loop
         Q := N / D;  -- Quotient
         R := N mod D;  -- Remainder
         
         -- Find the largest D' such that N / D' = Q
         -- This means D' = N / Q
         -- But we need to be careful about integer division
         declare
            D_End : constant Large_Integer := N / Q;
            Count : constant Large_Integer := D_End - D + 1;
         begin
            -- Sum of arithmetic sequence: Q * (Count * (Count + 1)) / 2
            -- But we need to be more careful with the sum
            -- The sum is Q * (D + (D+1) + ... + D_End)
            -- = Q * (D_End - D + 1) * (D + D_End) / 2
            -- = Q * Count * (D + D_End) / 2
            
            -- Actually, we want sum of d * Q for d from D to D_End
            -- = Q * sum of d from D to D_End
            -- = Q * (D_End - D + 1) * (D + D_End) / 2
            
            -- But we also need to compute the sum of (d * Q) for d from D to D_End
            -- = Q * sum of d from D to D_End
            -- = Q * (D_End - D + 1) * (D + D_End) / 2
            
            -- Let's compute this more carefully:
            -- Sum = Q * (sum of d from D to D_End)
            -- Sum = Q * (D_End - D + 1) * (D + D_End) / 2
            
            -- But we're computing sum of divisors, so we need to be careful
            -- The sum of sum of divisors = sum over d of d * number of multiples of d
            -- = sum over d of d * floor(N/d)
            
            -- Better approach: group terms with same floor(N/d)
            declare
               Sum_D : constant Large_Integer := (D_End - D + 1) * (D + D_End) / 2;
               Term : constant Mod_Integer := Mod_Mul(Q, Mod_Integer(Sum_D));
            begin
               Result := Mod_Add(Result, Term);
            end;
            
            D := D_End + 1;
         end;
      end loop;
      
      return Result;
   end Sum_Of_Divisors_Sum;
   
   function Sum_Of_Divisors_Sum_Optimized(N : Large_Integer) return Mod_Integer is
      Result : Mod_Integer := 0;
      D      : Large_Integer := 1;
      Q      : Large_Integer;
   begin
      while D <= N loop
         Q := N / D;
         -- Find the largest D' such that floor(N/D') = Q
         -- This is D' = floor(N/Q)
         declare
            D_End : constant Large_Integer := N / Q;
            Count : constant Large_Integer := D_End - D + 1;
            Sum_D : constant Large_Integer := (D + D_End) * Count / 2;
            Term  : constant Mod_Integer := Mod_Mul(Q, Mod_Integer(Sum_D));
         begin
            Result := Mod_Add(Result, Term);
            D := D_End + 1;
         end;
      end loop;
      
      return Result;
   end Sum_Of_Divisors_Sum_Optimized;
   
   function Sum_Of_Divisors_Sum_Final(N : Large_Integer) return Mod_Integer is
      Result : Mod_Integer := 0;
      D      : Large_Integer := 1;
      Q      : Large_Integer;
   begin
      while D <= N loop
         Q := N / D;
         -- Find the largest D' such that floor(N/D') = Q
         declare
            D_End : constant Large_Integer := N / Q;
            Count : constant Large_Integer := D_End - D + 1;
            Sum_D : constant Large_Integer := (D + D_End) * Count / 2;
            Term  : constant Mod_Integer := Mod_Mul(Q, Mod_Integer(Sum_D));
         begin
            Result := Mod_Add(Result, Term);
            D := D_End + 1;
         end;
      end loop;
      
      return Result;
   end Sum_Of_Divisors_Sum_Final;

## Explanation

The solution works by:

1. **Mathematical Insight**: Instead of computing the sum of divisors for each number separately, we group terms by the value of ⌊N/d⌋.

2. **Optimization**: For a given quotient Q = ⌊N/d⌋, we find the range of values d where this quotient remains constant, then compute the sum efficiently.

3. **Formula**: For a range [D, D_End] where ⌊N/d⌋ = Q for all d in this range:
   - Sum of divisors = Q × (sum of d from D to D_End)
   - Sum of d from D to D_End = (D + D_End) × (D_End - D + 1) / 2

4. **Modular Arithmetic**: All operations are done modulo 10^9 to prevent overflow.

The time complexity is O(√N) which is efficient enough for N = 10^15.
