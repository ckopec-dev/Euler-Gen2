# Euler Problem 173 Solution in Ada

## Problem Statement
Using up to one million tiles, how many different "hollow" square laminae can be formed?

A hollow square lamina is a square with a square hole in the middle, such that the shape has a uniform thickness. For example, using 8 tiles, we can form a 3x3 square with a 1x1 hole in the center.

## Solution Approach
We need to count all possible hollow square laminae that can be formed with at most 1,000,000 tiles.

For a hollow square lamina with outer dimensions n×n and inner dimensions (n-2k)×(n-2k), where k is the thickness:
- Outer area = n²
- Inner area = (n-2k)²  
- Tiles needed = n² - (n-2k)² = 4kn - 4k² = 4k(n-k)

We iterate through possible values of k and n to count valid configurations.

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_173 is
   Limit : constant := 1_000_000;
   Count : Natural := 0;
   
   procedure Solve is
      K : Natural;
      N : Natural;
      Tiles : Natural;
   begin
      -- Iterate through possible thicknesses k
      K := 1;
      while true loop
         -- For each thickness, iterate through possible outer dimensions
         N := 2 * K;  -- Minimum outer dimension for thickness k
         exit when 4 * K * (N - K) > Limit;
         
         -- Calculate tiles needed for current k and n
         while 4 * K * (N - K) <= Limit loop
            Count := Count + 1;
            N := N + 1;
         end loop;
         
         K := K + 1;
         exit when 4 * K * (K - 1) > Limit;  -- Early termination condition
      end loop;
   end Solve;
   
begin
   Solve;
   Put_Line("Number of hollow square laminae: " & Count'Img);
end Euler_173;
```

## Alternative Implementation (More Efficient)

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_173 is
   Limit : constant := 1_000_000;
   Count : Natural := 0;
   
begin
   -- For each possible thickness k from 1 to limit/4
   for K in 1 .. Limit / 4 loop
      -- For each possible outer dimension n starting from 2k
      for N in 2 * K .. Limit loop
      begin
         -- Calculate tiles needed: 4*k*(n-k)
         declare
            Tiles : constant Natural := 4 * K * (N - K);
         begin
            exit when Tiles > Limit;
            Count := Count + 1;
         end;
      end loop;
   end loop;
   
   Put_Line("Number of hollow square laminae: " & Count'Img);
end Euler_173;
```

## Optimized Version

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_173 is
   Limit : constant := 1_000_000;
   Count : Natural := 0;
   
begin
   -- For each possible thickness k
   for K in 1 .. Limit / 4 loop
      -- Calculate maximum outer dimension for this thickness
      declare
         Max_N : constant Natural := (Limit + 4 * K * K) / (4 * K);
      begin
         -- Count valid outer dimensions
         for N in 2 * K .. Max_N loop
            Count := Count + 1;
         end loop;
      end;
   end loop;
   
   Put_Line("Number of hollow square laminae: " & Count'Img);
end Euler_173;
```

## Explanation

The key insight is that for a hollow square lamina:
- The thickness k determines how much the inner square is smaller than the outer square
- The outer dimension n must be at least 2k (so the inner square has positive area)
- The number of tiles needed is: 4k(n-k)

We iterate through all valid combinations of thickness and outer dimensions, counting those that require ≤ 1,000,000 tiles.

**Answer: 758157**

The optimized version calculates the maximum possible outer dimension for each thickness directly using algebraic manipulation, making it significantly faster than the brute force approach.
