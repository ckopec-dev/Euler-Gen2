# Euler Problem 25 Solution in Ada

This problem asks for the index of the first Fibonacci number that has 1000 digits.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_25 is
   
   type Big_Integer is array (Positive range <>) of Natural;
   
   function "+" (Left, Right : Big_Integer) return Big_Integer is
      Result : Big_Integer (1 .. Max(Left'Length, Right'Length) + 1);
      Carry  : Natural := 0;
      I, J   : Integer;
   begin
      -- Initialize result array
      for K in Result'Range loop
         Result(K) := 0;
      end loop;
      
      -- Add digits from right to left
      I := Left'Length;
      J := Right'Length;
      for K in reverse Result'Range loop
         if I >= Left'First then
            Carry := Carry + Left(I);
            I := I - 1;
         end if;
         
         if J >= Right'First then
            Carry := Carry + Right(J);
            J := J - 1;
         end if;
         
         Result(K) := Carry mod 10;
         Carry := Carry / 10;
      end loop;
      
      -- Remove leading zero if present
      if Result(1) = 0 then
         return Result(2 .. Result'Last);
      else
         return Result;
      end if;
   end "+";
   
   function "Length" (Num : Big_Integer) return Natural is
   begin
      return Num'Length;
   end "Length";
   
   -- Generate Fibonacci numbers and check their length
   function First_Fibonacci_With_Digits(Digits : Positive) return Natural is
      F1, F2, Temp : Big_Integer := (1 => 1);
      Index        : Natural := 2;
   begin
      loop
         -- Check if F2 has the required number of digits
         if F2'Length >= Digits then
            return Index;
         end if;
         
         -- Calculate next Fibonacci number
         Temp := F1 + F2;
         F1 := F2;
         F2 := Temp;
         Index := Index + 1;
      end loop;
   end First_Fibonacci_With_Digits;
   
begin
   Put_Line("The index of the first Fibonacci number with 1000 digits is:");
   Put(First_Fibonacci_With_Digits(1000));
   New_Line;
end Euler_25;
```

This solution implements a custom big integer addition type to handle numbers with many digits, then generates Fibonacci numbers until one with 1000 digits is found. The key insights are:

1. **Big Integer Arithmetic**: Since standard integers can't hold very large Fibonacci numbers, we implement our own addition for arrays of digits
2. **Fibonacci Generation**: We maintain two consecutive Fibonacci numbers and generate the next one in each iteration
3. **Digit Counting**: We check the length of the big integer representation to determine when we've reached 1000 digits

The answer is **4782** - the 4782nd Fibonacci number is the first to have exactly 1000 digits.
