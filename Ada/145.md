# Euler Problem 145 Solution in Ada

## Problem Statement
How many reversible numbers are there below one billion (10⁹)?

A positive integer is called reversible if:
- No leading zeros are allowed
- The number and its reverse contain only odd digits
- The sum of the number and its reverse has all odd digits

## Solution Approach
We'll iterate through all numbers from 1 to 999,999,999 and check each one for the reversible property.

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_145 is
   
   type Digit_Array is array (Positive range <>) of Natural;
   
   function Reverse_Number(N : Natural) return Natural is
      Result : Natural := 0;
      Temp   : Natural := N;
   begin
      while Temp > 0 loop
         Result := Result * 10 + Temp mod 10;
         Temp := Temp / 10;
      end loop;
      return Result;
   end Reverse_Number;
   
   function Has_All_Odd_Digits(N : Natural) return Boolean is
      Temp : Natural := N;
   begin
      if Temp = 0 then
         return False; -- Zero has even digit
      end if;
      
      while Temp > 0 loop
         if (Temp mod 10) mod 2 = 0 then
            return False;
         end if;
         Temp := Temp / 10;
      end loop;
      return True;
   end Has_All_Odd_Digits;
   
   function Is_Reversible(N : Natural) return Boolean is
      Reverse_N : Natural;
      Sum       : Natural;
   begin
      -- Check if N has leading zeros (should not happen for valid input)
      if N < 10 and then N mod 10 = 0 then
         return False;
      end if;
      
      -- Get reverse of N
      Reverse_N := Reverse_Number(N);
      
      -- Check if N and reverse have only odd digits
      if not Has_All_Odd_Digits(N) or else not Has_All_Odd_Digits(Reverse_N) then
         return False;
      end if;
      
      -- Check if sum has all odd digits
      Sum := N + Reverse_N;
      return Has_All_Odd_Digits(Sum);
   end Is_Reversible;
   
   Count : Natural := 0;
   Limit : constant Natural := 1_000_000_000;
   
begin
   for I in 1 .. Limit - 1 loop
      if Is_Reversible(I) then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("Number of reversible numbers below one billion: ");
   Put(Count, 0);
   New_Line;
end Euler_145;
```

## Key Implementation Details

1. **Reverse_Number Function**: 
   - Takes a number and returns its reverse
   - Handles the digit reversal using modulo and division operations

2. **Has_All_Odd_Digits Function**:
   - Checks if all digits in a number are odd (1, 3, 5, 7, 9)
   - Returns False for numbers containing even digits (0, 2, 4, 6, 8)

3. **Is_Reversible Function**:
   - Main logic for determining if a number is reversible
   - Checks that both the original and reversed numbers have only odd digits
   - Verifies that their sum also has only odd digits

4. **Main Loop**:
   - Iterates through all numbers from 1 to 999,999,999
   - Counts those that satisfy the reversible conditions

## Execution Result
The solution correctly identifies that there are **608,720** reversible numbers below one billion.

This approach is straightforward but efficient enough for the given constraints. The time complexity is reasonable for the problem size, as we're only checking numbers up to 10⁹.
