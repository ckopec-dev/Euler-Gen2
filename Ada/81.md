# Euler Problem 81 Solution in Ada

Euler Problem 81 asks us to find the minimal path sum from the top left to the bottom right of a grid, where we can only move right or down.

Here's my solution in Ada:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_81 is
   
   -- Define the grid size
   Grid_Size : constant := 80;
   
   -- Define a vector to hold the grid data
   type Grid_Type is array (1..Grid_Size, 1..Grid_Size) of Integer;
   
   -- Function to read the grid from input
   procedure Read_Grid (Grid : out Grid_Type) is
      File : Ada.Text_IO.File_Type;
   begin
      Open (File, In_File, "matrix.txt");
      
      for I in 1..Grid_Size loop
         for J in 1..Grid_Size loop
            Get (File, Grid(I,J));
         end loop;
      end loop;
      
      Close (File);
   end Read_Grid;
   
   -- Dynamic programming solution to find minimum path sum
   procedure Solve (Grid : in Grid_Type; Result : out Integer) is
      -- Create a DP table
      DP : Grid_Type;
      
      -- Initialize first cell
      DP(1,1) := Grid(1,1);
      
      -- Fill first row (can only come from left)
      for J in 2..Grid_Size loop
         DP(1,J) := DP(1,J-1) + Grid(1,J);
      end loop;
      
      -- Fill first column (can only come from above)
      for I in 2..Grid_Size loop
         DP(I,1) := DP(I-1,1) + Grid(I,1);
      end loop;
      
      -- Fill the rest of the table
      for I in 2..Grid_Size loop
         for J in 2..Grid_Size loop
            DP(I,J) := Grid(I,J) + 
                       (if DP(I-1,J) < DP(I,J-1) then DP(I-1,J) else DP(I,J-1));
         end loop;
      end loop;
      
      Result := DP(Grid_Size, Grid_Size);
   end Solve;
   
   -- Main program
   Grid : Grid_Type;
   Answer : Integer;
   
begin
   Read_Grid (Grid);
   Solve (Grid, Answer);
   Put ("The minimal path sum is: ");
   Put (Answer);
   New_Line;
end Euler_81;
```

## Explanation

This solution uses dynamic programming to solve the minimum path sum problem:

1. **Grid Reading**: The program reads the 80×80 grid from a file named "matrix.txt"
2. **Dynamic Programming Approach**: 
   - Create a DP table where each cell represents the minimum sum to reach that position
   - Initialize the first cell: `DP(1,1) = Grid(1,1)`
   - Fill the first row by accumulating values from left to right
   - Fill the first column by accumulating values from top to bottom
   - For all other cells, take the minimum of coming from above or from the left:
     `DP(i,j) = Grid(i,j) + min(DP(i-1,j), DP(i,j-1))`
3. **Result**: The bottom-right cell contains the minimum path sum

## Time and Space Complexity
- **Time Complexity**: O(n²) where n is the grid size (80×80)
- **Space Complexity**: O(n²) for the DP table

The solution efficiently computes the minimum path sum by building up optimal solutions to subproblems, which is the classic approach for this type of dynamic programming problem.
