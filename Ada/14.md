# Euler Problem 14 Solution in Ada

Euler Problem 14 asks: "Which starting number, under one million, produces the longest Collatz sequence?"

The Collatz sequence is defined as:
- If n is even, divide by 2
- If n is odd, multiply by 3 and add 1
- Continue until reaching 1

Here's the Ada solution:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_14 is
   Max_Length : Integer := 0;
   Best_Number : Integer := 0;
   
   function Collatz_Length(N : Integer) return Integer is
      Length : Integer := 1;
      Current : Integer := N;
   begin
      while Current /= 1 loop
         if Current mod 2 = 0 then
            Current := Current / 2;
         else
            Current := 3 * Current + 1;
         end if;
         Length := Length + 1;
      end loop;
      return Length;
   end Collatz_Length;
   
begin
   for I in 1 .. 999_999 loop
      declare
         Length : constant Integer := Collatz_Length(I);
      begin
         if Length > Max_Length then
            Max_Length := Length;
            Best_Number := I;
         end if;
      end;
   end loop;
   
   Put_Line("The starting number under one million that produces the longest Collatz sequence is:");
   Put_Line(Integer'Image(Best_Number));
   Put_Line("With a sequence length of:");
   Put_Line(Integer'Image(Max_Length));
end Euler_14;
```

## Explanation:

1. **Main Logic**: We iterate through all numbers from 1 to 999,999
2. **Collatz_Length Function**: Calculates the length of the Collatz sequence for a given number
3. **Sequence Generation**: 
   - If current number is even: divide by 2
   - If odd: multiply by 3 and add 1
4. **Tracking**: Keep track of the maximum sequence length and corresponding starting number

## Optimization Note:

This solution can be optimized further by using memoization to store previously calculated sequence lengths, but the above solution is clear and works efficiently for the given problem constraints.

The answer is **837799** with a sequence length of **525**.
