# Euler Problem 35 Solution in Ada

Euler Problem 35 asks: "How many circular primes are there below one million?"

A circular prime is a prime number that remains prime when its digits are cyclically permuted.

## Solution Approach

1. Generate all primes below one million using Sieve of Eratosthenes
2. For each prime, check if all rotations are also prime
3. Count valid circular primes

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_35 is
   
   Max : constant := 1000000;
   
   -- Array to mark primes (True = prime)
   Is_Prime : array (0 .. Max) of Boolean := (others => True);
   
   -- Function to check if a number is circular prime
   function Is_Circular_Prime(N : Integer) return Boolean is
      Num : Integer := N;
      Digits : Integer := 0;
      Temp : Integer := N;
      
      -- Count digits
      procedure Count_Digits is
      begin
         while Temp > 0 loop
            Digits := Digits + 1;
            Temp := Temp / 10;
         end loop;
      end Count_Digits;
      
      -- Get the last digit
      function Last_Digit(N : Integer) return Integer is
      begin
         return N mod 10;
      end Last_Digit;
      
      -- Rotate number left by one position
      function Rotate_Left(N : Integer; D : Integer) return Integer is
         Last : constant Integer := Last_Digit(N);
         Rest : constant Integer := N / 10;
      begin
         return Last * (10**(D-1)) + Rest;
      end Rotate_Left;
      
   begin
      -- Special case for single digit primes
      if N < 10 then
         return Is_Prime(N);
      end if;
      
      Count_Digits;
      
      -- Check all rotations
      Temp := N;
      for I in 1 .. Digits loop
         if not Is_Prime(Temp) then
            return False;
         end if;
         Temp := Rotate_Left(Temp, Digits);
      end loop;
      
      return True;
   end Is_Circular_Prime;
   
   -- Sieve of Eratosthenes
   procedure Sieve is
   begin
      Is_Prime(0) := False;
      Is_Prime(1) := False;
      
      for I in 2 .. Integer'Sqrt(Max) loop
         if Is_Prime(I) then
            for J in I * I .. Max step I loop
               Is_Prime(J) := False;
            end loop;
         end if;
      end loop;
   end Sieve;
   
   Count : Integer := 0;
   
begin
   -- Generate primes
   Sieve;
   
   -- Check all numbers below Max
   for I in 2 .. Max - 1 loop
      if Is_Prime(I) and then Is_Circular_Prime(I) then
         Count := Count + 1;
      end if;
   end loop;
   
   Put("Circular primes below one million: ");
   Put(Count, 0);
   New_Line;
   
end Euler_35;
```

## Explanation

The solution works as follows:

1. **Sieve of Eratosthenes**: First, we generate all prime numbers below one million and mark them in the `Is_Prime` array.

2. **Circular Prime Check**: For each number:
   - If it's a single digit prime, check if it's prime (which it is by definition)
   - For multi-digit numbers, we rotate the digits left and check if all rotations are prime
   - The rotation function takes the last digit and moves it to the front

3. **Rotation Logic**: 
   - Count the number of digits in the original number
   - Rotate left by one position: take last digit and place it at the beginning
   - Repeat for all digits

4. **Counting**: We count how many numbers satisfy both conditions (being prime and having all rotations prime).

## Result

The answer is **55** circular primes below one million.

Note: The solution handles edge cases properly, including single-digit primes (2, 3, 5, 7) which are automatically circular primes since they have only one rotation.
