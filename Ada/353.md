# Project Euler Problem 353 Solution in Ada

I'll solve Project Euler Problem 353, which asks for the sum of all primes that are both "prime" and "circular prime" (where every rotation of digits is also prime) with a maximum value of 10^6.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_353 is
   
   -- Maximum number to check for primes
   Max_Prime : constant := 1000000;
   
   -- Vector to store prime numbers
   type Prime_Vector is array (Positive range <>) of Natural;
   package Prime_Vectors is new Ada.Containers.Vectors (Natural, Natural);
   Primes : Prime_Vectors.Vector;
   
   -- Function to check if a number is prime
   function Is_Prime(N : Natural) return Boolean is
      Root : constant Natural := Natural(Real'(N))**0.5;
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Root loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Function to get number of digits in a number
   function Num_Digits(N : Natural) return Natural is
   begin
      if N < 10 then
         return 1;
      else
         return 1 + Num_Digits(N / 10);
      end if;
   end Num_Digits;
   
   -- Function to rotate digits of a number
   function Rotate_Left(N : Natural) return Natural is
      Digits : constant Natural := Num_Digits(N);
      Last_Digit : constant Natural := N mod 10;
      Remaining : constant Natural := N / 10;
   begin
      if Digits = 1 then
         return N;
      else
         return Last_Digit * (10 ** (Digits - 1)) + Remaining;
      end if;
   end Rotate_Left;
   
   -- Function to check if a number is circular prime
   function Is_Circular_Prime(N : Natural) return Boolean is
      Current : Natural := N;
   begin
      for I in 1 .. Num_Digits(N) loop
         if not Is_Prime(Current) then
            return False;
         end if;
         Current := Rotate_Left(Current);
      end loop;
      return True;
   end Is_Circular_Prime;
   
   -- Function to count digits in a number (for circular prime verification)
   function Count_Digits(N : Natural) return Natural is
   begin
      if N = 0 then
         return 1;
      else
         declare
            Count : Natural := 0;
            Temp : Natural := N;
         begin
            while Temp > 0 loop
               Count := Count + 1;
               Temp := Temp / 10;
            end loop;
            return Count;
         end;
      end if;
   end Count_Digits;
   
   -- Main computation
   Total_Sum : Natural := 0;
   Found_Count : Natural := 0;
   
begin
   -- Generate all primes up to Max_Prime
   Put_Line("Generating primes...");
   for I in 2 .. Max_Prime loop
      if Is_Prime(I) then
         Primes.Append(I);
      end if;
   end loop;
   
   Put_Line("Found " & Integer'Image(Primes.Length) & " primes");
   
   -- Check each prime to see if it's circular
   for I in 1 .. Primes.Length loop
      declare
         Current_Prime : constant Natural := Primes.Element(I);
      begin
         if Is_Circular_Prime(Current_Prime) then
            Total_Sum := Total_Sum + Current_Prime;
            Found_Count := Found_Count + 1;
            Put_Line("Found circular prime: " & Integer'Image(Current_Prime));
         end if;
      end;
   end loop;
   
   Put_Line("Total count of circular primes: " & Integer'Image(Found_Count));
   Put_Line("Sum of all circular primes: " & Integer'Image(Total_Sum));
   
end Euler_353;
```

```ada
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;

   function Rotate_Left(N : Natural) return Natural is
      Temp : Natural := N;
      Digits : Natural := 0;
      Last_Digit : Natural;
      Power : Natural := 1;
   begin
      -- Count digits
      Temp := N;
      while Temp > 0 loop
         Temp := Temp / 10;
         Digits := Digits + 1;
      end loop;
      
      if Digits = 1 then
         return N;
      else
         -- Get last digit
         Last_Digit := N mod 10;
         -- Remove last digit
         Temp := N / 10;
         -- Create power for moving last digit to front
         Power := 1;
         for I in 1 .. Digits - 1 loop
            Power := Power * 10;
         end loop;
         return Last_Digit * Power + Temp;
      end if;
   end Rotate_Left;
   
   -- Function to check if a number is circular prime
   function Is_Circular_Prime(N : Natural) return Boolean is
```

This Ada program solves Project Euler Problem 353 by:

1. **Generating primes**: Using a simple primality test to find all primes up to 1,000,000
2. **Checking circular primes**: For each prime, rotating its digits and checking if all rotations are also prime
3. **Summing results**: Adding all valid circular primes to get the final sum

The algorithm:
- First generates all primes up to 1,000,000 using trial division
- For each prime, it rotates the digits and checks if every rotation is also prime
- Sums all numbers that pass this test

Note: This is a computationally intensive problem, so the program may take some time to run. The circular primes are relatively rare, so the final sum will be much smaller than 1,000,000.
