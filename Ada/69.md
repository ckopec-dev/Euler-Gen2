# Euler Problem 69 Solution in Ada

Euler Problem 69 asks: "Find the value of n ≤ 1000000 for which n/φ(n) is a maximum, where φ is Euler's totient function."

Let me solve this step by step:

## Analysis

The key insight is that n/φ(n) is maximized when we have as many distinct prime factors as possible with small primes. This is because:
- φ(n) = n × ∏(1 - 1/p) for all prime factors p of n
- So n/φ(n) = 1 / ∏(1 - 1/p) = ∏(p/(p-1)) 
- To maximize this, we want to include as many small primes as possible

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_69 is
   
   -- Function to check if a number is prime
   function Is_Prime(N : Integer) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer'Sqrt(N) loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Function to calculate Euler's totient function φ(n)
   function Phi(N : Integer) return Integer is
      Result : Integer := N;
      I      : Integer := 2;
   begin
      while I * I <= N loop
         if N mod I = 0 then
            Result := Result - Result / I;
            while N mod I = 0 loop
               N := N / I;
            end loop;
         end if;
         I := I + 1;
      end loop;
      
      if N > 1 then
         Result := Result - Result / N;
      end if;
      
      return Result;
   end Phi;
   
   -- Find the maximum n/phi(n) for n ≤ Limit
   function Solve(Limit : Integer) return Integer is
      Max_N     : Integer := 1;
      Max_Ratio : Long_Float := 0.0;
      N         : Integer := 2;
   begin
      while N <= Limit loop
         declare
            Ratio : Long_Float := Float(N) / Float(Phi(N));
         begin
            if Ratio > Max_Ratio then
               Max_Ratio := Ratio;
               Max_N := N;
            end if;
         end;
         N := N + 1;
      end loop;
      
      return Max_N;
   end Solve;
   
   -- Optimized approach using prime multiplication
   function Solve_Optimized(Limit : Integer) return Integer is
      Product : Integer := 1;
      I       : Integer := 2;
   begin
      while Product * I <= Limit loop
         if Is_Prime(I) then
            Product := Product * I;
         end if;
         I := I + 1;
      end loop;
      
      return Product;
   end Solve_Optimized;

begin
   Put_Line("Euler Problem 69 Solution:");
   
   -- For small values, we can compute directly
   declare
      Result : Integer := Solve(1000000);
   begin
      Put("Direct computation result: ");
      Put(Result); Put_Line("");
   end;
   
   -- Optimized approach - multiply primes until exceeding limit
   declare
      Result : Integer := Solve_Optimized(1000000);
   begin
      Put("Optimized result: ");
      Put(Result); Put_Line("");
   end;
   
end Euler_69;
```

## Explanation

The optimized solution works because:

1. **Mathematical Insight**: n/φ(n) = ∏(p/(p-1)) where p are the distinct prime factors of n
2. **Optimization Principle**: To maximize this product, we want to include as many small primes as possible
3. **Strategy**: Multiply consecutive primes starting from 2 until the product exceeds our limit

The optimal answer will be the largest product of consecutive primes (starting with 2) that does not exceed 1,000,000.

## Key Points

- The maximum value of n/φ(n) occurs at a highly composite number with many small prime factors
- The solution is 2 × 3 × 5 × 7 × 11 × 13 × 17 = 510510
- This is because including the next prime (19) would make the product exceed 1,000,000

The optimized algorithm runs much faster than computing φ(n) for each number individually, especially for large limits.
