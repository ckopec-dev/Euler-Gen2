# Euler Problem 191 Solution in Ada

This problem asks for the number of ways to award prizes in a school where students can be absent (A), late (L), or present (P) over 30 days, with the constraint that no student can have more than 2 consecutive absences or more than 1 total absence.

Let me solve this step by step:

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_191 is
   
   -- Define the maximum number of days
   Days : constant := 30;
   
   -- Memoization array for dynamic programming
   type DP_Array is array (0 .. Days, 0 .. 2, 0 .. 1) of Long_Long_Integer;
   DP : DP_Array := (others => (others => (others => 0)));
   
   -- Function to calculate valid sequences
   function Count_Sequences(Day, Consecutive_Absent, Total_Absent : Natural) return Long_Long_Integer is
      Result : Long_Long_Integer;
   begin
      -- Base case: reached end of days
      if Day = Days then
         return 1;
      end if;
      
      -- Check if already computed
      if DP(Day, Consecutive_Absent, Total_Absent) /= 0 then
         return DP(Day, Consecutive_Absent, Total_Absent);
      end if;
      
      Result := 0;
      
      -- Case 1: Student is Present (P)
      Result := Result + Count_Sequences(Day + 1, 0, Total_Absent);
      
      -- Case 2: Student is Late (L) - only if not already 1 late
      if Total_Absent < 1 then
         Result := Result + Count_Sequences(Day + 1, 0, Total_Absent + 1);
      end if;
      
      -- Case 3: Student is Absent (A) - only if less than 2 consecutive absents
      if Consecutive_Absent < 2 then
         Result := Result + Count_Sequences(Day + 1, Consecutive_Absent + 1, Total_Absent);
      end if;
      
      -- Store result for memoization
      DP(Day, Consecutive_Absent, Total_Absent) := Result;
      return Result;
   end Count_Sequences;
   
begin
   Put_Line("Euler Problem 191 Solution:");
   Put_Line("Number of valid prize awarding sequences for 30 days:");
   Put(Long_Long_Integer'Image(Count_Sequences(0, 0, 0)));
   New_Line;
end Euler_191;
```

The solution uses dynamic programming with memoization. The state is defined by three parameters:
- `Day`: Current day (0 to 29)
- `Consecutive_Absent`: Number of consecutive absences at the current position
- `Total_Absent`: Total number of absences so far

For each day, we can choose one of three options:
1. **Present (P)**: Reset consecutive absent counter to 0
2. **Late (L)**: Increment total absent counter by 1 (if not already 1)
3. **Absent (A)**: Increment consecutive absent counter by 1 (if less than 2)

The constraints are:
- No more than 2 consecutive absences
- No more than 1 total absence

The answer for 30 days is **1918080160**.

This approach efficiently computes the result using recursion with memoization, avoiding redundant calculations and providing an optimal solution.
