# Euler Problem 89 Solution in Ada

Euler Problem 89 asks us to find the number of characters saved by writing Roman numerals in their minimal form.

## Problem Analysis

Roman numerals follow specific rules for representation:
- I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000
- Subtractive notation: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900
- Numbers are written from largest to smallest value
- For subtractive cases, the smaller numeral appears before the larger one

The minimal form means converting numbers to their shortest possible Roman numeral representation.

## Solution Approach

1. Parse each Roman numeral string
2. Convert it to its decimal value
3. Convert that decimal back to minimal Roman numeral form
4. Calculate character difference between original and minimal forms

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_89 is
   
   type Roman_Decimal is record
      Value : Integer;
      Symbol : Character;
   end record;
   
   -- Roman numeral values in descending order (including subtractive cases)
   Roman_Table : constant array(1..13) of Roman_Decimal :=
     ((1000, 'M'), (900, 'C'), (500, 'D'), (400, 'C'),
      (100, 'C'), (90, 'X'), (50, 'L'), (40, 'X'),
      (10, 'X'), (9, 'I'), (5, 'V'), (4, 'I'), (1, 'I'));
   
   -- Read input file
   File : File_Type;
   Line : Unbounded_String;
   
   Total_Saved : Integer := 0;
   
   function Roman_To_Integer(Roman : String) return Integer is
      Result : Integer := 0;
      I : Integer := 1;
   begin
      while I <= Roman'Length loop
         declare
            Current_Char : Character := Roman(I);
            Value : Integer := 0;
         begin
            -- Find the value of current character
            case Current_Char is
               when 'I' => Value := 1;
               when 'V' => Value := 5;
               when 'X' => Value := 10;
               when 'L' => Value := 50;
               when 'C' => Value := 100;
               when 'D' => Value := 500;
               when 'M' => Value := 1000;
               when others => Value := 0;
            end case;
            
            -- Check for subtractive cases
            if I < Roman'Length then
               declare
                  Next_Char : Character := Roman(I + 1);
                  Next_Value : Integer := 0;
               begin
                  case Next_Char is
                     when 'I' => Next_Value := 1;
                     when 'V' => Next_Value := 5;
                     when 'X' => Next_Value := 10;
                     when 'L' => Next_Value := 50;
                     when 'C' => Next_Value := 100;
                     when 'D' => Next_Value := 500;
                     when 'M' => Next_Value := 1000;
                     when others => Next_Value := 0;
                  end case;
                  
                  -- If current value is less than next, it's subtractive
                  if Value < Next_Value then
                     Result := Result + (Next_Value - Value);
                     I := I + 1; -- Skip next character
                  else
                     Result := Result + Value;
                  end if;
               end;
            else
               Result := Result + Value;
            end if;
            
            I := I + 1;
         end;
      end loop;
      
      return Result;
   end Roman_To_Integer;
   
   function Integer_To_Roman(Value : Integer) return String is
      Result : Unbounded_String := Null_Unbounded_String;
      Remaining : Integer := Value;
      I : Integer := 1;
   begin
      while Remaining > 0 and then I <= Roman_Table'Length loop
         if Remaining >= Roman_Table(I).Value then
            Append(Result, Roman_Table(I).Symbol);
            Remaining := Remaining - Roman_Table(I).Value;
         else
            I := I + 1;
         end if;
      end loop;
      
      return To_String(Result);
   end Integer_To_Roman;
   
begin
   -- Open the file containing Roman numerals
   Open(File, In_File, "roman.txt");
   
   while not End_Of_File(File) loop
      Line := To_Unbounded_String(Get_Line(File));
      
      -- Convert to integer
      declare
         Value : Integer := Roman_To_Integer(To_String(Line));
         Minimal_Roman : String := Integer_To_Roman(Value);
      begin
         Total_Saved := Total_Saved + (Length(Line) - Length(Minimal_Roman));
      end;
   end loop;
   
   Close(File);
   
   Put_Line("Characters saved: " & Integer'Image(Total_Saved));
end Euler_89;
```

## Key Implementation Details

1. **Roman to Integer Conversion**: The algorithm handles both regular and subtractive notation by checking if a smaller numeral appears before a larger one.

2. **Integer to Roman Conversion**: Uses a greedy approach with the Roman numeral table sorted in descending order, including subtractive cases (like CM for 900).

3. **Character Counting**: For each Roman numeral, we calculate the difference between original length and minimal form length.

4. **File Handling**: Reads from "roman.txt" file containing one Roman numeral per line.

## Expected Output

The program will output the total number of characters saved by converting all Roman numerals to their minimal forms.

Note: This solution assumes there's a file named "roman.txt" in the working directory containing the Roman numerals as specified in Project Euler Problem 89.
