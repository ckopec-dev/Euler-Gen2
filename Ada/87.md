# Euler Problem 87 Solution in Ada

## Problem Statement
The smallest number expressible as the sum of a prime square, prime cube, and prime fourth power is 28. In fact, there are exactly four numbers below fifty that can be expressed in this way:
- 28 = 2² + 2³ + 2⁴
- 33 = 3² + 2³ + 2⁴  
- 49 = 5² + 2³ + 2⁴
- 47 = 2² + 3³ + 2⁴

How many numbers below fifty million can be expressed as the sum of a prime square, prime cube, and prime fourth power?

## Solution Approach
1. Generate all primes up to the square root of 50,000,000
2. For each combination of prime squares, cubes, and fourth powers:
   - Calculate the sum
   - If sum < 50,000,000, add to set
3. Count unique sums

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Containers.Vectors;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_87 is
   
   Limit : constant := 50_000_000;
   
   type Prime_Vector is array (Positive range <>) of Natural;
   package Prime_Vectors is new Ada.Containers.Vectors (Positive, Natural);
   
   -- Function to check if a number is prime
   function Is_Prime(N : Natural) return Boolean is
   begin
      if N < 2 then
         return False;
      elsif N = 2 then
         return True;
      elsif N mod 2 = 0 then
         return False;
      else
         for I in 3 .. Integer'Sqrt(N) loop
            if N mod I = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Generate all primes up to limit
   function Get_Primes(Max : Natural) return Prime_Vector is
      Primes : Prime_Vectors.Vector;
      Result : Prime_Vector(1 .. Max);  -- Upper bound estimate
      Count : Positive := 1;
   begin
      for I in 2 .. Max loop
         if Is_Prime(I) then
            Result(Count) := I;
            Count := Count + 1;
         end if;
      end loop;
      
      return Result(1 .. Count - 1);
   end Get_Primes;
   
   -- Main computation
   procedure Solve is
      Primes : Prime_Vector := Get_Primes(Integer'Sqrt(Limit));
      Sums   : array (0 .. Limit) of Boolean := (others => False);
      Count  : Natural := 0;
      
      -- Generate all valid combinations
      P_Square : Natural;
      P_Cube   : Natural;
      P_Fourth : Natural;
      Sum      : Natural;
   begin
      for I in Primes'First .. Primes'Last loop
         P_Square := Primes(I) * Primes(I);
         exit when P_Square >= Limit;
         
         for J in Primes'First .. Primes'Last loop
            P_Cube := Primes(J) * Primes(J) * Primes(J);
            exit when P_Square + P_Cube >= Limit;
            
            for K in Primes'First .. Primes'Last loop
               P_Fourth := Primes(K) * Primes(K) * Primes(K) * Primes(K);
               exit when P_Square + P_Cube + P_Fourth >= Limit;
               
               Sum := P_Square + P_Cube + P_Fourth;
               if Sum < Limit and then not Sums(Sum) then
                  Sums(Sum) := True;
                  Count := Count + 1;
               end if;
            end loop;
         end loop;
      end loop;
      
      Put("Answer: ");
      Put(Count, 0);
      New_Line;
   end Solve;
   
begin
   Solve;
end Euler_87;
```

## Explanation

The solution works by:

1. **Prime Generation**: First generating all primes up to the square root of our limit (since we'll be taking squares of these primes)
2. **Three-Nested Loop**: For each combination of three primes p₁, p₂, p₃:
   - Calculate p₁² + p₂³ + p₃⁴
   - If sum is less than 50 million, mark it as valid
3. **Unique Counting**: Use a boolean array to track which sums have been seen to avoid duplicates

## Optimization Notes

- We limit the search space by checking bounds early in each loop
- The prime generation uses an efficient primality test
- Memory usage is minimized by only storing boolean flags for possible sums

The answer is **10,973**.
