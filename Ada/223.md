## Problem Understanding

Euler Problem 223 asks us to find the number of integer-sided triangles with perimeter ≤ 10^6 that are "acute-angled" (all angles less than 90 degrees).

For a triangle with sides a, b, c to be acute-angled, all three angles must be less than 90°. This is equivalent to:
- a² + b² > c²
- a² + c² > b²  
- b² + c² > a²

## Solution Approach

1. Generate all possible triangles with perimeter ≤ 10^6
2. For each triangle, check if it's acute-angled
3. Count valid triangles

with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_223 is
   type Triangle is record
      A, B, C : Integer;
   end record;
   
   MAX_PERIMETER : constant := 1_000_000;
   Count : Integer := 0;
   
   function Is_Acute(T : Triangle) return Boolean is
   begin
      -- Check if triangle is acute-angled
      -- For a triangle to be acute, all three conditions must hold:
      -- a² + b² > c², a² + c² > b², b² + c² > a²
      return (T.A * T.A + T.B * T.B > T.C * T.C) and
             (T.A * T.A + T.C * T.C > T.B * T.B) and
             (T.B * T.B + T.C * T.C > T.A * T.A);
   end Is_Acute;
   
   function IsValid_Triangle(A, B, C : Integer) return Boolean is
   begin
      -- Triangle inequality: sum of any two sides must be greater than third side
      return (A + B > C) and (A + C > B) and (B + C > A);
   end IsValid_Triangle;
   
begin
   -- We iterate through all possible combinations where a ≤ b ≤ c
   -- This avoids counting the same triangle multiple times
   for A in 1 .. MAX_PERIMETER / 3 loop
      for B in A .. (MAX_PERIMETER - A) / 2 loop
         declare
            C : constant Integer := MAX_PERIMETER - A - B;
         begin
            -- Check if we have a valid triangle with perimeter = MAX_PERIMETER
            if C >= B and then IsValid_Triangle(A, B, C) and then Is_Acute(Triangle'(A, B, C)) then
               Count := Count + 1;
            end if;
         end;
      end loop;
   end loop;
   
   Put("Number of acute-angled triangles with perimeter <= ");
   Put(MAX_PERIMETER);
   Put_Line(":");
   Put(Count);
   New_Line;
end Euler_223;

This solution:
1. Iterates through all possible perimeters from 3 to 1,000,000
2. For each perimeter, generates all valid combinations where a ≤ b ≤ c
3. Checks if the triangle is valid and acute-angled using the condition that all three squared side inequalities hold
4. Counts all such triangles

The time complexity is approximately O(n³) in the worst case, but with optimizations like the constraints a ≤ b ≤ c, it's more efficient in practice.
