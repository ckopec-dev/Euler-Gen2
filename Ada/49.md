# Euler Problem 49 Solution in Ada

## Problem Statement
The arithmetic sequence, 1487, 4817, 8147, in which each of the terms increases by 3330, is unusual in two ways: (i) each of the three terms are prime, and (ii) each of the three terms are permutations of one another.

There are no arithmetic sequences made up of three 1-digit primes, there are no arithmetic sequences made up of three 2-digit primes, and there are no arithmetic sequences made up of three 3-digit primes. However, there is one arithmetic sequence made up of three 4-digit primes that are permutations of each other.

What 12-digit number do you form by concatenating the three terms in this sequence?

## Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Strings.Unbounded; use Ada.Strings.Unbounded;

procedure Euler_49 is
   
   type Prime_Array is array (Positive range <>) of Boolean;
   
   function Is_Prime(N : Integer) return Boolean is
      Result : Boolean := True;
   begin
      if N < 2 then
         Result := False;
      elsif N = 2 then
         Result := True;
      elsif N mod 2 = 0 then
         Result := False;
      else
         for I in 3 .. Integer'Sqrt(N) loop
            if N mod I = 0 then
               Result := False;
               exit;
            end if;
         end loop;
      end if;
      return Result;
   end Is_Prime;
   
   function Are_Permutations(N1, N2 : Integer) return Boolean is
      S1, S2 : Unbounded_String;
      C1, C2 : array (Character range <>) of Character;
   begin
      S1 := To_Unbounded_String(Integer'Image(N1));
      S2 := To_Unbounded_String(Integer'Image(N2));
      
      -- Remove leading spaces
      declare
         I : Integer := 1;
      begin
         while I <= Length(S1) and then Element(S1, I) = ' ' loop
            I := I + 1;
         end loop;
         S1 := Slice(S1, I, Length(S1));
      end;
      
      declare
         I : Integer := 1;
      begin
         while I <= Length(S2) and then Element(S2, I) = ' ' loop
            I := I + 1;
         end loop;
         S2 := Slice(S2, I, Length(S2));
      end;
      
      -- Convert to character arrays and sort
      C1 := (others => ' ');
      C2 := (others => ' ');
      
      for I in 1 .. Length(S1) loop
         C1(I) := Element(S1, I);
      end loop;
      
      for I in 1 .. Length(S2) loop
         C2(I) := Element(S2, I);
      end loop;
      
      -- Sort characters (simple bubble sort)
      for I in 1 .. Length(S1) - 1 loop
         for J in I + 1 .. Length(S1) loop
            if C1(I) > C1(J) then
               declare
                  Temp : Character := C1(I);
               begin
                  C1(I) := C1(J);
                  C1(J) := Temp;
               end;
            end if;
         end loop;
      end loop;
      
      for I in 1 .. Length(S2) - 1 loop
         for J in I + 1 .. Length(S2) loop
            if C2(I) > C2(J) then
               declare
                  Temp : Character := C2(I);
               begin
                  C2(I) := C2(J);
                  C2(J) := Temp;
               end;
            end if;
         end loop;
      end loop;
      
      -- Compare sorted strings
      for I in 1 .. Length(S1) loop
         if C1(I) /= C2(I) then
            return False;
         end if;
      end loop;
      
      return True;
   end Are_Permutations;
   
   procedure Find_Sequence is
      Found : Boolean := False;
      P1, P2, P3 : Integer;
   begin
      -- Check all 4-digit numbers
      for I in 1000 .. 9999 loop
         if Is_Prime(I) then
            for J in (I + 1) .. 9999 loop
               if Is_Prime(J) and then Are_Permutations(I, J) then
                  -- Calculate the third term in arithmetic sequence
                  P3 := J + (J - I);
                  if P3 <= 9999 and then Is_Prime(P3) and then Are_Permutations(J, P3) then
                     -- Check if this is the special case we're looking for
                     -- (excluding the known example 1487, 4817, 8147)
                     if I /= 1487 or J /= 4817 or P3 /= 8147 then
                        Put_Line("Found sequence: " & Integer'Image(I) & 
                                " " & Integer'Image(J) & " " & Integer'Image(P3));
                        Put_Line("Concatenated result: " & 
                                Integer'Image(I) & Integer'Image(J) & Integer'Image(P3));
                        Found := True;
                        return;
                     end if;
                  end if;
               end if;
            end loop;
         end if;
      end loop;
      
      if not Found then
         Put_Line("No sequence found");
      end if;
   end Find_Sequence;
   
begin
   Find_Sequence;
end Euler_49;
```

## Explanation

This solution works by:

1. **Prime checking**: The `Is_Prime` function efficiently checks if a number is prime by testing divisibility up to the square root.

2. **Permutation checking**: The `Are_Permutations` function compares two numbers by sorting their digits and checking if the sorted results are identical.

3. **Sequence search**: For each 4-digit prime, it searches for arithmetic sequences where:
   - The common difference is reasonable (≤ (9999 - P1) / 2)
   - All three terms in the sequence are prime
   - All three terms are permutations of each other

4. **Exclusion**: It excludes the known example 1487, 4817, 8147 to find the other valid sequence.
