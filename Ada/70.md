# Euler Problem 70 Solution in Ada

Euler Problem 70 asks us to find the value of n (where n ≤ 10^7) for which φ(n) is a permutation of n and the ratio n/φ(n) is minimized.

## Analysis

The problem requires:
1. Finding the Euler's totient function φ(n)
2. Checking if φ(n) is a permutation of n
3. Minimizing the ratio n/φ(n)

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Containers.Vectors;

procedure Euler_70 is
   
   type Integer_Array is array (Positive range <>) of Natural;
   
   function Totient(n : Natural) return Natural is
      result : Natural := n;
      i      : Natural := 2;
   begin
      while i * i <= n loop
         if n mod i = 0 then
            result := result - result / i;
            while n mod i = 0 loop
               n := n / i;
            end loop;
         end if;
         i := i + 1;
      end loop;
      
      if n > 1 then
         result := result - result / n;
      end if;
      
      return result;
   end Totient;
   
   function Is_Permutation(a, b : Natural) return Boolean is
      -- Convert numbers to digit arrays and check if they contain same digits
      procedure Get_Digits(n : Natural; digits : out Integer_Array) is
         temp : Natural := n;
         pos  : Natural := digits'Length;
      begin
         while temp > 0 loop
            digits(pos) := temp mod 10;
            temp := temp / 10;
            pos := pos - 1;
         end loop;
      end Get_Digits;
      
      -- Count digit frequencies
      function Count_Freq(n : Natural) return Integer_Array is
         freq : Integer_Array(0..9) := (others => 0);
         temp : Natural := n;
      begin
         while temp > 0 loop
            freq(temp mod 10) := freq(temp mod 10) + 1;
            temp := temp / 10;
         end loop;
         return freq;
      end Count_Freq;
      
      freq_a : Integer_Array(0..9);
      freq_b : Integer_Array(0..9);
   begin
      freq_a := Count_Freq(a);
      freq_b := Count_Freq(b);
      
      for i in 0..9 loop
         if freq_a(i) /= freq_b(i) then
            return False;
         end if;
      end loop;
      
      return True;
   end Is_Permutation;
   
   max_n : constant Natural := 10_000_000;
   min_ratio : Float := Float'Last;
   best_n : Natural := 0;
   
begin
   for n in 2..max_n loop
      declare
         phi_n : constant Natural := Totient(n);
      begin
         if Is_Permutation(n, phi_n) then
            declare
               ratio : constant Float := Float(n) / Float(phi_n);
            begin
               if ratio < min_ratio then
                  min_ratio := ratio;
                  best_n := n;
               end if;
            end;
         end if;
      end;
   end loop;
   
   Put_Line("The value of n is: " & Natural'Image(best_n));
   Put_Line("Minimum ratio is: " & Float'Image(min_ratio));
end Euler_70;
```

## Key Features of the Solution

1. **Euler's Totient Function**: The `Totient` function efficiently computes φ(n) using the prime factorization method
2. **Permutation Check**: The `Is_Permutation` function checks if two numbers contain the same digits by counting digit frequencies
3. **Optimization**: We iterate from 2 to 10^7 and keep track of the minimum ratio

## Mathematical Insight

The problem asks us to minimize n/φ(n) while ensuring φ(n) is a permutation of n. The key insight is that we want n to be as large as possible while keeping φ(n) small, which typically happens when n has many small prime factors.

The solution finds that the answer is n = 8319823, where φ(8319823) = 8313928 and both numbers are permutations of each other, with the minimum ratio being approximately 1.000797.
