# Euler Problem 123 Solution in Ada

## Problem Statement
Let pₙ be the nth prime number. Let R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ. Find the least value of n for which R(n) is divisible by 10¹⁰.

## Solution Approach
We need to find the smallest n such that R(n) ≡ 0 (mod 10¹⁰), where R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ.

Key insights:
1. We can use modular arithmetic to avoid computing large numbers directly
2. For odd n: R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ ≡ (-1)ⁿ + 1ⁿ ≡ -1 + 1 ≡ 0 (mod 2)
3. For even n: R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ ≡ 1ⁿ + 1ⁿ ≡ 2 (mod 2)
4. We need to check divisibility by 10¹⁰, so we compute modulo 10¹⁰

## Ada Implementation

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with Ada.Numerics.Discrete_Random;

procedure Euler_123 is
   
   type Natural_Array is array (Positive range <>) of Natural;
   
   -- Generate primes using Sieve of Eratosthenes
   function Is_Prime(n : Natural) return Boolean is
   begin
      if n < 2 then
         return False;
      elsif n = 2 then
         return True;
      elsif n mod 2 = 0 then
         return False;
      else
         for i in 3 .. Integer(Sqrt(Float(n))) by 2 loop
            if n mod i = 0 then
               return False;
            end if;
         end loop;
         return True;
      end if;
   end Is_Prime;
   
   -- Find nth prime
   function Nth_Prime(n : Positive) return Natural is
      count : Natural := 0;
      candidate : Natural := 1;
      prime : Natural;
   begin
      while count < n loop
         candidate := candidate + 1;
         if Is_Prime(candidate) then
            count := count + 1;
            prime := candidate;
         end if;
      end loop;
      return prime;
   end Nth_Prime;
   
   -- Modular exponentiation
   function Modular_Power(base, exp, mod : Natural) return Natural is
      result : Natural := 1;
      b : Natural := base mod mod;
      e : Natural := exp;
   begin
      while e > 0 loop
         if e mod 2 = 1 then
            result := (result * b) mod mod;
         end if;
         b := (b * b) mod mod;
         e := e / 2;
      end loop;
      return result;
   end Modular_Power;
   
   -- Calculate R(n) = (p_n-1)^n + (p_n+1)^n mod 10^10
   function R(n : Positive) return Natural is
      p : Natural := Nth_Prime(n);
      mod_value : constant Natural := 10_000_000_000;
   begin
      -- R(n) = (p-1)^n + (p+1)^n (mod 10^10)
      return (Modular_Power(p-1, n, mod_value) + 
              Modular_Power(p+1, n, mod_value)) mod mod_value;
   end R;
   
   -- Find the least n such that R(n) = 0 (mod 10^10)
   n : Positive := 1;
   r_value : Natural;
begin
   loop
      r_value := R(n);
      if r_value = 0 then
         Put_Line("Answer: " & Integer'Image(n));
         exit;
      end if;
      n := n + 1;
   end loop;
end Euler_123;
```

3. **R(n) Calculation**: Computing R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ (mod 10¹⁰)
