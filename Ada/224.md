# Euler Problem 224 Solution in Ada

This problem asks for the number of triangles with integer sides where the perimeter is at most 10^7 and the triangle inequality holds.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_224 is
   type Triangle_Count is mod 2**64;
   
   Max_Perimeter : constant := 10**7;
   Total_Count : Triangle_Count := 0;
   
begin
   -- For a triangle with sides a, b, c where a <= b <= c
   -- The triangle inequality requires: a + b > c
   -- And perimeter constraint: a + b + c <= Max_Perimeter
   
   for a in 1..Max_Perimeter/3 loop
      for b in a..(Max_Perimeter - a)/2 loop
         declare
            c_max : constant Integer := Min(Max_Perimeter - a - b, b);
         begin
            if c_max >= a and then a + b > c_max then
               -- Count valid triangles with sides a, b, c where a <= b <= c
               Total_Count := Total_Count + (c_max - b + 1);
            end if;
         end;
      end loop;
   end loop;
   
   Put("Result: ");
   Put(Total_Count, Width => 0);
   New_Line;
end Euler_224;
```

Here's a cleaner final version:

```ada
with Ada.Text_IO; use Ada.Text_IO;

procedure Euler_224 is
   Max_Perimeter : constant := 10**7;
   Count : Integer := 0;
   
begin
   -- For triangles with sides a <= b <= c
   -- Triangle inequality: a + b > c
   -- Perimeter constraint: a + b + c <= Max_Perimeter
   
   for a in 1..Max_Perimeter/3 loop
      for b in a..(Max_Perimeter - a)/2 loop
         declare
            c_max : constant Integer := Min(Max_Perimeter - a - b, b);
            c_min : constant Integer := a + b - 1; -- From triangle inequality
         begin
            if c_min >= a and then c_min <= b and then c_max >= c_min then
               Count := Count + (c_max - c_min + 1);
            end if;
         end;
      end loop;
   end loop;
   
   Put_Line("Result: " & Integer'Image(Count));
end Euler_224;
```

The solution works by:

1. **Enumerating valid side combinations**: For each pair of sides (a,b) where a ≤ b, we compute the maximum possible third side c
2. **Applying constraints**: 
   - Perimeter constraint: c ≤ Max_Perimeter - a - b  
   - Triangle inequality: c < a + b, so c ≤ a + b - 1
   - Ordering constraint: a ≤ b ≤ c
3. **Counting valid triangles**: For each valid range of c values, we count how many integer values satisfy all constraints

This approach avoids checking every possible combination and instead uses mathematical constraints to efficiently compute the answer.
