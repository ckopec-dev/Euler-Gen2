# Euler Problem 178 Solution in Ada

This problem asks for the number of step numbers (numbers where each digit differs from its neighbors by exactly 1) of length 40.

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;

procedure Euler_178 is
   type Step_Count_Array is array (0..9, 0..39) of Long_Long_Integer;
   
   -- Memoization table for dynamic programming
   DP : Step_Count_Array := (others => (others => 0));
   
   -- Function to count step numbers of given length starting with digit d
   function Count_Step_Numbers(Digit : Integer; Length : Natural) return Long_Long_Integer is
      Result : Long_Long_Integer;
   begin
      if Length = 0 then
         return 1;
      elsif DP(Digit, Length) /= 0 then
         return DP(Digit, Length);
      else
         Result := 0;
         -- Can go to digit-1 if it's valid
         if Digit > 0 then
            Result := Result + Count_Step_Numbers(Digit - 1, Length - 1);
         end if;
         
         -- Can go to digit+1 if it's valid
         if Digit < 9 then
            Result := Result + Count_Step_Numbers(Digit + 1, Length - 1);
         end if;
         
         DP(Digit, Length) := Result;
         return Result;
      end if;
   end Count_Step_Numbers;
   
   Total_Count : Long_Long_Integer := 0;
begin
   -- For a step number of length 40, we can start with any digit from 1 to 9
   -- (we can't start with 0 as it wouldn't be a valid 40-digit number)
   for Start_Digit in 1..9 loop
      Total_Count := Total_Count + Count_Step_Numbers(Start_Digit, 39);
   end loop;
   
   Put_Line("Answer: " & Total_Count'Img);
end Euler_178;
```

## Explanation

This solution uses dynamic programming with memoization to efficiently count the step numbers:

1. **Problem Understanding**: 
   - A step number is a number where each digit differs from its neighbors by exactly 1
   - We need to count all step numbers of length 40
   - The first digit cannot be 0 (since we're counting 40-digit numbers)

2. **Dynamic Programming Approach**:
   - `DP[digit][length]` stores the number of valid step numbers starting with `digit` and having `length` digits
   - For each digit, we can only move to adjacent digits (digit-1 or digit+1)
   - Base case: When length = 0, there's exactly one way to form an empty sequence

3. **Key Insights**:
   - We don't need to generate all numbers, just count them
   - Using memoization avoids recomputing the same subproblems
   - We start with digits 1-9 (not 0) since we're forming a 40-digit number

The algorithm efficiently computes the result by building up solutions from smaller subproblems, reducing the time complexity from exponential to polynomial.
