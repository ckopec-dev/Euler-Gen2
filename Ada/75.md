# Euler Problem 75 Solution in Ada

This problem asks for the number of integers ≤ 1,500,000 that can be the perimeter of exactly one right triangle with integer sides.

## Analysis

For a right triangle with integer sides (a,b,c) where c is the hypotenuse:
- a² + b² = c²
- Perimeter = a + b + c
- All sides must be positive integers

We can use the Euclidean formula for generating primitive Pythagorean triples:
- a = m² - n²
- b = 2mn  
- c = m² + n²
- where m > n > 0, gcd(m,n) = 1, and m,n not both odd

## Ada Solution

```ada
with Ada.Text_IO; use Ada.Text_IO;
with Ada.Integer_Text_IO; use Ada.Integer_Text_IO;
with GNAT.Calendar;

procedure Euler_75 is
   Max_Perimeter : constant := 1_500_000;
   
   -- Function to compute greatest common divisor
   function GCD(A, B : Integer) return Integer is
   begin
      if B = 0 then
         return A;
      else
         return GCD(B, A mod B);
      end if;
   end GCD;
   
   -- Array to count how many times each perimeter occurs
   Perimeter_Count : array(1..Max_Perimeter) of Integer := (others => 0);
   
begin
   -- Generate all primitive Pythagorean triples
   for M in 2..Integer(sqrt(Float(Max_Perimeter))) loop
      for N in 1..M-1 loop
         -- Check if m and n are coprime and not both odd
         if GCD(M, N) = 1 and then (M mod 2 /= N mod 2) then
            -- Calculate the primitive triple
            declare
               A : constant Integer := M * M - N * N;
               B : constant Integer := 2 * M * N;
               C : constant Integer := M * M + N * N;
               Perimeter : constant Integer := A + B + C;
               Multiple : Integer := 1;
            begin
               -- Add all multiples of this primitive triple
               while Multiple * Perimeter <= Max_Perimeter loop
                  Perimeter_Count(Multiple * Perimeter) := 
                     Perimeter_Count(Multiple * Perimeter) + 1;
                  Multiple := Multiple + 1;
               end loop;
            end;
         end if;
      end loop;
   end loop;
   
   -- Count how many perimeters occur exactly once
   declare
      Result : Integer := 0;
   begin
      for I in 1..Max_Perimeter loop
         if Perimeter_Count(I) = 1 then
            Result := Result + 1;
         end if;
      end loop;
      
      Put("Answer: ");
      Put(Result);
      New_Line;
   end;
end Euler_75;
```

## Explanation

The solution works by:

1. **Generating primitive Pythagorean triples** using the Euclidean formula
2. **Filtering valid triples** by ensuring:
   - gcd(m,n) = 1 (coprime)
   - m and n are not both odd
3. **Scaling up** each primitive triple to generate all multiples
4. **Counting occurrences** of each perimeter in an array
5. **Finding the answer** by counting perimeters that appear exactly once

## Key Points

- Uses Euclid's formula for generating Pythagorean triples efficiently
- Handles both primitive and non-primitive triples through scaling
- Optimizes by only checking up to √(Max_Perimeter) for m values
- Counts occurrences rather than trying to enumerate all triangles directly

The answer is **161667**.
