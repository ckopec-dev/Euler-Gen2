# Euler Problem 80 Solution in Ruby

## Problem Statement
For the first one hundred natural numbers, find the total of the digital sums of the first one hundred decimal digits for all the irrational square roots.

## Solution

```ruby
def sqrt_digits(n, precision = 100)
  # Calculate square root of n with given precision
  # Using Newton's method for finding square root
  return Math.sqrt(n).to_s if n == 0
  
  # Start with initial guess
  x = n.to_f
  precision = precision + 10 # Add extra precision for accuracy
  
  # Newton's method: x_new = (x + n/x) / 2
  (0..precision).each do
    x = (x + n.to_f / x) / 2.0
  end
  
  # Convert to string and extract first precision digits
  x.to_s.split('.')[0] + x.to_s.split('.')[1][0, precision]
end

def digital_sum(n)
  # Calculate sum of digits in a number
  n.to_s.chars.map(&:to_i).sum
end

def solve_euler_80
  total_sum = 0
  
  (1..100).each do |n|
    # Skip perfect squares
    next if Math.sqrt(n) == Math.sqrt(n).to_i
    
    # Calculate square root with high precision
    sqrt_str = sqrt_digits(n, 100)
    
    # Take first 100 digits and calculate sum
    digits = sqrt_str[0, 100]
    total_sum += digital_sum(digits)
  end
  
  total_sum
end

# Alternative approach using BigDecimal for better precision
require 'bigdecimal'
require 'bigdecimal/util'

def solve_euler_80_precise
  total_sum = 0
  precision = 100
  
  (1..100).each do |n|
    # Skip perfect squares
    next if Math.sqrt(n) == Math.sqrt(n).to_i
    
    # Calculate square root using BigDecimal for high precision
    num = BigDecimal(n.to_s)
    sqrt_result = num.sqrt(precision + 10)
    
    # Convert to string and get first 100 digits
    sqrt_str = sqrt_result.to_s('F')
    # Remove "0." prefix and get first 100 digits
    digits = sqrt_str.gsub('.', '')[0, precision]
    
    # Calculate sum of digits
    total_sum += digits.chars.map(&:to_i).sum
  end
  
  total_sum
end

# Even more precise approach
def sqrt_decimal(n, precision)
  # Use BigDecimal for precise calculation
  n = BigDecimal(n.to_s)
  result = n.sqrt(precision + 20)
  
  # Convert to string and extract digits
  str = result.to_s('F')
  # Remove decimal point and take first precision digits
  digits = str.gsub('.', '')[0, precision]
  
  digits
end

def solve_euler_80_final
  total_sum = 0
  
  (1..100).each do |n|
    # Skip perfect squares
    next if (Math.sqrt(n) % 1) == 0
    
    # Calculate square root with 100 digits precision
    sqrt_str = sqrt_decimal(n, 100)
    
    # Calculate sum of first 100 digits
    digit_sum = sqrt_str.chars.map(&:to_i).sum
    total_sum += digit_sum
  end
  
  total_sum
end

# Run the solution
result = solve_euler_80_final
puts "The total of digital sums is: #{result}"
```

## Explanation

The solution works as follows:

1. **Identify Irrational Square Roots**: We iterate through numbers 1 to 100 and skip perfect squares since their square roots are rational.

2. **High Precision Calculation**: For each irrational square root, we calculate it with sufficient precision (100+ digits) using BigDecimal for accuracy.

3. **Digit Sum Calculation**: For each square root, we extract the first 100 decimal digits and sum them up.

4. **Total Sum**: We accumulate the sum of all these digit sums.

## Key Points

- **Perfect Squares**: We skip numbers like 1, 4, 9, 16, 25, etc. since their square roots are rational
- **Precision**: We need high precision to get accurate decimal digits
- **BigDecimal**: Used for precise arithmetic operations
- **Digit Extraction**: We take the first 100 digits after the decimal point

## Result

The answer to Euler Problem 80 is **40886**.
