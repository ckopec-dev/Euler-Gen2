# Euler Problem 71 Solution in Ruby

## Problem Statement
Consider the fraction n/d where n and d are positive integers. If n < d and HCF(n,d)=1, it is called a reduced proper fraction.

If we list the set of reduced proper fractions for d ≤ 1,000,000 in ascending order of size, find the numerator of the fraction immediately to the left of 3/7.

## Solution

```ruby
def gcd(a, b)
  while b != 0
    a, b = b, a % b
  end
  a
end

def solve
  target = 3.0 / 7.0
  max_d = 1000000
  closest_numerator = 0
  closest_denominator = 1
  
  # For each denominator d from 2 to max_d
  (2..max_d).each do |d|
    # Find the largest numerator n such that n/d < 3/7
    # This means n < 3*d/7, so n = floor(3*d/7 - epsilon)
    n = (3 * d - 1) / 7
    
    # Skip if n = 0 or if gcd(n,d) != 1 (not reduced)
    next if n == 0
    
    # Check if the fraction n/d is reduced
    if gcd(n, d) == 1
      # Calculate the actual value
      fraction_value = n.to_f / d.to_f
      
      # Check if this is closer to 3/7 than our current closest
      if fraction_value < target && fraction_value > closest_numerator.to_f / closest_denominator.to_f
        closest_numerator = n
        closest_denominator = d
      end
    end
  end
  
  closest_numerator
end

puts solve
```

## Explanation

The approach is to iterate through all possible denominators from 2 to 1,000,000 and for each denominator, find the largest numerator that creates a fraction less than 3/7 while maintaining the condition that the fraction is in its reduced form (HCF(n,d) = 1).

Key insights:
1. For a given denominator `d`, we want the largest `n` such that `n/d < 3/7`
2. This translates to `n < 3*d/7`, so `n = floor(3*d/7 - epsilon)` where epsilon is a small positive number
3. We need to ensure that `gcd(n,d) = 1` for the fraction to be reduced
4. Among all valid fractions, we want the one that's closest to but less than 3/7

The solution efficiently finds the numerator of the fraction immediately to the left of 3/7 in the ordered list of reduced proper fractions with denominators up to 1,000,000.

**Answer: 428570**
