# Euler Problem 25 Solution in Ruby

## Problem Statement
The Fibonacci sequence is defined by the recurrence relation:
- F₁ = 1
- F₂ = 1  
- Fₙ = Fₙ₋₁ + Fₙ₋₂, for n > 2

The 12th term, F₁₂ = 144, is the first term to contain three digits.

What is the index of the first term in the Fibonacci sequence to contain 1000 digits?

## Solution

```ruby
def fibonacci_with_1000_digits
  # Initialize first two Fibonacci numbers
  fib_prev = 1
  fib_curr = 1
  index = 2
  
  # Continue until we find a Fibonacci number with 1000 digits
  while fib_curr.to_s.length < 1000
    fib_next = fib_prev + fib_curr
    fib_prev = fib_curr
    fib_curr = fib_next
    index += 1
  end
  
  index
end

# Execute the solution
result = fibonacci_with_1000_digits
puts "The index of the first Fibonacci number with 1000 digits is: #{result}"
```

## Explanation

1. **Initialization**: Start with the first two Fibonacci numbers (both equal to 1) and set the index to 2.

2. **Loop Condition**: Continue generating Fibonacci numbers while the current number has fewer than 1000 digits.

3. **Generation**: In each iteration:
   - Calculate the next Fibonacci number by adding the previous two
   - Update the previous and current values
   - Increment the index

4. **Digit Check**: Convert the current Fibonacci number to a string and check its length to determine if it has 1000 digits.

5. **Return**: When we find the first Fibonacci number with 1000 digits, return its index.

## Output
```
The index of the first Fibonacci number with 1000 digits is: 4782
```

The solution efficiently computes Fibonacci numbers iteratively without storing all previous values, making it memory efficient while finding that the 4782nd Fibonacci number is the first to contain exactly 1000 digits.
