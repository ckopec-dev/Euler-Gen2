For a 3×n rectangle, I need to consider how to fill the first column:
- I can place 0, 1, or 2 dominoes in the first column
- If I place 0 dominoes, I need to fill the remaining 3×(n-1) rectangle
- If I place 1 domino, I need to consider different placements
- If I place 2 dominoes, I need to consider different arrangements

Let me define f(n) = number of ways to tile a 3×n rectangle with 2×1 dominoes.

After analyzing the possible configurations, the recurrence relation is:
f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4) for n ≥ 4
