First, let me understand what Euler Problem 606 asks:
- Find the sum of all primes p < 10^8 such that when we write p in base 10, we can rearrange the digits to form a prime q where q = 2p + 1.

This is a variant of the Sophie Germain prime problem, where p is a Sophie Germain prime (p and 2p+1 are both prime).

Let me break this down:
1. Generate primes up to 10^8
2. For each prime p, check if 2p+1 is also prime
3. Check if the digits of p can be rearranged to form 2p+1
4. Sum all such primes

```ruby
def sieve_of_eratosthenes(limit)
  sieve = Array.new(limit + 1, true)
  sieve[0] = sieve[1] = false
  
  (2..Math.sqrt(limit)).each do |i|
    if sieve[i]
      (i * i).step(limit, i) do |j|
        sieve[j] = false
      end
    end
  end
  
  (2..limit).select { |i| sieve[i] }
end

def get_digits(n)
  n.to_s.chars.map(&:to_i)
end

def can_rearrange_to?(digits, target)
  target_digits = get_digits(target)
  digits.sort == target_digits.sort
end

def solve
  limit = 10**8
  primes = sieve_of_eratosthenes(limit)
  prime_set = primes.to_set
  
  sum = 0
  
  primes.each do |p|
    break if p >= limit
    
    q = 2 * p + 1
    
    # Check if q is prime
    next unless prime_set.include?(q)
    
    # Check if digits of p can be rearranged to form q
    if can_rearrange_to?(get_digits(p), q)
      sum += p
    end
  end
  
  sum
end

# Run the solution
result = solve
puts result
```
