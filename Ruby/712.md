First, let me understand what Euler Problem 712 asks for:

**Problem Statement**: 
Find the number of integers 1 < n < 10^10 for which the number of divisors of n is equal to the number of divisors of n+1.

This is asking us to count integers n where d(n) = d(n+1), where d(n) is the number of divisors of n.

def count_divisors(n)
  return 1 if n == 1
  count = 0
  sqrt_n = Math.sqrt(n).to_i
  
  (1..sqrt_n).each do |i|
    if n % i == 0
      if i * i == n
        count += 1
      else
        count += 2
      end
    end
  end
  
  count
end
