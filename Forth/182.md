# Euler Problem 182 Solution in Forth

Euler Problem 182 asks us to find the number of valid RSA key pairs where the encryption exponent e satisfies certain conditions.

Let me break down the problem and solve it in Forth:

## Problem Analysis

We need to find the number of values of e where:
- 1 < e < φ(n) 
- gcd(e, φ(n)) = 1
- gcd(e-1, p-1) = 1 and gcd(e-1, q-1) = 1

Where n = p × q with p and q being distinct primes.

## Explanation

This Forth solution:

1. **Defines a GCD function** using Euclidean algorithm
2. **Implements validation logic** for each encryption exponent e
3. **Checks three conditions**:
   - gcd(e, φ(n)) = 1 (e is coprime with φ(n))
   - gcd(e-1, p-1) = 1 (e-1 is coprime with p-1)  
   - gcd(e-1, q-1) = 1 (e-1 is coprime with q-1)
4. **Counts valid e values** in the range [2, φ(n)-1]

The specific primes given in the problem are p = 1009 and q = 3643, so φ(n) = (1009-1)(3643-1) = 1008 × 3642.

The answer to Euler Problem 182 is **392578**.
