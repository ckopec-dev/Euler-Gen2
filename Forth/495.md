## Analysis

The key insight is that we need to find numbers n where d(n) = 10^12, where d(n) is the number of divisors of n.

For a number n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, the number of divisors is:
d(n) = (a₁ + 1)(a₂ + 1)...(aₖ + 1)

So we need to find all possible factorizations of 10^12 into factors, then determine which combinations of prime powers give valid n ≤ 10^17.
