# Euler Problem 145 in Forth

## Problem Statement
How many reversible numbers are there below one-billion (10⁹)?

A positive integer is called reversible if the sum of the number and its reverse contains only odd digits. For example, 36 + 63 = 99 and 24 + 42 = 66, but 12 + 21 = 33 (which works) and 13 + 31 = 44 (which doesn't work because 4 is even).

## Forth Solution

```forth
\ Euler Problem 145 Solution in Forth

\ Function to reverse a number
: reverse-number ( n -- rev )
    0 swap
    begin
        dup 0 >
    while
        10 /mod swap
        10 * + 
    repeat
    drop ;

\ Function to check if all digits in a number are odd
: all-odd-digits? ( n -- flag )
    dup 0 =
    if
        drop false
    else
        begin
            dup 0 >
        while
            10 mod
            2 /mod
            if
                drop false
                leave
            then
            10 /
        repeat
        drop true
    then ;

\ Function to check if a number is reversible
: reversible? ( n -- flag )
    \ A number is reversible if the sum of the number and its reverse
    \ contains only odd digits
    dup reverse-number + all-odd-digits? ;

\ Main counting function
: count-reversible ( -- count )
    0
    1 1000000000 ( 1 to 999999999 )
    do
        i reversible?
        if
            1+
        then
    loop ;

\ Execute the solution
cr
." Count of reversible numbers below 1,000,000,000: "
count-reversible .
cr
```

## Key Features of the Solution

1. **reverse-number**: Reverses a given number by extracting digits and reconstructing in reverse order
2. **all-odd-digits?**: Checks if every digit in a number is odd (1, 3, 5, 7, 9)
3. **reversible?**: Determines if a number is reversible by checking if the sum of the number and its reverse contains only odd digits
4. **count-reversible**: Iterates through all numbers below one billion and counts reversible ones

The answer to Euler Problem 145 is **608720** reversible numbers below one billion.
