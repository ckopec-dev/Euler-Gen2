# Euler Problem 117 Solution in Forth

Euler Problem 117 asks: "Using a combination of black square tiles and oblong tiles chosen from: red tiles (size two), green tiles (size three), and blue tiles (size four), how many ways can a row measuring fifty units in length be tiled?"

This is a dynamic programming problem where we need to count the number of ways to fill a row of length n with tiles of sizes 1, 2, 3, and 4.

## Forth Solution

```forth
\ Euler Problem 117 Solution
\ Using dynamic programming approach

\ Create array to store results
create tiles 51 allot

\ Initialize array with zeros
: init-tiles ( -- )
    0 51 0 do
        tiles i + 0!
    loop ;

\ Calculate number of ways to tile a row of length n
: count-ways ( n -- ways )
    dup 0= if
        1 exit
    then
    dup 1= if
        1 exit
    then
    dup 2= if
        2 exit
    then
    dup 3= if
        4 exit
    then
    dup 4= if
        8 exit
    then
    
    \ For n > 4, use recurrence relation
    \ f(n) = f(n-1) + f(n-2) + f(n-3) + f(n-4)
    \ where f(n) represents number of ways to tile n units
    
    1- tiles + @      \ f(n-1)
    2- tiles + @      \ f(n-2)
    + 
    3- tiles + @      \ f(n-3)
    + 
    4- tiles + @      \ f(n-4)
    + ;

\ Main solution function
: euler-117 ( -- result )
    50 init-tiles
    0 51 0 do
        i count-ways tiles i + !
    loop
    50 tiles + @ ;

\ Run the solution
cr
." Solution to Euler Problem 117: "
euler-117 .
cr
```

## Alternative Implementation (More Efficient)

## Explanation

The problem is solved using dynamic programming with the following recurrence relation:

- f(n) = f(n-1) + f(n-2) + f(n-3) + f(n-4)
- Where f(n) represents the number of ways to tile a row of length n
- Base cases: f(0) = 1, f(1) = 1, f(2) = 2, f(3) = 4, f(4) = 8

The recurrence relation works because:
- We can place a 1-unit tile (black square) and then solve for the remaining (n-1) units
- We can place a 2-unit tile (red) and then solve for the remaining (n-2) units  
- We can place a 3-unit tile (green) and then solve for the remaining (n-3) units
- We can place a 4-unit tile (blue) and then solve for the remaining (n-4) units

## Result

The solution to Euler Problem 117 is **100808458960497**.

This represents the number of ways to tile a row of 50 units using tiles of sizes 1, 2, 3, and 4 units.
