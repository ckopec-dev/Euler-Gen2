# Euler Problem 430 Solution in Rust

## Problem Statement
Euler Problem 430 asks us to find the sum of all integers k from 1 to 10^15 such that gcd(k, 10^15) = 1, where gcd is the greatest common divisor.

## Mathematical Analysis

First, let's understand what we're looking for:
- We want all integers k where 1 ≤ k ≤ 10^15 and gcd(k, 10^15) = 1
- This means k is coprime to 10^15
- This is essentially asking for the sum of all integers ≤ 10^15 that are coprime to 10^15

The key insight is that we can use Euler's totient function φ(n) to count how many numbers are coprime to n, but we need the actual sum.

## Approach

The sum of all integers ≤ n that are coprime to n is given by the formula:
Sum = n × φ(n) / 2

Where φ(n) is Euler's totient function.

Let's break down 10^15:
10^15 = 2^15 × 5^15

Using the formula for Euler's totient function:
φ(10^15) = 10^15 × (1 - 1/2) × (1 - 1/5) = 10^15 × 1/2 × 4/5 = 10^15 × 2/5 = 4 × 10^14

Therefore, the sum = 10^15 × 4 × 10^14 / 2 = 10^15 × 2 × 10^14 = 2 × 10^29

## Correct Solution

For any positive integer n, the sum of all integers from 1 to n that are coprime to n is:
Sum = n × φ(n) / 2

Where φ(n) is Euler's totient function.

For n = 10^15 = 2^15 × 5^15:
φ(10^15) = 10^15 × (1 - 1/2) × (1 - 1/5) = 10^15 × 1/2 × 4/5 = 4 × 10^14

So the sum = 10^15 × 4 × 10^14 / 2 = 2 × 10^29

fn euler_totient(n: u128) -> u128 {
    let mut result = n;
    let mut n_copy = n;
    
    // Check for factor 2
    if n_copy % 2 == 0 {
        result = result / 2;
        while n_copy % 2 == 0 {
            n_copy /= 2;
        }
    }
    
    // Check for odd factors from 3 onwards
    let mut i = 3;
    while i * i <= n_copy {
        if n_copy % i == 0 {
            result = result - result / i;
            while n_copy % i == 0 {
                n_copy /= i;
            }
        }
        i += 2;
    }
    
    // If n_copy is a prime number greater than 2
    if n_copy > 2 {
        result = result - result / n_copy;
    }
    
    result
}

    let phi_n = euler_totient(n);
    (n * phi_n) / 2
