## Explanation

The key insight is that we're counting the number of ways to tile a 3×n rectangle using 2×1 dominoes and 1×1 squares. The recurrence relation comes from analyzing how we can fill the rightmost columns of the rectangle.

The recurrence `f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)` accounts for:
- `f(n-1)`: Adding a vertical domino or 1×1 square
- `5*f(n-2)`: Various configurations of two dominoes
- `f(n-3)`: More complex arrangements
- `-f(n-4)`: Subtraction to avoid overcounting

The solution uses modular arithmetic to handle large numbers and returns the result for n = 1,000,000.
