# Euler Problem 90 Solution in Rust

This problem asks us to find how many distinct arrangements of two cubes can represent all square numbers from 1 to 99 using pairs of digits.

## Problem Understanding

We need to:
1. Create two cubes with digits (0-9) on their faces
2. Each cube has 6 faces
3. The arrangement should allow representing all square numbers from 1 to 99
4. A square number like 16 can be represented as 1,6 or 6,1 (order matters for the pair)
5. The digit 6 and 9 are interchangeable (as shown in the problem)

## Solution Approach

I'll use a brute force approach:
1. Generate all possible combinations of 6 digits from 0-9 for each cube
2. For each pair of cubes, check if they can represent all square numbers
3. Handle the 6/9 interchangeability properly

```rust
fn main() {
    let mut count = 0;
    
    // Generate all combinations of 6 digits from 0-9
    let combinations: Vec<Vec<i32>> = (0..=9)
        .combinations(6)
        .map(|v| v.into_iter().collect())
        .collect();
    
    // Check each pair of combinations
    for i in 0..combinations.len() {
        for j in 0..combinations.len() {
            if can_represent_all_squares(&combinations[i], &combinations[j]) {
                count += 1;
            }
        }
    }
    
    // Since we count each pair twice (once as (a,b) and once as (b,a)), 
    // we need to divide by 2 to get unique arrangements
    println!("Number of distinct arrangements: {}", count / 2);
}

fn can_represent_all_squares(cube1: &Vec<i32>, cube2: &Vec<i32>) -> bool {
    let squares = vec![1, 4, 9, 16, 25, 36, 49, 64, 81];
    
    for square in squares {
        let tens = (square / 10) as i32;
        let units = (square % 10) as i32;
        
        if !can_represent_pair(cube1, cube2, tens, units) {
            return false;
        }
    }
    
    true
}

fn can_represent_pair(cube1: &Vec<i32>, cube2: &Vec<i32>, tens: i32, units: i32) -> bool {
    // Check if we can form the pair (tens, units) with the two cubes
    let cube1_has_tens = cube1.contains(&tens) || (tens == 6 && cube1.contains(&9));
    let cube2_has_units = cube2.contains(&units) || (units == 6 && cube2.contains(&9));
    
    let cube1_has_units = cube1.contains(&units) || (units == 6 && cube1.contains(&9));
    let cube2_has_tens = cube2.contains(&tens) || (tens == 6 && cube2.contains(&9));
    
    (cube1_has_tens && cube2_has_units) || (cube1_has_units && cube2_has_tens)
}

fn solve() -> i64 {
    let mut count = 0i64;
    
    // Generate all combinations of 6 digits from 0-9
    let mut cubes = Vec::new();
    
    // Generate all 6-digit combinations from 0-9
    generate_combinations(&mut cubes, &mut vec![], 0, 6);
    
    // Check all pairs of cubes
    for i in 0..cubes.len() {
        for j in i..cubes.len() {  // Start from i to avoid double counting
            if can_represent_all_squares(&cubes[i], &cubes[j]) {
                count += 1;
            }
        }
    }
    
    count
}

fn generate_combinations(cubes: &mut Vec<Vec<i32>>, current: &mut Vec<i32>, start: i32, len: usize) {
    if current.len() == len {
        cubes.push(current.clone());
        return;
    }
    
    for i in start..=9 {
        current.push(i);
        generate_combinations(cubes, current, i + 1, len);
        current.pop();
    }
}
```
