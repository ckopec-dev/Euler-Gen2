# Euler Problem 7 Solution in Rust

## Problem Statement
By listing the first six prime numbers: 2, 3, 5, 7, 11, and 13, we can see that the 6th prime is 13.

What is the 10,001st prime number?

## Solution

```rust
fn is_prime(n: u64) -> bool {
    if n <= 1 {
        return false;
    }
    if n <= 3 {
        return true;
    }
    if n % 2 == 0 || n % 3 == 0 {
        return false;
    }
    
    let mut i = 5;
    while i * i <= n {
        if n % i == 0 || n % (i + 2) == 0 {
            return false;
        }
        i += 6;
    }
    true
}

fn find_nth_prime(n: usize) -> u64 {
    let mut count = 0;
    let mut num = 1;
    
    while count < n {
        num += 1;
        if is_prime(num) {
            count += 1;
        }
    }
    
    num
}

fn main() {
    let result = find_nth_prime(10001);
    println!("The 10,001st prime number is: {}", result);
}
```

## Explanation

The solution consists of two main functions:

1. **`is_prime(n: u64) -> bool`**: This function efficiently checks if a number is prime using the 6k±1 optimization. It:
   - Handles edge cases (numbers ≤ 1, 2, and 3)
   - Checks divisibility by 2 and 3
   - Uses the fact that all primes > 3 are of the form 6k±1
   - Only checks divisors up to √n

2. **`find_nth_prime(n: usize) -> u64`**: This function:
   - Iterates through numbers starting from 1
   - Counts prime numbers found
   - Returns the nth prime when found

## Output
```
The 10,001st prime number is: 104743
```

## Performance Notes
- The algorithm has a time complexity of approximately O(n√p) where p is the nth prime
- The 6k±1 optimization in `is_prime` significantly reduces the number of divisibility checks
- For very large values, more advanced algorithms like the Sieve of Eratosthenes could be used, but this solution is efficient enough for the given problem
