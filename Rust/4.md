# Euler Problem 4 Solution in Rust

## Problem Statement
A palindromic number reads the same both ways. The largest palindrome made from the product of two 2-digit numbers is 9009 = 91 × 99. Find the largest palindrome made from the product of two 3-digit numbers.

## Solution

```rust
fn is_palindrome(n: u64) -> bool {
    let s = n.to_string();
    let chars: Vec<char> = s.chars().collect();
    let len = chars.len();
    
    for i in 0..len / 2 {
        if chars[i] != chars[len - 1 - i] {
            return false;
        }
    }
    true
}

fn largest_palindrome_product() -> u64 {
    let mut largest = 0;
    
    // Check all products of 3-digit numbers
    for i in (100..=999).rev() {
        for j in (100..=999).rev() {
            let product = i * j;
            
            // If product is smaller than our current largest, 
            // no need to check smaller j values
            if product < largest {
                break;
            }
            
            if is_palindrome(product) && product > largest {
                largest = product;
            }
        }
    }
    
    largest
}

fn main() {
    let result = largest_palindrome_product();
    println!("The largest palindrome made from the product of two 3-digit numbers is: {}", result);
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_is_palindrome() {
        assert_eq!(is_palindrome(9009), true);
        assert_eq!(is_palindrome(12321), true);
        assert_eq!(is_palindrome(12345), false);
        assert_eq!(is_palindrome(1), true);
    }

    #[test]
    fn test_example() {
        // For 2-digit numbers, the answer should be 9009
        let mut largest = 0;
        for i in (10..=99).rev() {
            for j in (10..=99).rev() {
                let product = i * j;
                if is_palindrome(product) && product > largest {
                    largest = product;
                }
            }
        }
        assert_eq!(largest, 9009);
    }
}
```

## Explanation

The solution works by:

1. **`is_palindrome` function**: Converts the number to a string and checks if it reads the same forwards and backwards by comparing characters from both ends moving inward.

2. **`largest_palindrome_product` function**: 
   - Iterates through all possible products of 3-digit numbers (100-999)
   - Uses reverse iteration to start with larger numbers first
   - Implements an optimization: if the current product is smaller than our largest found palindrome, we break out of the inner loop since all remaining products will be smaller
   - Updates the largest palindrome found

3. **Optimization**: By iterating from 999 down to 100, we find larger palindromes earlier, allowing us to skip checking smaller products once we've found a large enough palindrome.

## Result
The largest palindrome made from the product of two 3-digit numbers is **906609**.
