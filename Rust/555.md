# Euler Problem 555 Solution in Rust

I'll solve Euler Problem 555, which asks for the sum of the number of digits in the decimal representation of all numbers from 1 to n.

## Problem Understanding

The problem asks us to find the sum of the number of digits in the decimal representation of all numbers from 1 to n. For example, for n=12:
- Numbers 1-9: each has 1 digit → 9×1 = 9 digits
- Numbers 10-12: each has 2 digits → 3×2 = 6 digits
- Total: 9 + 6 = 15 digits

## Approach

I'll use a mathematical approach to calculate this efficiently:
1. Count numbers with 1 digit (1-9)
2. Count numbers with 2 digits (10-99)
3. And so on...
4. For each group, multiply the count by the number of digits

## Rust Implementation

```rust
fn count_digits_sum(n: u64) -> u64 {
    if n == 0 {
        return 0;
    }
    
    let mut total = 0;
    let mut digits = 1;
    let mut count = 9;
    let mut current = 1;
    
    while current <= n {
        let next_power = 10u64.pow(digits + 1);
        let max_in_range = next_power - 1;
        let range_end = max_in_range.min(n);
        let range_count = range_end - current + 1;
        
        total += range_count * digits;
        
        current = next_power;
        digits += 1;
    }
    
    total
}

fn count_digits_sum_v2(n: u64) -> u64 {
    if n == 0 {
        return 0;
    }
    
    let mut total = 0;
    let mut digits = 1;
    let mut power_of_ten = 10u64.pow(digits);
    
    while power_of_ten <= n {
        let range_count = power_of_ten - 10u64.pow(digits - 1);
        total += range_count * digits;
        digits += 1;
        power_of_ten *= 10;
    }
    
    // Handle the remaining numbers
    let last_power = 10u64.pow(digits - 1);
    if last_power <= n {
        let remaining_count = n - last_power + 1;
        total += remaining_count * (digits - 1);
    }
    
    total
}

fn count_digits_sum_final(n: u64) -> u64 {
    if n == 0 {
        return 0;
    }
    
    let mut total = 0;
    let mut digits = 1;
    let mut start = 1;
    
    while start <= n {
        let end = (start * 10 - 1).min(n);
        let count = end - start + 1;
        total += count * digits;
        start *= 10;
        digits += 1;
    }
    
    total
}
```

## Explanation

The solution works by grouping numbers by their digit count:

1. **1-digit numbers (1-9)**: 9 numbers, each contributes 1 digit → 9×1 = 9 digits
2. **2-digit numbers (10-99)**: 90 numbers, each contributes 2 digits → 90×2 = 180 digits  
3. **3-digit numbers (100-999)**: 900 numbers, each contributes 3 digits → 900×3 = 2700 digits
4. And so on...

For a given n, we:
1. Start with 1-digit numbers (1-9)
2. Then 2-digit numbers (10-99)
3. Continue with 3-digit numbers (100-999), etc.
4. For each group, calculate how many numbers are in that range and multiply by the digit count

## Key Insights

- We can calculate the count of numbers with d digits: 9 × 10^(d-1)
- For any range of numbers with the same digit count, we multiply the count by the digit number
- The algorithm is efficient with O(log n) time complexity
