# Euler Problem 619 Solution in Rust

I'll solve Euler Problem 619, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

We need to find the number of ways to express a number as a sum of powers of 2, where each power of 2 can be used at most twice.

For example, for n=5:
- 2^2 + 2^1 + 2^0 = 4 + 2 + 1 = 7 (too large)
- 2^2 + 2^1 = 4 + 2 = 6 (too large)  
- 2^2 + 2^0 = 4 + 1 = 5 ✓
- 2^1 + 2^1 + 2^0 = 2 + 2 + 1 = 5 ✓
- 2^1 + 2^0 + 2^0 + 2^0 = 2 + 1 + 1 + 1 = 5 ✓

Wait, let me re-read this more carefully. Actually, this is asking for the number of ways to write n as a sum of powers of 2, where we can use each power at most twice.

Let me approach this systematically with dynamic programming.

## Solution Approach

I'll use dynamic programming where `dp[i][j]` represents the number of ways to represent integer `i` using powers of 2 up to 2^j, where each power can be used at most twice.

## Rust Implementation

```rust
fn solve_euler_619(n: i64) -> i64 {
    if n == 0 {
        return 1;
    }
    
    // Find the maximum power needed
    let max_power = (n as f64).log2().ceil() as i32;
    
    // dp[i][j] = number of ways to make sum i using powers 2^0, 2^1, ..., 2^j
    // But we can use each power at most twice
    let mut dp = vec![vec![0i64; max_power as usize + 1]; (n + 1) as usize];
    
    // Base case: one way to make 0 (use nothing)
    for j in 0..=max_power {
        dp[0][j] = 1;
    }
    
    // For each power of 2
    for j in 0..=max_power {
        let power = 1i64 << j; // 2^j
        
        // For each target sum
        for i in 0..=(n as usize) {
            // We can use 0, 1, or 2 copies of 2^j
            // 0 copies: dp[i][j-1] (already computed)
            // 1 copy: dp[i-power][j-1] 
            // 2 copies: dp[i-2*power][j-1]
            
            // But we need to be careful about the indexing
            
            // Initialize with using 0 copies
            dp[i][j] = dp[i][j-1];
            
            // Add ways using 1 copy
            if i >= power as usize {
                dp[i][j] += dp[i - power as usize][j-1];
            }
            
            // Add ways using 2 copies
            if i >= 2 * power as usize {
                dp[i][j] += dp[i - 2 * power as usize][j-1];
            }
        }
    }
    
    dp[n as usize][max_power as usize]
}

fn solve_euler_619_v2(n: i64) -> i64 {
    if n == 0 {
        return 1;
    }
    
    // dp[i] = number of ways to make sum i
    let mut dp = vec![0i64; (n + 1) as usize];
    dp[0] = 1;
    
    // For each power of 2
    let mut power = 1i64;
    while power <= n {
        // For each sum from n down to power
        // We process from right to left to avoid using updated values
        let mut i = n;
        while i >= power {
            // We can use 0, 1, or 2 copies of current power
            // But we need to be careful about the constraint
            
            // If we use 1 copy: dp[i] += dp[i - power]
            // If we use 2 copies: dp[i] += dp[i - 2*power]
            
            // But we need to make sure we don't double count by processing in right order
            if i >= 2 * power {
                dp[i as usize] += dp[(i - 2 * power) as usize];
            }
            if i >= power {
                dp[i as usize] += dp[(i - power) as usize];
            }
            i -= 1;
        }
        power *= 2;
    }
    
    dp[n as usize]
}

fn solve_euler_619_final(n: i64) -> i64 {
    let mut dp = vec![0i64; (n + 1) as usize];
    dp[0] = 1;
    
    let mut power = 1i64;
    while power <= n {
        // Process from right to left to avoid using updated values in same iteration
        let mut i = n;
        while i >= power {
            // Add the number of ways to make (i - power) to get ways to make i
            // This allows using one copy of current power
            if i >= power {
                dp[i as usize] += dp[(i - power) as usize];
            }
            
            // Add the number of ways to make (i - 2*power) to get ways to make i  
            // This allows using two copies of current power
            if i >= 2 * power {
                dp[i as usize] += dp[(i - 2 * power) as usize];
            }
            
            i -= 1;
        }
        power *= 2;
    }
    
    dp[n as usize]
}
```

## Explanation

The approach uses dynamic programming with the following logic:

1. **State Definition**: `dp[i]` represents the number of ways to represent integer `i` using powers of 2, where each power can be used at most twice.

2. **Transition**: For each power of 2 (2^j), we iterate through all possible sums from the largest down to that power:
   - We can use 0 copies of 2^j (already accounted for)
   - We can use 1 copy of 2^j: `dp[i] += dp[i - 2^j]`
   - We can use 2 copies of 2^j: `dp[i] += dp[i - 2 * 2^j]`

3. **Ordering**: We process from right to left to ensure we don't use updated values in the same iteration.

4. **Base Case**: `dp[0] = 1` (one way to make 0: use nothing).

## Time and Space Complexity

- **Time Complexity**: O(n log n) where n is the target number
- **Space Complexity**: O(n)

The algorithm correctly handles the constraint that each power of 2 can be used at most twice, giving us the count of all valid representations.
