# Euler Problem 62 Solution in Rust

## Problem Statement
The cube, 41063625 (345³), can be permuted to produce two other cubes: 56623104 (384³) and 66430125 (405³). In fact, 41063625 is the smallest cube which has exactly three permutations that are also cubes.

Find the smallest cube for which exactly five permutations of its digits are also cubes.

## Solution Approach
1. Generate cubes and group them by their sorted digits
2. For each group, count how many cubes have the same digit pattern
3. Find the smallest cube in the group that has exactly 5 permutations

## Rust Implementation

```rust
use std::collections::HashMap;

fn solve() -> u64 {
    let mut cubes_by_digits: HashMap<String, Vec<u64>> = HashMap::new();
    
    // Generate cubes and group by sorted digits
    let mut n = 1u64;
    loop {
        let cube = n * n * n;
        let mut digits = cube.to_string().chars().collect::<Vec<char>>();
        digits.sort_unstable();
        let sorted_digits = digits.into_iter().collect::<String>();
        
        cubes_by_digits.entry(sorted_digits).or_insert_with(Vec::new).push(cube);
        
        // Check if we found a group with exactly 5 cubes
        if let Some(cubes) = cubes_by_digits.get(&sorted_digits) {
            if cubes.len() == 5 {
                return *cubes.iter().min().unwrap();
            }
        }
        
        n += 1;
        
        // Safety check to prevent infinite loop - we know the answer is small
        if n > 10000 {
            break;
        }
    }
    
    0
}

fn main() {
    println!("The smallest cube with exactly five permutations that are also cubes is: {}", solve());
}
```

## Alternative Implementation (More Efficient)

```rust
use std::collections::HashMap;

fn solve_optimized() -> u64 {
    let mut cubes_by_digits: HashMap<String, Vec<u64>> = HashMap::new();
    let mut n = 1u64;
    
    loop {
        let cube = n * n * n;
        let sorted_digits = {
            let mut digits = cube.to_string().chars().collect::<Vec<char>>();
            digits.sort_unstable();
            digits.into_iter().collect::<String>()
        };
        
        let entry = cubes_by_digits.entry(sorted_digits).or_insert_with(Vec::new);
        entry.push(cube);
        
        // If this group now has 5 cubes, return the smallest one
        if entry.len() == 5 {
            return *entry.iter().min().unwrap();
        }
        
        n += 1;
    }
}

fn main() {
    println!("The smallest cube with exactly five permutations that are also cubes is: {}", solve_optimized());
}
```

## Explanation

The solution works by:

1. **Generating cubes**: Starting from 1³, we generate successive cubes
2. **Digit sorting**: For each cube, we sort its digits to create a canonical representation
3. **Grouping**: We use a HashMap to group cubes by their sorted digit patterns
4. **Finding the answer**: When we find a group with exactly 5 cubes, we return the smallest one

The key insight is that if two numbers are permutations of each other, they will have the same sorted digits. So we group cubes by their sorted digit sequences and look for groups of size 5.
