# Euler Problem 922 Solution in Rust

I need to solve Euler Problem 922, which asks for the sum of all numbers n ≤ 10^7 such that the sum of squares of digits of n equals the sum of squares of digits of n².

Let me break this down:
- For each number n from 1 to 10^7
- Calculate sum of squares of digits of n
- Calculate sum of squares of digits of n²
- If they're equal, add n to the result

Here's my Rust solution:

```rust
fn sum_of_squares_of_digits(mut n: u64) -> u64 {
    let mut sum = 0;
    while n > 0 {
        let digit = n % 10;
        sum += digit * digit;
        n /= 10;
    }
    sum
}

fn solve() -> u64 {
    let limit = 10_000_000;
    let mut total = 0;
    
    for n in 1..=limit {
        let sum_digits_n = sum_of_squares_of_digits(n);
        let sum_digits_n2 = sum_of_squares_of_digits(n * n);
        
        if sum_digits_n == sum_digits_n2 {
            total += n;
        }
    }
    
    total
}

fn main() {
    println!("Answer: {}", solve());
}
```
