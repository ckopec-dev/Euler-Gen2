# Euler Problem 794 Solution in Rust

I'll solve Euler Problem 794, which asks for the number of ways to arrange n distinct objects in a circle such that no object is in its original position (derangements in a circular arrangement).

## Problem Analysis

This is a variant of the derangement problem with circular arrangements. We need to count the number of circular permutations where no element appears in its original position.

Let's denote:
- D(n) = number of derangements of n objects in a line
- C(n) = number of derangements of n objects in a circle

## Mathematical Approach

For circular derangements, we can use the inclusion-exclusion principle or derive a recurrence relation.

The number of circular derangements of n objects is:
C(n) = (n-1)! × D(n) / n

Where D(n) is the number of linear derangements:
D(n) = (n-1)!(1 - 1/1! + 1/2! - 1/3! + ... + (-1)^n/n!)
