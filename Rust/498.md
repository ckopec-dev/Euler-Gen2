# Euler Problem 498 Solution in Rust

I'll solve Euler Problem 498, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most 3 times.

## Problem Analysis

The problem asks for the number of ways to express a number as a sum of powers of 2, where each power of 2 (2^0, 2^1, 2^2, ...) can be used at most 3 times.

This is a classic dynamic programming problem where we need to count the number of compositions of a number using powers of 2 with limited repetitions.

## Solution Approach

I'll use dynamic programming with memoization. For each number, I'll recursively calculate how many ways it can be expressed using powers of 2, keeping track of how many times each power can still be used.

## Rust Implementation

fn solve(n: i64) -> i64 {
    let mut memo = HashMap::new();
    count_ways(n, 0, &mut memo) % 1_000_000_007
}

fn count_ways(n: i64, power: i64, memo: &mut HashMap<(i64, i64), i64>) -> i64 {
    if n == 0 {
        return 1;
    }
    
    if n < 0 {
        return 0;
    }
    
    if let Some(&cached) = memo.get(&(n, power)) {
        return cached;
    }
    
    let mut result = 0;
    let power_of_2 = 1i64 << power; // 2^power
    
    // We can use 0, 1, 2, or 3 copies of this power
    for count in 0..=3 {
        let remaining = n - count * power_of_2;
        if remaining >= 0 {
            result = (result + count_ways(remaining, power + 1, memo)) % 1_000_000_007;
        } else {
            break;
        }
    }
    
    memo.insert((n, power), result);
    result
}

## Key Points of the Solution:

1. **Dynamic Programming with Memoization**: We use a HashMap to cache results to avoid recomputation
2. **Recursive Approach**: For each power of 2, we try using 0, 1, 2, or 3 copies
3. **Modular Arithmetic**: Results are taken modulo 1,000,000,007 as required
4. **Efficient Computation**: The memoization ensures we don't recalculate the same subproblems

## Time and Space Complexity:

- **Time Complexity**: O(n × log n) where n is the input number
- **Space Complexity**: O(n × log n) for the memoization table
