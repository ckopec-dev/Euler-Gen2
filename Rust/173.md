## Solution Approach
We want to count positive integers n ≤ 10⁸ that can be written as n = a² - b² = (a-b)(a+b) in exactly one way.

For a number n to have exactly one representation as difference of squares, we need to analyze when n = (a-b)(a+b) has exactly one solution.

Let d₁ = a-b and d₂ = a+b where d₁ ≤ d₂ and both are positive integers.
Then n = d₁ × d₂ and a = (d₁ + d₂)/2, b = (d₂ - d₁)/2

For a and b to be integers, d₁ + d₂ and d₂ - d₁ must both be even, which means d₁ and d₂ have the same parity.

Also, for valid solutions, we need d₁ ≥ 1 and d₂ ≥ 1, and d₂ ≥ d₁.
