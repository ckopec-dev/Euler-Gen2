# Euler Problem 158 Solution in Rust

This problem asks for the maximum number of valid strings of length n that can be formed using letters from 'a' to 'z', where each string must be lexicographically strictly increasing (each letter is greater than the previous one).

Let me break down the approach:

1. For a string of length n, we need to choose n distinct letters from 26 letters
2. For each set of n letters, there's exactly one way to arrange them in strictly increasing order
3. So the answer is C(26, n) for each n, and we want the maximum value of C(26, n) for n from 1 to 26

However, I need to re-read the problem carefully. Looking at the actual problem statement, it's about finding the maximum number of valid strings of length n, where valid means the string is strictly increasing.

The key insight is that we want to maximize C(26, n) for n from 1 to 26, which occurs at n = 13.

Let me implement this:

```rust
fn combination(n: u64, k: u64) -> u64 {
    if k > n || k == 0 {
        return 1;
    }
    if k == n {
        return 1;
    }
    
    let k = k.min(n - k); // Take advantage of symmetry
    let mut result = 1u64;
    
    for i in 0..k {
        result = result * (n - i) / (i + 1);
    }
    
    result
}

fn solve() -> u64 {
    let mut max_count = 0;
    let n = 26;
    
    // Find the maximum value of C(26, k) for k from 1 to 26
    for k in 1..=n {
        let count = combination(n, k);
        if count > max_count {
            max_count = count;
        }
    }
    
    max_count
}

fn main() {
    println!("The maximum number of valid strings is: {}", solve());
}
```
