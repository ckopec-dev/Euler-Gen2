# Euler Problem 155 Solution in Rust

This problem asks us to find the number of distinct capacitance values that can be obtained by connecting exactly 18 identical capacitors of 1 μF in series and/or parallel combinations.

## Problem Analysis

For this problem, we need to:
1. Generate all possible combinations of capacitors in series and parallel
2. Track unique capacitance values
3. Count the total number of distinct values

The key insight is that we can break down the problem recursively:
- For n capacitors, we can split them into two groups of i and (n-i) capacitors
- For each split, we can connect the two groups in series or parallel
- We need to be careful about the base case (1 capacitor = 1 μF)

## Solution Approach

I'll use a recursive approach with memoization to avoid recomputing the same subproblems.

```rust
use std::collections::HashSet;
use std::collections::HashMap;

fn main() {
    let result = solve(18);
    println!("Number of distinct capacitance values: {}", result);
}

fn solve(n: usize) -> usize {
    let mut memo = HashMap::new();
    let mut all_values = HashSet::new();
    
    // Generate all possible capacitance values for n capacitors
    let values = generate_capacitance_values(n, &mut memo);
    
    // Add all values to the set to get unique values
    for value in values {
        all_values.insert(value);
    }
    
    all_values.len()
}

fn generate_capacitance_values(n: usize, memo: &mut HashMap<usize, HashSet<f64>>) -> HashSet<f64> {
    // Base case
    if n == 1 {
        let mut set = HashSet::new();
        set.insert(1.0); // 1 μF capacitor
        return set;
    }
    
    // Check if already computed
    if let Some(cached) = memo.get(&n) {
        return cached.clone();
    }
    
    let mut result = HashSet::new();
    
    // Try all possible splits of n capacitors into two groups
    for i in 1..n {
        let left = generate_capacitance_values(i, memo);
        let right = generate_capacitance_values(n - i, memo);
        
        // Combine left and right groups in series and parallel
        for &l_val in &left {
            for &r_val in &right {
                // Series combination: C_total = C1 * C2 / (C1 + C2)
                let series = (l_val * r_val) / (l_val + r_val);
                result.insert(series);
                
                // Parallel combination: C_total = C1 + C2
                let parallel = l_val + r_val;
                result.insert(parallel);
            }
        }
    }
    
    // Add the result to memoization
    memo.insert(n, result.clone());
    result
}
```

```rust
                }
```

However, let me also consider that we might want to optimize further and make sure we're handling floating point precision properly. Here's the final, cleaner solution:

```rust
use std::collections::HashSet;

fn main() {
    let result = solve(18);
    println!("Number of distinct capacitance values: {}", result);
}

fn solve(n: usize) -> usize {
    // Memoization array where memo[i] contains all possible capacitance values with i capacitors
    let mut memo: Vec<HashSet<f64>> = vec![HashSet::new(); n + 1];
    
    // Base case: 1 capacitor = 1.0 μF
    memo[1].insert(1.0);
    
    // For each number of capacitors from 2 to n
    for capacitors in 2..=n {
        // Try all possible splits of capacitors into two groups
        for left_capacitors in 1..capacitors {
            let right_capacitors = capacitors - left_capacitors;
            
            // For each possible value from left group and right group
            for &left_val in &memo[left_capacitors] {
                for &right_val in &memo[right_capacitors] {
                    // Series combination: C_total = C1*C2/(C1+C2)
                    let series = (left_val * right_val) / (left_val + right_val);
                    memo[capacitors].insert(series);
                    
                    // Parallel combination: C_total = C1 + C2
                    let parallel = left_val + right_val;
                    memo[capacitors].insert(parallel);
                }
            }
        }
    }
    
    memo[n].len()
}
```

This solution works by:
1. Using dynamic programming with memoization
2. For each number of capacitors from 2 to 18, trying all possible ways to split them
3. For each split, combining the results from left and right groups in both series and parallel
4. Storing unique values in a HashSet to automatically handle duplicates
5. Returning the count of unique capacitance values

The time complexity is manageable for n=18, and the space complexity is reasonable for the problem size.
