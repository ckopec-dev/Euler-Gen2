# Euler Problem 141 Solution in Rust

This problem asks us to find the sum of all positive integers n ≤ 10¹⁶ for which the equation n = q³ + r where q and r are positive integers and r < q, has a solution where n is a perfect square.

Let me break down the approach:

```rust
fn solve() -> u64 {
    let limit = 10u64.pow(16);
    let mut sum = 0u64;
    
    // We need to find all n = q³ + r where n is a perfect square
    // and 0 < r < q
    // This means n = q³ + r = k² for some integer k
    // So r = k² - q³
    // And we need 0 < r < q, which means 0 < k² - q³ < q
    // This gives us q³ < k² < q³ + q
    
    // We'll iterate through possible values of q
    let mut q = 1u64;
    while q * q * q <= limit {
        // For each q, we need to find k such that:
        // q³ < k² < q³ + q and k² is a perfect square
        let q_cubed = q * q * q;
        let max_k_squared = q_cubed + q;
        
        // Find the range of k values
        let min_k = (q_cubed as f64).sqrt().ceil() as u64;
        let max_k = (max_k_squared as f64).sqrt().floor() as u64;
        
        for k in min_k..=max_k {
            let k_squared = k * k;
            let r = k_squared - q_cubed;
            
            // Check if r is valid: 0 < r < q
            if r > 0 && r < q {
                sum += k_squared;
            }
        }
        
        q += 1;
    }
    
    sum
}

fn main() {
    println!("{}", solve());
}

fn is_perfect_square(n: u64) -> bool {
    if n == 0 {
        return true;
    }
    let mut low = 1u64;
    let mut high = n;
    
    while low <= high {
        let mid = low + (high - low) / 2;
        let square = mid * mid;
        
        if square == n {
            return true;
        } else if square < n {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    false
}

use std::collections::HashSet;

fn solve() -> u64 {
    let limit = 10u64.pow(16);
    let mut sum = 0u64;
    let mut seen = HashSet::new();
    
    let mut q = 1u64;
    while q * q * q <= limit {
        let q_cubed = q * q * q;
        let max_k_squared = q_cubed + q;

        let min_k = (q_cubed as f64).sqrt().ceil() as u64;
        let max_k = (max_k_squared as f64).sqrt().floor() as u64;
        
        for k in min_k..=max_k {
            let k_squared = k * k;
            let r = k_squared - q_cubed;
            
            // Check if this gives us a valid solution
            if r > 0 && r < q && k_squared <= limit {
                if seen.insert(k_squared) {
                    sum += k_squared;
                }
            }
        }
        
        q += 1;
    }
    
    sum
}

fn main() {
    println!("{}", solve());
}
```

This solution:
1. Iterates through all possible values of q
2. For each q, determines the valid range of k values such that q³ < k² < q³ + q
3. Checks if the resulting n = k² is a valid solution (n = q³ + r where 0 < r < q)
4. Uses a HashSet to avoid counting duplicates
5. Returns the sum of all valid n values ≤ 10¹⁶

The time complexity is approximately O(√limit) since we're iterating through q values up to √limit and for each q, we're checking a small range of k values.
