# Euler Problem 789 Solution in Visual Basic

I'll solve Euler Problem 789 which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding
We need to find the number of ways to write a number n as a sum of powers of 2, where each power of 2 can be used at most twice.

## Visual Basic Solution

```vb
Module Euler789
    ' Memoization dictionary to store computed results
    Private memo As New Dictionary(Of Long, Long)
    
    ' Main function to solve the problem
    Function Solve(n As Long) As Long
        ' Initialize memoization
        memo.Clear()
        Return CountWays(n)
    End Function
    
    ' Recursive function with memoization
    Function CountWays(n As Long) As Long
        ' Base cases
        If n = 0 Then Return 1
        If n < 0 Then Return 0
        
        ' Check if already computed
        If memo.ContainsKey(n) Then
            Return memo(n)
        End If
        
        Dim result As Long = 0
        Dim power As Long = 1
        
        ' Try all powers of 2 that are <= n
        While power <= n
            ' We can use 0, 1, or 2 copies of this power
            ' Use 0 copies: n remains same
            result += CountWays(n)
            
            ' Use 1 copy: n becomes n - power
            result += CountWays(n - power)
            
            ' Use 2 copies: n becomes n - 2*power
            If n >= 2 * power Then
                result += CountWays(n - 2 * power)
            End If
            
            power *= 2
        End While
        
        ' Store result in memo
        memo(n) = result
        Return result
    End Function
    
    ' Optimized version using dynamic programming
    Function SolveOptimized(n As Long) As Long
        ' dp(i) represents number of ways to write i
        Dim dp(n) As Long
        dp(0) = 1
        
        ' For each power of 2
        Dim power As Long = 1
        While power <= n
            ' For each number from power to n
            For i As Long = power To n
                ' We can use 0, 1, or 2 copies of this power
                dp(i) += dp(i - power)  ' Use 1 copy
                If i >= 2 * power Then
                    dp(i) += dp(i - 2 * power)  ' Use 2 copies
                End If
            Next
            power *= 2
        End While
        
        Return dp(n)
    End Function
    
    ' Alternative approach - direct calculation
    Function SolveDirect(n As Long) As Long
        ' This approach uses the fact that we can use at most 2 copies
        ' of each power of 2
        
        Dim result As Long = 0
        Dim power As Long = 1
        
        ' Generate all possible combinations
        ' This is a recursive approach with better optimization
        Return CountWaysOptimized(n, 1)
    End Function
    
    Function CountWaysOptimized(n As Long, power As Long) As Long
        If n = 0 Then Return 1
        If n < 0 OrElse power > n Then Return 0
        
        ' Memoization
        Dim key As String = n.ToString() & "," & power.ToString()
        If memo.ContainsKey(key) Then
            Return memo(key)
        End If
        
        ' Three cases:
        ' 1. Don't use this power of 2
        ' 2. Use 1 copy of this power of 2
        ' 3. Use 2 copies of this power of 2
        Dim result As Long = CountWaysOptimized(n, power * 2) + _
                            CountWaysOptimized(n - power, power * 2) + _
                            CountWaysOptimized(n - 2 * power, power * 2)
        
        memo(key) = result
        Return result
    End Function
    
    Sub Main()
        ' Test with small values
        Console.WriteLine("Euler Problem 789 Solution")
        Console.WriteLine("==========================")
        
        ' For n = 10, we should get 5
        Dim testValue As Long = 10
        Dim result As Long = SolveOptimized(testValue)
        Console.WriteLine($"Number of ways to write {testValue} as sum of powers of 2 (at most 2 copies each): {result}")
        
        ' For n = 100
        testValue = 100
        result = SolveOptimized(testValue)
        Console.WriteLine($"Number of ways to write {testValue} as sum of powers of 2 (at most 2 copies each): {result}")
        
        ' For n = 1000 (the actual problem)
        testValue = 1000
        result = SolveOptimized(testValue)
        Console.WriteLine($"Number of ways to write {testValue} as sum of powers of 2 (at most 2 copies each): {result}")
        
        Console.WriteLine("Press any key to exit...")
        Console.ReadKey()
    End Sub
End Module
```

## Explanation

The solution uses dynamic programming with memoization to efficiently count the number of ways to express a number as a sum of powers of 2, where each power can be used at most twice.

### Key Concepts:
1. **Dynamic Programming**: We build up solutions for smaller numbers to solve larger ones
2. **Memoization**: We cache results to avoid recomputation
3. **Power of 2**: We consider each power of 2 (1, 2, 4, 8, 16, ...) and decide how many times to use it (0, 1, or 2 times)

### Algorithm Steps:
1. Initialize a DP array where `dp[i]` represents the number of ways to write `i`
2. For each power of 2, update the DP array by considering:
   - Using 0 copies of that power
   - Using 1 copy of that power  
   - Using 2 copies of that power
3. Return `dp[n]` as the final answer

### Time Complexity:
- O(n log n) where n is the target number
- Space complexity: O(n)

This approach efficiently handles the constraint that each power of 2 can be used at most twice, which makes it different from the standard coin change problem.
