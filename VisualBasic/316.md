# Euler Problem 316 Solution in Visual Basic

Euler Problem 316 asks: "Numbers in decimal expansions" - Find the sum of all numbers n such that the decimal expansion of 1/n contains all digits 0-9 at least once.

Here's the Visual Basic solution:

```vb
Module Problem316
    Sub Main()
        Dim sum As Long = 0
        Dim limit As Integer = 1000000
        
        For n As Integer = 1 To limit
            If ContainsAllDigits(1.0 / n) Then
                sum += n
            End If
        Next
        
        Console.WriteLine("Sum of all numbers n such that 1/n contains all digits 0-9: " & sum)
        Console.ReadLine()
    End Sub
    
    Function ContainsAllDigits(decimalValue As Double) As Boolean
        ' Convert to string and remove "0." prefix
        Dim strValue As String = decimalValue.ToString()
        
        ' Remove the "0." prefix if present
        If strValue.StartsWith("0.") Then
            strValue = strValue.Substring(2)
        End If
        
        ' Check if we have enough digits (at least 10)
        If strValue.Length < 10 Then
            Return False
        End If
        
        ' Create a set of digits we've seen
        Dim seenDigits As New HashSet(Of Char)
        
        ' Check first 100 digits to be safe
        Dim maxLength As Integer = Math.Min(100, strValue.Length)
        
        For i As Integer = 0 To maxLength - 1
            Dim digit As Char = strValue(i)
            If Char.IsDigit(digit) Then
                seenDigits.Add(digit)
            End If
        Next
        
        ' Check if we have all digits 0-9
        Return seenDigits.Count >= 10
    End Function
End Module
```
