# Euler Problem 211 Solution in Visual Basic

## Problem Statement
For a positive integer n, let σ2(n) be the sum of the squares of its divisors. For example:
σ2(6) = 1² + 2² + 3² + 6² = 1 + 4 + 9 + 36 = 50

We are interested in numbers n for which σ2(n) is a perfect square.

Let D(N) be the number of such numbers n ≤ N for which σ2(n) is a perfect square.

Find D(64,000,000).

## Visual Basic Solution

```vb
Module Euler211
    Sub Main()
        Dim limit As Long = 64000000
        Dim result As Long = 0
        
        ' Array to store σ2(n) values
        Dim sigma2 As Long() = New Long(limit) {}
        
        ' Calculate σ2(n) for all numbers up to limit
        For i As Long = 1 To limit
            For j As Long = i To limit Step i
                sigma2(j) += i * i
            Next
        Next
        
        ' Check which σ2(n) values are perfect squares
        For i As Long = 1 To limit
            If IsPerfectSquare(sigma2(i)) Then
                result += 1
            End If
        Next
        
        Console.WriteLine("D(" & limit & ") = " & result)
        Console.ReadLine()
    End Sub
    
    ' Function to check if a number is a perfect square
    Function IsPerfectSquare(num As Long) As Boolean
        If num < 0 Then Return False
        If num = 0 Then Return True
        
        Dim sqrtNum As Long = CLng(Math.Sqrt(num))
        Return sqrtNum * sqrtNum = num
    End Function
End Module
```

## Explanation

This solution works by:

1. **Preprocessing**: Using a nested loop approach to calculate σ2(n) for all numbers up to the limit
   - For each number `i` from 1 to limit, we add `i²` to all its multiples
   - This efficiently computes the sum of squares of divisors for each number

2. **Perfect Square Check**: For each computed σ2(n), we check if it's a perfect square using the `IsPerfectSquare` function

3. **Counting**: We count how many numbers satisfy the condition

## Optimization Notes

The algorithm uses the fact that for each divisor `d` of `n`, we add `d²` to σ2(n). By iterating through all possible divisors and updating their multiples, we efficiently compute all σ2 values in O(n log n) time complexity.

The solution handles the large limit (64,000,000) by using `Long` data types and optimizing the calculation to avoid redundant computations.
