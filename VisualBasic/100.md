# Euler Problem 100 Solution in Visual Basic

## Problem Statement
Euler Problem 100 asks: "If a box contains twenty-one coloured discs, composed of fifteen blue discs and six red discs, and two discs were taken at random, the probability that both were blue was 15/21 × 14/20 = 1/2.

The next such arrangement, for which there is exactly 50% chance of taking two blue discs at random, is a box containing eighty-five blue discs and thirty-five red discs.

By finding the first arrangement to contain over 10^12 = 1,000,000,000,000 discs in total, determine the number of blue discs in that arrangement."

## Solution Approach
This is a Pell equation problem. We need to find the smallest solution to the equation where the probability of drawing two blue discs equals 1/2.

The probability equation: (b/(b+r)) × ((b-1)/(b+r-1)) = 1/2
This simplifies to: b² - b = (b+r)²/2 - (b+r)/2
Which leads to: b² - b = (b+r)(b+r-1)/2
Further simplification gives us: 2b² - 2b = (b+r)² - (b+r)
Therefore: 2b² - 2b = (b+r)² - (b+r)
Rearranging: 2b² - 2b = (b+r)(b+r-1)
This gives us: 2b² - 2b = (b+r)² - (b+r)
Which becomes: 2b² - 2b = (b+r)² - (b+r)
Or: 2b² - 2b = (b+r)(b+r-1)

Let's use the recurrence relation approach to solve this Pell equation.

## Visual Basic Implementation

```vb
Module Euler100
    Sub Main()
        ' Solve Euler Problem 100
        ' Find the first arrangement with over 10^12 discs where P(2 blue) = 1/2
        
        Dim limit As Long = 1000000000000L
        Dim blue As Long = 15L
        Dim total As Long = 21L
        
        ' Using the recurrence relation for Pell equation
        ' The pattern is: b(n+1) = 3*b(n) + 2*t(n) - 2
        '                 t(n+1) = 4*b(n) + 3*t(n) - 3
        ' Starting with b = 15, t = 21
        
        Do While total < limit
            ' Calculate next values using recurrence relation
            Dim nextBlue As Long = 3 * blue + 2 * total - 2
            Dim nextTotal As Long = 4 * blue + 3 * total - 3
            
            blue = nextBlue
            total = nextTotal
        Loop
        
        Console.WriteLine("Number of blue discs: " & blue)
        Console.WriteLine("Total discs: " & total)
        
        ' Verify the probability
        Dim prob As Double = (blue * (blue - 1)) / (total * (total - 1))
        Console.WriteLine("Probability verification: " & prob)
        
        Console.ReadKey()
    End Sub
End Module
```

## Alternative Implementation with Better Precision

```vb
Module Euler100
    Sub Main()
        ' Solve Euler Problem 100 - More precise approach
        
        Dim limit As Long = 1000000000000L
        Dim blue As Long = 15L
        Dim total As Long = 21L
        
        ' The recurrence relation for this Pell equation:
        ' b(n+1) = 3*b(n) + 2*t(n) - 2
        ' t(n+1) = 4*b(n) + 3*t(n) - 3
        
        Do While total < limit
            Dim nextBlue As Long = 3 * blue + 2 * total - 2
            Dim nextTotal As Long = 4 * blue + 3 * total - 3
            
            blue = nextBlue
            total = nextTotal
        Loop
        
        Console.WriteLine("Answer: " & blue)
        Console.WriteLine("Total discs: " & total)
        
        ' Verify the probability is 1/2
        Dim numerator As Long = blue * (blue - 1)
        Dim denominator As Long = total * (total - 1)
        Dim probability As Double = CDbl(numerator) / CDbl(denominator)
        
        Console.WriteLine("Verification: " & probability)
        Console.WriteLine("Expected: 0.5")
        
        Console.ReadKey()
    End Sub
End Module
```

## Mathematical Explanation

The problem reduces to solving the Pell equation:
$$\frac{b(b-1)}{t(t-1)} = \frac{1}{2}$$

Where:
- $b$ = number of blue discs
- $t$ = total number of discs

This leads to the recurrence relation:
$$b_{n+1} = 3b_n + 2t_n - 2$$
$$t_{n+1} = 4b_n + 3t_n - 3$$

Starting with $b_1 = 15, t_1 = 21$, we generate the sequence until $t_n > 10^{12}$.

## Expected Output
The answer is **756872327473** blue discs.

This solution uses the recurrence relation method which is efficient for large numbers and avoids floating-point precision issues.
