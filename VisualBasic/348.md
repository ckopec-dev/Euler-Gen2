# Euler Problem 348 Solution in Visual Basic

Euler Problem 348 asks us to find the sum of all numbers that can be expressed as the sum of a cube and a square in exactly 4 different ways.

Here's the Visual Basic solution:

```vb
Module Problem348
    Sub Main()
        Dim limit As Long = 100000000
        Dim cubeSquares As New Dictionary(Of Long, Integer)
        Dim results As New List(Of Long)
        
        ' Generate all possible sums of cube + square up to limit
        Dim maxCube As Long = CInt(Math.Pow(limit, 1.0 / 3.0)) + 1
        Dim maxSquare As Long = CInt(Math.Sqrt(limit)) + 1
        
        For i As Long = 1 To maxCube
            Dim cube As Long = i * i * i
            If cube > limit Then Exit For
            
            For j As Long = 1 To maxSquare
                Dim square As Long = j * j
                Dim sum As Long = cube + square
                If sum > limit Then Exit For
                
                If cubeSquares.ContainsKey(sum) Then
                    cubeSquares(sum) += 1
                Else
                    cubeSquares.Add(sum, 1)
                End If
            Next
        Next
        
        ' Find numbers that can be expressed in exactly 4 ways
        For Each kvp As KeyValuePair(Of Long, Integer) In cubeSquares
            If kvp.Value = 4 Then
                results.Add(kvp.Key)
            End If
        Next
        
        ' Sort and display results
        results.Sort()
        
        Console.WriteLine("Numbers that can be expressed as cube + square in exactly 4 ways:")
        For Each num As Long In results
            Console.WriteLine(num)
        Next
        
        Dim total As Long = 0
        For Each num As Long In results
            total += num
        Next
        
        Console.WriteLine("Sum of all such numbers: " & total)
        Console.ReadLine()
    End Sub
End Module
```

## Explanation:

1. **Approach**: The solution generates all possible sums of cubes and squares up to a reasonable limit (100,000,000).

2. **Data Structure**: Uses a Dictionary to count how many different ways each sum can be expressed as a cube + square.

3. **Generation Process**:
   - Loop through possible cube values (1³, 2³, 3³, ...)
   - For each cube, loop through possible square values (1², 2², 3², ...)
   - Calculate sum = cube + square
   - Count occurrences in dictionary

4. **Filtering**: Select numbers that appear exactly 4 times in the dictionary.

5. **Result**: Sum all qualifying numbers.

## Key Optimizations:

- Calculate maximum possible cube and square values needed
- Stop generating when values exceed the limit
- Use Dictionary for efficient counting
- Sort results for clear presentation

The solution will find that there are only a few numbers that can be expressed as the sum of a cube and a square in exactly 4 different ways, and then sum those numbers to get the final answer.
