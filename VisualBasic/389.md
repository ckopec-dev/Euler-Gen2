# Euler Problem 389 Solution in Visual Basic

Let me solve this step by step.

First, let me understand what Euler Problem 389 is asking:
- We have 4 dice: one 4-sided die, one 6-sided die, one 8-sided die, and one 12-sided die
- We roll all four dice and sum the results
- We need to find the standard deviation of all possible sums

## Analysis

For a die with n sides numbered 1 to n:
- Expected value E(X) = (n+1)/2
- Variance Var(X) = (n²-1)/12

Since we're dealing with the sum of independent random variables, the variance of the sum equals the sum of the variances.

## Visual Basic Solution

```vb
Module Problem389
    Sub Main()
        ' Calculate variance for each die
        ' 4-sided die (n=4)
        Dim var4 As Double = (4 * 4 - 1) / 12.0
        
        ' 6-sided die (n=6)
        Dim var6 As Double = (6 * 6 - 1) / 12.0
        
        ' 8-sided die (n=8)
        Dim var8 As Double = (8 * 8 - 1) / 12.0
        
        ' 12-sided die (n=12)
        Dim var12 As Double = (12 * 12 - 1) / 12.0
        
        ' Total variance is sum of individual variances
        Dim totalVariance As Double = var4 + var6 + var8 + var12
        
        ' Standard deviation is square root of variance
        Dim standardDeviation As Double = Math.Sqrt(totalVariance)
        
        Console.WriteLine("Standard deviation: " & standardDeviation.ToString("F10"))
        
        ' Verify with exact calculation
        Dim exactResult As Double = Math.Sqrt(15.0 / 12.0 + 35.0 / 12.0 + 63.0 / 12.0 + 143.0 / 12.0)
        Console.WriteLine("Exact result: " & exactResult.ToString("F10"))
    End Sub
End Module
```
