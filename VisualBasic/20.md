# Euler Problem 20 Solution in Visual Basic

Euler Problem 20 asks for the sum of the digits in 100!

Here's the Visual Basic solution:

```vb
Module Problem20
    Sub Main()
        Dim factorial As String = Factorial(100)
        Dim sum As Long = SumOfDigits(factorial)
        Console.WriteLine("Sum of digits in 100! = " & sum)
        Console.ReadLine()
    End Sub

    Function Factorial(n As Integer) As String
        ' Using String to handle very large numbers
        Dim result As String = "1"
        
        For i As Integer = 2 To n
            result = Multiply(result, i)
        Next
        
        Return result
    End Function

    Function Multiply(num As String, multiplier As Integer) As String
        Dim result As String = ""
        Dim carry As Integer = 0
        Dim digit As Integer
        
        ' Multiply from right to left
        For i As Integer = num.Length - 1 To 0 Step -1
            digit = CInt(num(i).ToString()) * multiplier + carry
            result = (digit Mod 10).ToString() & result
            carry = digit \ 10
        Next
        
        ' Handle remaining carry
        While carry > 0
            result = (carry Mod 10).ToString() & result
            carry = carry \ 10
        End While
        
        Return result
    End Function

    Function SumOfDigits(num As String) As Long
        Dim sum As Long = 0
        
        For i As Integer = 0 To num.Length - 1
            sum += CInt(num(i).ToString())
        Next
        
        Return sum
    End Function
End Module
```

## Explanation:

1. **Factorial Function**: Calculates 100! using string manipulation since the result is too large for standard numeric types
2. **Multiply Function**: Multiplies a large number (stored as string) by a single digit
3. **SumOfDigits Function**: Sums all digits in the factorial result
4. **Main Logic**: Computes 100!, then sums its digits

## Output:
The sum of the digits in 100! is **648**

This solution handles the large numbers that would overflow standard integer types by using string manipulation to perform arithmetic operations.
