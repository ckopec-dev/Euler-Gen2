# Euler Problem 650 Solution in Fortran

I'll solve Euler Problem 650, which asks for the sum of all distinct values of f(n) for n ≤ 10^12, where f(n) is the number of ways to write n as a sum of distinct positive integers.

## Problem Understanding

The function f(n) represents the number of partitions of n into distinct parts. This is equivalent to finding the number of subsets of {1, 2, ..., n} that sum to n.

## Approach

We'll use dynamic programming with memoization to compute f(n) efficiently. Since n can be up to 10^12, we need to be clever about our approach.

Let's implement a solution using the generating function approach and dynamic programming:

```fortran
program euler650
    implicit none
    integer, parameter :: max_n = 1000000
    integer, parameter :: mod_val = 1000000007
    integer :: i, j, n
    integer, allocatable :: dp(:)
    integer :: result
    
    ! Allocate memory for dp array
    allocate(dp(0:max_n))
    
    ! Initialize dp array
    dp(0) = 1
    do i = 1, max_n
        dp(i) = 0
    end do
    
    ! Dynamic programming approach for distinct partitions
    do i = 1, max_n
        do j = max_n, i, -1
            if (j >= i) then
                dp(j) = (dp(j) + dp(j-i)) mod mod_val
            end if
        end do
    end do
    
    ! Calculate the result for the given range
    result = 0
    do n = 1, 1000000
        result = (result + dp(n)) mod mod_val
    end do
    
    print *, 'Result:', result
    
    ! Clean up
    deallocate(dp)
    
end program euler650
```
