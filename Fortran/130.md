# Euler Problem 130 Solution in Fortran

## Problem Statement
Find the sum of all composite numbers n that are not divisible by 2 or 5, and for which A(n) divides (n-1), where A(n) is the least value of k such that R(k) = 10^k - 1 is divisible by n.

## Solution

```fortran
program euler130
    implicit none
    integer, parameter :: MAX_N = 1000000
    integer :: n, k, sum_result, count
    integer :: a_n, temp, gcd_val
    
    ! Initialize variables
    sum_result = 0
    count = 0
    
    ! Check odd composite numbers starting from 9
    do n = 9, MAX_N, 2
        ! Skip if n is divisible by 5
        if (mod(n, 5) == 0) cycle
        
        ! Skip if n is prime
        if (is_prime(n)) cycle
        
        ! Calculate A(n) - the smallest k such that 10^k ≡ 1 (mod n)
        a_n = find_a_n(n)
        
        ! Check if A(n) divides (n-1)
        if (mod(n-1, a_n) == 0) then
            sum_result = sum_result + n
            count = count + 1
            print *, 'Found: n =', n, 'A(n) =', a_n
        end if
    end do
    
    print *, 'Sum of all qualifying composite numbers:', sum_result
    print *, 'Count:', count
    
contains

    ! Function to check if a number is prime
    logical function is_prime(num)
        integer, intent(in) :: num
        integer :: i
        
        if (num <= 1) then
            is_prime = .false.
            return
        end if
        
        if (num <= 3) then
            is_prime = .true.
            return
        end if
        
        if (mod(num, 2) == 0 .or. mod(num, 3) == 0) then
            is_prime = .false.
            return
        end if
        
        i = 5
        do while (i*i <= num)
            if (mod(num, i) == 0 .or. mod(num, i+2) == 0) then
                is_prime = .false.
                return
            end if
            i = i + 6
        end do
        
        is_prime = .true.
    end function is_prime
    
    ! Function to find A(n) - smallest k such that 10^k ≡ 1 (mod n)
    integer function find_a_n(n)
        integer, intent(in) :: n
        integer :: k, power, temp_n
        
        ! Start with k = 1
        k = 1
        power = 10
        
        ! Keep incrementing k until 10^k ≡ 1 (mod n)
        do while (mod(power - 1, n) /= 0)
            k = k + 1
            power = mod(power * 10, n)
        end do
        
        find_a_n = k
    end function find_a_n
    
end program euler130
```

## Explanation

This Fortran program solves Euler Problem 130 by:

1. **Iterating through composite numbers**: Starting from 9 (the first odd composite number), it checks each odd composite number up to a reasonable limit.

2. **Skipping invalid cases**: 
   - Numbers divisible by 5 are skipped (since they're not coprime with 10)
   - Prime numbers are skipped (as specified in the problem)

3. **Computing A(n)**: For each composite number n, it calculates A(n) - the smallest positive integer k such that 10^k ≡ 1 (mod n). This is done by repeatedly multiplying by 10 and taking modulo n until we get 1.

4. **Checking divisibility condition**: It verifies if A(n) divides (n-1). If so, the number qualifies.

5. **Accumulating results**: All qualifying numbers are added to the running sum.

## Key Features

- **Efficient prime checking**: Uses optimized trial division with 6k±1 optimization
- **Modular arithmetic**: Uses modular exponentiation to avoid overflow
- **Memory efficient**: No arrays needed, processes numbers sequentially
- **Clear structure**: Well-documented functions for readability
