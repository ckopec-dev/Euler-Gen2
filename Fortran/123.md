# Euler Problem 123 Solution in Fortran

## Problem Statement
Let pₙ be the n-th prime number. Let R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ mod pₙ².

Find the least value of n for which R(n) first exceeds 10¹⁰.

## Solution Approach
We need to:
1. Generate prime numbers
2. Calculate R(n) = (pₙ-1)ⁿ + (pₙ+1)ⁿ mod pₙ²
3. Find the smallest n where R(n) > 10¹⁰

## Fortran Implementation

```fortran
program euler123
    implicit none
    integer, parameter :: MAX_PRIMES = 1000000
    integer :: n, i, prime_count
    integer, allocatable :: primes(:)
    integer :: p_n, p_n_squared
    integer :: r_n
    integer :: target
    logical :: found
    
    ! Initialize
    target = 10000000000_int64  ! 10^10
    found = .false.
    prime_count = 0
    
    ! Allocate memory for primes
    allocate(primes(MAX_PRIMES))
    
    ! Generate primes using Sieve of Eratosthenes
    call sieve_of_eratosthenes(primes, MAX_PRIMES, prime_count)
    
    ! Main search loop
    do n = 1, prime_count
        p_n = primes(n)
        p_n_squared = p_n * p_n
        
        ! Calculate R(n) = (p_n-1)^n + (p_n+1)^n mod p_n^2
        r_n = mod(mod_power(p_n-1, n, p_n_squared) + mod_power(p_n+1, n, p_n_squared), p_n_squared)
        
        if (r_n > target) then
            print *, 'Answer:', n
            found = .true.
            exit
        end if
    end do
    
    if (.not. found) then
        print *, 'No solution found within range'
    end if
    
    deallocate(primes)
    
contains
    
    subroutine sieve_of_eratosthenes(primes, max_size, count)
        implicit none
        integer, intent(in) :: max_size
        integer, intent(out) :: count
        integer, intent(out) :: primes(max_size)
        logical :: is_prime(max_size)
        integer :: i, j
        
        ! Initialize
        is_prime = .true.
        is_prime(1) = .false.
        
        ! Sieve of Eratosthenes
        do i = 2, int(sqrt(real(max_size)))
            if (is_prime(i)) then
                do j = i*i, max_size, i
                    is_prime(j) = .false.
                end do
            end if
        end do
        
        ! Collect primes
        count = 0
        do i = 2, max_size
            if (is_prime(i)) then
                count = count + 1
                primes(count) = i
            end if
        end do
    end subroutine sieve_of_eratosthenes
    
    integer function mod_power(base, exponent, modulus)
        implicit none
        integer, intent(in) :: base, exponent, modulus
        integer :: result, temp_base, temp_exp
        
        result = 1
        temp_base = mod(base, modulus)
        temp_exp = exponent
        
        do while (temp_exp > 0)
            if (mod(temp_exp, 2) == 1) then
                result = mod(result * temp_base, modulus)
            end if
            temp_base = mod(temp_base * temp_base, modulus)
            temp_exp = temp_exp / 2
        end do
        
        mod_power = result
    end function mod_power
    
end program euler123
```

## Key Features of the Solution

1. **Prime Generation**: Uses Sieve of Eratosthenes to efficiently generate prime numbers
2. **Modular Exponentiation**: Implements fast modular exponentiation to handle large powers
3. **Efficient Calculation**: Uses the property that (a+b) mod m = ((a mod m) + (b mod m)) mod m

## Mathematical Insight

The key insight is that for large n, we can use the binomial theorem:
- (pₙ-1)ⁿ + (pₙ+1)ⁿ = 2(pₙ²)^(n/2) + ... (terms with higher powers)
- When we take mod pₙ², most terms vanish
- For odd n: R(n) = 2 * n * pₙ mod pₙ²

## Expected Output
The program will output the least value of n for which R(n) > 10¹⁰.

**Note**: This implementation uses integer64 for handling large numbers and includes optimizations for modular arithmetic to avoid overflow issues.
