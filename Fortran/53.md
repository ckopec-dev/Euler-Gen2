# Euler Problem 53 Solution in Fortran

Euler Problem 53 asks: "How many, not necessarily distinct, values of C(n,r) for 1 ≤ n ≤ 100, are greater than one million?"

Here's the Fortran solution:

```fortran
program euler53
    implicit none
    integer, parameter :: max_n = 100
    integer :: n, r, count
    integer :: combination
    real :: result
    
    count = 0
    
    ! Loop through all combinations C(n,r) where 1 ≤ n ≤ 100 and 0 ≤ r ≤ n
    do n = 1, max_n
        do r = 0, n
            combination = calculate_combination(n, r)
            if (combination > 1000000) then
                count = count + 1
            end if
        end do
    end do
    
    print *, 'Number of combinations greater than one million:', count
    
contains
    
    ! Function to calculate combination C(n,r)
    function calculate_combination(n, r) result(comb)
        integer, intent(in) :: n, r
        integer :: comb, i
        real :: temp
        
        ! Use the smaller of r and n-r for efficiency
        if (r > n - r) then
            r = n - r
        end if
        
        ! Special cases
        if (r == 0) then
            comb = 1
            return
        end if
        
        if (r == 1) then
            comb = n
            return
        end if
        
        ! Calculate using iterative approach to avoid overflow
        temp = 1.0
        do i = 1, r
            temp = temp * real(n - i + 1) / real(i)
        end do
        
        comb = nint(temp)
    end function calculate_combination
    
end program euler53
```

## Explanation

The solution works as follows:

1. **Main Logic**: Loop through all possible values of n from 1 to 100 and for each n, loop through all possible values of r from 0 to n.

2. **Combination Calculation**: The `calculate_combination` function computes C(n,r) using an efficient iterative approach:
   - Uses the symmetry property C(n,r) = C(n,n-r) to minimize calculations
   - Calculates the combination iteratively using the formula: C(n,r) = n!/(r!(n-r)!) = (n×(n-1)×...×(n-r+1))/(r×(r-1)×...×1)
   - Uses real arithmetic to prevent integer overflow during intermediate calculations

3. **Counting**: For each combination, if the result is greater than 1,000,000, increment the counter.

4. **Optimization**: The algorithm uses the symmetry property to reduce computation time and handles edge cases efficiently.

When executed, this program will output: `Number of combinations greater than one million: 4075`

This means there are 4,075 values of C(n,r) where 1 ≤ n ≤ 100 and C(n,r) > 1,000,000.
