# Euler Problem 105 Solution in Fortran

## Problem Statement
Let S(A) represent the sum of elements in set A of size n. We shall call a set A special if for any two non-empty disjoint subsets B and C:
- S(B) ≠ S(C); that is, sums of subsets cannot be equal
- If B contains more elements than C then S(B) > S(C)

For this problem, we need to find the sum of all elements in special sets from the given file.

## Solution Approach
1. Read the sets from the file
2. For each set, check if it's special by:
   - Verifying all subset sums are unique
   - Verifying the sum property (larger sets have larger sums)
3. Sum all elements of special sets

## Fortran Implementation

```fortran
program euler105
    implicit none
    integer, parameter :: max_n = 12
    integer, parameter :: max_sets = 100
    integer :: n_sets, i, j, k, l
    integer :: sets(max_sets, max_n)
    integer :: set_sizes(max_sets)
    integer :: total_sum
    logical :: is_special
    
    ! Initialize variables
    n_sets = 0
    total_sum = 0
    
    ! Read data from file (assuming data is in a file called "sets.txt")
    call read_sets(sets, set_sizes, n_sets)
    
    ! Check each set for special property
    do i = 1, n_sets
        is_special = check_special(sets(i,:), set_sizes(i))
        if (is_special) then
            ! Add sum of elements in this set to total
            do j = 1, set_sizes(i)
                total_sum = total_sum + sets(i,j)
            end do
        end if
    end do
    
    print *, 'Sum of all elements in special sets:', total_sum
    
end program euler105

subroutine read_sets(sets, set_sizes, n_sets)
    implicit none
    integer, parameter :: max_n = 12
    integer, parameter :: max_sets = 100
    integer :: sets(max_sets, max_n)
    integer :: set_sizes(max_sets)
    integer :: n_sets
    integer :: i, j, k, io_status
    character(len=100) :: line
    character(len=10) :: num_str
    
    n_sets = 0
    
    ! Open file and read sets
    open(unit=10, file='sets.txt', status='old', iostat=io_status)
    if (io_status /= 0) then
        print *, 'Error opening file'
        return
    end if
    
    do
        read(10, '(A)', iostat=io_status) line
        if (io_status /= 0) exit
        
        n_sets = n_sets + 1
        set_sizes(n_sets) = 0
        
        ! Parse the line to extract numbers
        i = 1
        do while (i <= len_trim(line))
            ! Skip whitespace
            do while (i <= len_trim(line) .and. line(i:i) == ' ')
                i = i + 1
            end do
            
            if (i > len_trim(line)) exit
            
            ! Extract number
            j = i
            do while (j <= len_trim(line) .and. line(j:j) /= ',')
                j = j + 1
            end do
            
            num_str = line(i:j-1)
            read(num_str, *) sets(n_sets, set_sizes(n_sets)+1)
            set_sizes(n_sets) = set_sizes(n_sets) + 1
            
            i = j + 1
        end do
    end do
    
    close(10)
end subroutine read_sets

function check_special(set, n) result(is_special)
    implicit none
    integer, parameter :: max_n = 12
    integer :: set(max_n)
    integer :: n
    logical :: is_special
    integer :: i, j, k, l, mask, subset_sum, sum1, sum2
    integer :: subset_sums(2**max_n)
    integer :: subset_count
    logical :: sums_unique
    
    is_special = .false.
    
    ! Check if all subset sums are unique
    subset_count = 0
    sums_unique = .true.
    
    ! Generate all non-empty subsets and calculate their sums
    do i = 1, 2**n - 1
        subset_sum = 0
        do j = 1, n
            if (i .and. (2**(j-1)) /= 0) then
                subset_sum = subset_sum + set(j)
            end if
        end do
        subset_sums(subset_count+1) = subset_sum
        subset_count = subset_count + 1
    end do
    
    ! Check uniqueness of subset sums
    do i = 1, subset_count
        do j = i+1, subset_count
            if (subset_sums(i) == subset_sums(j)) then
                sums_unique = .false.
                return
            end if
        end do
    end do
    
    if (.not. sums_unique) return
    
    ! Check sum property: larger sets have larger sums
    ! This is more complex - we need to check all pairs of subsets
    ! For each subset size, we need to verify the sum property
    
    is_special = check_sum_property(set, n)
    
end function check_special

function check_sum_property(set, n) result(valid)
    implicit none
    integer, parameter :: max_n = 12
    integer :: set(max_n)
    integer :: n
    logical :: valid
    integer :: i, j, k, l, mask1, mask2, size1, size2, sum1, sum2
    integer :: subset1(2**max_n), subset2(2**max_n)
    integer :: count1, count2
    
    valid = .true.
    
    ! For small sets, we can check all pairs of subsets
    ! Generate all subsets and check the property
    do i = 1, 2**n - 1
        ! Count elements in subset i
        size1 = 0
        sum1 = 0
        do j = 1, n
            if (i .and. (2**(j-1)) /= 0) then
                size1 = size1 + 1
                sum1 = sum1 + set(j)
            end if
        end do
        
        ! Compare with all other subsets
        do k = 1, 2**n - 1
            if (k == i) cycle
            
            ! Count elements in subset k
            size2 = 0
            sum2 = 0
            do l = 1, n
                if (k .and. (2**(l-1)) /= 0) then
                    size2 = size2 + 1
                    sum2 = sum2 + set(l)
                end if
            end do
            
            ! If size1 > size2, then sum1 must be > sum2
            if (size1 > size2 .and. sum1 <= sum2) then
                valid = .false.
                return
            end if
        end do
    end do
    
end function check_sum_property
```

## Alternative Simpler Approach

Since the problem involves checking the special property of sets, here's a more focused approach:

## Key Points

1. **Special Set Definition**: A set is special if:
   - No two non-empty disjoint subsets have the same sum
   - If one subset has more elements than another, its sum is greater

2. **Algorithm**:
   - Generate all non-empty subsets
   - Check that all subset sums are unique
   - Verify the sum property for all subset pairs

3. **Implementation Notes**:
   - The code reads data from a file (in practice)
   - Uses bit manipulation to generate subsets efficiently
   - Checks both uniqueness and ordering constraints

4. **Time Complexity**: O(2^n * n) for checking each set, where n is the size of the set

The solution would need to be adapted to read the actual data file provided in the Euler problem.
