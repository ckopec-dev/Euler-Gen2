# Euler Problem 285 Solution in Fortran

I'll solve Euler Problem 285, which involves finding the expected value of a geometric distribution.

## Problem Statement
Euler Problem 285 asks for the expected value of the number of steps required to find a point inside a circle of radius 1, where each step moves to a random point in the unit square [0,1]×[0,1].

## Solution Approach
This problem requires computing the expected value of a geometric distribution with probability of success p = π/4 (the ratio of circle area to square area).

## Fortran Implementation

```fortran
program euler285
    implicit none
    real, parameter :: pi = 3.14159265358979323846264338327950288419716939937510
    real :: expected_value
    integer :: i, n
    real :: sum_prob, prob, cumulative_prob
    
    ! Calculate expected value of geometric distribution
    ! E[X] = 1/p where p = π/4
    expected_value = 4.0 / pi
    
    ! Verify by computing partial sums
    sum_prob = 0.0
    cumulative_prob = 0.0
    
    write(*,*) 'Euler Problem 285 Solution'
    write(*,*) 'Expected value: ', expected_value
    write(*,*) 'Exact value: ', 4.0/pi
    write(*,*) 'Decimal approximation: ', expected_value
    
    ! Additional verification using series expansion
    write(*,*) 'Verification using series:'
    write(*,*) 'E[X] = 1 + (1-p) + (1-p)² + (1-p)³ + ...'
    write(*,*) 'Where p = π/4 = ', pi/4.0
    
    ! Calculate first few terms to show convergence
    do i = 1, 10
        prob = (1.0 - pi/4.0)**(i-1) * (pi/4.0)
        sum_prob = sum_prob + i * prob
        write(*,*) 'Term ', i, ': ', prob, '  Cumulative: ', sum_prob
    end do
    
    write(*,*) 'Final result: ', expected_value
    
end program euler285
```

## Mathematical Explanation

The problem can be solved analytically:

1. **Setup**: We have a unit square [0,1]×[0,1] and a circle of radius 1 centered at the origin
2. **Probability of success**: The probability of landing inside the circle is the ratio of areas: p = π/4
3. **Expected value**: For a geometric distribution with success probability p, the expected number of trials is E[X] = 1/p
4. **Final result**: E[X] = 1/(π/4) = 4/π
