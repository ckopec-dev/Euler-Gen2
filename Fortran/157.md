# Euler Problem 157 Solution in Fortran

Euler Problem 157 asks: "Considering the Diophantine equation 1/x + 1/y = p/10^n, for positive integers x, y and p, what is the sum of all possible values of p for n = 1 to 10?"

Let me solve this step by step.

```fortran
program euler157
    implicit none
    integer, parameter :: max_n = 10
    integer :: n, p, x, y, count, total_sum
    integer :: ten_power, divisor, temp
    logical :: found
    integer, allocatable :: solutions(:)
    
    total_sum = 0
    
    do n = 1, max_n
        ten_power = 10**n
        count = 0
        
        ! For each possible x value
        do x = 1, ten_power
            ! Check if (10^n * x) is divisible by (10^n - x)
            if (ten_power * x) > 0 .and. mod(ten_power * x, (ten_power - x)) == 0 then
                ! Calculate y
                y = (ten_power * x) / (ten_power - x)
                
                ! Check if y is a positive integer
                if (y > 0) then
                    ! Calculate p = x + y
                    p = x + y
                    count = count + 1
                    total_sum = total_sum + p
                end if
            end if
        end do
    end do
    
    print *, "Sum of all possible values of p:", total_sum
end program euler157
```

Wait, let me reconsider the mathematical approach more carefully. The equation is:

1/x + 1/y = p/(10^n)

Rearranging:
(x + y)/(xy) = p/(10^n)
10^n(x + y) = pxy
10^n x + 10^n y = pxy
10^n x = pxy - 10^n y
10^n x = y(px - 10^n)
y = 10^n x / (px - 10^n)

For this to be a positive integer, (px - 10^n) must divide 10^n x.
