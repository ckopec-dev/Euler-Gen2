# Euler Problem 63 Solution in Fortran

Euler Problem 63 asks: "How many n-digit positive integers exist which are also an nth power?"

Let me analyze this step by step and then provide the Fortran solution.

## Analysis

We need to find numbers that are both:
1. n-digit numbers
2. nth powers of some integer

For an n-digit number, we have: 10^(n-1) ≤ x < 10^n
For x = k^n, we need: 10^(n-1) ≤ k^n < 10^n

This gives us: 10^((n-1)/n) ≤ k < 10^(1/n)

For each n, we can calculate how many integers k satisfy this condition.

## Fortran Solution

```fortran
program euler63
    implicit none
    integer, parameter :: max_n = 25
    integer :: n, k, count
    integer :: power_k, power_n
    real :: lower_bound, upper_bound
    logical :: found
    
    count = 0
    
    ! For each possible number of digits n
    do n = 1, max_n
        ! Calculate the bounds for k
        lower_bound = 10.0 ** ((real(n-1)) / real(n))
        upper_bound = 10.0 ** (1.0 / real(n))
        
        ! Find valid k values
        do k = ceiling(lower_bound), floor(upper_bound)
            if (k > 0) then
                ! Check if k^n has exactly n digits
                power_n = k ** n
                if (power_n >= 10 ** (n-1) .and. power_n < 10 ** n) then
                    count = count + 1
                end if
            end if
        end do
    end do
    
    print *, 'Answer:', count
end program euler63
```

## Alternative More Efficient Solution

```fortran
program euler63_optimized
    implicit none
    integer :: n, k, count
    integer :: power_n
    integer :: digits
    
    count = 0
    
    ! For n from 1 to 25 (reasonable upper bound)
    do n = 1, 25
        ! For each possible base k
        k = 1
        do while (k ** n < 10 ** n)
            power_n = k ** n
            
            ! Count digits in power_n
            digits = 0
            if (power_n == 0) then
                digits = 1
            else
                digits = int(log10(real(power_n))) + 1
            end if
            
            ! If number of digits equals n, increment count
            if (digits == n) then
                count = count + 1
            end if
            
            k = k + 1
        end do
    end do
    
    print *, 'Answer:', count
end program euler63_optimized
```
