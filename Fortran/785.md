# Euler Problem 785 Solution in Fortran

I'll solve Euler Problem 785, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Analysis
The problem asks us to find the number of ways to write a number n as a sum of powers of 2 (2^0, 2^1, 2^2, ...) where each power can be used at most twice.

This is a classic dynamic programming problem - we need to count the number of partitions with restricted multiplicities.

## Fortran Solution

```fortran
program euler785
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j, k
    integer :: ways(max_n + 1)
    integer :: result
    
    ! Initialize the ways array
    do i = 0, max_n
        ways(i) = 0
    end do
    
    ! Base case: 0 can be represented in 1 way (empty sum)
    ways(0) = 1
    
    ! For each power of 2 (2^0, 2^1, 2^2, ...)
    i = 0
    do while (2**i <= max_n)
        ! Process each number from 2^i to max_n
        do j = 2**i, max_n
            ! Add the number of ways to form (j - 2^i) 
            ! This represents using one more 2^i
            ways(j) = ways(j) + ways(j - 2**i)
            
            ! If we can use two copies of 2^i, add those ways too
            if (j >= 2 * 2**i) then
                ways(j) = ways(j) + ways(j - 2 * 2**i)
            end if
        end do
        i = i + 1
    end do
    
    ! Read input and solve
    print *, 'Enter the number n (or 0 to exit):'
    do
        read *, n
        if (n == 0) then
            exit
        end if
        
        if (n > 0 .and. n <= max_n) then
            print *, 'Number of ways to write', n, 'as sum of powers of 2 (each used at most twice):'
            print *, ways(n)
        else
            print *, 'Please enter a number between 1 and', max_n
        end if
    end do
    
    ! For the specific problem, we can also compute for a fixed value
    ! Let's compute for n = 1000000 as an example
    print *, 'For n = 1000000:'
    print *, ways(1000000)
    
end program euler785
```

## Alternative Implementation (More Efficient)

```fortran
program euler785_optimized
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j, power
    integer :: ways(max_n + 1)
    integer :: result
    
    ! Initialize array
    do i = 0, max_n
        ways(i) = 0
    end do
    
    ! Base case
    ways(0) = 1
    
    ! For each power of 2
    power = 1
    do while (power <= max_n)
        ! Process each number from power to max_n
        do j = power, max_n
            ! Add ways using one more copy of power
            ways(j) = ways(j) + ways(j - power)
            ! Add ways using two copies of power (if possible)
            if (j >= 2 * power) then
                ways(j) = ways(j) + ways(j - 2 * power)
            end if
        end do
        power = power * 2
    end do
    
    ! Example computation for specific values
    print *, 'Number of ways to write numbers as sum of powers of 2 (each used at most twice):'
    print *, 'n = 10:', ways(10)
    print *, 'n = 100:', ways(100)
    print *, 'n = 1000:', ways(1000)
    print *, 'n = 10000:', ways(10000)
    print *, 'n = 100000:', ways(100000)
    print *, 'n = 1000000:', ways(1000000)
    
end program euler785_optimized
```

## Explanation of the Algorithm

1. **Dynamic Programming Approach**: We use a DP array `ways[i]` to store the number of ways to represent number `i` as a sum of powers of 2.

2. **Base Case**: `ways[0] = 1` (there's one way to make 0: use no elements).

3. **Transition**: For each power of 2 (2^k), we update the DP array:
   - For each number `j` from 2^k to max_n:
     - `ways[j] += ways[j - 2^k]` (use one more 2^k)
     - If `j >= 2 * 2^k`, add `ways[j - 2 * 2^k]` (use two copies of 2^k)

4. **Time Complexity**: O(n log n) where n is the maximum number we're computing for.

5. **Space Complexity**: O(n) for the DP array.

## Key Insights

- This problem is essentially counting partitions with restricted multiplicities
- Each power of 2 can be used 0, 1, or 2 times
- The DP approach builds up solutions incrementally
- The constraint that each power can be used at most twice makes this different from standard partition problems

The solution correctly handles the mathematical requirement that each power of 2 can be used at most twice in the sum representation.
