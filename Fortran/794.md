# Euler Problem 794 Solution in Fortran

I'll solve Euler Problem 794, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

The problem asks for the number of ways to express a given number N as a sum of powers of 2 (1, 2, 4, 8, 16, ...) where each power can be used at most twice.

This is equivalent to finding the number of representations of N in a "base-2" system where each digit can be 0, 1, or 2 (but not 3 or higher).

## Mathematical Approach

This is a classic dynamic programming problem. We can use the recurrence relation:
- `f(n) = f(n-1) + f(n-2) + f(n-4) + f(n-8) + ...`

program euler794
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j
    integer :: dp(max_n + 1)
    integer :: result
    
    ! Initialize dp array
    dp = 0
    dp(0) = 1  ! One way to make 0 (use nothing)
    
    ! Powers of 2
    do i = 1, 20  ! 2^20 = 1048576, which is larger than max_n
        integer :: power
        power = 2**i
        
        ! For each power, update dp array
        ! We process from high to low to avoid using updated values
        do j = max_n, power, -1
            if (j >= power) then
                dp(j) = dp(j) + dp(j - power)
                if (j >= 2 * power) then
                    dp(j) = dp(j) + dp(j - 2 * power)
                end if
            end if
        end do
    end do
    
    ! Read input and solve
    write(*,*) 'Enter the number N:'
    read(*,*) n
    
    if (n <= max_n) then
        result = dp(n)
        write(*,*) 'Number of ways to write ', n, ' as sum of powers of 2 (each used at most twice):'
        write(*,*) result
    else
        write(*,*) 'Number too large for precomputed solution'
    end if
    
    ! Test with small examples
    write(*,*) 'Testing with small values:'
    do i = 1, 10
        write(*,*) 'n =', i, ':', dp(i)
    end do
    
end program euler794

```fortran
program euler794
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j
    integer :: dp(max_n + 1)
    
    ! Initialize dp array
    dp = 0
    dp(0) = 1
    
    ! Process powers of 2
    i = 1
    do while (i <= max_n)
        ! For each power of 2, we can use 0, 1, or 2 copies
        ! We process from high to low to avoid using updated values
        do j = max_n, i, -1
            if (j >= i) then
                dp(j) = dp(j) + dp(j - i)
            end if
            if (j >= 2 * i) then
                dp(j) = dp(j) + dp(j - 2 * i)
            end if
        end do
        i = i * 2
    end do
    
    ! Read input
    write(*,*) 'Enter the number N:'
    read(*,*) n
    
    if (n <= max_n) then
        write(*,*) 'Number of ways to write ', n, ' as sum of powers of 2 (each used at most twice):'
        write(*,*) dp(n)
    else
        write(*,*) 'Number too large for precomputed solution'
    end if
    
end program euler794
```

This solution uses dynamic programming where:
1. `dp[i]` represents the number of ways to represent number `i`
2. For each power of 2, we update the dp array to account for using 0, 1, or 2 copies of that power
3. We process from high to low to avoid double counting
4. The base case is `dp[0] = 1` (one way to make 0)

The time complexity is O(N log N) where N is the maximum number we're considering, and space complexity is O(N).
