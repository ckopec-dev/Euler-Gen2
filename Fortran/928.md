# Euler Problem 928 Solution in Fortran

I'll solve Euler Problem 928, which asks for the number of integers n ≤ 10^12 such that the sum of squares of the digits of n is a perfect square.

## Problem Analysis

We need to count integers n ≤ 10^12 where the sum of squares of digits of n is a perfect square.

## Fortran Solution

```fortran
program euler928
    implicit none
    integer, parameter :: max_n = 1000000000000
    integer, parameter :: max_digits = 13
    integer :: i, j, k, n, sum_squares, count
    integer :: digit_squares(0:9)
    integer :: max_sum_sq
    logical :: is_perfect_square(1000000)
    integer :: result
    integer :: temp, digit
    
    ! Precompute squares of digits
    do i = 0, 9
        digit_squares(i) = i * i
    end do
    
    ! Precompute which numbers are perfect squares up to max possible sum
    max_sum_sq = 9 * 9 * max_digits  ! Maximum possible sum for 13 digits
    is_perfect_square = .false.
    
    do i = 1, int(sqrt(real(max_sum_sq))) + 1
        is_perfect_square(i*i) = .true.
    end do
    
    ! Count numbers where sum of squares of digits is perfect square
    count = 0
    
    ! For numbers with 1 digit
    do i = 1, 9
        if (is_perfect_square(i*i)) then
            count = count + 1
        end if
    end do
    
    ! For numbers with more digits, use dynamic programming approach
    ! This is a simplified version - the full solution would be more complex
    
    ! For demonstration, let's compute a smaller case
    result = 0
    
    ! Simple brute force for small numbers to verify approach
    do n = 1, 1000000
        sum_squares = 0
        temp = n
        do while (temp > 0)
            digit = mod(temp, 10)
            sum_squares = sum_squares + digit_squares(digit)
            temp = temp / 10
        end do
        
        ! Check if sum_squares is a perfect square
        if (sum_squares > 0) then
            i = int(sqrt(real(sum_squares)))
            if (i * i == sum_squares) then
                result = result + 1
            end if
        end if
    end do
    
    write(*,*) 'Count for n <= 10^6:', result
    
    ! For the full problem, we would need a much more sophisticated approach

end program euler928
```

## Mathematical Approach

The problem requires a more mathematical approach:

1. **Digit DP Approach**: Use dynamic programming with states representing:
   - Current position in the number
   - Sum of squares of digits so far
   - Whether we're still bounded by the original number

2. **Key Insight**: 
   - For a 13-digit number, maximum sum of squares is 13 × 81 = 1053
   - We only need to check sums up to 1053 for perfect squares

## Optimized Solution

```fortran
program euler928_optimized
    implicit none
    integer, parameter :: MAX_DIGITS = 13
    integer, parameter :: MAX_SUM = 1053
    integer :: i, j, k, n, sum_squares, count
    integer :: digit_squares(0:9)
    integer :: perfect_squares(1000)
    integer :: num_perfect_squares
    integer :: dp(MAX_DIGITS, MAX_SUM)
    integer :: result
    
    ! Precompute digit squares
    do i = 0, 9
        digit_squares(i) = i * i
    end do
    
    ! Precompute perfect squares up to MAX_SUM
    num_perfect_squares = 0
    do i = 1, int(sqrt(real(MAX_SUM))) + 1
        if (i * i <= MAX_SUM) then
            num_perfect_squares = num_perfect_squares + 1
            perfect_squares(num_perfect_squares) = i * i
        end if
    end do
    
    ! Initialize DP table
    dp = 0
    
    ! Base case: 0 digits, sum = 0
    dp(0, 0) = 1
    
    ! Fill DP table
    do i = 1, MAX_DIGITS
        do j = 0, MAX_SUM
            do k = 0, 9
                if (j >= digit_squares(k)) then
                    dp(i, j) = dp(i, j) + dp(i-1, j - digit_squares(k))
                end if
            end do
        end do
    end do
    
    ! Count valid numbers
    result = 0
    do i = 1, num_perfect_squares
        if (perfect_squares(i) <= MAX_SUM) then
            result = result + dp(MAX_DIGITS, perfect_squares(i))
        end if
    end do
    
    ! Subtract 1 because we counted 0, but problem asks for n >= 1
    result = result - 1
    
    write(*,*) 'Result:', result
    
end program euler928_optimized
```
