# Euler Problem 443 Solution in Fortran

I'll solve Euler Problem 443, which asks for the number of ways to write a positive integer as a sum of powers of 2, where each power can be used at most twice.

```fortran
program euler443
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j, k
    integer :: ways(max_n + 1)
    integer :: result
    
    ! Initialize the ways array
    do i = 1, max_n
        ways(i) = 0
    end do
    
    ! Base case: 0 can be represented in 1 way (empty sum)
    ways(0) = 1
    
    ! For each power of 2 (2^0, 2^1, 2^2, ...)
    i = 1
    do while (i <= max_n)
        ! For each number from i to max_n
        do j = i, max_n
            ! Add ways to form (j - i) to ways[j]
            ! We can use 2^k at most twice, so we add:
            ! ways[j-i] for using 2^k once
            ! ways[j-2*i] for using 2^k twice (if j >= 2*i)
            if (j >= i) then
                ways(j) = ways(j) + ways(j - i)
            end if
            if (j >= 2*i) then
                ways(j) = ways(j) + ways(j - 2*i)
            end if
        end do
        i = i * 2
    end do
    
    ! Find the first number n where ways(n) > 10^6
    do n = 1, max_n
        if (ways(n) > 1000000) then
            result = n
            exit
        end if
    end do
    
    write(*,*) 'The answer is: ', result
    write(*,*) 'ways(', result, ') = ', ways(result)
    
end program euler443
```

Actually, let me think about this more systematically. The problem asks for the number of ways to write n as a sum of powers of 2, where each power can be used at most twice. This is a classic dynamic programming problem:

```fortran
program euler443
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: n, i, j
    integer :: ways(max_n + 1)
    integer :: result
    
    ! Initialize the ways array
    do i = 0, max_n
        ways(i) = 0
    end do
    
    ! Base case: 0 can be represented in 1 way (empty sum)
    ways(0) = 1
    
    ! For each power of 2 (2^0, 2^1, 2^2, ...)
    i = 1
    do while (i <= max_n)
        ! Process from i to max_n to avoid double counting
        do j = i, max_n
            ! We can use this power 0, 1, or 2 times
            ! So we add: ways[j-i] + ways[j-2*i] (if j >= 2*i)
            ways(j) = ways(j) + ways(j - i)
            if (j >= 2*i) then
                ways(j) = ways(j) + ways(j - 2*i)
            end if
        end do
        i = i * 2
    end do
    
    ! Find the first number n where ways(n) > 10^6
    do n = 1, max_n
        if (ways(n) > 1000000) then
            result = n
            exit
        end if
    end do
    
    write(*,*) 'The answer is: ', result
    write(*,*) 'ways(', result, ') = ', ways(result)
    
end program euler443
```
