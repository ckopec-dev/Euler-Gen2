    do i = 1, max_n

```fortran
program euler546
    implicit none
    integer, parameter :: max_n = 1000000
    integer :: ways(max_n + 1)
    integer :: i, j, power
    integer :: result
    
    ! Initialize all ways to 0
    do i = 0, max_n
        ways(i) = 0
    end do
    
    ! Base case: there's 1 way to make 0 (use nothing)
    ways(0) = 1
    
    ! For each power of 2 (1, 2, 4, 8, 16, ...)
    power = 1
    do while (power <= max_n)
        ! For each number from power to max_n
        do i = power, max_n
            ! Add the number of ways to make (i - power) 
            ! (which means we use one more of this power)
            ways(i) = ways(i) + ways(i - power)
            
            ! If we can use this power twice, add ways to make (i - 2*power)
            if (i >= 2*power) then
                ways(i) = ways(i) + ways(i - 2*power)
            end if
        end do
        
        ! Move to next power of 2
        power = power * 2
    end do
    
    ! The answer for n = 1000000
    result = ways(1000000)
    write(*,*) 'Euler Problem 546 Answer:', result
    
end program euler546
```

This Fortran program solves Euler Problem 546 by using dynamic programming to count the number of ways to represent integers as sums of powers of 2 where each power can be used at most twice. The algorithm works by:

1. Initializing a DP array where `ways[i]` represents the number of ways to make sum `i`
2. For each power of 2 (1, 2, 4, 8, ...), updating the DP array
3. For each sum `i`, we can either:
   - Use the current power once: add `ways[i-power]` 
   - Use the current power twice: add `ways[i-2*power]`
4. The final answer is `ways(1000000)`
