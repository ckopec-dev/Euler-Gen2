# Euler Problem 879 Solution in Fortran

I'll solve Euler Problem 879, which asks for the number of ways to write a positive integer n as a sum of positive integers, where each integer in the sum is at least 2 and at most 10, and the order of terms matters.

This is a dynamic programming problem where we need to count the number of compositions of n using parts from {2,3,4,5,6,7,8,9,10}.

```fortran
program euler879
    implicit none
    integer, parameter :: MAX_N = 1000
    integer :: n, i, j
    integer :: dp(MAX_N + 1)
    integer :: result
    
    ! Initialize dp array
    do i = 0, MAX_N
        dp(i) = 0
    end do
    
    ! Base case: there's one way to make 0 (empty sum)
    dp(0) = 1
    
    ! Available parts: 2, 3, 4, 5, 6, 7, 8, 9, 10
    do i = 2, 10
        do j = i, MAX_N
            dp(j) = dp(j) + dp(j - i)
        end do
    end do
    
    ! Read input n and calculate result
    write(*,*) 'Enter the value of n:'
    read(*,*) n
    
    if (n < 0 .or. n > MAX_N) then
        write(*,*) 'Invalid input. n must be between 0 and', MAX_N
        stop
    end if
    
    result = dp(n)
    
    write(*,*) 'Number of ways to write', n, 'as sum of integers from 2 to 10:'
    write(*,*) result
    
    ! For verification, also calculate for small values
    write(*,*) 'Verification for small values:'
    do i = 0, 10
        write(*,*) 'n =', i, ':', dp(i), 'ways'
    end do
    
end program euler879
```

## Explanation of the Solution

This Fortran program solves Euler Problem 879 using dynamic programming:

1. **Problem Understanding**: We need to count the number of ordered compositions of a positive integer n using parts from {2,3,4,5,6,7,8,9,10}.

2. **Dynamic Programming Approach**:
   - Create a dp array where dp[i] represents the number of ways to write integer i as such a sum
   - Initialize dp[0] = 1 (one way to make 0: empty sum)
   - For each possible part size (2 through 10), update the dp array by adding dp[j-i] to dp[j] for all valid j

3. **Algorithm Steps**:
   - Initialize dp array with zeros
   - Set dp[0] = 1 as base case
   - For each part size from 2 to 10:
     - For each possible sum from that part size to n:
       - Add dp[j-part] to dp[j]
   - Return dp[n] as the answer

4. **Time Complexity**: O(n × 9) = O(n)
5. **Space Complexity**: O(n)

The solution handles input validation and provides verification for small cases to ensure correctness. For the actual Euler problem, you would typically run this with the specific value of n given in the problem statement.
