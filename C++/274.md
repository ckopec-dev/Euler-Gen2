# Euler Problem 274 Solution in C++

## Problem Statement
Find the sum of all primes p < 1000000 such that for some integer k, we have p = k! + 1 and k! ≡ -1 (mod p).

## Solution

#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

// Function to check if a number is prime
bool isPrime(long long n) {
    if (n <= 1) return false;
    if (n <= 3) return true;
    if (n % 2 == 0 || n % 3 == 0) return false;
    
    for (long long i = 5; i * i <= n; i += 6) {
        if (n % i == 0 || n % (i + 2) == 0) {
            return false;
        }
    }
    return true;
}

// Function to compute factorial modulo n
long long modFact(long long n, long long mod) {
    long long result = 1;
    for (long long i = 1; i <= n; i++) {
        result = (result * i) % mod;
    }
    return result;
}

// Function to check if k! ≡ -1 (mod p) for prime p
bool checkCondition(long long p) {
    // We need to find k such that k! + 1 = p and k! ≡ -1 (mod p)
    // This means k! ≡ p-1 (mod p) or k! ≡ -1 (mod p)
    
    // For small primes, we can directly check
    for (long long k = 1; k < p; k++) {
        long long fact = 1;
        for (long long i = 1; i <= k; i++) {
            fact = (fact * i) % p;
        }
        if (fact == p - 1) {  // fact ≡ -1 (mod p)
            // Check if k! + 1 = p
            long long temp = 1;
            for (long long i = 1; i <= k; i++) {
                temp = (temp * i) % p;
            }
            if ((temp + 1) % p == 0) {
                return true;
            }
        }
    }
    return false;
}

    for (long long p : primes) {
        // Check if p can be expressed as k! + 1 for some k
        // This means k! = p - 1
        
        // We know that if p is prime and k! ≡ -1 (mod p), then p is a Wilson prime
        // But we need to be more careful here
        
        bool found = false;
        long long k = 1;
        
        // Try small values of k
        long long fact = 1;
        while (fact < p && k < 100) {  // Reasonable upper bound
            if (fact == p - 1) {
                found = true;
                break;
            }
            k++;
            fact *= k;
        }
        
        if (found) {
            // Verify that k! ≡ -1 (mod p)
            long long verification = 1;
            for (long long i = 1; i <= k; i++) {
                verification = (verification * i) % p;
            }
            if (verification == p - 1) {
                sum += p;
            }
        }
    }
    
    return sum;
}

## Explanation

This solution addresses Euler Problem 274 by:

1. **Understanding the problem**: We need to find primes p < 1,000,000 such that there exists an integer k where p = k! + 1 and k! ≡ -1 (mod p).

2. **Key insights**: 
   - If p is prime and k! ≡ -1 (mod p), then by Wilson's theorem, (p-1)! ≡ -1 (mod p)
   - We're looking for primes of the form k! + 1
   - For such primes, we need to verify the congruence condition

3. **Approach**:
   - Generate all primes up to 1,000,000 using sieve of Eratosthenes
   - For each prime p, check if it can be written as k! + 1 for some k
   - Verify that k! ≡ -1 (mod p) for that k

4. **Optimization**: 
   - Limit k to reasonable values (k < 100) since factorials grow very quickly
   - Use modular arithmetic to avoid overflow issues

The solution efficiently identifies primes that satisfy the given conditions and returns their sum.
