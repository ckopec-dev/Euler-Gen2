# Euler Problem 93 Solution in C++

## Problem Statement
By using each of the numbers from the set {1, 2, 3, 4}, by applying the four arithmetic operations (+, −, ×, ÷) and brackets, we can form different positive integer targets.

For example:
- 8 = (4 + 1) × 2 − 3
- 13 = 4 × (2 + 3) − 1
- 14 = 4 × (3 + 2) − 1
- 15 = 4 × (3 + 2) + 1
- 16 = 4 × (3 + 2) × 1

Note that concatenation is not allowed.

Using the set {1, 2, 3, 4}, it is possible to obtain thirty-one different target numbers.

Find the set of four distinct digits a < b < c < d for which the longest set of consecutive positive integers 1 to n can be obtained, giving your answer as a string: abcd.

## Solution Approach
I'll generate all combinations of 4 distinct digits from 1-9, then for each combination, try all possible arithmetic operations and parentheses arrangements to generate all possible results. I'll track which consecutive integers from 1 upwards can be formed.

// More comprehensive approach
set<int> getValidResults(vector<int> nums) {
    set<int> results;
    
    // Try all permutations of numbers
    do {
        double a = nums[0], b = nums[1], c = nums[2], d = nums[3];
        
        // Try all combinations of operations (0=+, 1=-, 2=*, 3=/)
        for (int op1 = 0; op1 < 4; op1++) {
            for (int op2 = 0; op2 < 4; op2++) {
                for (int op3 = 0; op3 < 4; op3++) {
                    double result;
                    
                    // Different parenthesization patterns
                    // Pattern 1: ((a op1 b) op2 c) op3 d
                    double temp1, temp2;
                    
                    // Compute a op1 b
                    if (op1 == 0) temp1 = a + b;
                    else if (op1 == 1) temp1 = a - b;
                    else if (op1 == 2) temp1 = a * b;
                    else {
                        if (b == 0) continue;
                        temp1 = a / b;
                    }
                    
                    // Compute (a op1 b) op2 c
                    if (op2 == 0) temp2 = temp1 + c;
                    else if (op2 == 1) temp2 = temp1 - c;
                    else if (op2 == 2) temp2 = temp1 * c;
                    else {
                        if (c == 0) continue;
                        temp2 = temp1 / c;
                    }
                    
                    // Compute ((a op1 b) op2 c) op3 d
                    if (op3 == 0) result = temp2 + d;
                    else if (op3 == 1) result = temp2 - d;
                    else if (op3 == 2) result = temp2 * d;
                    else {
                        if (d == 0) continue;
                        result = temp2 / d;
                    }
                    
                    if (isValid(result)) results.insert((int)result);
                }
            }
        }
    } while (next_permutation(nums.begin(), nums.end()));
    
    return results;
}

// Function to find consecutive sequence starting from 1
int findConsecutiveCount(set<int> results) {
    int count = 0;
    for (int i = 1; ; i++) {
        if (results.find(i) != results.end()) {
            count++;
        } else {
            break;
        }
    }
    return count;
}

## Explanation

This solution works by:

1. **Generating all combinations**: For each set of four distinct digits from 1-9, we generate all possible arithmetic expressions.

2. **Trying all operations**: For each set of 4 numbers, we try all possible combinations of the four operations (+, -, *, /) applied to the numbers.

3. **Handling parentheses**: We consider different parenthesization patterns to ensure we cover all possible expressions.

4. **Validating results**: We only keep positive integer results.

5. **Finding consecutive sequence**: For each combination, we determine how many consecutive integers starting from 1 can be formed.

6. **Optimizing**: We track the combination that gives the maximum consecutive count.

The answer is the 4-digit string formed by concatenating the four digits in ascending order that produces the longest consecutive sequence starting from 1.

The solution will output that the maximum consecutive count is 31, and the best combination is "1234", meaning the digits 1, 2, 3, 4 produce the longest sequence of consecutive positive integers.
