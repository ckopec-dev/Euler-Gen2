# Euler Problem 536 Solution in C++

## Problem Statement
Euler Problem 536 asks us to find the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Solution Approach
We'll use dynamic programming with memoization to count the number of ways to represent a number as a sum of powers of 2, with each power used at most twice.

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <algorithm>

using namespace std;

class Solution {
private:
    map<pair<long long, int>, long long> memo;
    
    // Recursive function to count ways to represent n using powers of 2
    // up to 2^power, where each power can be used at most twice
    long long countWays(long long n, int power) {
        // Base cases
        if (n == 0) return 1;
        if (n < 0 || power < 0) return 0;
        
        // Check memoization
        if (memo.find({n, power}) != memo.end()) {
            return memo[{n, power}];
        }
        
        long long result = 0;
        long long powerOf2 = 1LL << power;  // 2^power
        
        // Try using 0, 1, or 2 of the current power of 2
        for (int count = 0; count <= 2 && count * powerOf2 <= n; count++) {
            result += countWays(n - count * powerOf2, power - 1);
        }
        
        memo[{n, power}] = result;
        return result;
    }
    
public:
    long long solve(long long n) {
        // Find the highest power of 2 needed
        int maxPower = 0;
        while ((1LL << maxPower) <= n) {
            maxPower++;
        }
        maxPower--;
        
        return countWays(n, maxPower);
    }
};

int main() {
    Solution sol;
    
    // Test with small values to verify correctness
    cout << "Ways to represent 1: " << sol.solve(1) << endl;   // Expected: 1
    cout << "Ways to represent 2: " << sol.solve(2) << endl;   // Expected: 2
    cout << "Ways to represent 3: " << sol.solve(3) << endl;   // Expected: 2
    cout << "Ways to represent 4: " << sol.solve(4) << endl;   // Expected: 3
    
    // For the actual problem, we need to find the answer for a specific value
    // Based on the problem description, we're looking for the answer to Euler 536
    long long result = sol.solve(1000000000000LL);  // 10^12
    cout << "Answer: " << result << endl;
    
    return 0;
}
```

## Explanation

The solution works as follows:

1. **Recursive Approach**: We use a recursive function `countWays(n, power)` that counts the number of ways to represent `n` using powers of 2 up to `2^power`, with each power used at most twice.

2. **Memoization**: To avoid recomputing the same subproblems, we use a map to store previously computed results.

3. **Base Cases**:
   - If `n = 0`, there's exactly one way (use nothing)
   - If `n < 0` or `power < 0`, there are zero ways

4. **Recurrence Relation**: For each power of 2, we try using 0, 1, or 2 copies of that power and recursively solve for the remaining amount.

5. **Optimization**: We determine the maximum power needed upfront to avoid unnecessary computations.

## Time and Space Complexity

- **Time Complexity**: O(n × log n) where n is the input number
- **Space Complexity**: O(log n) for the memoization table and recursion stack

## Key Insights

The problem is essentially counting the number of partitions of n into powers of 2 where each part appears at most twice. This is a classic dynamic programming problem with a twist - the constraint that each power can be used at most twice makes it more interesting than the standard coin change problem.

The solution efficiently handles large numbers by using memoization and avoiding redundant calculations.
