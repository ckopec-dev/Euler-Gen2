# Euler Problem 676 Solution in C++

I'll solve Euler Problem 676, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most 3 times.

## Problem Understanding

We need to find the number of ways to write a number N as a sum of powers of 2 (1, 2, 4, 8, 16, ...) where each power can be used at most 3 times.

This is a dynamic programming problem where we need to count the number of representations of N using powers of 2 with coefficients 0, 1, 2, or 3.

## Solution Approach

I'll use dynamic programming with the recurrence relation:
- `dp[i][j]` = number of ways to represent number `i` using powers of 2 up to `2^j`
- For each power of 2, we can use 0, 1, 2, or 3 copies
- We build up the solution incrementally

## C++ Implementation

```cpp
#include <iostream>
#include <vector>
#include <cstring>

using namespace std;

const int MAX_N = 1000000;
const int MAX_POW = 20; // 2^20 > 10^6

long long dp[MAX_N + 1][MAX_POW + 1];

long long solve(int n) {
    // Initialize dp array
    memset(dp, 0, sizeof(dp));
    
    // Base case: 0 can be represented in 1 way (using no elements)
    dp[0][0] = 1;
    
    // For each power of 2
    for (int j = 0; j <= MAX_POW; j++) {
        long long power = 1LL << j; // 2^j
        
        // For each number from 0 to n
        for (int i = 0; i <= n; i++) {
            // If we can use this power, add the ways from previous state
            if (i >= power) {
                dp[i][j] += dp[i - power][j];
            }
            // If we can use 2 copies of this power
            if (i >= 2 * power) {
                dp[i][j] += dp[i - 2 * power][j];
            }
            // If we can use 3 copies of this power
            if (i >= 3 * power) {
                dp[i][j] += dp[i - 3 * power][j];
            }
            
            // If we can use this power in the next position
            if (j > 0) {
                dp[i][j] += dp[i][j - 1];
            }
        }
    }
    
    return dp[n][MAX_POW];
}

// Better approach: Use the recurrence properly
long long count_ways(int n) {
    vector<vector<long long>> dp(n + 1, vector<long long>(21, 0));
    
    // Base case
    dp[0][0] = 1;
    
    // For each power of 2 (0 to 20)
    for (int j = 0; j < 20; j++) {
        long long power = 1LL << j;
        
        // For each number from 0 to n
        for (int i = 0; i <= n; i++) {
            // We can use 0, 1, 2, or 3 copies of 2^j
            for (int k = 0; k <= 3 && i >= k * power; k++) {
                dp[i][j + 1] += dp[i - k * power][j];
            }
        }
    }
    
    return dp[n][20];
}

// Even better approach - correct DP
long long solve_correct(int n) {
    vector<long long> dp(n + 1, 0);
    dp[0] = 1;
    
    // For each power of 2
    for (int j = 0; j < 20; j++) {
        long long power = 1LL << j;
        
        // Process from right to left to avoid using updated values
        for (int i = n; i >= 0; i--) {
            // We can use 0, 1, 2, or 3 copies of power
            for (int k = 1; k <= 3 && i >= k * power; k++) {
                dp[i] += dp[i - k * power];
            }
        }
    }
    
    return dp[n];
}

int main() {
    int n = 1000000;
    long long result = solve_correct(n);
    cout << "Number of ways to represent " << n << " as sum of powers of 2 (each used at most 3 times): " 
         << result << endl;
    
    // For verification with smaller cases
    cout << "Verification for small cases:" << endl;
    cout << "N=1: " << solve_correct(1) << endl;   // Should be 1 (1)
    cout << "N=2: " << solve_correct(2) << endl;   // Should be 2 (1+1, 2)
    cout << "N=3: " << solve_correct(3) << endl;   // Should be 3 (1+1+1, 1+2, 3)
    cout << "N=4: " << solve_correct(4) << endl;   // Should be 4 (1+1+1+1, 1+1+2, 2+2, 4)
    
    return 0;
}
```

## Key Insights

1. **Dynamic Programming State**: `dp[i]` represents the number of ways to form sum `i`
2. **Transition**: For each power of 2, we can use 0, 1, 2, or 3 copies
3. **Optimization**: We process powers sequentially and update the dp array accordingly
4. **Efficiency**: Time complexity O(n × log n), space complexity O(n)

## Final Answer

The solution computes the number of ways to write 1,000,000 as a sum of powers of 2 where each power can be used at most 3 times. The answer is the value returned by `solve_correct(1000000)`.

The approach uses a clean DP formulation where we iterate through powers of 2 and for each power, we consider all possible numbers of times it can be used (0, 1, 2, or 3) and update our DP states accordingly.
