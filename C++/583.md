# Euler Problem 583 Solution in C++

## Problem Statement
Let's first understand what Euler Problem 583 asks for:

We need to find the sum of all distinct values of `f(n)` where `f(n)` is the number of ways to write `n` as a sum of positive integers, where each summand is at least 2, and the order of summands matters.

## Mathematical Analysis

This is essentially finding the number of compositions of `n` into parts ≥ 2. This is equivalent to finding the number of ways to write `n` as:
n = a₁ + a₂ + ... + aₖ
where each aᵢ ≥ 2.

This is a classic problem that can be solved using dynamic programming or generating functions.

## Explanation

This solution works as follows:

1. **Dynamic Programming Approach**: We use a DP array where `dp[i]` represents the number of ways to write `i` as a sum of integers where each integer is at least 2.

2. **Base Case**: `dp[0] = 1` (one way to make 0: the empty sum).

3. **Transition**: For each possible part size `part` starting from 2, we update all positions `i` where `i ≥ part` by adding `dp[i - part]` to `dp[i]`.

4. **Distinct Values**: We collect all non-zero values in a set to ensure uniqueness.

5. **Final Sum**: We sum all the distinct values.
