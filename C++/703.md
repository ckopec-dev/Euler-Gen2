## Problem Statement
The problem asks us to find the sum of all positive integers n ≤ 10^17 such that φ(n) = φ(n+1) = φ(n+2), where φ is Euler's totient function.

long long phi(long long n) {
    long long result = n;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {

                n /= i;
            }
            result -= result / i;
        }

    }

}
