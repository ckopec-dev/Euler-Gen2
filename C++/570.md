# Euler Problem 570 Solution in C++

## Problem Statement
Euler Problem 570 asks us to find the number of ways to tile a 3×n rectangle with 2×1 dominoes, where the dominoes can be placed either horizontally or vertically.

## Approach
This is a classic dynamic programming problem. We need to find a recurrence relation for tiling a 3×n rectangle.

Let's define:
- `dp[i]` = number of ways to tile a 3×i rectangle
- For a 3×n rectangle, we can either:
  1. Place a vertical domino in the first column (leaving a 3×(n-1) rectangle)
  2. Place two horizontal dominoes in the first two rows (leaving a 3×(n-2) rectangle)
  3. Place two horizontal dominoes in the last two rows (leaving a 3×(n-2) rectangle)

#include <iostream>
#include <vector>

using namespace std;

long long solve(int n) {
    if (n == 0) return 1;
    if (n == 1) return 1;
    if (n == 2) return 3;
    
    vector<long long> dp(n + 1, 0);
    dp[0] = 1;
    dp[1] = 1;
    dp[2] = 3;
    
    // For 3×n rectangle with 2×1 dominoes, the recurrence is:
    // f(n) = f(n-1) + 3*f(n-2) + 2*f(n-3)
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + 3 * dp[i-2] + 2 * dp[i-3];
    }
    
    return dp[n];
}

int main() {
    cout << "Result for n=12: " << solve(12) << endl;

## Explanation

The solution uses dynamic programming to count the number of ways to tile a 3×n rectangle using 2×1 dominoes.

### Key Insights:
1. **Base Cases**: 
   - f(0) = 1 (empty rectangle has one way - do nothing)
   - f(1) = 1 (3×1 rectangle can only be filled with 3 vertical dominoes)
   - f(2) = 3 (3×2 rectangle can be filled in 3 ways)

2. **Recurrence Relation**: 
   - f(n) = f(n-1) + 3×f(n-2) + 2×f(n-3)
   - This accounts for all possible configurations when filling the last few columns

3. **Time Complexity**: O(n) 
4. **Space Complexity**: O(n)

The recurrence relation comes from analyzing all possible ways to fill the last few columns of the rectangle, considering both horizontal and vertical domino placements.
