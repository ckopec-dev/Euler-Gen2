# Euler Problem 720 Solution in C++

## Problem Statement
The problem asks us to find the number of ways to write a positive integer n as a sum of positive integers, where the order matters and we only consider sums with at least 2 terms.

## Approach
This is a classic dynamic programming problem. We need to count the number of compositions (ordered partitions) of n with at least 2 parts.

Let's define:
- `dp[i]` = number of ways to write integer i as a sum of positive integers (including 1 term)
- For compositions with at least 2 terms, we subtract 1 (the case with only 1 term)

## Solution

```cpp
#include <iostream>
#include <vector>
using namespace std;

const long long MOD = 1000000007;

long long solve(int n) {
    // dp[i] represents number of compositions of i (including 1 term)
    vector<long long> dp(n + 1, 0);
    
    // Base case: 0 has 1 composition (empty sum)
    dp[0] = 1;
    
    // For each number from 1 to n
    for (int i = 1; i <= n; i++) {
        // For each possible first term (1 to i)
        for (int j = 1; j <= i; j++) {
            dp[i] = (dp[i] + dp[i - j]) % MOD;
        }
    }
    
    // Subtract 1 to exclude the composition with only 1 term
    // But we need to be careful about the base case
    if (n == 0) return 0;
    return (dp[n] - 1 + MOD) % MOD;
}

int main() {
    int n = 1000000;  // For the actual problem
    cout << "Answer for n = " << n << ": " << solve(n) << endl;
    return 0;
}
```

## Mathematical Insight

The number of compositions of n into positive integers is 2^(n-1). This is because we can think of placing n ones in a row and deciding where to place dividers between them. There are n-1 possible positions for dividers, and each position can either have a divider or not, giving 2^(n-1) possibilities.

However, since we want compositions with at least 2 terms, we subtract 1 (the case where there's only one term). So the answer is 2^(n-1) - 1.

But since we're dealing with large numbers, we need to be careful with modular arithmetic:

```cpp
#include <iostream>
#include <vector>
using namespace std;

const long long MOD = 1000000007;

long long modPow(long long base, long long exp, long long mod) {
    long long result = 1;
    base = base % mod;
    while (exp > 0) {
        if (exp % 2 == 1) {
            result = (result * base) % mod;
        }
        exp = exp >> 1;
        base = (base * base) % mod;
    }
    return result;
}

long long solve(int n) {
    if (n == 0) return 0;
    // Number of compositions of n with at least 2 terms
    // = 2^(n-1) - 1
    long long result = modPow(2, n - 1, MOD);
    return (result - 1 + MOD) % MOD;
}

int main() {
    int n = 1000000;
```

2. **Mathematical Insight**: 
   - The total number of compositions of n is 2^(n-1)
   - This includes the composition with just one part (n itself)
   - So compositions with at least 2 parts = 2^(n-1) - 1

   - Use modular exponentiation to compute 2^(n-1) mod 1000000007

4. **Time Complexity**: O(log n) due to modular exponentiation
