# Euler Problem 113 Solution in C++

## Problem Statement
Working from left-to-right if no digit is exceeded by the digit to its left it is called an increasing number; for example, 13679.
Similarly if no digit is exceeded by the digit to its right it is called a decreasing number; for example, 98430.
We shall call a positive integer that is neither increasing nor decreasing a "bouncy" number; for example, 155349.
As n increases, the proportion of bouncy numbers below n increases such that there are only 12951 numbers below one-million that are not bouncy.
Find the number of non-bouncy numbers below one trillion (10^12).

## Solution Approach
This problem can be solved using dynamic programming. We need to count:
1. Increasing numbers (digits never decrease)
2. Decreasing numbers (digits never increase)
3. Numbers that are both increasing and decreasing (i.e., all digits same)

The key insight is that we can use digit DP (Dynamic Programming) to count these numbers efficiently.

// More accurate approach using DP
long long countNonBouncy(int maxDigits) {
    // dp[i][j][0] = count of increasing numbers with i digits, ending with digit j
    // dp[i][j][1] = count of decreasing numbers with i digits, ending with digit j
    
    vector<vector<vector<long long>>> dp(maxDigits + 1, 
                                         vector<vector<long long>>(10, vector<long long>(2, 0)));
    
    // Base case: 1-digit numbers
    for (int j = 1; j <= 9; j++) {
        dp[1][j][0] = 1; // increasing
        dp[1][j][1] = 1; // decreasing
    }
    
    // Fill DP table
    for (int i = 2; i <= maxDigits; i++) {
        // For increasing numbers
        for (int j = 1; j <= 9; j++) {
            for (int k = 1; k <= j; k++) {
                dp[i][j][0] += dp[i-1][k][0];
            }
        }
        
        // For decreasing numbers
        for (int j = 0; j <= 9; j++) {
            for (int k = j; k <= 9; k++) {
                dp[i][j][1] += dp[i-1][k][1];
            }
        }
    }
    
    // Count total non-bouncy numbers
    long long result = 0;
    for (int i = 1; i <= maxDigits; i++) {
        for (int j = 0; j <= 9; j++) {
            result += dp[i][j][0] + dp[i][j][1];
        }
    }
    
    // Subtract double-counted numbers (numbers with all same digits)
    // These are counted in both increasing and decreasing
    result -= 9 * maxDigits; // 1-digit to maxDigits, each digit 1-9 appears once
    
    return result;
}

// Mathematical approach - more efficient
long long combination(int n, int r) {
    if (r > n || r < 0) return 0;
    if (r == 0 || r == n) return 1;
    
    long long result = 1;
    for (int i = 0; i < r; i++) {
        result = result * (n - i) / (i + 1);
    }
    return result;
}

    // These are counted in both increasing and decreasing

    return total;
}
