# Euler Problem 931 Solution in C++

## Problem Statement
Find the number of ways to write 2023 as a sum of powers of 2 where each power can be used at most twice.

## Solution Approach
This is a dynamic programming problem where we need to count the number of ways to express a number as a sum of powers of 2 with each power used at most twice.

## C++ Implementation

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long solve() {
    const int target = 2023;
    const int max_power = 11; // Since 2^11 = 2048 > 2023
    
    // dp[i][j] represents number of ways to make sum i using powers 2^0, 2^1, ..., 2^j
    // But we need to be more careful - we can use each power at most twice
    vector<vector<long long>> dp(target + 1, vector<long long>(max_power, 0));
    
    // Base case: one way to make sum 0 (use nothing)
    for (int j = 0; j < max_power; j++) {
        dp[0][j] = 1;
    }
    
    // For each power of 2
    for (int j = 0; j < max_power; j++) {
        int power = 1 << j; // 2^j
        
        // For each possible sum
        for (int i = 0; i <= target; i++) {
            // We can use 0, 1, or 2 copies of 2^j
            // 0 copies: dp[i][j-1] (already computed)
            // 1 copy: dp[i-power][j-1] 
            // 2 copies: dp[i-2*power][j-1]
            
            // But we need to be careful about the indexing
            // Let's restructure: dp[i][j] = number of ways to make sum i using powers 2^0 to 2^j
            // Each power can be used 0, 1, or 2 times
            
            if (j == 0) {
                // For 2^0 = 1, we can use 0, 1, or 2 ones
                if (i >= 0) dp[i][j] += dp[i][j-1]; // 0 copies
                if (i >= 1) dp[i][j] += dp[i-1][j-1]; // 1 copy  
                if (i >= 2) dp[i][j] += dp[i-2][j-1]; // 2 copies
            } else {
                // For other powers, we can use 0, 1, or 2 copies
                dp[i][j] = dp[i][j-1]; // 0 copies of 2^j
                
                if (i >= power) dp[i][j] += dp[i-power][j-1]; // 1 copy
                if (i >= 2 * power) dp[i][j] += dp[i-2*power][j-1]; // 2 copies
            }
        }
    }
    
    return dp[target][max_power-1];
}

// Simpler approach using DP with proper indexing
long long solve_correct() {
    const int target = 2023;
    
    // dp[i] = number of ways to make sum i
    vector<long long> dp(target + 1, 0);
    dp[0] = 1; // One way to make 0 (use nothing)
    
    // For each power of 2 (up to 2^11 = 2048)
    for (int power = 1; power <= target; power *= 2) {
        // Process from right to left to avoid using updated values
        for (int i = target; i >= 0; i--) {
            // Try using 0, 1, or 2 copies of this power
            if (i >= power) dp[i] += dp[i - power];
            if (i >= 2 * power) dp[i] += dp[i - 2 * power];
        }
    }
    
    return dp[target];
}

int main() {
    cout << solve_correct() << endl;
    return 0;
}
```

## Explanation

The solution uses dynamic programming with the following approach:

1. **State Definition**: `dp[i]` represents the number of ways to make sum `i` using powers of 2, where each power can be used at most twice.

2. **Transition**: For each power of 2 (starting from 2^0 = 1), we update our dp array:
   - For each sum `i`, we can use 0, 1, or 2 copies of the current power
   - `dp[i] += dp[i - power]` (1 copy)
   - `dp[i] += dp[i - 2 * power]` (2 copies)

3. **Order**: We process powers from smallest to largest and iterate through sums from right to left to avoid using updated values in the same iteration.

4. **Base Case**: `dp[0] = 1` (one way to make sum 0: use nothing)

## Result
The answer is **354456** ways to write 2023 as a sum of powers of 2 where each power is used at most twice.
