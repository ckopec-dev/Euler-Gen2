# Euler Problem 88 Solution in C++

## Problem Statement
A natural number N is called a "minimal product-sum number" if there exists a minimal set of integers that multiply to N and sum to N. For example, 12 = 2 × 2 × 3 and 2 + 2 + 3 = 7, so 12 is not a minimal product-sum number. However, 6 = 2 × 3 and 2 + 3 = 5, so 6 is not a minimal product-sum number either. The minimal product-sum number for k = 2 is 4 = 2 × 2 and 2 + 2 = 4.

## Solution Approach
We'll use a recursive approach to find all possible factorizations of numbers and check if they form product-sum numbers. For each k (number of factors), we'll find the minimal product-sum number.

// Recursive function to find product-sum numbers
void findProductSum(int product, int sum, int count, int start, int k) {
    // If we've reached k factors
    if (count == k) {
        // Check if product equals sum (product-sum condition)
        if (product == sum) {
            if (product <= MAX_K) {
                min_product_sum[k] = min(min_product_sum[k], (long long)product);
            }
        }
        return;
    }
    
    // Optimization: if current product is already larger than k, no point continuing
    if (product > k) return;
    
    // Try all possible factors starting from 'start'
    for (int i = start; i <= k; i++) {
        if (product * i > k) break; // Pruning
        findProductSum(product * i, sum + i, count + 1, i, k);
    }
}

## Explanation

The solution works by:

1. **Defining the problem**: For each number of factors k, we want to find the minimal N such that there exists a set of k integers whose product equals N and whose sum equals N.

2. **Recursive approach**: We use backtracking to generate all possible combinations of factors:
   - Start with product=1, sum=0, count=0
   - For each step, try adding a new factor
   - Stop when we have exactly k factors
   - Check if product equals sum (product-sum condition)

3. **Optimization**: 
   - Pruning: If product > k, no point continuing
   - Start factor from previous factor to avoid duplicates
   - Early termination when product exceeds k

4. **Result processing**: Collect all minimal values for each k and sum the unique ones.
