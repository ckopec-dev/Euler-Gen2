    vector<long long> dp(n + 1, 0);

This solution uses dynamic programming where:
1. `dp[i]` represents the number of ways to partition integer `i` into distinct parts
2. For each new part `part`, we update the DP array from right to left to avoid using updated values
3. The time complexity is O(n²) and space complexity is O(n)
4. The result is taken modulo 10^9 + 7 as required
