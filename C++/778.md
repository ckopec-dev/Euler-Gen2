# Euler Problem 778 Solution in C++

## Problem Statement
Find the number of ways to write 10^10 as a sum of powers of 2, where each power can be used at most 3 times.

## Solution Approach
This is a dynamic programming problem where we need to count the number of ways to express a number as a sum of powers of 2 with each power used at most 3 times.

## C++ Implementation

```cpp
#include <iostream>
#include <vector>
#include <cstring>

using namespace std;

long long solve(long long n) {
    // Precompute powers of 2 up to a reasonable limit
    vector<long long> powers;
    long long power = 1;
    while (power <= n) {
        powers.push_back(power);
        power *= 2;
    }
    
    // dp[i][j] = number of ways to make sum i using first j powers
    // We use a 1D array for optimization
    vector<long long> dp(n + 1, 0);
    dp[0] = 1; // One way to make 0 (use nothing)
    
    // For each power of 2
    for (long long p : powers) {
        // We can use this power 0, 1, 2, or 3 times
        // Process from right to left to avoid counting the same power multiple times
        for (int i = n; i >= 0; i--) {
            // Try using 1, 2, or 3 copies of this power
            if (i >= p) dp[i] += dp[i - p];
            if (i >= 2 * p) dp[i] += dp[i - 2 * p];
            if (i >= 3 * p) dp[i] += dp[i - 3 * p];
        }
    }
    
    return dp[n];
}

int main() {
    long long n = 10000000000LL; // 10^10
    cout << "Number of ways to write " << n << " as sum of powers of 2 (each used at most 3 times): " << solve(n) << endl;
    return 0;
}
```

## Alternative Optimized Solution

```cpp
#include <iostream>
#include <vector>

using namespace std;

const long long MOD = 1000000007;

long long countWays(long long target) {
    // dp[i] represents number of ways to make sum i
    vector<long long> dp(target + 1, 0);
    dp[0] = 1;
    
    // For each power of 2 (2^k)
    for (long long power = 1; power <= target; power *= 2) {
        // Process from right to left to avoid using updated values
        for (long long i = target; i >= 0; i--) {
            // Use 0, 1, 2, or 3 copies of this power
            for (int count = 1; count <= 3 && i >= count * power; count++) {
                dp[i] = (dp[i] + dp[i - count * power]) % MOD;
            }
        }
    }
    
    return dp[target];
}

int main() {
    long long n = 10000000000LL; // 10^10
    cout << "Answer: " << countWays(n) << endl;
    return 0;
}
```

## Explanation

The solution uses dynamic programming with the following approach:

1. **Precompute powers of 2**: Generate all powers of 2 that are ≤ 10^10
2. **DP State**: `dp[i]` = number of ways to make sum `i`
3. **Transition**: For each power of 2, we can use it 0, 1, 2, or 3 times
4. **Optimization**: Process from right to left to avoid counting the same power multiple times

## Time and Space Complexity
- **Time Complexity**: O(n × log n) where n = 10^10
- **Space Complexity**: O(n)

## Key Insights
- Each power of 2 can be used at most 3 times
- We process powers in increasing order to ensure we don't overcount
- The right-to-left processing prevents using updated values in the same iteration
- The solution handles the large input (10^10) efficiently through the DP approach
