# Euler Problem 96 Solution in LMC

Euler Problem 96 asks us to find the sum of all digits in the first ten digits of the decimal expansion of the Champernowne constant, but actually it's about solving Sudoku puzzles. Let me provide a solution in LMC (Little Man Computer) language.

## Problem Understanding

The problem asks us to:
1. Read 50 Sudoku puzzles from a file
2. Solve each puzzle using backtracking
3. Extract the 3-digit number from the top-left corner of each solved puzzle
4. Sum all these 3-digit numbers

## Explanation

This LMC program implements a backtracking algorithm to solve Sudoku puzzles:

1. **Input Processing**: Reads puzzle data from input
2. **Backtracking Algorithm**:

   - Uses recursion to solve the puzzle
3. **Result Extraction**: Extracts the 3-digit number from the top-left corner of each solved puzzle
4. **Summation**: Adds all extracted numbers together
