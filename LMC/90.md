# Euler Problem 90 Solution in LMC

Euler Problem 90 asks: "How many distinct arrangements of two cubes can form all square numbers from 1 to 99 when placed side by side?"

## Analysis

We need to find pairs of 6-digit dice (each die has 6 faces) that can form all square numbers from 1 to 99. The key insight is that we need to be able to form numbers like 1, 4, 9, 16, 25, 36, 49, 64, 81 using two dice where each die shows one digit.
