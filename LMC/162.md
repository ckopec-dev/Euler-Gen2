# Euler Problem 162 Solution in LMC

Euler Problem 162 asks for the number of hexadecimal numbers containing at most 16 hexadecimal digits with all three digits 0, 1, and A present at least once.

## Approach

I'll use dynamic programming with states representing which of the required digits (0, 1, A) have been seen so far. The states will be:
- 000: No required digits seen
- 001: Only A seen
- 010: Only 1 seen  
- 011: Both 1 and A seen
- 100: Only 0 seen
- 101: Both 0 and A seen
- 110: Both 0 and 1 seen
- 111: All three digits seen (final state)
