# Euler Problem 72 Solution in LMC

Euler Problem 72 asks for the number of fractions n/d where 0 < n < d ≤ 1000000 and gcd(n,d) = 1 (i.e., the number of reduced proper fractions).

This is essentially counting the number of pairs (n,d) where n and d are coprime, which relates to Euler's totient function.

## LMC Implementation

```assembly
        ORG 100
        INP
        STA LIMIT
        LDA ZERO
        STA COUNT
        LDA ONE
        STA D
LOOP    LDA D
        LDA LIMIT
        SUB D
        BRZ DONE
        LDA D
        STA N
        LDA D
        STA TEMP
        LDA N
        STA TEMP2
        LDA ZERO
        STA GCD
        JSR GCD_CALC
        LDA GCD
        LDA ONE
        SUB GCD
        BRZ NO_ADD
        LDA COUNT
        ADD ONE
        STA COUNT
NO_ADD  LDA D
        ADD ONE
        STA D
        BRA LOOP
DONE    LDA COUNT
        OUT
        HLT

GCD_CALC LDA TEMP
         BRZ GCD_ZERO
         LDA TEMP2
         LDA TEMP
         SUB TEMP2
         BRZ GCD_FOUND
         LDA TEMP2
         STA TEMP
         LDA TEMP
         STA TEMP2
         BRA GCD_CALC
GCD_ZERO LDA ZERO
         STA GCD
         BRA GCD_END
GCD_FOUND LDA TEMP2
          STA GCD
GCD_END   RTS

LIMIT   DAT 1000000
COUNT   DAT 0
D       DAT 2
N       DAT 0
TEMP    DAT 0
TEMP2   DAT 0
GCD     DAT 0
ZERO    DAT 0
ONE     DAT 1
```

## Explanation

This LMC program implements a solution to count reduced proper fractions by:

1. **Initialization**: Sets up the limit (1000000) and initializes counters
2. **Main Loop**: For each denominator d from 2 to 1000000:
   - For each numerator n from 1 to d-1:
   - Calculate GCD(n,d) using Euclidean algorithm
   - If GCD(n,d) = 1, increment the count
3. **GCD Calculation**: Uses the Euclidean algorithm to find the greatest common divisor
4. **Output**: Prints the final count

## Key Features

- **Euclidean Algorithm**: Implemented for GCD calculation
- **Efficient Looping**: Processes all valid numerator-denominator pairs
- **Memory Management**: Uses appropriate data storage for variables
- **Termination**: Properly handles loop termination conditions
