# Euler Problem 559 Solution in LMC

I'll solve Euler Problem 559 in LMC (Little Man Computer) programming language.

## Problem Understanding

Euler Problem 559 asks for the number of integers n ≤ 10^18 such that the sum of the digits of n equals the sum of the digits of n².

This is a computational problem that requires:
1. For each number n from 1 to 10^18
2. Calculate sum of digits of n
3. Calculate sum of digits of n²
4. Count how many times these sums are equal
