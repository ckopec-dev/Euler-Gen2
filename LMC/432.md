# Euler Problem 432 Solution in LMC

I'll solve Euler Problem 432 in LMC (Little Man Computer) programming language. First, let me understand what the problem is asking.

Euler Problem 432 asks for the sum of all positive integers n ≤ 10^12 such that φ(n) = φ(n+1) = φ(n+2), where φ is Euler's totient function.

## Understanding the Problem

The totient function φ(n) counts the number of positive integers ≤ n that are coprime to n. We need to find all n where three consecutive integers have the same totient value.
