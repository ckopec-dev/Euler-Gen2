# Euler Problem 843 Solution in LMC

I'll solve Euler Problem 843 in LMC (Little Man Computer) programming language. First, let me understand what the problem asks for.

## Problem Understanding

Euler Problem 843 asks us to find the number of ways to write a positive integer n as a sum of positive integers, where the order of summands matters (this is called compositions of n).

For example, for n=3:
- 3 = 3
- 3 = 2 + 1  
- 3 = 1 + 2
- 3 = 1 + 1 + 1

So there are 4 compositions of 3.

## Mathematical Insight

The number of compositions of n is 2^(n-1), because we have n positions and for each of the (n-1) gaps between them, we can either put a plus sign or not.

## LMC Implementation

```assembly
    INP         // Read input n
    STA N       // Store n
    LDA ONE     // Load 1
    STA RESULT  // Initialize result = 1
    LDA N       // Load n
    SUB ONE     // Subtract 1 (n-1)
    STA EXP     // Store exponent
    LDA ZERO    // Load 0
    STA COUNT   // Initialize count = 0

LOOP    LDA COUNT   // Load count
    SUB EXP     // Subtract exponent
    BRZ DONE    // If count = exponent, we're done
    LDA RESULT  // Load result
    ADD RESULT  // Double it (result = result * 2)
    STA RESULT  // Store result
    LDA COUNT   // Load count
    ADD ONE     // Increment count
    STA COUNT   // Store count
    BRA LOOP    // Go back to loop

DONE    LDA RESULT  // Load final result
    OUT         // Output result
    HLT         // Halt

N       DAT     // Input number n
RESULT  DAT     // Result storage
EXP     DAT     // Exponent (n-1)
COUNT   DAT     // Loop counter
ONE     DAT 1   // Constant 1
ZERO    DAT 0   // Constant 0
```

## How It Works

1. **Input**: Read the number n from input
2. **Initialization**: Set result = 1, count = 0, exponent = n-1
3. **Loop**: 
   - While count < exponent:
   - Double the result (multiply by 2)
   - Increment count
   - Repeat
4. **Output**: Output the final result (which is 2^(n-1))

## Example Trace

For n = 3:
- Initial: result = 1, count = 0, exp = 2
- Loop 1: result = 1×2 = 2, count = 1
- Loop 2: result = 2×2 = 4, count = 2  
- Loop 3: count = 2 = exp, so exit
- Output: 4

## Alternative Implementation (More Efficient)

Since we're computing 2^(n-1), we can also implement it as bit shifting:

```assembly
    INP         // Read input n
    STA N       // Store n
    LDA ONE     // Load 1
    STA RESULT  // Initialize result = 1
    LDA N       // Load n
    SUB ONE     // Subtract 1 (n-1)
    STA EXP     // Store exponent

LOOP    LDA EXP     // Load exponent
    BRZ DONE    // If exponent = 0, we're done
    LDA RESULT  // Load result
    ADD RESULT  // Double it (result = result * 2)
    STA RESULT  // Store result
    LDA EXP     // Load exponent
    SUB ONE     // Decrement exponent
    STA EXP     // Store exponent
    BRA LOOP    // Go back to loop

DONE    LDA RESULT  // Load final result
    OUT         // Output result
    HLT         // Halt

N       DAT     // Input number n
RESULT  DAT     // Result storage
EXP     DAT     // Exponent (n-1)
ONE     DAT 1   // Constant 1
```

This implementation computes 2^(n-1) by repeatedly doubling the result, which is mathematically equivalent to computing 2 to the power of (n-1).
