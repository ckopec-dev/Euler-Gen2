# Euler Problem 783 Solution

The problem asks for the sum of all positive integers n ≤ 10^12 such that the number of divisors of n equals the number of divisors of n².

## Mathematical Analysis

Let n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ be the prime factorization of n.

- Number of divisors of n: d(n) = (a₁ + 1)(a₂ + 1)...(aₖ + 1)
- Number of divisors of n²: d(n²) = (2a₁ + 1)(2a₂ + 1)...(2aₖ + 1)

We want d(n) = d(n²), which means:
(a₁ + 1)(a₂ + 1)...(aₖ + 1) = (2a₁ + 1)(2a₂ + 1)...(2aₖ + 1)

For this equation to hold, we must have for each i:
aᵢ + 1 = 2aᵢ + 1

Solving: aᵢ = 0

This means that n must be of the form n = p₁⁰ × p₂⁰ × ... × pₖ⁰ = 1.

## Solution

Therefore, the sum of all such n ≤ 10^12 is simply 1.
