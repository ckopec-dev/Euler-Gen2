# Euler Problem 102 Solution in F#

## Problem Statement
Three distinct points are plotted at random on a Cartesian plane, where all coordinates are between 0 and 100, inclusive. We shall call the collection of three points a triangle if the area is non-zero. For how many of the 50,000 random triangles does the origin (0,0) lie inside the triangle?

## Solution Approach
To determine if the origin lies inside a triangle, I'll use the barycentric coordinate method. For a triangle with vertices A, B, C, the origin is inside the triangle if and only if all barycentric coordinates are positive.

## F# Implementation

```fsharp
open System

// Function to calculate the area of a triangle using cross product
let triangleArea (x1, y1) (x2, y2) (x3, y3) =
    abs (x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2)) / 2.0

// Function to check if origin (0,0) is inside triangle
let isOriginInsideTriangle (x1, y1) (x2, y2) (x3, y3) =
    // Calculate areas of sub-triangles formed with origin
    let areaTotal = triangleArea (x1, y1) (x2, y2) (x3, y3)
    let area1 = triangleArea (0.0, 0.0) (x2, y2) (x3, y3)
    let area2 = triangleArea (x1, y1) (0.0, 0.0) (x3, y3)
    let area3 = triangleArea (x1, y1) (x2, y2) (0.0, 0.0)
    
    // Origin is inside if sum of sub-areas equals total area
    // Using a small epsilon for floating point comparison
    let epsilon = 1e-10
    abs (area1 + area2 + area3 - areaTotal) < epsilon

// Alternative approach using barycentric coordinates
let isOriginInsideTriangleBarycentric (x1, y1) (x2, y2) (x3, y3) =
    // Calculate barycentric coordinates
    let denominator = (y2 - y3) * (x1 - x3) + (x3 - x2) * (y1 - y3)
    
    if abs denominator < 1e-10 then
        false  // Degenerate triangle
    else
        let a = ((y2 - y3) * (0.0 - x3) + (x3 - x2) * (0.0 - y3)) / denominator
        let b = ((y3 - y1) * (0.0 - x3) + (x1 - x3) * (0.0 - y3)) / denominator
        let c = 1.0 - a - b
        
        // Origin is inside if all barycentric coordinates are positive
        a > 0.0 && b > 0.0 && c > 0.0

// Generate random triangle coordinates
let random = Random()
let generateRandomPoint() = (random.NextDouble() * 100.0, random.NextDouble() * 100.0)

// Generate 50,000 random triangles and count how many contain origin
let solve() =
    let triangles = 
        [1..50000]
        |> List.map (fun _ -> 
            let p1 = generateRandomPoint()
            let p2 = generateRandomPoint()
            let p3 = generateRandomPoint()
            (p1, p2, p3))
    
    triangles 
    |> List.filter (fun (p1, p2, p3) -> isOriginInsideTriangleBarycentric p1 p2 p3)
    |> List.length

// Execute solution
let result = solve()
printfn "Number of triangles containing the origin: %d" result
```

## Alternative Cleaner Implementation

```fsharp
open System

let random = Random()

// Barycentric coordinate method - cleaner version
let isOriginInTriangle (x1, y1) (x2, y2) (x3, y3) =
    let denominator = (y2 - y3) * (x1 - x3) + (x3 - x2) * (y1 - y3)
    
    if abs denominator < 1e-10 then
        false  // Degenerate triangle
    else
        let a = ((y2 - y3) * (-x3) + (x3 - x2) * (-y3)) / denominator
        let b = ((y3 - y1) * (-x3) + (x1 - x3) * (-y3)) / denominator
        let c = 1.0 - a - b
        
        a > 0.0 && b > 0.0 && c > 0.0

// Generate random triangles and count those containing origin
let countTrianglesWithOrigin() =
    [1..50000]
    |> List.map (fun _ -> 
        let x1 = random.NextDouble() * 100.0
        let y1 = random.NextDouble() * 100.0
        let x2 = random.NextDouble() * 100.0
        let y2 = random.NextDouble() * 100.0
        let x3 = random.NextDouble() * 100.0
        let y3 = random.NextDouble() * 100.0
        (x1, y1, x2, y2, x3, y3))
    |> List.filter (fun (x1, y1, x2, y2, x3, y3) -> 
        isOriginInTriangle (x1, y1) (x2, y2) (x3, y3))
    |> List.length

// Main execution
let result = countTrianglesWithOrigin()
printfn "Answer: %d" result
```

## Key Insights

1. **Barycentric Coordinates**: The most reliable method to determine if a point is inside a triangle
2. **Floating Point Precision**: Need to handle small numerical errors in calculations
3. **Efficiency**: The algorithm is O(1) per triangle, so 50,000 iterations are manageable
4. **Edge Cases**: Handle degenerate triangles (zero area) properly

The solution generates 50,000 random triangles and counts how many contain the origin using barycentric coordinates, which is the most mathematically sound approach for this problem.
