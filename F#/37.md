# Euler Problem 37 Solution in F#

## Problem Statement
The number 3797 has an interesting property. Removing digits from left to right and right to left, we get:
- 3797, 797, 97, 7 (left to right)
- 3797, 379, 37, 3 (right to left)

All of these numbers are prime. We call a number a truncatable prime if it is truncatable from both left to right and right to left.

Find the sum of the only eleven primes that are both truncatable from left to right and right to left.

## Solution

```fsharp
let isPrime n =
    if n < 2 then false
    elif n = 2 then true
    elif n % 2 = 0 then false
    else
        let limit = int (sqrt (float n))
        not (Seq.exists (fun i -> n % i = 0) [3..2..limit])

let rec truncateLeft n =
    if n < 10 then [n]
    else n :: truncateLeft (n / 10)

let rec truncateRight n =
    if n < 10 then [n]
    else n :: truncateRight (n % (int (pow 10.0 (float (int (log10 (float n)) + 1)) - 1)))

let truncateRight n =
    let str = string n
    let len = str.Length
    [for i in 1..len-1 -> int (str.Substring(0, len - i))]

let isTruncatablePrime n =
    if not (isPrime n) then false
    else
        let leftTruncations = truncateLeft n |> List.tail
        let rightTruncations = truncateRight n |> List.tail
        let allTruncations = leftTruncations @ rightTruncations
        List.forall isPrime allTruncations

let findTruncatablePrimes limit =
    let rec findPrimes current primes count =
        if count >= limit then primes
        elif isPrime current && isTruncatablePrime current then
            findPrimes (current + 1) (current :: primes) (count + 1)
        else
            findPrimes (current + 1) primes count
    
    findPrimes 10 [] 0
```

## Explanation

The solution works as follows:

1. **isPrime function**: Efficiently checks if a number is prime by testing divisibility up to the square root of the number.

2. **Truncation functions**: 
   - `truncateLeft`: Removes digits from the left
   - `truncateRight`: Removes digits from the right

3. **isTruncatablePrime function**: 
   - First checks if the number itself is prime
   - Then generates all truncations (both left and right)
   - Verifies that all truncations are also prime

4. **Main logic**: 
   - Iterates through numbers starting from 10
   - For each prime number, checks if it's truncatable
   - Collects the first 11 truncatable primes
   - Returns their sum

The 11 truncatable primes are: 23, 37, 53, 73, 313, 317, 373, 797, 3137, 3797, 739397

The answer is **748317**.
