# Euler Problem 852 Solution in F#

I'll solve Euler Problem 852, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

```fsharp
let solveEuler852() =
    // For a 3×n rectangle tiled with 2×1 dominoes, we need to find the number of tilings
    // This is a classic dynamic programming problem
    
    // Let f(n) be the number of ways to tile a 3×n rectangle
    // We can derive the recurrence relation:
    // f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
    // Base cases:
    // f(0) = 1 (empty rectangle)
    // f(1) = 1 (one vertical domino)
    // f(2) = 3 (two horizontal dominoes, or two vertical dominoes, or one vertical and two horizontal)
    // f(3) = 11 (more complex combinations)
    
    let rec countTilings n =
        match n with
        | 0 -> 1L
        | 1 -> 1L
        | 2 -> 3L
        | 3 -> 11L
        | _ ->
            let mutable a = 1L  // f(0)
            let mutable b = 1L  // f(1)
            let mutable c = 3L  // f(2)
            let mutable d = 11L // f(3)
            
            for i in 4 .. n do
                let next = (a + 5L * b + d - c) % 1000000007L
                a <- b
                b <- c
                c <- d
                d <- next
            d
    
    countTilings 1000000

let solveEuler852Optimized() =
    let modValue = 1000000007L
    
    // Matrix multiplication for 4x4 matrices
    let matrixMult (m1: int64[,]) (m2: int64[,]) =
        let result = Array2D.create 4 4 0L
        for i in 0 .. 3 do
            for j in 0 .. 3 do
                for k in 0 .. 3 do
                    result.[i, j] <- (result.[i, j] + m1.[i, k] * m2.[k, j]) % modValue
        result
    
    // Matrix exponentiation
    let rec matrixPower (m: int64[,]) n =
        if n = 0 then
            let result = Array2D.create 4 4 0L
            for i in 0 .. 3 do result.[i, i] <- 1L
            result
        elif n % 2 = 0 then
            let half = matrixPower m (n / 2)
            matrixMult half half
        else
            matrixMult m (matrixPower m (n - 1))
    
    // Transition matrix for the recurrence: f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4)
    // The recurrence relation can be represented as:
    // [f(n)   ]   [1 5 1 -1] [f(n-1)]
    // [f(n-1)] = [1 0 0  0] [f(n-2)]
    // [f(n-2)]   [0 1 0  0] [f(n-3)]
    // [f(n-3)]   [0 0 1  0] [f(n-4)]
    
    let transitionMatrix = 
        [||
            [| 1L; 5L; 1L; -1L |]
            [| 1L; 0L; 0L;  0L |]
            [| 0L; 1L; 0L;  0L |]
            [| 0L; 0L; 1L;  0L |]
        |]
    
    // For n >= 4, we need to compute the matrix power and multiply with initial vector
    let rec countTilingsMatrix n =
        match n with
        | 0 -> 1L
        | 1 -> 1L
        | 2 -> 3L
        | 3 -> 11L
        | _ ->
            let powerMatrix = matrixPower transitionMatrix (n - 3)
            // Initial vector [f(3); f(2); f(1); f(0)] = [11; 3; 1; 1]
            let result = (powerMatrix.[0, 0] * 11L + powerMatrix.[0, 1] * 3L + 
                         powerMatrix.[0, 2] * 1L + powerMatrix.[0, 3] * 1L) % modValue
            result
    
    countTilingsMatrix 1000000
```

## Explanation

The problem asks for the number of ways to tile a 3×n rectangle using 2×1 dominoes.

**Key Insights:**
1. This is a classic dynamic programming problem
2. We can derive a recurrence relation for the number of tilings
3. The recurrence relation is: f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4) for n ≥ 4
4. Base cases: f(0) = 1, f(1) = 1, f(2) = 3, f(3) = 11

**Approach:**
1. Use dynamic programming with the recurrence relation
2. For efficiency with large n (1,000,000), I've provided both iterative and matrix exponentiation approaches
3. Apply modular arithmetic to prevent overflow
4. The final answer for n = 1,000,000 is computed and returned

The solution uses a bottom-up dynamic programming approach with O(n) time complexity and O(1) space complexity for the optimized version, making it efficient enough to handle the large input value of 1,000,000.
