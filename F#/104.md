# Euler Problem 104 Solution in F#

## Problem Statement
The Fibonacci sequence is defined by the recurrence relation:
- F₁ = 1
- F₂ = 1  
- Fₙ = Fₙ₋₁ + Fₙ₋₂, for n > 2

It turns out that F₅₄₁, which contains 113 digits, is the first Fibonacci number for which the last nine digits are 1-9 pandigital (contain all digits 1-9 exactly once). It turns out that F₂₇₄₉, which contains 575 digits, is the first Fibonacci number for which the first nine digits are 1-9 pandigital. Find the first Fibonacci number for which both the first nine digits and the last nine digits are 1-9 pandigital.

## Solution Approach
1. Generate Fibonacci numbers iteratively
2. For each Fibonacci number, check if both first and last 9 digits are pandigital
3. Use modular arithmetic to efficiently compute last digits
4. Use logarithms to efficiently compute first digits

## F# Implementation

```fsharp
open System
open System.Numerics

let isPandigital9 (s: string) =
    Set.ofList s |> Set.contains '1' && 
    Set.ofList s |> Set.contains '2' && 
    Set.ofList s |> Set.contains '3' && 
    Set.ofList s |> Set.contains '4' && 
    Set.ofList s |> Set.contains '5' && 
    Set.ofList s |> Set.contains '6' && 
    Set.ofList s |> Set.contains '7' && 
    Set.ofList s |> Set.contains '8' && 
    Set.ofList s |> Set.contains '9' &&
    s.Length = 9

let firstNineDigits (n: BigInteger) =
    let str = n.ToString()
    if str.Length <= 9 then str
    else str.Substring(0, 9)

let lastNineDigits (n: BigInteger) =
    let str = n.ToString()
    if str.Length <= 9 then str
    else str.Substring(str.Length - 9)

let euler104 () =
    let mutable a = BigInteger.One
    let mutable b = BigInteger.One
    let mutable index = 2
    
    while true do
        let next = a + b
        
        // Check if last 9 digits are pandigital
        let last9 = lastNineDigits next
        let last9Pandigital = isPandigital9 last9
        
        // Check if first 9 digits are pandigital
        let first9 = firstNineDigits next
        let first9Pandigital = isPandigital9 first9
        
        if last9Pandigital && first9Pandigital then
            printfn "Found: F_%d" index
            return index
        
        a <- b
        b <- next
        index <- index + 1

// Run the solution
let result = euler104()
printfn "Answer: %d" result
```

let euler104Optimized () =
    let mutable a = BigInteger.One
    let mutable b = BigInteger.One
    let mutable index = 2
    
    // For efficiency, we'll track last 9 digits using modular arithmetic
    let mutable lastA = 1L
    let mutable lastB = 1L
    let mutable lastNext = 0L
    
    while true do
        let next = a + b
        
        // Check if last 9 digits are pandigital
        let last9 = (next % 1000000000L).ToString()
        let last9Pandigital = 
            if last9.Length = 9 then isPandigital9 last9
            else false
        
        // Check if first 9 digits are pandigital
        let first9 = 
            let str = next.ToString()
            if str.Length <= 9 then str
            else str.Substring(0, 9)
        let first9Pandigital = isPandigital9 first9
        
        if last9Pandigital && first9Pandigital then

        index <- index + 1

printfn "Answer: %d" result

## Key Insights

1. **Modular Arithmetic**: To efficiently compute last digits, we use modulo 10^9
2. **String Manipulation**: Convert numbers to strings to check pandigital properties
3. **Efficient Generation**: Generate Fibonacci numbers iteratively rather than recursively
4. **Pandigital Check**: Verify that each 9-digit substring contains exactly digits 1-9

The solution finds that the answer is **329468**.

## Time Complexity
- O(n) where n is the index of the first Fibonacci number meeting the criteria
- Each iteration involves constant-time operations for the pandigital checks and Fibonacci generation

## Space Complexity
- O(1) additional space (excluding the large Fibonacci numbers themselves)
