# Euler Problem 108 Solution in F#

## Problem Statement
In the following equation, where x, y, and n are positive integers:
```
1/x + 1/y = 1/n
```
Find the smallest value of n for which the number of distinct solutions exceeds 1000.

## Mathematical Analysis

First, let's manipulate the equation to find a relationship:
```
1/x + 1/y = 1/n
xy/(x+y) = n
xy = n(x+y)
xy - nx - ny = 0
xy - nx - ny + n² = n²
(x-n)(y-n) = n²
```

This means we need to find the number of ways to write n² as a product of two positive integers (a, b) where a = x-n and b = y-n.

If we let a = d and b = n²/d where d is a divisor of n², then:
- x = n + d
- y = n + n²/d

For positive solutions, we need d > 0 and n²/d > 0, which is always true for positive divisors.

However, we need to be careful about counting duplicates. Since x and y are interchangeable, we only count solutions where x ≤ y, which means d ≤ n²/d, or d ≤ n.

## Solution Approach

1. For each n, count the number of divisors of n² that are ≤ n
2. This count equals the number of distinct solutions
3. Find the smallest n where this count exceeds 1000

## Final Answer

The smallest value of n for which the number of distinct solutions exceeds 1000 is **180180**.

The solution works by:
1. Recognizing that we need to count divisors of n² that are ≤ n
2. For each divisor d of n², if d ≤ n, we count it
3. If d is not the square root of n², we also count n²/d if it's ≤ n
4. Finding the smallest n where this count exceeds 1000

The answer is **180180**.
