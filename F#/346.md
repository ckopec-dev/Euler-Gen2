# Euler Problem 346 Solution in F#

## Problem Statement
The number 145 is a curious number, as 1! + 4! + 5! = 1 + 24 + 120 = 145.

Find the sum of all numbers which are equal to the sum of the factorial of their digits.

## Solution

```fsharp
let factorial n =
    if n <= 1 then 1
    else [1..n] |> List.reduce (*)

let sumOfFactorialOfDigits n =
    n.ToString()
    |> Seq.map (fun c -> int c - int '0')
    |> Seq.map factorial
    |> Seq.sum

let isCuriousNumber n =
    n = sumOfFactorialOfDigits n

// Find all curious numbers
let findCuriousNumbers max =
    [1..max]
    |> List.filter isCuriousNumber

// Since 1! = 1 and 2! = 2, we can limit our search
// For numbers with more digits, the sum of factorials grows much slower than the number itself
let curiousNumbers = findCuriousNumbers 100000

let result = curiousNumbers |> List.sum

printfn "Curious numbers: %A" curiousNumbers
printfn "Sum: %d" result
```

## Explanation

Let me trace through the solution:

1. **Factorial function**: Computes n! using recursion or list reduction
2. **Sum of factorial of digits**: 
   - Convert number to string
   - Map each character to its digit value
   - Calculate factorial of each digit
   - Sum all factorials
3. **Curious number check**: Compare the original number with sum of factorial of its digits
4. **Search range**: Since factorials grow very quickly, we only need to check up to a reasonable limit (100,000 in this case)

## Key Insights

- The maximum possible sum of factorials for an n-digit number is n × 9! = n × 362880
- For numbers with more than 7 digits, the number itself grows much faster than the sum of factorials
- We only need to check up to about 100,000 to find all curious numbers

The curious numbers are: 1, 2, 145, 40585
