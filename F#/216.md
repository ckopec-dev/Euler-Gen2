# Euler Problem 216 Solution in F#

## Problem Statement
Consider numbers of the form $n^2 + n + 41$. For $n = 0, 1, 2, \ldots$, this formula generates 41 primes for the first 41 values of $n$. 

Let's define $P(n)$ as the number of primes in the sequence $n^2 + n + 41$ for $n = 0, 1, 2, \ldots, n-1$.

Find the largest value of $n$ such that $P(n) = 41$.

Wait, let me re-read this more carefully. Actually, this is about a different sequence. Let me solve the actual Euler Problem 216:

**Euler Problem 216**: Consider numbers of the form $2n^2 - 1$. Find the number of such numbers that are prime and less than 10^8.

## Solution

```fsharp
let isPrime n =
    if n < 2 then false
    elif n = 2 then true
    elif n % 2 = 0 then false
    else
        let sqrtN = int (sqrt (float n))
        not [3..2..sqrtN] |> List.exists (fun i -> n % i = 0)

let euler216 () =
    let limit = 100000000  // 10^8
    let rec countPrimes n acc =
        if 2 * n * n - 1 >= limit then acc
        else
            let value = 2 * n * n - 1
            if isPrime value then countPrimes (n + 1) (acc + 1)
            else countPrimes (n + 1) acc
    countPrimes 1 0

// Run the solution
let result = euler216()
printfn "The answer is: %d" result
```

## More Efficient Version Using Sieve

```fsharp
let euler216Sieve () =
    let limit = 100000000  // 10^8
    let maxN = int (sqrt (float (limit / 2))) + 1
    
    // Generate all possible values of 2n² - 1
    let values = 
        [1..maxN] 
        |> List.map (fun n -> 2 * n * n - 1)
        |> List.filter (fun v -> v < limit)
    
    // Sieve approach for prime checking
    let sieve = Array.create (limit + 1) true
    sieve.[0] <- false
    sieve.[1] <- false
    
    for i in 2..int (sqrt (float limit)) do
        if sieve.[i] then
            for j in i * i..i..limit do
                sieve.[j] <- false
    
    // Count primes among the values
    values 
    |> List.filter (fun v -> sieve.[v])
    |> List.length

// Run the solution
let result = euler216Sieve()
printfn "The answer is: %d" result
```

The solution works by:
1. Generating numbers of the form $2n^2 - 1$ for $n = 1, 2, 3, \ldots$
2. Checking each number for primality
3. Counting how many of these numbers are prime and less than $10^8$
4. Returning the total count
