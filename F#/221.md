# Euler Problem 221 Solution in F#

## Problem Statement
Let us call a positive integer ABCD with 4 digits (A, B, C, D) a "magic number" if it satisfies the condition: ABCD = A^3 + B^3 + C^3 + D^3. Find the sum of all such magic numbers.

## Solution Approach
I'll solve this step by step:

1. Generate all 4-digit numbers (1000-9999)
2. For each number, extract the individual digits
3. Check if the number equals the sum of cubes of its digits
4. Sum all magic numbers found

## F# Implementation

```fsharp
let solveEuler221() =
    // Function to extract digits from a number
    let getDigits n =
        let rec digits acc num =
            if num = 0 then acc
            else digits (num % 10 :: acc) (num / 10)
        digits [] n
    
    // Function to check if a number is a magic number
    let isMagicNumber n =
        let digits = getDigits n
        let sumOfCubes = digits |> List.map (fun d -> d * d * d) |> List.sum
        n = sumOfCubes
    
    // Find all magic numbers in range 1000-9999
    let magicNumbers = 
        [1000..9999]
        |> List.filter isMagicNumber
    
    // Return the sum of all magic numbers
    magicNumbers |> List.sum

// Execute the solution
let result = solveEuler221()
printfn "The sum of all magic numbers is: %d" result
```
