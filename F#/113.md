# Euler Problem 113 Solution in F#

## Problem Statement
Working from left-to-right if no digit is exceeded by the digit to its left, we call it an increasing number; for example, 13679.
Similarly, if no digit is exceeded by the digit to its right, we call it a decreasing number; for example, 98430.
We shall call a positive integer that is neither increasing nor decreasing a "bouncy" number; for example, 155349.
As n increases, the proportion of bouncy numbers below n increases such that there are only 12951 numbers below one-million that are not bouncy.
Find the number of non-bouncy numbers below one trillion (10^12).

## Solution Approach
This is a dynamic programming problem. We need to count:
1. Increasing numbers (digits never decrease)
2. Decreasing numbers (digits never increase)
3. Subtract the overlap (numbers that are both increasing and decreasing - i.e., numbers with all same digits)

We'll use digit DP (Dynamic Programming) where we track:
- Current position
- Previous digit
- Whether we're still in increasing/decreasing mode

## F# Implementation

let euler113 () =
    let maxDigits = 12
    
    // Memoization for increasing numbers
    let mutable incMemo = Map.empty
    
    // Memoization for decreasing numbers  
    let mutable decMemo = Map.empty
    
    // Count increasing numbers with given constraints
    let rec countIncreasing pos prevDigit maxDigit =
        if pos = maxDigits then 1
        else
            let key = (pos, prevDigit, maxDigit)
            match Map.tryFind key incMemo with
            | Some result -> result
            | None ->
                let result = 
                    [prevDigit..maxDigit]
                    |> List.sumBy (fun digit -> countIncreasing (pos + 1) digit maxDigit)
                incMemo <- Map.add key result incMemo
                result
    
    // Count decreasing numbers with given constraints
    let rec countDecreasing pos prevDigit maxDigit =
        if pos = maxDigits then 1
        else
            let key = (pos, prevDigit, maxDigit)
            match Map.tryFind key decMemo with
            | Some result -> result
            | None ->
                let result = 
                    [maxDigit..prevDigit]
                    |> List.sumBy (fun digit -> countDecreasing (pos + 1) digit maxDigit)
                decMemo <- Map.add key result decMemo
                result
    
    // Count all increasing numbers (1 to 10^12)
    let increasingCount = 
        [1..9]  // First digit can be 1-9
        |> List.sumBy (fun firstDigit -> countIncreasing 1 firstDigit 9)
    
    // Count all decreasing numbers (1 to 10^12)
    let decreasingCount = 
        [1..9]  // First digit can be 1-9
        |> List.sumBy (fun firstDigit -> countDecreasing 1 firstDigit 9)
    
    // Count numbers with all same digits (both increasing and decreasing)
    let sameDigitCount = 9  // 1, 2, 3, 4, 5, 6, 7, 8, 9
    
    // Total non-bouncy numbers = increasing + decreasing - overlap
    increasingCount + decreasingCount - sameDigitCount
