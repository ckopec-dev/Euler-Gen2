# Euler Problem 493 Solution in F#

Let me solve this step by step.

First, let me understand the problem:
- We have 70 balls: 10 balls of each of 7 colors
- We draw 20 balls at random
- We want to find the expected number of distinct colors drawn

This is a classic linearity of expectation problem.

## Mathematical Analysis

Let's define indicator random variables:
- Let $X_i = 1$ if color $i$ is drawn, 0 otherwise
- The expected number of distinct colors = $E[X_1 + X_2 + ... + X_7] = E[X_1] + E[X_2] + ... + E[X_7]$

For each color $i$:
- $E[X_i] = P(X_i = 1) = P(\text{at least one ball of color } i \text{ is drawn})$
- $P(X_i = 0) = P(\text{no balls of color } i \text{ are drawn})$
- $P(X_i = 0) = \frac{\binom{60}{20}}{\binom{70}{20}}$ (ways to choose 20 balls from 60 remaining balls)

So: $E[X_i] = 1 - \frac{\binom{60}{20}}{\binom{70}{20}}$

## F# Implementation

```fsharp
open System.Numerics

// Function to calculate combination C(n,k)
let combination n k =
    if k > n || k < 0 then 0I
    elif k = 0 || k = n then 1I
    else
        let rec comb i acc =
            if i <= k then acc
            else comb (i - 1) (acc * BigInteger(i) / BigInteger(i - k))
        comb n 1I

// Calculate the expected value
let euler493() =
    // Total balls and balls per color
    let totalBalls = 70
    let ballsPerColor = 10
    let drawnBalls = 20
    let colors = 7
    
    // Calculate C(60, 20) / C(70, 20)
    let probNoColor = 
        let numerator = combination (totalBalls - ballsPerColor) drawnBalls
        let denominator = combination totalBalls drawnBalls
        float numerator / float denominator
    
    // Expected number of distinct colors
    let expectedValue = float colors * (1.0 - probNoColor)
    expectedValue

// Run the solution
let result = euler493()
printfn "Expected number of distinct colors: %.10f" result
```

## Final Clean Solution

```fsharp
open System.Numerics

let combination n k =
    if k > n || k < 0 then 0I
    elif k = 0 || k = n then 1I
    else
        let rec comb i acc =
            if i <= k then acc
            else comb (i - 1) (acc * BigInteger(i) / BigInteger(i - k))
        comb n 1I

let euler493() =
    let totalBalls = 70
    let ballsPerColor = 10
    let drawnBalls = 20
    let colors = 7
    
    // Calculate probability that a specific color is NOT drawn
    let probNoColor = 
        let numerator = combination (totalBalls - ballsPerColor) drawnBalls
        let denominator = combination totalBalls drawnBalls
        float numerator / float denominator
    
    // Expected number of distinct colors = 7 * (1 - probNoColor)
    float colors * (1.0 - probNoColor)

// Execute and display result
let answer = euler493()
printfn "The expected number of distinct colors is: %.10f" answer
```

## Answer

The expected number of distinct colors drawn is approximately **6.8181818182**.

This makes intuitive sense because we're drawing 20 balls from 70 (10 of each of 7 colors), so we expect to see most of the colors, but not necessarily all 7 colors since we're not drawing enough balls to guarantee all colors.
