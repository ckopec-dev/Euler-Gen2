# Euler Problem 351 Solution in F#

## Problem Statement
A hexagonal orchard of order n is a triangular lattice made up of points within a regular hexagon with n+1 points along each edge. The hexagonal orchard of order 6 is shown below.

We define H(n) as the number of points in a hexagonal orchard of order n that are not visible from the center.

Find H(100000).

## Solution Approach
This problem involves counting lattice points that are not visible from the center of a hexagonal orchard. The key insight is to use the inclusion-exclusion principle with the Möbius function.

For a hexagonal orchard of order n, we need to count points (x,y) where gcd(x,y) = 1, but we must be careful about the hexagonal geometry.
