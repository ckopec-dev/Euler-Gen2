# Euler Problem 156 Solution in C#

## Problem Statement
Starting from 1 and going up to 10^9, how many numbers contain exactly 100 occurrences of the digit 1?

## Solution Approach
This is a classic digit dynamic programming problem. We need to count how many numbers contain exactly 100 occurrences of digit 1.

## C# Implementation

using System;
using System.Collections.Generic;
using System.Numerics;

public class Euler156

    // Memoization for digit DP
    private static Dictionary<(int, int, bool, int, int), BigInteger> memo;
    
    public static void Main()

        Console.WriteLine($"Answer: {result}");
    }
    
    // Digit DP function to count numbers with exactly 'target' occurrences of digit 'd'
    private static BigInteger CountNumbersWithDigit(int target, int d, bool tight, int pos, int count, int num)
    {
        // Base case: if we've processed all digits
        if (pos == 10) // Since we're dealing with 10^9, max 10 digits
        {
            return count == target ? 1 : 0;
        }
        
        // Memoization key
        var key = (pos, tight ? 1 : 0, d, count, num);
        if (memo.ContainsKey(key))
            return memo[key];
        
        BigInteger result = 0;
        int limit = tight ? 9 : 9; // Upper limit for current digit
        
        // Try all possible digits
        for (int digit = 0; digit <= limit; digit++)
        {
            // Check if this digit contributes to our count
            int newCount = count + (digit == d ? 1 : 0);
            
            // If count exceeds target, no point in continuing
            if (newCount > target)
                continue;
                
            bool newTight = tight && (digit == limit);
            int newNum = num * 10 + digit;
            
            result += CountNumbersWithDigit(target, d, newTight, pos + 1, newCount, newNum);
        }
        
        memo[key] = result;
        return result;
    }

    private static BigInteger CountWithDigit1(int target, int pos, bool tight, int count, int prefix)
    {
        // Base case
        if (pos == 10) // 10-digit number (10^9)
        {
            return count == target ? 1 : 0;
        }
        
        // Memoization key
        var key = (pos, tight ? 1 : 0, count, prefix);
        if (memo.ContainsKey(key))
            return memo[key];

        int limit = tight ? 9 : 9;
        
        for (int digit = 0; digit <= limit; digit++)
        {
            int newCount = count + (digit == 1 ? 1 : 0);
            
            // Early termination if count exceeds target
            if (newCount > target)
                continue;
                
            bool newTight = tight && (digit == limit);
            int newPrefix = prefix * 10 + digit;
            
            result += CountWithDigit1(target, pos + 1, newTight, newCount, newPrefix);
        }
        
        memo[key] = result;
        return result;
    }
}

## Mathematical Analysis

The problem requires counting numbers where the digit '1' appears exactly 100 times. This is a classic application of digit dynamic programming:

1. **State Definition**: 
   - Position in the number
   - Tight constraint (whether we're bounded by the original number)
   - Count of digit 1 so far
   - Current prefix

2. **Transition**: For each position, try all valid digits (0-9) and update the count accordingly

3. **Base Case**: When we've filled all 10 positions, check if we have exactly 100 occurrences

## Key Insights

- The upper bound is 10^9, which is a 10-digit number
- We use memoization to avoid recomputing overlapping subproblems
- Early termination when count exceeds target for efficiency
- The solution handles the constraint that we're counting numbers from 1 to 10^9

O(10 × 2 × 101 × 10^10) = O(10^12) in worst case, but memoization reduces actual computation significantly.
