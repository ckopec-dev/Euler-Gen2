# Euler Problem 650 Solution in C#

I'll solve Euler Problem 650, which asks for the sum of all distinct values of f(n) for 1 ≤ n ≤ 10^14, where f(n) is the number of ways to write n as a sum of positive integers, where the order doesn't matter (partition function).

## Mathematical Analysis

Euler Problem 650 involves the partition function p(n), which counts the number of ways to write n as a sum of positive integers (where order doesn't matter).

The key mathematical concepts needed:

1. **Pentagonal Number Theorem**: 
   $$p(n) = \sum_{k=-\infty}^{\infty} (-1)^k p(n - g_k)$$
   where $g_k = \frac{k(3k-1)}{2}$ are pentagonal numbers

2. **Recurrence Relation**: 
   $$p(n) = \sum_{k=1}^{\infty} (-1)^{k+1}[p(n - k(3k-1)/2) + p(n - k(3k+1)/2)]$$

3. **Base Cases**: 
   - $p(0) = 1$
   - $p(n) = 0$ for $n < 0$
