# Euler Problem 656 Solution in C#

## Problem Statement
Let $S(n)$ be the sum of all positive integers $k$ such that $k \leq n$ and $\gcd(k,n) = 1$.

Let $T(n)$ be the sum of all positive integers $k$ such that $k \leq n$ and $\gcd(k,n) > 1$.

Let $F(n) = S(n) + T(n)$.

Find $F(10^{12}) \bmod 1000000007$.

## Solution Approach

This problem requires us to compute the sum of all integers from 1 to n, which is simply $n(n+1)/2$. However, we need to be more careful about the interpretation.

Looking at the problem more carefully:
- $S(n)$: Sum of integers $k \leq n$ where $\gcd(k,n) = 1$
- $T(n)$: Sum of integers $k \leq n$ where $\gcd(k,n) > 1$
- $F(n) = S(n) + T(n)$ = Sum of all integers from 1 to n

So $F(n) = \frac{n(n+1)}{2}$.

Actually, since $S(n) + T(n)$ is simply the sum of all integers from 1 to n, we have:
$$F(n) = \sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$

However, looking at the problem structure and typical Euler problems, there might be a different interpretation. Let me consider that we might need to compute $F(n)$ in a more complex way.

Actually, re-reading carefully: $F(n) = S(n) + T(n)$ where:
- $S(n)$ is sum of coprime integers
- $T(n)$ is sum of non-coprime integers

Since every integer from 1 to n is either coprime or not coprime with n, we have:
$$F(n) = \sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$

## Final Solution

using System;

public class Euler656
{
    private const long MOD = 1000000007;
    
    public static long Solve(long n)
    {
        // F(n) = sum of integers from 1 to n = n(n+1)/2
        // We compute this modularly to avoid overflow
        
        long nMod = n % MOD;
        long nPlus1Mod = (n + 1) % MOD;
        
        // Calculate n * (n+1) / 2 mod MOD
        // Using Fermat's little theorem: a^(-1) ≡ a^(p-2) (mod p)
        long inv2 = ModPow(2, MOD - 2, MOD);
        
        long product = (nMod * nPlus1Mod) % MOD;
        long result = (product * inv2) % MOD;
        
        return result;
    }
    
    // Fast modular exponentiation
    private static long ModPow(long baseNum, long exp, long mod)
    {
        long result = 1;
        baseNum = baseNum % mod;
        
        while (exp > 0)
        {
            if (exp % 2 == 1)
                result = (result * baseNum) % mod;
            exp = exp >> 1;
            baseNum = (baseNum * baseNum) % mod;
        }
        
        return result;
    }
