# Euler Problem 789 Solution in C#

I'll solve Euler Problem 789, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

The problem asks us to find the number of ways to express a number n as a sum of powers of 2 (2^0, 2^1, 2^2, ...) where each power can be used at most twice.

This is equivalent to finding the number of partitions of n into parts that are powers of 2, with each part appearing at most twice.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to partition numbers using powers of 2 with the given constraint.

```csharp
using System;
using System.Collections.Generic;

public class Euler789
{
    private static Dictionary<(long, int), long> memo = new Dictionary<(long, int), long>();
    
    public static void Main()
    {
        // Calculate the result for the given problem
        long result = CountWays(1000000000000000000L);
        Console.WriteLine($"Result: {result}");
    }
    
    private static long CountWays(long n)
    {
        memo.Clear();
        return CountWaysHelper(n, 0);
    }
    
    private static long CountWaysHelper(long remaining, int power)
    {
        // Base case: if remaining is 0, we found one way
        if (remaining == 0)
            return 1;
            
        // Base case: if remaining is negative or we've gone too far, no way
        if (remaining < 0 || power > 60) // 2^60 is much larger than 10^18
            return 0;
            
        // Check memoization
        var key = (remaining, power);
        if (memo.ContainsKey(key))
            return memo[key];
            
        long ways = 0;
        long powerOf2 = 1L << power; // 2^power
        
        // We can use 0, 1, or 2 copies of this power of 2
        for (int count = 0; count <= 2; count++)
        {
            long newRemaining = remaining - (count * powerOf2);
            if (newRemaining >= 0)
            {
                ways += CountWaysHelper(newRemaining, power + 1);
            }
        }
        
        memo[key] = ways;
        return ways;
    }
}
```

## Explanation

The solution works by:

1. **Dynamic Programming with Memoization**: We recursively count the number of ways to partition a number using powers of 2, with each power used at most twice.

2. **State Definition**: At each step, we have a remaining number to partition and a current power of 2 to consider.

3. **Transition**: For each power of 2, we can use 0, 1, or 2 copies of it, and recursively solve for the remaining amount.

4. **Base Cases**: 
   - If remaining = 0, we found one valid partition
   - If remaining < 0 or we've considered all powers, no valid partition exists

5. **Memoization**: We cache results to avoid recomputation.

The time complexity is manageable for reasonable inputs, though for the specific large number in the problem (10^18), the mathematical properties of the sequence would be used to derive the answer directly.
