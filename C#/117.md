# Euler Problem 117 Solution in C#

## Problem Statement
Using a combination of grey (1 unit), red (2 units), green (3 units), and blue (4 units) tiles, how many ways can a row measuring fifty units in length be tiled?

## Solution

```csharp
using System;

class Program
{
    static void Main()
    {
        int targetLength = 50;
        long result = CountWays(targetLength);
        Console.WriteLine($"Number of ways to tile a row of length {targetLength}: {result}");
    }
    
    static long CountWays(int n)
    {
        // dp[i] represents number of ways to tile a row of length i
        long[] dp = new long[n + 1];
        
        // Base cases
        dp[0] = 1; // One way to tile empty row (use no tiles)
        
        // For each position in the row
        for (int i = 1; i <= n; i++)
        {
            // Add ways to reach position i using each tile size
            // Grey tile (1 unit)
            if (i >= 1)
                dp[i] += dp[i - 1];
            
            // Red tile (2 units)
            if (i >= 2)
                dp[i] += dp[i - 2];
            
            // Green tile (3 units)
            if (i >= 3)
                dp[i] += dp[i - 3];
            
            // Blue tile (4 units)
            if (i >= 4)
                dp[i] += dp[i - 4];
        }
        
        return dp[n];
    }
}
```

## Explanation

This is a dynamic programming problem where we need to count the number of ways to tile a row of length `n` using tiles of sizes 1, 2, 3, and 4 units.

### Approach:
1. **Dynamic Programming**: We use an array `dp` where `dp[i]` represents the number of ways to tile a row of length `i`
2. **Base Case**: `dp[0] = 1` (one way to tile an empty row - use no tiles)
3. **Recurrence Relation**: For each position `i`, we can reach it by:
   - Adding a grey tile (1 unit) from position `i-1`
   - Adding a red tile (2 units) from position `i-2`
   - Adding a green tile (3 units) from position `i-3`
   - Adding a blue tile (4 units) from position `i-4`
4. **Final Answer**: `dp[n]` gives us the total number of ways to tile a row of length `n`

### Time Complexity: O(n)
### Space Complexity: O(n)

The solution uses the principle that the number of ways to reach position `i` is the sum of ways to reach all positions from which we can directly reach `i` using one of our tile types.

Running this code with `n = 50` will give us the answer: **100808458960497**
