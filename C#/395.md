# Euler Problem 395 Solution in C#

I'll solve Euler Problem 395, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

## Problem Understanding

We need to find the number of ways to completely tile a 3×n rectangle using 2×1 dominoes. Each domino covers exactly 2 unit squares.

## Approach

This is a classic dynamic programming problem. I'll use the transfer matrix method or direct DP approach to count the tilings.

Let me define states based on the configuration of the last column:
- State 0: No squares filled in the last column
- State 1: First square filled in last column
- State 2: Second square filled in last column  
- State 3: Third square filled in last column
- State 4: First and second squares filled in last column
- State 5: First and third squares filled in last column
- State 6: Second and third squares filled in last column
- State 7: All three squares filled in last column

## C# Solution

```csharp
using System;
using System.Numerics;

public class Euler395
{
    public static void Main()
    {
        Console.WriteLine($"Answer: {Solve(12)}");
    }
    
    public static BigInteger Solve(int n)
    {
        if (n == 0) return 1;
        if (n == 1) return 0;
        if (n == 2) return 3;
        
        // For n >= 3, we use matrix exponentiation or direct DP
        // State representation: 
        // 0: no squares filled
        // 1: first square filled
        // 2: second square filled
        // 3: third square filled
        // 4: first and second filled
        // 5: first and third filled
        // 6: second and third filled
        // 7: all three filled
        
        // Using recurrence relation approach
        // Let f(n) be the number of ways to tile 3×n rectangle
        // We can derive: f(n) = f(n-2) + 2*f(n-4) + 2*f(n-6) + ... + 2*f(0)
        // But let's use a cleaner approach with DP
        
        // Better approach: Use the recurrence relation
        // f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
        // Base cases: f(0) = 1, f(1) = 0, f(2) = 3, f(3) = 11
        
        BigInteger[] dp = new BigInteger[n + 1];
        dp[0] = 1;
        dp[1] = 0;
        dp[2] = 3;
        dp[3] = 11;
        
        for (int i = 4; i <= n; i++)
        {
            dp[i] = dp[i - 1] + 5 * dp[i - 2] + dp[i - 3] - dp[i - 4];
        }
        
        return dp[n];
    }
}

public class Euler395Alternative

        // The recurrence relation for 3×n tiling with 2×1 dominoes:
        // f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
        BigInteger a = 1; // f(0)
        BigInteger b = 0; // f(1)  
        BigInteger c = 3; // f(2)
        BigInteger d = 11; // f(3)
        
        for (int i = 4; i <= n; i++)
        {
            BigInteger next = a + 5 * b + c - d;
            a = b;
            b = c;
            c = d;
            d = next;
        }
        
        return d;
    }
}
```

## Mathematical Analysis

The problem can be solved using the recurrence relation for tiling a 3×n rectangle with 2×1 dominoes:

**f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4)** for n ≥ 4

With base cases:
- f(0) = 1 (empty rectangle)
- f(1) = 0 (impossible to tile 3×1 with 2×1 dominoes)
- f(2) = 3 (three ways to tile 3×2)
- f(3) = 11 (eleven ways to tile 3×3)
