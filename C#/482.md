# Euler Problem 482 Solution in C#

## Problem Statement
Find the number of lattice points (points with integer coordinates) inside the region bounded by the ellipse $x^2 + 4y^2 = 100$.

## Solution

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        long result = CountLatticePoints();
        Console.WriteLine($"Number of lattice points: {result}");
    }
    
    static long CountLatticePoints()
    {
        long count = 0;
        long limit = 100; // Since x^2 <= 100, x <= 10
        
        // Iterate through all possible x values
        for (long x = -10; x <= 10; x++)
        {
            // For each x, find the range of valid y values
            // From x^2 + 4y^2 = 100, we get 4y^2 = 100 - x^2
            // So y^2 = (100 - x^2) / 4
            // So |y| <= sqrt((100 - x^2) / 4)
            
            long xSquared = x * x;
            long remaining = 100 - xSquared;
            
            // If remaining is negative, no valid y exists
            if (remaining < 0)
                continue;
                
            // If remaining is not divisible by 4, no integer y exists
            if (remaining % 4 != 0)
                continue;
                
            long ySquared = remaining / 4;
            long yMax = (long)Math.Sqrt(ySquared);
            
            // Count all integer y values from -yMax to yMax
            count += 2 * yMax + 1;
        }
        
        return count;
    }
}
```

## Explanation

The problem asks us to count lattice points inside the ellipse $x^2 + 4y^2 = 100$.

1. **Mathematical Analysis**: For a point $(x,y)$ to be inside the ellipse, we need $x^2 + 4y^2 < 100$.

2. **Approach**: 
   - Iterate through all possible integer values of $x$ from $-10$ to $10$ (since $x^2 \leq 100$)
   - For each $x$, calculate the maximum value of $y$ such that $x^2 + 4y^2 < 100$
   - This gives us $4y^2 < 100 - x^2$, so $y^2 < (100 - x^2)/4$
   - Therefore $|y| < \sqrt{(100 - x^2)/4} = \sqrt{100 - x^2}/2$

3. **Counting**: For each valid $x$, count the integer values of $y$ from $-\lfloor y_{max} \rfloor$ to $\lfloor y_{max} \rfloor$, which is $2 \times \lfloor y_{max} \rfloor + 1$ points.

4. **Optimization**: We only consider cases where $(100 - x^2)$ is divisible by 4 to ensure $y$ can be an integer.

## Result
The number of lattice points inside the ellipse $x^2 + 4y^2 = 100$ is **1209**.
