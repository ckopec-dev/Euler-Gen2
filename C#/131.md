# Euler Problem 131 Solution in C#

## Problem Statement
There are some prime numbers that when added to a perfect cube result in another perfect cube. Find how many such primes exist where the prime is less than one million.

## Mathematical Analysis
Let's say we have a prime number `p` such that:
- `p + n³ = m³` where `n` and `m` are positive integers
- This can be rewritten as: `p = m³ - n³ = (m-n)(m² + mn + n²)`
- Since `p` is prime, either `m-n = 1` or `m-n = p`
- If `m-n = p`, then `m² + mn + n² = 1`, which is impossible for positive integers
- Therefore, `m-n = 1`, so `m = n+1`
- Substituting back: `p = (n+1)³ - n³ = 3n² + 3n + 1`

So we need to find primes of the form `3n² + 3n + 1` where `p < 1,000,000`.

## C# Solution

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        int count = 0;
        int limit = 1000000;
        
        // Generate primes up to limit using Sieve of Eratosthenes
        bool[] isPrime = SieveOfEratosthenes(limit);
        
        // Check for primes of the form 3n² + 3n + 1
        for (int n = 1; ; n++)
        {
            long primeCandidate = 3 * (long)n * n + 3 * n + 1;
            
            if (primeCandidate >= limit)
                break;
                
            if (isPrime[primeCandidate])
                count++;
        }
        
        Console.WriteLine($"Number of primes: {count}");
    }
    
    static bool[] SieveOfEratosthenes(int limit)
    {
        bool[] isPrime = new bool[limit + 1];
        for (int i = 2; i <= limit; i++)
            isPrime[i] = true;
            
        for (int i = 2; i * i <= limit; i++)
        {
            if (isPrime[i])
            {
                for (int j = i * i; j <= limit; j += i)
                    isPrime[j] = false;
            }
        }
        
        return isPrime;
    }
}
```

## Explanation

1. **Mathematical Insight**: Through algebraic manipulation, we derived that primes of the form `p = 3n² + 3n + 1` are the only primes that can be expressed as the difference of two consecutive cubes.

2. **Algorithm**:
   - Generate all primes up to 1,000,000 using the Sieve of Eratosthenes
   - For each positive integer n, calculate `3n² + 3n + 1`
   - Check if this number is prime
   - Count how many such primes are less than 1,000,000

3. **Optimization**: 
   - We use the Sieve of Eratosthenes for efficient prime checking
   - We stop the loop when the prime candidate exceeds our limit
   - We use `long` for the calculation to prevent integer overflow

## Result
The answer is **173** primes less than one million that can be expressed as the difference of two consecutive cubes.

This solution is efficient with O(n log log n) time complexity due to the sieve, where n is approximately 1000 (since we need n such that 3n² + 3n + 1 < 1,000,000).
