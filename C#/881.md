## Mathematical Analysis

The problem asks for the sum of all distinct values of f(n) where f(n) is the number of partitions of n into distinct positive integers.

For large values, we can use the pentagonal number theorem:
```
f(n) = sum_{k=1}^{∞} (-1)^{k+1} [f(n - k(3k-1)/2) + f(n - k(3k+1)/2)]
```

Where k(3k-1)/2 and k(3k+1)/2 are generalized pentagonal numbers.
