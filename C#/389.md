# Euler Problem 389 Solution in C#

## Problem Statement
Let $ M(n) $ be the number of ways to write $ n $ as a sum of powers of 2, where we keep track of the order of the summands. For example, $ M(4) = 2 $ since $ 4 = 4 = 2 + 2 $.

Let $ S(n) = \sum_{k=1}^{n} M(k) $. Find $ S(10^{10}) $.

## Solution Approach

This is a classic dynamic programming problem. The key insight is that $ M(n) $ represents the number of compositions of $ n $ using powers of 2 (where order matters).

We can solve this using generating functions or dynamic programming. Since we need to compute $ S(10^{10}) $, we need an efficient approach.

Let's use dynamic programming with the recurrence relation:
- $ M(0) = 1 $ (one way to make 0: empty sum)
- $ M(n) = \sum_{i=1}^{k} M(n - 2^i) $ where $ 2^i \leq n $

However, for large $ n $, we need to optimize this further.
