# Euler Problem 43 Solution in C#

## Problem Statement
The number 1406357289 is a 0 to 9 pandigital number because it uses all the digits 0 to 9 exactly once. The number also has a rather interesting sub-string divisibility property:

- d₂d₃d₄ = 406 is divisible by 2
- d₃d₄d₅ = 063 is divisible by 3
- d₄d₅d₆ = 635 is divisible by 5
- d₅d₆d₇ = 357 is divisible by 7
- d₆d₇d₈ = 572 is divisible by 11
- d₇d₈d₉ = 728 is divisible by 13
- d₈d₉d₁₀ = 289 is divisible by 17

Find the sum of all 0 to 9 pandigital numbers with this property.

## Solution

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        long sum = 0;
        int[] primes = { 2, 3, 5, 7, 11, 13, 17 };
        
        // Generate all permutations of digits 0-9
        var digits = Enumerable.Range(0, 10).ToArray();
        var permutations = GetPermutations(digits, 10);
        
        foreach (var perm in permutations)
        {
            string number = string.Join("", perm);
            
            // Skip numbers starting with 0 (not valid pandigital)
            if (number[0] == '0') continue;
            
            bool hasProperty = true;
            
            // Check each substring divisibility condition
            for (int i = 0; i < 7; i++)
            {
                int substringValue = int.Parse(number.Substring(i + 1, 3));
                if (substringValue % primes[i] != 0)
                {
                    hasProperty = false;
                    break;
                }
            }
            
            if (hasProperty)
            {
                sum += long.Parse(number);
            }
        }
        
        Console.WriteLine($"Sum of all 0-9 pandigital numbers with the property: {sum}");
    }
    
    // Generate all permutations of the given array
    static IEnumerable<int[]> GetPermutations(int[] array, int length)
    {
        if (length == 1)
        {
            yield return array;
        }
        else
        {
            for (int i = 0; i < length; i++)
            {
                foreach (var perm in GetPermutations(array, length - 1))
                {
                    yield return perm;
                }
                
                if (length % 2 == 1)
                {
                    Swap(array, 0, length - 1);
                }
                else
                {
                    Swap(array, i, length - 1);
                }
            }
        }
    }
    
    static void Swap(int[] array, int i, int j)
    {
        int temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }
}
```

## Alternative Optimized Solution

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        long sum = 0;
        int[] primes = { 2, 3, 5, 7, 11, 13, 17 };
        
        // Generate all valid permutations by building them step by step
        var results = new List<string>();
        GeneratePermutations("", "0123456789", primes, results);
        
        foreach (string result in results)
        {
            sum += long.Parse(result);
        }
        
        Console.WriteLine($"Sum of all 0-9 pandigital numbers with the property: {sum}");
    }
    
    static void GeneratePermutations(string prefix, string remaining, int[] primes, List<string> results)
    {
        if (remaining.Length == 0)
        {
            // Check if the complete number satisfies the property
            if (CheckProperty(prefix, primes))
            {
                results.Add(prefix);
            }
            return;
        }
        
        // Try each remaining digit
        for (int i = 0; i < remaining.Length; i++)
        {
            char digit = remaining[i];
            string newPrefix = prefix + digit;
            string newRemaining = remaining.Substring(0, i) + remaining.Substring(i + 1);
            
            // Early termination if prefix doesn't satisfy property
            if (prefix.Length >= 1 && prefix.Length <= 7)
            {
                int substringValue = int.Parse(prefix.Substring(1));
                if (substringValue % primes[prefix.Length - 1] != 0)
                {
                    continue; // Skip this branch
                }
            }
            
            GeneratePermutations(newPrefix, newRemaining, primes, results);
        }
    }
    
    static bool CheckProperty(string number, int[] primes)
    {
        // Check each substring divisibility
        for (int i = 0; i < 7; i++)
        {
            int substringValue = int.Parse(number.Substring(i + 1, 3));
            if (substringValue % primes[i] != 0)
            {
                return false;
            }
        }
        return true;
    }
}
```

## Output
The sum of all 0 to 9 pandigital numbers with the specified property is **16695334890**.

## Explanation

The solution works by:

1. **Generating permutations**: Create all possible arrangements of digits 0-9
2. **Checking divisibility property**: For each permutation, verify that:
   - The 3-digit substring starting at position 2 is divisible by 2
   - The 3-digit substring starting at position 3 is divisible by 3
   - And so on, up to position 10 with divisibility by 17
3. **Summing valid numbers**: Add all numbers that satisfy the property to the total

The optimized version uses early termination to avoid checking invalid branches in the permutation tree, making it more efficient than checking all permutations.
