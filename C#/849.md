# Euler Problem 849 Solution in C#

I'll solve Euler Problem 849, which asks for the sum of all positive integers that can be expressed as the sum of two positive perfect cubes in exactly 3 different ways.

## Problem Analysis

We need to find numbers that can be expressed as $a^3 + b^3$ where $a, b$ are positive integers, and this representation occurs in exactly 3 different ways.

## Solution Approach

1. Generate all possible sums of two positive cubes
2. Count how many ways each sum can be represented
3. Sum all numbers that have exactly 3 representations

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        // We need to find numbers that can be expressed as sum of two cubes in exactly 3 ways
        var cubeSums = new Dictionary<long, int>();
        
        // Set reasonable bounds - we'll check up to a reasonable limit
        // Since we're looking for numbers that can be represented in 3 ways,
        // we need to consider enough cubes to get meaningful results
        long limit = 1000000000000; // 10^12
        int maxCubeRoot = (int)Math.Ceiling(Math.Pow(limit, 1.0/3.0)) + 1000;
        
        // Generate all possible sums of two cubes
        for (long i = 1; i <= maxCubeRoot; i++)
        {
            long i3 = i * i * i;
            if (i3 > limit) break;
            
            for (long j = i; j <= maxCubeRoot; j++) // j >= i to avoid duplicates
            {
                long j3 = j * j * j;
                if (i3 + j3 > limit) break;
                
                long sum = i3 + j3;
                if (cubeSums.ContainsKey(sum))
                {
                    cubeSums[sum]++;
                }
                else
                {
                    cubeSums[sum] = 1;
                }
            }
        }
        
        // Find numbers with exactly 3 representations
        var result = cubeSums.Where(pair => pair.Value == 3)
                             .Select(pair => pair.Key)
                             .OrderBy(x => x);
        
        long total = result.Sum();
        Console.WriteLine($"Sum of all positive integers that can be expressed as sum of two positive cubes in exactly 3 ways: {total}");
        
        // Print some examples for verification
        Console.WriteLine("Some examples with exactly 3 representations:");
        foreach (var num in result.Take(10))
        {
            Console.WriteLine(num);
        }
    }
}
```
