# Euler Problem 56 Solution in C#

## Problem Statement
A googol (10^100) is a massive number: one followed by one-hundred zeros; 100^100 is almost unimaginably large: one followed by two-hundred zeros. Despite their size, the sum of the digits in each number is only 1.

Considering natural numbers of the form, a^b, where a, b < 100, what is the maximum digital sum?

## Solution

```csharp
using System;
using System.Numerics;

class Program
{
    static void Main()
    {
        int maxSum = 0;
        
        // Check all combinations of a and b where both are less than 100
        for (int a = 1; a < 100; a++)
        {
            for (int b = 1; b < 100; b++)
            {
                // Calculate a^b using BigInteger to handle large numbers
                BigInteger result = BigInteger.Pow(a, b);
                
                // Calculate the sum of digits
                int digitSum = GetDigitSum(result);
                
                // Update maximum if current sum is greater
                if (digitSum > maxSum)
                {
                    maxSum = digitSum;
                }
            }
        }
        
        Console.WriteLine($"Maximum digital sum: {maxSum}");
    }
    
    // Helper method to calculate sum of digits in a BigInteger
    static int GetDigitSum(BigInteger number)
    {
        int sum = 0;
        string numberStr = number.ToString();
        
        foreach (char digit in numberStr)
        {
            sum += (int)Char.GetNumericValue(digit);
        }
        
        return sum;
    }
}
```

## Explanation

1. **Approach**: We iterate through all possible combinations of `a` and `b` where both are less than 100 (1 to 99).

2. **BigInteger Usage**: Since the numbers can become extremely large (like 99^99), we use `BigInteger` from `System.Numerics` to handle arbitrary precision arithmetic.

3. **Digit Sum Calculation**: For each result `a^b`, we convert it to a string and sum up each digit character by converting it back to a numeric value.

4. **Optimization**: We keep track of the maximum digit sum encountered and update it as we find larger sums.

## Result
The maximum digital sum is **972**.

This occurs for the number 99^95, which produces a very large result whose digits sum to 972.
