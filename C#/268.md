# Euler Problem 268 Solution in C#

## Problem Statement
A number is considered "smooth" if all of its prime factors are less than or equal to a given limit. For example, 1000 = 2³ × 5³ is smooth for limit 5. 

We are to find the number of positive integers ≤ 10¹⁸ that are smooth for limit 100.

## Solution Approach
This is a classic inclusion-exclusion principle problem. We need to:
1. Find all primes up to 100
2. Use inclusion-exclusion to count numbers that are divisible by at least one prime > 100
3. Subtract from total to get smooth numbers

But actually, the correct interpretation is: we want numbers ≤ 10¹⁸ that are divisible by NO prime > 100, which means they're only divisible by primes ≤ 100.

Let me use the inclusion-exclusion principle correctly:
- Let P be the set of primes ≤ 100
- We want numbers ≤ 10¹⁸ that are NOT divisible by ANY prime in P
- This equals: 10¹⁸ - |A₁ ∪ A₂ ∪ ... ∪ Aₖ| where Aᵢ is set of numbers divisible by prime pᵢ

Using inclusion-exclusion:
|A₁ ∪ A₂ ∪ ... ∪ Aₖ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ...

## C# Implementation

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

public class Euler268
{
    public static void Main()
    {
        long limit = 100;
        long maxN = 1000000000000000000; // 10^18
        
        // Find all primes up to 100
        var primes = GetPrimes(limit);
        
        // Use inclusion-exclusion principle
        long result = maxN;
        int nPrimes = primes.Count;
        
        // Generate all possible combinations of primes using bit manipulation
        for (int mask = 1; mask < (1 << nPrimes); mask++)
        {
            long product = 1;
            int count = 0;
            
            for (int i = 0; i < nPrimes; i++)
            {
                if ((mask & (1 << i)) != 0)
                {
                    // Check for overflow
                    if (product > maxN / primes[i])
                        product = maxN + 1; // Mark as overflow
                    else
                        product *= primes[i];
                    count++;
                }
            }
            
            if (product <= maxN)
            {
                long countOfMultiples = maxN / product;
                if (count % 2 == 1)
                    result -= countOfMultiples;
                else
                    result += countOfMultiples;
            }
        }
        
        Console.WriteLine(result);
    }
    
    private static List<long> GetPrimes(long limit)
    {
        var primes = new List<long>();
        var isPrime = new bool[limit + 1];
        
        for (int i = 2; i <= limit; i++)
            isPrime[i] = true;
            
        for (long i = 2; i <= limit; i++)
        {
            if (isPrime[i])
            {
                primes.Add(i);
                for (long j = i * i; j <= limit; j += i)
                    isPrime[j] = false;
            }
        }
        
        return primes;
    }
}
```

## Explanation

1. **Prime Generation**: First, we generate all primes up to 100 using the Sieve of Eratosthenes.

2. **Inclusion-Exclusion Principle**: 
   - We want numbers ≤ 10¹⁸ that are NOT divisible by any prime > 100
   - This means we count numbers divisible by at least one prime > 100 and subtract from total
   - Using inclusion-exclusion: |A₁ ∪ A₂ ∪ ... ∪ Aₖ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ...

3. **Bit Manipulation**: We iterate through all possible combinations of primes using bit masks (2^k combinations where k is number of primes).

4. **Overflow Handling**: We check if the product would overflow 10¹⁸ before computing.

5. **Alternating Signs**: For each combination of i primes, we add or subtract based on whether i is odd or even.

The time complexity is O(2^k) where k is the number of primes ≤ 100 (which is 25), so it's feasible.
