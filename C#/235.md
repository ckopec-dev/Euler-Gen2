using System;

class Program
{
    static void Main()
    {
        // Euler Problem 235
        // Find the sum of the first 50 terms of the sequence where:
        // a_n = (1 + 1/n)^n for n = 1 to 50
        
        double sum = 0;
        
        for (int n = 1; n <= 50; n++)
        {
            double term = Math.Pow(1.0 + 1.0 / n, n);
            sum += term;
        }
        
        Console.WriteLine($"Sum of first 50 terms: {sum:F10}");
        Console.WriteLine($"Answer: {sum:F10}");
    }
}

## Explanation

The solution calculates the sum of the sequence where each term is defined as $(1 + \frac{1}{n})^n$ for $n$ from 1 to 50.

This sequence converges to $e$ (Euler's number) as $n$ approaches infinity, so the sum represents a partial sum of this convergent sequence.

**Time Complexity**: O(n) where n = 50
**Space Complexity**: O(1)
