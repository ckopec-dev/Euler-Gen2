# Euler Problem 38 Solution in C#

## Problem Statement
Take the number 192 and multiply it by each of 1, 2, and 3:
- 192 × 1 = 192
- 192 × 2 = 384
- 192 × 3 = 576

By concatenating each product we get the 1 to 9 pandigital, 192384576. We will call 192384576 the concatenated product of 192 and (1,2,3).

The same can be achieved by starting with 9 and multiplying by 1, 2, 3, 4, and 5, giving the pandigital, 918273645, which is the concatenated product of 9 and (1,2,3,4,5).

What is the largest 1 to 9 pandigital 9-digit number that can be formed as the concatenated product of an integer with (1,2, ..., n) where n > 1?

## Solution

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        Console.WriteLine("Euler Problem 38 Solution");
        Console.WriteLine($"Largest 1-9 pandigital: {Solve()}");
    }

    static long Solve()
    {
        long maxPandigital = 0;
        
        // We need to find a number that when multiplied by 1,2,3,...,n
        // produces a 9-digit pandigital number
        // The number should be less than 10000 because:
        // - If it's 5 digits or more, even with n=2, we'd get more than 9 digits
        // - If it's 4 digits, with n=2 we get 8 digits, with n=3 we get 12 digits
        // - So we need to check numbers up to 9999
        
        for (int i = 1; i < 10000; i++)
        {
            string concatenated = "";
            int n = 1;
            
            // Keep multiplying by 1, 2, 3, ... until we have at least 9 digits
            while (concatenated.Length < 9)
            {
                concatenated += (i * n).ToString();
                n++;
            }
            
            // Check if we have exactly 9 digits and it's pandigital
            if (concatenated.Length == 9 && IsPandigital(concatenated))
            {
                long pandigital = long.Parse(concatenated);
                if (pandigital > maxPandigital)
                {
                    maxPandigital = pandigital;
                }
            }
        }
        
        return maxPandigital;
    }
    
    static bool IsPandigital(string s)
    {
        // Check if string contains each digit from 1 to 9 exactly once
        if (s.Length != 9) return false;
        
        var digits = s.ToList();
        digits.Sort();
        
        // Should be "123456789"
        return new string(digits.ToArray()) == "123456789";
    }
}
```

## Alternative Implementation (More Efficient)

```csharp
using System;
using System.Text;

class Program
{
    static void Main()
    {
        Console.WriteLine("Euler Problem 38 Solution");
        Console.WriteLine($"Largest 1-9 pandigital: {Solve()}");
    }

    static long Solve()
    {
        long maxPandigital = 0;
        
        // Try numbers from 1 to 9999
        for (int num = 1; num < 10000; num++)
        {
            StringBuilder sb = new StringBuilder();
            int multiplier = 1;
            
            // Build concatenated product
            while (sb.Length < 9)
            {
                sb.Append(num * multiplier);
                multiplier++;
            }
            
            // Check if we have exactly 9 digits and it's pandigital
            if (sb.Length == 9 && IsPandigital(sb.ToString()))
            {
                long pandigital = long.Parse(sb.ToString());
                maxPandigital = Math.Max(maxPandigital, pandigital);
            }
        }
        
        return maxPandigital;
    }
    
    static bool IsPandigital(string s)
    {
        if (s.Length != 9) return false;
        
        // Check if it contains all digits 1-9 exactly once
        bool[] seen = new bool[10]; // Index 0 unused, 1-9 for digits
        
        foreach (char c in s)
        {
            int digit = c - '0';
            if (digit == 0 || seen[digit]) return false;
            seen[digit] = true;
        }
        
        // Check that we've seen all digits 1-9
        for (int i = 1; i <= 9; i++)
        {
            if (!seen[i]) return false;
        }
        
        return true;
    }
}
```

## Explanation

The solution works by:

1. **Iterating through potential base numbers**: We test numbers from 1 to 9999 (since larger numbers would produce more than 9 digits when multiplied by 2 or more).

2. **Building concatenated products**: For each base number, we multiply it by 1, 2, 3, ... and concatenate the results until we have 9 digits.

3. **Checking pandigital property**: We verify that the resulting 9-digit number contains each digit 1-9 exactly once.

4. **Tracking maximum**: We keep track of the largest valid pandigital number found.

The largest 1-9 pandigital that can be formed is **932718654**, which comes from the number 9327 multiplied by (1,2,3,4).
