# Euler Problem 526 Solution in C#

## Problem Statement
Let F(n) be the number of 1's in the binary representation of n.
Let G(n) be the number of 1's in the binary representation of F(n).
Let S(n) be the sum of G(i) for i from 1 to n.
Find S(10^12) mod 10^9.

## Solution Approach

This is a classic digit DP (Dynamic Programming) problem. We need to count the number of 1's in the binary representation of numbers from 1 to n, then count 1's in those counts, and sum them all up.
