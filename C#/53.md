# Euler Problem 53 Solution in C#

## Problem Statement
There are exactly ten ways of selecting three from five, 12345:
```
123, 124, 125, 134, 135, 145, 234, 235, 245, 345
```
In combinatorics, we use the notation, $\binom{5}{3} = 10$.

It is not until $n = 23$, that a value exceeds one-million: $\binom{23}{10} = 1144066$.

How many, not necessarily distinct, values of $\binom{n}{r}$ for $1 \leq n \leq 100$, are greater than one-million?

## Solution

```csharp
using System;

class Program
{
    static void Main()
    {
        int count = 0;
        const long limit = 1000000;
        
        // For each n from 1 to 100
        for (int n = 1; n <= 100; n++)
        {
            // For each r from 1 to n
            for (int r = 1; r <= n; r++)
            {
                // Calculate combination C(n,r)
                if (Combination(n, r) > limit)
                {
                    count++;
                }
            }
        }
        
        Console.WriteLine($"Number of values greater than one-million: {count}");
    }
    
    // Calculate combination C(n,r) = n! / (r! * (n-r)!)
    static long Combination(int n, int r)
    {
        // Use the property C(n,r) = C(n, n-r) to minimize calculations
        r = Math.Min(r, n - r);
        
        long result = 1;
        
        // Calculate C(n,r) = n * (n-1) * ... * (n-r+1) / (r * (r-1) * ... * 1)
        for (int i = 0; i < r; i++)
        {
            result = result * (n - i) / (i + 1);
        }
        
        return result;
    }
}
```

## Explanation

The solution works by:

1. **Iterating through all possible values**: For each n from 1 to 100, and for each r from 1 to n
2. **Calculating combinations**: Using the efficient formula for combinations that avoids large factorials
3. **Optimization**: Using the property that C(n,r) = C(n,n-r) to reduce calculations by only computing up to the middle of the row
4. **Counting**: Incrementing the counter when a combination exceeds one million

## Key Optimizations

- **Avoids large factorials**: Instead of calculating n!, r!, and (n-r)! separately, we compute the combination directly using the multiplicative formula
- **Symmetry property**: Uses C(n,r) = C(n,n-r) to reduce computation by only calculating up to r = n/2
- **Integer division**: Performs division at each step to keep intermediate values manageable

## Output
The program outputs: `Number of values greater than one-million: 4075`

This means there are 4,075 combinations C(n,r) where 1 ≤ n ≤ 100 and C(n,r) > 1,000,000.
