# Euler Problem 717 Solution in C#

## Problem Statement
Let $S(n)$ be the number of strings of length $n$ that contain the substring "AB" at least once, where the string is formed from the letters {A, B, C, D}.

Find $S(10^{12}) \bmod 1000000007$.

## Solution Approach

I'll use dynamic programming with matrix exponentiation to solve this efficiently for large n.

Let me define states:
- State 0: String that doesn't contain "AB" yet
- State 1: String that ends with "A" but doesn't contain "AB"
- State 2: String that contains "AB"
