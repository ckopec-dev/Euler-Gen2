# Euler Problem 74 Solution in C#

## Problem Statement
The number 145 is well known for the property that the sum of the factorial of its digits is equal to 145:
1! + 4! + 5! = 1 + 24 + 120 = 145

Perhaps less well known is 169, in that it produces the longest chain of numbers that link back to 169; it turns out that there are only three such loops that exist:
169 → 363601 → 1454 → 169
871 → 45361 → 871
872 → 45362 → 872

It is not difficult to prove that EVERY starting number will eventually get stuck in a loop. For example,
69 → 363600 → 1454 → 169 → 363601 (→ 1454)
78 → 45360 → 871 → 45361 (→ 871)
540 → 145 (→ 145)

Starting with 69 produces a chain of five non-repeating terms, but the longest non-repeating chain with a starting number below one million is sixty terms.

How many chains, with a starting number below one million, contain exactly sixty non-repeating terms?

## Solution

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        // Precompute factorials for digits 0-9
        long[] factorials = new long[10];
        for (int i = 0; i < 10; i++)
        {
            factorials[i] = Factorial(i);
        }

        int count = 0;
        HashSet<int> visited = new HashSet<int>();
        
        // For each number below one million
        for (int i = 1; i < 1000000; i++)
        {
            int current = i;
            visited.Clear();
            int chainLength = 0;
            
            // Follow the chain until we hit a repeated number
            while (!visited.Contains(current))
            {
                visited.Add(current);
                chainLength++;
                current = GetSumOfFactorialOfDigits(current, factorials);
            }
            
            // If chain length is exactly 60, increment count
            if (chainLength == 60)
            {
                count++;
            }
        }
        
        Console.WriteLine(count);
    }
    
    static long Factorial(int n)
    {
        if (n <= 1) return 1;
        long result = 1;
        for (int i = 2; i <= n; i++)
        {
            result *= i;
        }
        return result;
    }
    
    static int GetSumOfFactorialOfDigits(int number, long[] factorials)
    {
        int sum = 0;
        while (number > 0)
        {
            int digit = number % 10;
            sum += (int)factorials[digit];
            number /= 10;
        }
        return sum;
    }
}
```

## Explanation

1. **Precompute Factorials**: First, I calculate and store factorials for digits 0-9 to avoid recalculating them repeatedly.

2. **Main Loop**: For each number from 1 to 999,999:
   - Track visited numbers in a HashSet to detect cycles
   - Follow the chain by repeatedly calculating the sum of factorials of digits
   - Count the length of the chain until a repeated number is encountered
   - If the chain length equals exactly 60, increment the counter

3. **Helper Functions**:
   - `Factorial()`: Computes factorial of a number
   - `GetSumOfFactorialOfDigits()`: Calculates sum of factorials of digits in a number

4. **Cycle Detection**: Using a HashSet to track visited numbers allows us to efficiently detect when we've entered a cycle.

## Result
The answer is **402** chains with exactly sixty non-repeating terms.
