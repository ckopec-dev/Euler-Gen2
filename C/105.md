# Euler Problem 105 Solution in C

## Problem Statement
Let S(A) represent the sum of elements in set A of size n. We shall call a set A special if for any two non-empty disjoint subsets B and C, S(B) ≠ S(C). That is, sums of subsets cannot be equal.

For this problem, we need to find the sum of all elements in special sets from the given file.

## Solution

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_SETS 100
#define MAX_ELEMENTS 12

// Global variables to store the sets
int sets[MAX_SETS][MAX_ELEMENTS];
int set_sizes[MAX_SETS];
int num_sets = 0;

// Function to read sets from file
int read_sets(const char* filename) {
    FILE* file = fopen(filename, "r");
    if (!file) {
        printf("Error opening file\n");
        return 0;
    }
    
    char line[1000];
    while (fgets(line, sizeof(line), file)) {
        int i = 0;
        char* token = strtok(line, ",");
        while (token != NULL && i < MAX_ELEMENTS) {
            sets[num_sets][i] = atoi(token);
            i++;
            token = strtok(NULL, ",");
        }
        set_sizes[num_sets] = i;
        num_sets++;
    }
    
    fclose(file);
    return 1;
}

// Function to calculate sum of elements in a set
int sum_set(int* set, int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += set[i];
    }
    return sum;
}

// Function to generate all subsets and check if they have unique sums
int is_special(int* set, int size) {
    // For a set to be special, we need to check all pairs of non-empty disjoint subsets
    // This is computationally expensive, so we'll use a more efficient approach
    
    // First check if elements are in strictly increasing order (necessary condition)
    for (int i = 0; i < size - 1; i++) {
        if (set[i] >= set[i + 1]) {
            return 0;
        }
    }
    
    // For small sets, we can check all subset pairs
    // But we'll use a more mathematical approach based on the properties of special sets
    
    // A key property: if a set is special, then for any two disjoint subsets,
    // their sums must be different
    
    // For efficiency, we'll use the fact that for small sets, we can generate all
    // possible subset sums and check for duplicates
    
    // Generate all possible subset sums
    int total_subsets = 1 << size;
    int* sums = (int*)malloc(total_subsets * sizeof(int));
    int sum_count = 0;
    
    // Generate all subset sums
    for (int mask = 1; mask < total_subsets; mask++) {
        int current_sum = 0;
        for (int i = 0; i < size; i++) {
            if (mask & (1 << i)) {
                current_sum += set[i];
            }
        }
        sums[sum_count++] = current_sum;
    }
    
    // Check if all sums are unique
    for (int i = 0; i < sum_count; i++) {
        for (int j = i + 1; j < sum_count; j++) {
            if (sums[i] == sums[j]) {
                free(sums);
                return 0;
            }
        }
    }
    
    free(sums);
    return 1;
}

// More efficient approach for checking special sets
int is_special_optimized(int* set, int size) {
    // For a set to be special, it must satisfy the property that no two disjoint subsets
    // have the same sum. A known mathematical result states that if a set is sorted
    // and satisfies certain conditions, it's special.
    
    // Check if elements are in strictly increasing order
    for (int i = 0; i < size - 1; i++) {
        if (set[i] >= set[i + 1]) {
            return 0;
        }
    }
    
    // For a set to be special, we need to verify that no two disjoint subsets have equal sums
    // We can do this by checking all pairs of disjoint subsets
    int total_subsets = 1 << size;
    
    // We'll use a hash-like approach to check for duplicate sums
    // Since we're dealing with small sets, this is manageable
    
    // Generate all subset sums and check for duplicates
    int* subset_sums = (int*)malloc((total_subsets - 1) * sizeof(int));
    int* subset_masks = (int*)malloc((total_subsets - 1) * sizeof(int));
    int count = 0;
    
    for (int mask = 1; mask < total_subsets; mask++) {
        int sum = 0;
        for (int i = 0; i < size; i++) {
            if (mask & (1 << i)) {
                sum += set[i];
            }
        }
        subset_sums[count] = sum;
        subset_masks[count] = mask;
        count++;
    }
    
    // Check for duplicate sums
    for (int i = 0; i < count; i++) {
        for (int j = i + 1; j < count; j++) {
            if (subset_sums[i] == subset_sums[j]) {
                free(subset_sums);
                free(subset_masks);
                return 0;
            }
        }
    }
    
    free(subset_sums);
    free(subset_masks);
    return 1;
}

// Main function
int main() {
    // Read the sets from the file
    if (!read_sets("sets.txt")) {
        printf("Failed to read sets from file\n");
        return 1;
    }
    
    int total_sum = 0;
    
    // Check each set
    for (int i = 0; i < num_sets; i++) {
        if (is_special_optimized(sets[i], set_sizes[i])) {
            int set_sum = sum_set(sets[i], set_sizes[i]);
            total_sum += set_sum;
            printf("Set %d is special. Sum: %d\n", i + 1, set_sum);
        }
    }
    
    printf("Sum of all elements in special sets: %d\n", total_sum);
    
    return 0;
}
```

## Explanation

This solution addresses Euler Problem 105 by:

1. **Reading Sets**: The program reads sets from a file (assumed to be named "sets.txt") where each line contains comma-separated integers representing a set.

2. **Special Set Check**: For each set, we check if it's a special set by verifying that no two non-empty disjoint subsets have the same sum.

3. **Optimization**: The algorithm uses bit manipulation to generate all possible subsets and their sums, then checks for duplicates.

4. **Efficiency**: While the brute force approach has exponential complexity, for the given problem size (sets with up to 12 elements), it's computationally feasible.

## Key Points

- A set is special if for any two non-empty disjoint subsets, their sums are different
- The solution checks all possible subset combinations to ensure no two subsets have equal sums
- The program sums all elements in sets that satisfy the special property
- The time complexity is O(2^n) where n is the size of the set, which is acceptable for small sets

The actual "sets.txt" file needs to be provided with the problem data. This implementation assumes the file format where each line represents a set with comma-separated integers.
