## Problem Understanding

Euler Problem 331 asks us to find the number of ways to tile a 3×2^n rectangle with 2×1 dominoes, where each domino can be placed either horizontally or vertically.

Let me analyze the pattern and solve it systematically.

## Mathematical Analysis

First, let me understand the recurrence relation for tiling a 3×2^n rectangle with 2×1 dominoes.

Let f(n) be the number of ways to tile a 3×2^n rectangle with 2×1 dominoes.

For n=0: 3×1 rectangle - 1 way (vertical dominoes)
For n=1: 3×2 rectangle - 3 ways
For n=2: 3×4 rectangle - 11 ways

The recurrence relation is: f(n) = 4×f(n-1) - f(n-2)

## C Implementation

```c
#include <stdio.h>
#include <stdlib.h>

// Function to calculate the number of ways to tile 3×2^n rectangle
long long solve(int n) {
    if (n == 0) return 1;
    if (n == 1) return 3;
    
    // Use recurrence relation: f(n) = 4*f(n-1) - f(n-2)
    long long prev2 = 1;  // f(0)
    long long prev1 = 3;  // f(1)
    long long current;
    
    for (int i = 2; i <= n; i++) {
        current = 4 * prev1 - prev2;
        prev2 = prev1;
        prev1 = current;
    }
    
    return current;
}

int main() {
    // Calculate for n = 13 (since 2^13 = 8192)
    int n = 13;
    long long result = solve(n);
    
    printf("The number of ways to tile a 3×2^%d rectangle is: %lld\n", n, result);
    
    // Let's also show the pattern for smaller values
    printf("\nPattern verification:\n");
    for (int i = 0; i <= 5; i++) {
        printf("f(%d) = %lld\n", i, solve(i));
    }
    
    return 0;
}
```
