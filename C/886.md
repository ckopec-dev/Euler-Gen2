# Euler Problem 886 Solution in C

I'll solve Euler Problem 886, which asks for the sum of all distinct values of a specific function over a range.

Let me first understand what the problem is asking for, then implement it in C.

## Problem Understanding

Euler Problem 886 asks us to find the sum of all distinct values of the function:
$$f(n) = \left\lfloor \frac{n}{\lfloor \sqrt{n} \rfloor} \right\rfloor$$
for all positive integers $n$ from 1 to 10^15.

## Approach

1. We need to analyze the function $f(n) = \left\lfloor \frac{n}{\lfloor \sqrt{n} \rfloor} \right\rfloor$
2. For each value of $\lfloor \sqrt{n} \rfloor = k$, we need to find the range of $n$ values that produce the same $f(n)$ value
3. We can group numbers by their floor of square root and calculate the distinct values efficiently

## C Implementation

```c
#include <stdio.h>
#include <math.h>
#include <stdint.h>

// Function to calculate sum of all distinct values of f(n)
// where f(n) = floor(n / floor(sqrt(n)))
uint64_t solve_euler_886() {
    uint64_t result = 0;
    uint64_t limit = 1000000000000000ULL; // 10^15
    
    uint64_t k = 1;
    uint64_t prev_sum = 0;
    
    // For each value of floor(sqrt(n)) = k
    while (k * k <= limit) {
        uint64_t start_n = (k * k);
        uint64_t end_n = ((k + 1) * (k + 1)) - 1;
        
        // If end_n exceeds our limit, adjust it
        if (end_n > limit) {
            end_n = limit;
        }
        
        // For this range of n, floor(sqrt(n)) = k
        // So f(n) = floor(n / k)
        // The minimum value of f(n) in this range is floor(start_n / k)
        // The maximum value of f(n) in this range is floor(end_n / k)
        
        uint64_t min_f = start_n / k;
        uint64_t max_f = end_n / k;
        
        // Add all distinct values from min_f to max_f
        for (uint64_t f_val = min_f; f_val <= max_f; f_val++) {
            result += f_val;
        }
        
        k++;
    }
    
    return result;
}

// More efficient approach
uint64_t solve_euler_886_optimized() {
    uint64_t result = 0;
    uint64_t limit = 1000000000000000ULL; // 10^15
    
    uint64_t k = 1;
    
    while (k * k <= limit) {
        uint64_t start_n = k * k;
        uint64_t end_n = (k + 1) * (k + 1) - 1;
        
        if (end_n > limit) {
            end_n = limit;
        }
        
        // For this range, floor(sqrt(n)) = k
        // So f(n) = floor(n / k)
        // The range of f(n) values is from floor(start_n / k) to floor(end_n / k)
        uint64_t min_f = start_n / k;
        uint64_t max_f = end_n / k;
        
        // Sum of arithmetic sequence from min_f to max_f
        if (min_f <= max_f) {
            // Sum = (number of terms) * (first + last) / 2
            uint64_t count = max_f - min_f + 1;
            uint64_t sum = count * (min_f + max_f) / 2;
            result += sum;
        }
        
        k++;
    }
    
    return result;
}

           (unsigned long long)answer);
    
    return 0;
}
```

## Explanation of the Solution

The key insight is to group numbers by their floor of square root:

1. For numbers $n$ where $\lfloor \sqrt{n} \rfloor = k$, we have $k^2 \leq n < (k+1)^2$
2. For these numbers, $f(n) = \left\lfloor \frac{n}{k} \right\rfloor$
3. The minimum value of $f(n)$ in this range is $\left\lfloor \frac{k^2}{k} \right\rfloor = k$
4. The maximum value of $f(n)$ in this range is $\left\lfloor \frac{(k+1)^2-1}{k} \right\rfloor$

The optimized approach calculates the arithmetic sum directly rather than iterating through each value.

#include <stdio.h>

// Even more mathematical approach
uint64_t solve_euler_886_math() {
    uint64_t result = 0;
    uint64_t limit = 1000000000000000ULL;
    
    uint64_t k = 1;
    uint64_t n = 1;
    
    // Process each group where floor(sqrt(n)) = k
    while (n <= limit) {
        uint64_t k_squared = k * k;
        uint64_t next_k_squared = (k + 1) * (k + 1);
        
        // Process all n in range [k^2, min(limit, (k+1)^2 - 1)]
        uint64_t end_n = (next_k_squared <= limit) ? next_k_squared - 1 : limit;
        
        // For this range, f(n) = floor(n / k)
        // The distinct values are floor(k^2/k) to floor(end_n/k)
        // Which is k to floor(end_n/k)
        
        uint64_t min_f = k;
        uint64_t max_f = end_n / k;
        
        // Sum of arithmetic sequence
        if (min_f <= max_f) {
            uint64_t count = max_f - min_f + 1;
            uint64_t sum = count * (min_f + max_f) / 2;
            result += sum;
        }
        
        n = next_k_squared;
        k++;
    }
    
    return result;
}

int main() {

    printf("Answer: %llu\n", (unsigned long long)answer);
    
    return 0;
}

The solution efficiently computes the sum by recognizing that we can group numbers by their floor of square root and calculate the contribution of each group mathematically rather than iterating through every single number up to 10^15.
