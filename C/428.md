# Euler Problem 428 Solution in C

I'll solve Euler Problem 428, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

Euler Problem 428 asks us to find the number of ways to write a positive integer n as a sum of powers of 2, where each power of 2 can be used at most twice.

For example, for n = 10:
- 10 = 8 + 2 = 2³ + 2¹
- 10 = 4 + 4 + 2 = 2² + 2² + 2¹  
- 10 = 2 + 2 + 2 + 2 + 2 = 2¹ + 2¹ + 2¹ + 2¹ + 2¹

## Approach

I'll use dynamic programming with memoization. The key insight is that we can use each power of 2 at most twice, so we need to track:
- The remaining sum to reach
- The maximum power of 2 we can use (to avoid counting permutations)

## Solution

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// Memoization table
long long memo[1000001][20]; // memo[sum][max_power_index]

// Function to calculate number of ways to represent n using powers of 2
// with each power used at most twice
long long count_ways(int n, int max_power) {
    // Base cases
    if (n == 0) return 1;
    if (n < 0 || max_power < 0) return 0;
    
    // Check memoization table
    if (memo[n][max_power] != -1) {
        return memo[n][max_power];
    }
    
    long long ways = 0;
    int power_of_2 = 1 << max_power; // 2^max_power
    
    // We can use 0, 1, or 2 of the current power of 2
    for (int count = 0; count <= 2 && count * power_of_2 <= n; count++) {
        ways += count_ways(n - count * power_of_2, max_power - 1);
    }
    
    memo[n][max_power] = ways;
    return ways;
}

// Main function to solve Euler Problem 428
long long solve_euler_428(int n) {
    // Initialize memoization table
    for (int i = 0; i <= n; i++) {
        for (int j = 0; j < 20; j++) {
            memo[i][j] = -1;
        }
    }
    
    // Find maximum power of 2 needed
    int max_power = 0;
    int temp = n;
    while (temp > 0) {
        temp >>= 1;
        max_power++;
    }
    
    return count_ways(n, max_power);
}

int main() {
    // For the actual Euler problem, we need to find the answer for a specific value
    // Since the problem asks for the answer to the specific problem, we'll compute it
    int n = 1000000; // This is typically the value used in the problem
    
    printf("Solving Euler Problem 428...\n");
    printf("Number of ways to write %d as sum of powers of 2 (each used at most twice):\n", n);
    
    long long result = solve_euler_428(n);
    printf("Result: %lld\n", result);
    
    // Let's also test with smaller values to verify correctness
    printf("\nVerification with smaller values:\n");
    printf("n=1: %lld ways\n", solve_euler_428(1));
    printf("n=2: %lld ways\n", solve_euler_428(2));
    printf("n=3: %lld ways\n", solve_euler_428(3));
    printf("n=4: %lld ways\n", solve_euler_428(4));
    
    return 0;
}
```

Here's a more optimized version that handles the specific constraints better:

```c
#include <string.h>

// Memoization table

// Function to calculate number of ways to represent n using powers of 2

    }
    
    memo[n][max_power] = ways;
    return ways;
}

// Precompute for efficiency
long long solve_euler_428() {
    // Initialize memoization table
    memset(memo, -1, sizeof(memo));
    
    // For Euler Problem 428, the specific value is 1000000
    int n = 1000000;
    
    // Find maximum power of 2 needed
    int max_power = 0;
    int temp = n;
    while (temp > 0) {
        temp >>= 1;
        max_power++;
    }
    
    return count_ways(n, max_power);
}

int main() {
    printf("Euler Problem 428 Solution\n");
    printf("==========================\n");
    
    long long result = solve_euler_428();
    printf("Answer: %lld\n", result);
    
    return 0;
}
```

## Explanation of the Solution

1. **Dynamic Programming Approach**: We use memoization to avoid recalculating the same subproblems.

2. **State Definition**: For each state, we track:
   - The remaining sum to reach
   - The maximum power of 2 we can use

3. **Transition**: For each power of 2, we can use it 0, 1, or 2 times (since each can be used at most twice).

4. **Base Cases**: 
   - If sum is 0, we found one valid way
   - If sum is negative or we've exhausted all powers, return 0

5. **Memoization**: We store results in a 2D array to avoid recomputation.

The time complexity is O(n × log n) where n is the target number, and space complexity is O(n × log n) for the memoization table.

The solution correctly handles the constraint that each power of 2 can be used at most twice, which makes this a variant of the classic coin change problem with limited coins.
