# Euler Problem 145 Solution in C

## Problem Statement
How many reversible numbers are there below one-billion (10⁹)?

A number is reversible if the sum of the number and its reverse contains only odd digits.

## Solution

```c
#include <stdio.h>
#include <stdbool.h>

// Function to reverse a number
long long reverse_number(long long n) {
    long long reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return reversed;
}

// Function to check if a number is reversible
bool is_reversible(long long n) {
    long long sum = n + reverse_number(n);
    
    // Check if all digits in sum are odd
    while (sum > 0) {
        if ((sum % 10) % 2 == 0) {
            return false;
        }
        sum /= 10;
    }
    return true;
}

int main() {
    int count = 0;
    long long limit = 1000000000LL; // 10^9
    
    // We only need to check numbers that don't end in 0
    // because their reverse would have leading zeros
    for (long long i = 1; i < limit; i++) {
        if (i % 10 != 0) {  // Skip numbers ending in 0
            if (is_reversible(i)) {
                count++;
            }
        }
    }
    
    printf("Number of reversible numbers below one billion: %d\n", count);
    return 0;
}
```

## Explanation

The solution works as follows:

1. **reverse_number()**: This function takes a number and returns its reverse by repeatedly extracting the last digit and building the reversed number.

2. **is_reversible()**: This function checks if a number is reversible by:
   - Adding the number to its reverse
   - Checking if all digits in the sum are odd
   - Returning false if any even digit is found

3. **Main logic**: 
   - We iterate through all numbers from 1 to 999,999,999
   - Skip numbers ending in 0 (since their reverse would have leading zeros)
   - For each valid number, check if it's reversible
   - Count all reversible numbers

## Key Insights

- Numbers ending in 0 cannot be reversible because their reverse would start with 0, which doesn't count as a valid digit in the sum
- The sum of a number and its reverse must contain only odd digits
- For example: 36 + 63 = 99 (all odd digits) → reversible
- For example: 12 + 21 = 33 (all odd digits) → reversible
- For example: 13 + 31 = 44 (even digits) → not reversible

## Output
The program will output: `Number of reversible numbers below one billion: 608720`

This is the count of all reversible numbers less than one billion.
