# Euler Problem 499 Solution in C

I'll solve Euler Problem 499, which is about finding the expected number of draws from a uniform distribution until the sum exceeds 1.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

// Function to calculate factorial
long double factorial(int n) {
    if (n <= 1) return 1.0;
    long double result = 1.0;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

// Function to calculate the expected number of draws
// For the sum of uniform random variables to exceed 1,
// the expected number of draws is e (Euler's number)
long double expected_draws() {
    // The mathematical result for this problem is e = 2.71828...
    // This can be derived from the theory of uniform distributions
    return M_E;
}

// Alternative implementation using the series expansion
// E[N] = 1 + 1/1! + 1/2! + 1/3! + ... = e
long double calculate_e_series(int terms) {
    long double sum = 0.0;
    for (int i = 0; i < terms; i++) {
        sum += 1.0 / factorial(i);
    }
    return sum;
}

int main() {
    printf("Euler Problem 499 Solution\n");
    printf("==========================\n\n");
    
    // Calculate using mathematical constant
    long double result1 = expected_draws();
    printf("Using mathematical constant e: %.15Lf\n", result1);
    
    // Calculate using series expansion (1 + 1/1! + 1/2! + ...)
    int terms = 20;
    long double result2 = calculate_e_series(terms);
    printf("Using series expansion (%d terms): %.15Lf\n", terms, result2);

    printf("20 terms: 2.718281828459045\n");

    printf("This is approximately %.10f\n", (double)result1);
```

## Mathematical Explanation

Euler Problem 499 asks for the expected number of draws from a uniform distribution [0,1] until the sum exceeds 1.

**Mathematical Solution:**

The key insight is that this problem relates to the **uniform distribution** and the **exponential function**.

Let $E(n)$ be the expected number of draws needed when the sum is less than 1.

Using the theory of uniform random variables, it can be shown that:

$$E[N] = \sum_{n=0}^{\infty} \frac{1}{n!} = e$$

This is because the probability that the sum of $n$ uniform random variables is less than 1 is $\frac{1}{n!}$, and the expected value is the sum of these probabilities.

## Key Points:

1. The expected number of draws is **e** (Euler's number)
2. This can be computed as $e = \sum_{n=0}^{\infty} \frac{1}{n!}$
3. The value is approximately **2.718281828459045**
