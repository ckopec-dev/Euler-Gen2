# Euler Problem 251 Solution in C

I'll solve Euler Problem 251, which asks for the number of ways to write a number as a sum of cubes of integers.

## Problem Statement
Find the number of ways to write a number n as a sum of cubes of positive integers, where each cube can be used multiple times.

## Solution Approach
I'll use dynamic programming with memoization to count the number of representations.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_N 1000000
#define MAX_CUBE 100

// Memoization table
long long dp[MAX_N + 1];
long long cubes[MAX_CUBE];
int cube_count;

// Function to generate cubes up to MAX_N
void generate_cubes() {
    cube_count = 0;
    long long cube = 1;
    while (cube <= MAX_N) {
        cubes[cube_count++] = cube;
        cube *= (cube_count + 1);
    }
}

// Function to count representations using dynamic programming
long long count_representations(int n) {
    // Initialize dp array
    memset(dp, 0, sizeof(dp));
    dp[0] = 1; // One way to make 0 (use nothing)
    
    // For each cube, update the dp array
    for (int i = 0; i < cube_count && cubes[i] <= n; i++) {
        long long cube = cubes[i];
        for (int j = cube; j <= n; j++) {
            dp[j] += dp[j - cube];
        }
    }
    
    return dp[n];
}

int main() {
    // Generate cubes
    generate_cubes();
    
    // Test with smaller values to verify
    printf("Number of representations for small values:\n");
    for (int i = 1; i <= 10; i++) {
        printf("n = %d: %lld ways\n", i, count_representations(i));
    }
    
    // For the actual problem, we need to find the answer for a specific n
    // Since the problem doesn't specify n, let's compute for a reasonable value
    int target = 1000;
    printf("\nNumber of ways to write %d as sum of cubes: %lld\n", 
           target, count_representations(target));
    
    return 0;
}
```

## Explanation

The solution works as follows:

1. **Cube Generation**: First, we generate all perfect cubes up to the maximum value we need to consider.

2. **Dynamic Programming**: We use a DP approach where `dp[i]` represents the number of ways to represent the integer `i` as a sum of cubes.

3. **Base Case**: `dp[0] = 1` because there's one way to make 0 (using no cubes).

4. **Transition**: For each cube `c`, we update all positions `j` where `j ≥ c` by adding `dp[j-c]` to `dp[j]`.

5. **Result**: The final answer is stored in `dp[n]`.

## Key Features

- **Efficient**: Uses dynamic programming with O(n × k) time complexity where k is the number of cubes
- **Memory Optimized**: Uses a single DP array
- **Scalable**: Can handle large values efficiently
