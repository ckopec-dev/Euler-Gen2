# Euler Problem 28 Solution in C

Euler Problem 28 asks for the sum of the numbers on the diagonals of a 1001×1001 spiral grid, where numbers are arranged in a clockwise spiral starting from 1 at the center.

## Analysis

Looking at the spiral pattern:
- Size 1×1: sum = 1
- Size 3×3: sum = 1 + 3 + 5 + 7 + 9 = 25
- Size 5×5: sum = 25 + 13 + 17 + 21 + 25 = 91

The pattern shows that for each layer (starting from the outermost), we add 4 numbers that form a square. These numbers can be calculated based on the size of the spiral.

## Solution

```c
#include <stdio.h>

int main() {
    int size = 1001;
    long long sum = 1; // Start with the center element
    
    // For each layer starting from size 3
    for (int layer = 3; layer <= size; layer += 2) {
        // The four corners of the current layer
        long long corner1 = layer * layer;                    // Top-right
        long long corner2 = corner1 - (layer - 1);           // Top-left
        long long corner3 = corner2 - (layer - 1);           // Bottom-left
        long long corner4 = corner3 - (layer - 1);           // Bottom-right
        
        // Add all four corners to the sum
        sum += corner1 + corner2 + corner3 + corner4;
    }
    
    printf("Sum of diagonals: %lld\n", sum);
    return 0;
}
```

## Explanation

1. **Initialization**: Start with `sum = 1` since the center element (1) is always part of the diagonal sum.

2. **Layer-by-layer approach**: For each odd-sized layer starting from 3×3 up to 1001×1001:
   - Calculate the four corner values of that layer
   - Add them to the running sum

3. **Corner calculation**: For a layer of size `n`:
   - Top-right corner: `n²`
   - Each subsequent corner decreases by `(n-1)`
   - The four corners are: `n²`, `n²-(n-1)`, `n²-2(n-1)`, `n²-3(n-1)`

4. **Optimization**: We only need to consider odd-sized layers since the spiral is always square and odd-sized.

## Output
```
Sum of diagonals: 669171001
```

The solution has O(n) time complexity where n = 1001, and O(1) space complexity.
