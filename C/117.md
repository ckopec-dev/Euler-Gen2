# Euler Problem 117 Solution in C

Euler Problem 117 asks: "Using a combination of grey square tiles and oblong tiles chosen from: red tiles (size two), green tiles (size three), and blue tiles (size four), how many ways can a row measuring fifty units in length be tiled?"

This is a dynamic programming problem where we need to count the number of ways to tile a row of length n using tiles of sizes 1, 2, 3, and 4.

```c
#include <stdio.h>
#include <stdlib.h>

long long int solve_euler_117(int n) {
    // dp[i] represents number of ways to tile a row of length i
    long long int *dp = (long long int*)calloc(n + 1, sizeof(long long int));
    
    // Base cases
    dp[0] = 1;  // One way to tile empty row (use no tiles)
    
    // For each position from 1 to n
    for (int i = 1; i <= n; i++) {
        // Place a 1x1 tile (grey square)
        if (i >= 1) {
            dp[i] += dp[i - 1];
        }
        
        // Place a 2x1 tile (red)
        if (i >= 2) {
            dp[i] += dp[i - 2];
        }
        
        // Place a 3x1 tile (green)
        if (i >= 3) {
            dp[i] += dp[i - 3];
        }
        
        // Place a 4x1 tile (blue)
        if (i >= 4) {
            dp[i] += dp[i - 4];
        }
    }
    
    int result = dp[n];
    free(dp);
    return result;
}

int main() {
    int n = 50;
    long long int result = solve_euler_117(n);
    printf("The number of ways to tile a row of length %d is: %lld\n", n, result);
    return 0;
}
```

## Explanation

The solution uses dynamic programming with the following approach:

1. **State Definition**: `dp[i]` represents the number of ways to tile a row of length `i`.

2. **Base Case**: `dp[0] = 1` (there's one way to tile an empty row - use no tiles).

3. **Recurrence Relation**: For each position `i`, we can:
   - Place a 1×1 grey square tile: contributes `dp[i-1]` ways
   - Place a 2×1 red tile: contributes `dp[i-2]` ways  
   - Place a 3×1 green tile: contributes `dp[i-3]` ways
   - Place a 4×1 blue tile: contributes `dp[i-4]` ways

4. **Final Answer**: `dp[50]` gives us the number of ways to tile a row of length 50.

## Time and Space Complexity
- **Time Complexity**: O(n) where n = 50
- **Space Complexity**: O(n) for the dp array
