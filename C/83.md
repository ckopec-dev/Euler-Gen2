# Euler Problem 83 Solution in C

## Problem Statement
In the 5 by 5 matrix below, the minimal path sum from the top left to the bottom right, by moving left, right, up, and down, is 2297. Find the minimal path sum from the top left to the bottom right by moving left, right, up, and down.

## Solution Approach
This is a shortest path problem that can be solved using Dijkstra's algorithm. We'll use a priority queue to efficiently find the minimum cost path from the top-left to bottom-right corner.

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

#define MAX_SIZE 80
#define INF INT_MAX

// Structure to represent a cell in the grid
typedef struct {
    int x, y, distance;
} Cell;

// Structure for priority queue (min heap)
typedef struct {
    Cell* data;
    int size;
    int capacity;
} PriorityQueue;

// Function to create a new priority queue
PriorityQueue* createPriorityQueue(int capacity) {
    PriorityQueue* pq = (PriorityQueue*)malloc(sizeof(PriorityQueue));
    pq->data = (Cell*)malloc(sizeof(Cell) * capacity);
    pq->size = 0;
    pq->capacity = capacity;
    return pq;
}

// Function to swap two cells
void swap(Cell* a, Cell* b) {
    Cell temp = *a;
    *a = *b;
    *b = temp;
}

// Function to maintain min heap property
void heapifyUp(PriorityQueue* pq, int index) {
    if (index == 0) return;
    
    int parent = (index - 1) / 2;
    if (pq->data[parent].distance > pq->data[index].distance) {
        swap(&pq->data[parent], &pq->data[index]);
        heapifyUp(pq, parent);
    }
}

// Function to maintain min heap property from top down
void heapifyDown(PriorityQueue* pq, int index) {
    int smallest = index;
    int left = 2 * index + 1;
    int right = 2 * index + 2;
    
    if (left < pq->size && pq->data[left].distance < pq->data[smallest].distance)
        smallest = left;
    
    if (right < pq->size && pq->data[right].distance < pq->data[smallest].distance)
        smallest = right;
    
    if (smallest != index) {
        swap(&pq->data[index], &pq->data[smallest]);
        heapifyDown(pq, smallest);
    }
}

// Function to insert a cell into priority queue
void enqueue(PriorityQueue* pq, Cell cell) {
    if (pq->size >= pq->capacity) return;
    
    pq->data[pq->size] = cell;
    pq->size++;
    heapifyUp(pq, pq->size - 1);
}

// Function to extract minimum element
Cell dequeue(PriorityQueue* pq) {
    if (pq->size <= 0) {
        Cell empty = {-1, -1, INF};
        return empty;
    }
    
    Cell min = pq->data[0];
    pq->data[0] = pq->data[pq->size - 1];
    pq->size--;
    heapifyDown(pq, 0);
    
    return min;
}

// Function to check if queue is empty
int isEmpty(PriorityQueue* pq) {
    return pq->size == 0;
}

// Function to get neighbors of a cell
void getNeighbors(int x, int y, int** grid, int rows, int cols, Cell* neighbors, int* count) {
    *count = 0;
    
    // Up
    if (x > 0) {
        neighbors[(*count)].x = x - 1;
        neighbors[(*count)].y = y;
        (*count)++;
    }
    
    // Down
    if (x < rows - 1) {
        neighbors[(*count)].x = x + 1;
        neighbors[(*count)].y = y;
        (*count)++;
    }
    
    // Left
    if (y > 0) {
        neighbors[(*count)].x = x;
        neighbors[(*count)].y = y - 1;
        (*count)++;
    }
    
    // Right
    if (y < cols - 1) {
        neighbors[(*count)].x = x;
        neighbors[(*count)].y = y + 1;
        (*count)++;
    }
}

int solveEuler83() {
    // Read the 80x80 grid from input
    int grid[MAX_SIZE][MAX_SIZE];
    FILE* file = fopen("matrix.txt", "r");
    
    if (file == NULL) {
        printf("Error opening file\n");
        return -1;
    }
    
    for (int i = 0; i < MAX_SIZE; i++) {
        for (int j = 0; j < MAX_SIZE; j++) {
            fscanf(file, "%d", &grid[i][j]);
        }
    }
    fclose(file);
    
    int rows = MAX_SIZE;
    int cols = MAX_SIZE;
    
    // Distance array to store minimum distances
    int distance[MAX_SIZE][MAX_SIZE];
    
    // Initialize distances to infinity
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            distance[i][j] = INF;
        }
    }
    
    // Priority queue for Dijkstra's algorithm
    PriorityQueue* pq = createPriorityQueue(rows * cols);
    
    // Start from top-left corner
    distance[0][0] = grid[0][0];
    Cell start = {0, 0, grid[0][0]};
    enqueue(pq, start);
    
    // Directions: up, down, left, right
    int dx[] = {-1, 1, 0, 0};
    int dy[] = {0, 0, -1, 1};
    
    // Dijkstra's algorithm
    while (!isEmpty(pq)) {
        Cell current = dequeue(pq);
        
        int x = current.x;
        int y = current.y;
        int currentDist = current.distance;
        
        // If we reached the destination
        if (x == rows - 1 && y == cols - 1) {
            return currentDist;
        }
        
        // Check all four neighbors
        for (int i = 0; i < 4; i++) {
            int newX = x + dx[i];
            int newY = y + dy[i];
            
            // Check bounds
            if (newX >= 0 && newX < rows && newY >= 0 && newY < cols) {
                int newDist = currentDist + grid[newX][newY];
                
                // If we found a shorter path
                if (newDist < distance[newX][newY]) {
                    distance[newX][newY] = newDist;
                    Cell neighbor = {newX, newY, newDist};
                    enqueue(pq, neighbor);
                }
            }
        }
    }
    
    return distance[rows - 1][cols - 1];
}

int main() {
    int result = solveEuler83();
    printf("The minimal path sum is: %d\n", result);
    return 0;
}
```

## Explanation

This solution uses Dijkstra's algorithm to find the shortest path in the grid:

1. **Data Structures**:
   - A 2D array `distance` to track the minimum distance to each cell
   - A priority queue (min heap) to efficiently get the cell with minimum distance
   - A `Cell` structure to represent coordinates and distances

2. **Algorithm**:
   - Initialize all distances to infinity except the starting cell
   - Add the starting cell to the priority queue
   - While the queue is not empty:
     - Extract the cell with minimum distance
     - For each neighbor, calculate the new distance
     - If this distance is better than the current distance, update it and add to queue
   - Return the distance to the bottom-right cell

3. **Time Complexity**: O(mn log(mn)) where m and n are the dimensions of the grid
4. **Space Complexity**: O(mn) for the distance array and priority queue

The solution reads the 80×80 matrix from a file named "matrix.txt" and returns the minimal path sum from top-left to bottom-right, moving in all four directions.
