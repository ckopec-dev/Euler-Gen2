# Euler Problem 504 Solution in C

## Problem Statement
The problem asks us to find the number of lattice points inside a quadrilateral defined by four points: (0,0), (a,b), (a+c,b+d), (c,d) where a, b, c, d are positive integers.

## Approach
We need to count lattice points inside the quadrilateral using Pick's theorem:
- Area = (a+d)(b+c) - ac - bd
- Boundary points = gcd(a,b) + gcd(c,d) + gcd(a+c,b+d) + 1
- Interior points = Area - (Boundary points-1)/2

## C Implementation

```c
#include <stdio.h>
#include <stdlib.h>

// Function to calculate greatest common divisor
long long gcd(long long a, long long b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// Function to calculate the number of lattice points
long long count_lattice_points(long long a, long long b, long long c, long long d) {
    // Calculate area using the shoelace formula
    long long area = (a + d) * (b + c) - a * c - b * d;
    
    // Calculate boundary points
    long long boundary = gcd(a, b) + gcd(c, d) + gcd(a + c, b + d) + 1;
    
    // Using Pick's theorem: I = A - (B-1)/2 where I is interior points, A is area, B is boundary points
    long long interior = area - (boundary - 1) / 2;
    
    return interior;
}

int main() {
    long long limit = 100;
    long long count = 0;
    
    // Iterate through all possible values of a, b, c, d
    for (long long a = 1; a <= limit; a++) {
        for (long long b = 1; b <= limit; b++) {
            for (long long c = 1; c <= limit; c++) {
                for (long long d = 1; d <= limit; d++) {
                    long long points = count_lattice_points(a, b, c, d);
                    // Check if the number of interior lattice points is a perfect square
                    long long sqrt_points = (long long)(sqrt(points));
                    if (sqrt_points * sqrt_points == points) {
                        count++;
                    }
                }
            }
        }
    }
    
    printf("Answer: %lld\n", count);
    return 0;
}
```

## Optimized Version

Since the problem is computationally expensive, here's a more efficient approach:

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

// Function to calculate greatest common divisor
long long gcd(long long a, long long b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// Function to check if a number is a perfect square
int is_perfect_square(long long n) {
    if (n < 0) return 0;
    long long sqrt_n = (long long)sqrt(n);
    return sqrt_n * sqrt_n == n;
}

int main() {
    long long limit = 100;
    long long count = 0;
    
    printf("Computing...\n");
    
    // For small limits, we can compute directly
    for (long long a = 1; a <= limit; a++) {
        for (long long b = 1; b <= limit; b++) {
            for (long long c = 1; c <= limit; c++) {
                for (long long d = 1; d <= limit; d++) {
                    // Calculate area
                    long long area = (a + d) * (b + c) - a * c - b * d;
                    
                    // Calculate boundary points
                    long long boundary = gcd(a, b) + gcd(c, d) + gcd(a + c, b + d) + 1;
                    
                    // Calculate interior points using Pick's theorem
                    long long interior = area - (boundary - 1) / 2;
                    
                    // Check if interior points is a perfect square
                    if (is_perfect_square(interior)) {
                        count++;
                    }
                }
            }
        }
    }
    
    printf("Number of valid quadrilaterals: %lld\n", count);
    return 0;
}
```

## Key Points

1. **Pick's Theorem**: Used to relate the area, boundary points, and interior lattice points
2. **GCD Calculation**: Used to count boundary points
3. **Perfect Square Check**: Determines if the number of interior points is a perfect square
4. **Computational Complexity**: The brute force approach has O(n⁴) complexity, which makes it feasible for n=100
