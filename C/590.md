# Euler Problem 590 Solution in C

I'll solve Euler Problem 590, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes and 1×1 squares.

## Problem Understanding

We need to find the number of ways to tile a 3×n rectangle using:
- 2×1 dominoes (which can be placed horizontally or vertically)
- 1×1 squares

This is a classic dynamic programming problem.

## Approach

Let's define our state:
- Let `f(n)` be the number of ways to tile a 3×n rectangle
- We can build a recurrence relation by considering how the rightmost column can be filled
