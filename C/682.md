# Euler Problem 682 Solution in C

I'll solve Euler Problem 682, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

The problem asks us to find the number of ways to express a number n as a sum of powers of 2 (2^0, 2^1, 2^2, ...), where each power can be used at most twice.

This is essentially finding the number of representations of n in a "restricted binary" system where each bit position can have value 0, 1, or 2.

## Mathematical Approach

This is a classic dynamic programming problem. We can use the recurrence:
- f(n) = f(n-1) + f(n-2) + f(n-4) + f(n-8) + ... (where we can use 2^k at most twice)
- But we need to be more careful about the constraint

Actually, let's think differently. This is equivalent to finding the number of partitions of n into parts that are powers of 2, where each part can appear at most twice.

    // dp[i] represents number of ways to form number i
    long long *dp = (long long*)calloc(n + 1, sizeof(long long));
    
    // Base case
    dp[0] = 1;
    
    // For each power of 2 (2^k)
    int power = 1;
    while (power <= n) {
        // For each number from power to n
        for (int i = power; i <= n; i++) {
            // We can use this power 0, 1, or 2 times
            // But we only consider using it 0, 1, or 2 times
            // So we add dp[i-power] + dp[i-2*power] (if 2*power <= n)
            // But this approach is wrong for overlapping cases
            
            // Better approach: for each i, we consider using 0, 1, or 2 copies of power
            // dp[i] += dp[i-power] (if we use one copy)
            // dp[i] += dp[i-2*power] (if we use two copies)
            
            // But we need to be careful with the order to avoid double counting
            // We should process powers from small to large and for each power,
            // update all numbers from power to n
            
            // Actually, let's do it properly with correct recurrence
            if (i >= 1 * power) dp[i] += dp[i - 1 * power];
            if (i >= 2 * power) dp[i] += dp[i - 2 * power];
        }
        power *= 2;
    }
    
    long long result = dp[n];
    free(dp);
    return result;
}
