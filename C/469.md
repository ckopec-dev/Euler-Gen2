# Euler Problem 469 Solution in C

I'll solve Euler Problem 469, which involves finding the expected number of draws from a uniform distribution until the sum exceeds 1.

## Problem Understanding

Euler Problem 469 asks for the expected number of draws from a uniform distribution on [0,1] until the sum exceeds 1. This is a classic probability problem that can be solved analytically.

## Mathematical Analysis

Let E(x) be the expected number of draws needed when the current sum is x. We want E(0).

For x ≥ 1, we need 0 more draws.
For x < 1, if we draw y from [0,1], we need 1 + E(x+y) draws on average.

This gives us the integral equation:
E(x) = 1 + ∫₀¹ E(x+y) dy

For x ≥ 1, E(x) = 0.

## C Implementation

```c
#include <stdio.h>
#include <math.h>

// Analytical solution for Euler Problem 469
// Expected number of draws until sum exceeds 1
double solve_euler_469() {
    // The analytical solution is e (Euler's number)
    // This can be derived from the integral equation
    return M_E;
}

// Alternative numerical approach using Monte Carlo simulation
double monte_carlo_simulation(int num_simulations) {
    int total_draws = 0;
    
    for (int i = 0; i < num_simulations; i++) {
        double sum = 0.0;
        int draws = 0;
        
        while (sum <= 1.0) {
            sum += (double)rand() / RAND_MAX;
            draws++;
        }
        
        total_draws += draws;
    }
    
    return (double)total_draws / num_simulations;
}

int main() {
    // Analytical solution
    double analytical_result = solve_euler_469();
    
    printf("Euler Problem 469 Solution\n");
    printf("==========================\n");
    printf("Analytical result: %.10f\n", analytical_result);
    printf("Euler's number e:  %.10f\n", M_E);
    printf("Difference: %.2e\n", fabs(analytical_result - M_E));
    
    // Verify with Monte Carlo simulation
    printf("\nMonte Carlo verification:\n");
    int simulations[] = {10000, 100000, 1000000};
    
    for (int i = 0; i < 3; i++) {
        double mc_result = monte_carlo_simulation(simulations[i]);
        printf("Simulations: %d, Result: %.6f\n", simulations[i], mc_result);
    }
    
    printf("\nExact answer: %.10f\n", M_E);
    printf("Answer rounded to 10 decimal places: %.10f\n", M_E);
    
    return 0;
}
```

## Alternative Mathematical Approach

```c
#include <stdio.h>
#include <math.h>

// More detailed mathematical derivation approach
double expected_draws_mathematical() {
    // The expected number of draws is exactly e
    // This can be derived as follows:
    // Let E be the expected number of draws
    // E = 1 + ∫₀¹ E(1-x) dx = 1 + ∫₀¹ E(x) dx (by symmetry)
    // But E(x) = 1 + ∫₀¹ E(x+y) dy for x < 1
    // The solution to this integral equation is E = e
    
    return M_E;
}

// Verification using the series expansion of e
double series_expansion() {
    double e_approx = 1.0;
    double term = 1.0;
    
    // e = 1 + 1/1! + 1/2! + 1/3! + ...
    for (int i = 1; i <= 20; i++) {
        term /= i;
        e_approx += term;
    }
    
    return e_approx;
}

int main() {
    printf("Euler Problem 469 - Expected number of uniform draws until sum exceeds 1\n");
    printf("========================================================================\n");
    
    double result = expected_draws_mathematical();

    return 0;
```
