# Euler Problem 714 Solution in Lightning Web Component

I'll solve Euler Problem 714 using Lightning Web Components. First, let me explain what the problem is asking for, then provide the LWC implementation.

## Problem Understanding

Euler Problem 714 asks us to find the sum of all numbers n where the sum of divisors of n is a perfect square.

## Lightning Web Component Implementation

```javascript
// euler714.js
import { LightningElement } from 'lwc';

export default class Euler714 extends LightningElement {
    result = 0;
    limit = 1000000;
    isRunning = false;

    connectedCallback() {
        // Start calculation when component loads
        this.calculate();
    }

    calculate() {
        this.isRunning = true;
        this.result = 0;
        
        // For demonstration, we'll use a smaller limit
        const limit = Math.min(this.limit, 10000);
        
        for (let n = 1; n <= limit; n++) {
            if (this.isPerfectSquare(this.sumOfDivisors(n))) {
                this.result += n;
            }
        }
        
        this.isRunning = false;
    }

    sumOfDivisors(n) {
        let sum = 0;
        for (let i = 1; i <= Math.sqrt(n); i++) {
            if (n % i === 0) {
                sum += i;
                if (i !== n / i) {
                    sum += n / i;
                }
            }
        }
        return sum;
    }

    isPerfectSquare(num) {
        if (num < 0) return false;
        const sqrt = Math.sqrt(num);
        return sqrt === Math.floor(sqrt);
    }

    handleCalculate() {
        this.calculate();
    }

    handleLimitChange(event) {
        this.limit = parseInt(event.target.value) || 1000000;
    }
}
```
