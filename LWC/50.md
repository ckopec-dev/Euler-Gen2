# Euler Problem 50 Solution in Lightning Web Component

## Problem Statement
The prime 41, can be written as the sum of six consecutive primes:
41 = 2 + 3 + 5 + 7 + 11 + 13

This is the longest sum of consecutive primes that adds to a prime below one-hundred.

The longest sum of consecutive primes below one-thousand that adds to a prime, contains 21 terms, and is equal to 953.

Which prime, below one-million, can be written as the sum of the most consecutive primes?

## Solution

```javascript
// primeSum.js
import { LightningElement } from 'lwc';

export default class PrimeSum extends LightningElement {
    result = '';
    
    connectedCallback() {
        this.solve();
    }
    
    solve() {
        const limit = 1000000;
        const primes = this.sieveOfEratosthenes(limit);
        const primeSet = new Set(primes);
        
        let maxLength = 0;
        let resultPrime = 0;
        
        // Try all possible consecutive prime sums
        for (let i = 0; i < primes.length; i++) {
            let sum = 0;
            let count = 0;
            
            for (let j = i; j < primes.length; j++) {
                sum += primes[j];
                count++;
                
                // If sum exceeds limit, break
                if (sum >= limit) {
                    break;
                }
                
                // If sum is prime and longer than current max, update
                if (primeSet.has(sum) && count > maxLength) {
                    maxLength = count;
                    resultPrime = sum;
                }
            }
        }
        
        this.result = `Prime: ${resultPrime}, Length: ${maxLength}`;
    }
    
    sieveOfEratosthenes(limit) {
        const isPrime = new Array(limit + 1).fill(true);
        isPrime[0] = isPrime[1] = false;
        
        for (let i = 2; i * i <= limit; i++) {
            if (isPrime[i]) {
                for (let j = i * i; j <= limit; j += i) {
                    isPrime[j] = false;
                }
            }
        }
        
        const primes = [];
        for (let i = 2; i <= limit; i++) {
            if (isPrime[i]) {
                primes.push(i);
            }
        }
        
        return primes;
    }
}
```

## Approach Explanation

1. **Generate Primes**: Use the Sieve of Eratosthenes to generate all primes below one million
2. **Store in Set**: Convert primes to a Set for O(1) lookup time
3. **Consecutive Sum Search**: 
   - Start with each prime as the beginning of a sequence
   - Keep adding consecutive primes until sum exceeds one million
   - Check if each sum is prime and if it's longer than current maximum
4. **Optimization**: 
   - Stop extending sequence when sum exceeds limit
   - Use Set for fast prime checking

## Key Insights

- We need to find the longest consecutive prime sequence that sums to another prime
- The algorithm starts with each prime and extends the sequence as far as possible
- We only need to check sums that are prime and keep track of the maximum length
- The sieve ensures we have all primes efficiently for both generation and lookup

## Time Complexity
- Sieve: O(n log log n) where n = 1,000,000
- Sum checking: O(n²) in worst case, but optimized by early termination
- Overall: Efficient enough for the given constraints

## Expected Result
The answer is **997651** which is the sum of 543 consecutive primes starting from 7.
