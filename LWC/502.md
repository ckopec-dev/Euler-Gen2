# Project Euler Problem 502 Solution in Lightning Web Component

```javascript
// euler502.js
import { LightningElement } from 'lwc';

export default class Euler502 extends LightningElement {
    result = 0;
    n = 30;
    
    connectedCallback() {
        this.calculateResult();
    }
    
    calculateResult() {
        // This is a mathematical problem that requires dynamic programming
        // For 3×n rectangle with 2×1 dominoes, we need to find the recurrence relation
        
        // Let f(n) be the number of ways to tile a 3×n rectangle
        // Using the recurrence relation derived from the problem:
        // f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
        // Base cases:
        // f(0) = 1, f(1) = 1, f(2) = 5, f(3) = 11
        
        const MOD = 1000000007;
        const dp = new Array(31).fill(0);
        
        // Base cases
        dp[0] = 1;
        dp[1] = 1;
        dp[2] = 5;
        dp[3] = 11;
        
        // Fill the dp array using recurrence relation
        for (let i = 4; i <= 30; i++) {
            dp[i] = (dp[i-1] + 5 * dp[i-2] + dp[i-3] - dp[i-4]) % MOD;
            if (dp[i] < 0) dp[i] += MOD; // Handle negative numbers
        }
        
        this.result = dp[30];
    }
    
    get displayResult() {
        return `Answer: ${this.result}`;
    }
}
```

## Problem Explanation

Project Euler Problem 502 asks us to find the number of ways to tile a 3×n rectangle using 2×1 dominoes.

### Mathematical Approach

This is a classic dynamic programming problem. The key insight is to recognize the recurrence relation:

1. **Base Cases**:
   - f(0) = 1 (one way to tile a 3×0 rectangle - do nothing)
   - f(1) = 1 (one way to tile a 3×1 rectangle)
   - f(2) = 5 (five ways to tile a 3×2 rectangle)
   - f(3) = 11 (eleven ways to tile a 3×3 rectangle)

2. **Recurrence Relation**:
   For n ≥ 4: f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4)

3. **Modular Arithmetic**:
   Since the result can be very large, we compute everything modulo 1000000007.

### Why This Solution Works

The recurrence relation accounts for all possible ways to add dominoes to extend a tiling from smaller rectangles. The pattern emerges from analyzing how dominoes can be placed in the 3×n grid and how they affect the tiling of subsequent columns.

### Time Complexity
- O(n) where n = 30
- Space complexity: O(n) for the DP array

The solution efficiently computes the result using dynamic programming rather than trying to enumerate all possibilities, which would be computationally infeasible for larger values of n.
