## Problem 255 Explanation

Project Euler Problem 255 asks us to find the number of integers n ≤ 10^18 for which the square root of n is "simplified" - meaning the decimal representation of √n has a finite number of digits after the decimal point.

## Solution Approach

The key insight is that √n has a finite decimal representation if and only if n can be written as n = k²/m² where m is a positive integer and the decimal representation of k/m terminates. This happens when m is of the form 2^a × 5^b for non-negative integers a, b.
