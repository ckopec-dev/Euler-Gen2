# Euler Problem 94 Solution in Lightning Web Component

Euler Problem 94 asks: "For which value of p ≤ 1000000 can we find exactly one integer sided triangle with perimeter p?"

## Analysis
This problem is about finding triangles with integer sides where the perimeter is exactly one value, and there's exactly one such triangle. The key insight is that we need to find perimeters where there's exactly one valid triangle with integer sides.

## Lightning Web Component Implementation

```javascript
// trianglePerimeter.js
import { LightningElement } from 'lwc';

export default class TrianglePerimeter extends LightningElement {
    result = 0;
    isLoading = false;

    connectedCallback() {
        this.findSpecialPerimeter();
    }

    findSpecialPerimeter() {
        this.isLoading = true;
        
        // Using setTimeout to avoid blocking the UI
        setTimeout(() => {
            const limit = 1000000;
            let maxPerimeter = 0;
            let maxCount = 0;
            
            // For each perimeter p, count how many valid triangles exist
            for (let p = 3; p <= limit; p++) {
                let count = 0;
                
                // For triangle with sides a, b, c where a ≤ b ≤ c
                // We have a + b + c = p and a + b > c (triangle inequality)
                // Also a ≥ 1, b ≥ a, c ≥ b, and c = p - a - b
                for (let a = 1; a <= p/3; a++) {
                    // For given a, find valid range of b
                    // b ≥ a
                    // b ≤ (p - a) / 2 (since c = p - a - b ≥ b)
                    // b < p - a (since c > 0)
                    
                    let bMin = a;
                    let bMax = Math.floor((p - a) / 2);
                    
                    if (bMax >= bMin) {
                        count += bMax - bMin + 1;
                    }
                }
                
                // We're looking for exactly one triangle
                if (count === 1) {
                    maxPerimeter = p;
                    maxCount = 1;
                }
            }
            
            this.result = maxPerimeter;
            this.isLoading = false;
        }, 0);
    }

    get displayResult() {
        return this.result > 0 ? `The perimeter is: ${this.result}` : 'Calculating...';
    }
}
```

## Mathematical Approach

The solution uses the following mathematical approach:

1. **Triangle Constraints**: For sides a, b, c where a ≤ b ≤ c:
   - a + b + c = p (perimeter constraint)
   - a + b > c (triangle inequality)
   - a ≥ 1, b ≥ a, c ≥ b

2. **Optimization**: Since a ≤ b ≤ c and a + b + c = p, we know:
   - a ≤ p/3 (since if a > p/3, then b, c > p/3, making sum > p)
   - For a fixed a, we can determine valid range for b
   - c = p - a - b, so b < p - a (since c > 0)
   - b ≥ a (ordering constraint)
   - a + b > c = p - a - b, so 2b > p - 2a, thus b > (p - 2a)/2

3. **Counting**: For each perimeter p, we count valid combinations of (a,b,c) that satisfy all constraints.

## Key Insights

- We're looking for the largest perimeter p ≤ 1000000 where exactly one triangle exists
- The approach involves iterating through all possible perimeters and counting valid triangles
- The mathematical constraints help reduce the search space significantly
- The solution handles the optimization to avoid brute force checking

This implementation efficiently solves the problem by using mathematical constraints to reduce the search space while maintaining readability in the Lightning Web Component framework.
