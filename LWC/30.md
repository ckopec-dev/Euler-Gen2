# Euler Problem 30 Solution in Lightning Web Component

Euler Problem 30 asks: Find the sum of all numbers that can be written as the sum of fifth powers of their digits.

Here's the solution implemented as a Lightning Web Component:

```javascript
// eulerProblem30.js
import { LightningElement } from 'lwc';

export default class EulerProblem30 extends LightningElement {
    result = 0;
    explanation = '';

    connectedCallback() {
        this.solveProblem();
    }

    solveProblem() {
        let totalSum = 0;
        let validNumbers = [];
        
        // For a 5-digit number, maximum sum of fifth powers is 9^5 * 5 = 295,245
        // So we only need to check up to about 300,000
        for (let i = 2; i < 300000; i++) {
            const digits = i.toString().split('');
            let sumOfPowers = 0;
            
            for (let digit of digits) {
                sumOfPowers += Math.pow(parseInt(digit), 5);
            }
            
            if (sumOfPowers === i) {
                totalSum += i;
                validNumbers.push(i);
            }
        }
        
        this.result = totalSum;
        this.explanation = `Valid numbers: ${validNumbers.join(', ')}\nSum: ${totalSum}`;
    }
}
```

## Solution Explanation

The approach works as follows:

1. **Range determination**: Since we're looking for numbers that equal the sum of fifth powers of their digits, we need to determine a reasonable upper bound. For a 6-digit number, the maximum possible sum would be 6 × 9^5 = 354,294, so we don't need to check beyond that.

2. **Digit processing**: For each number in our range:
   - Convert the number to a string to easily access individual digits
   - Calculate the sum of each digit raised to the 5th power
   - Compare this sum with the original number

3. **Validation**: If the sum equals the original number, we've found a valid number.

4. **Summation**: Add all valid numbers to get the final result.

## Key Insights

- The number 1 = 1^5 = 1 is excluded since we need numbers that are "written as the sum of fifth powers" (not just single digits)
- The valid numbers are: 4150, 4151, 54748, 92727, 93084
- These numbers are interesting because they are equal to the sum of their digits raised to the fifth power

## Expected Result

The sum of all such numbers is **443839**.
