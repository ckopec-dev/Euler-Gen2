# Euler Problem 805 Solution in Lightning Web Component

## Problem Understanding

Euler Problem 805 asks us to find the sum of all numbers that are divisible by 3 or 5, but not by 15, in the range from 1 to 10^12.

## Solution Approach

We'll use the inclusion-exclusion principle:
- Sum of numbers divisible by 3: S(3)
- Sum of numbers divisible by 5: S(5)  
- Sum of numbers divisible by 15: S(15)
- Answer = S(3) + S(5) - S(15)

For a number n, the sum of all multiples of d up to n is: d × (n/d) × (n/d + 1) / 2

### javascript file (euler805.js)
```javascript
import { LightningElement } from 'lwc';

export default class Euler805 extends LightningElement {
    result = '';
    executionTime = 0;

    calculateResult() {
        const startTime = Date.now();
        
        // The upper limit as given in the problem
        const limit = 1000000000000; // 10^12
        
        // Using inclusion-exclusion principle
        // Sum of multiples of 3 + Sum of multiples of 5 - Sum of multiples of 15
        const sum3 = this.sumOfMultiples(3, limit);
        const sum5 = this.sumOfMultiples(5, limit);
        const sum15 = this.sumOfMultiples(15, limit);
        
        const result = sum3 + sum5 - sum15;
        
        this.result = result.toLocaleString();
        this.executionTime = Date.now() - startTime;
    }

    // Calculate sum of all multiples of 'divisor' up to 'limit'
    sumOfMultiples(divisor, limit) {
        // Number of multiples of 'divisor' up to 'limit'
        const count = Math.floor(limit / divisor);
        
        // Sum = divisor * (1 + 2 + ... + count)
        // Using arithmetic series formula: n * (n + 1) / 2
        return divisor * count * (count + 1) / 2;
    }
}
```

## Explanation

The solution uses the inclusion-exclusion principle to avoid double-counting numbers that are divisible by both 3 and 5 (i.e., divisible by 15):

1. **Sum of multiples of 3**: Calculate sum of all numbers divisible by 3 up to 10^12
2. **Sum of multiples of 5**: Calculate sum of all numbers divisible by 5 up to 10^12  
3. **Sum of multiples of 15**: Calculate sum of all numbers divisible by 15 up to 10^12 (to subtract since these are counted twice)

The formula for sum of multiples of d up to n:
```
Sum = d × (n/d) × (n/d + 1) / 2
```

This approach is efficient because it runs in O(1) time complexity rather than iterating through all numbers.
