# Euler Problem 100 Solution in Lightning Web Component

I'll solve Project Euler Problem 100 using Lightning Web Components. This problem asks for the arrangement of red and blue discs such that the probability of drawing two blue discs is exactly 1/2.

```javascript
// blueDiscs.js
import { LightningElement } from 'lwc';

export default class BlueDiscs extends LightningElement {
    result = '';
    iterations = 0;
    blueDiscs = 0;
    totalDiscs = 0;

    solveProblem() {
        // We need to find integers n (blue discs) and d (total discs) 
        // such that n(n-1)/(d(d-1)) = 1/2
        // This simplifies to 2n(n-1) = d(d-1)
        // Which gives us: 2n² - 2n = d² - d
        // Rearranging: 2n² - 2n - d² + d = 0
        // Or: 2n² - 2n = d² - d
        
        // Using the recurrence relation for Pell's equation:
        // If (n,d) is a solution, then (n',d') = (3n + 2d, 4n + 3d) is also a solution
        // Starting with n=1, d=2 (since 1*1/2*2 = 1/4 ≠ 1/2)
        // Actually, let's start with n=3, d=4 (since 3*2/4*3 = 6/12 = 1/2 ✓)
        
        let n = 3;  // blue discs
        let d = 4;  // total discs
        
        // We want the first solution where d > 10^12
        while (d <= 1000000000000) {
            this.iterations++;
            // Generate next solution using recurrence relation
            let nextN = 3 * n + 2 * d;
            let nextD = 4 * n + 3 * d;
            
            n = nextN;
            d = nextD;
        }
        
        this.blueDiscs = n;
        this.totalDiscs = d;
        this.result = `Blue discs: ${n}, Total discs: ${d}`;
    }

    connectedCallback() {
        this.solveProblem();
    }
}
```

## Mathematical Approach

The problem can be solved using the theory of Pell's equation. Here's the mathematical reasoning:

1. **Setting up the equation**: 
   - Probability of drawing two blue discs = n(n-1)/d(d-1) = 1/2
   - This gives us: 2n(n-1) = d(d-1)

2. **Transformation**:
   - Rearranging: 2n² - 2n = d² - d
   - 2n² - 2n - d² + d = 0
   - This is a quadratic Diophantine equation

3. **Using recurrence relations**:
   - The solutions follow the recurrence relation:
   - n' = 3n + 2d
   - d' = 4n + 3d
   - Starting with n=3, d=4 (which satisfies the equation)

4. **Finding the answer**:
   - Continue generating solutions until d > 10^12
   - The first such solution gives us the answer

## Key Insights

- This is an application of Pell's equation theory
- The recurrence relation allows us to generate solutions efficiently
- The constraint d > 10^12 makes a brute-force approach impractical
- The LWC component efficiently computes the result using the mathematical recurrence

The solution returns the number of blue discs when the total number of discs exceeds 10^12, which is the answer to Project Euler Problem 100.
