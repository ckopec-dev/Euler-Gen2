# Euler Problem 19 Solution in Lightning Web Component

Euler Problem 19 asks: "How many Sundays fell on the first of the month during the twentieth century (1 Jan 1901 to 31 Dec 2000)?"

Here's the solution implemented as a Lightning Web Component:

```javascript
// sundayCounter.js
import { LightningElement } from 'lwc';

export default class SundayCounter extends LightningElement {
    result = 0;
    explanation = '';

    connectedCallback() {
        this.calculateSundays();
    }

    calculateSundays() {
        let sundayCount = 0;
        let dayOfWeek = 1; // 0 = Sunday, 1 = Monday, ..., 6 = Saturday
        // Days in each month (non-leap year)
        const daysInMonth = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31];
        
        // Iterate through years 1901 to 2000
        for (let year = 1901; year <= 2000; year++) {
            // Check if leap year
            const isLeapYear = (year % 4 === 0 && year % 100 !== 0) || (year % 400 === 0);
            
            // Update February days for leap year
            daysInMonth[1] = isLeapYear ? 29 : 28;
            
            // Iterate through months
            for (let month = 0; month < 12; month++) {
                // If the first day of the month is Sunday (dayOfWeek = 0)
                if (dayOfWeek === 0) {
                    sundayCount++;
                }
                
                // Move to the first day of next month
                dayOfWeek = (dayOfWeek + daysInMonth[month]) % 7;
            }
        }
        
        this.result = sundayCount;
        this.explanation = `There were ${sundayCount} Sundays that fell on the first of the month during the twentieth century (1901-2000).`;
    }

    get resultMessage() {
        return this.explanation;
    }
}
```

## Solution Explanation

This LWC component solves Euler Problem 19 by:

1. **Tracking the day of week**: Using modular arithmetic to keep track of which day of the week we're on
2. **Handling leap years**: Correctly identifying leap years using the standard rules
3. **Iterating through time**: Going through each year from 1901 to 2000
4. **Counting Sundays**: Checking if the first day of each month is a Sunday (day 0)

## Key Algorithm Details

- **Day numbering**: 0 = Sunday, 1 = Monday, ..., 6 = Saturday
- **Leap year logic**: A year is leap if divisible by 4 but not by 100, OR divisible by 400
- **Modular arithmetic**: Using `% 7` to cycle through days of the week
- **Efficiency**: No need to create actual date objects, just track the day numbers

The answer is **171 Sundays** that fell on the first of the month during the twentieth century.
