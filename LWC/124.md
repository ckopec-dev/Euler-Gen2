# Euler Problem 124 Solution in Lightning Web Component

This solution finds the ordered radical of numbers and identifies the nth element in the sorted list.

```javascript
// Lightning Web Component for Euler Problem 124
import { LightningElement } from 'lwc';

export default class Euler124 extends LightningElement {
    result = '';
    
    connectedCallback() {
        this.solveProblem();
    }
    
    solveProblem() {
        const limit = 100000;
        const radicalArray = new Array(limit + 1).fill(1);
        
        // Calculate radical values using sieve method
        for (let i = 2; i <= limit; i++) {
            if (radicalArray[i] === 1) { // i is prime
                for (let j = i; j <= limit; j += i) {
                    radicalArray[j] *= i;
                }
            }
        }
        
        // Create array of [radical, number] pairs
        const pairs = [];
        for (let i = 1; i <= limit; i++) {
            pairs.push([radicalArray[i], i]);
        }
        
        // Sort by radical value
        pairs.sort((a, b) => a[0] - b[0]);
        
        // Return the 10000th element (1-indexed)
        this.result = pairs[9999][1].toString();
    }
    
    get getResult() {
        return this.result;
    }
}
```

## Explanation

This solution implements Euler Problem 124 which asks for the 10000th element in the sorted list of numbers based on their "ordered radical" values.

**Key Steps:**

1. **Radical Calculation**: For each number n, calculate the product of its distinct prime factors
2. **Sieve Method**: Use a modified sieve to efficiently compute radical values
3. **Sorting**: Sort all numbers by their radical values
4. **Result**: Return the 10000th element (0-indexed as 9999)

**Algorithm Details:**
- Initialize an array where each index represents a number's radical value
- For each prime number, multiply all its multiples by that prime
- This gives us the product of distinct prime factors for each number
- Sort by radical values and return the 10000th element

**Time Complexity**: O(n log log n) due to the sieve method
**Space Complexity**: O(n) for the radical array

The answer is **21417**.
