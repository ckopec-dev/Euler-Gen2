# Euler Problem 144 Solution in Lightning Web Component

I'll solve Euler Problem 144 using Lightning Web Components. This problem involves finding the number of reflections a laser beam makes before escaping an elliptical mirror.

## Problem Understanding

Euler Problem 144 asks: "A laser beam enters an ellipse with the equation 4x² + y² = 100. The beam starts at the point (1.4, -3.6) with a slope of -1.25. Find the number of reflections before the beam exits the ellipse."

## Solution Implementation

```javascript
// lightning-web-component.js
import { LightningElement } from 'lwc';

export default class Euler144 extends LightningElement {
    result = 0;
    solution = '';

    connectedCallback() {
        this.solveProblem();
    }

    solveProblem() {
        // Ellipse parameters: 4x² + y² = 100
        // Standard form: x²/25 + y²/100 = 1
        // So a² = 25, b² = 100, a = 5, b = 10
        
        const a = 5;
        const b = 10;
        const aSquared = a * a;
        const bSquared = b * b;
        
        // Initial beam position and slope
        let x = 1.4;
        let y = -3.6;
        let slope = -1.25;
        
        let reflections = 0;
        const tolerance = 1e-10;
        
        // Continue until beam exits the ellipse (x²/a² + y²/b² > 1)
        while (true) {
            // Calculate intersection with ellipse
            const intersection = this.findIntersection(x, y, slope, aSquared, bSquared);
            
            if (intersection === null) {
                break;
            }
            
            const [newX, newY] = intersection;
            
            // Check if beam is escaping the ellipse
            const ellipseValue = (newX * newX) / aSquared + (newY * newY) / bSquared;
            if (ellipseValue > 1.0 + tolerance) {
                break;
            }
            
            // Calculate normal vector at intersection point
            const normalX = (2 * newX) / aSquared;
            const normalY = (2 * newY) / bSquared;
            
            // Normalize normal vector
            const normalLength = Math.sqrt(normalX * normalX + normalY * normalY);
            const unitNormalX = normalX / normalLength;
            const unitNormalY = normalY / normalLength;
            
            // Calculate reflection using vector reflection formula
            const dotProduct = slope * unitNormalY - unitNormalX;
            const reflectionSlope = (slope * unitNormalY - unitNormalX) / 
                                  (unitNormalX + slope * unitNormalY);
            
            // Update position and slope for next reflection
            x = newX;
            y = newY;
            slope = reflectionSlope;
            
            reflections++;
            
            // Safety check to prevent infinite loop
            if (reflections > 10000) {
                break;
            }
        }
        
        this.result = reflections;
        this.solution = `The laser beam makes ${reflections} reflections before escaping the ellipse.`;
    }
    
    findIntersection(x, y, slope, aSquared, bSquared) {
        // For ellipse 4x² + y² = 100, we have: 4x² + y² = 100
        // Line equation: y - y1 = m(x - x1)
        // So: y = m(x - x1) + y1
        
        const m = slope;
        const x1 = x;
        const y1 = y;
        
        // Substitute line equation into ellipse equation
        // 4x² + (m(x - x1) + y1)² = 100
        // 4x² + m²(x - x1)² + 2m(x - x1)y1 + y1² = 100
        // 4x² + m²(x² - 2x1x + x1²) + 2m(x - x1)y1 + y1² = 100
        // 4x² + m²x² - 2m²x1x + m²x1² + 2mx - 2mx1y1 + y1² = 100
        // (4 + m²)x² + (-2m²x1 + 2m)x + (m²x1² - 2mx1y1 + y1² - 100) = 0
        
        const A = 4 + m * m;
        const B = -2 * m * m * x1 + 2 * m;
        const C = m * m * x1 * x1 - 2 * m * x1 * y1 + y1 * y1 - 100;
        
        // Solve quadratic equation
        const discriminant = B * B - 4 * A * C;
        
        if (discriminant < 0) {
            return null; // No intersection
        }
        
        // Find two intersection points
        const sqrtDiscriminant = Math.sqrt(discriminant);
        const x1Intersection = (-B + sqrtDiscriminant) / (2 * A);
        const x2Intersection = (-B - sqrtDiscriminant) / (2 * A);
        
        // Calculate corresponding y values
        const y1Intersection = m * (x1Intersection - x1) + y1;
        const y2Intersection = m * (x2Intersection - x1) + y1;
        
        // Choose the intersection point that's not the current position
        const distance1 = Math.sqrt((x1Intersection - x) * (x1Intersection - x) + 
                                   (y1Intersection - y) * (y1Intersection - y));
        const distance2 = Math.sqrt((x2Intersection - x) * (x2Intersection - x) + 
                                   (y2Intersection - y) * (y2Intersection - y));
        
        // Return the point that's farther from current position (the next intersection)
        if (distance1 > distance2) {
            return [x1Intersection, y1Intersection];
        } else {
            return [x2Intersection, y2Intersection];
        }
    }
}
```

## Mathematical Approach

The solution uses the following mathematical concepts:

1. **Ellipse Equation**: 4x² + y² = 100 (which can be rewritten as x²/25 + y²/100 = 1)
2. **Ray Intersection**: Finding where a line intersects the ellipse
3. **Reflection Law**: Using vector mathematics to calculate reflection angles
4. **Iterative Process**: Repeating the intersection and reflection calculations

## Key Algorithm Steps

1. Start with initial beam position and slope
2. Find intersection point with ellipse
3. Calculate reflection angle using normal vector
4. Update beam position and slope
5. Repeat until beam escapes the ellipse
6. Count total reflections
