# Euler Problem 142 Solution in Kotlin

## Problem Statement
Find the smallest x such that there exist positive integers a, b, c such that:
- x + a² is a perfect square
- x + b² is a perfect square  
- x + c² is a perfect square
- a, b, c are in arithmetic progression

## Solution

```kotlin
fun isPerfectSquare(n: Long): Boolean {
    if (n < 0) return false
    val sqrt = Math.sqrt(n.toDouble()).toLong()
    return sqrt * sqrt == n
}

fun solveEuler142(): Long {
    // We need to find the smallest x such that:
    // x + a² = k₁², x + b² = k₂², x + c² = k₃²
    // where a, b, c form an arithmetic progression
    
    // Let a = b - d, c = b + d (arithmetic progression with common difference d)
    // Then: x + (b-d)² = k₁², x + b² = k₂², x + (b+d)² = k₃²
    
    // From these equations:
    // k₁² - (b-d)² = k₂² - b² = k₃² - (b+d)² = x
    
    // This gives us: k₁² - (b-d)² = k₂² - b²
    // k₁² - b² + 2bd - d² = k₂² - b²
    // k₁² - k₂² = 2bd - d² = d(2b - d)
    
    // Similarly: k₂² - b² = k₃² - (b+d)²
    // k₂² - k₃² = 2bd + d² = d(2b + d)
    
    // We can iterate through possible values and check conditions
    
    var x = 1L
    
    while (true) {
        // Check if x can be expressed as x = k² - a² for some integers k, a
        // This means k² - x = a², so a² = k² - x
        
        var found = false
        
        // Try different values of b (middle term of arithmetic progression)
        for (b in 1..10000) {
            // Check if x + b² is a perfect square
            val bSquaredPlusX = x + b.toLong() * b
            if (isPerfectSquare(bSquaredPlusX)) {
                val k2 = Math.sqrt(bSquaredPlusX.toDouble()).toLong()
                
                // Try different values of d (common difference)
                for (d in 1..1000) {
                    val a = b - d
                    val c = b + d
                    
                    if (a <= 0) continue
                    
                    // Check if x + a² and x + c² are perfect squares
                    val aSquaredPlusX = x + a.toLong() * a
                    val cSquaredPlusX = x + c.toLong() * c
                    
                    if (isPerfectSquare(aSquaredPlusX) && isPerfectSquare(cSquaredPlusX)) {
                        val k1 = Math.sqrt(aSquaredPlusX.toDouble()).toLong()
                        val k3 = Math.sqrt(cSquaredPlusX.toDouble()).toLong()
                        
                        // Verify the arithmetic progression of squares
                        // k₁² - x = a², k₂² - x = b², k₃² - x = c²
                        if (k1 * k1 == aSquaredPlusX && 
                            k2 * k2 == bSquaredPlusX && 
                            k3 * k3 == cSquaredPlusX) {
                            found = true
                            break
                        }
                    }
                }
                
                if (found) break
            }
        }
        
        if (found) return x
        x++
    }
    
    return -1L
}
```

## Mathematical Analysis

The problem requires finding the smallest positive integer x such that there exist positive integers a, b, c forming an arithmetic progression where:
- x + a² is a perfect square
- x + b² is a perfect square  
- x + c² is a perfect square

Let's say a, b, c form an arithmetic progression with common difference d:
- a = b - d
- c = b + d

This leads to the system:
- x + (b-d)² = k₁²
- x + b² = k₂²
- x + (b+d)² = k₃²

Where k₁, k₂, k₃ are positive integers.
