# Euler Problem 543 Solution in Kotlin

I'll solve Euler Problem 543, which asks for the sum of all primes less than 100,000,000 that are palindromes in both base 10 and base 2.

## Problem Analysis

We need to:
1. Find all primes less than 100,000,000
2. Check if each prime is palindromic in base 10
3. Check if each prime is palindromic in base 2
4. Sum all primes that satisfy both conditions

## Solution Approach

I'll use:
- Sieve of Eratosthenes to efficiently find primes
- Helper functions to check palindromes in different bases
- Iterate through primes and apply the conditions

```kotlin
fun main() {
    val limit = 100_000_000
    val primes = sieveOfEratosthenes(limit)
    
    val result = primes.filter { prime ->
        isPalindrome(prime.toString()) && 
        isPalindrome(Integer.toBinaryString(prime))
    }.sumOf { it.toLong() }
    
    println(result)
}

fun sieveOfEratosthenes(limit: Int): List<Int> {
    val isPrime = BooleanArray(limit + 1) { true }
    isPrime[0] = isPrime[1] = false
    
    for (i in 2..kotlin.math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit step i) {
                isPrime[j] = false
            }
        }
    }
    
    return (2..limit).filter { isPrime[it] }
}

fun isPalindrome(s: String): Boolean {
    val reversed = s.reversed()
    return s == reversed
}
```

```kotlin
fun main() {
    val limit = 100_000_000
    val primes = sieveOfEratosthenes(limit)
    
    val result = primes.filter { prime ->
        isPalindrome(prime.toString()) && 
        isPalindrome(Integer.toBinaryString(prime))
    }.sumOf { it.toLong() }
    
    println(result)
}

fun sieveOfEratosthenes(limit: Int): List<Int> {
    val isPrime = BooleanArray(limit + 1) { true }
    isPrime[0] = isPrime[1] = false
    
    for (i in 2..kotlin.math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit step i) {
```

```kotlin
            }
        }
    }
    
    return (2..limit).filter { isPrime[it] }
}

fun isPalindrome(s: String): Boolean {
    return s == s.reversed()
}
```

The solution works by:
1. Generating all primes up to 100,000,000 using the Sieve of Eratosthenes
2. For each prime, checking if it's palindromic in both base 10 and base 2
3. Summing all primes that satisfy both conditions

The time complexity is approximately O(n log log n) for the sieve, plus O(n × log n) for palindrome checking, where n is 100,000,000.
