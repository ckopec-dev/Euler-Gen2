# Euler Problem 770 Solution in Kotlin

I'll solve Euler Problem 770, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most 3 times.

## Problem Understanding

The problem asks us to find the number of ways to write a positive integer n as a sum of powers of 2 (1, 2, 4, 8, 16, ...) where each power can be used at most 3 times.

This is a classic dynamic programming problem - essentially counting the number of partitions with restricted multiplicities.

## Solution Approach

I'll use dynamic programming where:
- `dp[i][j]` represents the number of ways to form sum `i` using powers of 2 up to 2^j
- For each power of 2, we can use it 0, 1, 2, or 3 times
- We'll build up the solution incrementally

## Kotlin Implementation

```kotlin
fun solveEuler770(target: Int): Long {
    // dp[i] will store the number of ways to form sum i
    val dp = LongArray(target + 1) { 0 }
    dp[0] = 1L // One way to form sum 0 (use nothing)
    
    // For each power of 2 (1, 2, 4, 8, 16, ...)
    var power = 1
    while (power <= target) {
        // For each possible sum from power to target
        for (i in power..target) {
            // We can use 1, 2, or 3 copies of current power
            // dp[i] += dp[i - power] + dp[i - 2*power] + dp[i - 3*power]
            for (k in 1..3) {
                if (i >= k * power) {
                    dp[i] += dp[i - k * power]
                }
            }
        }
        power *= 2
    }
    
    return dp[target]
}
```

## Final Clean Solution

```kotlin
fun countPartitions(target: Long): Long {
    val dp = LongArray(target.toInt() + 1) { 0 }
    dp[0] = 1L
    
    var power = 1L
    while (power <= target) {
        // Process from right to left to avoid using updated values
        for (i in target downTo power) {
            val iInt = i.toInt()
            val powerInt = power.toInt()
            
            // We can use 1, 2, or 3 copies of the current power
            for (k in 1..3) {
                if (i >= k * power) {
                    dp[iInt] += dp[iInt - k * powerInt]
                }
            }
        }
        power *= 2
    }
    
    return dp[target.toInt()]
}

fun main() {
    val answer = countPartitions(1000000000000L)
    println("Euler Problem 770: $answer")
}
```

This solution uses dynamic programming where:
1. We process powers of 2 in increasing order (1, 2, 4, 8, ...)
2. For each power, we update our dp array from right to left
3. For each position, we consider using 1, 2, or 3 copies of the current power
4. The final answer is stored in dp[10^12]

The time complexity is O(n log n) where n = 10^12, and space complexity is O(n).
