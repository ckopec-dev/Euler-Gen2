# Euler Problem 795 Solution in Kotlin

## Problem Statement
Let $f(n)$ be the number of ways to write $n$ as a sum of powers of $2$, where we count the number of ways to write $n$ as a sum of powers of $2$ with each power used at most once, and where we also count the number of ways to write $n$ as a sum of powers of $2$ with each power used at most twice.

## Solution Approach
This problem is asking for the number of ways to write a number as a sum of powers of 2, where each power can be used 0, 1, or 2 times. This is a classic dynamic programming problem that can be solved using the concept of generating functions or direct DP.

## Kotlin Implementation

```kotlin
fun solveEuler795(n: Int): Long {
    // dp[i] represents number of ways to form sum i
    val dp = LongArray(n + 1) { 0 }
    dp[0] = 1L
    
    // For each power of 2
    var power = 1
    while (power <= n) {
        // For each sum from power to n
        for (i in power..n) {
            // We can use 0, 1, or 2 copies of this power
            dp[i] += dp[i - power]  // use 1 copy
            if (i >= 2 * power) {
                dp[i] += dp[i - 2 * power]  // use 2 copies
            }
        }
        power *= 2
    }
    
    return dp[n]
}

fun main() {
    // Test with small values to verify correctness
    println("f(1) = ${solveEuler795(1)}")  // Should be 1
    println("f(2) = ${solveEuler795(2)}")  // Should be 2
    println("f(3) = ${solveEuler795(3)}")  // Should be 3
    println("f(4) = ${solveEuler795(4)}")  // Should be 4
    
    // For the actual problem, we need f(10^12)
    val result = solveEuler795(1000000000000L)
    println("f(10^12) = $result")
}
```

## Alternative Mathematical Approach

We can also solve this using the mathematical formula. Since we can use each power of 2 at most twice, we're essentially counting representations in a modified base-2 system.

fun solveEuler795Mathematical(n: Long): Long {
    // The number of ways to write n as sum of powers of 2 with each power used at most twice
    // is equal to the number of ways to write n in base 3, but we need to be more careful
    
    // This is equivalent to: for each bit position, we can have 0, 1, or 2 copies of that power
    // which gives us 3 choices per bit position
    
    // Actually, let's think differently:
    // f(n) = sum over all valid combinations where each power of 2 can be used 0, 1, or 2 times
    
    // Let's use the recurrence relation approach
    val dp = LongArray(n.toInt() + 1) { 0 }

    var power = 1L
    while (power <= n) {
        for (i in power..n) {
            dp[i.toInt()] += dp[(i - power).toInt()]
            if (i >= 2 * power) {
                dp[i.toInt()] += dp[(i - 2 * power).toInt()]
            }
        }
        power *= 2
    }
    
    return dp[n.toInt()]
}

## Key Insights

1. **Dynamic Programming**: This problem is solved using dynamic programming where we build up solutions for smaller numbers and use them to solve larger ones.

2. **State Transition**: For each power of 2, we can use 0, 1, or 2 copies of it in our sum.

3. **Efficient Computation**: We iterate through powers of 2 and update our DP array accordingly.

4. **Time Complexity**: O(n log n) where n is the target number.

## Mathematical Pattern

The solution computes the exact number of ways to represent the given number using powers of 2 with each power used at most twice.
