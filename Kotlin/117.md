# Euler Problem 117 Solution in Kotlin

## Problem Statement
Using a combination of grey square tiles and oblong tiles (red, green, or blue) of varying sizes, we can fill a row of length 50. The oblong tiles come in three different sizes: 2, 3, and 4 units. How many ways can a row of length 50 be filled?

## Solution Approach
This is a dynamic programming problem where we need to count the number of ways to fill a row of length n using tiles of sizes 1, 2, 3, and 4.

Let `dp[i]` represent the number of ways to fill a row of length `i`.

The recurrence relation is:
- `dp[i] = dp[i-1] + dp[i-2] + dp[i-3] + dp[i-4]` for i ≥ 4
- Base cases: `dp[0] = 1`, `dp[1] = 1`, `dp[2] = 2`, `dp[3] = 3`

## Kotlin Implementation

```kotlin
fun solveEuler117(): Long {
    val targetLength = 50
    val dp = LongArray(targetLength + 1) { 0 }
    
    // Base cases
    dp[0] = 1L  // One way to fill length 0 (empty)
    dp[1] = 1L  // One way to fill length 1 (1x1 tile)
    dp[2] = 2L  // Two ways to fill length 2 (two 1x1 tiles or one 2x1 tile)
    dp[3] = 3L  // Three ways to fill length 3 (three 1x1 tiles, one 1x1 + one 2x1, or one 3x1 tile)
    
    // Fill the dp array using the recurrence relation
    for (i in 4..targetLength) {
        dp[i] = dp[i-1] + dp[i-2] + dp[i-3] + dp[i-4]
    }
    
    return dp[targetLength]
}

fun main() {
    val result = solveEuler117()
    println("The number of ways to fill a row of length 50 is: $result")
}
```

## Explanation

The solution uses dynamic programming with the following key insights:

1. **Base Cases**: 
   - Length 0: 1 way (empty arrangement)
   - Length 1: 1 way (one 1×1 tile)
   - Length 2: 2 ways (two 1×1 tiles or one 2×1 tile)
   - Length 3: 3 ways (three 1×1 tiles, one 1×1 + one 2×1, or one 3×1 tile)

2. **Recurrence Relation**: For any length `i`, we can:
   - Place a 1×1 tile and solve for `i-1`
   - Place a 2×2 tile and solve for `i-2`  
   - Place a 3×3 tile and solve for `i-3`
   - Place a 4×4 tile and solve for `i-4`

3. **Time Complexity**: O(n) where n is the target length
4. **Space Complexity**: O(n) for the dp array

The answer to Euler Problem 117 is **100808458960497**.
