# Euler Problem 681 Solution in Kotlin

## Problem Statement
The problem asks us to find the number of ways to arrange the numbers 1 to n in a circle such that the sum of any two adjacent numbers is a perfect square.

## Approach
1. First, we need to identify which pairs of numbers sum to perfect squares
2. This forms a graph where nodes are numbers and edges connect numbers that sum to perfect squares
3. We need to find Hamiltonian cycles in this graph (cycles that visit each node exactly once)
4. Since we're dealing with a circle, we need to account for rotational symmetry

## Solution

```kotlin
fun main() {
    val result = solve(15)
    println("Answer: $result")
}

fun solve(n: Int): Long {
    // Precompute which pairs sum to perfect squares
    val validPairs = mutableListOf<MutableList<Int>>()
    for (i in 1..n) {
        validPairs.add(mutableListOf())
        for (j in 1..n) {
            if (i != j) {
                val sum = i + j
                val sqrt = Math.sqrt(sum.toDouble()).toInt()
                if (sqrt * sqrt == sum) {
                    validPairs[i - 1].add(j)
                }
            }
        }
    }
    
    // Use backtracking to find all valid arrangements
    val used = BooleanArray(n + 1) { false }
    val arrangement = IntArray(n) { 0 }
    var count = 0L
    
    // Start with 1 (we can fix one number due to rotational symmetry)
    used[1] = true
    arrangement[0] = 1
    count = backtrack(1, n, validPairs, used, arrangement, count)
    
    // Since we fixed the first position, we need to multiply by 2 for the two possible rotations
    // But actually, we're looking for circular arrangements, so we don't multiply by 2
    // The backtracking already handles the circular nature properly
    return count
}

fun backtrack(position: Int, n: Int, validPairs: List<MutableList<Int>>, 
             used: BooleanArray, arrangement: IntArray, count: Long): Long {
    if (position == n) {
        // Check if the last element connects back to the first (circular)
        val first = arrangement[0]
        val last = arrangement[n - 1]
        val sum = first + last
        val sqrt = Math.sqrt(sum.toDouble()).toInt()
        if (sqrt * sqrt == sum) {
            return count + 1
        }
        return count
    }
    
    var result = count
    val lastElement = arrangement[position - 1]
    
    // Try all valid next elements
    for (next in validPairs[lastElement - 1]) {
        if (!used[next]) {
            used[next] = true
            arrangement[position] = next
            result = backtrack(position + 1, n, validPairs, used, arrangement, result)
            used[next] = false
        }
    }
    
    return result
}
```

## Key Points

1. **Preprocessing**: We first compute which pairs of numbers sum to perfect squares
2. **Graph Representation**: This creates a graph where edges represent valid adjacent pairs
3. **Backtracking**: We use recursive backtracking to find all valid Hamiltonian cycles
4. **Circular Constraint**: We ensure the last element connects back to the first element
5. **Symmetry Handling**: We fix the first element to avoid counting rotations as different arrangements

## Time Complexity
The time complexity is exponential in the worst case, as we're essentially finding all Hamiltonian cycles in a graph.
