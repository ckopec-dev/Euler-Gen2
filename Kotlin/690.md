# Euler Problem 690 Solution in Kotlin

I'll solve Euler Problem 690, which asks for the number of integers $0 \leq n < 10^{18}$ such that $\gcd(n, \phi(n)) = 1$, where $\phi(n)$ is Euler's totient function.

## Problem Understanding

We need to count integers $n < 10^{18}$ where $\gcd(n, \phi(n)) = 1$. This means $n$ and $\phi(n)$ share no common prime factors.

## Key Insights

1. If $\gcd(n, \phi(n)) = 1$, then $n$ and $\phi(n)$ are coprime
2. For a prime $p$, $\phi(p) = p-1$, so we need $\gcd(p, p-1) = 1$ (which is always true)
3. For a prime power $p^k$, $\phi(p^k) = p^{k-1}(p-1)$, so we need $\gcd(p^k, p^{k-1}(p-1)) = 1$
4. This condition is satisfied if and only if $n$ is a product of distinct primes, each of which is one more than a prime

## Mathematical Approach

The key insight is that if $\gcd(n, \phi(n)) = 1$, then $n$ must be of the form where all prime factors of $n$ are of the form $p = q + 1$ where $q$ is prime.

This means we're looking for numbers that are products of distinct primes $p$ such that $p-1$ is also prime (twin primes).

## Solution Strategy

1. Generate all primes up to a reasonable limit
2. Find primes $p$ where $p-1$ is also prime (twin primes)
3. Count all possible products of these primes that are less than $10^{18}$

```kotlin
import java.math.BigInteger

fun main() {
    val limit = BigInteger("10").pow(18)
    
    // Generate primes up to a reasonable limit using Sieve of Eratosthenes
    val sieveLimit = 1_000_000
    val primes = sieveOfEratosthenes(sieveLimit)
    
    // Find primes p where p-1 is also prime (twin primes)
    val validPrimes = mutableSetOf<Int>()
    val primeSet = primes.toSet()
    
    for (p in primes) {
        if (p > 2 && primeSet.contains(p - 1)) {
            validPrimes.add(p)
        }
    }
    
    // Count valid numbers using inclusion-exclusion principle
    val result = countValidNumbers(validPrimes, limit)
    println(result)
}

fun sieveOfEratosthenes(limit: Int): List<Int> {
    val isPrime = BooleanArray(limit + 1) { true }
    isPrime[0] = false
    isPrime[1] = false
    
    for (i in 2..Math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit step i) {
                isPrime[j] = false
            }
        }
    }
    
    return (2..limit).filter { isPrime[it] }
}

fun countValidNumbers(validPrimes: Set<Int>, limit: BigInteger): Long {
    var count = 0L
    
    // Use recursive approach to generate all valid products
    fun generateProducts(index: Int, currentProduct: BigInteger) {
        if (currentProduct >= limit) return
        
        if (index < validPrimes.size) {
            val prime = validPrimes.elementAt(index)
            val newProduct = currentProduct * prime.toBigInteger()
            
            // Include this prime
            if (newProduct < limit) {
                count++
                generateProducts(index + 1, newProduct)
            }
            
            // Skip this prime
            generateProducts(index + 1, currentProduct)
        } else {
            // Base case - we've processed all primes
            if (currentProduct < limit) {
                count++
            }
        }
    }
    
    // Generate all valid products
    generateProducts(0, BigInteger.ONE)
    
    return count
}
```
