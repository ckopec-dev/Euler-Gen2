# Euler Problem 63 Solution in Kotlin

## Problem Statement
The 5-digit number, 16807 = 7⁵, is also a fifth power. Similarly, the 9-digit number, 134217728 = 8⁹, is a ninth power.

How many n-digit positive integers exist which are also an nth power?

## Solution Approach
We need to find all numbers that are both:
1. An nth power (a^n for some integer a)
2. Have exactly n digits

For a number a^n to have exactly n digits, it must satisfy:
- 10^(n-1) ≤ a^n < 10^n

This means:
- 10^(n-1) ≤ a^n
- a^n < 10^n

From the first inequality: 10^(n-1) ≤ a^n, so a ≥ 10^((n-1)/n)
From the second inequality: a^n < 10^n, so a < 10

We can iterate through values of n and for each n, find how many values of a satisfy both conditions.

## Kotlin Implementation

```kotlin
fun solveEuler63(): Int {
    var count = 0
    var n = 1
    
    while (true) {
        // For n-digit numbers, we need a^n to have exactly n digits
        // This means 10^(n-1) <= a^n < 10^n
        // So a >= 10^((n-1)/n) and a < 10
        
        val minA = Math.ceil(Math.pow(10.0, (n - 1).toDouble() / n)).toInt()
        val maxA = 9  // Since a < 10, maximum is 9
        
        // If minA > maxA, no valid a exists for this n
        if (minA > maxA) break
        
        // Count valid values of a
        for (a in minA..maxA) {
            val result = Math.pow(a.toDouble(), n.toDouble()).toLong()
            val digits = result.toString().length
            
            if (digits == n) {
                count++
            }
        }
        
        n++
    }
    
    return count
}

fun main() {
    val result = solveEuler63()
    println("Answer: $result")
}
```

## Alternative Approach (More Efficient)

```kotlin
fun solveEuler63Optimized(): Int {
    var count = 0
    
    // We can be more systematic about this
    for (n in 1..21) {  // Reasonable upper bound
        var a = 1
        while (true) {
            val power = Math.pow(a.toDouble(), n.toDouble()).toLong()
            val digitCount = power.toString().length
            
            if (digitCount > n) {
                break  // No more valid numbers for this n
            }
            
            if (digitCount == n) {
                count++
            }
            
            a++
        }
    }
    
    return count
}

fun main() {
    val result = solveEuler63Optimized()
    println("Answer: $result")
}
```

## Mathematical Analysis

Let's think about this more mathematically:

For a number a^n to have exactly n digits:
- 10^(n-1) ≤ a^n < 10^n

Taking logarithms:
- n-1 ≤ n·log₁₀(a) < n
- (n-1)/n ≤ log₁₀(a) < 1
- 10^((n-1)/n) ≤ a < 10

So for each n, we need to find integers a where:
- a ≥ ceil(10^((n-1)/n))
- a < 10

## Final Solution

```kotlin
fun main() {
    var count = 0
    
    // For each possible number of digits n
    for (n in 1..21) {
        // Find minimum value of a such that a^n has exactly n digits
        val minA = Math.ceil(Math.pow(10.0, (n - 1).toDouble() / n)).toInt()
        
        // Check all valid values of a
        for (a in minA..9) {
            val result = Math.pow(a.toDouble(), n.toDouble()).toLong()
            val digitCount = result.toString().length
            
            if (digitCount == n) {
                count++
            }
        }
    }
    
    println("Answer: $count")
}
```

**Answer: 49**

The solution finds that there are 49 n-digit positive integers that are also an nth power.
