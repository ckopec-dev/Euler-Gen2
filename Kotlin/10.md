# Euler Problem 10 Solution in Kotlin

## Problem Statement
The sum of the primes below 10 is 2 + 3 + 5 + 7 = 17.
Find the sum of all the primes below two million.

## Solution

```kotlin
fun main() {
    val limit = 2000000
    val sum = sumOfPrimesBelow(limit)
    println("Sum of all primes below $limit: $sum")
}

fun sumOfPrimesBelow(limit: Int): Long {
    if (limit < 2) return 0
    
    val isPrime = BooleanArray(limit) { true }
    isPrime[0] = false
    isPrime[1] = false
    
    // Sieve of Eratosthenes
    for (i in 2..kotlin.math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i until limit step i) {
                isPrime[j] = false
            }
        }
    }
    
    // Sum all primes
    var sum = 0L
    for (i in 2 until limit) {
        if (isPrime[i]) {
            sum += i
        }
    }
    
    return sum
}
```

## Explanation

This solution uses the **Sieve of Eratosthenes** algorithm to efficiently find all prime numbers below the given limit:

1. **Initialize**: Create a boolean array `isPrime` where each index represents whether that number is prime
2. **Mark non-primes**: Starting from 2, mark all multiples of each prime number as non-prime
3. **Optimization**: Only check up to √limit since larger factors would have been found already
4. **Sum primes**: Add all numbers that remain marked as prime

## Key Features

- **Efficient algorithm**: Sieve of Eratosthenes has O(n log log n) time complexity
- **Memory optimization**: Uses boolean array instead of storing all primes
- **Long return type**: Uses `Long` to handle large sums that exceed `Int` range
- **Edge case handling**: Properly handles limits less than 2
