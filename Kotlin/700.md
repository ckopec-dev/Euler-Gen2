# Euler Problem 700 Solution in Kotlin

I'll solve Euler Problem 700, which asks for the number of ways to write a number as a sum of powers of 2.

## Problem Understanding

Euler Problem 700 asks: "How many ways are there to write 10^20 as a sum of powers of 2, where each power of 2 can be used at most twice?"

This is essentially asking for the number of representations of a number as a sum of powers of 2, with each power appearing at most twice.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to represent a number using powers of 2, where each power can be used 0, 1, or 2 times.

                result += helper(remaining - used, maxPower - 1)

                break
            }

fun solveEuler700(): Long {
    val target = BigInteger("10").pow(20)
    val memo = mutableMapOf<Pair<BigInteger, Int>, Long>()
    
    fun countWays(remaining: BigInteger, maxPower: Int): Long {
        if (remaining == BigInteger.ZERO) return 1L
        if (remaining < BigInteger.ZERO || maxPower < 0) return 0L
        
        val key = Pair(remaining, maxPower)
        if (memo.containsKey(key)) {
            return memo[key]!!
        }
        
        val powerValue = BigInteger("2").pow(maxPower)
        var result = 0L
        
        // Try using 0, 1, or 2 of the current power
        for (count in 0..2) {
            val used = powerValue.multiply(BigInteger.valueOf(count.toLong()))
            if (used <= remaining) {
                result += countWays(remaining - used, maxPower - 1)
            } else {
                break
            }
        }
        
        memo[key] = result
        return result
    }
    
    val maxPower = target.bitLength() - 1
    return countWays(target, maxPower)
}

## Explanation

The solution works as follows:

1. **Problem Analysis**: We need to count the number of ways to represent 10^20 as a sum of powers of 2, where each power can be used at most twice.

2. **Approach**: Use recursive dynamic programming with memoization:
   - For each number, try using 0, 1, or 2 of each power of 2
   - Use memoization to avoid recalculating the same subproblems
   - Start with the largest power and work down

3. **Key Components**:
   - `countWays` function that recursively computes the number of ways
   - Memoization using `Pair<BigInteger, Int>` as key
   - Bit manipulation to determine the maximum power needed

4. **Time Complexity**: O(log²(n)) where n = 10^20, since we have at most log(n) different powers and for each power we try at most 3 possibilities.
