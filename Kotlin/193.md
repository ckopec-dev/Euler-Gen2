# Euler Problem 193 Solution in Kotlin

## Problem Statement
A positive integer n is called squarefree if no square of a prime divides n. For example, 10 = 2 × 5 is squarefree, but 18 = 2 × 3² is not, because 3² divides 18.

Let S(N) be the number of squarefree integers n such that 1 ≤ n ≤ N.

It can be shown that S(1000000) = 608383.

Find S(50000000).

## Solution Approach
This is a classic inclusion-exclusion principle problem. We need to count integers that are NOT divisible by any perfect square (other than 1).

The approach:
1. Use inclusion-exclusion principle
2. Count numbers divisible by squares of primes
3. Apply inclusion-exclusion to avoid overcounting

## Kotlin Implementation

fun main() {
    val limit = 50000000L
    val result = squarefreeCount(limit)
    println(result)
}

fun squarefreeCount(n: Long): Long {
    val primes = sieveOfEratosthenes(findPrimesLimit(n))
    
    // Use inclusion-exclusion principle
    var count = 0L
    
    // Generate all possible products of distinct primes
    val products = mutableListOf<Long>()
    
    // Generate all square-free products of primes
    generateProducts(primes, 1L, 0, n, products)
    
    // Apply inclusion-exclusion
    for (i in 1..products.size) {
        val product = products[i - 1]
        val countForProduct = n / (product * product)
        
        if (i % 2 == 1) {
            count += countForProduct
        } else {
            count -= countForProduct
        }
    }
    
    // Total numbers minus those that are NOT squarefree
    return n - count
}

fun generateProducts(primes: List<Long>, currentProduct: Long, startIndex: Int, limit: Long, products: MutableList<Long>) {
    if (currentProduct > limit) return
    
    // Add current product to our list
    if (currentProduct <= limit) {
        products.add(currentProduct)
    }
    
    // Generate products by multiplying with remaining primes
    for (i in startIndex until primes.size) {
        val newProduct = currentProduct * primes[i]
        if (newProduct > limit) break
        generateProducts(primes, newProduct, i + 1, limit, products)
    }
}

fun findPrimesLimit(n: Long): Long {
    // We need primes up to sqrt(n) for our calculation
    // But since we're looking at products of squares, we need more
    // Actually, we need primes up to sqrt(n) because we're looking at n/p²
    return sqrt(n.toDouble()).toLong() + 1000
}

fun sieveOfEratosthenes(limit: Long): List<Long> {
    val isPrime = BooleanArray(limit.toInt() + 1) { true }
    isPrime[0] = false
    isPrime[1] = false
    
    for (i in 2..sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit.toInt() step i) {
                isPrime[j] = false
            }
        }
    }
    
    return (2..limit.toInt()).filter { isPrime[it] }.map { it.toLong() }
}

fun squarefreeCountOptimized(n: Long): Long {
    val primes = sieveOfEratosthenes(sqrt(n.toDouble()).toLong() + 1000)
    
    var result = n
    val numPrimes = primes.size
    
    // For each subset of primes (using bit manipulation)
    for (mask in 1 until (1 shl numPrimes)) {
        var product = 1L
        var bits = 0
        
        for (i in 0 until numPrimes) {
            if (mask and (1 shl i) != 0) {
                // Check if product would overflow
                if (product > n / (primes[i] * primes[i])) {
                    product = -1L  // Mark as invalid
                    break
                }
                product *= primes[i] * primes[i]
                bits++
            }
        }
        
        if (product != -1L) {
            val count = n / product
            if (bits % 2 == 1) {
                result -= count
            } else {
                result += count
            }
        }
    }
    
    return result

## Explanation

This solution uses the inclusion-exclusion principle:

1. **Total numbers**: We start with all numbers from 1 to N
2. **Subtract**: Numbers divisible by squares of primes (these are NOT squarefree)
3. **Add back**: Numbers divisible by products of two distinct prime squares (since we subtracted them twice)
4. **Continue**: Alternate adding and subtracting for higher-order intersections

The key insight is that we want to count numbers that are NOT divisible by any perfect square > 1, which is equivalent to counting numbers that are squarefree.

The time complexity is O(2^k) where k is the number of primes up to √N, which is manageable for this problem.
