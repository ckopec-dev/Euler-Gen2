# Euler Problem 230 Solution in Kotlin

I'll solve Euler Problem 230, which involves finding the nth digit in a sequence generated by a specific rule.

## Problem Understanding

Euler Problem 230 asks us to find the nth digit in a sequence where:
- S₁ = "1"
- S₂ = "2" 
- Sₙ = Sₙ₋₁ + Sₙ₋₂ for n > 2 (concatenation)
- We need to find the dth digit in the infinite sequence

## Solution Approach

I'll use a recursive approach with memoization to efficiently calculate the length of each sequence and determine which part of the sequence contains the desired digit.

fun findDigit(position: Long, lengths: Map<Int, Long>): Char {
    // Find which sequence S_n contains the position
    var n = 1
    var totalLength = lengths[1]!!
    
    while (totalLength < position) {
        n++
        totalLength += lengths[n]!!
    }
    
    // If we found the exact sequence, we need to find the position within it
    if (totalLength == position) {
        // If position is at the end of a sequence, we need to check the previous one
        if (n > 2) {
            return findDigit(position - lengths[n-1]!!, lengths)
        }
    }
    
    // If we're in S_n where n > 2, we need to determine if it's in S_{n-1} or S_{n-2}
    if (n > 2) {
        val lengthNMinus1 = lengths[n-1]!!
        if (position <= lengthNMinus1) {
            // Position is in S_{n-1}
            return findDigit(position, lengths)
        } else {
            // Position is in S_{n-2}
            return findDigit(position - lengthNMinus1, lengths)
        }
    } else {
        // We're in S_1 or S_2
        return if (n == 1) '1' else '2'
    }
}
