# Euler Problem 74 Solution in Kotlin

## Problem Statement
The number 145 is well known for the property that the sum of the factorial of its digits is equal to 145:
1! + 4! + 5! = 1 + 24 + 120 = 145

Perhaps less well known is 169, in that it produces the longest chain of numbers that link back to 169? 
It turns out that there are only three such loops that exist:
- 169 → 363601 → 1454 → 169
- 871 → 45361 → 871
- 872 → 45362 → 872

Starting with any positive integer, we form a sequence by repeatedly replacing the number with the sum of the factorial of its digits.
The chain of numbers will eventually reach a loop.

How many chains, with a starting number below one million, contain exactly sixty non-repeating terms?

## Solution

```kotlin
fun main() {
    val factorials = IntArray(10) { factorial(it) }
    val chainLengths = mutableMapOf<Int, Int>()
    
    var count = 0
    for (i in 1 until 1_000_000) {
        val length = getChainLength(i, factorials, chainLengths)
        if (length == 60) {
            count++
        }
    }
    
    println(count)
}

fun getChainLength(n: Int, factorials: IntArray, chainLengths: MutableMap<Int, Int>): Int {
    if (n in chainLengths) {
        return chainLengths[n]!!
    }
    
    val visited = mutableSetOf<Int>()
    var current = n
    var length = 0
    
    while (current !in visited) {
        visited.add(current)
        current = current.sumOfFactorialDigits(factorials)
        length++
        
        // If we've already computed the chain length for this number, we can stop
        if (current in chainLengths) {
            length += chainLengths[current]!!
            break
        }
    }
    
    // Memoize the chain lengths for all numbers in the current chain
    val chainElements = visited.toList()
    for (i in chainElements.indices) {
        val element = chainElements[i]
        if (element !in chainLengths) {
            chainLengths[element] = length - i
        }
    }
    
    return length
}

fun Int.sumOfFactorialDigits(factorials: IntArray): Int {
    var sum = 0
    var num = this
    while (num > 0) {
        sum += factorials[num % 10]
        num /= 10
    }
    return sum
}

fun factorial(n: Int): Int {
    if (n <= 1) return 1
    var result = 1
    for (i in 2..n) {
        result *= i
    }
    return result
}
```

## Explanation

This solution uses dynamic programming with memoization to efficiently compute chain lengths:

1. **Precompute factorials**: We calculate factorials 0! through 9! once and store them in an array.

2. **Memoization approach**: We use a `chainLengths` map to store previously computed chain lengths to avoid redundant calculations.

3. **Chain computation**: For each starting number, we follow the chain until we either:
   - Reach a number we've seen before (indicating a loop)
   - Find a number whose chain length we've already computed

4. **Optimization**: When we detect a loop or reach a previously computed number, we can determine the full chain length and memoize all intermediate numbers in the current chain.

5. **Counting**: We count how many chains have exactly 60 terms.

The key insight is that once we know the chain length for any number in a sequence, we can compute the chain lengths for all numbers in that sequence efficiently.

**Answer: 402**
