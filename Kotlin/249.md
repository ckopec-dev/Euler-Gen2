# Euler Problem 249 Solution in Kotlin

This problem asks us to find the number of ways to select a subset of primes less than 100,000 such that the sum of the selected primes is a prime number.

Let me solve this step by step:

```kotlin
import java.math.BigInteger

fun main() {
    // Generate all primes less than 100,000
    val primes = sieveOfEratosthenes(100000)
    
    // Calculate sum of all primes
    val totalSum = primes.sumOf { it.toLong() }
    
    // Use dynamic programming to count subsets with each possible sum
    // dp[i] = number of ways to achieve sum i
    val dp = LongArray(totalSum.toInt() + 1) { 0 }
    dp[0] = 1
    
    for (prime in primes) {
        // Traverse backwards to avoid using updated values in same iteration
        for (i in totalSum downTo prime) {
            dp[i] += dp[i - prime]
        }
    }
    
    // Count how many of these subset sums are themselves prime
    var result = 0L
    for (i in 0..totalSum) {
        if (dp[i] > 0 && isPrime(i)) {
            result += dp[i]
        }
    }
    
    println(result)
}

fun sieveOfEratosthenes(limit: Int): List<Int> {
    val isPrime = BooleanArray(limit + 1) { true }
    isPrime[0] = isPrime[1] = false
    
    for (i in 2..kotlin.math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit step i) {
                isPrime[j] = false
            }
        }
    }
    
    return (2..limit).filter { isPrime[it] }
}

fun isPrime(n: Int): Boolean {
    if (n < 2) return false
    if (n == 2) return true
    if (n % 2 == 0) return false
    
    for (i in 3..kotlin.math.sqrt(n.toDouble()).toInt() step 2) {
        if (n % i == 0) return false
    }
    return true
}
```

```kotlin
fun main() {
    val primes = sieveOfEratosthenes(100000)
    
    // Use dynamic programming with map for efficient memory usage
    val dp = mutableMapOf(0 to 1L)
    
    for (prime in primes) {
        val newDp = mutableMapOf<Int, Long>()
        // Copy existing entries
        for ((sum, count) in dp) {
            newDp[sum] = newDp.getOrDefault(sum, 0L) + count
        }
        // Add new entries with current prime
        for ((sum, count) in dp) {
            val newSum = sum + prime
            newDp[newSum] = newDp.getOrDefault(newSum, 0L) + count
        }
        dp.clear()
        dp.putAll(newDp)
    }
    
    // Count subset sums that are prime
    var result = 0L
    for ((sum, count) in dp) {
        if (isPrime(sum)) {
            result += count
        }
    }
    
    println(result)
}
```

The solution works by:

1. **Generating primes**: Using the Sieve of Eratosthenes to find all primes less than 100,000
2. **Dynamic Programming**: For each prime, we update our count of possible subset sums
3. **Prime checking**: For each possible subset sum, we check if it's prime
4. **Counting**: Sum up all valid combinations where the subset sum is prime

The time complexity is manageable due to the efficient DP approach and the fact that we only need to consider primes up to 100,000.
