# Euler Problem 381 Solution in Kotlin

## Problem Statement
Let f(n) be the largest integer r such that n^r divides r!.
For example, f(3) = 1 because 3^1 divides 1! = 1, but 3^2 = 9 does not divide 1! = 1.
Also f(6) = 1 because 6^1 divides 1! = 1, but 6^2 = 36 does not divide 1! = 1.
Let S(n) = Σ f(k) for k = 1 to n.
Find S(10^8) mod 10^9.

## Solution Approach
This is a complex number theory problem. The key insight is that f(n) is related to the largest power of n that divides n!.

// Sieve of Eratosthenes to get primes up to n
fun sieveOfEratosthenes(limit: Int): List<Int> {
    val isPrime = BooleanArray(limit + 1) { true }
    isPrime[0] = false
    isPrime[1] = false
    
    for (i in 2..kotlin.math.sqrt(limit.toDouble()).toInt()) {
        if (isPrime[i]) {
            for (j in i * i..limit step i) {
                isPrime[j] = false
            }
        }
    }
    
    return (2..limit).filter { isPrime[it] }
}
