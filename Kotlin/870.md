I need to solve Euler Problem 870, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

Let me break down the problem:
- We want to count the number of ways to express a number n as a sum of powers of 2
- Each power of 2 can be used at most twice
- This is essentially counting the number of partitions where each part (power of 2) appears at most twice

```kotlin
    // Memoization cache
    val memo = mutableMapOf<Pair<Int, Int>, Long>()
    
    // Recursive function to count partitions
    fun countPartitions(remaining: Int, maxPower: Int): Long {
        // Base cases
        if (remaining == 0) return 1L
        if (remaining < 0 || maxPower < 0) return 0L
        
        // Check memoization
        val key = Pair(remaining, maxPower)
        if (memo.containsKey(key)) return memo[key]!!
        
        val powerOf2 = 1L shl maxPower  // 2^maxPower
        
        // We can use 0, 1, or 2 of this power of 2
        val result = countPartitions(remaining, maxPower - 1) +  // Use 0 of this power
                     if (remaining >= powerOf2) countPartitions(remaining - powerOf2, maxPower - 1) else 0L +  // Use 1 of this power
                     if (remaining >= 2 * powerOf2) countPartitions(remaining - 2 * powerOf2, maxPower - 1) else 0L  // Use 2 of this power
        
        memo[key] = result
        return result
    }
    
    // Find the maximum power needed
    val maxPower = if (target > 0) 31 - Integer.numberOfLeadingZeros(target) else -1
    
    return countPartitions(target, maxPower)
}
```

```kotlin
fun solveEuler870(target: Int): Long {
    if (target == 0) return 1L
    
    // dp[i] = number of ways to make sum i using powers of 2 with each used at most twice
    val dp = LongArray(target + 1) { 0L }
    dp[0] = 1L
    
    var power = 1L
    while (power <= target) {
        // Process from right to left to avoid using updated values in same iteration
        for (i in target downTo 0) {
            // Use 0 of current power (already handled by previous state)
            // Use 1 of current power
            if (i >= power) {
                dp[i] += dp[i - power]
            }
            // Use 2 of current power  
            if (i >= 2 * power) {
                dp[i] += dp[i - 2 * power]
            }
        }
        power *= 2
    }
    
    return dp[target]
}

fun main() {
    // The actual answer for Euler Problem 870 with target 10^6
    val result = solveEuler870(1000000)
    println("Euler Problem 870 answer: $result")
}
```

This solution uses dynamic programming where:
1. We build up the solution by considering each power of 2
2. For each power, we update our dp array from right to left to avoid using values that were already updated in the same iteration
3. For each sum i, we can use 0, 1, or 2 of the current power of 2
4. The time complexity is O(target × log(target)) and space complexity is O(target)
