# Euler Problem 518 Solution in Kotlin

## Problem Statement
We define a function F(n) as the number of ways to write n as a sum of powers of 2 where each power can be used at most twice. For example, F(10) = 5 because:
- 10 = 8 + 2
- 10 = 8 + 1 + 1
- 10 = 4 + 4 + 2
- 10 = 4 + 2 + 2 + 1 + 1
- 10 = 2 + 2 + 2 + 2 + 2

Find the sum of F(n) for n from 1 to 10^12.

## Solution Approach
This is a classic dynamic programming problem. We need to count the number of ways to represent numbers as sums of powers of 2 where each power can be used at most twice.

Let's think of this recursively:
- F(n) = sum of F(n - 2^k) for all valid k where 2^k ≤ n
- But we need to ensure each power of 2 is used at most twice

We can use dynamic programming with memoization or generate all possible combinations.

However, given the large constraint (10^12), we need a more mathematical approach.

Let's use the fact that this is equivalent to counting partitions with restricted multiplicities.
