# Euler Problem 107 Solution

## Problem Statement
The problem asks us to find the maximum saving possible by removing redundant edges from a network while keeping it connected.

## Solution Approach
This is essentially finding the Minimum Spanning Tree (MST) of a graph. We need to:
1. Read the network as a weighted graph
2. Find the total weight of all edges
3. Find the MST weight using Kruskal's or Prim's algorithm
4. Calculate the difference as the maximum saving

## Python Implementation

def find(parent, i):
    """Find root of element with path compression"""
    if parent[i] == i:
        return i
    parent[i] = find(parent, parent[i])
    return parent[i]

def union(parent, rank, x, y):
    """Union two sets with union by rank"""
    x_root = find(parent, x)
    y_root = find(parent, y)
    
    if rank[x_root] < rank[y_root]:
        parent[x_root] = y_root
    elif rank[x_root] > rank[y_root]:
        parent[y_root] = x_root
    else:
        parent[y_root] = x_root
        rank[x_root] += 1

def kruskal_mst(edges, num_vertices):
    """Find MST using Kruskal's algorithm"""
    # Sort edges by weight
    edges.sort(key=lambda x: x[2])
    
    parent = list(range(num_vertices))
    rank = [0] * num_vertices
    
    mst_weight = 0
    edge_count = 0
    
    for u, v, weight in edges:
        if edge_count == num_vertices - 1:
            break
            
        if find(parent, u) != find(parent, v):
            union(parent, rank, u, v)
            mst_weight += weight
            edge_count += 1
    
    return mst_weight

## Key Points

1. **Algorithm Choice**: Used Kruskal's algorithm with Union-Find for efficient MST computation
2. **Data Structure**: Converted adjacency matrix to edge list representation
3. **Optimization**: Used path compression and union by rank for efficient Union-Find operations
4. **Result**: The difference between total edge weight and MST weight gives maximum saving

## Time Complexity
- O(E log E) where E is the number of edges
- Dominated by sorting edges

## Space Complexity
- O(V + E) where V is vertices and E is edges
