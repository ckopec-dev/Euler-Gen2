## Problem Statement
Euler Problem 804 asks us to find the sum of all integers n ≤ 10^12 such that the number of divisors of n is exactly 1000.

## Analysis

First, let's understand what it means for a number to have exactly 1000 divisors.

If n has the prime factorization n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then the number of divisors is:
d(n) = (a₁ + 1)(a₂ + 1)...(aₖ + 1) = 1000

So we need to find all possible ways to write 1000 as a product of integers ≥ 2, and then find all numbers n ≤ 10^12 that correspond to these factorizations.

    """Return prime factorization as a dictionary"""
    factors = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors
