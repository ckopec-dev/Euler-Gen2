## Problem Understanding

This is about counting the number of moves required to display numbers on a 7-segment display. Each digit is represented by lighting up specific segments, and we need to count how many segment changes occur when transitioning from one number to another.

## Analysis

1. **7-segment display**: Each digit 0-9 requires specific segments to be lit
2. **Segment representation**: Each segment can be represented as a bit in a binary number
3. **Transition cost**: The cost to change from one digit to another is the number of segments that need to be turned on/off

def solve_euler_315():
    # Define which segments are lit for each digit (0-9)
    # Segments are numbered 0-6 (from top to bottom, left to right)
    segments = [
        0b1111110,  # 0: all segments except bottom
        0b0110000,  # 1: only top segment
        0b1101101,  # 2: top, middle, bottom, left-bottom, right-top
        0b1111001,  # 3: top, middle, bottom, right-top, right-bottom
        0b0110011,  # 4: middle, right-top, right-bottom
        0b1011011,  # 5: top, bottom, left-top, left-bottom, right-bottom
        0b1011111,  # 6: top, bottom, left-top, left-bottom, right-top, right-bottom
        0b1110000,  # 7: top, middle, bottom
        0b1111111,  # 8: all segments
        0b1111011   # 9: all segments except left-bottom
    ]
    
    def count_bits(n):
        """Count number of 1-bits in binary representation"""
        return bin(n).count('1')
    
    def get_transition_cost(from_digit, to_digit):
        """Calculate cost to transition from one digit to another"""
        # XOR gives us the bits that differ
        diff = segments[from_digit] ^ segments[to_digit]
        # Count the number of bits that change
        return count_bits(diff)
    
    def get_number_cost(number):
        """Calculate total cost to display a number"""
        # Convert number to string to process each digit
        digits = [int(d) for d in str(number)]
        total_cost = 0
        
        # For each consecutive pair of digits, add transition cost
        for i in range(len(digits) - 1):
            total_cost += get_transition_cost(digits[i], digits[i + 1])
            
        return total_cost
    
    # Calculate the sum for all numbers from 1 to 10^7
    total_sum = 0
    for num in range(1, 10**7 + 1):
        total_sum += get_number_cost(num)
        
    return total_sum
