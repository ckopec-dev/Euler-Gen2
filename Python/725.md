# Euler Problem 725 Solution

I'll solve Euler Problem 725 step by step.

## Problem Statement
Find the sum of all positive integers n ≤ 10^11 such that n has exactly 11 divisors.

## Analysis
First, I need to understand when a number has exactly 11 divisors.

If a number n has the prime factorization n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then the number of divisors is (a₁ + 1)(a₂ + 1)...(aₖ + 1).

For the number of divisors to equal 11, since 11 is prime, we need:
- Either n = p^10 for some prime p (since 10 + 1 = 11)
- Or n = p₁^a₁ × p₂^a₂ where (a₁ + 1)(a₂ + 1) = 11

Since 11 is prime, the second case is impossible because 11 cannot be factored as a product of two integers greater than 1.

Therefore, n must be of the form p^10 where p is prime.

## Solution Approach
I need to:
1. Find all primes p such that p^10 ≤ 10^11
2. Calculate p^10 for each such prime
3. Sum all these values

Let me find the upper bound for primes:
If p^10 ≤ 10^11, then p ≤ (10^11)^(1/10) = 10^1.1 ≈ 12.59

So I need primes p ≤ 12.

## Implementation

```python
def sieve_of_eratosthenes(limit):
    """Generate all prime numbers up to limit using Sieve of Eratosthenes"""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False
    
    for i in range(2, int(limit**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, limit + 1, i):
                is_prime[j] = False
    
    return [i for i in range(2, limit + 1) if is_prime[i]]

def solve():
    # Find all primes up to 13 (since 13^10 > 10^11)
    primes = sieve_of_eratosthenes(13)
    
    # Calculate sum of p^10 for all primes p such that p^10 <= 10^11
    total_sum = 0
    for p in primes:
        power = p ** 10
        if power <= 10**11:
            total_sum += power
        else:
            break
    
    return total_sum

# Calculate the result
result = solve()
print(f"The sum is: {result}")
```
