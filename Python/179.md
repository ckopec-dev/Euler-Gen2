## Problem Statement
Find the number of integers 1 < n < 10^7 for which n and n + 1 have the same number of divisors.

## Analysis
1. For each integer n from 2 to 9,999,999, I need to:
   - Count the number of divisors of n
   - Count the number of divisors of n + 1
   - Check if they're equal
2. Return the count of such integers

## Approach
I'll use an efficient method to count divisors by iterating up to √n and counting pairs of divisors.

## Solution

```python
def count_divisors(n):
    """Count the number of divisors of n"""
    count = 0
    sqrt_n = int(n**0.5)
    
    for i in range(1, sqrt_n + 1):
        if n % i == 0:
            if i * i == n:
                count += 1  # Perfect square case
            else:
                count += 2  # Count both i and n/i
    
    return count

def solve():
    """Solve Euler Problem 179"""
    limit = 10**7
    count = 0
    
    # Precompute divisor counts for efficiency
    divisor_counts = [0] * (limit + 1)
    
    # Calculate divisor counts for all numbers
    for i in range(1, limit + 1):
        for j in range(i, limit + 1, i):
            divisor_counts[j] += 1
    
    # Check consecutive numbers
    for n in range(2, limit):
        if divisor_counts[n] == divisor_counts[n + 1]:
            count += 1
    
    return count
```
