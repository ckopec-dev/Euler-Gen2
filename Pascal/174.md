# Euler Problem 174 Solution in Pascal

## Problem Statement
We shall define a square lamina to be an arrangement of unit squares which forms a square with a square hole in the center. Let's call a square lamina that can be tiled with exactly t unit squares, a "t-lamina".

For example, using exactly thirty-six unit squares we can form two different square laminae:
- One with a 6×6 square and a 4×4 hole (area = 36 - 16 = 20)
- One with a 5×5 square and a 3×3 hole (area = 25 - 9 = 16)

However, we are interested in the number of ways to tile a square lamina with exactly t unit squares.

## Solution Approach
We need to find how many different square laminae can be formed with exactly t unit squares.

For a square lamina with outer square of size n and inner square of size m, the area is:
Area = n² - m²

We want to count how many pairs (n,m) satisfy n² - m² = t where n > m > 0.

This can be factored as: (n+m)(n-m) = t

Let's iterate through all possible values of n and m to count valid combinations.
