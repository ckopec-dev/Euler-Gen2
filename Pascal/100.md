# Euler Problem 100 Solution in Pascal

## Problem Statement
Finding the number of blue discs for which there is a 50% chance of taking two blue discs.

## Mathematical Analysis

Let's say we have `b` blue discs and `t` total discs. The probability of drawing two blue discs is:
$$P = \frac{b}{t} \times \frac{b-1}{t-1} = \frac{b(b-1)}{t(t-1)}$$

We want this probability to equal 0.5:
$$\frac{b(b-1)}{t(t-1)} = \frac{1}{2}$$

Rearranging:
$$2b(b-1) = t(t-1)$$
$$2b^2 - 2b = t^2 - t$$
$$2b^2 - 2b - t^2 + t = 0$$
$$2b^2 - 2b = t^2 - t$$

This can be rewritten as:
$$2b(b-1) = t(t-1)$$

This is a Pell-like equation. We can solve it using the recurrence relation approach.

## Pascal Solution

```pascal
program Euler100;
{$APPTYPE CONSOLE}

var
  b1, b2, t1, t2: int64;
  b, t: int64;
  limit: int64;

begin
  // Initial values for the recurrence relation
  // Starting with b = 1, t = 2 (which gives probability 1/2)
  b1 := 1;
  t1 := 2;
  
  // Next values in sequence
  b2 := 3;
  t2 := 4;
  
  limit := 1000000000000; // 10^12
  
  writeln('Finding the number of blue discs for which there is a 50% chance of taking two blue discs');
  writeln('Looking for solutions where total discs exceed 10^12');
  writeln;
  
  // We need to find the first solution where t > 10^12
  b := b2;
  t := t2;
  
  // Generate the sequence using recurrence relation
  // From the Pell equation, we have the recurrence:
  // b_{n+1} = 3*b_n + 2*t_n - 2
  // t_{n+1} = 4*b_n + 3*t_n - 3
  
  while t <= limit do
  begin
    // Calculate next terms using recurrence relation
    b := 3 * b2 + 2 * t2 - 2;
    t := 4 * b2 + 3 * t2 - 3;
    
    b1 := b2;
    t1 := t2;
    b2 := b;
    t2 := t;
  end;
  
  writeln('The number of blue discs is: ', b1);
  writeln('Total discs is: ', t1);
  
  // Verify the solution
  if (b1 * (b1 - 1)) * 2 = t1 * (t1 - 1) then
    writeln('Verification: Probability = ', (b1 * (b1 - 1)) / (t1 * (t1 - 1)))
  else
    writeln('Error in calculation');
  
  readln;
end.
```

## Alternative Approach (More Direct)

```pascal
program Euler100;
{$APPTYPE CONSOLE}

var
  b, t: int64;
  limit: int64;

begin
  limit := 1000000000000; // 10^12
  
  // Using the recurrence relation approach
  // Based on the Pell equation solution
  b := 1;
  t := 2;
  
  while t <= limit do
  begin
    // Next solution in the sequence
    // b_{n+1} = 3*b_n + 2*t_n - 2
    // t_{n+1} = 4*b_n + 3*t_n - 3
    b := 3 * b + 2 * t - 2;
    t := 4 * b + 3 * t - 3;
  end;
  
  writeln('Answer: ', b);
  writeln('Total discs: ', t);
  
  // Verify the probability
  writeln('Verification: ', (b * (b - 1)) / (t * (t - 1)));
  
  readln;
end.
```

## Explanation

The key insight is that this problem leads to a Pell equation of the form:
$$2b^2 - 2b = t^2 - t$$

The solutions follow a recurrence relation:
- $b_{n+1} = 3b_n + 2t_n - 2$
- $t_{n+1} = 4b_n + 3t_n - 3$

Starting with $b_1 = 1, t_1 = 2$, we generate the sequence until we find the first solution where $t > 10^{12}$.

The answer is the value of $b$ when this condition is met.

## Answer
The number of blue discs is **756872327471**.
