# Euler Problem 95 Solution in Pascal

## Problem Statement
The proper divisors of a number are all the divisors excluding the number itself. For example, the proper divisors of 28 are 1, 2, 4, 7, and 14. As the sum of these divisors is equal to 28, we call it a perfect number.

Interestingly, the sum of the proper divisors of 12 is 16 (1+2+3+4+6=16). If we repeat this process, we get 1+2+4+8=15, then 1+3=4, then 1=1, and we end up at 1. This is called an aliquot sequence.

However, some numbers are part of a cycle. For example, starting with 220, we get:
220 → 284 → 220 → ...

This is called an amicable chain. The longest amicable chain with no element exceeding one million is the chain of length 28.

Find the smallest member of the longest amicable chain with no element exceeding one million.

## Solution

```pascal
program Euler95;
{$APPTYPE CONSOLE}

var
  divisorsSum: array[1..1000000] of longint;
  chainLength: array[1..1000000] of longint;
  visited: array[1..1000000] of boolean;
  maxChainLength: longint;
  result: longint;
  i, j, current, next, chainStart, chainEnd: longint;

procedure PrecomputeDivisorsSum;
var
  k: longint;
begin
  // Initialize all sums to 1 (since 1 is a divisor of all numbers)
  for i := 1 to 1000000 do
    divisorsSum[i] := 1;
  
  // For each number, add it to the divisors sum of its multiples
  for i := 2 to 1000000 div 2 do
  begin
    k := i + i;  // Start from 2*i
    while k <= 1000000 do
    begin
      divisorsSum[k] := divisorsSum[k] + i;
      k := k + i;
    end;
  end;
end;

function FindChainLength(start: longint): longint;
var
  current, next, cycleStart, cycleEnd: longint;
  visitedArray: array[1..1000000] of boolean;
  chain: array[1..1000000] of longint;
  chainIndex: longint;
begin
  // Reset visited array for this chain
  for i := 1 to 1000000 do
    visitedArray[i] := false;
    
  current := start;
  chainIndex := 0;
  
  // Follow the chain until we hit a number > 1000000 or a repeated number
  while (current <= 1000000) and (not visitedArray[current]) do
  begin
    visitedArray[current] := true;
    chain[chainIndex] := current;
    chainIndex := chainIndex + 1;
    current := divisorsSum[current];
  end;
  
  // If we reached a number > 1000000, this chain is invalid
  if current > 1000000 then
  begin
    FindChainLength := 0;
    exit;
  end;
  
  // Check if this is a cycle (the current number is the same as one we've seen)
  // Find where the cycle starts
  for i := 0 to chainIndex - 1 do
  begin
    if chain[i] = current then
    begin
      cycleStart := i;
      break;
    end;
  end;
  
  // If we found a cycle, return the length
  if cycleStart < chainIndex then
  begin
    FindChainLength := chainIndex - cycleStart;
  end
  else
  begin
    FindChainLength := 0;
  end;
end;

function FindSmallestInCycle(start: longint): longint;
var
  current, next, cycleStart, cycleEnd: longint;
  visitedArray: array[1..1000000] of boolean;
  chain: array[1..1000000] of longint;
  chainIndex: longint;
  minVal: longint;
begin
  // Reset visited array for this chain
  for i := 1 to 1000000 do
    visitedArray[i] := false;
    
  current := start;
  chainIndex := 0;
  minVal := current;
  
  // Follow the chain until we hit a number > 1000000 or a repeated number
  while (current <= 1000000) and (not visitedArray[current]) do
  begin
    visitedArray[current] := true;
    chain[chainIndex] := current;
    chainIndex := chainIndex + 1;
    if current < minVal then
      minVal := current;
    current := divisorsSum[current];
  end;
  
  // If we reached a number > 1000000, this chain is invalid
  if current > 1000000 then
  begin
    FindSmallestInCycle := 0;
    exit;
  end;
  
  // Check if this is a cycle (the current number is the same as one we've seen)
  // Find where the cycle starts
  for i := 0 to chainIndex - 1 do
  begin
    if chain[i] = current then
    begin
      cycleStart := i;
      break;
    end;
  end;
  
  // If we found a cycle, return the smallest element in the cycle
  if cycleStart < chainIndex then
  begin
    FindSmallestInCycle := minVal;
  end
  else
  begin
    FindSmallestInCycle := 0;
  end;
end;

begin
  PrecomputeDivisorsSum;
  
  maxChainLength := 0;
  result := 0;
  
  // Check all numbers from 1 to 1000000
  for i := 1 to 1000000 do
  begin
    // Skip if already computed
    if chainLength[i] > 0 then
      continue;
      
    // Find chain length for this number
    chainLength[i] := FindChainLength(i);
    
    // If this is a valid chain and longer than current max
    if (chainLength[i] > 0) and (chainLength[i] > maxChainLength) then
    begin
      maxChainLength := chainLength[i];
      result := FindSmallestInCycle(i);
    end;
  end;
  
  writeln('The smallest member of the longest amicable chain is: ', result);
  writeln('The chain length is: ', maxChainLength);
end.
```

## Explanation

This solution works by:

1. **Precomputing divisor sums**: First, we compute the sum of proper divisors for all numbers up to 1,000,000 using a method similar to the Sieve of Eratosthenes. For each number `i`, we add `i` to the divisor sum of all its multiples.

2. **Finding chains**: For each number, we trace the aliquot sequence by repeatedly applying the divisor sum function until we either:
   - Reach a number greater than 1,000,000 (invalid chain)
   - Encounter a number we've already seen (cycle detected)

3. **Identifying the longest chain**: We keep track of the longest valid chain found and the smallest number in that chain.

The key insight is that we only need to compute each chain once, and we can detect cycles by keeping track of visited numbers during the traversal.

The answer to Euler Problem 95 is **14316**.
