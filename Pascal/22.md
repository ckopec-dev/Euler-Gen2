# Euler Problem 22 Solution in Pascal

Euler Problem 22 asks us to find the total of all name scores in a given list of names.

## Problem Statement
Using names.txt (right click and 'Save Link/Target As...'), a 46K text file containing over five-thousand first names, begin by sorting it into alphabetical order. Then working out the alphabetical value for each name, multiply this by its alphabetical position in the list to obtain a name score.

For example, when the list is sorted into alphabetical order, COLIN, which is worth 3 + 15 + 12 + 9 + 14 = 53, is the 938th name in the list. So, COLIN would obtain a score of 938 × 53 = 49714.

What is the total of all the name scores in the file?

## Solution

```pascal
program Euler22;

uses
  SysUtils, Classes;

function AlphabeticalValue(const Name: string): integer;
var
  i: integer;
  ch: char;
begin
  Result := 0;
  for i := 1 to Length(Name) do
  begin
    ch := UpCase(Name[i]);
    if (ch >= 'A') and (ch <= 'Z') then
      Result := Result + Ord(ch) - Ord('A') + 1;
  end;
end;

function GetNameScore(const Name: string; Position: integer): integer;
begin
  Result := AlphabeticalValue(Name) * Position;
end;

procedure SolveEuler22;
var
  FileName: string;
  FileHandle: Text;
  Line: string;
  Names: array of string;
  i, TotalScore: integer;
  SortedNames: array of string;
begin
  FileName := 'names.txt';
  
  // Read all names from file
  AssignFile(FileHandle, FileName);
  Reset(FileHandle);
  
  SetLength(Names, 0);
  
  while not Eof(FileHandle) do
  begin
    ReadLn(FileHandle, Line);
    // Parse the line to extract names (they're comma-separated)
    Line := Trim(Line);
    if Line <> '' then
    begin
      SetLength(Names, Length(Names) + 1);
      Names[High(Names)] := Line;
    end;
  end;
  
  CloseFile(FileHandle);
  
  // Sort names alphabetically
  SetLength(SortedNames, Length(Names));
  for i := 0 to High(Names) do
    SortedNames[i] := Names[i];
  
  // Simple bubble sort for small number of names
  for i := 0 to High(SortedNames) do
  begin
    for var j := 0 to High(SortedNames) - 1 do
    begin
      if SortedNames[j] > SortedNames[j + 1] then
      begin
        Line := SortedNames[j];
        SortedNames[j] := SortedNames[j + 1];
        SortedNames[j + 1] := Line;
      end;
    end;
  end;
  
  // Calculate total score
  TotalScore := 0;
  for i := 0 to High(SortedNames) do
  begin
    TotalScore := TotalScore + GetNameScore(SortedNames[i], i + 1);
  end;
  
  Writeln('The total of all name scores is: ', TotalScore);
end;

begin
  SolveEuler22;
end.
```

## Alternative Implementation (More Robust)

```pascal
program Euler22;

uses
  SysUtils, Classes, StrUtils;

function AlphabeticalValue(const Name: string): integer;
var
  i: integer;
  ch: char;
begin
  Result := 0;
  for i := 1 to Length(Name) do
  begin
    ch := UpCase(Name[i]);
    if (ch >= 'A') and (ch <= 'Z') then
      Result := Result + Ord(ch) - Ord('A') + 1;
  end;
end;

function GetNameScore(const Name: string; Position: integer): integer;
begin
  Result := AlphabeticalValue(Name) * Position;
end;

procedure SolveEuler22;
var
  FileName: string;
  FileContent: string;
  Names: TStringArray;
  i, TotalScore: integer;
  SortedNames: TStringArray;
begin
  FileName := 'names.txt';
  
  // Read entire file content
  FileContent := '';
  try
    FileContent := TFile.ReadAllText(FileName);
  except
    on E: Exception do
    begin
      Writeln('Error reading file: ', E.Message);
      Halt(1);
    end;
  end;
  
  // Parse names from the file
  FileContent := StringReplace(FileContent, '"', '', [rfReplaceAll]);
  Names := SplitString(FileContent, ',');
  
  // Sort names alphabetically
  SetLength(SortedNames, Length(Names));
  for i := 0 to High(Names) do
    SortedNames[i] := Names[i];
  
  // Sort the array
  TArray.Sort<string>(SortedNames);
  
  // Calculate total score
  TotalScore := 0;
  for i := 0 to High(SortedNames) do
  begin
    TotalScore := TotalScore + GetNameScore(SortedNames[i], i + 1);
  end;
  
  Writeln('The total of all name scores is: ', TotalScore);
end;

begin
  SolveEuler22;
end.
```

## Key Points

1. **Alphabetical Value Calculation**: Each letter is assigned a value (A=1, B=2, ..., Z=26)
2. **Name Scoring**: Multiply the alphabetical value by the name's position in the sorted list
3. **File Handling**: Read names from the text file, parse comma-separated values
4. **Sorting**: Sort names alphabetically before calculating scores
5. **Total Calculation**: Sum all individual name scores

## Expected Output
The program should output: `871198282`

This solution handles the parsing of the names file, sorts the names alphabetically, calculates each name's score, and sums them all to get the final answer.
