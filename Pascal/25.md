# Euler Problem 25 Solution in Pascal

Euler Problem 25 asks: "What is the index of the first term in the Fibonacci sequence to contain 1000 digits?"

Here's the Pascal solution:

```pascal
program Euler25;

type
  TBigNum = array[1..1000] of integer;

var
  fib1, fib2, temp: TBigNum;
  index: integer;
  digits: integer;
  i: integer;
  carry: integer;

function CountDigits(num: TBigNum): integer;
var
  i: integer;
begin
  CountDigits := 0;
  for i := 1000 downto 1 do
  begin
    if num[i] <> 0 then
    begin
      CountDigits := i;
      break;
    end;
  end;
end;

procedure AddBigNums(var result, num1, num2: TBigNum);
var
  i: integer;
  carry: integer;
begin
  carry := 0;
  for i := 1 to 1000 do
  begin
    result[i] := num1[i] + num2[i] + carry;
    carry := result[i] div 10;
    result[i] := result[i] mod 10;
  end;
end;

procedure InitializeBigNum(var num: TBigNum; value: integer);
var
  i: integer;
begin
  for i := 1 to 1000 do
    num[i] := 0;
  num[1] := value;
end;

begin
  // Initialize first two Fibonacci numbers
  InitializeBigNum(fib1, 1);
  InitializeBigNum(fib2, 1);
  
  index := 2;
  
  while true do
  begin
    // Calculate next Fibonacci number
    AddBigNums(temp, fib1, fib2);
    
    // Check if we have 1000 digits
    digits := CountDigits(temp);
    if digits >= 1000 then
    begin
      writeln('The index of the first term with 1000 digits is: ', index + 1);
      break;
    end;
    
    // Shift Fibonacci numbers
    fib1 := fib2;
    fib2 := temp;
    inc(index);
  end;
end.
```

## Explanation

This solution uses a custom big number implementation to handle Fibonacci numbers with 1000+ digits:

1. **Data Structure**: Uses an array `TBigNum` of 1000 integers to represent each digit of a large number
2. **Big Number Operations**: Implements addition with carry handling for large numbers
3. **Digit Counting**: Function to count actual digits in the big number
4. **Main Logic**: 
   - Start with F₁ = 1 and F₂ = 1
   - Generate Fibonacci numbers iteratively
   - Check when the number reaches 1000 digits
   - Return the index of that number

The algorithm efficiently handles the large numbers by storing each digit in an array and performing addition with proper carry propagation.

**Answer**: The index of the first term in the Fibonacci sequence to contain 1000 digits is **4782**.
