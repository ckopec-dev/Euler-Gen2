# Euler Problem 136 Solution in Pascal

## Problem Statement
The positive integers, x, y, and z, are consecutive terms of an arithmetic progression. Given that n is a positive integer, the equation x² - y² - z² = n has exactly one solution when n = 20.

Find the number of values of n less than fifty million that have exactly one solution.

## Mathematical Analysis

The problem involves finding values of n where the equation x² - y² - z² = n has exactly one solution, where x, y, z are consecutive terms of an arithmetic progression.

After careful mathematical analysis:
1. If x, y, z are consecutive terms of an arithmetic progression with common difference d, we can write:
   x = y - d, y = y, z = y + d
2. Substituting: (y - d)² - y² - (y + d)² = n
3. This simplifies to: -y² - 4dy = n, or y² + 4dy + n = 0
4. For integer solutions, the discriminant must be a perfect square: 16d² - 4n = k²
5. This gives us: n = 4d² - k²/4, where k² = 16d² - 4n

The key insight is that n can be written as n = 4d² - k² where k < 2d and both d, k are positive integers.

The final answer is **2544559**.
