# Euler Problem 59 Solution in Pascal

## Problem Statement
Each character on a computer is assigned a unique code and the preferred standard is ASCII (American Standard Code for Information Interchange). For example, A = 65, B = 66, C = 67, etc. The plaintext message "HELLO" would be encoded as:
H = 72, E = 69, L = 76, L = 76, O = 79

The "key" for the one-time pad is a sequence of random numbers. To encrypt, we simply XOR each character with the corresponding key value. For example, if the key is 123, 45, 67, 89, 101, then:
H XOR 123 = 195
E XOR 45 = 102
L XOR 67 = 107
L XOR 89 = 113
O XOR 101 = 112

The encrypted message would be: 195, 102, 107, 113, 112

Now, given that the original text is a known English phrase, and the key is a sequence of three lowercase letters (a-z), find the original text and the sum of the ASCII values in the original text.

function IsEnglishChar(c: char): boolean;
begin
  // Check if character is printable ASCII
  Result := (c >= ' ') and (c <= '~');
end;

var
  i: integer;

  Result := 0;

    c := text[i];

        Result := Result + 2;

        Result := Result + 1;
    end;
  end;
end;

begin

## Explanation

This solution works by:

1. **Reading the encrypted data**: The encrypted data is read from the file `cipher1.txt`
2. **Brute force approach**: Try all possible 3-character keys (a-z) 
3. **Decryption**: For each key, XOR each encrypted value with the corresponding key character
4. **Scoring**: Score each decrypted result based on how many characters are printable ASCII and common English letters
5. **Finding the best key**: Select the key that produces the highest score
6. **Final calculation**: Calculate the sum of ASCII values of the decrypted text

The key insight is that the key consists of three lowercase letters, so we only need to test 26³ = 17,576 possible combinations, which is computationally feasible.

The final answer is the sum of all ASCII values in the original decrypted text.
