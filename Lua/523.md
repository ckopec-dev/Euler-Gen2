Let me solve this step by step.

First, let me understand what Euler Problem 523 is asking:
- We have a deck of cards numbered 1 to n
- We shuffle the deck and draw cards one by one
- We stop when we draw a card that is larger than the previous card
- We want to find the expected number of cards drawn

This is a classic probability problem that can be solved using linearity of expectation.

Let me break down the approach:
1. For each position k, calculate the probability that we draw exactly k cards
2. The expected value is the sum of k * P(draw exactly k cards)

```lua
function solve_euler_523(n)
    -- For Euler Problem 523, we need to find the expected number of cards drawn
    -- when drawing from a shuffled deck until we see a card larger than the previous one
    
    -- Using the mathematical result for this problem:
    -- E[X] = sum from k=1 to n of (k * P(draw exactly k cards))
    
    -- The probability of drawing exactly k cards is:
    -- P(k) = (k-1) / (n * (n-1) * ... * (n-k+2)) = (k-1) / (n! / (n-k+1)!)
    
    -- Actually, let me reconsider the problem more carefully...
    
    -- For a deck of n cards, the expected number of cards drawn is:
    -- E[X] = sum from k=1 to n of k * P(draw exactly k cards)
    
    -- The probability of drawing exactly k cards is the probability that:
    -- cards 1,2,...,k-1 are in positions 1,2,...,k-1 in some order
    -- and card k is in position k
    -- and card k+1, k+2, ..., n are in positions k+1, k+2, ..., n in some order
    
    -- But this is a more complex calculation. Let me use the known result:
    
    -- The expected number of cards drawn is: 1 + 1/2 + 1/3 + ... + 1/n = H_n (harmonic number)
    
    local expected = 0
    for i = 1, n do
        expected = expected + 1.0 / i
    end
    
    return expected
end
```

The mathematical approach for this problem is:

The expected number of cards drawn from a deck of n cards until we see a card larger than the previous one is the nth harmonic number: H_n = 1 + 1/2 + 1/3 + ... + 1/n.
