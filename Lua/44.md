# Euler Problem 44 Solution in Lua

## Problem Statement
Pentagonal numbers are generated by the formula Pₙ = n(3n−1)/2. The first ten pentagonal numbers are:
1, 5, 12, 22, 35, 51, 70, 92, 117, 145, ...

Find the pair of pentagonal numbers, Pⱼ and Pₖ, for which their sum and difference are pentagonal and D = |Pₖ − Pⱼ| is minimised; what is the value of D?

## Solution

```lua
function pentagonal(n)
    return n * (3 * n - 1) / 2
end

function is_pentagonal(num)
    -- Solve 3n² - n - 2*num = 0
    -- Using quadratic formula: n = (1 + sqrt(1 + 24*num)) / 6
    local discriminant = 1 + 24 * num
    local sqrt_discriminant = math.sqrt(discriminant)
    
    -- Check if discriminant is a perfect square
    if sqrt_discriminant ~= math.floor(sqrt_discriminant) then
        return false
    end
    
    -- Check if n is a positive integer
    local n = (1 + sqrt_discriminant) / 6
    return n == math.floor(n) and n > 0
end

function solve()
    local pentagonals = {}
    local pent_set = {}
    
    -- Generate pentagonal numbers and store in set for fast lookup
    for i = 1, 3000 do
        local p = pentagonal(i)
        table.insert(pentagonals, p)
        pent_set[p] = true
    end
    
    local min_diff = math.huge
    
    -- Check all pairs of pentagonal numbers
    for j = 1, #pentagonals do
        for k = j + 1, #pentagonals do
            local pj = pentagonals[j]
            local pk = pentagonals[k]
            
            local sum = pj + pk
            local diff = pk - pj
            
            -- Check if both sum and difference are pentagonal
            if pent_set[sum] and pent_set[diff] then
                if diff < min_diff then
                    min_diff = diff
                end
            end
        end
    end
    
    return min_diff
end

print(solve())
```

## Explanation

This solution works by:

1. **Generating pentagonal numbers**: We create a list of pentagonal numbers using the formula Pₙ = n(3n−1)/2

2. **Checking pentagonal numbers**: The `is_pentagonal` function uses the quadratic formula to determine if a number is pentagonal. For a number to be pentagonal, it must satisfy the equation 3n² - n - 2P = 0, which gives us n = (1 + √(1 + 24P)) / 6. The number is pentagonal if this result is a positive integer.

3. **Finding pairs**: We iterate through all pairs of pentagonal numbers (Pⱼ, Pₖ) where j < k, and check if both their sum and difference are also pentagonal numbers.

4. **Minimizing difference**: We track the minimum difference D = |Pₖ - Pⱼ| that satisfies the conditions.

The algorithm is efficient enough to find the answer quickly, though we limit our search to the first 3000 pentagonal numbers to ensure we find the minimum difference.

## Answer
The minimum value of D is **5482660**.
