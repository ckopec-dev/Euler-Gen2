# Euler Problem 425 Solution in Lua

I'll solve Euler Problem 425, which asks for the sum of all primes p < 10^7 such that p is not a strong prime.

Let me break down the problem:
- Find all primes < 10^7
- Check which ones are NOT strong primes
- Sum those primes

A strong prime p is one where p > (p_{i-1} + p_{i+1})/2, where p_{i-1} and p_{i+1} are the previous and next primes in the sequence.

```lua
function sieve_of_eratosthenes(limit)
    local is_prime = {}
    for i = 2, limit do
        is_prime[i] = true
    end
    
    for i = 2, math.sqrt(limit) do
        if is_prime[i] then
            for j = i * i, limit, i do
                is_prime[j] = false
            end
        end
    end
    
    local primes = {}
    for i = 2, limit do
        if is_prime[i] then
            table.insert(primes, i)
        end
    end
    
    return primes
end

function is_strong_prime(primes, prime_index)
    -- Check if prime at prime_index is a strong prime
    local p = primes[prime_index]
    local prev_prime = primes[prime_index - 1]
    local next_prime = primes[prime_index + 1]
    
    -- A strong prime p satisfies: p > (prev + next)/2
    return p > (prev_prime + next_prime) / 2
end

function solve_euler_425(limit)
    -- Get all primes up to limit
    local primes = sieve_of_eratosthenes(limit)
    
    local sum = 0
    
    -- Check each prime (excluding first and last)
    for i = 2, #primes - 1 do
        if not is_strong_prime(primes, i) then
            sum = sum + primes[i]
        end
    end
    
    return sum
end

-- Solve the problem for primes < 10^7
local result = solve_euler_425(10000000)
print("Sum of all primes < 10^7 that are not strong primes: " .. result)
```

1. Generate all primes up to 10^7 using the Sieve of Eratosthenes
2. For each prime (except the first and last), check if it's NOT a strong prime
3. A strong prime p satisfies: p > (p_prev + p_next)/2
4. Sum all primes that are not strong primes

The time complexity is O(n log log n) for the sieve plus O(n) for checking, where n is approximately 10^7.
