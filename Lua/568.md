# Euler Problem 568 Solution in Lua

## Problem Statement
The problem asks us to find the sum of all distinct values of a(n) where a(n) = n^2 + n + 41, for n from 0 to 1000, such that a(n) is prime.

## Analysis
This is a classic problem involving the Euler's prime-generating polynomial. We need to:
1. Generate values using the formula a(n) = n² + n + 41
2. Check if each value is prime
3. Sum all distinct prime values

## Solution

```lua
function is_prime(n)
    if n < 2 then return false end
    if n == 2 then return true end
    if n % 2 == 0 then return false end
    
    local sqrt_n = math.floor(math.sqrt(n))
    for i = 3, sqrt_n, 2 do
        if n % i == 0 then return false end
    end
    return true
end

function euler568()
    local primes = {}
    local sum = 0
    
    for n = 0, 1000 do
        local a_n = n * n + n + 41
        if is_prime(a_n) then
            if not primes[a_n] then
                primes[a_n] = true
                sum = sum + a_n
            end
        end
    end
    
    return sum
end

-- Run the solution
local result = euler568()
print("The sum of all distinct prime values is: " .. result)
```

## Explanation

1. **Prime Checking Function**: The `is_prime` function efficiently checks if a number is prime by:
   - Handling edge cases (n < 2, n = 2, even numbers)
   - Only checking odd divisors up to √n

2. **Main Algorithm**: 
   - Iterate n from 0 to 1000
   - Calculate a(n) = n² + n + 41
   - Check if the result is prime
   - If prime and not already counted, add it to our sum
   - Use a hash table `primes` to track distinct values

3. **Key Insight**: 
   - The polynomial n² + n + 41 generates prime numbers for n = 0 to 39
   - For n > 39, some values will be composite
   - We only sum distinct primes (hence the hash table check)

## Optimization Notes

The solution uses:
- Efficient prime checking with square root optimization
- Hash table for tracking distinct primes to avoid double counting
- Simple iteration through the required range
