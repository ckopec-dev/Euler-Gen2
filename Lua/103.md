# Euler Problem 103 Solution in Lua

## Problem Statement
Let S(A) represent the sum of elements in set A of size n. We shall call a set A which satisfies the following properties:
- S(A) is minimised for a given n
- For any two non-empty disjoint subsets, B and C, S(B) ≠ S(C)
- If B contains more elements than C then S(B) > S(C)

Such a set is called a "special sum set". Find the set S(A) for n = 7.

## Solution Approach
This is a complex optimization problem that requires finding a special sum set with 7 elements. The key insight is that we need to construct a set where:
1. The sum is minimized
2. All subset sums are distinct
3. Larger subsets have larger sums

We'll use a systematic approach to generate candidate sets and verify they meet the criteria.

function sum(arr)
    local total = 0
    for i = 1, #arr do
        total = total + arr[i]
    end
    return total
end

function getSubsets(arr)
    local subsets = {}
    local n = #arr
    
    -- Generate all non-empty subsets using bit manipulation
    for i = 1, 2^n - 1 do
        local subset = {}
        for j = 1, n do
            if (i & (1 << (j-1))) ~= 0 then
                table.insert(subset, arr[j])
            end
        end
        table.insert(subsets, subset)
    end
    
    return subsets
end

function areSubsetSumsDistinct(subsets)
    local sums = {}
    for i = 1, #subsets do
        local subsetSum = sum(subsets[i])
        if sums[subsetSum] then
            return false
        end
        sums[subsetSum] = true
    end
    return true
end

function isValidSpecialSumSet(arr)
    local subsets = getSubsets(arr)
    
    -- Check if all subset sums are distinct
    if not areSubsetSumsDistinct(subsets) then
        return false
    end
    
    -- Check if larger subsets have larger sums
    -- Sort subsets by size
    table.sort(subsets, function(a, b)
        if #a == #b then
            return sum(a) < sum(b)
        else
            return #a < #b
        end
    end)
    
    -- Verify that each subset has sum greater than previous subset of same size
    local sizeToSum = {}
    for i = 1, #subsets do
        local size = #subsets[i]
        local subsetSum = sum(subsets[i])
        
        if sizeToSum[size] then
            if subsetSum <= sizeToSum[size] then
                return false
            end
        else
            sizeToSum[size] = subsetSum
        end
    end
    
    return true
end
