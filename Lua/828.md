# Euler Problem 828 Solution in Lua

I'll solve Euler Problem 828, which asks for the sum of all positive integers n ≤ 10^17 such that n has exactly 10^10 divisors.

Let me break down the approach:

## Problem Analysis

For a number n with exactly 10^10 divisors, I need to understand the divisor function formula:
- If n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then the number of divisors is (a₁+1)(a₂+1)...(aₖ+1) = 10^10

Since 10^10 = 2^10 × 5^10, I need to find all ways to express 10^10 as a product of integers ≥ 2.

## Solution Approach

I'll:
1. Find all possible factorizations of 10^10
2. For each factorization, construct the minimal number n
3. Sum all valid n ≤ 10^17

    while b ~= 0 do
        a, b = b, a % b
    end
    return a

function power_mod(base, exp, mod)
    local result = 1
    base = base % mod
    while exp > 0 do
        if exp % 2 == 1 then

        end

    end

function sieve_of_eratosthenes(limit)
    local is_prime = {}
    for i = 2, limit do
        is_prime[i] = true
    end
    
    for i = 2, math.floor(math.sqrt(limit)) do
        if is_prime[i] then
            for j = i * i, limit, i do
                is_prime[j] = false
            end
        end
    end
    
    local primes = {}
    for i = 2, limit do
        if is_prime[i] then
            table.insert(primes, i)

        if n % i == 0 then
            table.insert(divisors, i)

function calculate_min_number(factorization)
    -- For factorization [a1, a2, ..., ak], we want n = 2^(a1-1) * 3^(a2-1) * ... * p_k^(a_k-1)
    local result = 1
    local prime_index = 1

        local prime = primes[prime_index]
        result = result * (prime ^ (exp - 1))
        prime_index = prime_index + 1

function solve_euler_828()
    local target = 10^10
    local limit = 10^17
    
    print("Finding factorizations of " .. target)
