# Euler Problem 179 Solution in Lua

## Problem Statement
Find the number of integers 1 < n < 10^7 for which n and n + 1 have the same number of positive divisors.

## Solution

```lua
function count_divisors(n)
    local count = 0
    local sqrt_n = math.floor(math.sqrt(n))
    
    for i = 1, sqrt_n do
        if n % i == 0 then
            if i * i == n then
                count = count + 1
            else
                count = count + 2
            end
        end
    end
    
    return count
end

function solve()
    local limit = 10000000
    local count = 0
    
    -- Precompute divisor counts for all numbers
    local div_count = {}
    for i = 1, limit do
        div_count[i] = count_divisors(i)
    end
    
    -- Check consecutive numbers
    for i = 2, limit - 1 do
        if div_count[i] == div_count[i + 1] then
            count = count + 1
        end
    end
    
    return count
end

-- Run the solution
print("Answer: " .. solve())
```

## Optimized Version

```lua
function solve_optimized()
    local limit = 10000000
    local count = 0
    
    -- Initialize divisor count array
    local div_count = {}
    for i = 1, limit do
        div_count[i] = 0
    end
    
    -- Sieve-like approach to count divisors
    for i = 1, limit do
        for j = i, limit, i do
            div_count[j] = div_count[j] + 1
        end
    end
    
    -- Count consecutive numbers with same divisor count
    for i = 2, limit - 1 do
        if div_count[i] == div_count[i + 1] then
            count = count + 1
        end
    end
    
    return count
end

-- Run the optimized solution
print("Answer: " .. solve_optimized())
```

## Explanation

The problem asks us to find how many integers n (where 1 < n < 10^7) have the same number of positive divisors as n + 1.

**Approach:**
1. **Divisor Counting**: For each number, we need to count its positive divisors
2. **Optimization**: Instead of counting divisors individually for each number, we use a sieve-like approach where we increment the divisor count for all multiples of each number
3. **Comparison**: We compare consecutive numbers to see if they have the same number of divisors

**Key Insights:**
- The optimized solution uses a sieve method to count divisors efficiently
- For each number i, we increment the divisor count for all its multiples (i, 2i, 3i, ...)
- This is much more efficient than checking each number individually for divisors

**Time Complexity:** O(n log n) where n = 10^7
**Space Complexity:** O(n)

The answer is **986262**.
