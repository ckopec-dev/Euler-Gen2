# Euler Problem 14 Solution in Lua

## Problem Statement
The following iterative sequence is defined for the set of positive integers:
- n → n/2 (n is even)
- n → 3n + 1 (n is odd)

Using the rule above and starting with 13, we generate the following sequence:
13 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1

It can be seen that this sequence (starting at 13 and finishing at 1) contains 10 terms. Although it has not been proved yet (Collatz Problem), it is thought that all starting numbers finish at 1.

Which starting number, under one million, produces the longest chain?

## Solution

```lua
function collatz_length(n)
    local length = 1
    while n ~= 1 do
        if n % 2 == 0 then
            n = n / 2
        else
            n = 3 * n + 1
        end
        length = length + 1
    end
    return length
end

function solve()
    local max_length = 0
    local starting_number = 0
    
    for i = 1, 999999 do
        local length = collatz_length(i)
        if length > max_length then
            max_length = length
            starting_number = i
        end
    end
    
    return starting_number, max_length
end

local result, length = solve()
print("Starting number: " .. result)
print("Chain length: " .. length)
```

## Optimized Version with Memoization

```lua
function solve_optimized()
    local memo = {}
    local max_length = 0
    local starting_number = 0
    
    function collatz_length(n)
        if n == 1 then
            return 1
        end
        
        if memo[n] then
            return memo[n]
        end
        
        local length
        if n % 2 == 0 then
            length = 1 + collatz_length(n / 2)
        else
            length = 1 + collatz_length(3 * n + 1)
        end
        
        memo[n] = length
        return length
    end
    
    for i = 1, 999999 do
        local length = collatz_length(i)
        if length > max_length then
            max_length = length
            starting_number = i
        end
    end
    
    return starting_number, max_length
end

local result, length = solve_optimized()
print("Starting number: " .. result)
print("Chain length: " .. length)
```

## Output
```
Starting number: 837799
Chain length: 525
```

## Explanation

The solution works by:

1. **Basic approach**: For each number from 1 to 999,999, we calculate the Collatz sequence length
2. **Optimization**: The memoized version stores previously calculated lengths to avoid redundant calculations
3. **Collatz sequence**: Follows the rules: if even divide by 2, if odd multiply by 3 and add 1
4. **Tracking**: Keeps track of the maximum chain length and corresponding starting number

The optimized version with memoization is significantly faster because it avoids recalculating the same sequence lengths multiple times. The answer is **837799**, which produces a chain of **525** terms.
