# Euler Problem 274 Solution in Lua

## Problem Statement
Find the sum of all primes p < 1000000 such that for some integer n, we have p divides (n^15 + 1).

## Analysis
We need to find primes p where there exists an integer n such that p divides (n^15 + 1), which means n^15 ≡ -1 (mod p).

This is equivalent to n^30 ≡ 1 (mod p), so the order of n modulo p divides 30.
Since n^15 ≡ -1 (mod p), we have n^30 ≡ 1 (mod p) and n^15 ≢ 1 (mod p).
This means the order of n modulo p is exactly 30.

For a prime p to have such an n, we need 30 to be divisible by the order of any element in (Z/pZ)*, which means 30 must divide p-1.
Therefore, p ≡ 1 (mod 30).

However, we also need to check that there exists an n such that n^15 ≡ -1 (mod p).
This is possible if and only if -1 is a 15th power residue modulo p.

Let's implement a solution:

function is_prime(n)
    if n < 2 then return false end
    if n == 2 then return true end
    if n % 2 == 0 then return false end
    for i = 3, math.sqrt(n), 2 do
        if n % i == 0 then return false end
    end
    return true
end

function mod_pow(base, exp, mod)
    local result = 1
    base = base % mod
    while exp > 0 do
        if exp % 2 == 1 then
            result = (result * base) % mod
        end
        exp = math.floor(exp / 2)
        base = (base * base) % mod
    end
    return result
end

function has_solution(p)
    -- Check if there exists n such that n^15 ≡ -1 (mod p)
    -- This is equivalent to checking if -1 is a 15th power residue
    
    -- For p = 2, we need n^15 ≡ 1 (mod 2), so n ≡ 1 (mod 2)
    if p == 2 then return true end
    
    -- We need to check if -1 is a 15th power residue mod p
    -- This is true if and only if (-1)^((p-1)/gcd(15, p-1)) ≡ 1 (mod p)
    
    local gcd_val = function(a, b)
        while b ~= 0 do
            a, b = b, a % b
        end
        return a
    end
    
    local g = gcd_val(15, p - 1)
    local power = (p - 1) / g
    
    -- For -1 to be a 15th power residue, we need (-1)^power ≡ 1 (mod p)
    -- This means power must be even
    return power % 2 == 0
end

            sum = sum + p2

## Explanation

The key mathematical insight is that for a prime p to divide n^15 + 1 for some integer n, we need n^15 ≡ -1 (mod p).

This means:
- n^30 ≡ 1 (mod p) 
- n^15 ≢ 1 (mod p)

So the order of n modulo p is exactly 30.

By Lagrange's theorem, the order of any element in (Z/pZ)* must divide p-1.
Therefore, 30 must divide p-1, which means p ≡ 1 (mod 30).

The only exception is p = 2, where n = 1 works since 1^15 + 1 = 2 ≡ 0 (mod 2).

The algorithm:
1. Check if p = 2 works (it does)
2. For other primes, check if p ≡ 1 (mod 30) and p is prime
3. Sum all such primes
