# Euler Problem 246 Solution in Lua

## Problem Statement
Problem 246 asks us to find the number of lattice points inside a specific ellipse with the equation $x^2 + 4y^2 < 10^8$.

## Approach
We need to count lattice points (points with integer coordinates) that satisfy the inequality $x^2 + 4y^2 < 10^8$.

For a fixed value of $y$, we can rearrange the inequality to find the range of valid $x$ values:
$x^2 < 10^8 - 4y^2$
$|x| < \sqrt{10^8 - 4y^2}$

So for each valid $y$, we can determine how many integer values of $x$ satisfy this condition.

## Solution

```lua
function count_lattice_points()
    local limit = 10^8
    local count = 0
    
    -- Find the maximum value of |y| such that 4y^2 < limit
    local max_y = math.floor(math.sqrt(limit / 4))
    
    -- For each valid y value
    for y = -max_y, max_y do
        -- Calculate the maximum value of x^2
        local x_squared_max = limit - 4 * y * y
        
        -- If x^2 is negative or zero, no valid x exists
        if x_squared_max > 0 then
            -- Find maximum |x| value
            local x_max = math.floor(math.sqrt(x_squared_max))
            
            -- Count valid integer x values: from -x_max to x_max
            local x_count = 2 * x_max + 1
            
            count = count + x_count
        end
    end
    
    return count
end

-- Execute the solution
local result = count_lattice_points()
print("Number of lattice points: " .. result)
```

## Explanation

1. **Finding the range of y values**: Since we need $x^2 + 4y^2 < 10^8$, the maximum value of $4y^2$ is $10^8$, so $|y| < \sqrt{10^8/4} = 50000$.

2. **For each y**: 
   - Calculate the maximum allowed value of $x^2$ as $10^8 - 4y^2$
   - Find the maximum absolute value of $x$ as $\lfloor\sqrt{10^8 - 4y^2}\rfloor$
   - Count the integer values of $x$ from $-x_{max}$ to $x_{max}$, which is $2 \times x_{max} + 1$ points

3. **Sum all valid points**: Add up the counts for all valid y values.

The algorithm efficiently computes the result by iterating only over the necessary range of y values and using the mathematical relationship to quickly determine the valid range of x values for each y.
