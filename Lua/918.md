# Euler Problem 918 Solution in Lua

I need to solve Euler Problem 918, which asks for the number of ways to arrange the digits 1, 2, 3, 4, 5, 6, 7, 8, 9 in a 3×3 grid such that the sum of each row and each column is the same.

Let me break this down:

1. We have digits 1-9 to place in a 3×3 grid
2. Each row and column must have the same sum
3. This is essentially finding magic squares of order 3

First, let me calculate what the magic sum should be:
- Sum of all digits 1+2+3+4+5+6+7+8+9 = 45
- Since there are 3 rows, each row sum = 45/3 = 15
- Similarly, each column sum = 15

Now I'll write a Lua program to find all valid arrangements:

function is_magic_square(grid)
    -- Check row sums
    for i = 1, 3 do
        local sum = grid[i][1] + grid[i][2] + grid[i][3]
        if sum ~= 15 then
            return false
        end
    end
    
    -- Check column sums
    for j = 1, 3 do
        local sum = grid[1][j] + grid[2][j] + grid[3][j]
        if sum ~= 15 then
            return false
        end
    end
    
    return true
end

function permute(arr, start, results)
    if start == #arr then
        table.insert(results, {arr[1], arr[2], arr[3], arr[4], arr[5], arr[6], arr[7], arr[8], arr[9]})
        return
    end
    
    for i = start, #arr do
        arr[start], arr[i] = arr[i], arr[start]
        permute(arr, start + 1, results)
        arr[start], arr[i] = arr[i], arr[start]
    end
end

function solve()
    local digits = {1, 2, 3, 4, 5, 6, 7, 8, 9}
    local permutations = {}
    local count = 0
    
    permute(digits, 1, permutations)
    
    for _, perm in ipairs(permutations) do
        -- Convert flat array to 3x3 grid
        local grid = {}
        for i = 1, 3 do
            grid[i] = {}
            for j = 1, 3 do
                grid[i][j] = perm[(i-1)*3 + j]
            end
        end
        
        if is_magic_square(grid) then
            count = count + 1
        end
    end
    
    return count
end

-- Run the solution
print("Number of 3x3 magic squares using digits 1-9: " .. solve())
