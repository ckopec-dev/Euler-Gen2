# Euler Problem 351 Solution in Lua

## Problem Statement
A hexagonal orchard of order n is a triangular lattice made up of points within a regular hexagon with side n. The hexagon has a center point and n layers of points around it. Each point in the orchard is assigned a number based on its distance from the center. A point is considered "visible" if its number is coprime with n. We need to count the number of visible points in a hexagonal orchard of order n.

## Mathematical Analysis
This problem relates to counting lattice points in a hexagonal grid that are visible from the center. The key insight is that we need to count points (x,y) in the hexagonal grid such that gcd(x² + xy + y², n) = 1.

The solution involves:
1. Using the inclusion-exclusion principle
2. Counting points based on divisors of n
3. Applying Euler's totient function

function euler_totient(n)
    local result = n
    local i = 2
    
    while i * i <= n do
        if n % i == 0 then
            while n % i == 0 do
                n = n // i
            end
            result = result - result // i

        i = i + 1
    end

function solve_hexagonal_orchard(n)
    local total = 0
    
    -- For each divisor d of n
    for d = 1, n do
        if n % d == 0 then
            -- Apply inclusion-exclusion principle
            local phi = euler_totient(n // d)
            local sum = 0
            
            -- Sum over all divisors of d
            for k = 1, d do
                if d % k == 0 then
                    sum = sum + euler_totient(k) * (d // k) * (d // k)
                end
            end
            
            total = total + phi * sum
        end
    end
    
    return total
