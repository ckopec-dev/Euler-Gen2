- We want to find the expected number of plates we need to see before we see all 371 plates
- This is a classic "Coupon Collector Problem"

However, looking more carefully at the problem, it seems to be asking about the expected number of plates needed to see all 371 plates, which is exactly the coupon collector problem.

The expected number of trials needed to collect all n coupons is:
E[X] = n × (1 + 1/2 + 1/3 + ... + 1/n) = n × H_n

Where H_n is the nth harmonic number.
