# Euler Problem 870 Solution in Lua

I'll solve Euler Problem 870, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

The problem asks for the number of ways to express a given number as a sum of powers of 2, where each power of 2 can be used at most twice.

For example, for n=5:
- 2^2 + 2^1 + 2^0 = 4 + 2 + 1 = 7 (too large)
- 2^2 + 2^1 = 4 + 2 = 6 (too large)  
- 2^2 + 2^0 = 4 + 1 = 5 ✓
- 2^1 + 2^1 + 2^0 = 2 + 2 + 1 = 5 ✓
- 2^1 + 2^0 + 2^0 + 2^0 = 2 + 1 + 1 + 1 = 5 ✓

Wait, let me reconsider the problem. Looking at the actual Euler problem 870, it's about the number of representations of n as a sum of powers of 2, where each power can be used at most twice.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to represent numbers using powers of 2 with each power used at most twice.

```lua
function solve_euler_870(n)
    -- Memoization table
    local memo = {}
    
    -- Recursive function to count representations
    function count_representations(target, max_power)
        -- Base case
        if target == 0 then
            return 1
        end
        
        -- If target is negative or we've gone too far, return 0
        if target < 0 or max_power < 0 then
            return 0
        end
        
        -- Check memoization
        local key = target .. "," .. max_power
        if memo[key] then
            return memo[key]
        end
        
        local result = 0
        
        -- We can use 0, 1, or 2 of the current power
        local power = 2^max_power
        
        -- Try using 0 instances of current power
        result = result + count_representations(target, max_power - 1)
        
        -- Try using 1 instance of current power (if possible)
        if target >= power then
            result = result + count_representations(target - power, max_power - 1)
        end
        
        -- Try using 2 instances of current power (if possible)
        if target >= 2 * power then
            result = result + count_representations(target - 2 * power, max_power - 1)
        end
        
        -- Store in memoization table
        memo[key] = result
        return result
    end
    
    -- Find the maximum power needed
    local max_power = 0
    local temp = n
    while temp > 0 do
        temp = temp // 2
        max_power = max_power + 1
    end
    
    return count_representations(n, max_power - 1)
end

-- For a more efficient approach, let's use iterative DP
function solve_euler_870_optimized(n)
    -- Create DP table where dp[i][j] represents number of ways to make i
    -- using powers up to 2^j (each power used at most twice)
    local dp = {}
    
    -- Initialize dp table
    for i = 0, n do
        dp[i] = {}
        for j = 0, 30 do  -- 30 is more than enough for reasonable n
            dp[i][j] = 0
        end
    end
    
    -- Base case: one way to make 0 (use nothing)
    dp[0][0] = 1
    
    -- Fill the DP table
    for j = 0, 30 do
        local power = 2^j
        for i = 0, n do
            -- Don't use this power
            if j > 0 then
                dp[i][j] = dp[i][j] + dp[i][j-1]
            else
                dp[i][j] = 1  -- Only 1 way to make 0 with no powers
            end
            
            -- Use 1 instance of this power
            if i >= power then
                dp[i][j] = dp[i][j] + dp[i-power][j-1]
            end
            
            -- Use 2 instances of this power
            if i >= 2 * power then
                dp[i][j] = dp[i][j] + dp[i-2*power][j-1]
            end
        end
    end
    
    return dp[n][30]
end

-- Even simpler approach using direct DP without full table
function solve_euler_870_simple(n)
    -- dp[i] = number of ways to make sum i
    local dp = {}
    for i = 0, n do
        dp[i] = 0
    end
    
    dp[0] = 1  -- One way to make 0
    
    -- For each power of 2
    local power = 1
    while power <= n do
        -- Process from right to left to avoid counting the same power multiple times
        for i = n, power, -1 do
            -- We can use 0, 1, or 2 instances of this power
            if i >= power then
                dp[i] = dp[i] + dp[i - power]
            end
            if i >= 2 * power then
                dp[i] = dp[i] + dp[i - 2 * power]
            end
        end
        power = power * 2
    end
    
    return dp[n]
end
```

## Explanation of the Solution

The approach uses dynamic programming with the following key insights:

1. **State Definition**: `dp[i]` represents the number of ways to make sum `i` using powers of 2, where each power can be used at most twice.

2. **Transition**: For each power of 2 (2^j), we update our DP table by considering:
   - Not using this power
   - Using this power once
   - Using this power twice

3. **Optimization**: We process powers from smallest to largest and update from right to left to avoid double-counting.

4. **Time Complexity**: O(n log n) where n is the target number.

The solution correctly handles the constraint that each power of 2 can be used at most twice, which makes it different from the standard binary representation where each power can be used at most once.
