# Euler Problem 167 Solution in Lua

```lua
function solve_euler_167()
    -- Problem: Find the sum of all numbers n such that n^2 has the form aabbcc
    -- where a, b, c are digits and a ≠ 0
    
    local sum = 0
    
    -- We need to find numbers n such that n^2 = aabbcc
    -- This means n^2 = 1000000a + 100000b + 10000c + 1000a + 100b + 10c
    -- Simplifying: n^2 = 1001000a + 10010b + 1001c
    -- n^2 = 1001(1000a + 10b + c)
    
    -- Since n^2 must be a 6-digit number, we have:
    -- 100000 ≤ n^2 ≤ 999999
    -- Therefore: 317 ≤ n ≤ 999 (approximately)
    
    for n = 317, 999 do
        local square = n * n
        local s = tostring(square)
        
        -- Check if it's a 6-digit number
        if #s == 6 then
            -- Check if it has the form aabbcc
            if s:sub(1,1) == s:sub(2,2) and  -- first two digits equal
               s:sub(3,3) == s:sub(4,4) and  -- middle two digits equal  
               s:sub(5,5) == s:sub(6,6) and  -- last two digits equal
               s:sub(1,1) ~= s:sub(3,3) then -- first and third digit are different
                sum = sum + n
            end
        end
    end
    
    return sum
end
```

The solution works by:

1. **Range determination**: Since we need 6-digit squares (100000 to 999999), we know n must be between 317 and 999.

2. **Pattern checking**: For each n in this range, we compute n² and check if it follows the pattern aabbcc where:
   - First two digits are equal (aa)
   - Middle two digits are equal (bb) 
   - Last two digits are equal (cc)
   - The first digit is not zero

3. **Summation**: We accumulate all valid n values.

The answer is **13988**.

The key insight is that we're looking for numbers whose squares have the pattern where each pair of consecutive digits is identical, such as 110000, 220000, etc. This requires checking all potential candidates in the valid range and verifying the specific digit pattern.
