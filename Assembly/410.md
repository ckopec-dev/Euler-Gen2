# Euler Problem 410 Solution in Assembly

Euler Problem 410 asks us to find the sum of all integers n ≤ 10^17 such that n is divisible by 10 and the number of ways to write n as a sum of squares of two positive integers is exactly 4.

## Problem Analysis

The problem asks for numbers n where:
1. n ≤ 10^17
2. n is divisible by 10
3. The number of representations of n as a sum of two squares (a² + b² = n) is exactly 4
