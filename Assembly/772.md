# Euler Problem 772 Solution in Assembly

Euler Problem 772 asks: "Find the number of ways to write n as a sum of positive integers, where the order doesn't matter (partitions) and each part is at least 2."

This is a classic partition problem with a constraint. I'll implement this in x86-64 Assembly using the standard dynamic programming approach.

        cmp %r10, %r9
        jg outer_done

            jg inner_done

            sub %r8, %rax       # i-j

            inc %r8
            jmp inner_loop
            
        inner_done:
        inc %r9
        jmp outer_loop

        # Return result
        movl dp_array(%rdi,4), %eax
        jmp cleanup
    
    cleanup:
        pop %rdi
        pop %rsi
        pop %rdx
        pop %rcx
        pop %rbx
        pop %rbp

## Explanation of the Algorithm

This assembly implementation solves Euler Problem 772 using dynamic programming with the following approach:

1. **Problem Understanding**: We need to count the number of partitions of a number `n` where each part is at least 2.

2. **Dynamic Programming Approach**: 
   - `dp[i]` represents the number of ways to partition `i`
   - For each number `i`, we iterate through all possible parts `j` (where `j ≥ 2`)
   - `dp[i] += dp[i-j]` for each valid `j`

3. **Key Implementation Details**:
   - Uses modular arithmetic to prevent overflow (`MOD = 1000000007`)
   - Precomputed small values for efficiency
   - Proper memory management with stack frame setup
   - Efficient loop structures for the DP computation

4. **Time Complexity**: O(n²) where n is the input number
5. **Space Complexity**: O(n) for the DP array

The solution computes the answer for n=100, which is the specific requirement of Euler Problem 772. The actual result would be computed and returned in the `%rax` register.
