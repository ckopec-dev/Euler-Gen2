# Euler Problem 218 Solution in Assembly

Euler Problem 218 asks us to find the number of Pythagorean triples (a,b,c) where a² + b² = c² and a + b + c = 1000.

Let me solve this step by step in assembly language.

## Problem Analysis
We need to find all Pythagorean triples where:
- a² + b² = c²
- a + b + c = 1000
- a, b, c are positive integers
- a ≤ b < c

## Assembly Solution

```assembly
.section .data
    target_sum: .long 1000
    result: .long 0
    count: .long 0

.section .text
    .global _start

_start:
    # Initialize registers
    movl $1, %eax          # a = 1
    movl $1, %ebx          # b = 1
    movl $1, %ecx          # c = 1
    
outer_loop:
    # Check if a + b + c > target
    addl %eax, %ebx        # a + b
    addl %ecx, %ebx        # a + b + c
    cmpl target_sum, %ebx
    jg outer_done          # If sum > 1000, break outer loop
    
    # Reset ebx to a
    movl %eax, %ebx        # b = a
    
inner_loop:
    # Calculate a + b + c
    movl %eax, %edx        # edx = a
    addl %ebx, %edx        # edx = a + b
    addl %ecx, %edx        # edx = a + b + c
    
    # Check if sum equals target
    cmpl target_sum, %edx
    je check_pythagorean   # If sum = 1000, check if it's pythagorean
    
    # If sum < target, increment c
    cmpl target_sum, %edx
    jl increment_c
    
    # If sum > target, break inner loop
    jmp inner_done
    
check_pythagorean:
    # Check if a² + b² = c²
    # Calculate a²
    movl %eax, %edx
    imull %edx, %edx       # a²
    
    # Calculate b²
    movl %ebx, %edi
    imull %edi, %edi       # b²
    
    # Add a² + b²
    addl %edi, %edx        # a² + b²
    
    # Calculate c²
    movl %ecx, %edi
    imull %edi, %edi       # c²
    
    # Compare a² + b² with c²
    cmpl %edi, %edx
    jne inner_continue     # If not equal, continue
    
    # Found a Pythagorean triple
    incl count             # Increment count
    
inner_continue:
    # Increment c
increment_c:
    incl %ecx
    jmp inner_loop
    
inner_done:
    # Increment a and reset b
    incl %eax
    movl %eax, %ebx        # b = a
    movl %eax, %ecx        # c = a
    
    # Check if we should continue outer loop
    jmp outer_loop
    
outer_done:
    # Exit program
    movl $1, %eax          # sys_exit
    movl $0, %ebx          # exit status
    int $0x80
```

## Alternative Approach (More Efficient)

Here's a more optimized version that directly calculates c from the constraint:

```assembly
.section .data
    target_sum: .long 1000
    count: .long 0

.section .text
    .global _start

_start:
    movl $1, %eax          # a = 1
    movl $1, %ebx          # b = 1
    
outer_loop:
    # Check if a + b + c > target
    # Since a + b + c = 1000, we have c = 1000 - a - b
    movl target_sum, %ecx  # c = 1000
    subl %eax, %ecx        # c = 1000 - a
    subl %ebx, %ecx        # c = 1000 - a - b
    
    # Check if c > 0
    cmpl $0, %ecx
    jle next_a
    
    # Check if c >= b (since a ≤ b < c)
    cmpl %ebx, %ecx
    jl next_a
    
    # Check Pythagorean triple: a² + b² = c²
    # Calculate a² + b²
    movl %eax, %edx        # a
    imull %edx, %edx       # a²
    movl %ebx, %edi        # b
    imull %edi, %edi       # b²
    addl %edi, %edx        # a² + b²
    
    # Calculate c²
    movl %ecx, %edi        # c
    imull %edi, %edi       # c²
    
    # Compare
    cmpl %edi, %edx
    jne next_a
    
    # Found valid triple
    incl count
    
next_a:
    # Increment b
    incl %ebx
    # Check if b >= a
    cmpl %eax, %ebx
    jge next_a_loop
    
    # If b >= a, increment a and reset b
next_a_loop:
    incl %eax
    movl %eax, %ebx        # Reset b = a
    
    # Check termination condition
    movl target_sum, %ecx
    subl %eax, %ecx        # c = 1000 - a
    cmpl $0, %ecx
    jle done
    
    jmp outer_loop
    
done:
    # Exit program
    movl $1, %eax          # sys_exit
    movl $0, %ebx
    int $0x80
```

## Explanation

The solution works by:

1. **Iterating through possible values**: Starting with a = 1, b = 1
2. **Calculating c**: Using the constraint a + b + c = 1000, so c = 1000 - a - b
3. **Checking constraints**: 
   - c must be positive
   - c ≥ b (since a ≤ b < c)
   - a² + b² = c² (Pythagorean theorem)
4. **Counting valid triples**: Incrementing counter when all conditions are met

## Key Assembly Concepts Used

- **Register operations**: Using EAX, EBX, ECX, EDX for calculations
- **Conditional jumps**: JG, JE, JL, JNE for control flow
- **Arithmetic operations**: ADD, SUB, IMUL for mathematical calculations
- **Memory operations**: Loading constants and accessing data segments
