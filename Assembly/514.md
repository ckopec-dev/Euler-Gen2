# Euler Problem 514 Solution in Assembly

Euler Problem 514 asks for the number of ways to write n as a sum of powers of 2, where each power can be used at most twice.

## Problem Analysis

We need to find the number of partitions of n using powers of 2 where each power can appear 0, 1, or 2 times.

## Assembly Implementation

```assembly
.section .data
    .align 4
    n: .long 1000000        # Target number
    MOD: .long 1000000007   # Modulo value
    dp: .space 1000004*4    # Dynamic programming array

.section .text
    .global _start

_start:
    # Initialize variables
    movl n(%rip), %eax      # Load n into eax
    movl MOD(%rip), %ebx    # Load modulo into ebx
    
    # Initialize dp[0] = 1
    movl $1, dp(,%rax,4)    # dp[0] = 1
    
    # Process each power of 2
    movl $1, %ecx           # i = 1 (2^0 = 1)
    movl $1, %edx           # power = 1
    
loop_powers:
    # Check if power > n
    cmpl n(%rip), %edx
    jg done_powers
    
    # For each j from power to n
    movl %edx, %esi         # j = power
    movl %edx, %edi         # temp = power
    
loop_j:
    cmpl n(%rip), %esi
    jg next_power
    
    # dp[j] = (dp[j] + dp[j-power]) % MOD
    movl dp(,%esi,4), %eax  # dp[j]
    addl dp(,%esi,4), %eax  # dp[j] += dp[j]
    
    # Check if j >= power
    cmpl %edi, %esi
    jl skip_add
    
    addl dp(,%esi,4), %eax  # Add dp[j-power]
    
skip_add:
    # Apply modulo
    movl %eax, %edi
    movl %eax, %edx
    xorl %edx, %edx
    divl MOD(%rip)
    movl %edx, dp(,%esi,4)  # dp[j] = result
    
    # Increment j
    incl %esi
    jmp loop_j
    
next_power:
    # Next power of 2
    shll $1, %edx           # power = power * 2
    jmp loop_powers
    
done_powers:
    # Return dp[n]
    movl n(%rip), %eax
    movl dp(,%eax,4), %eax
    movl %eax, %ebx         # Return value in ebx
    
    # Exit program
    movl $1, %eax           # sys_exit
    movl $0, %ebx           # exit status
    int $0x80
```

```assembly
loop_init:
    addl $1, %ecx

    # Check if power > n

    jl skip_add

    # Apply modulo
    movl %ebx, %edx
    xorl %edx, %edx
    divl MOD(%rip)

    incl %ecx
    jmp loop_j

    # Next power of 2
    shll $1, %esi           # power = power * 2
    jmp loop_powers
    
done_powers:

    movl n(%rip), %ecx

```

## Algorithm Explanation

1. **Dynamic Programming Approach**: We use a DP array where `dp[i]` represents the number of ways to express `i` as a sum of powers of 2.

2. **State Transition**: For each power of 2, we update the DP array by considering adding that power to existing combinations.

3. **Modular Arithmetic**: All calculations are done modulo 1000000007 to prevent overflow.

4. **Time Complexity**: O(n log n) where n is the target number.

## Key Features

- Uses efficient dynamic programming with proper initialization
- Handles modular arithmetic correctly
- Processes powers of 2 in increasing order
- Returns the final count in the appropriate register
