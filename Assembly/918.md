# Euler Problem 918 Solution in Assembly

Euler Problem 918 asks: "Find the sum of all numbers n < 10^10 such that when n is written in base 3, all of its digits are 1."

Let me solve this step by step.

## Problem Analysis

We need to find numbers less than 10^10 where all digits in base 3 representation are 1.
These numbers in base 3 look like: 1, 11, 111, 1111, 11111, etc.
In decimal, these are: 1, 4, 13, 40, 121, 364, ...

These follow the pattern: 1 + 3 + 3² + 3³ + ... + 3^k = (3^(k+1) - 1)/2

## Assembly Implementation

```assembly
.section .data
    # Constants
    max_limit: .quad 10000000000    # 10^10
    one: .quad 1
    three: .quad 3
    result_sum: .quad 0

.section .text
    .global _start

_start:
    # Initialize variables
    movq $1, %rax           # current_number = 1
    movq $0, %rbx           # sum = 0
    movq $1, %rcx           # power_of_3 = 1
    movq $0, %rdx           # temp for calculations

calculate_sum:
    # Check if current_number >= max_limit
    cmpq max_limit(%rip), %rax
    jge done
    
    # Add current_number to sum
    addq %rax, %rbx
    
    # Generate next number in sequence
    # Next number = current_number * 3 + 1
    movq %rax, %rdx
    imulq three(%rip), %rdx
    addq one(%rip), %rdx
    
    # Check if next number would exceed limit
    cmpq max_limit(%rip), %rdx
    jge done
    
    # Update current number
    movq %rdx, %rax
    
    # Continue loop
    jmp calculate_sum

done:
    # Store result
    movq %rbx, result_sum(%rip)
    
    # Exit program
    movq $60, %rax          # sys_exit
    movq $0, %rdi           # exit status
    syscall

# Alternative approach using geometric series formula
# This is more efficient for large computations
_alternative_approach:

    movq $0, %rbx           # sum = 0

    # Loop through geometric series
    # Each term: (3^n - 1) / 2 where n = 1,2,3...
    # But we need to be careful about overflow
    # Let's compute using the recurrence relation
    movq $1, %r8            # previous_sum = 1
    movq $1, %r9            # previous_term = 1
    
    # We'll compute: 1 + 4 + 13 + 40 + ...
    # Each term = 3 * previous_term + 1
    # This is more efficient for the computation
    
    movq $1, %r10           # term = 1
    movq $1, %r11           # sum = 1
    
compute_terms:
    # Calculate next term: term = 3 * term + 1
    movq %r10, %rax
    imulq three(%rip), %rax
    addq one(%rip), %rax
    
    # Check if term >= 10^10
    cmpq max_limit(%rip), %rax
    jge finish_loop
    
    # Add to sum
    addq %rax, %r11
    
    # Update term
    movq %rax, %r10
    
    jmp compute_terms

finish_loop:
    # Result is in %r11
    movq %r11, result_sum(%rip)
    
    # Exit
    movq $60, %rax
    movq $0, %rdi
    syscall

# Optimized version using bit operations
_optimized_approach:
    # We know the sequence: 1, 4, 13, 40, 121, 364, ...
    # These are numbers of the form (3^n - 1) / 2
    
    movq $1, %rax           # n = 1
    movq $0, %rbx           # sum = 0
    movq $1, %rcx           # power = 1
    movq $1, %rdx           # term = 1
    
compute_geometric:
    # Add term to sum
    addq %rdx, %rbx
    
    # Calculate next term = 3 * term + 1
    movq %rdx, %r8
    imulq three(%rip), %r8
    addq one(%rip), %r8
    
    # Check if next term >= 10^10
    cmpq max_limit(%rip), %r8
    jge end_compute
    
    # Update term
    movq %r8, %rdx
    
    jmp compute_geometric

end_compute:
    # Result is in %rbx
    movq %rbx, result_sum(%rip)
    
    # Exit
    movq $60, %rax
```

## Mathematical Approach

For a cleaner solution, let's think mathematically:

The numbers we're looking for are of the form:
- 1 (base 3: 1)
- 4 (base 3: 11)  
- 13 (base 3: 111)
- 40 (base 3: 1111)
- etc.

These are numbers of the form (3^n - 1)/2 for n = 1, 2, 3, ...

The recurrence relation is: a(n) = 3 * a(n-1) + 1, with a(1) = 1.

## Final Optimized Assembly Solution

```assembly
.section .data
    MAX_LIMIT: .quad 10000000000
    RESULT: .quad 0

.section .text
    .global _start

_start:
    # Initialize
    movq $1, %rax           # current number = 1
    movq $0, %rbx           # sum = 0
    
    # Main loop
loop_start:
    # Check if current number >= 10^10
    cmpq MAX_LIMIT(%rip), %rax
    jge end_program
    
    # Add to sum
    addq %rax, %rbx
    
    # Calculate next number: next = 3 * current + 1
    movq %rax, %rcx
    imulq $3, %rcx
    addq $1, %rcx
    
    # Check if next number would exceed limit
    cmpq MAX_LIMIT(%rip), %rcx
    jge end_program
    
    # Update current number
    movq %rcx, %rax
    
    jmp loop_start

end_program:
    # Store result
    movq %rbx, RESULT(%rip)
    
    # Exit
    movq $60, %rax
    movq $0, %rdi
    syscall
```
