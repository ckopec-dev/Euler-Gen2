# Euler Problem 431 in Assembly

Euler Problem 431 asks us to find the sum of all positive integers n ≤ 10^17 such that n is divisible by 3 and n! is divisible by n^3.

Let me analyze this problem first, then provide an assembly solution.

## Problem Analysis

For n! to be divisible by n^3, we need to check when n! ≡ 0 (mod n^3).

Since n = 3k for some integer k, we're looking for values where n! is divisible by 3^3 = 27.

The key insight is that n! contains many factors of 3, and we need to ensure there are at least 3 factors of 3 in n!.
