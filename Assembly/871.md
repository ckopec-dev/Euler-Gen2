## Problem Understanding

Euler Problem 871 asks us to find the sum of all positive integers n ≤ 10^12 such that n has exactly 10^12 divisors.

This is a very challenging mathematical problem that requires understanding of number theory and divisor functions.

## Mathematical Analysis

Let's analyze what we're looking for:
- We want integers n ≤ 10^12 with exactly 10^12 divisors
- If n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then the number of divisors is (a₁+1)(a₂+1)...(aₖ+1) = 10^12
- We need to find all such n ≤ 10^12
