# Euler Problem 226 Solution in Assembly

Euler Problem 226 asks us to find the area of the shaded region in the blancmange curve, which is defined as the area between the curve and the x-axis from x=0 to x=1.

## Problem Analysis

The blancmange curve is defined as:
```
f(x) = Σ(1/2^n * |2^n * x - floor(2^n * x)|)
```

The problem asks for the area under this curve from 0 to 1.
