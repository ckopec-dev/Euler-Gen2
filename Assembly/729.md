# Euler Problem 729 in Assembly Language

Euler Problem 729 asks us to find the sum of all distinct values of f(n) for 1 ≤ n ≤ 10^8, where f(n) is the number of ways to write n as a sum of distinct positive integers, where the order doesn't matter (partitions into distinct parts).

Let me solve this using Assembly language with a focus on the mathematical approach.

## Problem Analysis

The function f(n) represents the number of partitions of n into distinct parts. This is equivalent to finding the number of subsets of {1,2,3,...,n} that sum to n, or equivalently, the number of partitions of n where all parts are distinct.

## Mathematical Approach

The key insight for Euler Problem 729 is that we need to compute the sum of all distinct values of f(n) where f(n) is the number of partitions of n into distinct parts.

The recurrence relation for partitions into distinct parts is:
- f(n) = sum_{k=1}^{floor((sqrt(8n+1)-1)/2)} (-1)^{k+1} f(n-k(k+1)/2)
- With f(0) = 1 and f(n) = 0 for n < 0
