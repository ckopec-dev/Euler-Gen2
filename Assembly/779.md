# Euler Problem 779 Solution in Assembly

Euler Problem 779 asks: "Find the sum of all positive integers n ≤ 10^12 such that n is divisible by 3 and the sum of digits of n is 3."

Let me break this down and provide an assembly solution:

## Problem Analysis

For a number n to be divisible by 3 and have digit sum = 3:
- n ≡ 0 (mod 3) 
- Sum of digits = 3
- n ≤ 10^12

Since n is divisible by 3 and digit sum is 3, we need to find numbers whose digits sum to 3 and are divisible by 3.

## Assembly Solution

```assembly
.section .data
    max_value: .quad 1000000000000    # 10^12
    digit_sum: .quad 3
    result: .quad 0
    temp: .quad 0

.section .text
    .global _start

_start:
    # Initialize variables
    movq $1, %rax           # current number
    movq $0, %rbx           # result accumulator
    movq $1000000000000, %rcx # max limit
    
check_loop:
    # Check if current number <= max_value
    cmpq %rcx, %rax
    jg done
    
    # Check if number is divisible by 3
    movq %rax, %rdx
    xorq %rdx, %rdx         # Clear rdx
    movq $3, %rbx
    divq %rbx               # Divide by 3
    cmpq $0, %rdx           # Check remainder
    jne next_number
    
    # Calculate sum of digits
    movq %rax, %rdi         # Copy number to rdi
    movq $0, %r8            # digit sum accumulator
    
digit_sum_loop:
    cmpq $0, %rdi
    je check_digit_sum
    movq %rdi, %r9
    xorq %r9, %r9
    movq $10, %rbx
    divq %rbx               # Get last digit in %rdx
    addq %rdx, %r8          # Add to digit sum
    movq %rax, %rdi         # Get remaining number
    jmp digit_sum_loop

check_digit_sum:
    cmpq $3, %r8
    jne next_number
    
    # If we get here, number satisfies both conditions
    addq %rax, %rbx         # Add to result
    
next_number:
    incq %rax               # Increment number
    jmp check_loop
    
done:
    # Store final result
    movq %rbx, result
    
    # Exit program
    movq $60, %rax          # sys_exit
    movq $0, %rdi           # exit status
    syscall
```
