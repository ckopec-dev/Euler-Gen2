## Problem Understanding

Euler Problem 670 asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes, where rotations are allowed.

## Mathematical Approach

The problem can be solved using dynamic programming with the recurrence relation:
- f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4) for n ≥ 4
- Base cases: f(0) = 1, f(1) = 1, f(2) = 5, f(3) = 11
