# Euler Problem 921 Solution in Lisp

I need to solve Euler Problem 921, which asks for the number of integers n ≤ 10^12 such that the sum of the squares of the digits of n equals the sum of the digits of n.

Let me break this down:
- For a number n, calculate sum of squares of digits
- Calculate sum of digits
- Count how many numbers n ≤ 10^12 satisfy: sum_of_squares_of_digits = sum_of_digits

First, let me implement helper functions:

```lisp
(defun sum-of-digits (n)
  "Calculate sum of digits of n"
  (let ((sum 0))
    (loop while (> n 0) do
      (incf sum (mod n 10))
      (setf n (floor n 10)))
    sum))

(defun sum-of-squares-of-digits (n)
  "Calculate sum of squares of digits of n"
  (let ((sum 0))
    (loop while (> n 0) do
      (let ((digit (mod n 10)))
        (incf sum (* digit digit)))
      (setf n (floor n 10)))
    sum))

(defun count-special-numbers (limit)
  "Count numbers n <= limit where sum of squares of digits = sum of digits"
  (let ((count 0))
    (loop for n from 1 to limit do
      (when (= (sum-of-squares-of-digits n) (sum-of-digits n))
        (incf count)))
    count))
```

However, for 10^12, this brute force approach would be too slow. Let me think about a mathematical approach.

Looking at the constraint more carefully:
- For a number with digits d₁, d₂, ..., dₖ
- We want: d₁² + d₂² + ... + dₖ² = d₁ + d₂ + ... + dₖ
- This means: d₁² - d₁ + d₂² - d₂ + ... + dₖ² - dₖ = 0
- Or: d₁(d₁-1) + d₂(d₂-1) + ... + dₖ(dₖ-1) = 0

For single digits (0-9):
- 0(0-1) = 0
- 1(1-1) = 0  
- 2(2-1) = 2

If we consider all digits as 0 or 1, we have:
