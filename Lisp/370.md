# Euler Problem 370 Solution in Lisp

I'll solve Euler Problem 370, which asks for the sum of all integers n ≤ 10^11 such that the number of ways to write n as a sum of consecutive positive integers is exactly 4.

Let me break down the approach:

## Problem Analysis

For a number n to have exactly 4 ways to be written as a sum of consecutive positive integers, we need to understand the mathematical structure.

If we write n as a sum of k consecutive integers starting from m:
n = m + (m+1) + (m+2) + ... + (m+k-1) = k*m + k(k-1)/2

This gives us: n = k(m + (k-1)/2), so m = (n - k(k-1)/2)/k

For this to be valid, we need:
1. m ≥ 1
2. n - k(k-1)/2 ≥ k
3. (n - k(k-1)/2) must be divisible by k

## Solution Approach

The key insight is that the number of ways to write n as a sum of consecutive positive integers equals the number of odd divisors of n (excluding 1).

So we want numbers n ≤ 10^11 where the number of odd divisors equals 4.

This means n = 2^a * p^3 where p is an odd prime, or n = 2^a * p1 * p2 where p1 and p2 are distinct odd primes.

(defun euler-370 ()
  "Solve Euler Problem 370: Sum of integers n ≤ 10^11 with exactly 4 representations as sum of consecutive positive integers"
  
  (defun count-odd-divisors (n)
    "Count the number of odd divisors of n"
    (let ((count 0) (sqrt-n (isqrt n)))
      (loop for i from 1 to sqrt-n by 2
            when (zerop (mod n i))
            do (progn
                 (incf count)
                 (when (/= i (quotient n i))
                   (incf count))))
      count))
  
  (defun isqrt (n)
    "Integer square root"
    (if (<= n 0) 0
        (let ((x n))
          (loop while (> x (quotient (+ x (quotient n x)) 2))
                do (setf x (quotient (+ x (quotient n x)) 2)))
          x)))
  
  (defun sum-of-consecutive-ways (limit)
    "Find sum of all n ≤ limit with exactly 4 ways to write as sum of consecutive positive integers"
    (let ((result 0))
      ;; Numbers with exactly 4 odd divisors are of the form:
      ;; 1. 2^a * p^3 where p is an odd prime
      ;; 2. 2^a * p1 * p2 where p1, p2 are distinct odd primes
      
      ;; Case 1: n = 2^a * p^3
      (let ((max-p (isqrt (isqrt limit))))
        (loop for p from 3 to max-p by 2
              when (primep p)
              do (loop for a from 0
                       while (<= (expt 2 a) (quotient limit (expt p 3)))
                       do (let ((n (* (expt 2 a) (expt p 3))))
                            (when (<= n limit)
                              (incf result n))))))
      
      ;; Case 2: n = 2^a * p1 * p2  
      (let ((max-p (isqrt limit)))
        (loop for p1 from 3 to max-p by 2
              when (primep p1)
              do (loop for p2 from (1+ p1) to (isqrt (quotient limit p1)) by 2
                       when (and (primep p2)
                                 (<= (* p1 p2) (quotient limit 2)))
                       do (loop for a from 0
                                while (<= (expt 2 a) (quotient limit (* p1 p2)))
                                do (let ((n (* (expt 2 a) p1 p2)))
                                     (when (<= n limit)
                                       (incf result n))))))))
      
      result))
  
  (defun primep (n)
    "Check if a number is prime"
    (if (<= n 1) nil
        (if (= n 2) t
            (if (evenp n) nil
                (loop for i from 3 to (isqrt n) by 2
                      when (zerop (mod n i))
                      return nil
                      finally (return t)))))
  
  ;; Optimized approach using the mathematical insight
  (defun solve-370 ()
    "Optimized solution using the fact that we want numbers with exactly 4 odd divisors"
    (let ((limit 100000000000)  ; 10^11
          (sum 0))
      
      ;; For numbers with exactly 4 odd divisors:
      ;; Type 1: n = 2^a * p^3 where p is an odd prime
      ;; Type 2: n = 2^a * p1 * p2 where p1, p2 are distinct odd primes
      
      ;; Generate primes up to sqrt(limit)
      (let ((primes (sieve-of-eratosthenes (isqrt limit))))
        ;; Type 1: 2^a * p^3
        (loop for p in primes
              when (and (> p 1) (oddp p))
              do (loop for a from 0
                       while (<= (expt 2 a) (quotient limit (expt p 3)))
                       do (let ((n (* (expt 2 a) (expt p 3))))
                            (when (<= n limit)
                              (incf sum n)))))
        
        ;; Type 2: 2^a * p1 * p2
        (loop for i from 0 to (1- (length primes))
              for p1 = (nth i primes)
              when (and (> p1 1) (oddp p1))
              do (loop for j from (1+ i) to (1- (length primes))
                       for p2 = (nth j primes)
                       when (and (oddp p2) (<= (* p1 p2) (quotient limit 2)))
                       do (loop for a from 0
                                while (<= (expt 2 a) (quotient limit (* p1 p2)))
                                do (let ((n (* (expt 2 a) p1 p2)))
                                     (when (<= n limit)
                                       (incf sum n))))))))
      
      sum))
  
  (defun sieve-of-eratosthenes (limit)
    "Generate list of primes up to limit using sieve of Eratosthenes"
    (if (<= limit 1) nil
        (let ((sieve (make-array (1+ limit) :element-type 'bit :initial-element 1)))
          (setf (bit sieve 0) 0)
          (setf (bit sieve 1) 0)
          (loop for i from 2 to (isqrt limit)
                when (bit sieve i)
                do (loop for j from (* i i) to limit by i
                         do (setf (bit sieve j) 0)))
          (loop for i from 2 to limit
                when (bit sieve i)
                collect i))))
  
  ;; Call the optimized solution
  (solve-370))

## Mathematical Insight

The key mathematical insight is that the number of ways to write a positive integer n as a sum of consecutive positive integers equals the number of odd divisors of n (excluding 1).

For n to have exactly 4 odd divisors, n must be of one of these forms:
1. n = 2^a × p^3 where p is an odd prime
2. n = 2^a × p1 × p2 where p1 and p2 are distinct odd primes

This is because:
- For p^3, the odd divisors are 1, p, p^2, p^3 (4 divisors total)
- For p1 × p2, the odd divisors are 1, p1, p2, p1×p2 (4 divisors total)

The solution efficiently generates all such numbers up to 10^11 and sums them.
