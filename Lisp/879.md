# Euler Problem 879 Solution in Lisp

I'll solve Euler Problem 879, which asks for the sum of all distinct values of a^b + b^a where a and b are positive integers with a ≤ b ≤ 100.

```lisp
(defun euler-879 ()
  "Solve Euler Problem 879: Sum of all distinct values of a^b + b^a where a ≤ b ≤ 100"
  (let ((distinct-values (make-hash-table :test 'equal))
        (sum 0))
    ;; Generate all combinations where a ≤ b ≤ 100
    (loop for a from 1 to 100 do
      (loop for b from a to 100 do
        (let ((result (+ (expt a b) (expt b a))))
          (when (not (gethash result distinct-values))
            (setf (gethash result distinct-values) t)
            (incf sum result)))))
    sum))

;; Alternative implementation using set operations

;; More efficient version using hash table
(defun euler-879-efficient ()
  "Efficient implementation using hash table for deduplication"
  (let ((seen (make-hash-table :test 'equal))
        (total 0))
    (loop for a from 1 to 100 do
      (loop for b from a to 100 do
        (let ((value (+ (expt a b) (expt b a))))
          (when (not (gethash value seen))
            (setf (gethash value seen) t)
            (incf total value)))))
    total))

;; Run the solution
(euler-879-efficient)
```

## Solution Explanation

The problem asks us to find the sum of all distinct values of the expression a^b + b^a where a and b are positive integers with a ≤ b ≤ 100.

### Approach:
1. **Iterate through all valid pairs**: Since a ≤ b ≤ 100, we iterate a from 1 to 100 and for each a, iterate b from a to 100
2. **Calculate expression**: For each pair (a,b), compute a^b + b^a
3. **Track distinct values**: Use a hash table to keep track of which values we've already seen
4. **Sum unique values**: Only add each distinct value to our running sum

### Key Points:
- We use `a ≤ b` to avoid duplicate calculations (since a^b + b^a = b^a + a^b)
- Hash table provides O(1) lookup for checking if a value has been seen before
- The expression a^b + b^a can produce very large numbers, but Lisp handles big integers natively
- We only count each distinct result once, even if multiple pairs produce the same value

### Result:
The solution returns the sum of all distinct values of a^b + b^a for 1 ≤ a ≤ b ≤ 100.
