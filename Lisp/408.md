# Euler Problem 408 Solution in Lisp

Euler Problem 408 asks us to find the sum of all numbers n ≤ 10^17 such that when n is written in base 10, the sum of its digits equals the sum of the digits of n².

Let me solve this step by step:

## Problem Understanding

We need to find numbers n where:
- n ≤ 10^17
- digit_sum(n) = digit_sum(n²)

## Approach

This is a computationally intensive problem due to the large upper bound. The key insights are:
1. For large numbers, the digit sum of n² is typically much larger than n
2. We can use mathematical properties to reduce the search space
3. Numbers with small digit sums are more likely to satisfy the condition
