# Euler Problem 499 Solution in Lisp

I'll solve Euler Problem 499, which asks for the expected number of draws from a uniform distribution on [0,1] until the sum exceeds 1.

## Problem Understanding

We need to find the expected number of draws from a uniform distribution on [0,1] until the sum exceeds 1.

Let E(n) be the expected number of draws needed when the current sum is n.
We want to find E(0).

## Mathematical Analysis

Let's define the expected number of draws starting from sum s:
- E(s) = 1 + ∫₀¹ E(s+x) dx for s < 1
- E(s) = 0 for s ≥ 1

This gives us the integral equation:
E(s) = 1 + ∫₀¹ E(s+x) dx

For s < 1, we have:
E(s) = 1 + ∫₀¹ E(s+x) dx

Let's make a substitution: let u = s+x, so du = dx
When x = 0, u = s; when x = 1, u = s+1

So: E(s) = 1 + ∫ₛ^(s+1) E(u) du

Differentiating both sides with respect to s:
E'(s) = 0 + E(s+1) - E(s)

This gives us: E'(s) = E(s+1) - E(s)

## Mathematical Justification

The solution to this problem is **e** (Euler's number, approximately 2.718281828...).

The derivation:
1. Let E(x) be the expected number of draws needed when the current sum is x
2. For x ≥ 1, E(x) = 0 (we're already done)
3. For x < 1: E(x) = 1 + ∫₀¹ E(x+t) dt
4. This integral equation has the solution E(x) = e^(1-x) for x < 1
5. Therefore E(0) = e^(1-0) = e^1 = e
