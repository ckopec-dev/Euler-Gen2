# Euler Problem 643 Solution in Lisp

I'll solve Euler Problem 643, which asks for the number of ways to write n as a sum of distinct positive integers, where each integer is at least 2 and the sum of their reciprocals equals 1.

Let me break down the approach:
1. This is a partition problem with additional constraints
2. Each part must be ≥ 2
3. The sum of reciprocals of parts must equal 1
4. All parts must be distinct

```lisp
(defun euler-643 (n)

    (labels ((count-partitions (remaining target sum-of-reciprocals parts)
               (cond
                 ;; Base case: if we've used all numbers from 2 to target
                 ((= remaining 0)
                  (when (and (= sum-of-reciprocals 1.0) 
                             (not (null parts)))
                    (incf count)))
                 ;; If remaining is negative or sum of reciprocals exceeds 1, prune
                 ((or (< remaining 0) (> sum-of-reciprocals 1.0))
                  nil)
                 ;; If remaining is 0 but sum is not 1, it's invalid
                 ((and (= remaining 0) (not (= sum-of-recciprocals 1.0)))
                  nil)
                 ;; Try adding each possible number
                 (t
                  (loop for i from (if (null parts) 2 (1+ (car parts))) 
                        to target
                        while (<= i remaining)
                        do (let ((new-sum (/ 1.0 i)))
                             (when (<= (+ sum-of-reciprocals new-sum) 1.0)
                               (count-partitions 
                                (- remaining i)
                                target
                                (+ sum-of-reciprocals new-sum)
                                (cons i parts))))))))
      (count-partitions n n 0 nil)
      count)))
```
