# Euler Problem 507 Solution in Lisp

I'll solve Euler Problem 507, which asks for the sum of all prime numbers p < 10^8 such that for some integer n, p divides (n^2 + 1).

## Problem Analysis

The problem asks us to find all primes p < 10^8 where p divides n^2 + 1 for some integer n. This is equivalent to finding primes p where n^2 ≡ -1 (mod p) has a solution.

This happens when -1 is a quadratic residue modulo p, which occurs when p ≡ 1 (mod 4).

## Solution Approach

1. Generate all primes less than 10^8
2. For each prime p, check if p ≡ 1 (mod 4)
3. Sum all such primes

(defun sieve-of-eratosthenes (limit)
  "Generate all prime numbers up to limit using Sieve of Eratosthenes"
  (let ((primes (make-array (1+ limit) :element-type 'bit :initial-element 1)))
    (setf (aref primes 0) 0)
    (setf (aref primes 1) 0)
    
    (loop for i from 2 to (isqrt limit)
          when (= (aref primes i) 1)
          do (loop for j from (* i i) to limit by i
                   do (setf (aref primes j) 0)))
    
    (loop for i from 2 to limit
          when (= (aref primes i) 1)
          collect i)))

(defun euler-507-solution ()
  "Solve Euler Problem 507"
  (let ((limit 100000000)
        (sum 0))
    ;; Generate all primes up to 10^8
    (let ((primes (sieve-of-eratosthenes limit)))
      ;; Sum primes that are congruent to 1 modulo 4
      (dolist (p primes)
        (when (< p limit)
          (when (= (mod p 4) 1)
            (incf sum p))))
      sum)))

(defun primep (n)
  "Check if a number is prime"
  (cond
    ((<= n 1) nil)
    ((= n 2) t)
    ((evenp n) nil)
    (t (loop for i from 3 to (isqrt n) by 2
             when (= (mod n i) 0)
             return nil
             finally (return t)))))

## Explanation

The key insight for this problem is that for a prime p to divide n² + 1 for some integer n, we need n² ≡ -1 (mod p). This is equivalent to -1 being a quadratic residue modulo p.

By quadratic reciprocity, -1 is a quadratic residue modulo p if and only if p ≡ 1 (mod 4).

Therefore, we need to:
1. Generate all primes less than 10^8
2. Filter for primes that are congruent to 1 modulo 4
3. Sum these primes
