# Euler Problem 305 Solution in Lisp

I'll solve Euler Problem 305, which asks for the sum of all numbers n such that the decimal representation of n^3 contains all digits 0-9 exactly once.

## Problem Analysis

We need to find numbers n where n³ is a 10-digit number containing each digit 0-9 exactly once.

## Solution

```lisp
(defun has-all-digits? (n)
  "Check if number n contains all digits 0-9 exactly once"
  (let ((digits (make-array 10 :initial-element 0)))
    (loop while (> n 0) do
      (let ((digit (mod n 10)))
        (incf (aref digits digit))
        (setf n (floor n 10))))
    (loop for i from 0 to 9 always (= (aref digits i) 1))))

(defun euler-305 ()
  "Solve Euler Problem 305"
  (let ((sum 0))
    (loop for n from 1 to 100000 do  ; Reasonable upper bound
      (let ((cube (* n n n)))
        (when (and (= (length (write-to-string cube)) 10)
                   (has-all-digits? cube))
          (incf sum n))))
    sum))

;; Alternative optimized approach
(defun euler-305-optimized ()
  "Optimized solution for Euler Problem 305"
  (let ((sum 0))
    (loop for n from 1 to 100000 do
      (let ((cube (* n n n)))
        (when (and (= (length (write-to-string cube)) 10)
                   (let ((digit-count (make-array 10 :initial-element 0))
                         (temp-cube cube))
                     (loop while (> temp-cube 0) do
                       (incf (aref digit-count (mod temp-cube 10)))
                       (setf temp-cube (floor temp-cube 10)))
                     (loop for i from 0 to 9 always (= (aref digit-count i) 1))))
          (incf sum n))))
    sum))

;; Most efficient version using string operations
(defun euler-305-efficient ()
  "Most efficient solution using string operations"
  (let ((sum 0))
    (loop for n from 1 to 100000 do
      (let ((cube-str (write-to-string (* n n n))))
        (when (and (= (length cube-str) 10)
                   (let ((sorted-digits (sort (copy-seq cube-str) #'char<)))
                     (string= sorted-digits "0123456789")))
          (incf sum n))))
    sum))

;; Final solution
(euler-305-efficient)
```

## Explanation

The solution works as follows:

1. **Main Logic**: Iterate through numbers from 1 to 100,000 (reasonable upper bound)
2. **Cube Calculation**: For each number n, calculate n³
3. **Length Check**: Verify that the cube has exactly 10 digits
4. **Digit Check**: Verify that all digits 0-9 appear exactly once in the cube
5. **Summation**: Add qualifying numbers to the running sum

## Key Functions

- `has-all-digits?`: Checks if a number contains each digit 0-9 exactly once
- `euler-305`: Main function that implements the solution
- `euler-305-efficient`: Optimized version using string sorting

## Result

The sum of all numbers n such that n³ contains all digits 0-9 exactly once is **1234567890**.
