# Euler Problem 246 Solution in Lisp

## Problem Statement
A hexagonal tile with a centre point (x, y) is defined by the six vertices:
- (x, y+1)
- (x+1, y+1/2)
- (x+1, y-1/2)
- (x, y-1)
- (x-1, y-1/2)
- (x-1, y+1/2)

We define a hexagonal tile as a hexagon with centre point (x, y) where x and y are integers. A hexagonal tile with centre (x, y) is denoted by H(x, y). 

The first few hexagonal tiles are H(0,0), H(1,0), H(-1,0), H(0,1), H(0,-1), H(1,1), H(-1,1), H(1,-1), H(-1,-1), etc.

Let H(n) be the set of all hexagonal tiles with centre (x, y) where x² + y² ≤ n².

Let S(n) be the set of all points that are inside at least one hexagonal tile in H(n).

Let D(n) be the number of points with integer coordinates that are inside at least one hexagonal tile in H(n).

Find D(1000000).

## Solution Approach

This problem requires us to:
1. Generate all hexagonal tiles within a circle of radius n
2. Determine which integer coordinate points are inside at least one tile
3. Count these points

The key insight is that we need to check which integer lattice points are covered by any hexagonal tile in our set.
