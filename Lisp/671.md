# Euler Problem 671 Solution in Lisp

Euler Problem 671 asks us to find the number of ways to tile a 3×n rectangle with 2×1 dominoes and 1×1 squares, where the dominoes can be placed either horizontally or vertically.

Let me solve this step by step:

## Problem Analysis

We need to find the number of ways to tile a 3×n rectangle using:
- 2×1 dominoes (can be placed horizontally or vertically)
- 1×1 squares

## Solution Approach

I'll use dynamic programming with states representing the configuration of the last column.

Let's define states for the last column:
- State 0: All cells in the last column are empty (000)
- State 1: Bottom cell filled (100)  
- State 2: Middle cell filled (010)
- State 3: Top cell filled (001)
- State 4: Bottom and middle cells filled (110)
- State 5: Bottom and top cells filled (101)
- State 6: Middle and top cells filled (011)
- State 7: All cells filled (111)

(defun euler-671 (n)
  "Find the number of ways to tile a 3×n rectangle with 2×1 dominoes and 1×1 squares"
  (if (<= n 0)
      0
      (let ((dp (make-array (list (1+ n) 8) :initial-element 0)))
        ;; Base case: 3×0 rectangle has 1 way (empty tiling)
        (setf (aref dp 0 0) 1)
        
        ;; Fill DP table
        (loop for i from 1 to n do
          (let ((prev-row (aref dp (1- i))))

            ;; State 5 (bottom and top filled) can be reached from:
            ;; - State 0 (place 1 horizontal domino)
            ;; - State 2 (place 1 vertical domino)
            ;; - State 6 (place 1 vertical domino)
            ;; - State 7 (place 1 horizontal domino)
            (incf (aref dp i 5) (aref prev-row 0)) ; 1 horizontal domino
            (incf (aref dp i 5) (aref prev-row 2)) ; 1 vertical domino

            ;; - State 1 (place 1 vertical domino)
            ;; - State 5 (place 1 vertical domino)
            ;; - State 7 (place 1 horizontal domino)
            (incf (aref dp i 6) (aref prev-row 0)) ; 1 horizontal domino

            (incf (aref dp i 6) (aref prev-row 5)) ; 1 vertical domino

        (aref dp n 0))))
