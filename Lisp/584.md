# Euler Problem 584 Solution in Lisp

I'll solve Euler Problem 584, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

## Problem Understanding

We need to find the number of ways to completely tile a 3×n rectangle using 2×1 dominoes. This is a classic dynamic programming problem.

## Approach

Let's define `f(n)` as the number of ways to tile a 3×n rectangle. We can use dynamic programming by considering how the rightmost columns can be filled.

## Solution

```lisp
(defun euler-584 ()
  "Solve Euler Problem 584: Number of ways to tile a 3×n rectangle with 2×1 dominoes"
  
  ;; Define the recurrence relation
  ;; f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
  ;; Base cases:
  ;; f(0) = 1 (empty rectangle)
  ;; f(1) = 1 (3×1 rectangle can only be filled with 3 vertical dominoes)
  ;; f(2) = 3 (3×2 rectangle can be filled in 3 ways)
  ;; f(3) = 11 (3×3 rectangle can be filled in 11 ways)
  
  (let ((dp (make-array 1000 :element-type 'fixnum :initial-element 0)))
    ;; Base cases
    (setf (aref dp 0) 1)
    (setf (aref dp 1) 1)
    (setf (aref dp 2) 3)
    (setf (aref dp 3) 11)
    
    ;; Fill the dp array using recurrence relation
    (loop for i from 4 to 999 do
          (setf (aref dp i) 
                (+ (aref dp (- i 1))
                   (* 5 (aref dp (- i 2)))
                   (aref dp (- i 3))
                   (- (aref dp (- i 4)))))
    
    ;; Return the result for n = 1000 (as per typical problem constraints)
    (aref dp 1000)))
```

## Explanation

The solution uses dynamic programming with the recurrence relation:

- `f(n) = f(n-1) + 5×f(n-2) + f(n-3) - f(n-4)` for `n ≥ 4`

This recurrence relation comes from analyzing all possible ways to fill the rightmost columns of a 3×n rectangle with dominoes.
