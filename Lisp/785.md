I'll use dynamic programming with memoization to count the number of ways to express each number as a sum of powers of 2 with each power used at most twice.

```lisp
(defun count-ways (n)
  "Count the number of ways to write n as sum of powers of 2,
   where each power can be used at most twice."
  (let ((memo (make-hash-table :test 'equal)))
    (labels ((dp (remaining power)
               (cond
                 ;; Base case: if remaining is 0, we found one way
                 ((zerop remaining) 1)
                 ;; If remaining is negative or power is too large, no way
                 ((or (minusp remaining) 
                      (> (expt 2 power) remaining)) 0)
                 ;; Check memoization
                 (t
                  (let ((key (list remaining power)))
                    (if (gethash key memo)
                        (gethash key memo)
                        (let ((result 
                               (+ (dp remaining (1+ power))  ; don't use current power
                                  (dp (- remaining (expt 2 power)) (1+ power))  ; use current power once
                                  (dp (- remaining (* 2 (expt 2 power))) (1+ power))))) ; use current power twice
                          (setf (gethash key memo) result)
                          result)))))))
      (dp n 0))))

(defun euler-785 ()

(defun count-ways-efficient (n)
  "Efficient bottom-up approach to count ways"
  (let ((dp (make-array (+ n 1) :initial-element 0)))
    (setf (aref dp 0) 1)  ; Base case: one way to make 0
    
    ;; For each power of 2
    (loop for power from 0 to (floor (log n 2))
          for pow = (expt 2 power)
          while (<= pow n)
          do
          (loop for i from pow to n
```

The key insight is that we're counting the number of ways to write a number as a sum of powers of 2 where each power can be used at most twice. This is essentially a variant of the coin change problem with a twist.

The solution uses dynamic programming where:
1. `dp[i]` represents the number of ways to make amount `i`
2. For each power of 2, we update all amounts from that power to the target
3. We add the number of ways to make `j - power` to the number of ways to make `j`

The answer is `dp[1000000]`.
