# Euler Problem 422 Solution in Lisp

Euler Problem 422 asks us to find the number of ways to tile a 3×n rectangle with 2×1 dominoes.

Let me solve this step by step.

## Problem Analysis

We need to find the number of ways to tile a 3×n rectangle using 2×1 dominoes. This is a classic dynamic programming problem.

Let's define:
- `f(n)` = number of ways to tile a 3×n rectangle
- We can place dominoes either horizontally (2×1) or vertically (1×2)

## Approach

I'll use dynamic programming with states representing the configuration of the last column.

Let's think about the possible states for the last column (3 rows):
1. All empty (000)
2. First row filled (100)
3. Second row filled (010)
4. Third row filled (001)
5. First and second row filled (110)
6. First and third row filled (101)
7. Second and third row filled (011)
8. All rows filled (111)

But since we're tiling a 3×n rectangle, we can use a simpler approach by considering how to fill the last column.

## Solution

```lisp
(defun euler-422 ()
  "Solve Euler Problem 422: Number of ways to tile a 3×n rectangle with 2×1 dominoes"
  
  ;; Let f(n) be the number of ways to tile a 3×n rectangle
  ;; We can derive the recurrence relation:
  ;; f(n) = f(n-1) + 5*f(n-2) + f(n-3) - f(n-4) for n >= 4
  ;; Base cases: f(0) = 1, f(1) = 1, f(2) = 3, f(3) = 11
  
  (let ((dp (make-array 1000 :element-type 'fixnum :initial-element 0)))
    (setf (aref dp 0) 1
          (aref dp 1) 1
          (aref dp 2) 3
          (aref dp 3) 11)
    
    ;; Fill the dp array using the recurrence relation
    (loop for i from 4 to 999 do
          (setf (aref dp i) 
                (+ (aref dp (- i 1))
                   (* 5 (aref dp (- i 2)))
                   (aref dp (- i 3))
                   (- (aref dp (- i 4)))))
    
    ;; Return f(999) as specified in the problem
    (aref dp 999)))
```
