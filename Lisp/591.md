# Euler Problem 591 Solution in Lisp

I'll solve Euler Problem 591 using Lisp. First, let me understand what the problem is asking for.

## Problem Understanding

Euler Problem 591 asks us to find the number of ways to write a positive integer n as a sum of distinct Fibonacci numbers, where each Fibonacci number can be used at most once.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to represent each number using distinct Fibonacci numbers.

```lisp
(defun fibonacci-sequence (limit)
  "Generate Fibonacci numbers up to limit"
  (let ((fib-list '(1 2))
        (a 1)
        (b 2))
    (loop while (<= (+ a b) limit) do
      (let ((next (+ a b)))
        (push next fib-list)
        (setf a b)
        (setf b next)))
    (nreverse fib-list)))

(defun count-fibonacci-sums (n)
  "Count ways to write n as sum of distinct Fibonacci numbers"
  (let ((fib-numbers (fibonacci-sequence n))
        (memo (make-hash-table :test 'equal)))
    
    (labels ((count-ways (target fib-index)
               (cond
                 ((= target 0) 1)
                 ((or (< target 0) (>= fib-index (length fib-numbers))) 0)
                 (t
                  (let ((key (list target fib-index)))
                    (if (gethash key memo)
                        (gethash key memo)
                        (let ((current-fib (nth fib-index fib-numbers))
                              (include (count-ways (- target current-fib) (1+ fib-index)))
                              (exclude (count-ways target (1+ fib-index)))))
                          (setf (gethash key memo) (+ include exclude))
                          (gethash key memo)))))))
      (count-ways n 0))))

(defun euler-591 ()
  "Solve Euler Problem 591"
  (let ((limit 1000000))
    (count-fibonacci-sums limit)))

;; Alternative approach using more explicit DP
(defun count-fibonacci-sums-dp (n)
  "Count ways using dynamic programming approach"
  (let ((fib-numbers (fibonacci-sequence n))
        (dp (make-array (1+ n) :initial-element 0)))
    (setf (aref dp 0) 1) ; One way to make 0 (use nothing)
    
    (loop for fib in fib-numbers do
      (loop for i from fib to n do
        (incf (aref dp i) (aref dp (- i fib)))))
    
    (aref dp n)))

;; More efficient version with proper Fibonacci generation
(defun euler-591-efficient ()
  "Efficient solution for Euler Problem 591"
  (let ((limit 1000000)
        (fib-list '()))
    ;; Generate Fibonacci numbers up to limit
    (loop with a = 1
          with b = 2
          while (<= a limit) do
            (push a fib-list)
            (let ((temp a))
              (setf a b)
              (setf b (+ temp b))))
    (setf fib-list (nreverse fib-list))
    
    ;; Dynamic programming approach
    (let ((dp (make-array (1+ limit) :initial-element 0)))
      (setf (aref dp 0) 1)
      (loop for fib in fib-list do
        (loop for i from fib to limit do
          (incf (aref dp i) (aref dp (- i fib)))))
      (aref dp limit))))

;; Final clean solution
(defun solve-euler-591 ()
  "Solve Euler Problem 591: Count representations as sum of distinct Fibonacci numbers"
  (let* ((limit 1000000)
         (fibonacci (loop for a = 1 then b
                          for b = 2 then (+ a b)
                          while (<= a limit)
                          collect a))
         (dp (make-array (1+ limit) :initial-element 0)))
    (setf (aref dp 0) 1)
    (loop for fib in fibonacci do
      (loop for i from fib to limit do
        (incf (aref dp i) (aref dp (- i fib)))))
    (aref dp limit)))
```

## Explanation

The solution works as follows:

1. **Generate Fibonacci Numbers**: Create a list of Fibonacci numbers up to the target limit (1,000,000)

2. **Dynamic Programming Approach**: 
   - Use a DP array where `dp[i]` represents the number of ways to represent integer `i`
   - Initialize `dp[0] = 1` (one way to make 0: use nothing)
   - For each Fibonacci number, update all possible sums that include this number
   - The recurrence is: `dp[i] += dp[i - fib]` for each Fibonacci number `fib`

3. **Result**: The answer is `dp[1000000]`

## Key Insights

- Each Fibonacci number can be used at most once (distinct requirement)
- This is essentially a classic "coin change" problem with distinct denominations
- The DP approach ensures we count all valid combinations without double-counting
- Time complexity: O(n × k) where n is the target and k is the number of Fibonacci numbers

The solution efficiently computes the answer using dynamic programming, which is much faster than trying to enumerate all possible combinations.
