# Euler Problem 578 Solution in Lisp

I'll solve Euler Problem 578, which asks for the sum of all integers n ≤ 10^11 such that the number of divisors of n is exactly 2^k for some non-negative integer k.

## Problem Analysis

First, let me understand what we're looking for:
- Find integers n ≤ 10^11 where the number of divisors d(n) = 2^k for some k ≥ 0
- This means d(n) must be a power of 2
- We need to sum all such n

## Key Insights

1. If d(n) = 2^k, then n must have a very specific form
2. The number of divisors function d(n) = ∏(e_i + 1) where n = ∏p_i^e_i
3. For d(n) to be a power of 2, each (e_i + 1) must be a power of 2
4. This means each e_i = 2^j - 1 for some j ≥ 0

## Approach

The numbers n with d(n) = 2^k are those where n is of the form:
n = p1^(2^j1 - 1) × p2^(2^j2 - 1) × ... × pk^(2^jk - 1)

Where p_i are primes and j_i ≥ 0.
