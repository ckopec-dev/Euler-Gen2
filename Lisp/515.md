# Euler Problem 515 Solution in Lisp

I'll solve Euler Problem 515, which asks for the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Problem Understanding

The problem asks us to find the number of ways to represent a number n as a sum of powers of 2 (2^0, 2^1, 2^2, ...) where each power can be used at most twice.

This is equivalent to finding the number of representations of n in a "base-2 with digits 0,1,2" system.

## Solution Approach

I'll use dynamic programming with memoization to count the number of ways to represent each number using powers of 2 with at most 2 uses per power.

```lisp
(defun euler-515 (n)
  "Solve Euler Problem 515: Count ways to write n as sum of powers of 2,
   where each power can be used at most twice."
  (let ((memo (make-hash-table :test 'equal)))
    (labels ((count-ways (num power)
               (cond
                 ;; Base cases
                 ((= num 0) 1)  ; One way to make 0
                 ((< num 0) 0)  ; No way to make negative number
                 ((= power 0) (if (<= num 2) 1 0))  ; Only 2^0 = 1
                 ;; Check memo
                 ((gethash (cons num power) memo)
                  (gethash (cons num power) memo))
                 ;; Recursive case: use 0, 1, or 2 of current power
                 (t
                  (let ((result (+ (count-ways num (1- power))
                                   (count-ways (- num (expt 2 (1- power))) (1- power))
                                   (count-ways (- num (* 2 (expt 2 (1- power)))) (1- power)))))
                    (setf (gethash (cons num power) memo) result)
                    result)))))
      (count-ways n (1+ (floor (log n 2))))))

;; Alternative cleaner implementation
(defun euler-515-clean (n)
  "Cleaner implementation of Euler Problem 515"
  (let ((memo (make-hash-table :test 'equal)))
    (labels ((ways (num power)
               (cond
                 ((= num 0) 1)
                 ((or (< num 0) (< power 0)) 0)
                 ((gethash (cons num power) memo))
                 (t
                  (let ((result (+ (ways num (1- power))
                                   (ways (- num (expt 2 power)) (1- power))
                                   (ways (- num (* 2 (expt 2 power))) (1- power)))))
                    (setf (gethash (cons num power) memo) result)
                    result)))))
      (ways n (floor (log n 2))))))

;; For the specific case mentioned in the problem
(defun solve-euler-515 ()
  "Solve the specific Euler Problem 515"
  (euler-515-clean 1000000))

;; Test with smaller examples
(defun test-euler-515 ()
  "Test with small values to verify correctness"
  (format t "Ways to make 1: ~A~%" (euler-515-clean 1))
  (format t "Ways to make 2: ~A~%" (euler-515-clean 2))
  (format t "Ways to make 3: ~A~%" (euler-515-clean 3))
  (format t "Ways to make 4: ~A~%" (euler-515-clean 4))
  (format t "Ways to make 5: ~A~%" (euler-515-clean 5))
  (format t "Ways to make 1000000: ~A~%" (solve-euler-515)))

;; Run the test
(test-euler-515)
```

## Explanation of the Solution

1. **Recursive Approach**: We define a function `ways(num, power)` that counts how many ways we can represent `num` using powers of 2 up to `power`, where each power can be used at most twice.

2. **Base Cases**:
   - If `num` is 0, there's exactly 1 way (use nothing)
   - If `num` is negative or `power` is negative, there are 0 ways
   - If we're at power 0 (2^0 = 1), we can use 0, 1, or 2 of them (but only if num ≤ 2)

3. **Recursive Cases**: For each power, we consider three possibilities:
   - Use 0 of the current power: `ways(num, power-1)`
   - Use 1 of the current power: `ways(num - 2^power, power-1)`
   - Use 2 of the current power: `ways(num - 2×2^power, power-1)`

4. **Memoization**: We use a hash table to store previously computed results to avoid redundant calculations.

## Key Insights

- This is essentially counting representations in a modified base-2 system where each digit can be 0, 1, or 2
- The problem has optimal substructure and overlapping subproblems, making it perfect for dynamic programming
- Memoization is crucial for performance with large inputs

The final answer for Euler Problem 515 is the result of calling `solve-euler-515()` which computes the number of ways to represent 1,000,000 as a sum of powers of 2 with each power used at most twice.
