I need to solve Euler Problem 853, which asks for the sum of all positive integers n ≤ 10^15 such that σ(n) = σ(n-1) + σ(n-2), where σ(n) is the sum of divisors function.

Let me break this down:
1. We need to find numbers n where the sum of divisors of n equals the sum of divisors of n-1 plus the sum of divisors of n-2
2. We need to sum all such numbers up to 10^15

This is a computational problem that requires efficient calculation of divisor sums and checking the condition.

(defun sum-of-divisors (n)
  "Calculate the sum of all divisors of n"
  (let ((sum 0))
    (loop for i from 1 to (isqrt n)
          when (= (mod n i) 0)
          do (progn
               (incf sum i)
               (when (not (= i (quotient n i)))
                 (incf sum (quotient n i)))))
    sum))
