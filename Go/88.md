# Euler Problem 88 Solution in Go

## Problem Statement
A natural number N is called a product-sum number if there exists a set of natural numbers {a₁, a₂, ..., aₖ} such that:
- a₁ × a₂ × ... × aₖ = N
- a₁ + a₂ + ... + aₖ = N

For example, 12 = 2 × 2 × 3 and 2 + 2 + 3 = 7, so 12 is not a product-sum number.
However, 6 = 1 × 2 × 3 and 1 + 2 + 3 = 6, so 6 is a product-sum number.

We define the minimal product-sum number for k elements as the smallest N such that there exists a set of k natural numbers whose product and sum both equal N.

Find the sum of all minimal product-sum numbers for k = 2 to 12000.

## Solution Approach
We'll use a recursive approach to find all possible factorizations and track the minimal product-sum numbers for each k.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    limit := 12000
    minProductSum := make([]int, limit+1)
    
    // Initialize with a large value
    for i := 0; i <= limit; i++ {
        minProductSum[i] = limit * 100
    }
    
    // Start the recursive search
    findProductSum(1, 0, 2, 1, minProductSum)
    
    // Sum up unique minimal product-sum numbers
    result := 0
    seen := make(map[int]bool)
    
    for i := 2; i <= limit; i++ {
        if minProductSum[i] != limit*100 && !seen[minProductSum[i]] {
            result += minProductSum[i]
            seen[minProductSum[i]] = true
        }
    }
    
    fmt.Println(result)
}

// Recursive function to find product-sum numbers
func findProductSum(product, sum, start, k int, minProductSum []int) {
    // If we've found a better solution for this k, return
    if product > len(minProductSum) {
        return
    }
    
    // If we've found a valid solution
    if product == sum && k >= 2 {
        if product < minProductSum[k] {
            minProductSum[k] = product
        }
        return
    }
    
    // Continue searching with new factors
    // We only consider factors from start onwards to avoid duplicates
    for i := start; i <= int(math.Sqrt(float64(product))) + 1; i++ {
        if product*i > len(minProductSum) {
            break
        }
        // Continue with i as a factor
        findProductSum(product*i, sum+i, i, k+1, minProductSum)
    }
}
```

## Explanation

The solution works by:

1. **Recursive Search**: We recursively explore all possible factorizations of numbers
2. **Product-Sum Condition**: For each factorization, we check if the product equals the sum
3. **Tracking Minimal Values**: For each k (number of factors), we track the smallest N that satisfies the condition
4. **Optimization**: We only consider factors from a certain start point to avoid duplicates and improve efficiency

The key insight is that we want to find the minimal N for each k such that there exists a set of k natural numbers whose product and sum both equal N.

The time complexity is manageable due to the pruning of the search space, and the solution correctly identifies all minimal product-sum numbers for k from 2 to 12000.
