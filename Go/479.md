# Euler Problem 479 Solution in Go

I'll solve Euler Problem 479, which asks for the sum of all integers k from 1 to 10^12 such that gcd(k, 10^12) = 1.

This is essentially asking for the sum of all integers up to 10^12 that are coprime to 10^12.

## Analysis

The problem is asking for:
$$\sum_{k=1}^{10^{12}} k \cdot \mathbb{1}_{\gcd(k, 10^{12}) = 1}$$

Where $\mathbb{1}_{\gcd(k, 10^{12}) = 1}$ is 1 if k and 10^12 are coprime, 0 otherwise.

## Approach

1. First, we need to find φ(10^12) where φ is Euler's totient function
2. Then use the property that the sum of all integers ≤ n that are coprime to n is:
   $$\frac{n \cdot \varphi(n)}{2}$$

Let's implement this in Go:

```go
package main

import (
    "fmt"
    "math/big"
)

// Function to compute Euler's totient function φ(n)
func eulerTotient(n *big.Int) *big.Int {
    result := new(big.Int).Set(n)
    
    // Check for factor 2
    if n.Bit(0) == 0 {
        result.Div(result, big.NewInt(2))
        for n.Bit(0) == 0 {
            n.Div(n, big.NewInt(2))
        }
    }
    
    // Check for odd factors
    d := big.NewInt(3)
    for d.Mul(d, d).Cmp(n) <= 0 {
        if n.Mod(n, d).Cmp(big.NewInt(0)) == 0 {
            result.Mul(result, new(big.Int).Sub(d, big.NewInt(1)))
            result.Div(result, d)
            for n.Mod(n, d).Cmp(big.NewInt(0)) == 0 {
                n.Div(n, d)
            }
        }
        d.Add(d, big.NewInt(2))
    }
    
    // If n is still greater than 1, then it's a prime factor
    if n.Cmp(big.NewInt(1)) > 0 {
        result.Mul(result, new(big.Int).Sub(n, big.NewInt(1)))
        result.Div(result, n)
    }
    
    return result
}

// Function to compute 10^12
func power10(n int) *big.Int {
    result := big.NewInt(1)
    for i := 0; i < n; i++ {
        result.Mul(result, big.NewInt(10))
    }
    return result
}

func main() {
    // Compute 10^12
    n := power10(12)
    
    // Compute φ(10^12)
    phi := eulerTotient(n)
    
    // Compute sum = n * φ(n) / 2
    sum := new(big.Int).Mul(n, phi)
    sum.Div(sum, big.NewInt(2))
    
    fmt.Printf("Sum of all integers k from 1 to 10^12 such that gcd(k, 10^12) = 1 is:\n")
    fmt.Println(sum.String())
}
```

## Mathematical Explanation

Let me also provide a more mathematical approach to verify the formula:

1. For any integer n, the sum of all integers from 1 to n that are coprime to n is:
   $$S(n) = \frac{n \cdot \varphi(n)}{2}$$

2. This can be proven by noting that if k is coprime to n, then n-k is also coprime to n, and they form pairs that sum to n.

3. For n = 10^12 = 2^12 × 5^12, we compute:
   - φ(10^12) = 10^12 × (1 - 1/2) × (1 - 1/5) = 10^12 × 1/2 × 4/5 = 10^12 × 2/5 = 4 × 10^11

4. Therefore: S(10^12) = 10^12 × 4 × 10^11 / 2 = 2 × 10^23
