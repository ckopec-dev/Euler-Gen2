# Euler Problem 519 Solution in Go

I'll solve Euler Problem 519, which asks for the sum of all numbers n where the sum of digits of n equals the sum of digits of 3n.

## Problem Analysis

The problem asks us to find all numbers n such that:
- Sum of digits of n = Sum of digits of 3n
- We need to sum all such numbers n where 1 ≤ n ≤ 10^17

Let me analyze the mathematical properties:
- If we have a number n and 3n, their digit sums must be equal
- This creates a specific pattern that we can exploit
- We can use the property that digit sum of 3n = digit sum of n if and only if there are no carries when multiplying by 3

## Solution Approach

The key insight is that we need to count numbers where 3n doesn't cause carries in any digit position. This happens when:
- Each digit of n is ≤ 3 (since 3×3 = 9, which is still a single digit)
- But we also need to consider the cases where carries occur but the digit sums remain equal

func sumOfDigits(n *big.Int) int {
    s := n.String()
    sum := 0
    for _, digit := range s {
        sum += int(digit - '0')
    }
    return sum
}
