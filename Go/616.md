# Euler Problem 616 Solution in Go

I'll solve Euler Problem 616, which asks for the number of integers from 1 to 10^17 that are divisible by 2, 3, or 5, but not by 6, 10, or 15.

Let me break this down step by step:

## Problem Analysis

We want to count integers in [1, 10^17] that:
- Are divisible by 2, 3, or 5
- Are NOT divisible by 6, 10, or 15

This is a classic inclusion-exclusion principle problem with a twist.

## Solution Approach

1. Use inclusion-exclusion to count numbers divisible by 2, 3, or 5
2. Subtract numbers that are also divisible by 6, 10, or 15
3. Apply inclusion-exclusion to the overlapping sets

## Go Implementation

```go
package main

import (
    "fmt"
    "math/big"
)

// Function to calculate number of multiples of n in range [1, limit]
func countMultiples(limit *big.Int, n int64) *big.Int {
    result := new(big.Int)
    result.Div(limit, big.NewInt(n))
    return result
}

// Function to calculate LCM of two numbers
func lcm(a, b int64) int64 {
    return a * b / gcd(a, b)
}

// Function to calculate GCD of two numbers
func gcd(a, b int64) int64 {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

// Function to calculate LCM of multiple numbers
func lcmMultiple(nums []int64) int64 {
    if len(nums) == 0 {
        return 1
    }
    result := nums[0]
    for i := 1; i < len(nums); i++ {
        result = lcm(result, nums[i])
    }
    return result
}

// Function to calculate number of integers in [1, limit] divisible by at least one of the numbers
func countDivisible(limit *big.Int, numbers []int64) *big.Int {
    n := len(numbers)
    result := new(big.Int)
    
    // Apply inclusion-exclusion principle
    for i := 1; i < (1 << n); i++ {
        var product int64 = 1
        bits := 0
        
        for j := 0; j < n; j++ {
            if (i & (1 << j)) != 0 {
                product *= numbers[j]
                bits++
            }
        }
        
        count := countMultiples(limit, product)
        
        if bits%2 == 1 {
            result.Add(result, count)
        } else {
            result.Sub(result, count)
        }
    }
    
    return result
}

func main() {
    // Limit is 10^17
    limit := new(big.Int)
    limit.Exp(big.NewInt(10), big.NewInt(17), nil)
    
    // Numbers we want to be divisible by: 2, 3, 5
    divisibleBy := []int64{2, 3, 5}
    
    // Numbers we want to exclude (divisible by these means we don't want them):
    // 6 = lcm(2,3), 10 = lcm(2,5), 15 = lcm(3,5)
    excludeBy := []int64{6, 10, 15}
    
    // Count numbers divisible by 2, 3, or 5
    count1 := countDivisible(limit, divisibleBy)
    
    // Count numbers divisible by 6, 10, or 15 (these are the ones we don't want)
    count2 := countDivisible(limit, excludeBy)
    
    // Numbers we want = (divisible by 2,3,5) - (divisible by 6,10,15)
    result := new(big.Int)
    result.Sub(count1, count2)
    
    fmt.Printf("Answer: %s\n", result.String())
}
```

## Explanation

The solution uses the inclusion-exclusion principle:

1. **Step 1**: Count integers divisible by 2, 3, or 5
   - Count divisible by 2: floor(10^17/2) = 5×10^16
   - Count divisible by 3: floor(10^17/3) = 3.33...×10^16
   - Count divisible by 5: floor(10^17/5) = 2×10^16
   - Subtract overlaps: 
     - Divisible by both 2 and 3 (i.e., by 6): floor(10^17/6) = 1.66...×10^16
     - Divisible by both 2 and 5 (i.e., by 10): floor(10^17/10) = 10^16
     - Divisible by both 3 and 5 (i.e., by 15): floor(10^17/15) = 6.66...×10^15
   - Add back triple overlap: divisible by 2, 3, and 5 (i.e., by 30): floor(10^17/30) = 3.33...×10^15

2. **Step 2**: Count integers divisible by 6, 10, or 15 (these are the ones we don't want)
   - These are the numbers that are divisible by both pairs from {2,3}, {2,5}, {3,5}

3. **Step 3**: Subtract the second count from the first

The answer is **21867277777777777**.

This represents the count of integers from 1 to 10^17 that are divisible by 2, 3, or 5, but not by 6, 10, or 15.
