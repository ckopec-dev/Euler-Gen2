# Euler Problem 549 Solution in Go

Euler Problem 549 asks: "Find the sum of the smallest values of n such that n! is divisible by a given number."

Let me break down the solution:

## Problem Understanding

We need to find the smallest positive integer `n` such that `n!` (n factorial) is divisible by a given number `k`. Then we sum all such smallest `n` values for all numbers from 1 to 10^8.

## Key Insights

1. For `n!` to be divisible by `k`, all prime factors of `k` with their respective powers must be present in `n!`
2. The smallest `n` is determined by the prime factorization of `k`
3. For a prime `p` with power `a` in `k`, we need at least `a` factors of `p` in `n!`
4. The number of times prime `p` divides `n!` is given by Legendre's formula: `⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ...`

## Mathematical Analysis

The key mathematical insight is that we're looking for the smallest `n` such that:

$$n! \equiv 0 \pmod{k}$$

This means that every prime factor of `k` with its multiplicity must appear in `n!`.

For a prime `p` with power `a` in the factorization of `k`, we need:
$$\sum_{i=1}^{\infty} \lfloor \frac{n}{p^i} \rfloor \geq a$$

The solution involves:
1. Prime factorization of each number
2. Binary search for the minimal `n` that satisfies the condition
3. Summing all minimal values
