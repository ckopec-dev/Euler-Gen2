# Euler Problem 364 Solution in Go

## Problem Statement
Consider the number 142857. We can right-rotate this number to obtain 714285. We can right-rotate this number to obtain 571428. We can right-rotate this number to obtain 857142. We can right-rotate this number to obtain 285714. We can right-rotate this number to obtain 428571. This number has a special property: when we multiply it by 1, 2, 3, 4, 5, and 6, we get the same digits in a different order.

Let's call a number a "right-rotating number" if it has this property. Find the sum of all right-rotating numbers less than 10^10.

## Analysis
This problem is asking us to find numbers where all cyclic permutations (right-rotations) of the number are multiples of the original number. This is a well-known property related to cyclic numbers.

For a number to have this property, it must be a cyclic number, which are related to the decimal expansion of 1/p where p is a prime number (specifically, the prime must be such that 10 is a primitive root modulo p).

The most famous example is 142857, which is related to 1/7 = 0.142857142857...

## Solution Approach
1. Generate cyclic numbers related to primes where 10 is a primitive root
2. Check which ones are less than 10^10
3. Sum all valid numbers
