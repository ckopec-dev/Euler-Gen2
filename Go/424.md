# Euler Problem 424 Solution in Go

## Problem Statement
Euler Problem 424 asks us to find the number of ways to write a number as a sum of powers of 2, where each power can be used at most twice.

## Solution Approach
I'll use dynamic programming to solve this problem. For each number, I'll count the number of ways to express it as a sum of powers of 2 where each power appears at most twice.

## Go Implementation

```go
package main

import (
    "fmt"
    "math"
)

func solveEuler424(n int) int {
    // dp[i] represents number of ways to express number i
    dp := make([]int, n+1)
    dp[0] = 1 // One way to make 0 (use nothing)
    
    // For each power of 2
    for i := 0; i < 32; i++ {
        power := 1 << i // 2^i
        if power > n {
            break
        }
        
        // For each number from power to n
        for j := power; j <= n; j++ {
            // We can use this power 0, 1, or 2 times
            // dp[j] += dp[j-power] (use 1 power)
            // But we also need to consider using 2 powers
            dp[j] += dp[j-power]
            
            // If we can use 2 powers, add that possibility
            if j >= 2*power {
                dp[j] += dp[j-2*power]
            }
        }
    }
    
    return dp[n]
}

// Alternative approach using memoization
func solveEuler424Memo(n int) int {
    memo := make(map[int]int)
    
    var dp func(int) int
    dp = func(num int) int {
        if num == 0 {
            return 1
        }
        if num < 0 {
            return 0
        }
        if val, exists := memo[num]; exists {
            return val
        }
        
        result := 0
        // Try all powers of 2 that are <= num
        for i := 0; i < 32; i++ {
            power := 1 << i
            if power > num {
                break
            }
            // Use 0, 1, or 2 of this power
            result += dp(num - power)  // Use 1 power
            if num >= 2*power {
                result += dp(num - 2*power) // Use 2 powers
            }
        }
        
        memo[num] = result
        return result
    }
    
    return dp(n)
}

// More efficient approach using the mathematical property
func solveEuler424Optimized(n int) int {
    // This is actually the number of partitions where each part can appear at most 2 times
    // This is a classic dynamic programming problem
    
    dp := make([]int, n+1)
    dp[0] = 1
    
    // For each power of 2
    for i := 0; i < 32; i++ {
        power := 1 << i
        if power > n {
            break
        }
        
        // Process from right to left to avoid counting the same power multiple times
        for j := n; j >= power; j-- {
            dp[j] += dp[j-power]
            if j >= 2*power {
                dp[j] += dp[j-2*power]
            }
        }
    }
    
    return dp[n]
}

func main() {
    // For Euler Problem 424, we need to find the answer for a specific value
    // The problem asks for the number of ways to write 10^12 as a sum of powers of 2

    n := 1000000000000 // 10^12
    
    fmt.Printf("Solving Euler Problem 424 for n = %d\n", n)
    
    // Since n is very large, we'll compute it for a smaller example first
    // to verify our approach works correctly
    
    fmt.Println("Testing with smaller values:")
    for i := 0; i <= 10; i++ {
        result := solveEuler424Optimized(i)
        fmt.Printf("n = %d: %d ways\n", i, result)
    }
    
    // For the actual problem, we'd compute it for 10^12
    // But since that's computationally intensive, let's show the approach
    
    fmt.Println("\nFor the actual problem (10^12), the approach would be:")
    fmt.Println("1. Use dynamic programming with dp[i] = number of ways to make sum i")
    fmt.Println("2. For each power of 2 (2^0, 2^1, 2^2, ...), update the dp array")
    fmt.Println("3. Each power can be used 0, 1, or 2 times")
    fmt.Println("4. Return dp[10^12]")
    
    // Since we can't actually compute 10^12 in reasonable time,
    // let's just verify with a reasonable example
    fmt.Printf("\nExample with n=10: %d\n", solveEuler424Optimized(10))
}
```

## Explanation

The solution uses dynamic programming with the following approach:

1. **State Definition**: `dp[i]` represents the number of ways to express the number `i` as a sum of powers of 2, where each power can be used at most twice.

2. **Transition**: For each power of 2 (2^0, 2^1, 2^2, ...), we update our dp array:
   - We can use 0, 1, or 2 of each power
   - For each valid power `p`, we add `dp[i-p]` and `dp[i-2*p]` to `dp[i]`

3. **Base Case**: `dp[0] = 1` (one way to make 0: use nothing)

## Key Insights

- This is essentially counting partitions with restricted multiplicities
- Each power of 2 can appear 0, 1, or 2 times in any valid partition
- The time complexity is O(n × log n) where n is the target number
- The space complexity is O(n)
