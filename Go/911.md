# Euler Problem 911 Solution in Go

I'll solve Euler Problem 911, which asks for the sum of all numbers n such that φ(n) = 12, where φ is Euler's totient function.

## Problem Understanding

Euler's totient function φ(n) counts the number of positive integers less than or equal to n that are relatively prime to n. We need to find all n where φ(n) = 12 and sum them.

## Approach

1. We'll use the property that if n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then:
   φ(n) = n × ∏(1 - 1/pᵢ) for all prime factors pᵢ of n

2. We'll iterate through possible values and check if φ(n) = 12

3. We'll use a more efficient approach by considering the possible prime factorizations

func sieveOfEratosthenes(limit int) []int {
    isPrime := make([]bool, limit+1)
    for i := 2; i <= limit; i++ {
        isPrime[i] = true
    }
    
    for i := 2; i*i <= limit; i++ {
        if isPrime[i] {
            for j := i * i; j <= limit; j += i {
                isPrime[j] = false
            }
        }
    }

            primes = append(primes, i)
        }
    }
    
    return primes
}
