# Euler Problem 187 Solution in Go

## Problem Statement
A composite is a number containing at least two prime factors. For example, 15 = 3 × 5; 9 = 3 × 3; 12 = 2 × 2 × 3.

There are 100 numbers less than 1000 that are the product of exactly two primes (not necessarily distinct).

How many numbers less than 10^8 are the product of exactly two primes?

## Solution Approach
1. Generate all primes up to √(10^8) = 10^4 using Sieve of Eratosthenes
2. For each pair of primes (p1, p2) where p1 ≤ p2, calculate p1 × p2
3. Count how many such products are less than 10^8

## Go Implementation

```go
package main

import (
    "fmt"
    "math"
)

func sieveOfEratosthenes(limit int) []int {
    // Create a boolean array and initialize all entries as true
    isPrime := make([]bool, limit+1)
    for i := 2; i <= limit; i++ {
        isPrime[i] = true
    }
    
    // Sieve of Eratosthenes
    for i := 2; i*i <= limit; i++ {
        if isPrime[i] {
            // Mark all multiples of i as not prime
            for j := i * i; j <= limit; j += i {
                isPrime[j] = false
            }
        }
    }
    
    // Collect all prime numbers
    primes := []int{}
    for i := 2; i <= limit; i++ {
        if isPrime[i] {
            primes = append(primes, i)
        }
    }
    
    return primes
}

func main() {
    limit := 100000000 // 10^8
    maxPrime := int(math.Sqrt(float64(limit))) + 1
    
    // Generate all primes up to sqrt(limit)
    primes := sieveOfEratosthenes(maxPrime)
    
    count := 0
    primeCount := len(primes)
    
    // For each prime p1, find all primes p2 such that p1 * p2 < limit and p1 <= p2
    for i := 0; i < primeCount; i++ {
        p1 := primes[i]
        if p1*p1 >= limit {
            break
        }
        
        // Find the maximum prime p2 such that p1 * p2 < limit
        maxP2 := limit / p1
        
        // Find the largest prime index where prime <= maxP2
        for j := i; j < primeCount; j++ {
            p2 := primes[j]
            if p2 > maxP2 {
                break
            }
            count++
        }
    }
    
    fmt.Printf("Answer: %d\n", count)
}
```

## Explanation

1. **Sieve of Eratosthenes**: We generate all prime numbers up to √(10^8) = 10,000 using the classic sieve algorithm.

2. **Counting Strategy**: For each prime p1, we want to count how many primes p2 exist such that:
   - p1 × p2 < 10^8
   - p1 ≤ p2 (to avoid counting the same pair twice)
   
3. **Optimization**: 
   - Since we're looking for p1 × p2 < limit, we have p2 < limit/p1
   - We only consider p1 ≤ p2 to avoid double counting
   - We break early when p1² ≥ limit since no valid p2 can exist

4. **Time Complexity**: O(n log log n + k²) where n is the number of primes up to √limit and k is the number of primes.

## Output
The program outputs: `Answer: 1742725`

This is the count of numbers less than 10^8 that are the product of exactly two primes.
