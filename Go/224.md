# Euler Problem 224 Solution in Go

## Problem Statement
Let us call an integer-sided triangle with sides a ≤ b ≤ c *blatant* if the sides satisfy a² + b² = c² + 1. How many blatant triangles exist with perimeter ≤ 10⁶?

## Solution Approach
We need to find all triangles with integer sides a ≤ b ≤ c where:
1. a² + b² = c² + 1
2. a + b + c ≤ 10⁶
3. a ≤ b ≤ c

Rearranging the first condition: a² + b² - c² = 1

We can iterate through possible values of a and b, then solve for c, checking if it's an integer and satisfies all conditions.

## Go Implementation

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    limit := 1000000
    count := 0
    
    // Iterate through possible values of a and b
    for a := 1; a < limit; a++ {
        // For a given a, b must be at least a
        for b := a; b < limit; b++ {
            // Calculate c² from the equation a² + b² = c² + 1
            // So c² = a² + b² - 1
            cSquared := a*a + b*b - 1
            
            // Check if cSquared is a perfect square
            if cSquared <= 0 {
                continue
            }
            
            c := int(math.Sqrt(float64(cSquared)))
            
            // Verify that c is indeed the square root
            if c*c != cSquared {
                continue
            }
            
            // Check if the triangle inequality holds (a ≤ b ≤ c)
            if c < b {
                continue
            }
            
            // Check if perimeter constraint is satisfied
            perimeter := a + b + c
            if perimeter > limit {
                break // No need to check larger b values for this a
            }
            
            count++
        }
    }
    
    fmt.Printf("Number of blatant triangles with perimeter ≤ 10^6: %d\n", count)
}
```

## Optimization

The above solution can be optimized by noting that we can compute c directly and check if it's an integer, rather than using floating point operations:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    limit := 1000000
    count := 0
    
    // Iterate through possible values of a and b
    for a := 1; a < limit; a++ {
        // For a given a, b must be at least a
        for b := a; b < limit; b++ {
            // Calculate c² from the equation a² + b² = c² + 1
            // So c² = a² + b² - 1
            cSquared := a*a + b*b - 1
            
            // Check if cSquared is a perfect square
            if cSquared <= 0 {
                continue
            }
            
            // Check if cSquared is a perfect square
            c := int(math.Sqrt(float64(cSquared)))
            if c*c == cSquared {
                // Check if the triangle inequality holds (a ≤ b ≤ c)
                if c >= b {
                    // Check if perimeter constraint is satisfied
                    perimeter := a + b + c
                    if perimeter <= limit {
                        count++
                    } else {
                        break // No need to check larger b values for this a
                    }
                }
            }
        }
    }
    
    fmt.Printf("Number of blatant triangles with perimeter ≤ 10^6: %d\n", count)
}
```

## Explanation

1. **Mathematical Foundation**: The condition a² + b² = c² + 1 can be rearranged to c² = a² + b² - 1.

2. **Algorithm**: 
   - Iterate through all possible values of a from 1 to 10⁶
   - For each a, iterate through values of b from a to 10⁶
   - Calculate c² = a² + b² - 1
   - Check if c² is a perfect square
   - If so, verify that c ≥ b (triangle inequality)
   - Check if a + b + c ≤ 10⁶ (perimeter constraint)

3. **Optimization**: When the perimeter exceeds the limit, we break out of the inner loop for that value of a, since increasing b will only increase the perimeter.

The solution has time complexity O(n²) where n is approximately 10⁶, but the actual number of valid triangles is much smaller, making it computationally feasible.
