# Euler Problem 26 Solution in R

## Problem Statement
A unit fraction contains 1 in the numerator. The decimal representation of the unit fractions with denominators 2 to 10 are given:

- 1/2 = 0.5
- 1/3 = 0.333333...
- 1/4 = 0.25
- 1/5 = 0.2
- 1/6 = 0.166666...
- 1/7 = 0.142857...
- 1/8 = 0.125
- 1/9 = 0.111111...
- 1/10 = 0.1

Where 1/7 has a 6-digit recurring cycle, we are to find the value of d < 1000 for which 1/d contains the longest recurring cycle in its decimal fraction part.

## Solution Approach
To find the length of the recurring cycle in 1/d, I need to perform long division and detect when a remainder repeats. When a remainder repeats, the cycle begins to repeat.

```r
# Function to find the length of recurring cycle in 1/d
find_cycle_length <- function(d) {
  # If d is divisible by 2 or 5, there's no recurring cycle
  if (d %% 2 == 0 || d %% 5 == 0) {
    return(0)
  }
  
  remainder <- 1
  remainders <- c()
  
  # Perform long division until remainder repeats or becomes 0
  while (remainder != 0) {
    # Check if we've seen this remainder before
    if (remainder %in% remainders) {
      # Return the length of the cycle
      return(length(remainders) - which(remainders == remainder) + 1)
    }
    
    # Add remainder to our list
    remainders <- c(remainders, remainder)
    
    # Perform long division step
    remainder <- (remainder * 10) %% d
  }
  
  # No cycle found
  return(0)
}

# Find the maximum cycle length for d < 1000
max_length <- 0
best_d <- 0

for (d in 2:999) {
  cycle_length <- find_cycle_length(d)
  if (cycle_length > max_length) {
    max_length <- cycle_length
    best_d <- d
  }
}

# Print result
cat("The value of d < 1000 for which 1/d contains the longest recurring cycle is:", best_d, "\n")
cat("The length of the cycle is:", max_length, "\n")
```

## Alternative Implementation (More Efficient)

```r
# More efficient approach using mathematical properties
find_cycle_length_efficient <- function(d) {
  # Remove factors of 2 and 5
  while (d %% 2 == 0) d <- d %/% 2
  while (d %% 5 == 0) d <- d %/% 5
  
  # If d becomes 1, there's no recurring cycle
  if (d == 1) return(0)
  
  # Find smallest k such that 10^k ≡ 1 (mod d)
  k <- 1
  remainder <- 10 %% d
  
  while (remainder != 1) {
    remainder <- (remainder * 10) %% d
    k <- k + 1
  }
  
  return(k)
}

# Find maximum cycle length
max_length <- 0
best_d <- 0

for (d in 2:999) {
  cycle_length <- find_cycle_length_efficient(d)
  if (cycle_length > max_length) {
    max_length <- cycle_length
    best_d <- d
  }
}

# Print result
cat("The value of d < 1000 for which 1/d contains the longest recurring cycle is:", best_d, "\n")
cat("The length of the cycle is:", max_length, "\n")
```
