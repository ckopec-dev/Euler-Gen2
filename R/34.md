# Euler Problem 34 Solution in R

## Problem Statement
145 is a curious number, as 1! + 4! + 5! = 1 + 24 + 120 = 145.

Find the sum of all numbers which are equal to the sum of the factorial of their digits.

Note: As 1! = 1 and 2! = 2 are not sums they are not included.

## Solution Approach
1. We need to find numbers where the sum of factorials of individual digits equals the number itself
2. We can limit our search space by determining an upper bound
3. For a number with n digits, if all digits were 9, the maximum sum would be n × 9!
4. We need to find where n × 9! < 10^(n-1) to determine our upper limit

## R Code Implementation

```r
# Function to calculate factorial
factorial <- function(n) {
  if (n <= 1) return(1)
  return(n * factorial(n - 1))
}

# Pre-calculate factorials for digits 0-9
factorial_digits <- sapply(0:9, factorial)

# Function to check if a number is equal to sum of factorials of its digits
is_curious <- function(num) {
  # Convert number to digits
  digits <- as.numeric(strsplit(as.character(num), "")[[1]])
  # Calculate sum of factorials of digits
  sum_factorials <- sum(factorial_digits[digits + 1])  # +1 because R uses 1-based indexing
  return(sum_factorials == num)
}

# Find upper bound
# For n-digit numbers, we need n * 9! < 10^(n-1)
# Let's check this systematically
upper_bound <- 1
while (upper_bound * factorial(9) >= 10^(nchar(upper_bound) - 1)) {
  upper_bound <- upper_bound * 10
}

# Actually, let's be more precise
# 7 * 9! = 7 * 362880 = 2,540,160
# 8 * 9! = 8 * 362880 = 2,903,040
# 9 * 9! = 9 * 362880 = 3,265,920
# So we can reasonably check up to about 10^7

# Find all curious numbers
curious_numbers <- c()

for (i in 3:1000000) {  # Start from 3 since 1! and 2! are excluded
  if (is_curious(i)) {
    curious_numbers <- c(curious_numbers, i)
    cat("Found curious number:", i, "\n")
  }
}

# Calculate the sum
result <- sum(curious_numbers)
cat("Sum of all curious numbers:", result, "\n")
cat("Curious numbers found:", curious_numbers, "\n")
```

## More Efficient Approach

```r
# More efficient implementation
factorial <- function(n) {
  if (n <= 1) return(1)
  return(n * factorial(n - 1))
}

# Pre-calculate all factorials needed (0! to 9!)
factorials <- sapply(0:9, factorial)

# Function to get sum of factorials of digits
sum_of_digit_factorials <- function(num) {
  digits <- as.numeric(strsplit(as.character(num), "")[[1]])
  return(sum(factorials[digits + 1]))
}

# Find all curious numbers
curious_numbers <- c()

# Upper bound estimation: 9! * 7 = 2,540,160, which is a 7-digit number
# So we only need to check up to about 10^7
for (i in 3:2540160) {
  if (sum_of_digit_factorials(i) == i) {
    curious_numbers <- c(curious_numbers, i)
  }
}

# Display results
cat("Curious numbers:", curious_numbers, "\n")
cat("Sum:", sum(curious_numbers), "\n")
```
