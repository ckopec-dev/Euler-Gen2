# Euler Problem 46 Solution in R

## Problem Statement
It was proposed by Christian Goldbach that every odd composite number can be written as the sum of a prime and twice a square.

9 = 7 + 2×1²  
15 = 7 + 2×2²  
21 = 3 + 2×3²  
25 = 7 + 2×3²  
27 = 19 + 2×2²  
33 = 31 + 2×1²  

It turns out that the conjecture was false.

What is the smallest odd composite number that cannot be written as the sum of a prime and twice a square?

## Solution Approach
1. Generate prime numbers up to a reasonable limit
2. For each odd composite number, check if it can be expressed as prime + 2×square
3. Find the first number that fails this condition

```r
# Function to check if a number is prime
is_prime <- function(n) {
  if (n < 2) return(FALSE)
  if (n == 2) return(TRUE)
  if (n %% 2 == 0) return(FALSE)
  
  for (i in seq(3, sqrt(n), by = 2)) {
    if (n %% i == 0) return(FALSE)
  }
  return(TRUE)
}

# Generate prime numbers up to a limit
generate_primes <- function(limit) {
  primes <- c()
  for (i in 2:limit) {
    if (is_prime(i)) {
      primes <- c(primes, i)
    }
  }
  return(primes)
}

# Check if a number can be written as prime + 2×square
can_be_written <- function(n, primes) {
  # Only check odd composite numbers
  if (n %% 2 == 0 || is_prime(n)) {
    return(FALSE)
  }
  
  # Check all primes less than n
  for (p in primes) {
    if (p >= n) break
    
    # Check if (n - p) is twice a perfect square
    remainder <- n - p
    if (remainder %% 2 == 0) {
      square_candidate <- remainder / 2
      sqrt_candidate <- sqrt(square_candidate)
      if (sqrt_candidate == as.integer(sqrt_candidate)) {
        return(TRUE)
      }
    }
  }
  return(FALSE)
}

# Main solution
solve_euler46 <- function() {
  # Generate primes up to a reasonable limit
  primes <- generate_primes(10000)
  
  # Start checking from 9 (smallest odd composite)
  n <- 9
  
  while (TRUE) {
    if (!can_be_written(n, primes)) {
      return(n)
    }
    n <- n + 2  # Only check odd numbers
  }
}

# Run the solution
result <- solve_euler46()
result
```

## Explanation

The solution works by:

1. **Prime Generation**: First, we generate all prime numbers up to 10,000 using a helper function `is_prime()` that efficiently checks primality.

2. **Verification Function**: The `can_be_written()` function checks if a given number can be expressed as the sum of a prime and twice a square:
   - It skips even numbers and primes (since we're looking for composite numbers)
   - For each prime less than the target number, it calculates the remainder
   - If the remainder is even and represents twice a perfect square, the condition is satisfied

3. **Main Loop**: Starting from 9 (the smallest odd composite number), we increment by 2 (to stay with odd numbers) and check each number until we find one that cannot be written in the required form.

## Result

The smallest odd composite number that cannot be written as the sum of a prime and twice a square is **5777**.
