# Euler Problem 45 Solution in R

Euler Problem 45 asks us to find the next triangle number that is also pentagonal and hexagonal after 40755.

Let me break down the approach:
- Triangle numbers: T_n = n(n+1)/2
- Pentagonal numbers: P_n = n(3n-1)/2  
- Hexagonal numbers: H_n = n(2n-1)

We need to find numbers that appear in all three sequences.

```r
# Function to generate triangle numbers
triangle <- function(n) {
  return(n * (n + 1) / 2)
}

# Function to generate pentagonal numbers
pentagonal <- function(n) {
  return(n * (3 * n - 1) / 2)
}

# Function to generate hexagonal numbers
hexagonal <- function(n) {
  return(n * (2 * n - 1) / 2)
}

# Function to check if a number is pentagonal
is.pentagonal <- function(x) {
  # Solve 3n² - n - 2x = 0 for n
  # Using quadratic formula: n = (1 + sqrt(1 + 24x)) / 6
  n <- (1 + sqrt(1 + 24 * x)) / 6
  return(n == floor(n))
}

# Function to check if a number is hexagonal
is.hexagonal <- function(x) {
  # Solve 2n² - n - x = 0 for n
  # Using quadratic formula: n = (1 + sqrt(1 + 8x)) / 4
  n <- (1 + sqrt(1 + 8 * x)) / 4
  return(n == floor(n))
}

# Find the next number that is triangle, pentagonal, and hexagonal
# Start from the next hexagonal number after 40755
# 40755 = H_143, so we start from H_144

result <- 0
n <- 144

while (result == 0) {
  hex_num <- hexagonal(n)
  
  # Check if this hexagonal number is also pentagonal
  if (is.pentagonal(hex_num)) {
    # Check if it's also triangle
    # We can verify this by checking if it's of the form n(n+1)/2
    # But since it's hexagonal and pentagonal, we can just verify it works
    result <- hex_num
  }
  
  n <- n + 1
}

print(result)
```

However, there's a more efficient mathematical approach. Since every hexagonal number is also a triangle number (specifically T_{2n-1}), we only need to check if hexagonal numbers are also pentagonal.

```r
# More efficient approach
# Every hexagonal number is also a triangle number
# So we only need to check if hexagonal numbers are pentagonal

# Function to check if a number is pentagonal
is.pentagonal <- function(x) {
  n <- (1 + sqrt(1 + 24 * x)) / 6
  return(n == floor(n))
}

# Start from the hexagonal number after 40755
# 40755 = H_143, so we start from H_144
n <- 144
result <- 0

while (result == 0) {
  hex_num <- n * (2 * n - 1)
  
  if (is.pentagonal(hex_num)) {
    result <- hex_num
  }
  
  n <- n + 1
}

print(result)
```
