# Euler Problem 632 Solution in R

## Problem Statement
Find the number of integers 1 < n < 10^10 for which the number of divisors of n equals the number of divisors of n+1.

## Analysis
This is a computational problem that requires:
1. Finding the number of divisors for each number
2. Comparing consecutive numbers' divisor counts
3. Counting how many times they match

## Approach
We'll use the fact that the number of divisors can be calculated efficiently using the prime factorization approach. For a number n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, the number of divisors is (a₁+1)(a₂+1)...(aₖ+1).
