# Euler Problem 69 Solution in R

## Problem Statement
Euler Problem 69 asks us to find the value of n ≤ 1000000 for which n/φ(n) is maximized, where φ(n) is Euler's totient function.

## Mathematical Analysis
To maximize n/φ(n), we need to minimize φ(n)/n. Since φ(n) = n × ∏(1 - 1/p) for all prime factors p of n, we have:
φ(n)/n = ∏(1 - 1/p)

This means we want to minimize the product of (1 - 1/p) for all prime factors p of n. This is minimized when we have many small prime factors, and the product is minimized when we include as many small primes as possible.

The optimal solution is the product of consecutive primes starting from 2, until the product exceeds 1000000.

## R Solution

```r
# Function to check if a number is prime
is_prime <- function(n) {
  if (n < 2) return(FALSE)
  if (n == 2) return(TRUE)
  if (n %% 2 == 0) return(FALSE)
  
  for (i in seq(3, sqrt(n), by = 2)) {
    if (n %% i == 0) return(FALSE)
  }
  return(TRUE)
}

# Function to generate primes up to n
primes_up_to <- function(n) {
  primes <- c()
  for (i in 2:n) {
    if (is_prime(i)) {
      primes <- c(primes, i)
    }
  }
  return(primes)
}

# Function to calculate Euler's totient function
phi <- function(n) {
  if (n == 1) return(1)
  
  # Find all prime factors
  prime_factors <- c()
  temp_n <- n
  
  # Check for factor 2
  if (temp_n %% 2 == 0) {
    prime_factors <- c(prime_factors, 2)
    while (temp_n %% 2 == 0) {
      temp_n <- temp_n / 2
    }
  }
  
  # Check for odd factors
  i <- 3
  while (i * i <= temp_n) {
    if (temp_n %% i == 0) {
      prime_factors <- c(prime_factors, i)
      while (temp_n %% i == 0) {
        temp_n <- temp_n / i
      }
    }
    i <- i + 2
  }
  
  # If temp_n is still > 1, then it's a prime factor
  if (temp_n > 1) {
    prime_factors <- c(prime_factors, temp_n)
  }
  
  # Calculate phi(n) = n * product(1 - 1/p) for all prime factors p
  result <- n
  for (p in prime_factors) {
    result <- result * (1 - 1/p)
  }
  
  return(as.integer(result))
}

# Alternative efficient approach using the mathematical insight
# We want to maximize n/phi(n), which means minimize phi(n)/n
# This happens when we have the product of smallest primes possible

solve_euler69 <- function(limit) {
  # Generate primes up to a reasonable limit
  primes <- primes_up_to(100)
  
  # Find the product of consecutive primes that doesn't exceed limit
  result <- 1
  for (p in primes) {
    if (result * p > limit) {
      break
    }
    result <- result * p
  }
  
  return(result)
}

# Main solution
limit <- 1000000
answer <- solve_euler69(limit)
cat("The value of n ≤ 1000000 for which n/φ(n) is maximized is:", answer, "\n")

# Verification - let's check the ratio for our answer
n <- answer
phi_n <- phi(n)
ratio <- n / phi_n
cat("n =", n, "\n")
cat("φ(n) =", phi_n, "\n")
cat("n/φ(n) =", ratio, "\n")
```

## Explanation

The key insight for this problem is that to maximize n/φ(n), we want to minimize φ(n)/n. Since φ(n)/n = ∏(1 - 1/p) where p ranges over all prime factors of n, we want to minimize this product.

This is minimized when we have many small prime factors. The optimal solution is to take the product of consecutive primes starting from 2, until the product exceeds our limit.

For the limit of 1000000:
- 2 × 3 = 6
- 2 × 3 × 5 = 30  
- 2 × 3 × 5 × 7 = 210
- 2 × 3 × 5 × 7 × 11 = 2310
- 2 × 3 × 5 × 7 × 11 × 13 = 30030
- 2 × 3 × 5 × 7 × 11 × 13 × 17 = 510510
- 2 × 3 × 5 × 7 × 11 × 13 × 17 × 19 = 9699690 (exceeds 1000000)

So the answer is 2 × 3 × 5 × 7 × 11 × 13 × 17 = 510510.

## Final Answer
The value of n ≤ 1000000 for which n/φ(n) is maximized is **510510**.
