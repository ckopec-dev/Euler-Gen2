# Euler Problem 389 Solution in R

## Problem Statement
Let $ m $ be the smallest integer whose cube root is of the form $ n + r $, where $ n $ is a positive integer and $ r $ is a positive real number less than $ 1/1000 $. Find $ m $.

## Analysis
We need to find the smallest integer $ m $ such that $ \sqrt[3]{m} = n + r $ where:
- $ n $ is a positive integer
- $ 0 < r < \frac{1}{1000} $

This means $ n < \sqrt[3]{m} < n + \frac{1}{1000} $.

Rearranging: $ n^3 < m < (n + \frac{1}{1000})^3 $

For each integer $ n $, we need to find the smallest integer $ m $ such that $ n^3 < m < (n + \frac{1}{1000})^3 $.
