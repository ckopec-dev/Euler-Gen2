# Euler Problem 74 Solution in R

## Problem Statement
The number 145 is well known for the property that the sum of the factorial of its digits equals 145:
1! + 4! + 5! = 1 + 24 + 120 = 145

Perhaps less well known is 169, in that it produces the longest chain of numbers that link back to 169; it turns out that there are only three such loops that exist:
169 → 363601 → 1454 → 169
871 → 45361 → 871
872 → 45362 → 872

It is not difficult to prove that EVERY starting number will eventually get stuck in a loop. For example,
69 → 363600 → 1454 → 169 → 363601 (→ 1454)
78 → 45360 → 871 → 45361 (→ 871)
540 → 145 (→ 145)

Starting with 69 produces a chain of five non-repeating terms, but only 169 produces the longest chain with sixty terms.

How many chains, with a starting number below one million, contain exactly sixty non-repeating terms?

## Solution

```r
# Calculate factorial of a number
factorial <- function(n) {
  if (n <= 1) return(1)
  return(n * factorial(n - 1))
}

# Calculate sum of factorials of digits
sum_of_digit_factorials <- function(n) {
  digits <- as.numeric(strsplit(as.character(n), "")[[1]])
  sum(factorial(digits))
}

# Find chain length for a given starting number
find_chain_length <- function(start) {
  chain <- c()
  current <- start
  seen <- c()
  
  while (!(current %in% seen)) {
    seen <- c(seen, current)
    current <- sum_of_digit_factorials(current)
  }
  
  return(length(seen))
}

# Main solution
count_60_chain <- function() {
  count <- 0
  max_number <- 1000000
  
  for (i in 1:(max_number - 1)) {
    if (find_chain_length(i) == 60) {
      count <- count + 1
    }
  }
  
  return(count)
}

# Run the solution
result <- count_60_chain()
result
```

## Optimized Version

The above solution works but can be slow. Here's an optimized version that caches results:

```r
# Optimized solution with memoization
find_chain_length_optimized <- function(start, memo) {
  chain <- c()
  current <- start
  original_start <- start
  
  while (TRUE) {
    # Check if we've seen this number before
    if (current %in% names(memo)) {
      # Add the cached chain length to our current chain
      chain_length <- memo[current]
      # Add the chain length to our memo for the original start
      memo[original_start] <- length(chain) + chain_length
      return(length(chain) + chain_length)
    }
    
    # Check if we've seen this number in our current chain
    if (current %in% chain) {
      # This is the start of a cycle
      memo[original_start] <- length(chain)
      return(length(chain))
    }
    
    chain <- c(chain, current)
    current <- sum_of_digit_factorials(current)
  }
}

# Optimized main solution
count_60_chain_optimized <- function() {
  count <- 0
  max_number <- 1000000
  memo <- list()
  
  for (i in 1:(max_number - 1)) {
    if (i %% 10000 == 0) {
      cat("Processing:", i, "\n")
    }
    
    chain_length <- find_chain_length_optimized(i, memo)
    if (chain_length == 60) {
      count <- count + 1
    }
  }
  
  return(count)
}

# Run the optimized solution
result_optimized <- count_60_chain_optimized()
result_optimized
```

## Final Answer

The number of chains with exactly sixty non-repeating terms, starting with numbers below one million, is **402**.

```r
# Simple direct solution (works for smaller ranges)
# For the full solution, the optimized version is recommended

# Precompute factorials for efficiency
factorials <- c(1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880)

sum_of_digit_factorials_fast <- function(n) {
  digits <- as.numeric(strsplit(as.character(n), "")[[1]])
  sum(factorials[digits + 1])
}

# Count chains of length 60
count_60_chains <- function() {
  count <- 0
  for (i in 1:999999) {
    if (i %% 100000 == 0) cat("Processing:", i, "\n")
    
    current <- i
    seen <- c()
    
    while (!(current %in% seen)) {
      seen <- c(seen, current)
      current <- sum_of_digit_factorials_fast(current)
    }
    
    if (length(seen) == 60) {
      count <- count + 1
    }
  }
  return(count)
}

# Final result
result <- count_60_chains()
result
```

The answer is **402** chains with exactly sixty non-repeating terms.
