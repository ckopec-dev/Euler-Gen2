# Euler Problem 103 Solution in Haskell

## Problem Statement
Let S(A) represent the sum of elements in set A of size n. We shall call it a special sum set if for any two non-empty disjoint subsets, B and C, the following properties hold:
1. S(B) ≠ S(C); that is, sums of subsets cannot be equal
2. If B contains more elements than C then S(B) > S(C)

If S(A) is minimised, find the set A.

## Solution Approach
This is a complex optimization problem requiring us to find the minimal special sum set of size 7. We need to:
1. Generate candidate sets systematically
2. Check if a set satisfies the special sum set properties
3. Find the one with minimum sum

import Data.List

-- Check if a set is a special sum set
isSpecialSumSet :: [Int] -> Bool
isSpecialSumSet xs = 
    let sums = map sum (subsequences xs)
        -- Property 1: All subset sums must be distinct
        allDistinct = length (nub sums) == length sums
        -- Property 2: For any two subsets B and C, if |B| > |C| then S(B) > S(C)
        -- We need to check this for all pairs of subsets with different sizes
        pairs = [(b, c) | b <- subsequences xs, c <- subsequences xs, 
                          not (null b) && not (null c) && length b > length c]
        property2 = all (\(b, c) -> sum b > sum c) pairs
    in allDistinct && property2

-- Backtracking approach
backtrack :: [Int] -> Int -> Int -> [[Int]] -> [[Int]]
backtrack current pos minVal results
    | pos == length current = 
        if isSpecialSumSet current then current : results else results
    | otherwise = 
        let -- Try different values for current position
            candidates = [x | x <- [minVal..100], 
                              isValidExtension current pos x]
        in foldl (\acc val -> 
                    backtrack (replaceAt pos val current) (pos + 1) (val + 1) acc)
                 results candidates

-- Helper function to check if extension is valid

isValidExtension current pos val = 
    let newSet = replaceAt pos val current
    in isSpecialSumSet newSet

-- Replace element at index
replaceAt :: Int -> a -> [a] -> [a]
replaceAt i val xs = take i xs ++ [val] ++ drop (i + 1) xs
