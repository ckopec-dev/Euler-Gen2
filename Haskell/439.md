# Euler Problem 439 Solution in Haskell

I'll solve Euler Problem 439, which asks for the sum of all divisors of all numbers from 1 to N, where N = 10^15.

Let me break down the approach:
- We need to find the sum of all divisors for all numbers from 1 to N
- For each divisor d, it appears as a divisor in exactly ⌊N/d⌋ numbers
- So the total sum is Σ(d=1 to N) d × ⌊N/d⌋

The solution uses the mathematical insight that we don't need to iterate through all numbers, but rather group them by the distinct values of floor(n/d). This reduces the time complexity from O(n) to O(√n), making it feasible for large values like 10^15.

The algorithm works by:
1. For each distinct value q = floor(n/d), find the range of d values that produce this q
2. Calculate the sum of d values in that range
3. Multiply by q and accumulate the result

This approach is much more efficient for large inputs and is the key to solving the problem within reasonable time limits.
