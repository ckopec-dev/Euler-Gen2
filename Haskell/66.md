# Euler Problem 66 Solution in Haskell

Euler Problem 66 asks us to find the value of D ≤ 1000 for which the equation x² - Dy² = 1 (Pell's equation) has the largest minimal solution for x.

Here's my solution:

```haskell
import Data.List (maximumBy)
import Data.Ord (comparing)

-- Continued fraction expansion of sqrt(n)
contFrac :: Integer -> [Integer]
contFrac n = a0 : map head (iterate step (a0, n, a0))
  where
    a0 = floor (sqrt (fromIntegral n))
    step (a, m, d) = (a1, m1, d1)
      where
        m1 = d * a - m
        d1 = (n - m1^2) `div` d
        a1 = (a0 + m1) `div` d1

-- Generate convergents from continued fraction
convergents :: [Integer] -> [(Integer, Integer)]
convergents as = map (\(x, y) -> (x, y)) $ scanl next (0, 1) (tail as)
  where
    next (num, den) a = (a * num + prevNum, num)
      where
        prevNum = num

-- Solve Pell's equation x² - Dy² = 1
pellSolution :: Integer -> Integer
pellSolution d = head [x | (x, y) <- convergents (contFrac d), x^2 - d*y^2 == 1]

-- Find the maximum x value for D ≤ 1000
solve :: Integer
solve = maximum [pellSolution d | d <- [2..1000], not (isPerfectSquare d)]
  where
    isPerfectSquare n = let root = floor (sqrt (fromIntegral n)) in root * root == n

main :: IO ()
main = print solve
```
