# Euler Problem 36 Solution in Haskell

Euler Problem 36 asks us to find the sum of all numbers less than one million that are palindromic in both base 10 and base 2.

Here's the Haskell solution:

```haskell
isPalindrome :: String -> Bool
isPalindrome str = str == reverse str

toBinary :: Int -> String
toBinary 0 = "0"
toBinary n = toBinary (n `div` 2) ++ show (n `mod` 2)

isDoublePalindrome :: Int -> Bool
isDoublePalindrome n = 
    let decimalStr = show n
        binaryStr = toBinary n
    in isPalindrome decimalStr && isPalindrome binaryStr

solve :: Int
solve = sum [n | n <- [1..999999], isDoublePalindrome n]

main :: IO ()
main = print solve
```

## Explanation:

1. **`isPalindrome`**: Checks if a string is the same when reversed
2. **`toBinary`**: Converts an integer to its binary string representation
3. **`isDoublePalindrome`**: Tests if a number is palindromic in both decimal and binary
4. **`solve`**: Uses list comprehension to find all numbers from 1 to 999,999 that are double palindromes, then sums them

## Alternative more efficient approach:

```haskell
isPalindrome :: String -> Bool
isPalindrome str = str == reverse str

isDoublePalindrome :: Int -> Bool
isDoublePalindrome n = 
    let decimalStr = show n
        binaryStr = foldl (\acc x -> show x ++ acc) "" (takeWhile (>0) (iterate (`div` 2) n))
    in isPalindrome decimalStr && isPalindrome binaryStr

solve :: Int
solve = sum [n | n <- [1..999999], isDoublePalindrome n]

main :: IO ()
main = print solve
```

The answer is **872187**.
