# Euler Problem 484 Solution in Haskell

I'll solve Euler Problem 484, which asks for the number of ways to tile a 3×n rectangle with 2×1 dominoes.

Let me break this down step by step:

## Problem Understanding
We need to find the number of ways to tile a 3×n rectangle using 2×1 dominoes (which can be placed either horizontally or vertically).

## Approach
This is a classic dynamic programming problem. I'll use the recurrence relation approach.

Let's define:
- f(n) = number of ways to tile a 3×n rectangle
- We can build the recurrence by considering how the rightmost column can be filled

## Solution

    | n == 0    = 1
    | n == 1    = 1

    | otherwise = 4 * tiledominoes (n-2) - tiledominoes (n-4)

-- Alternative implementation using dynamic programming for better performance
tiledominoesDP :: Int -> Integer
tiledominoesDP n
    | n < 0 = 0
    | n == 0 = 1
    | n == 1 = 1
    | n == 2 = 3
    | otherwise = dp !! n
  where
    dp = 1 : 1 : 3 : zipWith (\a b -> 4 * a - b) (drop 2 dp) dp

## Mathematical Analysis

The key insight is to derive the recurrence relation for tiling a 3×n rectangle with 2×1 dominoes.

Let's think about how we can fill the rightmost columns:
- We can place a vertical domino (taking 2×1 space) in the last column
- We can place two horizontal dominoes (taking 2×2 space) in the last two columns

Through careful analysis of all possible configurations, the recurrence relation is:
**f(n) = 4×f(n-2) - f(n-4)** for n ≥ 4

With base cases:
- f(0) = 1 (empty rectangle)
- f(1) = 1 (3×1 rectangle can only be filled with 3 vertical dominoes)
- f(2) = 3 (3×2 rectangle can be filled in 3 ways)
- f(3) = 5 (3×3 rectangle can be filled in 5 ways)
