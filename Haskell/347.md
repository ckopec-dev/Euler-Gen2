# Euler Problem 347 Solution in Haskell

Euler Problem 347 asks us to find the sum of all distinct numbers that can be expressed as the product of two distinct primes, where both primes are less than or equal to a given limit.

Let me break down the approach:
1. Generate all primes up to the limit
2. For each pair of distinct primes, calculate their product
3. Keep track of products that are less than or equal to the limit
4. Sum all distinct products

```haskell
-- Generate all primes up to n using Sieve of Eratosthenes
primes :: Int -> [Int]
primes n = sieve [2..n]
  where
    sieve [] = []
    sieve (p:xs) = p : sieve [x | x <- xs, x `mod` p /= 0]

-- Generate all distinct products of two distinct primes <= n
distinctProducts :: Int -> [Int]
distinctProducts n = 
  let ps = primes n
      pairs = [(p1, p2) | p1 <- ps, p2 <- ps, p1 < p2]
      products = [p1 * p2 | (p1, p2) <- pairs, p1 * p2 <= n]
  in nub products
  where
    nub [] = []
    nub (x:xs) = x : nub (filter (/= x) xs)

-- Main solution
solve :: Int -> Int
solve n = sum (distinctProducts n)

-- For the specific problem, we want the sum of all distinct numbers
-- that can be expressed as the product of two distinct primes <= 10000
main :: IO ()
main = do
  let result = solve 10000
  print result
```
