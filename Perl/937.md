# Euler Problem 937 Solution in Perl

I need to solve Euler Problem 937, which asks for the sum of all positive integers n ≤ 10^12 such that n is divisible by 3 and n+1 is divisible by 7.

Let me analyze this step by step:

1. We need n such that:
   - n ≡ 0 (mod 3) 
   - n+1 ≡ 0 (mod 7), which means n ≡ 6 (mod 7)

2. This is a system of congruences that I can solve using the Chinese Remainder Theorem.

3. We have:
   - n ≡ 0 (mod 3)
   - n ≡ 6 (mod 7)

Let me solve this system:
- n = 3k for some integer k
- 3k ≡ 6 (mod 7)
- k ≡ 2 (mod 7) (since 3 × 2 = 6)
- So k = 7j + 2 for some integer j
- Therefore n = 3(7j + 2) = 21j + 6

So n ≡ 6 (mod 21)

This means the numbers we want are of the form n = 21j + 6 where j ≥ 0.

The sequence is: 6, 27, 48, 69, 90, 111, 132, 153, 174, 195, 216, ...

Now I need to find the sum of all such n ≤ 10^12.

The largest j such that 21j + 6 ≤ 10^12:
21j + 6 ≤ 10^12
21j ≤ 10^12 - 6
j ≤ (10^12 - 6)/21

Let me calculate this in Perl:

```perl
#!/usr/bin/perl
use strict;
use warnings;

my $limit = 10**12;
my $sum = 0;
my $j = 0;

# Find the largest valid j
my $max_j = int(($limit - 6) / 21);

# Sum all valid numbers
for my $j (0..$max_j) {
    my $n = 21 * $j + 6;
    $sum += $n;
}

print "Sum: $sum\n";
```

However, let me use a more efficient mathematical approach:

The sum of arithmetic sequence 6, 27, 48, ..., up to the largest term ≤ 10^12:

This is an arithmetic sequence with:
- First term a₁ = 6
- Common difference d = 21
- Last term aₙ ≤ 10^12

Number of terms: n = max_j + 1 = int((10^12 - 6)/21) + 1

Sum = n × (first_term + last_term) / 2

Let me compute this properly:

```perl
#!/usr/bin/perl
use strict;
use warnings;

my $limit = 10**12;
my $first = 6;
my $diff = 21;

# Find number of terms
my $max_j = int(($limit - $first) / $diff);
my $n = $max_j + 1;

# Find last term
my $last = $first + ($n - 1) * $diff;

# Sum of arithmetic sequence
my $sum = $n * ($first + $last) / 2;

print "Sum: $sum\n";
```
