# Euler Problem 459 Solution in Perl

## Problem Statement
The problem asks us to find the sum of all integers n ≤ 10^11 such that the number of divisors of n is equal to the number of divisors of n+1.

## Approach
This is a challenging number theory problem. We need to:
1. Find integers n where d(n) = d(n+1) (where d(n) is the number of divisors)
2. Sum all such n up to 10^11

The key insight is that we're looking for consecutive integers with the same number of divisors. This is a rare occurrence, and we can use mathematical properties to optimize our search.
