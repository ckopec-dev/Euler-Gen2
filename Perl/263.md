# Euler Problem 263 Solution in Perl

I'll solve Euler Problem 263, which asks for the first 4 consecutive integers that are Smith numbers.

## Problem Understanding

A Smith number is a composite number for which the sum of its digits equals the sum of the digits in its prime factorization (counting multiplicities).

## Solution

```perl
#!/usr/bin/perl
use strict;
use warnings;

sub sum_of_digits {
    my $n = shift;
    my $sum = 0;
    while ($n > 0) {
        $sum += $n % 10;
        $n = int($n / 10);
    }
    return $sum;
}

sub prime_factorization_sum {
    my $n = shift;
    my $sum = 0;
    my $original = $n;
    
    # Handle factor 2
    while ($n % 2 == 0) {
        $sum += sum_of_digits(2);
        $n = int($n / 2);
    }
    
    # Handle odd factors
    my $factor = 3;
    while ($factor * $factor <= $n) {
        while ($n % $factor == 0) {
            $sum += sum_of_digits($factor);
            $n = int($n / $factor);
        }
        $factor += 2;
    }
    
    # If n is still greater than 1, then it's a prime factor
    if ($n > 1) {
        $sum += sum_of_digits($n);
    }
    
    return $sum;
}

sub is_smith_number {
    my $n = shift;
    
    # Smith numbers must be composite
    return 0 if $n < 4;
    
    # Check if the sum of digits equals the sum of prime factorization digits
    return sum_of_digits($n) == prime_factorization_sum($n);
}

sub find_consecutive_smith_numbers {
    my $count = shift;
    my $num = 4;  # Start from 4 since 1, 2, 3 are not composite
    
    while (1) {
        my $consecutive = 0;
        my $start = $num;
        
        # Check if we have 'count' consecutive Smith numbers
        for my $i (0..$count-1) {
            if (is_smith_number($start + $i)) {
                $consecutive++;
            } else {
                $consecutive = 0;
                $num = $start + $i + 1;
                last;
            }
        }
        
        if ($consecutive == $count) {
            return $start;
        }
    }
}

# Find the first 4 consecutive Smith numbers
my $result = find_consecutive_smith_numbers(4);
print "The first 4 consecutive Smith numbers start with: $result\n";

# Verify the result
print "Verification:\n";
for my $i (0..3) {
    my $num = $result + $i;
    my $is_smith = is_smith_number($num) ? "Smith" : "Not Smith";
    print "$num: $is_smith\n";
}
```

## Explanation

The solution works as follows:

1. **sum_of_digits**: Calculates the sum of digits of a number
2. **prime_factorization_sum**: Calculates the sum of digits of all prime factors (with multiplicities)
3. **is_smith_number**: Determines if a number is a Smith number by comparing the sum of digits with the sum of prime factor digits
4. **find_consecutive_smith_numbers**: Finds the first sequence of consecutive Smith numbers

## Key Functions

- `sum_of_digits`: Extracts individual digits and sums them
- `prime_factorization_sum`: Uses trial division to find prime factors and sums their digits
- `is_smith_number`: Main logic to identify Smith numbers
- `find_consecutive_smith_numbers`: Searches for consecutive sequences
