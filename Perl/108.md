# Euler Problem 108 Solution in Perl

## Problem Statement
In the following equation, where x, y, and n are positive integers:
```
1/x + 1/y = 1/n
```

For n = 4 there are exactly three distinct solutions:
- 1/5 + 1/20 = 1/4
- 1/6 + 1/12 = 1/4  
- 1/8 + 1/8 = 1/4

What is the least value of n for which the number of distinct solutions exceeds one thousand?

## Solution Approach
We can rearrange the equation to find a relationship between the variables:
```
1/x + 1/y = 1/n
xy = n(x + y)
xy - nx - ny = 0
xy - nx - ny + n² = n²
(x - n)(y - n) = n²
```

So for each divisor d of n², we can set:
- x - n = d
- y - n = n²/d

This gives us x = n + d and y = n + n²/d.

use strict;
use warnings;

sub count_solutions {
    my ($n) = @_;
    my $count = 0;
    
    # Find all divisors of n²
    my $n_squared = $n * $n;
    
    for my $d (1..int(sqrt($n_squared))) {
        if ($n_squared % $d == 0) {
            # d is a divisor
            my $other_div = $n_squared / $d;
            
            # Check if we get positive integer solutions
            my $x = $n + $d;
            my $y = $n + $n_squared / $d;
            
            if ($x > 0 && $y > 0) {
                $count++;
            }
            
            # If d != other_div, we also have the pair (other_div, d)
            if ($d != $other_div) {
                $x = $n + $other_div;
                $y = $n + $n_squared / $other_div;
                
                if ($x > 0 && $y > 0) {
                    $count++;
                }
            }
        }
    }
    
    # We need to be careful about counting duplicates
    # Actually, let's use a cleaner approach:
    # For each divisor d of n² where d <= sqrt(n²), we get a solution
    # But we need to avoid double counting
    
    my $solution_count = 0;

                if ($x2 <= $y2) {
                    $unique_solutions++;
                }
            }
        }
    }
    
    # Actually, let's think differently - the number of solutions is

    # Simpler approach: count divisors of n² and use the formula
    # Number of solutions = (number of divisors of n² + 1) / 2
    # But this is wrong - let me reconsider the math
    
    # Let's just compute directly
    my $solutions = 0;
    my %seen = ();

            # First pair

            my $y1 = $n + $d2;

                my $key = ($x1 < $y1) ? "$x1,$y1" : "$y1,$x1";
                $seen{$key} = 1;

            # Second pair (if different)
            if ($d != $d2) {
                my $x2 = $n + $d2;
                my $y2 = $n + $d;

                    $seen{$key} = 1;
                }
            }
        }
    }

# But we need to be more careful - let's re-derive properly:
# 1/x + 1/y = 1/n
# xy = n(x + y)  
# xy - nx - ny = 0
# xy - nx - ny + n² = n²  
# (x - n)(y - n) = n²
# So x = n + d, y = n + n²/d where d is a divisor of n²

# But we also need to consider that we don't want to double count solutions
# where x = y. When x = y, we have 1/x + 1/x = 1/n, so 2/x = 1/n, so x = 2n
# This happens when n² = (2n - n)² = n², which is always true when x = y = 2n
# So we have exactly one solution where x = y when n² = n², which is always true.

# Actually, the correct approach:
# If (x-n)(y-n) = n², and we want x,y > 0, then x = n + d, y = n + n²/d
# where d is a positive divisor of n².
# But we need to avoid double counting.
# The number of solutions = (number of divisors of n² + 1) / 2

sub count_solutions_correct {
    my ($n) = @_;
    my $n_squared = $n * $n;
    my $divisor_count = 0;
    
    for my $d (1..int(sqrt($n_squared))) {
        if ($n_squared % $d == 0) {
            $divisor_count++;
            if ($d != $n_squared / $d) {
                $divisor_count++;
            }
        }
    }
    
    # For the equation 1/x + 1/y = 1/n, the number of distinct solutions is:
    # (number of divisors of n² + 1) / 2
    return int(($divisor_count + 1) / 2);
}

# But wait, let's test with n=4:
# n² = 16, divisors of 16: 1,2,4,8,16
# So 5 divisors, (5+1)/2 = 3, which matches the problem statement.
# So this formula is correct.

# Now let's find the smallest n where this count exceeds 1000
my $n = 1;
while (1) {
    my $solutions = count_solutions_correct($n);
    if ($solutions > 1000) {

}

# Let's also implement a more efficient version:
sub count_divisors {
    my ($n) = @_;
    my $count = 0;
    my $sqrt_n = int(sqrt($n));
    
    for my $i (1..$sqrt_n) {
        if ($n % $i == 0) {
            $count++;
            if ($i != $n / $i) {
                $count++;
            }
        }
    }
    return $count;
}

# Final approach
my $target = 1000;
my $n = 1;

while (1) {

    if ($solution_count > $target) {

}

## Final Answer

The least value of n for which the number of distinct solutions exceeds one thousand is **180180**.

The solution works by recognizing that the number of distinct solutions to the equation 1/x + 1/y = 1/n is given by (d(n²) + 1)/2, where d(n²) is the number of divisors of n². We iterate through values of n until we find the first one where this count exceeds 1000.
