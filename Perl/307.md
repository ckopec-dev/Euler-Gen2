# Euler Problem 307 Solution in Perl

I'll solve Euler Problem 307, which asks for the expected number of draws to collect all types of coupons when each draw gives a random coupon.

## Problem Understanding

We have a set of N different types of coupons. Each time we draw a coupon, we get one of the N types with equal probability 1/N. We want to find the expected number of draws needed to collect all N types.

This is the classic "Coupon Collector's Problem" with expected value E[T] = N × H_N, where H_N is the N-th harmonic number.

## Solution Approach

I'll calculate the expected value using the formula for the coupon collector's problem and implement it in Perl.

```perl
#!/usr/bin/perl
use strict;
use warnings;
use Math::BigFloat;

# Set precision for accuracy
Math::BigFloat->accuracy(50);

sub harmonic_number {
    my $n = shift;
    my $sum = Math::BigFloat->new(0);
    
    for my $i (1..$n) {
        $sum += Math::BigFloat->new(1) / Math::BigFloat->new($i);
    }
    
    return $sum;
}

sub coupon_collector_expected {
    my $n = shift;
    my $harmonic = harmonic_number($n);
    return $n * $harmonic;
}

# Main solution for N = 100
my $n = 100;
my $expected = coupon_collector_expected($n);

# Format output to 10 decimal places
print "Expected number of draws to collect all " . $n . " coupons: ";
print $expected->bstr() . "\n";

# For verification, let's also calculate with regular floats for smaller N
sub harmonic_number_simple {
    my $n = shift;
    my $sum = 0;
    
    for my $i (1..$n) {
        $sum += 1.0 / $i;
    }
    
    return $sum;
}

# Test with smaller values for verification
print "\nVerification with smaller values:\n";
for my $test_n (1, 2, 3, 5, 10) {
    my $expected_test = $test_n * harmonic_number_simple($test_n);
    print "N = $test_n: Expected = $expected_test\n";
}

# Calculate exact result for N = 100
print "\nExact result for N = 100:\n";
my $exact_result = $n * harmonic_number($n);
print "E[T] = $n × H_$n = " . $exact_result->bstr() . "\n";
```

## Mathematical Analysis

The expected number of draws to collect all N coupons is given by:

E[T] = N × (1 + 1/2 + 1/3 + ... + 1/N) = N × H_N

Where H_N is the N-th harmonic number.

For N = 100:
- H_100 = 1 + 1/2 + 1/3 + ... + 1/100
- E[T] = 100 × H_100
