# Euler Problem 102 Solution in Perl

## Problem Statement
Three distinct points are plotted at random on a Cartesian plane, where all coordinates are between 0 and 100, inclusive. We shall call the points A(x₁, y₁), B(x₂, y₂), and C(x₃, y₃). The triangle ABC is formed. We shall say that triangle ABC contains the origin if the origin lies strictly inside the triangle.

We are given 25,000 triangles, each defined by six coordinates (x₁, y₁, x₂, y₂, x₃, y₃). How many triangles contain the origin?

## Solution Approach
I'll use the barycentric coordinate method to determine if the origin (0,0) lies inside a triangle. The key insight is that for a triangle with vertices A, B, C, the origin is inside the triangle if and only if all barycentric coordinates are positive.

## Perl Implementation

```perl
#!/usr/bin/perl
use strict;
use warnings;

# Function to calculate the area of a triangle using cross product
sub triangle_area {
    my ($x1, $y1, $x2, $y2, $x3, $y3) = @_;
    return abs(($x1 * ($y2 - $y3) + $x2 * ($y3 - $y1) + $x3 * ($y1 - $y2)) / 2);
}

# Function to check if origin is inside triangle using barycentric coordinates
sub origin_in_triangle {
    my ($x1, $y1, $x2, $y2, $x3, $y3) = @_;
    
    # Calculate areas of sub-triangles
    my $total_area = triangle_area($x1, $y1, $x2, $y2, $x3, $y3);
    
    # Areas of triangles with origin
    my $area1 = triangle_area(0, 0, $x2, $y2, $x3, $y3);
    my $area2 = triangle_area($x1, $y1, 0, 0, $x3, $y3);
    my $area3 = triangle_area($x1, $y1, $x2, $y2, 0, 0);
    
    # If sum of sub-areas equals total area, origin is inside
    return abs($area1 + $area2 + $area3 - $total_area) < 1e-10;
}

# Alternative method using cross products (more robust)
sub origin_in_triangle_cross {
    my ($x1, $y1, $x2, $y2, $x3, $y3) = @_;
    
    # Vector from point 1 to point 2
    my $dx1 = $x2 - $x1;
    my $dy1 = $y2 - $y1;
    
    # Vector from point 1 to point 3
    my $dx2 = $x3 - $x1;
    my $dy2 = $y3 - $y1;
    
    # Vector from point 1 to origin
    my $dx3 = 0 - $x1;
    my $dy3 = 0 - $y1;
    
    # Calculate cross products
    my $cross1 = $dx1 * $dy3 - $dy1 * $dx3;
    my $cross2 = $dx2 * $dy1 - $dy2 * $dx1;
    my $cross3 = $dx3 * $dy2 - $dy3 * $dx2;
    
    # Check if all cross products have the same sign
    my $sign1 = $cross1 > 0 ? 1 : ($cross1 < 0 ? -1 : 0);
    my $sign2 = $cross2 > 0 ? 1 : ($cross2 < 0 ? -1 : 0);
    my $sign3 = $cross3 > 0 ? 1 : ($cross3 < 0 ? -1 : 0);
    
    # If all signs are the same, origin is inside
    return ($sign1 == $sign2) && ($sign2 == $sign3) && ($sign1 != 0);
}

# Main program
my $count = 0;
my $filename = "triangles.txt";

# Read the triangles from file
open(my $fh, '<', $filename) or die "Could not open '$filename' $!";

while (my $line = <$fh>) {
    chomp $line;
    my @coords = split(',', $line);
    
    # Extract coordinates
    my ($x1, $y1, $x2, $y2, $x3, $y3) = @coords;
    
    # Check if origin is inside triangle
    if (origin_in_triangle_cross($x1, $y1, $x2, $y2, $x3, $y3)) {
        $count++;
    }
}

close($fh);
print "Number of triangles containing the origin: $count\n";
```

## Alternative Cleaner Solution

```perl
#!/usr/bin/perl
use strict;
use warnings;

# Function to determine if origin is inside triangle using cross product method
sub contains_origin {
    my ($x1, $y1, $x2, $y2, $x3, $y3) = @_;
    
    # Calculate cross products for each edge
    my $cross1 = ($x2 - $x1) * (0 - $y1) - (0 - $x1) * ($y2 - $y1);
    my $cross2 = ($x3 - $x2) * (0 - $y2) - (0 - $x2) * ($y3 - $y2);
    my $cross3 = ($x1 - $x3) * (0 - $y3) - (0 - $x3) * ($y1 - $y3);
    
    # All cross products should have the same sign (positive or negative)
    # This means the origin is on the same side of all three edges
    my $sign1 = $cross1 > 0 ? 1 : ($cross1 < 0 ? -1 : 0);
    my $sign2 = $cross2 > 0 ? 1 : ($cross2 < 0 ? -1 : 0);
    my $sign3 = $cross3 > 0 ? 1 : ($cross3 < 0 ? -1 : 0);
    
    return ($sign1 == $sign2) && ($sign2 == $sign3) && ($sign1 != 0);
}

# Main execution
my $count = 0;

# Read triangles from input
while (my $line = <STDIN>) {
    chomp $line;
    my @coords = split(',', $line);
    if (contains_origin(@coords)) {
        $count++;
    }
}

print "Answer: $count\n";
```

## Key Concepts

1. **Cross Product Method**: The most robust approach uses the cross product to determine which side of each edge the origin lies on
2. **Sign Consistency**: If the origin is inside the triangle, it will be on the same side of all three edges
3. **Edge Cases**: The method handles degenerate cases (when points are collinear) properly

## Time Complexity
- O(n) where n is the number of triangles
- Each triangle requires constant time operations

## Space Complexity
- O(1) additional space

The solution correctly identifies triangles that contain the origin by checking the relative positions of the origin with respect to each edge of the triangle using cross products.
