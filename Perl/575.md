# Euler Problem 575 Solution in Perl

I need to solve Euler Problem 575, which asks for the sum of all distinct values of n such that there exists a positive integer k where the number of divisors of n is equal to k, and the number of divisors of k is equal to n.

Let me break this down:
- We want n such that d(n) = k and d(k) = n, where d(n) is the number of divisors of n
- This means we're looking for n where d(d(n)) = n
- We need to find all such n and sum the distinct values

Let me approach this systematically:

```perl
#!/usr/bin/perl
use strict;
use warnings;

# Function to calculate number of divisors
sub num_divisors {
    my $n = shift;
    my $count = 0;
    
    for my $i (1..int(sqrt($n))) {
        if ($n % $i == 0) {
            $count++;
            # If i is not the square root, we also count n/i
            $count++ if ($i != $n/$i);
        }
    }
    
    return $count;
}

# Function to find all n such that d(d(n)) = n
sub solve_euler_575 {
    my $limit = 1000000;  # Reasonable limit to find solutions
    my %solutions = ();
    
    print "Searching for solutions...\n";
    
    for my $n (1..$limit) {
        my $d_n = num_divisors($n);
        my $d_d_n = num_divisors($d_n);
        
        if ($d_d_n == $n) {
            $solutions{$n} = 1;
            print "Found solution: n = $n, d(n) = $d_n, d(d(n)) = $d_d_n\n" if $n <= 100;
        }
        
        # Progress indicator
        if ($n % 100000 == 0) {
            print "Processed $n numbers...\n";
        }
    }
    
    # Sum all distinct solutions
    my $sum = 0;
    for my $n (keys %solutions) {
        $sum += $n;
    }
    
    return $sum;
}
```
