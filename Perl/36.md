# Euler Problem 36 Solution in Perl

## Problem Statement
The decimal number, 585 = 1001001001₂ (binary), is palindromic in both bases.
Find the sum of all numbers, less than one million, which are palindromic in base 10 and base 2.

## Solution

```perl
#!/usr/bin/perl
use strict;
use warnings;

sub is_palindrome {
    my $str = shift;
    return $str eq reverse($str);
}

sub to_binary {
    my $num = shift;
    my $binary = "";
    
    while ($num > 0) {
        $binary = ($num % 2) . $binary;
        $num = int($num / 2);
    }
    
    return $binary || "0";
}

my $sum = 0;

for my $i (1..999999) {
    # Check if decimal number is palindromic
    if (is_palindrome($i)) {
        # Convert to binary and check if binary is palindromic
        my $binary = to_binary($i);
        if (is_palindrome($binary)) {
            $sum += $i;
        }
    }
}

print "Sum of all palindromic numbers in base 10 and base 2: $sum\n";
```

## Alternative Optimized Solution

```perl
#!/usr/bin/perl
use strict;
use warnings;

sub is_palindrome {
    my $str = shift;
    return $str eq reverse($str);
}

my $sum = 0;

# Check odd numbers only (even numbers in binary end with 0, so can't be palindromic)
for my $i (1..999999 step 2) {
    # Check if decimal number is palindromic
    if (is_palindrome($i)) {
        # Convert to binary and check if binary is palindromic
        my $binary = sprintf("%b", $i);  # Built-in binary conversion
        if (is_palindrome($binary)) {
            $sum += $i;
        }
    }
}

print "Sum of all palindromic numbers in base 10 and base 2: $sum\n";
```

## Output
```
Sum of all palindromic numbers in base 10 and base 2: 872187
```

## Explanation

The solution works by:

1. **Checking palindromes**: The `is_palindrome` function compares a string with its reverse
2. **Binary conversion**: The `to_binary` function converts decimal numbers to binary representation
3. **Iterating through numbers**: We check all numbers from 1 to 999,999
4. **Double palindrome check**: For each number, we verify it's palindromic in both base 10 and base 2
5. **Summing results**: When both conditions are met, we add the number to our running sum

The optimized version uses Perl's built-in `sprintf("%b", $i)` for binary conversion and only checks odd numbers since even numbers in binary will always end with 0, making them non-palindromic.

The answer is **872187**.
