# Euler Problem 305 Solution in Perl

I'll solve Euler Problem 305, which asks for the sum of all numbers n such that the first 12 digits of n^3 are equal to n.

## Problem Understanding

We need to find all numbers n where the first 12 digits of n³ are exactly equal to n itself. For example, if n = 123456789012, then the first 12 digits of n³ should be 123456789012.

## Solution Approach

1. We'll iterate through potential values of n
2. For each n, calculate n³
3. Extract the first 12 digits of n³
4. Compare with n
5. Sum all valid n values

    my ($number, $digits) = @_;
    my $str = "$number";
    return substr($str, 0, $digits);
}

    my $limit = 1000000000000;  # 10^12
    my $sum = 0;
    my $count = 0;
    
    print "Searching for numbers where first 12 digits of n³ = n\n";
    
    for my $n (1..$limit) {
        # Skip if n is too large to be meaningful
        last if $n > 10**12;
        
        # Calculate n^3
        my $cube = $n * $n * $n;
        
        # Get first 12 digits of n^3
        my $first_12_digits = get_first_digits($cube, 12);
        
        # Check if first 12 digits equal n (as string)
        if ($first_12_digits == $n) {
            $sum += $n;
            $count++;
            print "Found: n = $n, n³ = $cube\n" if $count <= 10;  # Show first 10 results
        }
        
        # Break early if we've found enough numbers
        last if $count > 1000;  # Prevent infinite loop
    }
    
    return $sum;
}
